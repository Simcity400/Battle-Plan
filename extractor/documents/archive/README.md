# Extractor Archive

This archive keeps old extraction plans, research notes, lane reports, proof
packets, and status snapshots out of the active documentation path.

Use archived files as evidence only. The active extraction backlog and
completion state live in `../MASTER_EXTRACTION_CONTRACT.md`.

Archive layout:

- `plans/`: superseded cross-extractor plans and status summaries.
- `research/`: historical memory-reader/reverse-engineering notes.
- `native_lanes/`: lane-local reports, proof packets, blocker notes, and
  registration patch plans that are not the active source of truth.

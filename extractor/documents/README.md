# Extractor Documents

Active extractor documentation is intentionally small.

| File | Purpose |
| --- | --- |
| `MASTER_EXTRACTION_CONTRACT.md` | The only active extraction completion checklist and backlog. |
| `DOMAIN_REGISTRY.md` | Compact domain ID registry. |
| `REVERSE_ENGINEERING_TOOLING.md` | Tooling setup and reverse-engineering workflow notes. |

Historical plans, research notes, proof reports, lane packets, and superseded
status files live in `archive/`. They are evidence only.

Do not create another extraction completion plan. Update
`MASTER_EXTRACTION_CONTRACT.md` instead.

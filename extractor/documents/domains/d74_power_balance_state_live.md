## Condensed knowledge











D74 is the passive, all-country POWER-BALANCE STATE census of the exact-a729
global manager. It is not a panel. It installs no hook, calls no engine
function, and does not depend on any player having a screen open. The A37
`CPowerBalanceView` panel carrier that used to be domain 74 was deleted on
2026-08-18: it read the local player's open politics screen, which is client UI
and therefore not something a multiplayer HOST may record.

Identity law (RE closed 2026-08-18):

    manager      = *(u64*)(gamestate + 0x450)      gamestate = module + 0x3316E90
    records_base = *(u64*)(manager + 0x08)   count = *(i32*)(manager + 0x14)   stride 0x190
    record +0x08 u8  validity        +0x10 ptr balance definition
           +0x18 ptr left side       +0x20 ptr right side   +0x28 ptr trending side
           +0x30 i64 value_raw_fixed5   +0x38 ptr member u32[]   +0x44 i32 member count
           +0x68 ptr range ptr[]     +0x74 i32 range count  +0xb0 ptr active range
           +0x178 ptr gfx override[] +0x184 i32 override count  (element stride 0x50)

Every authored token is an MSVC SSO `std::string` (`capacity > 15` selects the
heap pointer): balance id at `definition + 0x10`, side id at `side + 0x10`,
range id at `range + 0x718`, override side id at `element + 0x08`, override GFX
at `element + 0x30`. Per-member accumulators are country modifiers `0x98`
(daily) and `0x99` (weekly) at `country + 0x5B8`.

Two facts shape the reader. **There is no consistency witness** anywhere on the
manager or the record, proved by exhaustion over the exported mutation
functions, so the reader copies the WHOLE census twice and requires the two
passes byte-identical — per-value closing reads prove one value at a time and
can never prove that two values came from the same moment. And **the value
changes daily, weekly and on scripted effects, never per tick**, and records are
appended lazily and never individually removed, so an hourly whole-census copy
is both cheap and correct.

A record whose member array is EMPTY is ordinary state, not a malformed payload:
decrementing the manager's record count, so a balance every country has left
keeps its record with no members. Live capture t79 lost every d74 hour to a
grammar rule that refused exactly that.

`_r2_power_balance_presentation_live` (the panel-shaped envelope) has no
producer and is an unconditional typed null. Under the derivation rule the panel
is derived at replay from this state plus the certified installed content; d74 must
never fabricate it.

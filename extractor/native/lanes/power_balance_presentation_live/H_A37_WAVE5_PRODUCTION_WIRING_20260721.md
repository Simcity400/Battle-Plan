# H-A37 wave-five production wiring

The remaining static engineering gap is closed without promoting the evidence
gate. `PBP2` schema 3 now carries the exact controller/GUI panel-open join, the
post-materialization QPC, QPC frequency, and the complete immutable selected-
Present receipt identity. The recorder fold preserves every custody field.
`replay_core` rejects d74 unless that receipt mechanically equals
`production_render.selected_present` for the same hour, candidate, ordinal,
selected/cutoff QPC, frequency, and receipt digest.

The Windows owner now has a real MinHook detour at terminal controller writer
RVA `0x01C4BAA0`. Installation validates the exact entry sentinel, calls the
original first, reads owner/selection/open/GUI-visible state in-process, and
samples QPC only after the writer returns. The owner can seal a pointer-free
resolved frame only against the same callback receipt. Disable, callback
quiescence, and hook removal are explicit. While activation is false,
installation is possible only with `BATTLE_PLAN_A37_EVIDENCE=1` and cannot schedule
d74.

The collector owns the hook lifecycle. In evidence mode it installs at capture
startup, obtains current/change/open/visibility and non-null selected-record/
range custody from the post-original callback, joins that raw receipt to the
hourly early-render selected Present, writes a pointer-free JSON receipt, and
uninstalls at teardown. It accepts no caller-authored PBP2 and the production
seal additionally requires every activation latch. The scheduled compact loop
has a real d74 emission call, but it is intentionally unreachable because
`PRODUCTION_SCHEDULING_ENABLED`, both observer activation latches, and the d74
registry descriptor all remain false/reserved; promotion is an explicit gate
review after the two live cases and central validation.

On replay, the A37/A25 typed model and portable asset identities are consumed
inside the same selected-Present runtime that executes the authenticated UI
pass. The execution receipt reports the A37 companion row count. It does not
paint reconstructed power-balance widgets: the pixel frontier remains solely
`AuthenticatedUiPass`, matching the existing A34 typed-companion rule.

The owner packet `H_A37_LIVE_FIXTURE_OWNER_20260721.json` requires two distinct
selected Presents with opposite nonzero current/change signs. The offline
regrader closes only the raw controller spine, panel visibility and QPC order.
It requires `pbp2_emitted=false` and an explicit unavailable-field ledger.
Stable semantic identities, range frame/geometry, icons, text, decisions and
full replay parity remain unproved, so even a passing raw receipt cannot
activate or schedule d74.

The complete acquisition owner is now
`extractor/native/scripts/Invoke-A37PromotionAcquisition.ps1`, with guarded UI
transactions in `Invoke-A37AutonomousControllerTransaction.ps1`. Each required
sign case starts a fresh exact-a729 process from the frozen D04 save. The
collector receives `BATTLE_PLAN_A37_EVIDENCE=1` at process creation, while its
case-local evidence directory is deliberately withheld until the target value
and change transaction has completed and the BOP panel is open. The collector
therefore retries rather than freezing an earlier zero-change callback. The
wrapper publishes the two exact filenames consumed by
`regrade_a37_live_fixture.py`, writes the regrade output atomically, and binds
all raw, transaction, recorder, attestation, verifier and supporting-matrix
identities in `a37_promotion_acquisition_receipt.json`. The existing screenshot
matrix remains supporting evidence only and is never substituted for either
raw selected-Present case.

# Charts

The in-house chart kit every widget draws with. It has no chart dependency: charts draw on Canvas 2D so dozens of animated widgets stay cheap, and one shared scheduler drives them all. Everything here except the DOM readers is pure and tested with `node --test`.

| Module | What it does |
|---|---|
| [scheduler.ts](scheduler.ts) | One `requestAnimationFrame` loop. A task draws when woken and keeps frames coming only while it is still moving; hidden tasks never draw; the loop sleeps when nothing moves. |
| [surface.ts](surface.ts) | Backing-store size from the canvas's real on-screen size (which includes the widget's Size zoom and display scaling), and pointer positions in layout pixels. |
| [tokens.ts](tokens.ts) | Theme values a chart draws with, read from CSS variables through a probe element, and `APPEARANCE_EVENT` for re-reading them. |
| [palette.ts](palette.ts) | The categorical palette for categories (not countries), solved per theme for 3:1 contrast, and `nudgeApart` for the fixed-colour setting and faction colours. `lineStyles` gives any number of lines a distinct look: each keeps its preferred colour (`lineColours`) where free, and every further round of lines the colours again with dashes of its own (`lineDashes`). |
| [timeAxis.ts](timeAxis.ts) | Ticks from the recording's own hours: decade, year, quarter, month or day, with labels centred on each period's visible part (quarters on their first tick). |
| [valueAxis.ts](valueAxis.ts) | Nice linear and log ticks; exact formatting of recorded fixed-point integers (`formatFixed`, and `formatAmount`/`formatSigned` for amounts as the game shows them); and `formatAxisValue`, the time chart's default value label, written exactly with the precision its ticks need (read on exact decimals), so no two ticks read the same. |
| [view.ts](view.ts) | Zoom state and its reducer (wheel, box, pan, dragging either axis, resets), playback domains (draw-in, cursor, window), how far past the playhead a chart shows, and axis settings. |
| [series.ts](series.ts) | Runs of recorded values: `runAt` for any run type, `sameStretch` (whether a value may glide between two hours: no gap, break or change of country between them), `clipToSpans` (runs cut to a date range or a group membership, keeping a line break only where a run starts) and `extentOfAll`; gap-aware segments, sampling, a monotone curve and stacking. |
| [intervalIndex.ts](intervalIndex.ts) | `IntervalIndex`: items spanning hours that may overlap (such as trade deals), found at any hour without a scan; `intervalIndexOf` builds one once per product reply. |
| [useChartTokens.ts](useChartTokens.ts) | `useChartTokens` (the tokens, kept current) and `useViewportHeight` (the window height every tooltip is fitted to). |
| [easing.ts](easing.ts) | Shape easing for the app's motion setting and playback speed. |
| [rowMotion.ts](rowMotion.ts), [useRowMotion.ts](useRowMotion.ts) | Table rows that move like the signed-off tables: each slides to its new place when the order changes, a new row flashes in and a row that is gone fades out where it was (`nextRows`, pure and tested). `useRowMotion` renders only from the history last committed (`shownRows`) and updates it after each commit (`commitRows`), so StrictMode's double renders and abandoned renders change nothing. The `.moving-row` styles in [charts.css](charts.css) glide over `--row-glide` and stay still under reduced motion, from the system or the app's Motion setting. |
| [labels.ts](labels.ts) | Non-overlapping end labels and label columns measured over the whole campaign. |
| [tooltipPlacement.ts](tooltipPlacement.ts) | Tooltips beside the pointer, flipped and clamped so they are never cut off. |
| [frame.ts](frame.ts) | The plot frame (hour/value ↔ pixel, linear or log, and where a strip under the plot sits), hit zones for the two axes, the plot and the strip, where the keyboard hover steps, and thin bar rectangles. |
| [draw.ts](draw.ts) | Canvas drawing shared by every chart: axes and gridlines (dates under any strip), gap-broken lines (solid or dashed) with a ringed end dot, a fill between two lines bounded by their drawn curves (coloured by which is higher), stacked areas, gap shading, event ticks, playhead, crosshair, box selection and end labels (muted for a secondary line such as a ceiling). |
| [strip.ts](strip.ts) | A bar strip under a time chart on the same time axis (mock-up economy-1's daily fuel gain and burn): each bar spans its hours with one amount up from a midline and one down, on one scale fitted to the bars in view, labelled in the value axis' gutter. Bars narrower than two pixels share a column that keeps the largest of each, so no peak is lost. A bar ending after the last hour shown is not drawn, since it is known only from its end. |
| [timeline/](timeline/) | Lane timelines: one lane per slot with bars for who held it and when, a left column naming each holder at the playhead, and the same zoom, hover and Jump to as the time chart. With the keyboard, the arrow keys step through lanes and bars and show each bar's tooltip, read out too. A span with `band` steps is drawn as a band whose thickness follows a value over its hours (a production line's factories each day), on the timeline's `bandMax`, so every lane shares one scale; it is drawn in whole pixel columns by one rule (`bandOutlines`, `bandHalf` in [layout.ts](timeline/layout.ts)): a column recorded hours cover fully is drawn at the thickest step touching it; a column a gap also touches stays empty, its thickest passing to the nearest column its own span draws (never across to another span), so rounding never fills over missing hours and no peak is lost; a stretch with no fully covered column keeps one column, its middle, moved one column away from a neighbouring run beyond more than a pixel of gap (resolved forward then backward, so at either plot edge whichever can move does), so no band vanishes and separate runs never touch across a visible gap; where the plot cuts a run is not a gap. A lane's band spans are placed together (`laneBands`), each column drawn by and in the colour of the span whose value it shows, so the rule holds between spans too; each drawn column also records the span and step it draws, and hover, the tooltip and Jump to describe what is drawn under the pointer (`bandHitAt`), even a short band moved off its own hours. Laying out is linear in the steps and the plot's columns, and a lane's layout is kept while its lane and view are unchanged (`laneBandLayouts`), so moving the pointer lays nothing out again. The keyboard stops at each band step shown as well as each bar (`laneStops`, on `keyStops`), so every value the pointer reaches is reachable. A `muted` lane is faded in the left column, such as a line that has ended. |
| [badges.ts](badges.ts) | Event badges: small glyphs along the top edge with a guide line down the plot. Hovering one snaps to its hour and names the event; a click picks it; right-click jumps there. The time chart lists the badges it draws, in its current view, as text for assistive technology. |
| [TimeChart.tsx](TimeChart.tsx) | The time chart component: layers, an optional `strip` under the plot (hovering, wheel, pan and a time-only box zoom work there too), a value axis fitted from zero or, with `fitValues`, to both bounds of what is drawn, its left side widened to fit the widest value label (unless the widget sets `padding.left`), value labels formatted with every tick drawn so neighbours stay apart, zoom that holds during playback (wheel, box, Shift/middle-drag pan, axis drags, double-click and Escape resets, a Reset zoom chip), live hover and right-click. With the keyboard, the arrow keys hover through `keyHours` (else a day at a time), Home and End go to either end, and Escape leaves; the hovered tooltip is read out, and the context-menu key and Enter act on the hovered hour. A navigation key takes the hover from the pointer, and moving the pointer takes it back ([hover.ts](hover.ts)), so the hour drawn, its tooltip, what is read out and what the keys act on always agree; the menu key opens one menu at that hour, and the browser's own menu event after it opens no second one. Pass every read as `keyHours`: a range or zoom that starts between two reads gets a stop at its start, where the earlier read's value is carried (`keyStops` in [frame.ts](frame.ts)). |
| [tooltip.ts](tooltip.ts), [TooltipLayer.tsx](TooltipLayer.tsx) | One tooltip for the whole dashboard, fed structured rows (never HTML), rendered in the top layer so no widget clips it and the native map stays visible; `tooltipText` reads a tooltip as one line for assistive technology. `fitTooltip` fits a tooltip to the window: the fullest of its forms that fits, else the most compact cut with its totals kept and one row counting the rest, never cut off by the window; the full content stays in `spoken`, which `tooltipText` (and so the time chart's keyboard read-out) reads. |
| [Legend.tsx](Legend.tsx) | A legend for two or more series, with each series' current value. |
| [jump.ts](jump.ts) | The "Jump to <date>" menu item, which asks the clock to seek. |
| [drill/](drill/) | The drill-down: its state (follow playback or a picked day), settings fields, Pin as widget, the host (a slide inside the widget or a panel beside it) and the parts list (swatches in the chart's colours, shares and a total row). `drawBands` and `divergingStack` draw a stack of signed parts. |

Widgets show loading, empty, error and "Not in this recording" with [WidgetState](../components/WidgetState.tsx). The Appearance settings' **Charts** section holds the app-wide chart motion (snappy, smooth, cinematic) and country colours (raw or adjusted); charts read both from `ChartTokens`.

## Rules

- **Shapes ease; numbers stay exact.** Labels and tooltips show the recorded value at the resolved hour; only positions glide. Nothing eases across a gap, and a gap is never drawn as zero.
- **No fixed dates.** Axes, ticks and ranges come from the recording's start and end; settings store offsets from the branch start.
- **No fixed colours or sizes.** Draw with `ChartTokens`. Countries use their recorded map colours; categories use the palette in its fixed order, and a ninth category folds into "Other".
- **Sharp at any Size.** Size the backing store with `backingSize` and draw in layout pixels; never stretch a canvas.
- **Zoom holds during playback.** A zoomed axis keeps its range until the user resets it.

# National spirits history

Every national spirit the country had, on the lane timeline ([charts/timeline](../../charts/timeline/)): one lane per spirit, its icon and name on the left with "Active since", "Held before" (already held when recording began or after an unrecorded stretch, so the day it was gained is unknown) "Ended", "Ended by" (it ended during an unrecorded stretch; the day shown is the first recorded one without it) or "Last recorded" (the hours after it are not recorded, so it may still be held), and a bar from when it was gained to when it ended. Ongoing spirits run to the playhead in the accent colour. Right-click jumps to that moment.

**Settings:** sort by date gained (default), date ended or name; ended spirits shown (default) or hidden. Data as [National spirits](../national-spirits/README.md).

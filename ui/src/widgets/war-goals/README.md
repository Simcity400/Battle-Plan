# War goals

The Diplomacy page's War goals widget and the expandable panel beside the Wars timeline read the exact-hour `wargoals` product. They show the complete owned inventory, the separate unused roster, all state/liberation/puppet targets, stored expiry, and justifications in progress. Lists preserve repeated native occurrences.

Progress is the stored native points and total, not a clock-based estimate. Completion uses the native stored-end/remaining-cost display rule. Payment pause status uses recorded political power; an unknown payment operand stays unknown. Expiry never removes an inventory entry before the native writer does. An unused goal does not assert that a declaration is enabled.

The view requests data for its selected country and displayed hour only. The Wars panel requests it when expanded. Replies for another country, branch or hour cannot supply the displayed values. Missing tables, unresolved countries and unrecorded action eligibility remain named diagnostics. Type names resolve through the recording's content stack.

Owned goals and active justifications show definition terms from recorded content: annexation, generation operands, default expiry, peace-term limits and cost/tension factors. Default expiry does not predict a justification's eventual grant time. A conditional term has no single inventory-wide result: its peace-action context and a stored outcome are absent, so the result is explicitly refused. Historical upfront political-power amounts are refused because the activity retains no payment amount. Progress totals are displayed without assuming they always measure days.

Names substitute ACTOR and TARGET through recorded country names. Allowed/available authored conditions use shared trigger descriptions in the native actor/target scopes; unsupported descriptions appear in counted diagnostics. Empty conditions and unavailable descriptions remain distinct. Next actions list only the displayed inventory pairs: a live war or the same nonzero faction blocks justification and declaration; each unresolved action retains its own reason and counted refusal.

## Exact GPU-visible law closed from FILE + CAPTURE

The shipped gather shader performs, in source order:

```text
mean_log = ordered mean of the gathered log-luminance samples
target_f32 = clamp(exp(mean_log), MinHdr_MaxHdr.x, MinHdr_MaxHdr.y)
last_f32 = point_sample(previous_r16, uv = (0.5, 0.5)).r
adapted_f32 = last_f32
            + (target_f32 - last_f32)
            * (1.0 - exp(-InvSize_TauDeltaTime.z))
current_r16 = R16_FLOAT_render_target_conversion(adapted_f32)
```

compiler's exact scalar instruction/reassociation sequence because no compiled-shader disassembly

instructions, not silently substitute host math.

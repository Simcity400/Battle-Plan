## Exact traversal law

The source pass scans class-0 pixels row-major in retained BMP storage order.
The helper uses cardinal neighbours only, in this exact priority:

1. left `(-1,0)`;
2. right `(1,0)`;
3. up `(0,-1)`;
4. down `(0,1)`.

Ordinary continuation accepts unvisited classes 3..11.  For a deferred class-1
or class-2 marker, the helper prepends the first already-visited neighbour in
the same priority, appends the marker, then resumes ordinary continuation.
Ordinary continuation wins over another special marker.

## Exact centerline transform

Points 0, 1, `n-2`, and `n-1` are unchanged.  For `i=2..n-3`:

```text
s = f32(q[i-2] + q[i-1])
s = f32(s + raw[i])
s = f32(s + raw[i+1])
s = f32(s + raw[i+2])
q[i] = f32(s / f32(5.0))
```

The update is in place, so later windows consume earlier smoothed results.
Division by `5.0f` is required; multiplication by `0.2f` produces different
later bits.  Every raw walk is uniquely inverted and replayed by this law.

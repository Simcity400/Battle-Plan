## Promotion contract

Carrier inputs and outputs are:

```text
eye    = carrier + 0x180
target = carrier + 0x18c
up_in  = carrier + 0x198
fov_y  = carrier + 0x1a4
aspect = carrier + 0x1a8 = f32(viewport_width) / f32(viewport_height)
near_z = carrier + 0x1ac
far_z  = carrier + 0x1b0

forward = normalize3(target - eye)
right   = normalize3(up_in cross forward)
up      = normalize3(forward cross right)

V = [ right.x, up.x, forward.x, 0 ]
    [ right.y, up.y, forward.y, 0 ]
    [ right.z, up.z, forward.z, 0 ]
    [ -dot(eye,right), -dot(eye,up), -dot(eye,forward), 1 ]

t = trig(fov_y * 0.5)
y = 1 / t
x = y / aspect
A = far_z / (far_z - near_z)
B = (-near_z * far_z) / (far_z - near_z)

P = [ x, 0, 0, 0 ]
    [ 0, y, 0, 0 ]
    [ 0, 0, A, 1 ]
    [ 0, 0, B, 0 ]

VP = V * P
inverse(VP) = Pinv * Vinv
```

This is row-vector, left-handed D3D clip depth `[0,1]`. `V` is stored at
carrier `+0x000`, `P` at `+0x040`, `VP` at `+0x080`, `Vinv` at `+0x0c0`,
`Pinv` at `+0x100`, and `Pinv * Vinv` at `+0x140`.

Matrix multiplication uses the exact non-FMA SIMD order for every output row:

```text
out = left[r][1] * right_row_1
out = out + left[r][0] * right_row_0
out = out + left[r][2] * right_row_2
out = out + left[r][3] * right_row_3
```

Each step is `MULPS`/`ADDPS`. The reflected branch reflects eye and target
about the supplied plane, flips `up.y`, computes `V * (P * R)`, and stores
inverse `R * Pinv * Vinv`, where `R = diag(-1,1,1,1)`.

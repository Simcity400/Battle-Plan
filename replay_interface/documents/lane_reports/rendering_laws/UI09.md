## FILE facts recovered

### National focus

`interface/nationalfocusview.gui` (SHA-256 `c2c02a79...94e88`) authors:

- root `nationalfocusview` at `(-3,78)` and scroll host `tree` at `(0,47)`,
  percent-sized to the parent (`lines 3-6,120-128`);
- host margin `(top,left,bottom,right)=(13,13,24,25)`, left/middle drag, and
  vertical/horizontal scrollbar styles (`lines 120-128`);
- `grid_window=(0,0)`, nested grid local position `(50,50)`, nominal grid slot
  `1x1`, and `format=UP` (`lines 147-157`);
- node/link templates and the named canvas constants: node `165x128`, link cell
  `16x16`, `focus_spacing=(96,130)`, center `(130,32)`, link spacing `(16,16)`,
  link begin/end `(80,64)/(80,0)`, plus exclusive offsets (`lines 493-673`);
- focus zoom controls and PageUp/PageDown shortcuts, but no scale value, range,
  step, clamp, or transform (`lines 90-118`).

This materially narrows the old blanket `TreeNodePixelPitchUnavailable`: pitch
constants do exist in shipped FILE. It does not close the engine transform;
the `focus_spacing` consumer, zoom multiplication/rounding, and pan composition
are still missing.

### Technology

folder as its own scrollable canvas. The infantry host is `(0,47)` with margins
`13/13/24/25`, left/middle drag, both scrollbars, and wheel factor 40
(`lines 29-49`). Its `infantry_weapons_tree` grid is local `(140,325)`, slot
`70x70`, `format=LEFT` (`lines 269-275`). BBA air includes `60x70` grids
(`lines 2918-2930`). The full infantry item is offset `(-56,-7)` and `183x84`

The CGridBox loader is durable exact-a729 evidence for the fields, but the
runtime semantics of `format=LEFT`, template choice, line construction, and
draw order are not present. A formula from folder x/y and `slotsize` to node
pixels is therefore not promoted.

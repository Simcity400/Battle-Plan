## Strong-concavity glyph-VB gate

The verifier checks all 23 retained `mapname_7b` VBs are whole 20-byte-stride, six-vertex glyph quads; resolves every UV rectangle through the retained `hoi_mapfont4.fnt`; hashes every VB; and independently recomputes the quarantined quadratic residual only to rank test cases. The three largest maximum residuals are `draw001:BRITISHIRAQ` (1.137622), `draw005:FRANCE` (0.947160), and `draw002:UNITEDKINGDOM` (0.877668) world units. This establishes exact fixture identities for the three previously documented strong-concavity outputs; the retired quadratic is not used as engine authority.

It cannot establish producer equality. The 7B fixture explicitly contains only VBs, constant buffers, and the font atlas description. It contains no capture-time owner/controller province raster. Those inputs determine the medial stations, trimming, phantom controls, component choice, and therefore the expected Catmull-Rom vertices. Reconstructing them from a different save or visually fitting controls to the captured VBs would be circular and non-exact. The verifier replaces the ambiguous document-level `UNITEDKINGDOM #2` name with exact fixture identity `draw002`, but its capture-time connected-component identity remains absent.

## Port audit finding that prevents closure

The exact function computes cumulative straight-layout glyph advance divided by total advance, clamps that fraction, and applies it directly as the spline parameter before the `0.5` segment split. The current product path instead calls `placement.t_at_arc_fraction(arc_fraction)` in `build_mapname_vertices` (`map_label_law.rs:381`), numerically re-inverting curve arc length before evaluating the curve. The existing test at `map_label_law.rs:2907` only proves uniform stepping on a straight baseline, where the two laws coincide. This is a real semantic mismatch for curved controls and means existing same-implementation parity tests cannot substitute for engine glyph-VB equality.

No source or canon files were changed in this lane.

Then compare decoded engine and replay glyph vertices in draw order, including positions and UVs, with an explicit float/byte equality policy. Until that passes—and the direct-parameterization mismatch is resolved—N02 must remain open even though no additional spline family remains to reverse engineer.

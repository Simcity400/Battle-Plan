### Engine producer and frame law

Constructors `0x1418a6be0` and `0x1418a5390` instantiate the named VP and
capital containers. Initializers `0x1418baa20` and `0x1418b8d00` resolve the
children named `icon` and `text` into object fields `+0x90` and `+0x88`.
Refresh functions `0x1418b5df0` (VP) and `0x1418b2e80` (capital) write the
label and select the icon frame through the child `+0xb0` virtual call.
Wrappers `0x1418bc3b0` and `0x1418bbd50` join those refreshes to the update
path.

The relationship selector is exact and one-based:

- enemy: `1`;
- same tag or same faction: `3`;
- otherwise: `5`.

Capital icons use that selector directly, yielding one-based frames `{1,3,5}`
and zero-based atlas columns `{0,2,4}`.

For non-capital VP icons, let `b` be the zero-based bucket selected from the
three shipped thresholds `{0,9,20}` and let `r` be the relationship selector.
The engine call is:

```text
one_based_frame = r + (3 - b) * 5
```

Thus the three VP bands occupy frames `{16,18,20}`, `{11,13,15}`, and
`{6,8,10}`; capitals occupy `{1,3,5}`. The unused positions in each five-frame
band are not synthesized or compacted.

### Icon draw state

The retained icon events are four-vertex triangle strips using VS resource
`157`, PS resource `158`, `MapTexture_Texture`, and `MapTexture_Sampler`.
The SRV is `580x27 B8G8R8A8_UNORM` with the exact strip payload hash above.
Sampling is linear min/mag, point mip, clamp-edge U/V, wrap W, max LOD 1024,
and mip bias `-0.800000011920929`. Color and alpha both use
`SrcAlpha / InvSrcAlpha`, operation `Add`, write mask 15.

### Text draw law

The retained text SRV is `512x256 B8G8R8A8_UNORM`, raw SHA-256
`2c451af07c7eea59cf2f3ba72f3b8e035e2e635fe0db74caca18e8b2dc961f25`.
That hash exactly equals the 128-byte-header-stripped payload of shipped
`gfx/fonts/hoi_20bs.dds`; it does not equal `hoi_mapfont4.dds`.

The font descriptor is Ubuntu Light, size 20, bold, line height 20, base 16,
atlas `512x256`, padding 2, spacing 1. The text path emits six vertices per
glyph with stride 28 and uses the authored `(26,5)` origin. Mechanical decoding
of the two retained VBs gives:

- chunk `22870`: `København` plus glyph id 0; pen X values
  `26,36,45,54,63,72,81,89,97,106`;
- chunk `23233`: `Königsberg` plus glyph id 0; pen X values
  `26,36,45,54,58,67,74,83,92,98,107`.

For every glyph, the UV rectangle maps exactly to the `.fnt` x/y/width/height,
the emitted rectangle is exactly the unscaled glyph width/height, X equals pen
plus x-offset, and Y equals `-(5 + yoffset + height)..-(5 + yoffset)`.
The resulting local baseline is exactly `-(5 + 16) = -21`. This is a 1:1
bitmap-font emission law. No `0.40` term occurs in the producer or geometry.

The text shader pair is VS resource `124`, PS resource `125`, with
`SimpleTexture_Texture` and `SimpleTexture_Sampler`. Sampling is linear
min/mag/mip and wrap U/V/W. Color uses `SrcAlpha / InvSrcAlpha`, `Add`; alpha
uses `One / Zero`, `Maximum`; write mask 15.

The first text draw has zero output delta. This is retained as an
occluded/no-op observation, not used to negate the label law. The second text
draw changes 1,044 pixels and is the positive pixel discriminator.

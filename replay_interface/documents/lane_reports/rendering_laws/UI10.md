## Focus topology

Across 81 effective `common/national_focus/*.txt` files, the exact usable graph
contains:

- 67 focus trees;
- 10,888 uniquely identified nodes: 10,273 tree-local `focus`, 335
  `shared_focus`, and 280 current-1.19 `joint_focus` nodes;
- 71 tree import references selecting 26 unique shared/joint roots;
- 27,155 typed edges: 13,734 prerequisite edges, 2,743 mutual-exclusion edges,
  and 10,678 relative-position edges.

Every import root and every edge endpoint resolves, with zero ID collisions.
The verifier computes each tree's imported connected component and effective
node count. It follows only shared/joint-to-shared/joint edges for branch
closure; a link to a tree-local focus remains a valid anchor and does not pull a
different country's whole tree into the component.

### Fixed defect

`parse_focus_def.py` previously recognized top-level `shared_focus` definitions
but silently omitted the 280 top-level `joint_focus` definitions introduced by
the current game. This made 23 of the 71 authored imports appear unresolved,
including ABDA, Saadabad, Habsburg, Lingguang, Ma Clique, and Indonesia roots.
The parser now accepts both kinds and exposes `joint_focus_count` separately.

## Composition boundary

UI10 closes definitions, topology, shared imports, and typed current/completed
subsets. It supplies nodes/edges/state to UI09, but does not claim canvas origin,
pan, clipping, zoom, draw order, resize persistence, or pixel equality. Those
are governed by UI09's canonical fail-closed production contract. In particular,
the 95 semantic subdoctrine positions must not be interpreted as `row*96`
pixels; UI09 proves one selected subdoctrine per track, 88px reward rows, and
75px candidate rows.

### Mechanical determinism fix

The original verifier persisted Cargo's elapsed-time strings in
`roundtrip_test_output_tail`. Identical successful runs could therefore change
`verifier_result.json` (`0.08s` versus `0.43s`) and invalidate UI09's frozen
typed-graph hash without any semantic change. `verify_ui10.py` now replaces
only Cargo/test elapsed durations with `<elapsed>` while retaining the command,
test name, pass/fail counts, executable path, exit code, and all topology data.

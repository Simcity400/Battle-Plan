## Air promotion contract

The exact fill producer is `0x140dff6e0`, reached by the dispatcher pre-hook
for internal ID `1`. The zero branch precedes division. Extractor output retains
`our`, `enemy`, `aux_left` and `aux_right`; it does not record evaluated colour.
For an unavailable lookup, retain absence and reproduce the proven all-zero
NEUTRAL branch.

The retained neutral carrier's dominant storage-order BGRA is
`(119,131,140,0)`, matching shipped RGB `(140,131,119)`; Channel2 provides
high-colour alpha byte `255` at all `2,883,584` active-layer texels.

## Infrastructure promotion contract

The exact producer is `0x140f1d0c0`. It calls the cap getter at
`0x140f1d182`, reads nominal level at `0x140f1d371`, divides at
`0x140f1d37d..0x140f1d389`, loads the two endpoint globals, and calls the
componentwise lerp at `0x140f1d3db`.

Production resolves the active building definition and fallback define from the
recording's effective modset, including effective `common/buildings/*.txt`
selection and `replace_path`; vanilla `5` is a fixture, never a fallback.
Extractor rows need the signed nominal installed level and resolved definition
identity. They do not need evaluated RGBA or damage-adjusted level.

Frame 141165's immutable resource contains none of the six old level/5 byte
candidates because it is immutable creation content, not the current producer
result. This negative capture finding is not a colour oracle and does not
contradict the instruction-proven law.

## Factions promotion contract

1. A country without a faction uses the shipped non-member colour.
2. A member retains its faction leader tag and resolves the leader through the
   proven COL3 pipeline: raw RGB → HSV, saturation `*0.6`, value `*0.8`, then
   HSV → RGB and the proven byte quantization.
3. Apply member alpha `1.0`; fail closed only for a malformed faction link or
   unresolved leader colour.

The retained differential changes AST COL3 BGR `(92,114,73)` to ENG leader
COL3 `(108,91,160)` for **22,793** interior pixels, SAF `(139,113,156)` to ENG
for **5,501**, and MON `(64,112,96)` to SOV `(51,46,100)` for **7,617**. ENG,
SOV and GER remain their own leader COL3 colours. This rejects member-own and
raw-leader-colour implementations.

## Naval promotion contract

The exact mode-2 pre-hook is `0x140dffd80`. For each region it applies these
producer rules:

1. If the activity value at region `+0xA0` is below `1000`, skip contestant
   scanning and emit carrier word `0x00FF`.
2. Otherwise, a contestant is active when country `+0x0C != 0`, or when its
   resolved object exists and object `+0x24 != 0`.
3. An active entry is flagged when `(entry_flags & 0xfffffff7) != 0`.
   Track whether any flagged entry and whether any unflagged/bit3-only entry
   exists. If any flagged exists, select colour global `0x14331a5c0`; else if
   any unflagged exists, select `0x14331a700`; else select `0x14331a530`.
4. Helper `0x140deba80` calls the naval classifier and maps result `1 → 0xFF`,
   `2 → 0x80`, otherwise `0 → 0x00`. Its second output begins at zero and may
   become `0x80` or `0xFF` from POV/visibility state. Pass both bytes to the
   region emitter `0x140f26950`.

The producer does not contain the shipped `0.5`, `0.8` or `2000` constants.
The `0.9f` immediate in its table setup is unrelated. Global `0x14331a660` is
loaded but never selected in this function; preserve that incidental finding.
The runtime opacity scalar at `0x143319c58` is zero in the static image before
loaders run, so it is not evidence for an alpha curve.

The captured water draw binds Channel1/2/3 at pixel-shader slots 12/13/14.
Channel2 green is zero at all `2,883,584` active top-layer texels; nonzero red
occurs at `192,713` and nonzero alpha at `135,134`. Channel3 raw BGRA is enemy
`[83,54,255,255]`, friendly `[255,195,13,255]`.

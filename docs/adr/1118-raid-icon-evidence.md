# Rebuild raid icons for the recorded hour and viewing country

The game rebuilds its raid cache when the local player changes. The viewer rebuilds that view from the recording as if the viewing country had just become the player. Active and ended raids are visited in country-slot order, active before ended, with each list kept in recorded order. A raid owned by the viewing country stays owned even if its target also belongs to that country. Incoming active raids require detection. An ended raid needs a non-cancelled outcome and the viewing country in its display list. At a province, the first registered incoming raid wins over an owned raid, and either wins over an offer. A nonempty country reference that cannot be joined through `CountryLinks` is undecided. An empty reference is separate from that refusal.

The game populates the player cache's allowed-type list at load, reset or a player-country switch. Its forced membership rebuild leaves the list intact. For the recorded cache's raw country, use its recorded list even after the triggers' inputs change. Another raw country, including a successor that shares its tag, evaluates the list at the viewed hour. The country raid-status eligibility list is a separate input. Without an authenticated cache, any viewing country may have been its owner. An unnamed cache member or used type may be any otherwise possible type. An unreadable declaration keeps any matching target undecided. Use the current recorded table rows for daily inputs, including rows carried forward from the last read. Report a reached refusal with the responsible name and retain independent facts.

A target must be valid and foreign. Visibility, category restrictions, used-up state, detection and the target script decide its shown types. Affordability, availability, cooldown and unit reach decide their tint. Free-targeting categories bypass the ordinary map filter. The offer unlock still runs the category visibility and availability checks. An absent category definition matches the game's empty category. Counts use wrapping bytes because the game tests those bytes for zero. Uncertain launchability can prove a tint only when every possible count gives the same zero test. Unknown `allowed` or tint leaves the offer grey with a reason. Unknown target membership withholds its icon. Missing incoming art retains a named stand-in and diagnostics.

Imported type and template tokens use the recorded literal and ASCII folding. Ambiguous, missing and unsupported keys give named refusals. The content-derived template and glyph caches resolve without holding their locks. Concurrent callers may duplicate work to avoid waiting while another caller builds the same value. A province offer uses the first shown target as its anchor. State buildings use the first province of the unmodified recorded state list with a matching site. Content order is admissible only while recorded membership agrees. A state or leader target can instead resolve to its province or the province nearest its state's centre. Map groups keep distinct identities even when drawn at the same province.

While playback advances, each built hour evaluates one rolling batch. A paused hour continues that cycle until complete. The viewed frame may draw only icons built for its branch, hour and canonical country, and pending or refused work can keep the screen empty. Revisiting the same hour must retain its evaluation so a saved-frame step cannot restart a completed cycle and wait on it again. An offer row keeps its last evaluation until the cursor reaches it. New rows join the cycle. Replacement or loss of a row's identity resets the cycle. Reusing an offer layout requires the same offer allocation, lexical table and state-order result.

The icon's signed priority comes from the low byte of the content define. A missing or nonnumeric batch-size value in a present raid section loads as zero and is then raised to one. A missing section remains refused. The standard camera includes both height-band edges, and the raids map mode has its own maximum. Map modes without raid icons hide them through the same path as leaving the band. A free camera computes the distance of each anchor. Layout scales the device viewport into interface pixels, using the first unit-stack position. The viewer sorts prepared windows by their draw rank and hit-tests in reverse. Pool insertion order can diverge after moving the camera or reusing slots. Preparing an hour does not mutate presented windows. Offers selectively enable the frame, own and incoming raids enable the glyph, and details display the selected strip frame without turning a viewer click into a game action. An inherited sprite retains the derived control's geometry. An unsupported hit shape blocks lower windows without dispatching an observer.

# 1302. Pack political borders from region fields

Political fill uses two RGBA8 textures with matching, stacked region layers separated by zero guard rows. The stock layers group sea provinces by strategic region and land provinces by recorded controller. Neither uses a state layer in political mode. Both textures follow the province bitmap from its north edge downward. Channel 1 stores region colour and distance alpha. Channel 2 stores naval control, opacity, pulse and contested bytes in that order. Field operands and presentation resolve through the recorded content stack.

Province IDs index the layer's region mapping directly. Key zero is outside a layer. Uncovered pixels use alpha 255 and zero effects, while region interiors beyond a boundary's reach keep their colour and opacity at distance alpha zero. Coastal pixels can borrow colour and effects from adjacent regions without acquiring interior fill. The effects byte accumulation wraps before division. Each output texel averages its source pixels vertically with truncation, then averages the byte results horizontally. Preserve both truncations for parity.

Country thickness interpolates from region area using the configured bounds directly. Strategic regions have a fixed thickness. A map mode can specify a fixed thickness and leave the country centre band at zero. The fill factor changes only alpha below the outline range, and the distance field bias caps the boundary at 247 so the land pass keeps it below its outline cutoff. The optimisation range supplies a minimum search reach, while the bucket radius can limit the actual search.

Resolve each key into a dense index and evaluate its colour once on the calling thread so per-pixel work needs neither a hash lookup nor a caller closure. Grid cells hold four-neighbour boundaries, wrap at the horizontal seam, and have no neighbours beyond the poles. The distance to nonempty cells skips empty interior work. Keep the original bucket scan order and close-distance early exit even when using a lower-bound test to skip a bucket. The CPU oracle writes disjoint, top-down row bands without materialising a full-resolution plane. Production uses the GPU path.

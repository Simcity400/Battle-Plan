# Share stable viewer inputs and keep display pacing separate from simulation

Index country identities by raw link and canonical slot. An identity-only index can be reused across hours even when power changes cause the country table to be reallocated. Size the index from observed rows, including dynamic countries. The complete identity index needs complete country and link tables. Consumers that can use known rows from a partial walk retain their own read. Appearance tags are optional, and only matched country rows can supply them.

Hold shared render objects by device and pipeline key while any view still uses them. Creation holds the device cache lock through the factory so two simultaneous view initializations share one object. Window pacing uses the refresh of the window's current display or a supplied harness rate, clamped to the application's frame limit. Re-read modes periodically instead of querying each frame. A frame with no observed rate uses the budget fallback. The fastest currently open window caps the shared simulation's processing without selecting its rate. Opening a slower pop-out cannot slow a faster main view. Dropping the faster window leaves the slow window's rate in effect.

Mirror shader constants using explicit register-sized storage. HLSL packs adjacent vectors and floats within a register, and a vector that cannot fit starts a new register. Preserve padding even when a shader field does not have an active read. WGSL consumes each CPU matrix row as a column for its transposed convention. Wrapped and actor draws share the local snow and mud presentation fade, while the sky uses the original camera. Shadow fade depends on camera distance and does not depend on old shadow values beyond the cutoff. Fog fades by the square of the remaining linear fade and contributes only with an available matching fog input. Ownership and controller views share political fog gates.

Use raw replay-hour modulo for the day/night phase. Its offset from the interface hour is intentional. Lighting strength can ease independently of simulation weather and position. Virtual light positions blend as the cycle strength falls, and the animation clock supplies the renderer's local epoch for water, fog and weather, with a deterministic zero for dumps. A seek initializes wind at the settled recorded target instead of inventing a load transient. The hourly weather target holds no rendered interpolation state, so its unobserved transients cannot be restored. The virtual sun direction follows the hour separately. Preserve the linearized authored light colours and the renderer's per-frame plane inputs.

Read the recorded mod stack's speed table as single-precision intervals in game order. Keep the authored padding and truncation to five positions, and an interval of zero or less admits any rate. The slowest sufficient speed classifies the replay rate. At the fastest speed the cycle fades out so it does not flash, while pause retains it. One speed right on a nominal boundary can classify differently after the recorded precision conversion. Unreadable content gets a named refusal.

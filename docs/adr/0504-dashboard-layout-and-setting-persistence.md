# Persist portable dashboard layouts and rebase immediate settings

Store allowlisted layout and option values independently of runtime paths, source IDs and query data. Slot and picker sequence state belong to the live session. Restore Overview through its layout library key without reading or deleting legacy single-layout keys. When stored data is unreadable, show the default and report the restoration problem. Reset can clear it. Compare sanitized layouts canonically so object key order does not signal a change. Each page has its own stored layout and retains drafts only while that page exists.

Retain unsupported widget versions and undeclared option values without migrating them. A generic parse preserves legal stored scalars even for an uninstalled widget. A control applies the current field's validator and falls back to its default when necessary. Saving a value equal to the default removes its override. Preserve content choices across campaigns that do not offer them. Escape non-token characters in stored content-set keys and keep mod country tags opaque. A rejected tag drops by itself and produces a restoration warning.

Apply immediate settings as changes from the drawn widget to the current widget, merging options per key so two actions based on one render can both land. Save only the view preferences being changed, leaving other layout drafts intact. A campaign change carries its country and time choices with it once the saved layout holds the referenced tracks. Before that it is a draft. A pin takes its time from the playback position and its dates from its own loaded branch. A selected branch can follow a join recorded by its source, and a missing selection falls back to the template. Only the clock changes playback time.

Widget option content is loaded in a separate component keyed by widget kind, so changing the widget cannot change the surrounding panel's hook sequence. The panel keeps a saved unavailable choice visible, and dates labels and faction choices at the widget's hour. A legal typed number saves immediately without losing in-progress text such as a minus sign or negative zero. The control recognizes its own saved echo even after JSON writes `-0` as `0`. On leaving, empty text means automatic in a field that supports it, and other invalid text returns to the saved value. A title edit commits on blur or Enter. A picker that closes its own settings row restores focus to the settings button.

Maintain the saved breakpoint layouts as complete widget sets. Narrow layouts stack the initial arrangement in reading order. Duplicating a widget below another first makes room in each existing breakpoint so grid compaction cannot take the reserved slot.

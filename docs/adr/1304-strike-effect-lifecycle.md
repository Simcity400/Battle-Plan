# Strike effects retain one transient slot per province

**Status:** Accepted

Each recorded nuclear strike, critical bombardment or completed missile scenario requests an authored effect entity, resolved from the recording's content stack. A launch-flagged aircraft effect can also place an explosion in a drawn province of its mission region when the launch entity completes. Strike effects stand on the province's standstill unit-stack anchor at object scale one. A missile's landing path can use a different scenario anchor without moving the explosion. Use the province's admission box to decide whether the effect can draw or retire. A new impact replaces any previous effect in that province even when the requested entity is missing. Named refusals distinguish partially available strike rows, unavailable tables and impacts without a recorded place.

The effect stays placed below the content's object cutoff. After the admitted root's actual animation variant reaches its end, retire the slot. A root with no playing clip can retire on its first check. A player that has not been created yet does not retire. Hidden display switches do not change the presentation or retirement rules. Test the clock that the installed player actually uses, including default and randomized clip variants.

Process shown hours oldest-first. During forward playback, skipped prepared hours can start their effects too. The individual impact's sub-hour instant, renderer clock and particle seeds are unavailable in the recording, so starts use the presentation clock and stable effect-specific seeds. Deduplicate nuclear IDs and consume map events once. A branch change, perspective change, gap or seek clears effect slots and restarts presentations for the shown hour. A failed hour surfaces its event refusal and resets the outstanding queues while preserving the same deduplication boundary as a prepared hour. A restart of the presentation clock restarts the effect's age. Each start has its own incarnation, even when successive hourly missile plans reuse the same flight and cycle numbers. Distinct incarnations must resolve distinct actors and animation clocks, such that an older effect playing in another province cannot be restarted by a later plan. The scene classifies resulting impact sounds as combat.

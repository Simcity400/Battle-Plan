# Separate hourly overlay products from presentation state

Workers prepare camera-independent overlay tables once for a branch, hour and canonical viewing country. Use declared rows at the head while the map playhead is open and the decoded frame otherwise. When a head read reaches an undeclared table, the read is unavailable, the dependency is reported, and the window can retain its previous complete presentation. Each worker learns its own reads. Raid offer path searches run on the worker, and the view draws a completed raid batch only for the matching hour. A layer-owned part is left vacant by the general maker. The window can then insert the layer's own results without duplicate work or cross-perspective reuse.

The camera projects immutable province fields and prepared labels without rereading the hour. Counter memory and already drawn plates remain reusable when the placement, stack and style agree. A refused projection leaves the existing view in place. The overlay identifies the table publication and the versions of its layer products. A changed layer product, asset decode or newly covered engagement history can require a new layout for the same hour. Read engagement coverage before building to avoid certifying a build with a flag that was unavailable while it was made. Intel readers race to publish the same deferred result without blocking another reader. Labels and intel from a new layer product must match the viewing country.

Each map view owns its presentation clock, windows, hovers and selection. Icon layout is in interface pixels and scales to device pixels on draw. The sprite batch uses the content's priority order for overlap, and raid icons remain separately replaceable. Advance the province schedule once before workers snapshot it. A quiet frame still advances active windows and the province schedule while preserving the last drawn batch, hits and reports. A draw refusal leaves its caller's previous outputs in place. Position changes can preserve static fields, and waiting for native window creation can require later frames even when the camera stays still.

Visibility filtering takes place with each producer so its native windows can retain their state. Hidden raid icons can still own a hover. A dump that omits the raid icon's group also omits that hover. Free-camera presentation transforms icons from their prepared state and uses the resulting shapes for hits. A dump takes its explicit recorded hour with settled units and can add named demilitarised states to the recording's own zone. Its cold path and the window's layered path report the same unavailable facts.

Use the smaller table memo for ordinary battle plans, keyed by the viewer and allied-plan request. Native adjacency triggers for invasions and labelled paradrops may require any table, so those requests use the full hour. Raid, trade-route and air arrows can share the scene's arrow manager. State air targets use the ordinary air-base queue, while hosted endpoints use the province centre. The trade route stop cache uses a nonblocking lock, and a competing builder searches its own route. Ships and land stacks built by their own layers are omitted from the general model preparation.

Playback holds recorded state per hour. Fractional presentation time goes only to consumers that can use it, such as in-flight raid presentation, while the recorded-hour dump sits at the exact hour. Recorded battles retain their order, geometry and object identity. Their audio uses that identity across hours even when the list reorders. Each battle counts all member combat units and includes template slots only for divisions. Disabled music stations have no weight, and an unreadable song body is refused by name. Unavailable fog inputs do not produce a fog draw.

# 0802. Preserve the game's military attribution and incomplete observations

Military aid, land army totals and casualty totals use different attribution rules because their inputs measure different relationships. These writers rebuild indexes after a resume, with their recorded tables holding the durable state. Live counts change only when an observed input or a relevant identity changes.

Military aid classifies each sender's live division references by channel. A volunteer's host is its division's logical owner. An expeditionary's host is the roster owner when the division's logical owner is the sender. Both lists skip null or dead references and count repetitions. Tallies come from the sender's `VolunteerHosts` vector and use the first listed count per host. Missing data is channel-specific. Duplicate lists, unresolved hosts, missing expeditionary references, and incomplete readings can withhold the sender's corresponding channel as a single count unknown row. An unassigned sender with a potentially nonempty list has a channel-wide unknown row and contributes no guessed pair rows.

Land army totals count each division under both its logical owner and roster host. A positive expeditionary owner supplies the logical owner. Strength sums finite nonnegative current hit points in fixed-five units. Manpower uses the game's wrapping dword arithmetic. Battalion counts use template composition and skip the null sub-unit definition. One unresolved owner withholds that attribution's totals for every country. Missing hit points, manpower or composition withhold the affected measure. Unknown composition also removes the affected mix rows. A country with a complete observation and no divisions gets a recorded zero. A template edit revisits only divisions of that template, and identity changes rebuild affected totals.

Each war relation lifetime is keyed by the pair of country identities and its start hour. The row is deleted when the relation disappears and its final counters remain available to historical readers. A country's cumulative dealt and taken totals include ended lifetimes. Unknown-attacker losses are copied across a victim's native relations, so the writer starts from a zero baseline and accepts a later increase only when every spanning relation agrees and a new relation's counter fits that increase. A negative increment, disagreement, missing spanning relation or gap irreversibly loses that unknown-attacker total for the run. Missing input, conflicting lifetimes, relations to oneself or unresolved identities withhold the hour. After a gap, an unobserved relation ending also leaves either participant's historical totals partial. Values outside signed 64-bit range stay unrecorded.

# Settle sprite animation only with a conservative clock proof

Determine whether a sprite can stop drawing from the translated stage. The graphics clock can change and the animation restart stays fixed. Track each buffer scalar's influence on stage output. Local and private variables join every store, and calls join their argument and result states. Control-flow conditions influence any conditional store, return or discard, including loop exits. An unsupported instruction or exhausted fixed point conservatively treats every buffer byte as a direct dependency. A dynamic index or unsupported width spreads dependencies over the relevant span.

An affine value carries error bounds for the program's float operations. Rounding error grows with the magnitude of the exact expression and its operands' error. Division uses a larger bound than the correctly rounded arithmetic operations. Propagate error from subnormal flushing, and refuse a settling proof if intermediate values might overflow. For constant multiplication, conservatively include the constant operand's own error and its effect on the other input. For constant division, require a nonzero denominator whose uncertainty stays below its magnitude. Clock-dependent rounding can keep a value changing even when exact algebra cancels the clock.

Only a saturated affine duration since restart can establish a deterministic settle time. The direction must actually reach the bound. An explicit clock moment or unrelated scalar-dependent rounding cannot establish a duration that covers all inputs. The result includes an error margin proportional to the larger magnitude of the clock and restart and is limited to the range where the intermediate values stay finite. When `step` approaches its low result from above, the edge still has the high result, so the caller must draw the edge and settle only at the next representable duration. Conservative bounds distinguish that case from reaching a closed edge.

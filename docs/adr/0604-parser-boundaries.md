# Keep native consumption separate from balanced text parsing

The native reader follows script field dispatch, including its recoveries and retained token slots. Saves use the balanced reader and refuse structural truncation. Descriptor callers may choose EOF recovery for graphics, fonts and particles. This can close strings and blocks, including a block in a trailing comment, and reports whether it did. The word-scan fallback is explicitly lexical and continues past structural errors and NUL boundaries, retaining an unterminated final quote. Save header validation belongs to the caller, and reported parse offsets refer to original bytes. Save variable parsing separately admits the empty-name spelling the writer emits, applying the writer's signed fixed5 precision and sign rules.

Values preserve bytes and token kind until a caller chooses their representation. Escapes decode quotes and backslashes, preserving unspecified escapes. Stored strings stop at NUL and substitute the native unreadable text for a line feed. Callers can opt out of that substitution when they need the raw C-string text. Text conversion refuses invalid UTF-8 by field name and the owning reader propagates the first conversion failure as a gap. Never substitute prior definitions across that gap. Exact decimal spelling and precision remain available to the oracle independently of the scaled integer value.

Only bare token names eligible for ASCII case folding reach keyword dispatch. Quoted keys, punctuation, and numeric-start keys take the nonkeyword branch, and a quoted value bypasses variable resolution. References inherit the definition's type. Retained text in an End slot is never promoted to a token of that text's type. Leading NUL makes a numeric bare token while a slot without any byte retains its initial kind. Operators each consume one character, so the value read after `>=` is the second operator. A stray operator is an anonymous value in the balanced grammar and a candidate key in native replay. Duplicate tree entries retain source order and the first exact match is available.

Native math parsing consumes tokens independently of evaluation. An opening operand takes its first `value` key before checking the tail. Atomic operands do not consume another token and operand indexes are signed bytes with the native upper boundary. A failed expression consumes its closing peek and skips the remaining raw input. Unary operations accept the exact lowercase `yes` token text, including quoted input. Conditional chains consume consecutive `else_if` branches and an optional `else`, even after a branch error. A collection reads its initial name, a branch reads its initial limit, and a fixed two-argument operation consumes one closing token without testing that it is a brace.

Native lexer callers choose whether the initial byte-order mark becomes part of the first token. The byte `0xFF` advances the input and ends the current read. A bare token retains its text on that failure and a quoted string still succeeds. Resuming the enclosing reader can read past this byte. A file loop stops at End and an object loop also stops at the closing brace. Its closing read resolves any retained reference. Retrying after a lone question mark or comment preserves the marker when the next read fails. A peek caches its advance and a failed peek sets End while preserving the quoted flag and text. The effect lexer copies code after `[[` through the closing delimiter, dropping the initial whitespace through the first line feed and ending stored text at NUL.

A single-value field consumes its opening brace as its value. Following text is then parsed as enclosing fields, including the brace that closes that enclosing object. A field with a missing operator can leave the old operator and value slots while dispatch still uses the new key. Reporting examines the current lexer token for a block, and skips recursively with reference resolution but without installing definitions. Literal skips use raw braces. An unresolved missing-operator ambiguity stops the remainder rather than assuming a body reader. Capture an item's own operator before processing its nested fields. A definition can also leave a previous key or the initial empty key for dispatch when it ends the input. Variables are file-local, shared by nested key readers, keyed by FNV-1a of the name after `@` and classified by the retained defining token. A taken name can leave its assignment operator in the stream. Quoted and unknown references keep their text.

Dispatch determines whether a body requires an opener, consumes a raw list, consumes one value or checks a closing token. Direct object and list loops can process following fields even from a scalar value. The default adjuster takes two object reads. In raw lists, whether resolution updates the value slot is part of the caller's contract. An optional equipment list copies each entry into that slot before reading the following object and leaves the closing token in the lexer alone. A country-token list similarly keeps its value when it closes. Uniform two-string pairs take raw tokens even if those are operators or an opening brace, then report extra data and skip it without defining anything. A fixed raw span reports only its first excess token. A block passed to the special raw-text reader counts braces in comments and quoted text and resumes the same lexer position without changing its slots. Conditional effect bodies retain the verified `limit` binding and count the deferred-key gap. The on-research-complete reader peeks for its optional initial limit, then uses the resulting opener to admit the effect body. Conditional equipment tails are unavailable when the trigger result changes their consumption. The balanced recovery for a keyless list admits no variable definitions, including definitions nested inside blocks of a mixed list, and a mixed list with a definition refuses. Keyed-only variable definitions inside an unknown-dispatch block are tracked to that block; a trailing definition before the block's closing brace refuses rather than swallowing the brace, and when a later value or redefinition outside that block depends on one (or a skipped block would depend on an opening-brace value), earlier proved content is preserved and the affected suffix is refused by name without storing the ambiguous value.

Diagnostics retain each top-level item's notes alongside file-wide notes. A variable definition's report is file-scoped or unowned because it does not leave an item. Repeated reports retain their first line and count across the file while each item's count stays local. An unsettled remainder is excluded from parsed items, and a caller returning the refusal also retains counted warnings reached before the stop.

Balanced block spans count line feeds in opening-brace order, including tagged blocks. Recovery at EOF closes the reported span on the last input line. This order keeps spans aligned with a preorder walk of the recovered values.

Parallel content readers retain result order. Workers inherit the caller's job and priority because the caller waits on those workers. A scoped join resumes the worker's panic on the caller.

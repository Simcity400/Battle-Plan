# 0401. Record authored equipment identity from one complete variant census

Module and upgrade walkers use the same complete variant census as the definition table. An unavailable census cannot be represented by an apparently successful shorter slice. Each row records a content token from the authored key, and an upgrade also retains its raw level. The authored name header is not required to record the token. A process pointer can support demanded immutable operands during that visit without becoming a replay identity.

A containing variant authenticates its embedded module collection. The collection's candidate identity word is not a verified vtable. The module count is signed. The batch size for module entries preserves error ordering because the walker refuses a failed contiguous copy as one span. Upgrade destinations grow after bounded payload reads, on a caller that permits allocation.

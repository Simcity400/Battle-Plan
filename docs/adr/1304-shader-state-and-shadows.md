# Compiled map shaders retain physical binding state

**Status:** Accepted

Resolve shader and include paths through the recorded content stack. The audit opens the implicit DirectX header and compares bytes and both include graphs for a proposed replacement, so an identical replacement passes and removing an include is still visible. When base-only comparison is needed, use the same folder and archive semantics without visual overlays. Register independent mesh, name, terrain, weather, shadow, arrow and post techniques. Arrow definitions can select effect sources. Renderer globals are prepended even without caller defines, and power-of-two settings can pad file textures without changing generated texture dimensions. Where a visual replacement cannot supply a supported effect, report it and try the recorded effect by name.

Track native state by physical slot and preserve previous bindings through absent shader techniques. Upload only known members of a constant allocation. An uninitialized read within an allocation refuses differently from a read outside its end. A world copy begins with light grid constants in the shared pixel allocation, which land borders replace with their time and alpha block. River, rail, tree and water consumers inherit that state. Retain the scene buffer's known ranges by draw. A vertex ring append after binding is visible through the bound handle, so suspend or snapshot ranges only at the draw that consumes them. Prepared geometry and retained particles can reuse resolution per view without changing which native commands are published. Authoritative texture and sampler declarations determine capability requirements. Point sampling the float light table does not require filterable-float support.

The caster depth map and screen receivers share a semantic shadow binding, so each pass must bind the physical texture it expects. The float depth texture keeps authored filtering and names an unsupported device when that filtering is unavailable. A shadow depth target uses the receiver's fixed texel span and a clear depth of one. Each wrap uses the light view-projection and submits visible model casters, then trees and admitted arrows. The sky and terrain cast none. A held camera gathers caster candidates. The current main camera's ground and figure cull decide the casters actually submitted. The light anchors at the map camera's ground intersection with no cap. The free eye caps this intersection to keep the light continuous through the horizon. Build its orthographic footprint from capped corner rays and centre. Pad the fitted box and back off the near plane for raised casters, without enlarging the box for outside casters. Preserve floating-point operation order, including fit-axis flattening, independent normalization of the full light direction and transformed corner and view translation rounding before snapping. Signed truncation and ten-unit snapping keep shadows stable during pans. Seasonal and hourly sun position, including the nearest horizontal wrap, drives the light. Texture projection reverses the vertical clip axis and keeps depth in the comparison interval.

Retain the cast-shadow map only when the current light, admission, viewport, wraps, caster identities and order match the submitted frame, and every caster repeats its draw. A replacement pass has a new identity and animated arrows invalidate reuse. A frame abandoned before submission leaves target contents unknown. A cleared target can be reused while there are no casters. Tree and terrain receivers draw their usual geometry into BGRA8 with their own depth, preventing a farther ridge from painting over a nearer one. Receivers also run below the fog cutoff without shadow casters. If neither receiver nor caster runs, bind a one-texel fully lit and fog-free stand-in, initialized by a render clear. Clear the screen target as needed even without receivers because the next frame's seabed samples it. Repeated identical clears need not alter its content identity. The previous allocation's first-use zeros do not describe native outputs, so verification dumps warm up first.

Cast shadows and run their horizontal and vertical blur only when shadows are enabled and the camera is below the shadow cutoff. Both blur passes filter shadow and retain the centre sample's fog values. Offset scale depends on camera height and the output dimensions, preserving the footprint of the filter in view pixels. Horizontal scratch has no depth attachment. Vertical blur reattaches receiver depth and preserves the authored depth comparison and writes. A program that reads a screen texture by location, texel offset or size has to bind the full view dimensions. Check actual compiled program use rather than sampler labels. For straits, keep authored alpha writes so light contributes to the bloom seed. Their 16-bit indices wrap as authored rather than using an invented geometry cap. Sky draws with ordinary depth comparison, no depth writes or stencil, and rejects unknown initialized scene ranges or extra unsupported retained registers.

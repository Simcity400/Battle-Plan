# Retain deferred equipment corrections under complete source identities

Deferred reserve credits use the full source division handle so the index distinguishes handles sharing a type word. Its fixed chained lookup allocates only during preparation or drain growth. Removing a source recycles its nodes, and load reset changes the generation. Growth copies the owned provenance to the new capacity. A deferred deficit plus the credit actually posted preserves the source-time total. A merge retains only its amount. If observation is lost, the index advances its revision while each old head keeps its original revision. Signed duplicate entries sum at wider precision and only the serialized correction needs to fit the native width. This prevents a temporary out-of-range partial sum from discarding a valid final correction.

HQ return proves posted credit through the original reserve operation, independently of a request flag or the still-owned source pool. Even zero credit preserves a transfer witness. Later bookkeeping writes to a credited source cannot change its earlier deficit. The first source revision is kept from before observation, including when the first head has yet to be created. If a native callback was skipped or refused, the code cannot certify stale credit merely because its original ran successfully. Authenticated sources invalidate their own holds by handle; an unobserved operation with an incomplete receiver set may need wider invalidation. One source's successful retirement cannot restore another's contaminated proof.

The queued disposition outranks a later direct caller once a transfer is proved, while the fold still records a direct merge caller as context. A reused address never inherits a predecessor's witness. The merge reads each selected physical pool once before the original may free a source. It attributes signed pool deltas to the selected recipient for main equipment and to the actual resolved reserve owner for canceled deliveries. Each deleted donor can cancel both delivery families, while the survivor keeps upgrade deliveries. Its new live residual and a prior source-time credit are independent. Unlocatable bookkeeping and unattributable callbacks withhold the affected interval instead of inventing an unknown loss. The tests compare source-time credits, subsequent cleanup and complete receiver identity even when the post-call address can no longer be read.

Foreign unwind regressions use authored native callers for both the HQ reserve-return path and land damage path. The fixture exercises the actual observation around the original call, with a foreign exception after the intended bookend. A new load does not establish that Windows and native callers have left the callback. Production does not clear an active count without a completion witness. The fixture may clear it in teardown after its handler and all callers have returned.

# 1104. Prepare air counters from registered and recorded operands

Wing grids preserve the registered country pools and their occurrence order through first-fit grouping. Repeated entries remain repeated across bases. A country has access when its indexed container exists, independently of its capacity. Registry references that no longer resolve drop out. Carrier-base preparation walks every member ship. The hovered range overlay needs only the first eligible carrier. The base wrapper disables the standalone window's selected-individual splitting. A wing grid uses the prepared hour's simulation inputs and its own presentation clocks and selection. Its parts compose in the item's coordinates, and the outer holder transforms the hit regions. A successful paint commits the hits in order, keyed to each drawing's hover.

Regional mission membership follows the registered order. A wing contributes its plane count once to each selected mission. Low and very low supply summaries add just the Air supply entry. Ground Crews use the content's cost, the flag and the country's command power. A missing flag row reads as inactive only when the table is present. An unavailable supply column and each refused operand retain their own named reasons.

The latest daily air pass can affect the last-day interception window by pruning records before their age cutoff. An earlier pass only removes older records that the newest-first window would already skip. A pass at or before the branch's first sample is already reflected in rows captured after it. Apply the recorded daily roster only when pruning could change the alert. An unknown mission gate or missing observation stays unknown. A mission-kind and classification pair shares one interception aggregation per region. Regional lookup uses indexed regional holders and ordered wing registrations instead of looking up unrelated wings or countries for each entry.

When a prepared layer is presented, hovers use current-hour efficiencies and recorded wing order. Average them by plane count with the native signed fixed5 arithmetic. A wing with no planes contributes zero, so the hover demands none of its otherwise unused efficiency inputs. The Air base volunteer calculation indexes aliases once and evaluates each demanded host's ordered sites once.

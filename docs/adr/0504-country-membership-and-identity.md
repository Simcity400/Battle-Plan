# Resolve country choices against recorded identity and membership

Use recorded tag changes to follow a country through renames without attributing a later holder of its former tag to it. Resolve every origin in a simultaneous rename against the previous hour so swaps and chains move whole identities. The implicit first lineage interval alone cannot prove native existence. Split tag runs at holder changes before grouping them by identity, and bound alias runs by both the rename and the holder's lifetime. When breaking a ranking tie, compare tags in Unicode code point order, which also matches the Rust service's UTF-8 ordering. Locale collation and UTF-16 unit order can produce different results at a ranking boundary.

A manual multi-country choice requests its literal tag roots and lets the service expand their recorded aliases. A dated single-country choice instead stores the original tag and branch-relative hour, which bind it to the identity the tag named then. A provisional identity history never rebinds such a choice. Once the history is complete, an unresolved choice can bind to the sole holder or ask the user to select among several. Keep the literal choice separate from the bound identity's tag at the shown hour.

Group membership can be counted at the row's own hour, at the branch end, or across the branch. A gap in group history cannot establish an empty group and cannot create a join or a leave marker. A proven empty group can stop a log before it scans for rows. While group or identity history loads, an unresolved choice is not proof of an empty result. Request an hourly group's branch-wide union and apply the dated membership in views. The service interprets an empty unscoped request as the whole world, so a pending or empty choice must never send one by accident. For top-N, rank only recorded values per hour and use the widget's measure. A drawn membership projection never changes the requested roots.

Reuse the service's faction totals for summed factions. Other group totals can combine member lines from the events that change them, and require every expected member to have a recorded value. Split the result at gaps and identity breaks. Even a complete world total cannot establish what an unrecorded group's members contributed. Group comparison geometry uses numeric membership, independent of names and warnings. Preparation can expose an approximate prefix, and a completed reply replaces that sample when available.

Reached-hour requests include subject and content identity independently of the hour. The dashboard can keep an earlier successful answer for the same subject while the new request is pending or fails, but only an exact request-key match can label it current. A different subject with the same tag must not inherit the answer. State-name requests retain every requested state and hour unless the transport refuses the reply on byte budget.

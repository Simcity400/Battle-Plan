# Date stability components by their recorded sample

`CountryStability` combines the country's last sampled inputs with the current command power allocation. A missing command power row leaves free command power unknown. Country and command power changes recompute only affected countries. A fresh baseline, a resume or a change in completeness can invalidate every row. [Stability writer](../../crates/recorder-derive-politics/src/stability.rs)

`StabilityParts` numbers sources into stable handles in a separate dictionary and keys per-country rows by measure and handle. Parts follow the game's arithmetic and the order of the modifier tree. Equal sources combine, including unpaired lines with the same displayed text. A line is known only if the line sample matches the inputs' sample hour. Character identities are looked up when a part actually names a character. Their changes alone do not rewrite parts from a previous sample. When `SliceReads` advances, character-dependent parts must be reconsidered even if the input cells are unchanged. A known missing template is distinct from an unknown template or token. The writer restores its dictionary and held part keys from its tables on resume. If those reads fail during priming, the next hour attempts the rebuild and reports the named failure. [Parts writer](../../crates/recorder-derive-politics/src/stability_parts.rs) · [Input reads](../../crates/recorder-derive-politics/src/stability_parts/inputs.rs)

The breakdown gives the total first, then the nonzero formula terms. It separates the modifier into its witnessed sources and any unexplained remainder, then applies the clamp. An unknown required term withholds the breakdown. A missing `SliceReads` timestamp can represent a read that found no lines, so the timestamp is considered with the inputs and coverage. An identified character that has no script token uses an empty name token, while unavailable character or token data remains unknown.

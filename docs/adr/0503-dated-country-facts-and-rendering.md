# Scope dated country facts and presentation to recorded evidence

A followed panel can keep the same rows while their values advance across membership changes, coverage boundaries or seeks. Use the last applicable boundary at which the held values are current. Steps without a boundary do not render, and a panel landing again unchanged still wakes the frame readers. Followed names, colours and flags use the last observed identity transition in the held country timeline. This keeps a stationary pointer, a widget header and a timeline lane consistent at the same displayed hour. Until the timeline covers that hour, use the clock to request the correct fact. An equal application value cannot require a paint, so the frame-to-React state adapter checks equality before calling its setter.

Dated facts use the transient product route, so they cannot evict the widget's branch history. Answer during rendering from a timeline that already proves the requested hour, preserving the value's identity until the timeline is replaced. An uncovered hour can request a growing timeline again after its retry interval. A settled read wakes callers even when its previous timeline survives. Share one colour object per recorded map colour within that timeline and release those colours with it. Keep every wanted hour and retain least-recently-used unwatched hours up to the recent-demand budget. Grow that budget to the maximum number once wanted together, avoiding repeated loads on backward playback. A completed read with no value is answered, a refused request is failed, and an in-flight request is pending. Dated identities ignore display ordering, while artwork can prioritize the current visible order. Hours admitted by a caller's bounds remain independent of request execution order.

Queue only current demand and keep an active read when at least one requested hour remains useful. Suppress requests already being read. A transient refusal backs off while still wanted, and a product refusal waits for explicit retry or new content. Clear a failure when its exact demand leaves even if another country keeps that hour wanted. A finished chunk starts the next one without a render. Coalesce replies to one notification per frame and handle synchronous completion without recursively growing the call stack. Share a recording's reads only when a country's answer does not depend on the other requested countries. Batch refusal may bisect a plan and remember a size that fit for that scope, without treating missing chunks as successful. Use the single-hour path when applicable. Tests advance a deterministic request clock, model each admission layer's transient refusal, and use counted store lookups to verify the work bound.

Country looks read an exact dated value when requested and otherwise sample within each country's continuous recorded identity interval. A gap does not inherit an earlier sample. Pending names and artwork can keep a known same-interval value, while completed refusal or absence gets its own fallback. Fading race rows retain looks only while identity is still proven. Use the full country set for styles and the visible set for flags. Held look maps keep their reference while unchanged so they can serve as a paint dependency. Flag drawings share a recorded choice per recording, content generation and size. A time the timeline does not cover yet cannot select a picture. Content changes and lease release discard old drawings, and only transient failures retry automatically. Palette colours are accompanied by the names of countries whose recorded colours were absent once the reads resolve.

Recorded identity distinguishes a literal tag from a canonical slot. The reserved NUL prefix makes slot keys disjoint from validated tags, and structured request keys preserve opaque mod tags. User-facing labels resolve the tag a slot held on the dated evidence and may name a slot by its nearest known tag when dating a label. Only exact coverage establishes a fact read or selection. When more than one holder supplies a slot, the service chooses its lowest raw ID. Exact evidence supersedes approximate aliases at overlapping times. A manual tag can select all native holders that carried it, while a smart group requires contemporary membership. A drill binds the holder identified at its origin date and stores the original choice. Missing origins and conflicts remain unbound; when several recorded holders are possible, the picker asks which holder the user meant. Capitulation badges take only the events belonging to that holder and the displayed interval. With legacy data, absent identity evidence permits proven coverage, while an explicitly empty identity interval proves no eligible holder. Late replies must echo the requested identity before a view can show them.

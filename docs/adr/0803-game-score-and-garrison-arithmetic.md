# Preserve the game's arithmetic for scores and garrison strength

The end-screen score writer keeps the game's fixed-point operation order, including low-64-bit products before signed division, and narrows each factory term where the game does. The overall score uses the army, navy and air components. A country's air sum counts every occurrence of a wing in the registrations reachable from its first strategic-air list. Track all joins reached before an unavailable operand so a later change to that registration or wing can trigger repair. A change to a link or multiplier, a different availability state, or a resume rebuilds indexes and scores. Other input changes update only the countries that reached them and retain named reasons for parts that could not be computed.

Garrison strength is derived before playback so the cell can be read without decoding its opaque equipment operands. Sum assigned manpower with wrapping arithmetic over the occupation state's rows whose resolved controller and occupied countries match the garrison. An incomplete assignment table or unresolved assignment identity in that state can make the sum unknown. Missing equipment operands and a refused capture remain distinct from zero assigned manpower or an explicit game requirement failure. The game's low-64-bit products, signed division and sentinel handling apply. Each repeated fixed5 multiplication rounds separately, so exponentiation by squaring would change the result. The weaker manpower and equipment result sets the strength.

# 1105. Keep naval combat and result icon decisions with the prepared hour

## Decision

Prepare the naval icon placements, their combat censuses, headquarters frames and result decisions per replay hour and viewing country. Camera rebuilds apply the recorded decisions. Rejoin details and grid members using combat handles and their province on the hour drawn. This also lets the naval marker layer supply its prepared values without exposing borrowed frame positions. A missing row produces a named omission. The combat icon pass has its own strict content distance cutoff and province-icon gate. It can build the ship context lazily for a large icon even when the unit counter pass is hidden.

## Live icon updates

- The direct pass admits naval entries in each province's stored vector order. The bound province of a direct icon comes from its call's anchor, independently of which vector named it. Rotate only when the bound province is the combat's own province. A spillover-only icon retains its background without rotating. When a spillover deduplicates onto a direct icon, it can update that icon's ordinal while preserving its bound province. Use the bound province's standstill anchor and move the icon down by its ordinal times the measured window height.
- A complete empty census with no direct combat reference needs no placement pass. A missing combat or side reference can leave existence or admission undecided. A known empty side erases the icon. Keep an undecided icon's identity, rotation state and placement when known, and preserve the distinction between erasure and waiting for an update. The spillover pass resolves only the units the recorded transfers name, through the complete key-sorted unit tables. A stopped chain leaves the whole spillover pass undecided. Name each omission with its cause and affected combat in windowed diagnostics, map details and the dump. An unavailable combat window omits each decided placement with a common cause.
- The viewing country's engagement index supplies flags and prior frames. A rotating engaged update writes the background frame and fills progress. A rotating unengaged icon keeps its slot's last engaged frame, or uses the index's answer in a new view. A history gap uses the binding's initial frame and reports the limitation. A spillover keeps its slot's prior background and needs no engagement answer for its own rotation. Report load-rebuilt flags as a limitation. A small widget draws when the camera is coarse or two entries of any combat class in the province's complete vector are engaged. That finding is conclusive even if a later entry is unknown. If enough entries could be missing to change the answer, the progress size is undecided. Direction follows the attacker's primary countries in order.
- Every live icon gets the headquarters frame after combat rotation, including a previously placed icon still retained by the pool. Use the side whose primary list contains the viewer, trying the attacker first. Consider only live ships in that side's forward groups and their viewer-owned task forces with attached naval headquarters. A known qualifying force decides the answer regardless of unresolved members. If no force qualifies, report the first unresolved member. An unresolved country reference can leave the side undecided.
- A rotation clears the grids. A large engaged icon can append attacker task-force tiles in allegiance runs and the attacker's convoy addition, then the same items for the defender. Each tile takes the port item's first-member visibility and mixed-owner flag rules. Resolve positive expeditionary owners and require the complete censuses used by the grids. Retain the authored convoy sprite if its replacement is missing and report the limitation. Convoy tint uses the side's allegiance or the first country's UI colour, with the authored other-allegiance colour for an empty list. Count each item refused by the window's authored capacity.
- Derive hover and click targets from presented native controls. Tooltip hits include visible progress controls. Click hits that open a battle only include the relevant background and frame buttons. Match the exact inherited handler binding for specialized actions. Apply holder clips in logical-parent coordinates using the screen origin. The diagnostic rectangle can have zero area at a clipped edge while native hit-testing remains authoritative. Inverse text hit geometry uses the measured font height and the unscaled layout offset.

## Retained results

- Keep one result icon per province. Store the result country's lists by their recorded ordinals. Admission uses list 2 and result visibility additionally uses side lists 0 and 1. A strike or a member with a copied sinking string makes an admitted side's result visible. A reached unresolved country yields an unknown result. Take the land or sea anchor associated with the province.
- Select the first applicable sprite category from all naval strikes, all port strikes, a majority of convoy battles, and other battles. A convoy majority uses more than half of the held references. Expired references are included in that denominator. Resolve the outcome frame as lost 0, won 1 or mixed 2. A readiness flag on every resolving result selects frame 2. Empty resolving results satisfy the all-strikes and all-readiness tests.
- An incomplete result census leaves province icon existence undecided even if no result row is available. A complete empty result census ends the pass. Run the retained result owner and manager on the presented frame. A missing or invalid content window, including a missing typed background button, omits and counts the visible or undecided provinces. A known hidden icon creates no omission.

# 0105. Capture operation and command events before their live owners disappear

Operation completion is copied after the native original reports a new successful completion and before its caller can repeat or destroy the instance. The callback preserves the complete native return value. An invalidation or unsuccessful call supplies no completion. Each observation gets a log-wide order across per-thread lanes, shared slots, and whole-record spills. A thread can publish through the shared lane when dedicated lanes are exhausted, and a description exceeding its byte ring can spill without waiting for the consumer. A failed spill allocation refuses the affected interval by name. Description demand records the rejected size so the next generations can grow without retrying the original read.

An off-thread offer becomes current at a lane boundary. It seals the previous generation only after active publishers leave. A caller keeping the old generation follows its sealed successor. Old records retain the byte-ring allocation they came from. A new byte ring may be published without losing an observation epoch, and generation storage is freed only after callbacks and consumers quiesce. A native unwind that escapes the callback leaves its old flight retained, because Rust cleanup does not certify that native return has finished.

The spool merges sealed records by global order and stops at the first unpublished order. Later cross-thread events do not cover a missing reservation. Admission advances the assembled boundary so a later queued frame can make progress, but it does not release records, bytes, or their sizing demand. Only committing a successfully written frame releases them. Failed conversion, encoding, or I/O leaves consumption intact. Loss recovery can reassemble from the last written interval. Discarding an unwritten old generation records any affected events as lost. Stale handoffs cannot move the epoch backward, and attach restores the exact historical sequence without rewinding it for an older campaign.

The command callback likewise has one nonwaiting writer and publishes immutable records. Accepted commands can arrive before the first hourly snapshot and while the game is paused. The command lanes grow from roster and burst demand. A packet without an emitted world cannot prove its coverage, although status still names the first refusal. The collector invalidates every interval a refusal could affect and charges its count to the latest world only once. Build-specific command classes are matched by verified name hashes and separated into ordinary categories and categories that can change the player roster or selected country.

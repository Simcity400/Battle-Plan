# 0805. Compare intelligence state by serialized occurrence and owner

The save witnesses targets of operation-buffer references that resolve to persisted instances. Buffer membership, order, and freshness are runtime-only. Incoming actions and assigned operative slots join by their owner and writer ordinal. Null action slots do not shift later identities. Duplicate ordinals are refused, while moving an ordinal produces a missing and an extra occurrence. An incoming action stores its wrapper ID and body definition but has no saved status byte. Its saved `initiator_matters` and `type` are separate operands. Ordinal assignment verifies presence and full handles, while retaining the literal saved mission block payload (absent, empty, or populated) without equating it to recorded selection words because the selection protocol is unproved. An absent parent operation or an unresolved owner is reported.

The operative roster preserves its native order and every saved membership. Join it by the full reference, including its type, and keep active and recruitment scopes distinct. Match recruitment and assignment keys through exact recorded lexical spellings. Unproved keys, vector widths, and unsupported assignment operands remain explicitly limited. Operative experience uses the inherited unit-leader writer’s nonzero gate, so an omitted `experience` field certifies exact zero independently of explicit zero or nonzero values. A mission action discriminator is distinct from the operative’s operation handle. The save gates the mission block on that discriminator, the country target on a positive reference, the state and ideology on the corresponding mission subtype and presence, and the portrait and unit leader name on stored text. An omitted nonpositive country reference has no tag. A stale operation instance fails its own comparison without aborting the roster. Cooldown reason and dates follow the inherited writer’s nonzero-kind gate.

The operation serializer witnesses required targets, optional date and duration, positive-count slots and phases, a nonzero province reference, and the prep requirements and equipment pool in native order. Manager history and priorities and the running operation census are distinct. An omitted running block means no running rows. A recorded extra row is counted once. Native description text is truncated at the first NUL, strips CR, and converts LF to a literal escape before the game writes ordinary text escapes. Preparation amounts are fixed-point, with factory amounts truncated toward zero to whole factories. Keep repeated resource occurrences. Omit zero equipment only when zero entries are disabled. The optional flags and preparation words use their own zero gates.

Cryptology keys by saved owner and target, with fixed-point amount and Boolean decryption. An omitted empty census still rejects recorded extras. Intel network states join positionally within each owner and target. Negative selectors carry no subnetwork, while a selector beyond the quiet list has no quiet flag. Separate strategic, weekly, auxiliary-source, and logical-history occurrences preserve their own collection order and owner slots, including reserved manager objects when the writer visits them. Collect the known slot set once so comparing each entry does not rescan all country links. Cross-side owner aliases normalize through the authenticated tag. The captured native removal word is compared against the writer’s Boolean projection, and a root-level raw alias has no independent save operand. Runtime mission rosters and effective modifier totals are outside the saved projection. Current autonomy uses its country-rooted serializer, which can disagree with an earlier relation definition.

Agency creation and name follow their own Boolean and unconditional string emission rules. Retain a named owner refusal even if the surrounding upgrade table is truncated, without comparing the partial table to a full save. A saved token and level cannot authenticate the wrong live upgrade branch. Character flags and variables join a saved character through its full reference and compare in that domain, separate from its country. The character serializer omits the flag block for an empty store. The variable block is omitted only when the store is empty and its random state has not been used. An unproved stream target prevents assuming that an embedded NUL gets truncated merely because a C-string pointer was passed. Operation assets omit empty per-target token vectors.

# 0701. Authenticate copied camera and string observations locally

The active camera root has no vtable witness. Accept it only when it names the current idler as owner and the embedded render view repeats the root's eye and look-at vectors. The tool reads eye and target in that order as native float triples and reads the signed viewport rectangle from the same root.

Preserve string bytes and stored lengths through the fixed callback and worker paths. A value built from owned bytes uses exactly those bytes. Sizing hints follow the same guarded protocol and error order, while their allocation pressure cannot veto a later admitted capture. Grow storage after a payload chunk succeeds and publish a string only after its terminator passes the original gate.

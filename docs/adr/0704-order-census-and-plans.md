# 0704. Preserve native order when gathering the army order census

One held acquisition pass owns the registry roots, visits, successor lists, and gathered plan or name records. It authenticates each root and each order's vtable and owning group before admitting it. The native roster order determines census entry order. Ordinary and virtual successors are distinct traversals, and fallback roots contribute only their own objects. Shared children may appear in source vectors. A cycle in a single traversal and a pointer shared across different owning groups must be refused. Transient pointer lookup is never replay identity. Published rows are keyed by full group handle and the scoped native instance ID.

Keep source array order for paths, target states, group roots and order links. Read predecessor vectors directly. Reuse a complete ordinary successor list from this census only if its header matches. Matching census identities and fully copied fixed records spare another read under the same held game thread. A missing or incomplete record leaves the original per-field reads. Consume gathered bytes only when the copy established them, and keep checked address and identity failures ahead of unreadable later fields. Gathering does not alter the census result. Count the source requests and ticks of plan data gathered in the census as plan work.

Plan reads are a pipelined, advisory optimization. Hint batches ahead, then gather their fixed spans and named-order string headers, hint their heap payloads, and decode in census order. A hint must not consume a guard page. The measured paired capture showed a loss from hinting all member or group-root arrays, so leave those out. A named move, invasion or paradrop reads its ordered prefix, name, first, second, unique and postfix strings. The unique text is already localized. Other strings are localization keys and unnamed order types do not acquire them. An absent front uses the shared invalid full reference. The embedded invasion subscriber contributes signed allocated convoys, including zero and negative values. A failed optional execution or child-front read preserves the core plan.

An assigned slot names the unit's embedded membership, so recover and authenticate the host before exposing its full handle. Bounded slot and host batches retain the prefix and first per-member failure. If a speculative gather fails, fall back to the original per-field reads without retrying the failed span as a span. Host pointers support a same-pass private verdict and never become row data. Short verdict storage cannot prove a root or fail an otherwise sound plan. Grow worker arenas from authenticated demand without treating an unreadable native count as an allocation request.

Parallel work splits consecutive groups in handle order. Stitch the result as a single walk would leave it, including the established entry prefix, geometry, counts, and first failure. A shared pointer is detected before any reads that would follow admission of that order. Compare that point against the part's first native failure, including failures between entries. A complete run sorts rows by key and checks duplicate keys. An incomplete run retains entry order and does not expose old placement. For complete plans, assign sorted row positions before decoding, and carry matching census-to-row placement into later passes. Accept a placement guess only if its row has the requested key. Stitch arenas in census order, preserving unacquired name spans, and keep the first failing host lane's retained pointers and demand.

The visit table has an intrusive depth-first stack. When growth rehashes the occupied entries, re-resolve the active parents and the pending child's parent by pointer. On a power-of-two table, masking is equivalent to remainder after hashing and each linear probe. Other lengths retain the original remainder path.

The owner approved relaxed read-ahead on 2026-10-12. A real speculative copy may consume a one-shot guard fault before the serial reader would encounter it. It may recover the affected row through scalar reads but must not withhold an additional row. Persistent faults still report the serial failure. When two parts reach the same one-shot fault, whichever reads it first consumes it. Fixtures compare the retained data and failure precedence across ordinary and partitioned walks, exercise both graph kinds, and contrast advisory hints with actual source reads.

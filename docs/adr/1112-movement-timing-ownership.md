# Share movement timing by branch and hour

The counter layer on the window thread and upcoming close-zoom model builds can request different hours concurrently. `EtaCache` keeps a strong reference to its latest entry and weak references to older entries. An hour in flight continues to share its result while a consumer holds it. Construction runs outside the cache lock so a worker deriving one hour cannot block the window on that lock. If two callers do build the same key, the first published value wins. Expired entries can be derived again. The branch is part of the key because identical hour numbers can have different operands.

A ticket separately shares success across its immutable overlay and movers inputs. Its synchronous initializer cannot wait for siblings or for locks they retain. An error publishes nothing. A panic unwinds the initializer lock, allowing another caller to retry.

Movement content comes from the recorded mod stack and is loaded once per document. Terrain arrays use database order with one-based terrain indices. The terrain database's null row supplies zero common adjustment. Authored naval terrain has a separate flag from the generic terrain-validity byte. Null sub-unit resolutions do not create adjustment entries, and repeated registered class tokens keep their first bucket. Task-force departure terrain adjusters are independent of naval mission and range defines.

Arrival estimates hold signed fixed5 hours to the next province and destination. Own counters show the destination estimate and other counters show the next province. The first-edge fraction drives the selected movement arrow and naval invasion hover. Missing base speed can withhold arrival timing while leaving progress intact. A stationary division's empty route yields zero progress without content. Missing geometry or a missing division census remains unavailable. If a route has a starting placement, later hops without the required neighbour or anchor are skipped. A caller estimating only a few divisions uses the same derivation without constructing the whole-hour result.

Fixtures cover movement terms independently. Ordinary land movement uses each edge's geometry, destination infrastructure and native speed floors, with recorded organisation, current location, supply, fuel, commander, river and relation terms as applicable. Approaches by water use the logical owner's recorded transport speed in the departure region. An allowed strategic redeployment chooses the greater of road and rail speed before applying its outer scale. A required operand that was unavailable remains a named refusal even when another, unused operand was recorded. Tests exercise the selected-table decoder and both cache entry points against an uncached whole-hour result.

# Retain graphics reader assignment order

Replay declarations with the native reader's field-by-field consumption. A field that consumes only a scalar can leave a following block to the enclosing reader. An unknown field that skips a block can resolve script variables while skipping it. Each file has one variable table. First definitions win, quoted text remains literal, and a key without an operator can read the previous value. End-of-stream tokens, terminating NUL and host CRT conversions follow the native parser's behavior. Named refusals track the declaration when further parsing would depend on an undefined read.

Plain sprite defaults and derivatives are kept separately from their parsed fields. An empty authored effect uses the kind's default during resource initialization. Frame direction controls texture grid orientation and whether geometry rewrites the frame step. Frame direction values with no geometry case preserve their authored step. Regular and animated draws update flip and scale under different conditions. The drawing backend decides whether to add the DirectX vertex offset, and transparency flags can affect pointer hit tests independently of shader output. Preserve resource scheduling flags independently of rendered fields. An uninitialized chart size or arrow field stays absent until a known assignment. Consumers that need an unset field report a refusal. Animated map text accumulates updates to its text block and retains the geometry fields the parser writes.

Sprite variants handle their fields before passing the remaining keys to common sprite readers. The frame and corner tile variants store rates in different units and can invert an earlier value after a failed scan. Progress bar resource initialization selects its technique from whether both textures exist. Pie colors read in order from a persistent local, so a bad entry may repeat the previous color. Text colors clear the global table for each block and keep the first valid definition for a code. Refuse out-of-domain codes and unsettled end-of-stream states. Global cursor and selection offsets use the same checked projection of component writes as sprite fields.

Animation blocks retain records with a set type. Preserve their authored order, masks, texture references and frame trigger flags. The texture scale is reciprocal, with a zero setting contributing one. Resource initialization supplies a texel size only for a named texture. Eager initialization and drawing can observe an invalid texture pointer that a lazy path may never use. The parser projects the current value or returns an explicit refusal based on that later use, and keeps static and resource-initialized fields distinct. Native scalar assignments can transform an unchanged value after a failed scan, including distance squaring and degree conversion. Do not normalize malformed input into a different sequence of updates.

Use the bootstrap lookup before traversing interface graphics files in native directory order. Retain exact listed path bytes. The object registry adds the graphics directory traversal after the interface pass. Startup dynamic tokens are registered before those files are read. Parallel parsing preserves file order and the serial first-failure rule. When a visual mod's refused graphics file has a complete recorded counterpart, use that counterpart and report the substituted file.

The GUI registry batches templates in native name order. Window-local children use the first matching name, including collisions with generated names. The generated-name counter follows load order, including duplicates the native reader destroys, but skips backgrounds and inner drop-down containers. The post-load pass copies unset listed values from the parent chain. A full-screen window uses the load-time root extent, while a local viewport can determine whether a position-relative axis stays unset. Backgrounds may be kept outside regular child lists. Empty button art can come from a parent, with an unsettled parent or unusable lookup refused. Extended scrollbar backgrounds use the lookup passed to the scrollbar. Bound localisation accepts native scalar forms and preserves a missing root key as an empty result.

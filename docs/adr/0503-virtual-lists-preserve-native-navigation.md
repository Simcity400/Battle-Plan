# Keep native Tab navigation in windowed lists

Virtual lists keep the authored positions of static rows and expose only eligible controls as keyboard stops. Native DOM navigation owns steps inside a mounted row, including an explicitly focused control with a negative tab index and starting points left by a removed descendant. The list mounts both logical neighbors before the native key action, pins the first eligible row when a viewport is wholly static, and uses stable row keys for handoffs across list mutations. Removing a row leaves the next step after the preceding surviving entry. Unrelated pointer and explicit focus changes retain the row they select. A cross-list handoff recognizes the consequent focus event even when the origin was unmounted. Detail controls can arrive during a later toggle task, so mutation and toggle observers complete the handoff with the actual restored stops.

Geometry uses a measured prefix index and keeps its draw window stable while scrolling inside the current coverage. A new index retains the measured gap. Padding and row gaps stay separate from row heights so expansion never adds spacing after the last row. The index uses subpixel layout heights from border-box observations, with a DOM height fallback before observation. Content owners hold independent geometry and expansion state. A short list can use its native flow. Bind an external scroller after commit, when ancestor refs have attached, and update geometry after layout or through the scroll event. Authored spacing can change without the outer size changing, so changes to the authored classes and styles refresh observation.

Expansion state belongs to surviving native details elements while a row is mounted. Only a remounted row restores saved expansion, walking outer details before children that depend on those toggles. After a structural change, keep only the positions of surviving mounted details and leave unseen saved entries for whole-row restoration.

Browser differential fixtures compare the windowed list against an identical fully mounted list. They reuse the same browser and session, deduplicate indistinguishable scenarios, and group equal content shapes to reuse the keyed trees while resetting through real external focus. Wait a frame only for paths with deferred handoff. Box assertions use a tolerance smaller than half a layout unit to catch rounded geometry errors.

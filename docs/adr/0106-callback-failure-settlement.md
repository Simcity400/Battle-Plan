# Settle callback failures once without retrying leased live inputs

The loader publishes Shared before hooks and withdraws it after the last admitted capture. The running callback owns the acquisition boundary until its Batch and every accepted job drains. Test-only callers use fixture memory and hold it through drain. A worker’s readiness is sufficient to collect its published result, not to bypass its ownership obligations. Every accepted or rejected terminal path returns its original owner exactly once. Return a sliced store only within the callback that took it and invalidate its unpublished observations so the next hour rereads them. One failed or unfinished capture cannot certify a later one. When the spool withholds a converted slice, it requests forgetting that family once without discarding unrelated observations.

Keep job-sized requests and completions off the hourly body’s stack. Dispatch and collect out of line, and park rejected requests in pool storage so the body holds tickets only. The accepted and parked request count is bounded by the same job limit. Only a rejected, still parked request can be eligible for inline work, and only when it has no native acquisition already in flight. Worker-only rejections return the original request and a refusal. For example, rejected air relation or history parts may have large owned vectors. Reacquire them next hour instead of copying on the game thread. The `ManuallyDrop` completion extraction reads its owned variant exactly once. If that extraction panics, it must not free the transferred request twice.

Owned acquisition reports each read group independently. Scheduled conversion can share its own typed census and spans within a family, never another family’s decoded roots. Relation, character, projects, lexical, air, session, production, construction, economy, player, weather, intel and map capture jobs all settle through the same FIFO. Capacity failure can take a family’s admitted typed fallback only when it did not publish an owned payload or lease. An interrupted accepted job settles a named failure. Families whose mode leaves raw capture out suppress typed fallback and publish the proper missing result. World’s production and construction parts retain separate due and failure verdicts. Economy has its own job, including hourly province supply. No failure in one changes another family’s verdict. AirBases, Projects and Radar joins convert incomplete owned acquisition to failure rather than admitting a second walk, so consumers may use their raw-mode verdicts before joining.

Contain acquisition panic before returning to the native caller. A panic while reestablishing capture ownership means later callbacks record losses without retrying or waiting for that buffer. Retain at most one panic payload so its destructor cannot panic in the capture. A dropped frame restores earlier witnesses and marks the current hour lost only if it has not already been accounted for. It invalidates unpublished held results and sliced acquisitions. A clockless frame did not read a new slice, so it leaves earlier selection state alone. Keep earlier loss witnesses until enqueue can transfer them with the frame.

An initial capture, continuity gap, world change, campaign change or recovery opens on fresh state. A periodic encoding keyframe is built from complete previously captured and carried rows and does not restart observation or add a game read. A user refresh or table shortage can request a full sample without invalidating observer continuity. Capture may walk the dictionary again when the lexical maximum changes, or reread modifier definitions when their header changes. Compare the daily division mark against the unit and reference counters by handle type. An unreadable mark leaves newly admitted division inputs unknown.

The first consistent fixed-layout check is retained for the attachment and applied during conversion. Its buffer is prepared before hooks and used by capture only. A changed modifier header includes either pointer or count, with distinct states for the first read and a refused header. Observe save-allocation counters passively from the same values the save header would emit. The attachment’s retained-layout report and job values use out-of-line frames so the hourly calling stack does not carry them.

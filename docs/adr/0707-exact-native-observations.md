# 0707. Preserve native read order while borrowing and batching

Readers can gather independent fields after their addresses are selected. A guarded copy reports its complete fields in original order, may partly write the first failed field, and leaves everything later untouched. Empty fields complete without a source observation. A scalar result is returned only after its exact bytes are present. Owned bytes and optional caches must produce the same observations. Recording adapters keep their own observation and accounting before using an optimization. [Memory reader](../../crates/engine-native-memory/src/memory.rs)

A hint prepares cache lines for selected future reads. It does not acquire a value, consume a guard, or decide validity. The advisory span limits its stride walk to a cache-line budget and hints the final byte separately, which can lie in another line. That bound applies to hints alone. An optimized path still copies only exact source spans in their original order. Strided envelopes can prove address arithmetic for all their fields without reading the holes. When the envelope cannot certify the spans, field-order checks retain the original prefix and fault precedence. [Memory reader](../../crates/engine-native-memory/src/memory.rs) · [Cache hints](../../crates/engine-native-memory/src/prefetch.rs)

Building a record layout checks destination geometry up front. Source address errors are checked in field order, so an earlier read failure still takes precedence. Packed layouts require ascending, nonoverlapping spans and map only contiguous acquired bytes of complete records. Successful payload bytes and nonempty requests are accounted from the layout and copy prefix. A whole row uses cached geometry. When rows are independent, a failed record does not prevent later records from being gathered. A payload prefix is never treated as a completed row. [Record layout](../../crates/engine-native-memory/src/memory.rs)

The per-field batch remembers its first failed field and never retries that field. Fields after it resume as independent scalar reads only on first use. A speculative field outside the selected path cannot withhold a result. No allocation is needed from the acquisition thread. The owned-slice source translates cache hints to its own backing allocation instead of hinting the foreign integer address directly. [Per-field batch](../../crates/engine-native-memory/src/memory.rs)

An optional memory capability is valid only for its exact source and lease. The current country census and the first reserved-slot result carry separately, including the reserved selection and its failures. An accumulator capability supplies complete raw sorted entries. Modifier metadata and the core-supply predicate memoize only exact observations for one pass. A primary-order lookup follows native own-group then parent order, including its cache-state validation and lazily read prefix. Observation recorders keep their own source operations and must not silently forward these capabilities. A prepared copy returning no execution indicates unsupported or insufficient geometry. A failed observed field or control comparison has its own result. [Memory capabilities](../../crates/engine-native-memory/src/memory.rs)

Strings use an inline union or heap storage selected by capacity. The length excludes the terminator. Read bytes exactly, including embedded bytes, without conversion or truncating text to a chosen limit. Validate the header and terminator in the reader's original order. A joined short-heap copy can fall back to the separated observations to preserve which source failed. A late address or range failure still leaves the earlier control observation available. An unreadable or malformed string publishes no length. [String reader](../../crates/engine-native-memory/src/msvc_string.rs)

The acquisition retains owned string bytes, not live addresses. Descriptors that select foreign heap payloads expire with the current callback. Appending grows worker-owned storage only for successful payload chunks. Advisory sizing follows the same chunks and uses its own failure handling. Reusing held bytes follows the same initialization and growth rules as acquiring fresh ones. Event callbacks can stage bounded owned words without allocating. [String arenas](../../crates/engine-native-memory/src/msvc_string.rs)

Ordered set and map walks use native links and the native count. Left links lead to the first node and parent links help find successors. The concrete key and value pair selects the node's payload layout. The count bounds the successor walk and does not itself authorize allocation. Walk the map with a stack-only cursor and preserve the named structural failures, including when its caller already has the header and sentinel. [Tree traversal](../../crates/engine-native-memory/src/msvc_tree_node.rs)

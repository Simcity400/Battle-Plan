# Validate regional mission carry against the current wing census

Every country air object is visited and its regional, all-active and active-region headers are gathered each hour. An object can carry the saved region IDs, vector ordinals and mission pointers only when the object address, canonical slot, headers and watch certificate still match. The registration and unregistration writers can change members without changing the gathered headers, so both are observed. The carrier pass can add active regions without touching the ordinary vectors. Those insertions move the active-region header and trigger a fresh regional walk.

The observer takes a quiet token before the walk registers any object. When the token still matches the held walk's, matching objects keep their certificates without an individual lookup. Otherwise the walk registers each object before acquiring the bytes that its certificate covers. It checks each carried wing against the current census. Disagreement causes a fresh read of that country, with the fresh outcome and failure context. Loads, gaps, recovery, table replacement, poison and in-flight writers revoke carry. Because an object observed twice has no unique source, duplicate identities cannot be held.

The store travels with the worker job, keeps only the latest complete walk and records allocation size at finish for the game thread. Forgotten or incomplete work is read afresh. Allocation is advisory, so losing planning or hold storage only makes the relevant object read again.

The all-active vector's paint order is an independent projection. The asynchronous caller can request it while the strict acquisition still reports the same registration rows and observations. It reuses order while the ordinary vector certificate matches, including when only the carrier active-region header changes. A failed read under a current certificate stays unknown. Labels are assigned in native vector order and indexed by wing. Increasing surviving labels are preserved; inserts fill gaps until a changed vector requires relabeling. The combined sorted projection is reused until an admitted root changes.

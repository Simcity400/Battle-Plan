# Bound dashboard request and reply work by client and recording

Limit outstanding requests before crossing the native host bridge. Queue consumers in order, hand a freed slot to the next waiter, and check cancellation again after a waiter acquires its slot. The host supplies raw JSON bytes. If a cancelled request needs its late reply to release a native resource, parse it for that release. Otherwise discard the reply without parsing it. Tests reproduce the late-reply case because parsing those abandoned replies consumed frame time. The host owns content folders and shares them with the native viewer.

Parse large replies in a worker and small replies on the caller, where worker transfer would cost more. A typed-array slice needs an owned whole buffer before transfer, and the worker can transfer decoded chart buffers back. On worker failure reject its in-flight work so the next request can start a fresh worker. Carry the prepared reply's digest across projections for comparison without rescanning data. When a batch hits the transport byte limit, learn its response size by client, recording and query scope, and discard the estimate on release.

Share immutable final results and in-flight work with independent cancellation per consumer. Delay dropping an abandoned shared read by one microtask because React can replay effects and subscribe again immediately. A mount that progressively polls preparation may reuse settled results only. Pins protect their exact owner-scoped keys outside the cache bounds. Apply count and byte bounds to unpinned settled entries and evict least recently used values first. Forgetting settled replies alone leaves pending consumers attached. Tests cover that transient hourly reads cannot evict whole-branch history and that different consumers still validate a shared value in their own way.

Maintain separate caches for playback-hour replies and reusable replies, while letting either cache answer a request it already holds. Size from transport bytes when possible. Store raw data and reuse each validator's successful output or refusal weakly, so recreating a validator does not keep it alive. Publish cursor pages in order as a joined reply. Validate each page before accepting it, deduplicate the joined country summaries, and carry preparation progress from the last page. A mount reading progressive groups can publish answers from increasingly complete prepared coverage.

A load started while its widget is visible can finish after scrolling away. Cancelling on every move would keep restarting a slow request while it still occupies a native connection. Unmounting or changing the request identity still ends the old run, and an old run's completion cannot clear a newer run. A failed request stays failed until retried. Successful replies keep their own hour and keep showing until a newer eligible answer lands. In a batch that represents one playback moment, a failure cancels its sibling requests so they cannot publish a partial moment.

Use fixed windows to keep reply size independent of campaign length. Retain only windows the current owner wants, including lookahead, and release old windows in the same commit as a new window lands. Replies landing before one frame commit as a batch. A window can expose a prepared prefix and then a replacement as coverage grows and can report its later failure beside already shown data. React may apply a queued state updater repeatedly to the same state during a rebase, so give that updater the same result for that state to avoid changing map identities and rebuilding rows each time.

Keep a recording's native lease through replayed effects and release it on actual unmount. Extend the picker catalogue independently for all campaigns, deduplicating witnesses by slot and tag as the native catalogues do. A failed roster read leaves its names and flags unavailable.

Country fact loads share a request and cache by source, revision, branch, content revision and fact spec. Ask only for countries not already answered or in flight at the requested hour. A successful response that omits a country is still a settled answer. Failures can be retried and are not held. Cancel in-flight work only after the last consumer leaves, and evict settled hours and old scopes by recency. Keep these facts apart from the ordinary product cache.

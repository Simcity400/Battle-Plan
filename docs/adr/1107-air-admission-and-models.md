# Air admission follows the recorded wing and its target chain

Aircraft admission uses same-hour operands and recorded content. The reached count gates every flight category independently of the reached IDs, which can survive transfers or changed objectives. Last target presence selects a category even if that province is absent from the reached vector. The equipment-at-base branch creates a base model, while bomber branches follow their flight route. Keep the native target-branch order. An unconditional success or an established existential match can settle a chain despite unavailable earlier operands. With no success, retain all reasons that remain undecided. A railway-gun omission alone has a distinct cause.

Build shared scan indexes once per hour and run only branches selected by the wing's mission. A complete active-war census proves peace where a pair is absent. Compare the mission country's own signed reference with the target's raw reference, resolving aliases for the war pair. A live war vetoes shared visibility through factions or the subject hierarchy. Volunteer hosts can change the mission country. Select the first eligible base controller, consulting a transfer base only if the preceding branch allows it. A null controller can match a zero host and a nonpositive selected reference falls back to the owner. Without volunteer hosts there is no base-controller lookup. Other relation tables provide no war witness. Carrier stances refuse only the wings that need a missing stance.

Land combat reads primary countries in attacker then defender order, with an authenticated attached group required to hold a combat army. A group that failed authentication matters only if a hostile combat is reached. Port strikes need a hostile naval-base province controller and a task force with a hostile logical owner. Naval combat tests hostility and visibility through primary participants and active detected group members, with spotting and recon disabled. An independent naval arm can still succeed if that combat arm fails. Sea occupants come from the witnessed province lists. A hostile task force can qualify without combat. An embarked army must be at sea in a naval transfer and outside combat. Complete division and task-force identification can prove a mixed occupant is neither army nor fleet, while missing railway-gun operands leave that branch undecided. Aircraft mine decisions share the complete sparse mine vector with the naval overlay.

Strategic scans select states intersecting the region, then inspect reached provinces even outside its boundary. An established peaceful state or province controller rejects the target. Use the active building censuses, where membership can include level zero. A level below one qualifies only through the railway-gun arm. The state-level vector lacks a province for that arm and therefore cannot decide it. Scouting uses state controllers and the wing's effective country, independent of the playback viewpoint and volunteer base. Directional fog allies, including attaché links, are excluded before the role or war test. The native overlap count includes duplicate region entries, and any positive coverage can qualify even when it belongs to a different intersected state. The cached region-state view depends only on ordered province and state identities.

Transport orders and base assignments share recorded map geometry. The first painted province selects the primary region cluster. The centre prefilter can reject a region before a reached province would qualify, so preserve it and the split-box vertical intersection before the per-province pass. State and hosted bases use different wrapped-distance calculations, including their signed overflow behavior. Invalid or unpainted provinces resolve to zero coordinates for the province test. Transport availability borrows existing content, reads the authored transport flag, excludes subtype zero, and refuses uncertain content.

Select conventional and raid aircraft equipment by largest signed amount and original ordinal on ties. A declaration ends the model ladder even when the renderer cannot draw it. Read optional operands only on branches that consult them. The equipment name chain tries type, archetype and sprite, optionally with a cosmetic prefix. A nonnull graphical override settles its branch without retrying for a null lookup. The designer branch gated by recorded DLC features reads the graphics pool for sub-unit equipment and the saved model otherwise. It then tries the saved model and equipment name ladder. An absent declaration leaves the model unresolved.

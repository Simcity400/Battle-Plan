# 1101. Rebuild commander hovers from the matching definitions

Look up commander traits using the recording's modifier name registry. A read without it cannot decide every trait body. Retain the registry index itself in the cache, so an evicted index cannot alias a new one by address. Duplicate definition names without recorded token resolution are ambiguous and malformed, unknown or missing definitions report their own cause. The native reader drops entries that cannot define a trait effect and keeps the first duplicate sub-unit. Match sub-units and traits with ASCII case folding. Use registered spellings and sub-unit registry order for merged child blocks rather than sorting emitted strings. A refused trait body withholds its whole effect description even when static context is otherwise present. An authored override replaces the rest of the effect, and the shared formatter still governs its text layout.

Use recorded raw country tags for country-qualified keys. Cosmetic or display tags never select localisation. A portrait's immediate text includes its role and name. Learning-trait progress appears only for the viewing country's commander. Land uses capture's rows selected with the live floor, and naval compares its recorded raw values strictly above the recorded floor. Keep the delayed description independent so a missing key does not clear immediate text. A missing retained skill definition cannot be substituted from its shown level. The native land helper overwrites its intermediate modifier text with the final description, so playback cannot expose the intermediate text as a second hover. Skill component hovers use actual retained definitions and the authored hidden set. An invalid skill contributes no modifiers.

Keep terrain adjusters in movement, attack and defence order, nonzero lines only, and use authored proximity thresholds on the default distance plus the offset. The trait description uses the common formatter for ordinary, nonshared and commander-role blocks, keeping the ordered sub-unit block and authored line separators. A timed trait uses its first matching entry, and a nonnegative day count appends expiry text. Exile trait templates route the attached hover to every child. A declined authored or builtin key leaves its precise refusal so the window can count it.

Advisor unlock hovers run only for the native contexts and rank flag that admit them. Roles keep recorded map ordinal identity, including gaps, and the native search checks genius before expert within a role. A later definition of the same name is a distinct identity. When no role qualifies, use the authored rank's fallback trait, including specialist fallback when the higher-rank reference is absent or null. Rank comparisons and localisation suffix selection retain their independent order even with nonmonotonic thresholds. Failure to read a rank define affects only that part of the hover.

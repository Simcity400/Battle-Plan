# Share map device and profiling contracts

The world renders at the chosen sample count into a floating-point scene and a shared depth and stencil attachment. Meshes, arrows and world names share stencil, cleared at the start and retained between passes. Resolve once before post-processing. Float scene and luminance targets preserve highlights until grading. The grade writes gamma-encoded RGB into a single-sample UNORM output for overlays, the host and PNG readback. Half-resolution mode changes scene and depth dimensions and samples the resolved scene back to full output size before grading. Sea-bed refraction uses a half-size target when water samples screen UVs, and full size for water that addresses the target by texel. The refraction cache is tied to the target allocation so a replaced texture gets drawn even with identical inputs.

Use the same adapter selection for the viewer, dashboard and headless rendering. Respect the configured power preference within qualifying hardware and use enumeration order to break ties. Require the map's compute limits, compressed textures, sampled texture count and surface presentation when applicable. Qualifying hardware wins over the platform's software fallback, which carries a visible warning. Ask for the adapter's own limits where map shaders use more than the defaults, including dynamic constant buffers and instanced storage. Choose anti-aliasing counts from the supported scene and depth formats. Device errors are scoped to the resource being created. Float32 filtering may be lowered in the shader pipeline. Clamp-to-border and dual-source blending remain optional and techniques needing unavailable states report the missing requirement.

Opt into GPU timestamps before making the device. A normal viewer run omits their CPU cost. The frame timer brackets rendering commands in the frame's submission and excludes prior queue uploads. It reads back later without making rendering wait. Labelled frames that close, fail or have a busy readback slot report why no measurement is available. Per-pass timing waits only for an explicitly printed profile. A view record collects completed results asynchronously and names missing timestamp support. Repeated wrap passes sum under their original labels, and a reordered timestamp contributes zero for that interval instead of wrapping. Timestamp groups are submission attributions and can differ from execution boundaries.

Political gradient operands come from the recorded content, including the country thickness and area ranges in map pixels, strategic-region thickness, neutral RGB and the search floor. The country's channel uses the largest fixed mode thickness so changing the map mode stays within its search. The viewer uses the full-quality divisor and requires compatible map dimensions.

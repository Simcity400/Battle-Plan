# 1109-A. Separate pointer geometry from GUI drawing

The viewer builds hit geometry from an object's retained position, scale and queried extent. A stretched or cropped drawable still uses that hit geometry. Construction uses the truncated half of the physical viewport before translating by the floating half. Inversion walks each position object in order with the native single-precision operations and scale thresholds. A zero size query falls back to the authored extent. Combining the walk into one affine transform can change the rounded coordinates, and a zero or subthreshold scale can still leave descendants hittable.

Clipping tests the original pointer in the clips' logical space and includes their upper edges. The drawable rectangle excludes its upper edges. After rectangle admission, alpha testing subtracts the drawable origin, truncates before and after scaling, and adds the selected frame's texel offset. It checks the flattened texture index, with no separate axis clamp, filtering or vertical flip. The mask marks alpha-zero texels. The diagnostic bounding rectangle is only a footprint, so dispatch tests the retained geometry.

Each pointer change keeps its position and order within the frame. The final position follows every button change. Window and clip coordinates are tracked separately for descendants. Across windows the press owner holds the pointer through release, even when the pointer moves over another window. Layout still tests and draws a held button as Down on the release step. A button activates on release over itself after its press. A check box toggles on press, with repeated toggles accumulated by parity for the frame. State transitions schedule the old and new controls' effects, and the next click stops the previous click sound for that control. Nested items qualify their control names with the owner's identity.

# 1109g. Measure and draw the same native GUI drawable

Native GUI identifiers stay raw bytes through lookup. Diagnostics alone decode them lossily. Resource preparation follows the constructor's registry lookups, including inherited parts and backgrounds. It loads frame textures, related fonts, text-sprite textures and inline icons ahead of the draw. A missing caller-supplied resource has a distinct refusal from a known absent content resource. An absent name can fall back to the configured fallback sprite. A name that depends on a text sprite left by unrecorded session history is refused unless the current text box creates it. The constructor's null texture and unavailable recorded input are represented separately.

Layout, measurement and lifecycle clocks all resolve the same current drawable. A sprite setter may restore a different subset of frame, scale, position and rotation depending on the control and setter. A standard button replacement centers on its unscaled extent, uses raw position and a frame of at least one, and clears rotation. An icon replacement follows its construction placement, configured scale and initial frame. Later writes supersede those restored fields. A bound atlas cell replaces the frame extent and texture without rewriting the sprite's anchor or effect. Centering on the sprite anchor takes precedence over centering on its queried extent.

Integer extent queries truncate reciprocally divided frame dimensions. Drawing keeps fractional frame sizes, and frame orientation selects the texture strip axis. Positive explicit frame values can advance beyond the strip and let the sampler address the resulting coordinates. Zero selects the first frame and a negative frame selects a supported state or falls back to the first. A cornered tile uses a checked unsigned frame selection, repeats whole texture spans and keeps the remainder without the frame offset. Its draw follows inherited transforms and ignores its own stored rotation and scale. Pulse or window opacity can replace tile alpha. A plain repeated tile uses whole texture spans. A resizeable sprite draws nothing. A chart without written slices or lines likewise draws nothing, while a reached undefined size is refused when measured.

The native quad is positioned from its bottom-left, with scale, vertical stretch around its center and rotation around the retained pivot. A loaded sprite mask selects the masking variant and binds to slot five. Progress bars use their unscaled size, have zero anchor, and select textured drawing only when both texture files are present. Their integer setter clamps above to the step count, while normalized progress first clamps the ratio, scales in double precision and rounds into retained state. Rendering uses that state directly. Circular progress draws sectors with a nonnegative remainder of the 100-unit total, omitting a sector whose weight is less than one. A flag mask uses its atlas cell and its own effect under a separate overlay. The overlay uses an unrounded centering offset and uploads zero clock values. A missing flag cell leaves only the overlay. An out-of-range index uses the default record where available.

Draws carry current constants and authored technique state. A null technique record retains the preceding program and samplers and disables blending. An undeclared sampler retains its previous binding. A state change restarts the effect clock on the next draw, including a return to Up or a transition to Disabled. Authored vertex programs receive local geometry and the accumulated transform. Straight color alpha is modulated by the window's opacity. Drawable extent measurement follows the same resource refusal path as drawing, including measurement for a control the caller later centers or offsets.

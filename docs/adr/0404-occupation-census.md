# Preserve occupation operands through authentication and capture

Occupation readers authenticate the occupied-country holder against its owner and the lookup key against the canonical country slot. The stored historical link and the retained country's current identity are distinct. The retained pointer supplies effect scope. A fault reading that scope can leave an override usable. State laws preserve raw keys, including zero and unknown keys that can survive a load. A null default-law pointer and a present law with an empty token are different cases.

Robin-hood lookup and enumeration use occupied buckets and derive their span from the stored capacity or mask and the maximum probe distance. An empty bucket can retain stale keys and values. The iterator sentinel is invalid inside the live span. The saved effect and serialization vector preserves group occurrences and supplies their country scopes. Roster-sorted allocation demand is independent of bucket order.

Template selection is captured independently of garrison allocation. The country default and an unset group override have distinct scope. The group inherits its country's default when its pointer is null, while state overrides are keyed by state. The collector authenticates division template identity and walks the country and occupation graph once, keeping capacity and faults per table. Law strings occupy a shared caller-owned arena as literal bytes. Reserve manpower stays separate from signed state assignments.

Garrison reads preserve full fixed-point strength and required values. Assigned manpower has an embedded container. The two equipment pools have distinct native headers and entry layouts. Required entries use authenticated archetype pointer identity. Allocation uses the first entry whose signed ID is at least the requested ID and returns the allocation only on equality. Sorting or deduplicating the pool would change the result for duplicate or unordered entries. Alert rows identify equipment types, even when their width matches an archetype row. A fault reading a state's equipment leaves the other garrison fields available.

Resistance records inactive objects, the raw country link, the active byte and the full signed fixed-point levels and speeds. Hover acquisition keeps receiver identities and accumulator operands separate from owned values. Province text ordinarily omits inactive objects. An admitted occupation marker can request detailed resistance without the active gate. Disabled effect keys are excluded when deciding whether a description is empty. The description uses the effects already aggregated at the root. Map icons come from the retained state and occupation lists in native order. Their country identity is taken from the retained pointer. An unreadable key withholds an existing group, while an empty lookup bucket proves it absent.

The occupation writer set covers updates, effect and script setters, activation and initialization, and rebuilding or clearing the state and core lists. Save loading and world construction invalidate observations at the load boundary. The garrison refresh can reset spread, add spread and rebuild speeds. The modifier rebuild writes the law scaling ratio. Added targets can be appended, removed, reset or expired. Daily diplomacy covers both war-goal expiry and exile legitimacy, so the occupation observer forwards the shared update to the goal observer. Existing observers forward country, state, exile and relation operations they already own.

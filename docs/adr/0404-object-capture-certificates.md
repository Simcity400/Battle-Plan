# Bind carried object inputs to their native writers and lifetimes

A held ship model depends on its equipment and subunit definition, cached fallback sprite, experience and medals, and carrier base. Equipment recalculation refreshes several cached fields after critical changes. Refit replaces the definition and equipment and can clear a carrier base. The experience accumulator refresh follows awards that set its dirty byte. Base creation, removal and destruction and medal changes have separate receiver sources. Full object identity and lifetime notifications prevent retired objects from certifying a new allocation at the same address. A load invalidates the old observation.

Template assignment, token loading, reset, grid changes, cache recomputation and model or role setters can affect retained template payloads. A role edit can change excluded variants without replacing their header. Scripted effects can write directly to the country roster, including an addition that renames the replaced entry. A custom-icon command resolves its target internally and invalidates every template, since there is no separable target at entry. Deployment and occupation configuration have their own holders. Membership insertions and destruction invalidate those holders. Country and world lifetime events invalidate the old epoch rather than trusting a reused address.

Unit leader capture retains links and cached text in addition to numeric fields. Formation assignment changes the formation reference independently of saved data. Shared skill definitions change on construction and database load. Level and experience updates, trait changes, skill setters, capture and release, owner changes, character links and operative renaming can all change retained rows. The two exile operations do not name a leader at entry, so they cannot certify one tightly selected record. The naval tree writer owner forwards leader construction, copying and destruction so an address reuse breaks the old certificate. Save load starts a new epoch.

Directional war participation tracks stored damage, bombing decay, first province credit and casualty changes. Display aggregation and lend-lease score calculations can touch temporary breakdowns without changing the retained ledger. Whole-ledger replacement changes both its scalars and captured membership. The war lifetime observation authenticates endpoints and invalidates old state on reset or load.

# 0706. Authenticate unit motion separately from combat-reference capture

Unit identity uses the native primary and secondary objects, the reached class and the full registry reference. The runtime mints reference type words independently of class. The configured viewer-unit walk retains the native vector order and emits divisions and railway guns, skipping authenticated task forces. Unknown classes, unreadable units and missing required IDs refuse the walk. Capture-owned resolvers can retain failed registry roots during their quiescent pass.

Motion follows stored simulation state. The route target and ordinary and alternate arrays are distinct operands. A new target can establish a one-entry ordinary route. A path longer than the loaded province roster is invalid because a native path cannot visit a province twice. Incomplete storage cannot turn a partially copied route into a stationary unit. Movement priority, embark distance scaling, withdrawal, exile, redeployment, retreat, naval-transfer membership and optional invalid-order reason are distinct inputs. Unknown reasons retain their raw signed values, and optional guarded arrow operands cannot invalidate an admitted motion row.

First combat reads identity, attacking side, side identity and backlink before checking the raw logical owner's membership and then reading the province. It accepts an authenticated alias, and a membership failure precedes a province failure. The action query stops at the first combat in which the owner attacks. Its old demand and signed count observation stay independent of the new ordered reference suffix. That suffix may reuse the original header and first pointer, then visits only the unvisited tail. A nonempty header is witnessed after its elements. An empty vector is fully witnessed by its initial header read. Every native occurrence remains in order even when it repeats a handle. A failed extra identity or registry reference refuses only the suffix.

The naval wrapper distinguishes a known empty vector or known absence of the naval class from a refused identity. The map motion row and the additional naval-reference projection keep separate admission. A successfully resolved combat identity can be memoized only for the current stopped capture. An optional memo filling up cannot shorten the walk, and an unsuccessful identity is never carried to a later occurrence. A complete first-combat role and province result can be reused within a capture by exact combat, raw owner and world roots. A role-only observation does not populate that full memo. Storage is prepared outside acquisition.

# Separate transient event witnesses from saved state

Equipment balances incorporate production, replenishment, upgrades and transfers. A saved balance cannot certify how much a single destruction event removed. Use pre- and post-operation witnesses and live coverage checks for event amounts and ownership. The combat log only has a saved counter for its own active-damage scope. A matching complete preceding census proves an owner only where expeditionary status did not change, and no census allocates an aggregate loss to individual owners. A full saved unit handle can prove absence independently of its pool. Deployment, overrun and orphan cleanup can remove or introduce a unit between census barriers, so event checks preserve their explicit coverage limits. [Equipment destruction oracle](../../crates/recorder-oracle-equipment-destruction/src/equipment_destruction.rs)

Retained decisions compare at the save hour independently of census age. Each named owner is evaluated separately, so one unreadable owner's rows cannot hide another owner's differences. An unnamed owner is a group-level failure. Native event actor roles and actions are transient, so the save supplies no equality witness for those fields. The event group reports that coverage separately from retained-state results at the same hour.

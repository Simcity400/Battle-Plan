# 0204k. Carry naval management only under the selecting census

Management capture reuses the core and map census to authenticate fleets, task forces, ships and bases. A task force owned outside its fleet's country is still admitted by the core census. Observer callbacks mark only registered receivers. The current census covers new objects without turning steady-state refresh into an extra world walk. A full watch table refuses that hour, and the next hourly boundary can install an offered replacement. Census demand includes refused registrations so a short table can recover. A capture that cannot certify the observation withdraws its output by name and waits for the next valid census epoch instead of retrying the same failed selecting root every hour.

Spool gaps can invalidate held data without disabling the native observer. A recovery cut discards the old marks and gives a self-contained keyframe. Lifetime marks take precedence over value marks. A short or refused take cannot certify the marks it may already have consumed, and a lost or unwound publication requires a fresh seed. Native reads finish before loaning the owned snapshot for publication. A dropped loan releases its owned store without borrowing live memory.

The ship's recorded refit source link survives resolution or retirement of its destination. Resolution selects which progress to acquire. Fleet transfer clears the repair-parent association while keeping the rejoin relationship. A repair queue erase marks its base immediately when one ship leaves. Assignments proved bit-identical do not read the repair work again, and an unreadable comparison withdraws the hold. Recalculation that does not initialize progress is not a progress write. Settings and hourly calculations clamp the repair allocation independently, and split can be commanded without selecting repair mode. Batch installation refusals name every candidate site when a narrower culprit is unproven.

An unresolved source link still contributes to demand. Cancelling or pruning a work order need not clear the same native link, and a retired receiver is not read merely because it also has a value mark. A quiet publication shares the exact committed snapshot allocation and avoids growing per-entity state on every hour.

In `changes::changed`, the pinned native store is about to access the live receiver. The comparison uses guarded copies and withdraws the hold if the previous value cannot be read. `Hooks::new` requires authenticated, exclusively owned sites and whole stack-independent spans that no branch or return enters part way through. `Hooks::drop` releases the registries only after runtime restoration and executable-range drain.

The `split_only_command_marks_its_task_force_without_a_mode_write` fixture zero-initializes `Registers` because its fields are integer values. The selected descriptor only marks the receiver in those registers. `one_ship_erased_from_a_base_repair_queue_marks_that_base` and `naval_management_method_timing_excludes_its_native_original` own their original slots and install fixture functions with the method ABI. `fixture::undersized` clears both registries under the serial lock, which excludes notifications and capture.

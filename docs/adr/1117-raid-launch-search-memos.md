# Evaluate raid launch gates in native order and share bounded search work

Offer launchability checks affordable command power within capacity, then sufficient nukes and whole essential stockpile archetypes, cooldown, authored availability, an eligible unit, and reachable source. Later gates preserve the early decision without reading unnecessary data. For diagnostics the admission path can still request a stored equipment breakdown after command power fails. Preserve native roster order for units and source order for visits. Country-local clones count under their definition’s token. Installed module checks case-fold the token spelling. Duplicate stockpile keys retain the last amount, and convoys take the greater of the stockpile and available amount. Capping the equipment total at the greatest requested amount is exact for every gate comparison and shortfall.

The hour shares lazy indexes and type preparation. Equal starting points share a source list, equal requirements share unit matching, and only equivalent source families, units, ranges and AI bypasses share search results. Each batch part owns mutable reach, air-distance and memo state so it can process targets without taking a lock on each target. Prefetch can schedule one source list per starting point alongside division reach and type preparation, with remaining worker capacity advancing the first expensive searches. The prefetch result does not change evaluation order or which source survives. Reach is read only once a unit’s range admits the target. With path inputs, visit order and first answer remain significant for the observed memo.

Pathless finite searches can prune distant sources using map geometry. A shared distance index is valid across hours while the source province set matches. A recorded-path search can skip out-of-range sources only when every required source/target pair is present in the exact memo table. Index reuse is tied to that table identity and source and range inputs. Its missing target bounds and deterministic internal ordering stay separate from the native source ordinal. A missing source location and missing target do not mean the same thing. An unbounded or unknown limit does not shrink the search. A zero-padded value cannot stand in for missing reach or distance evidence.

Different source families demand only the data their path needs. A complete census can prove absence; a partial census cannot. Preserve uncertainty when a positive owner reference fails to resolve, which differs from the actual zero country. Use the runtime state’s building list unless content order has been proved equivalent. A naval or building distance does not need to resolve the raw holder country solely to preserve its owner bits. An air source can come from a province provider or a carrier’s task force. The wing’s stored site, its access and volunteer link, and the site kind determine admission. Missile and gun sites are withheld in the native order. Refused source families remain an uncertainty boundary rather than forcing evaluation of later families.

# 1203. Keep trade measures exact and date their holder and coverage evidence

Each ribbon represents one resource between an ordered seller and buyer. Read dated native aliases from the recording's identity census. Preserve native holder keys when a country changes tag or another country reuses one. Reject numeric runs that conflict with the census or cross a missing identity witness. An absent present alias can fall back to its latest supplying census observation. Never borrow a future alias. Scope's end or ever-membership chooses holders before including their histories. Hourly membership clips each side to confirmed membership dates. A Between filter needs both holders in scope. Resource colors use full content order even when the chart is filtered. Native country colors reserve slots for a whole recorded census independent of diagram ranks and request order, and update a shared correction after all chunks answer. An unknown color is drawn neutrally. A pending push can carry a color only within the same recorded holder, alias and stretch.

Use exact fixed-point integers for labels and calculations. Floating geometry does not set displayed amounts. A daily amount held 24 hours delivers that amount once. Divide each flow's integrated amount by its own traded duration for a daily average, then combine the exact fractions before rounding. Read whether any convoy was assigned, required or used, and whether any factories were paid from the exact sums. A recorded zero delivery keeps the deal and its identity. Only positive flows create geometry. Measure current terms at the selected hour and cumulative terms over the shown interval. Unknown hours and unattributed flows are separate from no deals. Cumulative measures keep recorded earlier contributions and report missing coverage. Hourly group membership gaps exclude those hours and report their absence. An empty current roster cannot explain away missing earlier membership.

The diagram keeps one scale for a campaign and scope. Compute the largest simultaneous positive total for current amounts, or a conservative sum of the flows' individual peaks for running totals and averages. Check run boundaries since an average can peak between sampled values. Negative corrections never lower the necessary scale. Hold a prior scale during an extent read only for the same scope. Keep node order tied to full-window holder rank and ribbon order tied to their counterparties. Make room for the sum of edges past the visible node limit. A single extra country remains identifiable. For a country history, stack positive bands by resource and draw imports below zero, exports above it. A full-country drill may need a separate request using the holder's aliases when the diagram reply did not include all its trade.

The React view advances at the look-grid step and paints amounts at the playback head. Request names, flags and colors on the look grid, with partner rows' labels requested only while mounted. A pinned drill uses its own date. A followed trade and market detail paints live values as appropriate without making a request on every clock step. The keyboard and labels open the same drill, and the screen-reader description identifies the largest ribbons. Window replies keep order by resource and dated native holder, join adjacent observations only with identical terms and tags, and reindex the shared aliases consistently.

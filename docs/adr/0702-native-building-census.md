# Preserve building census order while batching guarded reads

Authenticate each state or province and its own building-status backlink before acquiring a building. A state failure and a province failure leave the other table independently available. Provinces with no state retain state zero. A province with a state must match its pointer and ID against the state table. Authenticate construction targets against those same map roots, without a whitelist guessed from template types.

Stage headers in slot order. For a batch of provinces, gather their state identities and then the state slots named by those identities. Keep each read's completed prefix so a later pointer or state fault never masks an earlier location's own reason. Walk building vectors in slot and native ordinal order. Batches can cross location boundaries to fill guarded reads, but each building still checks its own backlink, index vector and duplicate type scope. Copy fixed fields before sizing destination storage, so a corrupt vector count cannot cause a count-sized allocation.

Match the stored active-building vector by pointer as an ordered subset of the building vector. The game rebuilds it after a level crosses zero and when loading a status, even after unknown tokens. Use the stored vector for the active count. A building's total and healthy levels use signed short values, and partial health uses the engine's signed fixed point. Reaching the full repair threshold raises the healthy level and clears the partial value. Fort movement weighs the healthy level. Production terms in the war overview sum signed naval, military, general and rocket contributions using wrapping arithmetic.

The building index is a signed array keyed by template ordinal, with a negative missing sentinel. Template ordinals, lexer tokens and localized names have different roles. The database's keys lag the parallel template list by one entry. Infrastructure and railway definitions can be missing, and display spelling comes from the recorded lexical dictionary. Lookup requires its observed enable byte, whose wider meaning is unknown. The template's scope distinguishes province from state.

Pass a held row set through only when the caller proves the current status header and writer certificate still match. Keep fresh identity acquisition for carried locations. After a touched status, refresh using the held status pointer alone only if its vtable and identity have stayed the same. Read fresh vector headers and rows in the same order as the ordinary walk. A separate consistency pass acquires its own roots. A load or reset can replace a root. Outside those transitions, only map editing writes the root headers.

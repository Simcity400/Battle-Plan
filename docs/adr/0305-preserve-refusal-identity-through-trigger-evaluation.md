# Preserve refusal identity through trigger evaluation

The accessor that cannot read an operand records its table, field and store. Global tables omit the owner store. Wrapping a failure can add user-facing context while retaining those identifiers. Merge Boolean and alias outcomes using those same identities. Presentation callers receive the formatted reason.

A positive reference whose target lookup fails is unresolved. An incomplete source cannot prove membership false, even through a warmed index. Literal nulls and membership operations retain their distinct rules. Record failed joins that a filter discards, separately from speculative failures in lazy indexes. Building a cache can defer recording until an accessor reaches the entry. Reading a cached value or error replays its observed failures from the original accessor.

An unknown operand counts as reached when evaluation consumes it, including when a Boolean sibling later decides the result. Tests enforce that the accessor already recorded the identity before consumption can mask a missed read. Constructing or wrapping a speculative error alone does not count as a read. Callback reporting is independent of display wording and restores the outer callback on unwind. A table acquisition and an optional field both record their typed refusal where the operand is read, so an outer trigger cannot reassign it to a different input.

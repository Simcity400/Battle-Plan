# Freeze division observations before ordered publication

Division capture shares one authenticated census between Presentation's status, naming and modifier readers. It takes each writer registry after the hourly boundary and before the first read. The hour keeps the first take for all consumers, including markers for army stats and name members, stored experience, previous templates, officer and career state, history roots and entry edits. The take returns an epoch only when it retained every visited receiver. An untouched registered receiver from that epoch can carry without a per-division certificate query. Captures register cold receivers before reading them. Display-only daily samples may carry across a sequence change within the same epoch. The hourly exercise predicate still needs certificate-current XP. A diagnostic feature takes another native operand slice for comparison with the recorder's derivation.

The army observer covers changes from the game thread and hourly workers. A country-wide refresh marks the names in the authenticated division roster after the original returns and invalidates the whole domain when the roster cannot be read. The existing combat damage observer forwards casualty XP and panel counter changes for its receiver. Presizing uses the live naming census before the first boundary and then complete division captures. Larger watch tables install at an invalidating hour. The game thread does not allocate to republish a diagnostic or reclaim replaced watch storage.

`army_stat_changes::Hooks::new` relies on runtime build admission and an authenticated executable in the current process. Refusals identify the withheld site and its family. The same family owns the authenticated executable and patch lifetime for `panel_operand_hooks::Hooks::new`. Before releasing code or unloading, the caller restores enabled hooks and drains native calls after the last capture. The watch registries released by `army_stat_changes::Hooks::drop` follow the same lifetime as the relays. The `LiveMemory` handle in `refresh_country_names` performs guarded reads on the native caller's thread while the observer retains its running guard.

The previous complete capture holds attack and movement operands, maxima, and name member text together in census order. Carry requires the same authenticated army and stat-block addresses, the same epoch and no writer mark on the corresponding receiver. An incomplete or failed job holds nothing. An unchanged census uses the prior ordinal directly. Reordered censuses use offsets and a reusable index. Distinct complete baselines get distinct stamps, and exhausting stamps disables index reuse. A refused advisory index falls back to ordered or linear lookup where needed to preserve carry and its failure semantics. A borrowed name read uses the caller's own position shift and keeps the member cache bytes together with their read.

Ranges own native reads and certificates that they acquired while the game is paused. Ordered settlement still owns cache admission, row order, write marks and failure accounting. It consumes frozen data only after resume. Optional scratch failure keeps the ordered route while memory is still available, and a missing required range for an owned handoff is a preparation error. A current staged miss differs from an absent staging entry. Registration may still refuse a provisional observation at ordered admission. Repeated admissions preserve the first outcome, including a refusal. Tests compare ordered and range-local behaviour, probe counts and failure scopes across varied completion orders, changed censuses and reset boundaries.

The dig-in pass memoizes group and leader selection and each commander's entrenchment term. A carried term is keyed by the leader and accumulator together and uses the retreat-ban writer certificate so reusing an address under a different leader cannot carry it. A missing group and an unread group preserve their respective native default and refusal. The pass can cut a longer complete capture to the status result's prefix because each factor is owned by its division. History rereads the latest career entry's province count even without a writer mark because it can grow in place. Only certified unchanged prefixes carry, and edited entries keep distinct ordinals even when multiple occurrences point to the same entry. A refusing root does not withdraw other histories.

The deployed panel owns its membership and modifier snapshots. Its hash keys use the whole handle and publication sorts where output order matters. A world reset withdraws old bindings and certificates while independent selections still authenticate afresh. Only the ordered consumer changes shared roots or row data. A refusal may need admission before it can carry. Replacing it with a successfully read empty membership still publishes a change. Equal reads do not allocate or insert rows, quantity-only changes have no membership delta, and stale pointers are pruned before following dirty variants. Withdrawn and refused sources publish the complete affected key range. The projection checks the world before and after reading a snapshot, including on unchanged rows. The three state attrition keys share one selection and one accumulator read because native lookup authenticates the whole accumulator for each key. The serial oracle repeats that read, so a deliberately injected later-touch fault may refuse only the oracle's term. Other published data must still agree.

Recorded supply uses the footer's display step for divisions, railway guns and task forces. A refused daily fragment is itself a sample and decode does not query its former native header. Owned reference vectors preserve order, repetitions and full-width values and publish only when complete for the requested frame. An authentic empty vector is still an observation. The hourly host supplies its timestamp. Panel projection reads anti-air from the movement operands already recorded and keeps suppression in its own slot.

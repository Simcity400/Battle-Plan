# 1305. Present supply trains from recorded paths

Build a train plan from complete recorded supply nodes, inventory, variants, rail edges, cooldowns, province supply and naval bases. Resolve country links and provinces before deriving the missing-link endpoints. A parent-chain vertex without a row refuses the route, including a route with an earlier closed portion. The connected portions are reversed into travel order, with duplicate adjacent provinces removed. At a missing link, derive a synthetic naval break using each province's controller and its membership in the recorded supply-node census. Only the registered node kinds qualify. Both endpoint checks run.

Check whether each node has an admitted kind, is unblocked, and has positive available supply after consumption. Round positive fixed5 weights up, retain native weight order, and sample from the signed weights using double-precision scaling. Travel over the curves the railway pass drew. Controller access, cooldowns and railway adjacency determine valid route portions. An invalid route still consumes its departure because route validity does not enter the weighted draw. Cache each node's routes and the province and link reads they depend on, so an hour can invalidate only the affected walks. Keep route curves while the network, heightmap and rail geometry agree.

An independent presentation clock owns one timetable and fleet. Draw a new interval before testing capacity or node weights. The first and last authored `TUNNELBANA_TIMETABLE` entries are truncated toward zero to 32-bit signed integers matching native `lua_tointeger` conversion and bound an inclusive whole-millisecond interval; empty tables, non-finite or out-of-range endpoints, and non-positive intervals are refused by name. One selected node can emit multiple land portions after a single fleet-cap check. The recording does not contain the previous fleet, timetable cursor or native animation state. Begin presentation warm-up from an empty fleet and keep its clock, randomness and wheel and particle history on continuous forward playback of the same country's branch, including forward skips. Presentation advances while playback is paused. Positive presentation time samples idle-state wheels and retained move-state exhaust through the entity animator, while time-zero dumps use the default pose. A train can carry over only if its track still has the same curve and end condition. A seek or changed track cannot move the old train onto guessed geometry.

The inventory's signed counts and order determine equipment selection. Resolve the variant's equipment token against an authored type, preserving the lexer's case folding. Lookup tries type before archetype within the original-country, recorded runtime culture and default tables, in that order. A signed-positive original reference, including one with an empty spelling, governs the country and culture lookup. A country hit needs no culture lookup. Raw zero has reserved-country naming and cannot infer a runtime culture from its tag. Unknown tokens and unresolvable models produce a named refusal when a departure selects them. Keep a published refusal only while the same cause still holds.

Create fixed front wagon slots followed by random entries and the fixed rear wagon. Clamp the minimum and maximum authored counts to at least one before ordering them, then add one to the chosen count and honor the fixed-slot floor. The train advances at content speed even when hidden. Only cars at or above the railway fade threshold draw, and their colour alpha uses that fade. Water-floored terrain and the authored offset place couplings, bounded chord fitting follows bends and the body's yaw points toward the preceding coupling before authored rotation. Endpoint planes clip and fade cars over 2.5 units. An open route ends when the head reaches its missing segment. A closed route allows the consist length beyond the final segment. Frame work scales with the live fleet instead of the node count and reuses its placement buffers.

# 1102. Derive fresh naval positioning from a complete applicable census

The active window derives its displayed positioning, detection, screening and anti-air from recorded operands and matching authored naval defines. The hourly stored positioning remains an input where the game uses it, including screening before the window's fresh positioning is built. Keep the traversals distinct. Positioning counts qualifying forward slots including unresolved handles. Detection visits only qualifying live ships, excluding retired and paired-only groups and vetoed states. Anti-air visits each live ship occurrence in the forward groups without the same exclusions. Detection and anti-air use the task force's default commander when applying the relevant modifiers.

The binding indexes the required references once per window refresh and shares the indexes across both sides and callers. An ambiguous key cannot resolve. An incomplete ShipModels table or aircraft census only withholds sides whose relevant branch needs it. In particular the zero opposing-air branch does not ask for own carrier air and the already categorized screen census does not demand model flags. The scale test exercises tens of thousands of ships and a million aircraft. Count only dense rows relevant to the current combat, resolving each referenced base once rather than rescanning them per wing or carrier.

Base aircraft are recorded from dense containers with repeated wing occurrences intact. An indexed country registration can overwrite a prior slot and still leave a second dense container. Use complete dense and wing tables and require an explicit empty dense row to know a base has zero aircraft. A base with no dense row is unknown. A referenced zero key or an out-of-roster wing invalidates the selected combat's census. Wings count through the dense occurrence rather than a wing's assigned-base backlink.

Resolve the host ship via the plane's air base even when its optional combat member no longer exists. A nonnegative carrier slot alone does not recover that member. Only a linked forward member of the same side and group supplies member-specific sortie modifiers. Keep organisation-adjusted and pre-organisation efficiency separate for the two hover gates. Use the combat's shared duration. Forward groups supply the aircraft slots, while paired-only and explicitly excluded slots contribute nothing. Equipment groups use the first variant's model identity in equipment registration order.

Preserve native operation order and fixed-point truncation. The signed products wrap before division, including the crowding and weighted-plane stages whose explicit ONE factors would cancel on ordinary operands. Surface detection clamps the computed fixed-point fill and preserves analogous multiplication wrapping. A division that would trap is unavailable. The fixed-point input guard can yield the game's exceptional sentinel. For screen demand, a positive fractional remainder rounds upward and negative values truncate toward zero. Apply the positioning factor only after truncating the intermediate screening ratio, and apply the zero-screen country correction after the first clamp without a second cap.

Build positioning from the side's location sources (country, regional weather and terrain), plus its own admiral's positioning bonus and the opposing admiral's initial-positioning bonus for an early defender. An absent modifier is zero, and eligibility and the per-definition clamp apply before accumulation. The aircraft pass returns fixed-point weighted counts and base-fill averages. Positioning combines its side's weighted count with the opposing fill and computes the carrier penalty only when the opponent's count is positive.

The ship and its positive equipment pool jointly determine the carrier predicate. Scope the screening adjustments by display box. Capital screening contributes the applicable positive screening modifier in boxes two and three, and combined screening adds the capital-screening modifier in box three. Apply the named global modifier metadata even when an accumulator has no local occurrence of that key. Screens protect capital ships and convoys in the capital percentage, and capitals protect carriers and convoys in the carrier percentage. The submarine eligibility census visits a broader set of forward states than the category census. Missing authored values are reported by name and only required where the law reads them.

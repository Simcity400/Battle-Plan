# Keep native counter roster order and branch-specific operands

Use the recorded mixed province occupant list for land and the naval list for port counters. The first occurrence supplies the unit's ordinal, and a missing or partial list cannot establish the native insertion order. Selection cursors, activation order and grouping belong to presentation state.

Naval hull selection compares capital status, positive variant availability, strength, and sub-unit ordering in that order. Keep the first tied roster member and retain an unknown when the missing operands can change the winner. A valid fallback sprite can replace a selected hull's unavailable name. Carrier status includes missile-carrier variants with positive count. The first carrier can settle its air-base branch even without a base, and missing earlier model operands can leave that branch undecided. A registered, nonempty owner wing pool proves stationing. At sea a stationed carrier settles the task force's scan and the counter takes the maximum across members. Port carriers use separate air-base and rocket-site latches in item order. The authored child has no selected-base frame in a replay without that selection.

Headquarters portraits with a character reference use the category and authored size holder. Absent generated portraits do not fall through to the other leader strings. Leaders without that reference try their recorded explicit path, country-qualified path, then sprite name and the unknown portrait. Paths must be in the loaded authored portrait set. Inspect an archetype before its own categories when testing the ship type so corrupt or cyclic links leave an unavailable result.

Use equal-weight fixed-point member ratios and the original truncation and wrapping arithmetic. At sea the strength and organisation bars use members at full visibility, while port bars use everyone. Task-force strength sums values and separately floors and sums maxima. Organisation averages per-ship ratios, including undefined entries in the wrapping sum before its range check. For land, clamp the raw ratio to its maximum floor and full range, interpreting the designated current-value sentinels as full. Apply the separate strength factor after truncation. Bar geometry is shared with the authored sprite. Quantize the fill through the fixed-point conversion, leave the left edge anchored and grow the right edge in two-pixel steps. A zero step still draws the sprite.

At sea, pride and order glyphs use fully visible members, and the active-mission plate tests all members. In port, every member participates and there is no active-mission child. For supply, a port starts at full and takes the minimum over all members only when its first member has full visibility. At sea use the last fully visible member. Use detached activity instead of the underlying mission when it is set. Only own members without any repair reference contribute order terms. A known true order term may decide the child through other unknown terms. To decide pride, a proved absent ship differs from an incomplete ship census. Fleet reserve checks the first task force.

For land, use the last visible member outside naval transfer for supply and keep full supply when all visible members are transferring. Supply grace and the three raw thresholds are content inputs and cannot take vanilla replacements. A positive entrenchment can show a spade, full only if every entrenched member is at its own cap. Training hides it and an unknown training predicate withholds it. The raw training request is insufficient on its own. Invalid or missing orders use two ordered latches. An own grouped unit without an order can set red, after which later grouped units can set yellow from the raw invalid-orders byte. A member without a group skips both. Keep an unknown only when missing operands can change the resulting latch.

Order membership checks the group and at most its immediate parent, primary before fallback. Preserve root order, stopping at the first unavailable root for still-unresolved members. A reached record carries its complete assigned member vector, even in a partial table. The primary-only communication read does not use fallback. A qualifying army-group order can inherit the parent branch when it has no child section. An observed area-defence target proves the positive branch despite incomplete membership, while disproving all candidates needs a complete order census. Marker colours come from the representative's recorded group or its inherited parent. Prepared-hour indexes preserve recorded key identity, where duplicate rows make an hour corrupt.

Division attrition reads recorded training, supply and border-war inputs, loaded terrain modifiers and the sub-unit operands for the special-forces share. Use the content clamp when loading the supply threshold. Share the equipment contribution preorder between the deployed panel and counter explanations. Each nonzero native occurrence contributes even if repeated. The lower bound stops terrain and equipment upkeep from making the total negative. The owned-relation fallback includes retired occurrences.

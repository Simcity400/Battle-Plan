# Preserve territory and threat attribution across recording changes

Owned and controlled places credit their respective resolved holder. An occupied place credits the controller only when both countries are known and differ. Zero represents land no country holds. An unresolved link withholds the affected measures for every holder. The world-owned and world-controlled counts include every place independently of country links. Area comes from the recorded map, and absence of an area's value withholds that measure for any applicable sum involving the province. [Territory writer](../../crates/recorder-derive-world/src/territory.rs)

Regional territory uses the same ownership rule and adds entire province counts, victory points and areas. State totals instead sum exact fractions, using each state's roster of provinces. Provinces that lack a single matching region and states that lack any province go into the no-region bucket. A fraction with a reduced denominator outside the representable range withholds the state total. Inserted, deleted or reassigned provinces change the denominators and require a full rebuild even though other place changes can apply incrementally. A resume also rebuilds the attribution indexes from recorded tables. [Regional writer](../../crates/recorder-derive-world/src/territory_regions.rs)

`ThreatTotals` adds every country's contribution before the cap on displayed world tension. It includes negative values and withholds the sum if any contribution is unknown. The separate `ThreatEvents` writer establishes a baseline for the first read and after a gap. The source list compacts, so positions alone cannot identify events. A source's country pair, date, reason and ordinal among equal sources identify it without misreading a position change as a new listing. An event retains the source's resolved country when it was listed. It lives at the hour it was witnessed, and a resume reads the commit hour to recover the baseline without duplicating those events.

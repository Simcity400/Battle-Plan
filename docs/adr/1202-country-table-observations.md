# 1202. Keep table ranks, names and values at their supplying observations

The country score table receives its moment from the push or request. Apply the group membership and resolve slots at that moment. A country with no known score does not take a rank. Paint live scores between structural changes. If the members of a top list change, commit them with the current score ordering so a newly admitted country never inherits an earlier list order. Country names need not be requested for every numerical push; read them for the changed row set. The race and table use the same total-score sort. The game multiplies after adding the army, navy and air components, so a split bar shows them proportionally. Use the recorded end-screen hint when the content supplies it.

The leader career view reads the whole career independently of the leader's current panel. A pinned leader or tooltip cannot turn into whichever leader later ranks first. The leaderboard applies its country filter in the same render as the supplying panel, avoiding a second commit after each push. Names and portraits use the recorded identity and date. Batch portraits in visible row order because decoding fresh art can otherwise make a mounted row wait on a whole roster. A load failure uses the named placeholder. Keep exact fixed-point experience until display, and show native additive training adjustments as percentage points. A battle count from incomplete history is a lower bound. A battle and its verdict become known at their separate supplying reads.

Factory counts use the game's three recalculated groups, including mod buildings with the appropriate group flags. In the built count, damaged factories appear as a subset of each group's bar. Experience similarly uses the engine's fixed army, navy and air branches rather than a content category. Daily experience series come from the recorder's daily table. While following, use the live value for each line's last bin, so a current value cannot be replaced by the previous bin's end.

An exile row identifies its native country and host at the supplying hour. Country choices can match either one. Unknown hosts or membership produce diagnostics. Paint numerical cells and report the hour they actually answer. Update the country filter when group membership changes and load every compared name for a name sort, while keeping flag reads limited to mounted rows.

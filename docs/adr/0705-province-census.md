# 0705. Authenticate province observations and reuse them within their witnessed lifetime

The unit-order walk preserves occurrences and native vector order in the mixed and naval lists. Rows address slices of caller-owned handle storage. The walk authenticates a province against its roster slot and an occupant against its full registry identity and backlink. It can reuse a division authenticated by the caller's census at the same boundary. Other occupants still require the full check, including the task-force class for naval entries. A selected-province walk takes ascending IDs and reads only those provinces. The caller supplies evidence for the others.

The direct-combat walk keeps parallel handle and kind arenas in source order. Land, border-war and naval classes are admitted explicitly. Empty vectors produce no row. The readers count complete demand for an off-thread resize and use checked capacities before reading body fields. They check remaining roster roots even when body capacity has run out, so a full buffer cannot hide a failed census. Null holes consume no row space. A valid zero-length vector may have a null data pointer. Batching uses exact fields to bound stack space and avoid copying padding. The dense plan is selected before reading body fields, and sparse or partial copies preserve which field first failed. Bounds on contiguous spans follow from the checked last element. The unit-order walk may hint a small group of already admitted addresses before serial registry checks to overlap independent misses.

The province row keeps the raw controller reference, unscaled victory-point value and name override. Strategic-location tokens retain insertion order and the native update rejects duplicate tokens. Name overrides preserve the native string length. Empty strings have no row, and a complete names snapshot removes a previously recorded override when it becomes empty. The reader copies the live override rather than deriving a localized display name.

For movement, a land province with no owner area is refused. A province in a border conflict is entered only when the moving army is already in such a conflict or its owning orders group matches one admitted by the destination's combat set. The reader considers both sides in native order and resolves the complete reference. Failure to copy conflict groups withholds those rows independently of the province census. The movement reader keeps the positive-fort predicate and the static port link. Replay derives the terrain ordinal from recorded map content. The reader reaches the state bunker term only when the fort sum and controller reference warrant it. The modifier resolves the controller and uses its state-country term with the country's own modifier.

Area pointers are capture-local and never enter the recording. An area is identified by its smallest member province, with zero for a null pointer and a missing area label when the area pass refuses. The representative row links to the corresponding area node. The area pass refreshes selected carried rows using fresh pointers to detect changed memberships. The capture callback lends each area and province store to the worker and takes it back afterward.

The province store holds only the latest complete walk. Carried rows match territory observation epochs, the table header and the roster slots that witnessed them. An incomplete read or failed job discards the store. The hour's territory marks are consumed by the next walk and may name provinces or their state. A state reset uses the held rows to recover its old membership. Provinces in an active conflict reread each hour because no membership mark certifies the combat groups. A bunker value also depends on the country census, links and state modifier observation epoch. When the witness changes or the state is marked, fortified carried rows reread the bunker term. Area labels are assigned by the separate area pass, after row reuse has been decided. A requested refresh or refused witness selects a full walk.

Territory observers mark the province state link, owner and controller assignments, victory-point writes, conflict membership changes and area rebuilds. A province definition and its port are content or construction inputs. The building observer forwards healthy-level and vector changes by province and template weights come from loaded content. The raid observer forwards changes to state modifier structures, including destruction. No observer certifies country links or roster identity, so the walk acquires them once per hour when it needs a fortified province.

State identity and ownership can be shared within one quiescent walk. The pointer cache compares complete keys and preserves several successful collisions. A full window falls back to a live read and does not cap the number of states. Building weights likewise use a small successful-read cache for repeated templates and fall back to reading others.

The movement geometry packet keeps typed observations, with directly indexed acquired adjacency prefixes. Capacity grows off the capture thread. The native province-root gate still runs for empty or all-null queries. Same-pass observations do not survive a new acquisition. Only a nonzero identity can be carried to a later pass of the same world, whose lifetime preserves both its province and ID. If a slot ID disagrees with an owned observation, the reader checks the object's own backlink. Speed selection may use a null roster slot or authenticated slot zero, while ETA endpoints are strict. Adjacency selection follows native order, retains the prefix actually acquired and reserves the remaining demand without retrying. Lookup counters distinguish memo hits and native reads and do not affect admission. For movement operands, identity is common, but the state, river destination, access, transport and terrain branches can fail independently. The batched reader retries an individual failed row when needed and resumes gathering its remaining siblings.

The static geometry cache keeps only immutable map fields across hours, keyed by session and province roster. An unreadable key bypasses memoization and allows a live read. Strait reloads can alter or append crossings without changing that key, and the embark define can reload independently, so both are read afresh each walk. An edge uses the first matching adjacency, retaining the native distance fallback when none matches. The reader checks the province's roster backlink and both object identities before accepting definition fields.

Fault parity tests compare batched and scalar acquisition, including partial writes, first and last byte faults and transient guard failures. A later prefetched fault cannot displace a semantic refusal already reached by the scalar walk. The test fixtures include an unrelated adjacent word to verify the native narrow building field, class mismatches, dynamic reference types and slot-zero lookups reused by stricter endpoints. Large-table benchmarks separate unmarked hours from controller-change workloads and measure the area pass both with all carried rows and with the rows a change can repoint.

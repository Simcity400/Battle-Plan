# Retain production attribution for the life of an output row

The producer of a slot is the lowest raw ID with a live country row whose link resolves to its own slot. Production and dockyard repairs use that same holder rule. A live line's captured output counts for the first producer its link identified, even if the links later change. A row can receive an owner later, including during an hour with no output change, only while it has delivered nothing and its amounts are exact. Prior deliveries or inexact values with unresolved ownership invalidate the affected measure for every producer. Assigning them retroactively would invent attribution.

The writer adds the difference from each line's retained previous cells. Deleting and recreating a key in one hour starts a new line. A line deleted without its terminal sample leaves units a lower bound and applied IC unknown. Unknown applied IC stays unknown until the observation restarts. A missed input hour carries the prior table rows under an unavailable status and the gap prevents claiming exact totals when the input returns. A different observation start hour resets totals and coverage. The resume blob stores the live rows' owner assignments and eligibility for late ownership. The sums live in the output tables. Rocket counters are covered only while successive observations are consistent. Regressions, changes without a new tick or delivery, lost rows, and ticks or deliveries with unresolved ownership affect coverage from their observation hour. `ProducedValues` combines exact production line and Rocket contributions for all equipment, each recorded archetype, and the remainder. A recorded missing archetype group in an otherwise complete input contributes zero. A live design with unclassified output instead invalidates the archetype and remainder totals, since it could belong to either. A units lower bound is not published as an exact combined value. Its clock uses the output's recorded sampling hour, falling back to the hour the totals changed when no sample was marked.

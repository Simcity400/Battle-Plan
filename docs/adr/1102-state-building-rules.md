# 1102. Build state building and resource grids from native slot and level rules

Use content database order and authored DLC gating. State building types that use no shared slot appear first, with railways last. The province grid omits railways and separates landmarks. A landmark frame reflects damage and uses the facility template scale when appropriate. A foreign building that needs detection depends on what the observed country knows. Building picture availability, level text and hovers needing the current maximum level are withheld when that maximum is unrecorded.

Derive shared slot count with the hour's authenticated state-owner modifiers. Fill slots by one-based building level in type order until the maximum, with empty rows up to that limit and only unlocked positions open. For each recorded building, full health covers healthy levels, partial health applies to the next level, and the others have no health. The damage bar uses the native percent and frame convention. Refuse slot fill when a pending construction or conversion can add slot-sharing levels whose contributions are unavailable. A slot without sufficient intel uses an explicit unknown sprite.

Compute railway summaries in recorded province order. Use the clicked province's building status supply country, falling back to its controller, and visit only provinces that country's daily supply access marks. A railway info record without a building is fully damaged. The first province to reach a new worst damage supplies its level for the damage count rounded upward. Track the highest level across all visited provinces separately. The railway damage bar reflects worst damage; the hover names absent level data. The health fraction includes the partial next level and preserves the native overflow outcome.

Read controller operands for factory energy and apply the state and country factors and the controller's energy per active factory group. A factory can count in more than one group. The building-modifier icon requires a healthy building with an effective state modifier. The hover formats state buildings followed by province buildings in territory held by the state's controller, scaling by healthy levels and dropping an empty description. Fixed-point resource amounts display in database order, whole and rounded with ties away from zero. Show the native no-resources message only when all three inputs establish that the template, pool, and additive modifiers contribute none.

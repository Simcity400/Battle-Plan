# Share the fleet census while keeping table admission independent

Walk fleets, task forces, and ships in native country, fleet, and roster order. A fleet can be empty. Authenticate each fleet against its owner and each task force against its fleet, and retain the task force's actual owners even when they differ from the fleet's owner. An authenticated native pointer only belongs to the current census. Record the complete native handle and retain duplicate keys for the encoding layer to reject. Compare both words with the native invalid-reference object when deciding whether a fleet leader is absent.

A failed root or relationship invalidates the shared traversal. A body-field fault, storage shortage, or independent suffix refusal applies only to its own table. A full fixed buffer stops its body reads while retaining counts and the roster checks needed for other tables. The worker sizes from each original header without a second native walk. A visited prefix cannot certify a dependent ship census after the parent table is truncated or unavailable. Share already authenticated objects with other consumers, such as fuel, movement, mission, management, name, supply, and political port readers. Each consumer reads only its own operands. Optional arenas and certificates leave the established prefix order and failures intact.

Copy fleet and task-force records once when possible, preserving authentication order and named failures for incomplete copies. Ships enter runs in census order. Cache hints warm later addresses without counting as reads or admitting their identities early. An incomplete run falls back to the isolated read for its remaining eligible ships, at most once each. Lasting failures match the serial walk, while a transient failure may admit an otherwise readable result. Flush ships already queued before returning a later roster failure, so any rows or visits before it still take place. Count-only capture preserves outcomes without reading omitted body fields. The fixtures cross task-force, fleet, and country boundaries to verify these guarantees.

The optional clock reports fleets and shared roots, task forces, and ships, in that order. A phase ends back at the root phase on success or failure. The caller separately accounts for a visitor's work inside the measured ship phase.

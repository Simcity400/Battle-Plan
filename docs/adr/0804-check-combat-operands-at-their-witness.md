# Check combat fields against the witness that can prove them

The text save omits several transient combat operands. Primary country sets accumulate logical owners as members join and survive transfers, so their correctness comes from the recorded census and reference resolution. The same-hour reserve census owns precisely the modifier sources selected by each reserve, including its expeditionary owner where present and only a commander whose contribution applied. Naval tree identities follow the references reached by live sides, escaping ships and linked air groups. Their values require the fresh diagnostic witness. Carrier and forward-air base joins check the bases reached by combat and the base and wing censuses because the save omits dense container order. [Combat-side and census comparisons](../../crates/recorder-oracle-combat-details/src/combat_details.rs)

Compare native ordered vectors in order, including formation membership and naval timed-trait days. A missing token spelling limits only the name comparison if the remaining operand is readable. A commander can join to its saved formation through the formation's leader reference. Army groups do not supply that reference. The saved last leader cannot establish a null current commander, but a wrong nonnull current selection differs. Localized text caches use the viewer's language and are not compared with frozen save text. Other readable operands still compare when one comparison has a named limitation.

The save writes positive-only scalar fields only above zero. An omitted field therefore proves at most nonpositivity. The stored anti-air operand is compared exactly and the prevented damage lanes at their display step. Combat width is unconditional. Recorded samples sum with native signed wrapping arithmetic, and every expected sample must be present. Reserve speed share belongs only to reserves. The commander's displayed skill ratio is separate from raw experience. [Combat serialization and precision checks](../../crates/recorder-oracle-combat-details/src/combat_details.rs)

## Division naming

A member's named operands come from its own row or the matching division status. The recorded member template is decisive when present. A reference of the template kind absent from both current and saved template membership can prove deletion and therefore no group. An older recording with no template-reference field can use the alternate or standard template that loading would bind, while preserving a named limitation for live groups that could have differed. A field the recording supports but did not record for this member does not justify that fallback.

Only a type-zero naming member resolves the template's group for a programmatic name. A set group supplies the displayed entry and suppresses the hidden override. A null group displays the stored override. The save always writes the name type. It omits default ordering fields, empty override text and a clear programmatic flag. The same projection is used for combat members and whole-roster naming. [Naming cases](../../crates/recorder-oracle-combat-details/src/combat_details/tests.rs)

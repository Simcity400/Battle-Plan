# Lower pass state and register uploads independently

Draws receive native register bytes and vertex semantics. Buffer names do not control the uploads. Vertex and pixel slots are separate, and lowering validates register bounds. Stage constants in ascending binding order. A caller-owned constant buffer must hold the full reflected block, zero-filled beyond supplied bytes and positioned at the device's dynamic-uniform alignment. A caller providing a partly initialized allocation validates the reflected reads before binding. Slots the compiled program cannot read need no bytes. The compiler reports actual byte and texture reads after dead-code elimination, allowing callers to invalidate on precisely those inputs.

For per-instance draws, the row selector holds base indices in binding order with the optional vertex stream last. The row array is bound whole and reads are indexed by instance. Rewritten streams are read from storage and are no longer vertex bindings. If the rewrite is refused, the pass retains its plain pipeline and the caller can draw separately. Normal staging retains the existing arena allocation and failure order. Differential buffer writes compare fixed-size blocks, including short tails, and bridge limited unchanged runs to reduce write calls. Identical input writes nothing.

Program, blend and sampler selection apply independently, including null fallback selection. Only samplers the compiled pass reads affect its pipeline key. The sampler uses the native maximum anisotropy convention of 16 for anisotropic filtering regardless of the parsed authored value. An explicit null shader-resource view reads zero. A two-dimensional native view sampled as a cube also reads zero. The WebGPU resources used for the null case are zero-initialized.

Depth and stencil bundle flags follow whether any bundled draw writes the attachment aspect. A bundle that reads an aspect can therefore execute in every pass that would accept the draws directly. Immutable pipeline state belongs in the device cache key. The caller still sets viewport, scissor rectangle, stencil reference and blend constant as render-pass commands. It forgets previous bindings whenever other commands may have changed the state. Bundled commands count at execution, independently of encoding.

The native alpha equation inherits the color equation for the `ONE/ZERO/ADD` sentinel, even when authored explicitly. WebGPU requires explicit factors of one for minimum and maximum blending, which ignore factors in D3D11. A null blend constant supplies ones. Depth and stencil indices follow D3D11 enumeration order, with unsupported indices using the first operation. The authored front-face stencil operation applies to both faces and masks use their low bytes. Native rasterizer depth bias lands in WebGPU's depth state. A disabled depth test cannot write. The renderer supplies multisampling and line antialiasing. Rasterizer depth clipping stays enabled and the caller sets the actual scissor rectangle.

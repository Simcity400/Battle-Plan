# 1103. Reconstruct plan geometry from authored map topology

Bound fronts and snapped offensive lines follow integer gradient-border pixels, using source-owned pairs. A one-hop sea crossing redirects the pixel lookup through its neighbor, but keeps the original target for the teeth probe. The first join sets orientation, reverses the next pair if its other end is nearer, and drops jumps of four pixels or more on either axis. The overlap offset follows the majority probe of the source controller, comparing positive canonical country identity. A tie selects the negative side. A quarter-turned raster probe from the first kept source pixel decides teeth direction. The raster does not wrap this probe. Missing raster data refuses only where offset reconstruction reaches it. Offset controls are resubmitted with the authored intersection budget and smoothing parameters.

An unbound offensive line reached by a move chooses the candidate side from the arriving direction and local tangent. The authored neighbor list establishes candidate order, duplicates, seed order and ties. Exclude impassable neighbors. A candidate may be slightly off the side within the fixed-point tolerance. Grow the longest pair chain through mutually adjacent candidates and snap only if it covers the native allowed fraction. Unsnapped geometry uses centroids and crossings. A one-province line takes the ray through an owned pixel, using the quarter-turned final valid predecessor direction or the diagonal fallback at the sentinel. The first samples outside the province define endpoints. Hitting the scan limit supplies no invented endpoint. Keep the submitted duplicate and inserted controls without resmoothing. A move starts at its first crossing, thins intermediate provinces, and can finish at its first successor's nearest stored control. The wrap and strict proximity tests retain the first tie.

The control builder computes insertion spacing from the count before submission. Keep fixed-point products, float square root and the native signed conversion behavior distinct. Invalid conversion produces the signed minimum, which wraps at the step subtraction and still encounters the native control cap. A forward loop removes the range at the first closed-segment crossing without inserting the intersection or repeating the search. Near-closed tail trimming starts at control zero and tests the budget after each distance check, so a zero budget still examines the first point. Negative intersection budgets scan the full existing list.

An invasion follows the source, the searched sea route and the first destination, wrapping each centroid and retaining the raw crossing before move smoothing. A paradrop has a signed source and first target, submits a densified straight segment with no intersection test, and lifts it by the sine curve over the terrain endpoint heights. The amplitude caps a length-scaled chord, with the native signed fixed-point square root and narrowing. Sample by stored control index, including both head samples, instead of using spatial arc length. Missing centroids refuse the order. Empty input paths and native destruction cases do not draw. Shared head, culling and texture rules affect ribbon presentation without changing which recorded order supplied it.

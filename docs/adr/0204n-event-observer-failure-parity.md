# 0204n. Preserve native event refusal and unwind behavior

Air losses that the writer would not store go directly to the original. The other calls retain their original argument, return and unwind behavior while the observer acquires the recording operands. A withheld gather steps through the guarded serial reads once, preserving the row and first-refusal behavior of the serial path. A generic capture in another execution context cannot consume the observer's in-flight ledger claim.

Building damage records signed downward health changes. Attribution is consulted only when the change qualifies. An observed absence of an aircraft wing preserves the damage event without counting an unreadable wing. A missing interval remains unavailable, while an unresolved execution preserves partial recovery. Sizing benefits from a building census shared with nuclear strike capture, and demand can still grow when that census is unavailable.

The native unwind fixtures run through the production observation paths with authored callers and native handlers, outside a Rust catcher. They exercise real unwind metadata. Returning from the synthetic handler permits test teardown. Production teardown keeps the owner when a callback is still stranded.

`air_losses::air_loss_entry` keeps argument and return slots independent of `CallContext`, which starts at `CONTEXT_OFFSET`. It copies the RSI and RDI values before entering Rust and leaves those registers unchanged. Its `.seh_stackalloc` covers the complete owned frame. `building_bombing::building_damage_entry` calls native code outside Rust and includes the owned snapshot in its unwind allocation. Its relocation moves only the RBX home-slot store. The synthetic stack in `assembly_wrapper_has_real_unwind_metadata_for_native_call_stack` fills the native R15, RDI and RSI push slots in that order and separately fills the RBX caller home save. The observer families' `Hooks::new` require the authenticated executable, exclusive ownership and a drained restore before release.

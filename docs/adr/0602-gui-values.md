# Share the native token reader while retaining each GUI value's consumption

GUI values depend on both the current lexer token and the persistent value slot. An operator or value that the native loop did not replace can be reused by a later key. A sub-reader can push a resolved token back into the current slot, but resolving into the value slot alone does not change the current one. This distinction determines whether a colour or object reader enters a block. Scalar readers may leave a block for the enclosing loop to read as its own keys. Some nested readers enter the next key loop even when given a scalar. Unknown-key recovery follows the respective field reader. Most skip an opening block, while others diagnose the value without skipping its remaining tokens.

String readers stop at NUL and use a named unreadable-string result for a line feed. The reader keeps the quoted flag, and a failed advance can retain the current token's text. The integer point reader consumes its fixed sequence and distinguishes an untouched axis from an undefined local and a successfully scanned value. A later failed scan can reuse the earlier axis in this reader. Other component readers accept positional or labeled values, write successive words, and refuse a label read outside the supported table. A boolean assignment distinguishes a stored false value from one that stored nothing.

Position, size, margin and bounds have separate accepted keys and recovery rules. `auto` stores zero with its own flag. `%%` on a size marks a percentage relative to its position. A numeric assignment clears the auto flag and leaves the percentage flags set. An invalid native access caused by an empty size token or lone percent is a refusal. Root-size values use the GUI session extent when the caller has it. A colour number uses the native hex scan on the current token. A colour block reads resolved channels, normalizes values over one by 255, and retains a prior channel when a scan stores nothing.

Tooltip hashes use case-sensitive authored first-NUL text, including the delayed and disabled variants. The text bytes remain available to localisation. A tooltip anchor runs its own key loop with integer coordinates and boolean relative/below settings. Map icon objects have no pointer hit list. Bound localisation uses a pre-order node list, preserving duplicate arguments in input order. A scalar builds one node. An empty root key empties the tree. Recognize the native token and formatter forms before the plain key fallback. Context-aware text uses the view's scoped localizer only during the corresponding shown refresh, and before or outside that refresh the static text applies.

# 0304. Keep recording metadata and supplying-read dates tied to recorded evidence

Opening reads only the frames needed to establish a branch's first complete country catalogue. Incremental refresh reads only new blocks and leaves earlier country catalogues untouched. A table can fail later when playback reaches it without invalidating a healthy catalogue, unrelated values, or the whole hour. The branch's recorded run or block index supplies its frame extent. Gaps and declared branch starts widen the presentation extent, with touching gaps merged. An unknown failed hour can leave terminal metadata without a gap. The first branch is the main history and alternatives name where they part from it, including when another one loaded first.

Raw country link ids resolve through their canonical slots. The first row with a matching tag and resolvable link identifies a country. An absent tag and an unresolved identity are distinct. Equal tag strings do not merge canonical countries. The raw-link tag cache projects slots and tags separately from changing balances. It can reuse that projection when a consecutive recorded delta proves every identity field unchanged, while snapshot and identity edits compare normally. Table identity does not retain an allocation, so later writes can update the underlying table in place. Incomplete inputs leave the held projection present and invalidate reuse. A persisted projection resumes those same comparisons. Tag intervals extend only across authenticated consecutive hours with the same country. An observed gap, missing holder or new holder ends the interval.

Use cadence from the format that wrote the recording. A formerly daily table retains the old slot for its supplying read, even after newer formats make it hourly. A daily table's nominal refresh slot or timing of a table in that slot can establish its read. Full captures can read off slot. A shared copy can be charged to an hourly anchor outside the daily table's slot, so lack of timing on the slot hour does not cancel its expected read. CountryIntel can be deferred and read on its own. Its timing never dates its slot mates, and theirs never dates it. A failed read leaves the table incomplete, which consumers check before relying on its date. Other hours carry the last complete read. Readers sharing the same timed table evidence can share one supplying-read result.

Warnings describe the installed build once known, including a supported or unrecognized build mismatch and withheld tables. If the warning collector cannot allocate distinct messages, it stores overflow identities on disk to count them without additional retained heap growth. On Windows the spill opens with delete-on-close so cleanup under allocation failure does not need a second path allocation. This overflow is separate from mandatory metadata allocations.

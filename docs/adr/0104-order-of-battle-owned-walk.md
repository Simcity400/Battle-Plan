# Preserve exact order-of-battle observations in gathered reads

The theatre and order-of-battle source families own independent observations. Assign shared country-root failures to active theatre tables. Land headers, land detail and air detail retain independent masks. An order-of-battle root failure affects that whole three-table group. Hours that only need land headers retain the same country and owner checks and skip wing membership and nested arenas. The callback can certify the country census once while holding the game thread through all worker jobs. Each corresponding decode uses its own saved roster. It falls back to the original roster walk when no snapshot fits. The OOB roster copy uses the complete authenticated registry census, and an attempted census refusal stays terminal. Standalone fixtures can supply their own first census. Capacity comes from observed roots and references instead of a per-country estimate.

Group and member records stage the exact spans their typed consumers request. The member path can request both the short identity check and the longer identity and backlink checks. Keep both exact lengths. A provider reference identifies an embedded member, whose host and backlink authenticate it. Only a successfully read nonzero army-group discriminator allows a child header or entries to be read. That header extends beyond an ordinary group's allocation. Name-only refusal retains the unchanged certified prefix with an unknown suffix. Reverse membership census continues even when subclass details are skipped. The authoritative reverse census can remain complete with a truncated independent group table or an incomplete wing mirror.

Gather a root's own fields in one guarded call, with one logged span per field. A failed field retains its own refusal, and later fields follow the original per-field path. Gather member or child entries in bounded runs only if the log's available storage can cover every entry and its worst-case dependent reads. Otherwise take and visit each entry in order so storage exhaustion occurs at the same point as the serial walk. An arithmetic overflow that would prevent a per-entry read still prevents it. A run stopped by a failed entry logs that failure and continues after it. A failed member host identity still leaves the backlink to its own read. Within a held pass the same address-length key retains its native observation sequence, even when grouped reads reorder different keys. Tests compare healthy and lasting-fault logs by key and verify that batching refuses no additional tables if a fault clears after its first touch. Fixed-capacity parity includes a last run whose first host fails and whose trailing entries are null, where consuming the entry bytes before the first dependent read would otherwise cause an early overflow.

An order-of-battle memo stages each authenticated root theatre's native rosters once, retaining their first-seen order and refusals even for an unused subtype. A separate source family cannot stand in for the memo even if its addresses match. Sorting scratch positions by value and original position finds first occurrences without repeated insertion shifts. Returning the retained positions to ascending order preserves traversal order. The callback maintains enough scratch capacity for this to allocate nothing during the pass.

Positive decode consumers finish before the independent reserved-country suffix, with independent address cursors and shapes. A later staged header failure cannot replace an earlier logical OOB refusal. Staging can reject successful whole publication. Demand alone cannot certify rows. The optional suffix reuses only a unique exact positive witness, stops on first failure and leaves positive fault masks unchanged. Missing, repeated, poisoned or uncertain positive observations cannot authorize fresh retries. Only checked, representable demand from the logical callback may schedule growth.

Child-front capture can inspect the owning order group's staged discriminator and child vector header without advancing regular raw cursors. The own-field batch emits a unique anchor even when it recorded a failed field. Parent checks never emit that anchor, so its position locates this root's own flag. The exact full child header must occur once. Smaller and bulk reads cannot recover a refused or ambiguous header.

# 1109h. Use the same text operands for GUI measurement and drawing

Authored control text uses the content stack's localization and substitutions without a second scripted-text pass. An undefined key retains its bytes. Decoder refusal yields no text draw, and an undecodable nonempty string still counts as text when a button selects its text-only case. Prepared producer text can supply a resolved atlas key. The asset walker uses the same decoded text as layout and tries its preferred sprite prefix first when loading inline icons. An undefined inline icon contributes no width or draw. A missing font page still contributes glyph geometry and binds the null texture. A text flag with no resident atlas cell contributes no draw.

Text-only buttons use a separate font object. A button over a registered text-sprite type can bake into that sprite, with construction and later text writes using their respective formats. A fallback text sprite bakes empty and still allows a text object alongside it. When a check box with a font creates an untextured named text sprite, its bake has no width. Another sprite kind can drop the text. A text sprite with no font is never baked. Text-sprite dimensions for a frame are measured from the same bake as the draw. Defaults and unsigned frame counts are applied before division, and a zero frame count is refused before baking.

Text layout wraps inside its borders, then applies orientation, format and vertical alignment. Fixed and single-line boxes truncate with dots. Measurement uses the same operands with the height limit removed. An unset authored size axis becomes 200. The native bitmap font projects through the copied GUI viewport unless a component independently overrides either axis. Using the current viewport rather than the font's retained one can move or scale the final positions. Swapping to the font's viewport retains even non-finite floating results from a zero extent. Font color reset restores the resting color. Other color codes search the font then the global table, and unknown codes leave the color alone. The content stack's last authored global color block wins.

Glyph vertices flush in native-sized batches. Inline icons and flags submit immediately with the inherited text projection and modulation. An inline quad covers earlier submitted glyphs and lies under glyphs still buffered. Text color travels in the glyphs, while window opacity reaches modulation. An instant text box clips to its own inner box. Its named scrollbar draws afterward without inheriting the text's window opacity. Every text write refreshes the fixed-point overflow range, visibility flag and slider immediately. Changed limits clamp the value without notifying the text object, so the previous text offset persists until a notification.

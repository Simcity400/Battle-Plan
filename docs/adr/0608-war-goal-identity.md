# Project war-goal names from the same reads as their definitions

Read direct war-goal definition files in filename order through the recorded mod stack. A type lookup uses the first matching interned token and keeps its first declared spelling for localisation. A recording can name the token without identifying which same-token definition supplied its operands. The names projection withholds conflicting definitions instead of assuming that the first definition identifies their recorded goal.

Even when a caller needs only a name or war-name prefix, the trigger, effect and scalar readers still determine where the next declaration starts. Reached instant rewards use the same effect consumption as the full identity read. A scalar reader consumes its one token, including on a failed conversion, so a later declaration can remain visible. The game reapplies its conversion to the held cost factor when a replacement value cannot be read. Preserve that behavior, and keep the definition operands independent of the action and peace-term eligibility checks. The index shared by the limits and factor arrays is take states, liberate, puppet and force government.

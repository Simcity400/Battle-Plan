# Publish witnessed events in their observation window

The division log's first complete census sets its baseline. A real division sighted for the first time after that can become a sighting. A changed deletion witness yields a loss or transfer. A real division that disappears from the census without a witness yields a vanishing. Intel reveal copies are excluded. Dedupe a witness using its country, expeditionary owner, disposition and cause. Compare the witnesses written this hour, or all held witnesses after an hour the writer did not run.

Division events live for the observation hour in the derived table. They carry prior province, template, naming and icon operands so playback does not need the full tables from the preceding read. Prefer deleted row cells while they are available and use their original sample hours. A removal is dated exactly and can name its killer only when one matching death is held within a certified complete `LandEventCoverage` span from the previous census through the current hour. `DestroyedDivisions` can supply that death before the removal appears. Retain still-listed deaths from the preceding census across a resume. An absent or ambiguous death leaves an undated removal, which remains a usable event for recordings without death evidence.

`BalanceDrops` compares known political and command power across consecutive complete hours only. It starts a new baseline after a gap or an incomplete country table. It keys a drop by kind, raw country ID and observation hour and discards that row when the next hour runs. On resume it primes the balances and the currently living drop keys from the commit without persisting another copy. This lets a drop immediately after a resume match the uninterrupted run and clears the prior hour's rows.

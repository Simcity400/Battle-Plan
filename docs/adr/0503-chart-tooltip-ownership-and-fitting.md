# Keep fitted chart tooltips complete for assistive technology

Charts publish plain structured rows to one dashboard layer. The layer renders recorded labels as text and keeps the internal lookup identity separate from the label. A country flag slot carries the dated picture or its absence, including the reason. Neutral game values use the yellow tone. These conventions keep presentation and the missing-data states consistent across chart types.

Fitting tries the authored forms in order of decreasing detail. Producers can build those forms lazily. If they all exceed the viewport budget, fitting keeps the requested tail rows, on short viewports drops the description and the note as needed, and shows as many leading rows as fit. A summary row carries its exact hidden count so another fitting pass can replace it without double-counting. The fitter budgets the row, header, divider, border and padding dimensions alongside the layer styles. The visually fitted tooltip stays out of the accessibility tree. Each row's separate description reads the complete form, including any content too long for the visual version.

Scrollable tooltips keep the complete ordered rows in the store, estimating offsets for unseen rows and measuring the ones mounted. Page movement uses the measured row viewport. Refreshes retain the scroll position for the same owner and hovered item, and rebuild the content only if that owner still holds the layer. The revision tracks taking or moving the layer, which lets late replies distinguish a refresh in place from a new interaction. An explicit content key avoids serializing content each playback frame. Row tools describe the current data while the pointer stays still, and hide and forget the pointer when their panel goes out of view.

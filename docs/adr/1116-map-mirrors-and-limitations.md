# Map mirrors preserve status and row identity across steps

Mirrors hold the requested columns and keys by slot, their values, live bits and table status. A reset builds them on the fetchers from the sought lane. Only the host writes them thereafter. It applies deletions, inserts, values and renumbering in order, before applying layers. A log reset reads listed rows by ordinal. An append uses the lowest free slot, and a forget removes the ordinal's slot. Packing moves slots from ascending source positions and leaves the unchanged prefix alone. Optional missing cells and columns absent from an older format remain distinct from recorded values. Opaque cells decode using the row format of their source.

Layer code reads rows in compose or settle. The `probe` counts row reads within a thread so apply can be tested as a change-marker phase. Resolved column handles avoid repeating the same lookup for each row. List and string bytes are accounted on writes because worker diagnostics can ask for mirror sizes at each wake. List buffers are reused across writes. A gap makes all mirrors unrecorded until the next step names them again. A status change, exit from a gap, or change in an unavailable reason invalidates the views whose rows it affects. A changed reason is resolved in its run's dictionary, because an equal string id in another run can name different text. If a seek or step did not transport the reason, a mirror retains the reason it already rebuilt or reports that the text was not supplied.

## Named refusals and limitation reports

The viewer reads table statuses at the mirror head from recording block pages without opening full tables for them. It reports the actual unavailable reason by reading the restore and subsequent parts' string data. Shared asynchronous reads keep the reason while the recording pages are held. The frame never waits for the text. Detail and proof reports can wait for it up to their own bound, then report the timeout or missing text by name. Row notes use only values held in the mirrors. Where a held row's column is unavailable, the note names the missing input. A table no drawn layer reads still has its status line. Layer-produced limitations are copied only for drawn layers and their current perspective. Refused layers supply their refusal by name.

The proof compares the head with a fresh frame at the same hour. It separates tables with no written run, invisible or unregistered owners, row facts without a read column, and script-produced raid notes whose layer has no product. The remaining lines compare by exact text with each occurrence matched once, then by order. Enable `BATTLEPLAN_VIEWER_CHECK_PIECE` to compare a boundary's incrementally carried mirror with the independently rebuilt mirror, including status, head, live keys and cell values. Text cells compare by their dictionary strings. At a boundary, the independently rebuilt state is taken only for this check.

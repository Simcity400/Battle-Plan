# Keep raid distance evaluation in recorded row order

The recorded distance memo takes precedence over a calculated answer. Land and naval dispatchers have distinct keys. Naval bases target a province with a naval base or the first such province in its state's native order. The reader uses content order only after the recorded province-state membership proves it valid. The target building's province anchors land searches. A null source's zero distance and an unsuccessful path search are distinct. Missing tables, links and geometry are named refusals where the reached branch needs them. The path ledger also notes pairs a skipped or unsuccessful launch check may have asked. This preserves ordering even when that caller does not read the distance.

A batch is split into contiguous target ranges. The ranges first decide shown types without adding launch-path state, then prefetch type preparations, memo indexes and reachable components, then evaluate their launch gates. Parts use the pre-batch ledger and record every read pair separately. Merge parts in order and recompute any part whose pairs overlap a completed earlier part's additions. This yields the same results and diagnostics as the single-threaded row walk. Smaller ranges stay serial when sharing the work cannot repay per-part memo costs. The full paused cycle must equal reconstruction from scratch, including across skipped hours and with missing memo pairs that force recomputation.

The long-lived content-only memo weakly indexes searches by pair. Kept raid units and offer rows own the search results they use. The search runs without the memo lock, so several builders can reach the same pair and converge on the first installed result. Errors remain out of that memo. A search result's destructor re-locks the memo and removes only its own weak entry. Dropping a strong result while the memo lock is held would deadlock. The hour-local ledger records requested pairs and holds only the content answers it used. Large recorded memo lookups may build an index shared by hours with the same backing table allocation. Changed allocations cannot reuse it. Army reach is also shared within an hour, with each search resumed only as far as the next source needs.

Reach checks demand evidence in the order the reached game branch reads it. Known-empty source loops need neither a historical packet nor its providers. A populated source walk preserves repetitions and independently empty states. Military access checks the queried owner and refuses an absent answer when an unresolved country row could affect it. Demilitarized states disallow passage. Enemy sets can be derived from active war relations except where the game supplies a direct vector for a revolter or retired-war owner. A signed-negative raw country fails the receiver gate even if the recording gives it a positive canonical slot.

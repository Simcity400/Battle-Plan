# Fold owned equipment observations in writer order

The collector observes destruction writers and records the native owner, cause, complete design handle and exact signed fixed-point pool difference. A negative removal is a native gain, including when the airplane-loss writer accepts a negative request. A division deletion emits a separate once-per-division witness, including when its residual pool is empty. Nested damage flushes keep the entry owner, which native deletion may clear before the flush. An excluded cleanup object may have no valid handle or owner. Its scope suppresses accounting and retires any owned queued metadata without dereferencing that object once it is freed.

The callback never holds the drain's store or a live memory borrow across the original. It pushes an open event before taking any reads and reserves close-event capacity before the original, so another writer cannot cross untracked read windows. The next event supplies the read basis, and the close event records the post-call observation or unsettled unwind. The drain folds these events in push order. It keeps closed-window evidence only while another thread is awaiting its basis. Overlapping writers to the same pools, or a destructor beside shared reserves, provide no known native ordering. Because the recording cannot withhold a single key, such a contest refuses the interval. Dropped events, unplaced failures and a lost drain also refuse affected intervals. A failure counted during a queue take may belong to either side, so both sides refuse. The next clean boundary can resume. The first, load and discontinuity boundaries discard partial prior intervals even without a reusable frame.

Failure never suppresses native mutation. A writer that cannot be observed may still invalidate another open observation or deferred credit. The fold advances its credit revision when provenance might have changed. It counts refused attempts when sizing future frame storage, and initializes the store before enabling any hooks. Queue and index growth occurs only in the drain. First-refusal status stays readable while the drain holds its store. Writer slots and timing track the full callback. A load does not show that Windows has left a callback during foreign unwind; the collector retires active callback ownership only on a proven normal return and releases storage only after a final drain and quiescence.

The land entry shim preserves the native stack arguments and supplies the actual caller return site under unwind metadata. The air entry needs no frame. Zero land damage bypasses pool observation but still notifies the experience clamp. The air-loss writer's one installed observer also serves the wing equipment watch, and both land and air forward applicable strike pool changes. Patch groups are located and verified before installation, admit independently, and keep executable storage through rollback or detach. A forwarded observer only certifies changes while its owning patch is installed.

The fixtures exercise real guarded reads and authored native callers, including incomparable overlaps, nonempty fake pools, refusing originals that still run, and a native return whose complete value survives the wrapper. Shared fixture state is serialized, with the observation assigned to the fixture thread. Each attachment resets counters and recovers poisoned shared test state. An isolated process tests the first installation refusal so its attachment-scoped diagnostic cannot affect neighboring fixtures.

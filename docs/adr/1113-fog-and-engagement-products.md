# Scope fog and combat products to recorded evidence

The engagement layer reads a background history for the current branch, hour and viewing country. A fold that does not cover that perspective and hour leaves flags unknown with provenance. Only the recorded player's undecided naval flags can take the recorded engagement bytes. Between whole reads, combine the index's changed flags with combat rows beginning or ending. Read whole again on a change of recording player, viewing country, table availability or index provenance. Report changed provenance even when the engagement decisions did not change, so dependents can publish the new limitation. A whole settle may wait for the fold and still return an unknown flag if its wait ends. A still publication holds the side lock and polls to avoid trapping the frame behind background work.

Land combat markers use that engagement layer plus an unseen combat's last recorded icon frame from the same history. A changed kept frame remakes an unseen marker without scanning every combat each hour. Use the index's per-hour changes with combat births and deletions, and rebuild from the index on provenance change. A division or member-row write marks the combats that consult its operands. Prefer the combat member's own values when recorded, then join division rows. Off-camera marks are deferred by admission. Camera changes that admit exactly the same unchanged combat markers preserve their cut of the overlay product. Preserve gaps and limitations in the comparison against the full-hour builder, with both sides using the same index coverage.

The fog texture is averaged from the vision layer's province bytes using the content's grid multiplicities. Keep reverse dependencies from provinces to texels. While there is no province fog, the all-clear grid does not depend on individual province bytes. Drawing fog again invalidates every cell. This rendering distinction does not establish evidence for country or unit vision.

Operatives icons read the recording's content scripts on a worker. Open the reader only in Operatives mode and keep learned script table dependencies with the content between openings. `Clock` is a core input because scripts can compare dates. Take the newest rows after an outstanding evaluation, rolling intervening rows into the skipped count. Drop results from before a seek or perspective change. A whole settle asks for the hour it needs, giving up when the reader is already past it or newly learned tables cannot join while the head is held. A late product reports its own age while the map can proceed. Drop replaced row and icon payloads off-frame, and close the reader on a worker since releasing its last reference can wait for its former owner.

Each hour borrows one status store through acquisition and FIFO settlement. If the latest store is still out, take a spare or allocate an empty store and read the operands again. Waiting on the previous decode would delay the current hour. Only the latest loan may carry the next baseline. Older returns empty their holds and can supply a later overlapping loan. When the latest loan returns, its spare allocations are freed. If a new store cannot be allocated, the failure follows the collector allocation boundary.

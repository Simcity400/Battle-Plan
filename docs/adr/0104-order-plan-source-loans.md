# Bind plan fronts and replay their exact source observations

Orders owns the shared group and order census, invasion inputs and the first child-front area phase. It reuses the prepared country and division source bounds. Part walkers gather their own plan rows. Joining their owned arenas in census order reads nothing, preserves original identity order, and charges their gathered costs with the remaining Orders work. Front binding uses the completed plans without a native read. The separate Fronts job reads the bound fronts beside ChildFronts and returns them before table assembly. Its own failure only refuses Fronts. A refusal inherited from Orders or absent plan sources takes precedence over its job's cancellation or admission result. The invasion and front walks have independent native outcomes, so a fault that disappears on first touch can refuse whichever reaches it first without refusing both. Invasion rows leave the native walk in census order and publish in required key order.

ChildFronts takes the same hour's Orders roots and exact Naval OOB record. The first stage already captured the area inputs. The second stage uses the OOB record to authenticate the owner's discriminator and child count, then obtains the demanded child entries. Missing or rejected OOB cannot authorize a fresh read of the owned header. Skip building the OOB index when no plan needs a group source. The no-demand case grows neither indexes nor section arena and may run on the joining thread. An incomplete area or group phase withholds its corresponding operands and counts named refusals. The core plans and unrelated fields stand. A terminal Orders failure can refuse the whole publication.

Orders loans its complete observations and identity memo to Late. The assigned-host and execution observations keep their original provenance. The borrowed parallel sources have independent completeness verdicts, so a healthy plan prefix cannot certify a short assigned-host lane. Each arena's changed output is owned separately. Late's prepared work may mutate only its bounded arenas and retains the completed country and metadata observations. Both jobs rebuild their borrowed views over the same memo without retrying accepted failures. Only sparse completed values move to replay; native pointers and internal memo controls stay in the pack. The output buffer grows off-hook.

Order and group names have separate arenas with one common capacity measure. Rows tile each used prefix in native order. Publication cannot read the discarded remainder. Names may be rewritten in a reused native buffer without a matching writer notification, so capture rereads their bytes each hour. A same-size rename or new inline/heap placement cannot reuse the old text. Recording consumers receive owned names, geometry, child areas, assigned hosts and links after the complete source walk has finished. Synthetic parity fixtures compare through authenticated plan placement and use retained output arenas across consecutive hours and worker return orders. Warm capture cost cases measure the Orders, ChildFronts and Fronts acquisitions separately on fixed and guarded sources, charging the census's plan gathers to ArmyOrderPlans.

The synthetic Late request runner reads only owned Rust payloads, so submitting its fixture does not borrow a live game source.

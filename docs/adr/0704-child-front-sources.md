# 0704. Demand child-front inputs from the same acquisition pass

The first path province's controller area determines the small-area guard independently of UI state. A valid plan with a front and path gets its area count before the optional child array is read. The area phase uses only live memory under the held pass. A refused optional child array leaves its earlier healthy operands available.

The area phase queues each empty child array and each nonempty line-order child array for the group phase. Empty spans take their place in the section arena but demand no army-group operands and no growth. Reserve the pending capacity before the area phase. The group phase uses the exact same plans, placement and scratch and consumes its pending entries in census order.

The order-of-battle producer owns the army-group discriminator and the full front-binding header read. Reuse its exact observation, including failure. A separately readable count word cannot repair a failed owned header, and a missing source must not fall back to live memory. Only the final signed count is this scalar's demand. Ordinary groups or failed operands cannot supply army-group child counts, and a refused operand is not retried in the held pass.

Read only the demanded prefix of the stored child records. The first matching section for a demanded record is at or before that record. A persistent fault in the demanded prefix refuses it rather than inventing a shorter prefix. Growth follows a successfully copied and authenticated batch. If several plans share a one-shot area fault, the first plan in census order encounters it, independent of pointer table layout.

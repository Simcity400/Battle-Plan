# Resolve names from recorded operands and authored precedence

Country names are rebuilt in the viewer's language from recorded operands. Use a dynamic country's original tag for its naming tag. Use the first leader subtype and ruling party group from their respective witnesses, and attempt cosmetic keys before tag keys. A subject key requires both current autonomy and a positive overlord. Bind subject arguments only for that overlord and evaluate each name on its own explicit stack. Unavailable overlord text matters only when the chosen localisation reaches it. The native retry changes suffix case once, lower case before upper. The bare tag is the final candidate, and the display can fall back to the tag when none is present. Scripted localisation is refused by name. Nested missing references contribute no text, and depth and output limits match the localiser.

Selected and full-frame reads reconstruct names identically. Canonical aliases retain the last Countries row; read every overlord a selected name reaches. Distinguish a missing table or uncommon row from a valid row with an absent optional field. Slot zero lives outside the positive census in its authenticated singleton. Its effective original-or-own reference and string payload are separate from the naming tag, and each of its three cached name forms needs its own built witness. The numeric getter works without tag text. Positive original-or-own references never retry the owner's own tag. Flag lookup uses cosmetic group, cosmetic, selected group, then selected tag. A known empty selected tag and an authenticated empty ideology token still supply candidates. The same original-or-own tag helper serves the collector's status summary.

For historical division and ship names, the recording supplies the selected group, ordinal and ordered flag. Rendering uses that selection without allocating a new name or re-evaluating group predicates. A positive ordered ID may be sparse; an unordered index is zero-based. Ordered zero is unassigned. Use the authored fallback for an unmatched entry, with subtractive Roman numerals for every Roman placeholder and decimal substitution only when none is present. Preserve authored empty names, reject non-text only when selected, and keep prefixes on the entry arrays rather than fallbacks. Repeated declarations update ordered IDs, append unordered and unique entries, and apply their prefix pass.

The group loader reuses a matching ASCII-folded name in the army, ship or code-name table without changing its original table. Railway-gun declarations are not searched. Divisions use the army table, while callers with a recorded group of a different selected type can use any searchable table. Keep an empty group's name distinct from the empty recorded key used for the null group. An unsettled body leaves that group and every group a later token could name uncertain, including groups seen in earlier layers; the independent completed groups stay usable. Reading continues as the original loader consumes tokens despite brace mismatches. One variable store spans the file, with definitions created only by readers that enter those bodies. The ordered loop rejects a signed index below one, leaving that value unread. Text fields consume one token, name lists use the first string, and authored names and group keys end at NUL. End of text closes open readers; an end token with retained keyword text does not dispatch as a type.

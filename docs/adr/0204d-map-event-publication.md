# 0204-D. Publish map events by occurrence and release space after writing

Map event observers copy the operands at the game action that supplies them. Their event-specific tests decide whether the game would report the event. A read refusal marks the affected family's interval incomplete. The observer takes the world occurrence before reading operands and verifies it again before publication. A world change can invalidate an in-flight event, and a late event from a previous occurrence cannot enter the next world's interval. The first interval of an attachment or new occurrence is partial. A callback unwound through native code remains counted until teardown can establish quiescence.

Each registered native thread writes to its own single-producer ring, with a shared lane for threads that arrive after the dedicated lanes are claimed. An event that does not fit uses an owned spill. Spill storage is acquired before a sequence number is taken and linked before the publication count moves. No callback waits for a slow spool or overwrites unread bytes. Ring positions separate written, published, assembled and consumed data. The producer writes ahead of publication, and the spool copies behind it. The sizing thread grows from hardware parallelism, the country's maximum event payload and observed shortfalls. A replaced generation stays available to its active publishers and retains its events through draining and writing.

The game thread seals an interval with a bounded counter read. It reads publication before the last allocated sequence so the publication count cannot include a sequence taken after the cut. An incomplete cut can leave an event for a later interval, which also records the incomplete observation. The spool sorts and copies owned events by global sequence. Admission prevents copying the same event into another queued interval. Its storage is freed only after writing, so losing queued intervals can reset admission to the last write and report the lost output. Published refusal reasons are recorded for diagnosis without allocating on the native thread.

`hooks::unpack` reconstructs text from a word written only by `hooks::pack`, which accepts a static Rust string. The nonzero word represents that string's pointer and length, so its storage remains live and its bytes are UTF-8. `hooks::Hooks::new` requires authenticated, exclusively owned sites and keeps other families available when one site is withheld. `lanes::release` clears all generations. It must follow hook restoration, the drain of native calls and completion of every assembled-interval reader.

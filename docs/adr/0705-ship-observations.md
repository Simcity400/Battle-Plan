# 0705. Retain signed ship operands and certify shared observations independently

Ship strength, organisation and experience preserve their signed fixed-point values. Strength is native current hit points. Current crew is a signed acquired amount and is independent of equipment demand. A signed negative convoy tally survives serialization. Each ship retains its original task-force vector position beside the full native reference. Ships and divisions share the unit ID high-water counter. The ship's copied subunit definition can have the ordinary vtable even when its source was the null singleton, so the definition and its index must be interpreted using the copied operands and presence guards. Their token, formation flags and signed model number remain available for the model-selection ladder.

The naming reader copies the current authenticated member cache exactly in peace or combat. It does not refresh the cache or consult the generator. Capture revalidates the full reference, primary identity and member before taking the retained string. Worker growth follows the original complete descriptor without retrying native observations. An off-hour byte hint uses the same guards and does not read the heap payload. A fixed inline buffer remains a callback or fixture bound and does not cap a worker's acquired string.

Model capture verifies its own ship identity and task-force backlink even when the task census supplied the ship. It preserves the original reach and first failure of unconditional counter fields and the model prefix. Carrier subtype, composition index, selected hull variant and dominance operands have independent admission. A refused suffix does not discard the model prefix. Composition and selected-variant reads are reached after the original maximum-organisation observation. A selected variant belongs to the current stopped capture only. Equipment clones can share tokens, so observations memoize the complete successful definition and module identity, including the actual definition pointer and its token. Capture drops those pointer keys each hour. No memo failure fabricates a model or changes the original reader's reach.

Maximum organisation retains native source order and fixed-point arithmetic. It gathers four modifier keys in one source traversal, preserving the critical-effect-scaling input. Each critical entry truncates before summing and the two passes retain their original reads. Ship weather factor precedes the location contributions, and the original base organisation field follows both critical passes. Signed arithmetic wraps and clamps the minimum in the native fixed-point scale. An invalid batch span may follow the narrow path so an earlier readable field and its refusal remain observable. A successful prefix cannot certify an unobserved required field.

Task-force ships are consecutive in the census. Their owner and country terms, pride ship, doctrine, weather region, province and fleet-leader source are shared within the stopped capture. Terrain-class or subunit selectors recur in mixed classes, so the memo retains recently used selectors rather than a single one. The ship weather factor and critical-entry data remain ship-owned. Position terms use the original terrain, ocean fallback and day/night observation. The fleet leader and HQ terms require the matching binding and authenticated classes.

Use a previous hour's doctrine, country, weather or fleet tree only under the corresponding complete certificate and source identity. The retained province definition and terrain survive because they are immutable in that map domain. Ship and medal-store certificates govern the ship-owned operands independently of the task-force terms. When a certificate changes, reacquire critical entries even when headers compare equal. Eligibility and clamp observations are compared for every key present in a carried ship, once per presence mask. Values from a direct census are reused only after the complete entry walk authenticates even unused suffix entries. Certified task and ship operands can then recompute the current maximum with the same arithmetic as a complete read.

Carrier capacity uses an independently authenticated air-base subtype. Mega carriers use the supplied model flags. Other subtypes check the retained predicate's engagement byte and scan the stored equipment modules when needed. A refit can leave the predicate engaged. Zero-quantity variants still supply modules and a later unreadable design can refuse despite an earlier positive design.

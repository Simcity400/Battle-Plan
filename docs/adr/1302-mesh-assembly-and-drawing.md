# 1302. Keep mesh admission, posing and draw order native-compatible

Admit each submesh from its authored material key before applying a mesh-settings override. A nonempty shader file setting can replace the sources for all variants. The installed global fallback can supply the base material when a lookup misses, without the original material's UV defines. If a visual mod replacement cannot support the mesh layout, use the recorded effect and its own input declaration. Where neither material works, withhold that submesh by reason.

Interleave only present, correctly sized vertex streams in their native order. Distinguish an absent UV1 flag from malformed UV1 data. Fixed tree fetches still request UV1. Repair zero direction vectors with the native replacement value and retain three skin weights for the shader to derive the fourth. Store geometry in mesh space and send actor transforms to the draw bindings. Map samplers are shared outside the authored material sampler list. The shadow pass uses the shadow material bindings and only its permitted pixel sampler updates.

Share compiled pipelines where program and state agree. Reorder figures only when nearest-fragment depth, colour writes, bias and stencil operations make both draw orders equivalent. Blending, multiple outputs, equal-depth ordering, depth-dependent stencil writes, or stencil values the pass reads can invalidate that proof. A stable write of matching stencil bits can preserve it. Order-independent portions can share bindings even when other parts still require ordered draws.

Compute actor transforms from the sampled rig so the pose worker need not own an animation player. Preserve palette and skeleton source order, including forward-parent reads of a parent's local matrix. Crossfade uses joint scale and a single sampled clip uses mesh scale. Preserve the original quaternion components and addition order. Only the near-linear interpolation normalizes, and static channels do not call it. Preserve the sample interval precision and the wrapped next index even near clamped playback.

Locator import retains declaration order and duplicated names. Match the caller's own priority when attachment, dummy, navy and event lookups disagree. Resolve entity parents once against the mesh that was registered, retaining that origin ordinal through clones. A missing attachment binding follows the actor root. An absent played palette leaves a locator in local space, but a refused pose needed by a binding is a named failure. Compare locator names as original bytes across the binary and script encodings. Attachments use joint world matrices, independently of the skin bind matrices.

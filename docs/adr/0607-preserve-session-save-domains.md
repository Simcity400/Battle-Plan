# Preserve independent save domains for session comparisons

## Decision

Keep each physical serializer occurrence and test its own presence predicate. Do not replace unsaved native state with a guessed value. The save and recorded hour may expose different parts of the same object. Keep enough evidence for the oracle to name that difference.

| Save domain | Evidence retained |
|---|---|
| Battle plans | Preserve typed orders-group references and ordered child fronts and successors, including repeats. `route_is_ok` certifies only the truth of its route byte, independently of `can_execute`. Read order kind and operation from their actual keys. Preserve ordered `order_instance` and `fallback` lists. Per-order names occupy prefix, name, first, second, unique and postfix slots, with omitted strings empty and `unique` omitted under checksum. Continue distinguishing a missing group name from an emitted empty first-NUL prefix. Nonzero `time` is exact fixed5 preparation. Type 3's nested signed convoy count is unconditional, including zero. |
| Projects and nuclear state | Keep ordered program occurrences and `None` for an absent manager independently of a present empty one. Stored fixed4 fields can serialize as unscaled signed integers. A project name can be a lexer token independent of its registered reference, and state is an enum. Retain signed spellings of optional raw reference bits without interpreting them as tags. A null or unresolvable reference can be omitted. The nuclear writer prints stock as raw divided by 100000 even though one weapon uses 100000000 raw units. Ready count is a signed, unscaled and unconditional integer. |
| Raids | Preserve roster, cooldown and used-type order and the distinct target counters and detection array. Do not filter nonpositive country entries. Refuse unfamiliar keys and keyed detection bytes. A missing source proves the kind presence flag is zero, which gives no evidence about the independent source location and reference words. Read the type's own name, omit detected and unit words when clear, retain exact fixed5 distance and preparation when present, and honor the end-date presence flag. Keep target scope forms separate. A character target may provide none of the leader-province or building arms. A building location follows its definition's scope, including -1 for a country-scoped reference. |
| Peace and war | Preserve history-node traversal order independently of sorted tag lookup because the turn is rebuilt from the first node. Count every occurrence and retain each country's action order. History collections and child and country arrays are omitted precisely when empty. Active peace references repeat in stored order without filtering resident rows, and completion serializes only when its byte is nonzero. Preserve war-goal countries in the written liberate list order. War participation's signed captured-province key order is native. Delivery-history omission constrains only the absence of a quantity converting to nonzero native binary fixed point. All ledger scalars are unconditional, including negative credit, and the unknown-casualty score is unsaved. |
| Script events | Read the unconditional pending and fired registries and each country's delayed queue independently. Their errors do not hide another result. A country must still have a name for the overall projection. Keep random words in text order, which reverses the two native words. Distinguish absent `ROOT`, `FROM` and `PREV` objects from present empty objects. Event history and pending originators have no saved counterpart. Preserve registry order, specific reference-kind presence bits and a known empty result when a saved-target block is omitted. |
| Session and weather | The speed index is unconditional and uses a literal integer spelling, independent of yes/no. Session threat keeps the ordered vector, not rebuilt totals or caches. Its counts, dates and reasons are unconditional, and two nonpositive country references are omitted. Retain extra keys so an unmodelled field is visible. In weather, preserve runtime slot order, repeated numeric keys, zero and each province's independent ID operand. Temperature is unconditional. Boolean weather proves truth only. Custom modifier order includes repeats and -1 marks permanent days. Empty template modifier arrays are omitted. |

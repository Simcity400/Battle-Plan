# 0805. Compare production by writer order, full handles, and observation windows

The save nests surviving lines under the producing country, independent of the variant’s owner or organisation. The line never moves between producer statuses. Compare its recorded producer where the saved census still has it. Compare output counts from the branch itself because the save does not store them. At each observation of the production slot, the live output rows and live census must agree in both directions, with compatible output purposes by line kind. Ended rows leave the census. A now-empty table still needs its earlier publications checked. Start at the latest known observation start, searching backward through blocks as needed.

Modifier, organisation, licence, and variant rosters follow their writers’ ordered occurrences, including repeats and inactive entries where the writer emits them. Compare organisation and constructor owner references separately and use the save’s unconditional text fields and occupied history slots. Best-variant caches rebuild on load. Missing unconditional licence containers or fields fail the comparison. Saved MIO accumulators have no witness, but a successful design read of the same key must agree even for an aliased raw author. Use the daily design observation boundary and exact raw author when the record demands it.

Join deployment children through their full parent line handle, reporting orphans. Compare the first-NUL name prefix, field presence, null and positive tag gates, the name order’s zero omission and explicit no-order value, custom name flags, default distributable priority, and independent halting reason. Training and maximum operands omitted by the writer prove only a nonpositive value. Manpower omits nonpositive entries inside its unconditional wrapper. Equipment allocation gates the pool wrapper independently of visible entries, so a nonzero allocation count alone cannot prove it was written. An emitted pool requires its zero policy. Compare retained pool entries by full variant handle with multiplicity; align later occurrences after one removal and report reordered surviving entries separately.

Compute the saved factory efficiency using the game’s arithmetic over the smaller of the active and maximum counts. A short array fails the comparison. Named production strings distinguish raw output from token formatting. Compare icon presence from the active flag and explicit model presence from its unset rule. The current speed projection omits exactly zero, while retired produced progress has no current recording counterpart.

The save identifies variant equipment type but omits archetype. Resolve it from the recorded mod stack, including duplicate archetypes and replacement declarations. Use folded names and the authored type, its explicit archetype, or its parent as appropriate. This static content join reaches carried variant definitions as well as current ones. A carried daily row still cannot authenticate an independently current saved variant tuple. Published variant stat lanes are checked against proved native invariants while withheld lanes are reported by name as limitations.

# 0904. Preserve the native evidence for intelligence playback

## Characters and advisor identity

Keep a character template's presence, lexer token, exact file and one-based source line, and generated marker. A template instance uses its leading `allowed` block's closing line. An unread template has an empty file and line −1. The viewer uses file, line and token to resolve the template, while a save keeps the token alone. Stored gender selects feminine pronouns only at value 2. Role map keys and current ideologies can change independently. The current ideology distinguishes refusal, a known null and a known token. Advisor caches and tooltip key strings retain their stored order, with refusal represented separately.

A unit leader retains signed residual fixed5 experience separate from skill level. Its owner is a raw country reference resolved through `CountryLinks`. Only an army leader can have the captured byte. Its own visibility choice takes precedence, followed by its template visibility choice when the stored operand admits it. A recorded formation reference is scoped to army leaders with unsigned category below two. Zero is observed null, and the enclosing option distinguishes that from an out-of-scope or refused read. Older recordings can omit the formation field. Commander training progress keeps the native ordered entries independently of assigned traits. The two training kinds represent progress and per-trait experience overrides.

Character-scope checks need the role's trait definitions as well as its token spellings. Country leader and advisor roles use database ordinals because two definitions can share a name. Scientist traits resolve by token. Use the ideology map key for a country leader role, the advisor ordinal for an advisor role and zero for the scientist role. Empty arrays supply no row. Country leader and scientist traits are saved by token, and advisor traits by name. When a character has no direct unit leader, resolve its nonzero operative reference through the registry. Keep unresolved references and only read leader operands from a resolved object. The resolved operands include category, raw owner, optional skill and trait-definition ordinals. A stored codename can be absent outside its scope or on refusal, while an unavailable stored name means an independent refusal.

Read active and retired character records hourly in name-token order, including null records. A country leader named by token takes the first matching active record. A positive country plus a retired record with the same name token establishes retirement. Save comparison treats the two rosters as sets because the save deduplicates and orders by reference. The advisor-token set has its own lifetime. Loading retired characters or updating availability can add tokens, and retirement or list disposal can leave them behind. Store its exact strings in byte order so hash bucket order contributes no recording instability. Save comparison can reconstruct the set exactly at load and reports unexplained runtime tokens otherwise. A faction advisor occupies a position in a faction's own slot list. Recover the idea token through the role on the saved character and preserve gaps in slot ordinals. Available advisors keep the native search order, separate from hired appointments and without slot bytes. `SliceReads` identifies each owner's daily read. Hired rows keep the exact stored idea and slot strings in appointment order.

## Agencies, missions and operations

The created agency's name is stored in the recording client's language, using the content identity to recognize it. Display uses the localized default while the created byte is clear. Upgrade rows retain duplicates and signed levels in native order. Derive token identity from the authenticated branch-owned definition, using both branch and database membership. An identity refusal leaves the raw reference and level available but cannot certify an acquired upgrade count.

Record the operative membership census daily and the active roster's missions hourly. Commands and recruitment, capture and operation processing can change a mission between daily ticks. Keep roster order, assignment cooldown where applicable, active and pending variants, raw country or optional state targets, ideology text and the unit leader's own portrait when it has no character. The saved literal or localization key is distinct from the rendered text cache. Mission detection dispatches an event. The old wire slot held the description length. Root-out-resistance effectiveness requires the owner and operative modifier operands and the nationality match against the mission's context country. That context is the state's positive resistance country, or the target country when absent. Keep the strategic operative manager's per-country raw activity, influence and pressure operands hourly, in native table order.

Hourly operation snapshots can miss an outcome when the daily manager completes and immediately destroys an instance. A drained `OperationCompletions` batch instead records the stored results before deletion, including player and AI owners and separate full handles for auto-repeat. Branch-local sequence orders the events. A complete empty batch establishes zero observed completions, and a missing batch leaves the count unknown. Invalidation cancels without a completion. Save comparison cannot inspect an already removed instance. The game saves preparation counters as `civilian_factories` and `total`, omitting each when zero. Preserve phase and requirement repeats, variant equipment entries, and the separately held per-archetype totals used for requirement checks. Those totals are absent from saves. Preserve the bonus and risk detection trial results independently of terminal status. Keep the recording client's exact effect-description bytes, including NUL or non-UTF-8 when the guarded read succeeds. A refused description preserves the outcome and stored length, with no partial byte prefix. The description status distinguishes success, historical budget refusal and current ring-capacity refusal. Agency UI membership is its own observation in icon-consumption order. It can remain stale on a tag switch. Snapshot key zero can witness four empty lists, and operation instances cannot supply the list contents.

## Intel values and independent caches

Keep fixed5 network state values, their exact signed selector, and strength even when zero or negative. A negative selector leaves the selected subnetwork's factors and strength absent. An out-of-range selector has a zero local quiet flag. The map reads the local strength and quiet flag, while state tooltips read gains and their operative and neighboring-state portions and the selected subnetwork's operands. Preserve national coverage and strength independently because the native cache may differ from the state rows. Read both at the daily, reset or growth boundary and carry the last observed value otherwise. The old cryptology formats omit cipher order. The propaganda owner's terminal sequence holds the loaded weekly cache. Once the cache is derived it is the wrapping Q15 sum of retained entries. Without that header the owner is unobserved.

Record a country's four signed intel lanes under raw owner reference and canonical target slot. A complete array is sparse and always contains its final native index, even when that entry is zero. Thus a missing interior index means observed zero, and an index past the final entry is outside the array. An owner with no rows has no records in a complete table. Incomplete rows establish none of these distinctions for their gaps. The four lanes feed the fog, naval base and raid intel consumers. Unit intel uses full unit handle and native ordinal and retains nonpositive levels. The stored viewer index is the native country array ordinal, while decay is outside the recorded operands.

Keep independent contribution vectors for allied, cipher, static, current and prior dynamic, pending and accumulator values. Final keys retain native extents, and missing entries within a witnessed extent are zero. Static pool, source and entry headers retain their own identities and discriminator, while reserved root entries record cheat, radar, token and network references with their target. Use stable logical keys rather than process pointers. Network auxiliary rows get their stable id from kind, subnetwork and ordinal, using the maximum unsigned value for national scope. They retain the network graph and its assignments, quiet flags, native control and worth sums, detection operands, strength occurrences and core states. The main network rows retain selected values, and carriers outside the selected scope are canonical zero.

Scientists preserve raw owner and native roster position, with vector lengths distinct from capacities. A refused saved-byte read leaves membership and counts available. Daily auxiliary fields have their own acquisition date and option for guarded refusal. The retained conjunction distinguishes null, nonempty and native true for an empty list. Capture preserves unresolved operative references as full pairs, leaving a resolved leader's owner absent when null. Skill records retain the specialization token and signed level and experience independently. Zero is a valid level.

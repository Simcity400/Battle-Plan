# 1303. Resolve and place world names from recorded content

Names resolve in the reader's chosen language from the recording. Areas group by the mode's controller, state, faction, player or strategic region. The mode decides whether countries outside a group keep their names. If the recording lacks a grouping table, the mode withholds its names instead of showing names from another mode. An unresolved country name may use the country tag with an explanation. Unnamed groups and states keep no label. Connected areas get independent placements and a stable order by smallest member. Authored adjacency joins its two provinces, even with a blank or impassable crossing kind. Raster adjacency includes the diagonal at a four-province meeting, wraps horizontally and excludes province zero.

Placement is a pure function of identity, text and area. Reuse the last placement per unchanged area and scan province bounds once for the document. The placement cache prunes areas the new placement did not use. Prepare static glyph geometry on hour installation or by key and keep it while the camera moves. An isolated renderer with no hour installation can prepare it on upload. A temporarily absent layer leaves its last prepared glyphs available. A buffer chunk cannot split a name, though runs of different font pages require separate draws.

Fit uppercase text over the longest continuous permitted run, using the bottom-up raster for fitting and top-down province pixels at the public boundary. Near the seam, move western members by one map width and wrap the lookups. The two regressions, sideways offsets, slight horizontal preference, integer truncation, Bresenham phase and its tie rule affect which line the fit chooses. A run may bridge allowed water but foreign land ends it. Its endpoints trim to area members where present. A failed trim can leave a wholly water run eligible. The unoffset fit still runs when an offset leaves the image. Degenerate or unmeasurable text leaves no placement.

A near-degenerate regression can yield finite endpoints far outside the raster. Pixel coordinates use checked 64-bit bounds, regression moments accumulate in 128-bit arithmetic, and the Bresenham walker clips analytically to the raster's vertical span using overflow-free 256-bit arithmetic with exact phase before capping emitted points by `width + height`, preserving wrap handling and tie rules across rasters wider than 65,536 pixels.

Authored `0x11` text colour runs are parsed before uppercasing using the same stack rules and font/global `textcolors` precedence as screen labels (replacing full RGBA on active runs). Colour control sequences break kerning, contribute zero width, and are preserved per emitted glyph through `WorldName` and map-text vertices; stock-signature `mapname` shaders without a `COLOR` vertex input multiply their pixel colour by the per-glyph vertex colour while mod shaders declaring `COLOR` receive it directly. The width measure reads the recorded font's special control sequence and kerning. The straight glyph builder skips a missing glyph and uses its own advances. Spaces retain advance without adding a quad. The height-limited fit can add spaces, and the bend follows two uniform spline segments by glyph widths and spacing. Convert the quads to world space using the terrain raster bilinearly, clamp corners at water, then remove the diagonal saddle while preserving mean and slope. Clamping again would distort the fitted plane.

Names blend in HDR before grading. Country labels test complete glyph bounds and their wrapped copy against each admitted view, with the wrapped copy winning a tie. The country layer's own distance leaves alpha to the layer fade. The fade integrates with display time and takes one second. A standalone frame uses the settled value. A changed hover can reset the fade when the user has not asked for all names. A battle-plan label inherits its arrow's admission and ordering, draws once with no independent glyph cull, and keeps that pass's cull-none raster state.

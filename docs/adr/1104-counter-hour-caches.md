# 1104. Keep counter hour products only while their inputs can be proved unchanged

The hour's whole-world counter parts track the table views they actually read. A retained part may be reused when every read view has the same allocation, derived inputs name the same source table views and the extra key matches. Replay those recorded reads into an enclosing capture. A walk without stable view identities or a failed build cannot seed reuse. Build outside the lock so competing calls can build independently. The last completed build is the one retained.

Counter geography keys keep the ordered province-state projection, including duplicates. A later positive state takes precedence and a zero does not erase an earlier nonzero value. A cached geographic result holds immutable map allocations and the bits of its scalar thresholds. Holding the allocations prevents address reuse and a copy-on-write edit yields a new key. A refused core province read cannot reuse a previous hour's successful geometry. The memo keeps recent keys while an already returned immutable hour can outlive its key.

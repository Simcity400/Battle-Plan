# Measure production within one holder and observation

Combine production-line and Rocket delivery rows in units or fixed5 applied industry, optionally including refits. A selected design type uses the recording's lexical spelling and resolved content archetype. A design whose type was never recorded could belong to any selected type. Keep such an amount unknown when it can affect the answer. A missing design row means zero only if the producer-level row or complete Rocket world row establishes that coverage. Keep the source's own refusal before the run's refusal, propagate the first unknown when combining values and refuse totals that JavaScript cannot carry exactly. Inexact unit totals are lower bounds, so they do not supply exact window values.

Compute daily, weekly and monthly output from two cumulative totals measured within one uninterrupted holder and observation. Align both endpoints with production reads. The previous calendar month uses the same day and hour, clamping the day to that month's end, and gives no boundary before the calendar begins. Do not bridge a holder or source observation restart, or estimate a missing boundary. When page metadata carries no sample hour, a change in world totals can prove a nonzero read. A possible update with no delivered amount leaves no such proof and cannot serve as an exact boundary. Keep segment boundaries when equal totals meet across different observations.

Each chart reply requests a bounded window of the derived `ProducedValues` tracks rather than a whole campaign. The view joins its windows and ranks a requested top N once at the selected hour. Only positive known counts rank. The type list is ordered by the resolved content's equipment database. A type appears if a run-end total includes deliveries, applied industry or unproved output for it. A newly created line with known zero output does not add a type. Rocket design handles and line design handles occupy distinct buckets. A run's world keys can be found at the end of its ascending key index and named once with its recorded dictionary. A reply names the affected designs and retains each operand's coverage.

The earlier whole-branch calculation is a test oracle. It reads every producer's keys together per run, preserving the request-local naming diagnostics. Compare its series, missing spans, read stamps and observation starts with results assembled across window boundaries. The reference must continue to exercise partial first windows, zero deliveries, and ranking before any country has known positive output.

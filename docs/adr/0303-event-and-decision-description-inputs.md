# 0303. Read event and decision operands when the native description reaches them

An event title uses a fresh seeded graph. A country or state event installs its appropriate object and preserves both operands where a leader and country are present. Its `FROM` comes from the caller's `ROOT`. A copied seed may carry a refusal until title selection actually draws. A single unambiguous title or a literal title does not need that draw. An explicit seed uses its own amount and a default seed requires recorded inputs. Event option lookup searches the proper country or state manager for the exact named option. The option copies its supplied object, seeds, `PREV` and saved targets, and swaps `ROOT` and `FROM` before rendering at zero indent in the existing session.

Decision labels check their authored alternate or base key and then the cosmetic-tag, country-tag and base ladder. Each rung checks the ruling-ideology version first. A category uses its own authored identifier. A `fixed_random_seed` decision does not read an execution count. Other selection reads the first matching definition and target, with a recorded complete roster that contains no match contributing zero. Both target slots participate. Lifecycle flags are execution-only. Targeted activation does not require an already-active targeted decision. Removal reads its recorded prerequisites and refuses when a recognised selector is missing. Raw country identity canonicalises while a state keeps its state ID. A kind-specific target search tries carried states before the scripted arrays, whose deduplicated candidates are considered in ascending state order. It evaluates validity in fresh scopes and draws from a copied seed so the caller is unchanged.

Detail failures in an unlock description keep its name line. The reader owns only its explicit detail flags and uses them independently. Mission timers evaluate their own days operand. The ordinary removal delay evaluates in a fresh owner scope and transforms a positive delay as the native description does. Diagnostic traversal visits native children and attached alternatives without evaluating weights or expanding a scripted template body. Description traversal may expand that template and may follow a native child projection different from the generic one. For an MIO tooltip, a template lookup precedes the caller's first matching instance. The instance's pool country identifies it and its owner supplies the naming environment. A missing policy definition can print its raw key without inventing cached modifiers.

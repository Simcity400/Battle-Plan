# Match the typed statistics walk with one owned acquisition per owner

The air-statistics worker grows and reuses flat pooled storage from each original request. It captures the country and link preamble, then visits owners in canonical slot order. Staging the complete country-link vector once covers the link checks for visited slots and raw IDs. The typed walk determines whether null, foreign and reserved-alias slots are relevant. Each admitted owner's history header, slot words and nonnull history objects are recorded together, stopping at the typed walk's first abort.

A history observation stages the same identification, window validation, record linkage and nine channel spans as the typed reader, with the native signed capacity check and observation order preserved. The full-capacity guard is selected before the first source read. The scalar path retains partial admission and growth demand when the pool is short. Replay uses exact address and length keys with ordered repeated observations, allowing census and history reads to interleave by owner without changing the typed consumer's result. Decode walks only the complete accepted owned payload into its pooled output.

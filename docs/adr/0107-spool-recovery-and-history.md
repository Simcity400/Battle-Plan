# 0107. Track continuity at the spool’s durable boundary

Each attach uses its own spool root. Opening a previous unfinalized root would hide its history from branch tracking and risk reassigning a branch ID. The replay’s campaign spelling, including case, also names its spool directory. Native invalidation can signal a transition without changing the stored clock operands, so branch admission checks the invalidation witness separately. A load starts at the loaded hour when the first hourly update after the load returns. Detach cannot supply a sample for an unreturned update.

On a reattach that continues a recorded branch, the first observation ends an interval in which event completeness was lost. Record that interval from the last read before detachment to the first observed hour after reattachment. A new branch begins its own interval. If the first observation’s context has been written but its frame fails, the loss still ends at that observation and the unwritten frame remains a gap. Keep the loss once across retries. An invalid campaign identity cannot succeed through another open, so preflight lets consumption count it once as unattributed loss.

Preparation may do file I/O, but it leaves the caller’s capture and loss acknowledgments untouched. After successful preflight, consume the loss witnesses and the frame once. Detach runs the same preflight before consuming its last losses. Rotate a segment only at an already encoded keyframe so segment packing does not reset the encoder. Queued work may use its admitted baseline only once admission succeeds. A failed write cancels the queued suffix, and a later branch start can change parent when an earlier queued hour is lost. Codec failures close partially published contexts as well. Complete bytes that survived a failed flush can still be recovered, once.

A halted native capture makes later hours gaps naming that reason, with no repeated full-refresh request. Recoverable write failures can request a refresh. A failed static or staggered read should not wait for its next ordinary slot, while permanent refusals are applied after the retry decision. Preserve the original failure when detach or sync also fails. A failed or racing background sizing hint is counted without promoting it to a session warning because it loses no captured data.

The collector leases the history file while recording. For a checkpoint it lets the recorder append the closed journal segments, then retakes the file. A session close must refer to the load the collector is on, and a segment becomes settled only when no writer can append to it. Wait for work already queued to reach the journals before exposing their contents to a reader. History requests carry a correlation token and return a token-matched acknowledgment or a named refusal. A context that failed to close is returned to the capture side once.

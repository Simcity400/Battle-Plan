# Replay selected movement with ordered facts

## Decision

Selected movement is separate from a counter ETA route. Use viewer-local selection, cursor, input flags and interface mode as request data. The recording supplies current simulation facts in their actual encounter order, including repeats. A missing or ambiguous class census refuses the reached query, while a non-army occupant and a known empty list are ordinary results. Demand facts only where the game's branch uses them. Use the current subject predicate rather than historical dates. Distinguish raw zero, a nonzero alias resolving to canonical zero, and the receiver's actual raw reference. Area predicates compare same-pass area identity independent of controller aliases. Direct war checks in disclosure and access keep their original gates and direction rather than adopting the signed-positive guard of another predicate.

The selected tooltip permits retreat bypass, tries transport after class-route failure, and does not enable enemy avoidance. Common admission precedes class gating and path or transport work. Railway retreat first tests the directed edge, cooldown and selected building. Combat retreat checks order defenders before attackers and check duration only after both commander-ban passes. Railway repeats its sea-to-land gate even when common admission accepted the current location. The railway graph keeps the first matching adjacency. A heap entry holds the estimate from insertion, so later relaxation cannot change the old entry's position. Its integer square-root heuristic passes negative wrapped values through. Army paths first check owner-area equality and ordered adjacent land, then native controller-area search.

Area connectivity uses the recorded first-land nonsea index for visit identity and marks nodes when inserted. Negative start identity proves failure before requesting neighbours. Preserve initial repeats and linked-list order. A nonzero land count, including a negative one, reaches owner access. Initial neighbours need nonnegative callback cost. During expansion a later target still calls the callback but uses zero even if the callback refuses. Heap comparison is by cost and first-land province only. An extra label tie-break would reorder distinct areas sharing the same representative. Pop chooses the right child when equal and moves the hole downward before inserting the previous last item. Reached capture faults are refused by name, with no inferred topology.

Admission and localised reason bytes are independent. An empty rejection remains false and a null orders group may leave the reason empty, giving the next unit a chance to contribute text. Consume ordered first rejections with the recorded localiser, preserving named `STATE`, `OWNER`, `RULE_NAME`, `VAL` and `DAYS` arguments. Format the fixed5 warning with zero decimal places. Ordinary reasons append and the advance warning replaces the mutable reason. Strength precedes organization and max organization is required only to format the low-organization warning. Keep wrapped signed arithmetic and the zero-extended 32-bit sentinel check. An army caller can demand the warning even with no enemy, and warning text can survive an admitted route. Only the first relevant non-retreating class-0 occupant invokes the enemy warning.

For the order cursor, read the first selected unit and demand only the facts reached by its branch. Keep raw roster ownership, truce, route endpoint, theatre membership, queued unit actions and the template's reveal-skip byte distinct. The reveal-skip byte selects enemy avoidance from sea. The positive-owner fallback keeps its answer after the access and truce reads. A task-force entry uses fleet base, mission and naval range and theatre operands, which the cursor refuses when unrecorded. A Shift order chains from the unit's preceding orders.

Transport uses the current local selection in insertion order and the chosen actual or planned sources. Sea admission still uses the actual unit location. Require current-hour operands and the correct convoy pool and reservation filters. Do not infer access or use a carried route as a result. A nonzero signed transfer status selects the combat branch. The transfer source is read only at zero status. Early target-base success skips subsequent transfer, convoy, access and path checks. Convert convoy demand with signed truncation, adding one for a positive remainder, then wrapped rescaling, division and the low signed 32 bits. This gives the engine result even at overflow boundaries.

Transport primary and secondary texts have independent lengths. The first railway call can be eligible when only secondary is nonempty. It transforms and appends primary bytes and ensures a line feed on a nonempty body. The second call tests primary length only, then appends a literal ASCII space and the raw primary. Neither rule makes text length an admission test.

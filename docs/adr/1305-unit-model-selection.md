# 1305. Select unit figures from recorded operands and authored content

Group land figures by province, canonical owner and route, using the same anchor and grouping as counters. The oldest visible member supplies the preferred template. A figure moves at the counter's rendered spline point. Rotation uses the drawn tangent and the authored mesh's local forward axis. The original rendered frame intervals and standing headings are absent from hourly data, so the presentation uses a tangent for movement and a deterministic standing heading.

Try a registered saved template model, then the equipment and sub-unit pair. The pair can use its saved variant model, authored graphic pools and conventional candidates. Keep the roster owner for counter grouping and sight. A selected pair can use the variant's signed-positive origin or creator for its model. Keep the land entity when it has naval movement over water. Apply the authored naval-transfer scale only for the reached visual states. Railway guns enter the ordinary sub-unit ladder. The walker uses the infantry ladder without template, variant, model number or camouflage. Ships have their own layer and docked hulls are hidden. Use hourly template rows and the dedicated model witness when the recording omits the wider status table. Daily equipment rows combine with hourly new-division rows. If the recording omits the hourly table, a division missing from the daily table is unknown. Selective equipment reads similarly withhold unqueried divisions. A refusal affects only stacks that reach it, leaving counters and the rest of the map available. Assembly determines animation from native visual slots, recorded exercise and combat predicates, with a land-combat side fallback when older recordings lack the movement row.

Bind mutable country identity, equipment and authored model choices from the current hour. Share a content library with append-only slots and bake only reached entities. Retry an unsupported visual replacement against the recording's layers, with a named explanation. If the layer itself cannot load, the rest of the map can still draw. The model report counts attachment rigs separately so an entity whose visible parts depend entirely on composition cannot silently disappear.

Each caller keeps its own selection sessions. Retained selections and camouflages survive while the context and the specific rows, ranges and census entries they read agree. Shared equipment and fallback answers expose all of those reads to each stack reusing them. The later airborne pools use the supplied country's context. Scope dependency recording separately for the designer branch, country geography and the rows the normal pool selection actually uses.

Keep figures, ships, raid units and convoys as separate inputs to the staged field. A builder may transfer one materialized field to the first view and rebuild for later views. Raid entities and convoy residency placements bypass the unit-slot history. The convoy upload carries no live fleet, so the frame supplies that presentation. Carry convoy motion only across forward rebuilds with unchanged route inputs. A seek can keep selector results while restarting the motion. A raid model's forward basis uses its local positive Z and the request defaults to idle before a reached authored stage.

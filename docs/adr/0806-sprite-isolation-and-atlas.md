# Isolate sprite rendering from dashboard layout

Dashboard artwork executes content programs with the native sprite layout. The caller lays out and composites the image. A normal sprite sends constants to both stages. A masked shield's flag pass sends constants to the vertex stage. Masked layers compose into a half-float premultiplied target and return straight alpha for the host to blend. This flattening preserves coverage for source-over color passes. Other equations refuse by effect because they cannot be reproduced by compositing the flattened image. Packed textures without a compatible WebGPU format expand to floating components before sampling to keep native normalized precision.

Device creation starts on its own thread so the first request need not wait for it to start. Multiple independent sprite targets share one command submission and one mapped readback. Preparation and submission hold the renderer lock. Wait and copy occur outside it. Resolved programs and failures are retained with their content reads. A new content stack retries failures so that a repaired compiler can serve it. An earlier machine-local draw failure can affect the later answer in the same process. GUI map globals use the province bitmap named by map content and are read once per stack.

A masked flag may render from a standalone texture only if the atlas rectangle is used exclusively to map the flag texture coordinate. Verify this on the translated stages before replacing the authored rectangle. The proof accepts straight-line code and the supported wrapper around one body call. It follows per-component origins through initializers and ordered stores, rejecting unsupported control flow, dynamic indexing and unknown instructions. The vertex output may carry rectangle information only as mapped coordinates. The pixel stage may use them only as the coordinates of an ordinary sample of the flag texture, and every sample of that texture uses those coordinates. Sampling the flag at an unrelated coordinate, putting the rectangle in color, or using it when sampling a mask all refuse. Testing sample atlas rectangles alone cannot prove that this restriction holds.

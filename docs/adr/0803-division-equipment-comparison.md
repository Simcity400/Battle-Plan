# Compare divisions with their own equipment requirements

Each real division contributes under two attributions, owner first and host second. The owner is its positive expeditionary owner or its roster owner. The host is its roster owner. Intel reveal copies contribute to neither side. If any counted division lacks a canonical link for one attribution, that side's comparison cells are withheld without withholding the other side.

Per-template need is the count of each sub-unit times its equipment requirements, grouped by recorded archetype. Use requirements from the recording's selected definition and lexical tokens. A country-local clone overrides the global data. Absence from a complete clone table allows the global definition. An incomplete table, an unresolved clone owner, or multiple clones for one canonical slot and token can make the requirements unknown. A folded archetype name spelled by multiple tokens is ambiguous. Only unambiguous names are used. Template dependencies record each clone lookup so a changed clone can invalidate the right template.

Compare the division's recorded pool by archetype with its template's need. Cap each archetype's filled amount to that division's own need before summing, so another division's surplus cannot hide a shortfall. A pool comes from its daily read or, for a newly minted division, the new-division table. Where the daily read has no rows for a division, the pool may be known empty when the new-division read is complete. Hold and comparison are separate: a held design can still contribute to inventory when no definition classifies it, but the missing classification withholds the comparison. Unknown pools, requirements, and unresolved attribution remain identifiable in the outputs.

The age limit uses the tables' sample hours, so a daily read can expire on an hour with no changed rows. The stock total requires `StockByVariant` to be complete and a current complete `Stockpiles` read. Per-division hit points and equipment quantities use fixed5 units. Manpower contributor dwords wrap before becoming the recorded total. Unknown inputs can leave manpower, maximum hit points, or national stock unavailable independently of the other comparison measures.

Changes to a template, token, clone, design or pool invalidate the terms that depend on it. A design's archetype also controls the stock grouping, so definition changes reread stock rows. A fresh hour, resume, relevant whole-table update, identity change, or change of required input availability rebuilds terms from held inputs. Publish only changed output rows even after rebuilding. This keeps a small input change from creating a whole-country update or requiring a persistent writer blob.

# Preserve content registration and load order

The mod stack supplies content names at the point each reader would encounter them. Trigger classification handles conditional siblings, the trigger registry, a scope with a block value, content count names, and scripted trigger text in that order. Invalid keys produce a report and follow the reader's skip behavior. The current value slot persists when a key omits its operator. Country tags match their exact declared bytes. Aliases, character tokens and the relevant scripted names use ASCII folding. Country tag files register three-byte keys in file order and stop at the first closing brace or end of text. Values do not hide nested keys from that loop. Idea tags and static modifiers run before later content names are available, and equipment and building triggers run before the building roster is complete. Independent loads may run together, but failure selection and trace output retain serial order. A failed traced read is not cached as a complete roster.

Ideologies start a fresh lexer for each file. The first file to define a folded group owns it. Duplicate bodies are skipped, while a later block in the owning file can reread its group and reset any group the block omits. The positions of admitted groups start at one. An unread suffix can make group or frame lookup uncertain, with the exact scope depending on which answer could change. Subtypes retain their authored spelling but look up by folded token. Color components begin white and subsequent reads update the same value. Failed float scans retain the prior component before the RGB normalization pass. Alpha defaults to one and a fourth component replaces it directly. Short lists and unexpected scalar carriers follow native token consumption, even when that leaves subsequent fields to an enclosing reader.

Industrial organisation templates keep the first registered definition. Their include pass visits templates once in creation order and copies each source as it stands at that point. Nonempty local values override inherited values, explicit deletions suppress inheritance, and a copied initial trait is reparented to the child. A genuinely absent include is skipped, while an incomplete or refused source can leave the answer unknown. Trait text and current research categories can be inherited, but a trait's condition falls back only to the included trait's own body. Policy files load after templates and can also be read independently. Policy visibility determines whether it appears, availability whether it can be chosen. Both conditions default true and repeated blocks are joined. Equipment and production share a group map ordered by folded hash then folded bytes, with the first group value kept.

Operations, operation tokens and phases keep the first registered definition. Unread files can conceal an earlier definition. Readers project the presentation fields and follow the appropriate nested token walks for other fields. The map sprite falls back to the authored icon only when no map sprite is stored. Agency upgrade localisation uses the authored identifier. A repeated upgrade can be reconstructed in its branch while the global lookup keeps the first registration.

Leader traits append in file order after the null object, including duplicates. Name and token lookups take the first match. The folded text lookup keeps digit- and minus-prefixed names distinct even when the token registry rejects them. An unread suffix can change a first-match answer only if it comes before the known definition. An unknown earlier suffix also makes later ordinals uncertain. The parser keeps command modifiers under their own fixed-point fields and preserves the last successfully converted value for each field. A non-common AI strategy field can reach a per-type reader whose consumption and variable definitions are unverified. Refuse that trait and the remaining definitions in its file by name when this occurs.

Diagnostics preserve the producer's message and category. A logged or misread field allows native reading to continue. An unsettled suffix means reading can no longer establish its contents. Unsupported forms, refused definitions, ambiguous lookups and presentation fallbacks identify distinct failure or substitution states.

# Measure guarded acquisitions with owned synthetic worlds

The shared unit and event fixtures model a native layout in owned buffers. Allocate before rebasing pointers and keep the backing memory immutable while the guarded reader uses it. The callers of `World::live` run each guarded walk while the fixture still owns every pointee. Vtable witnesses resolve against the synthetic module base. Chosen populations expose repeated pointers, grouped reads and late faults without depending on a game installation or its content. Smaller tests can use just the fleet or event subset and leave optional fields unreadable without changing the base census. [Unit world](../../crates/engine/tests/native/support/unit_world.rs) · [Peace world](../../crates/engine/tests/native/support/peace_world.rs)

Event-scale fixtures isolate acquisition cost by reusing the small shapes of a result, post-dispatch state and destruction. A final result needs a fresh snapshot after dispatch: the measurement includes both the paired commander records and the later snapshot. A fixture's iteration count makes no claim about event frequency. Excluded peace bids are authenticated before their status is trusted, then omit their action-specific operands. Resident bids retain their full status and row accounting. [Peace settlement fixture](../../crates/engine/tests/native/peace_settlement.rs)

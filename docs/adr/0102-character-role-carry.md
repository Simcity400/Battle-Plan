# Carry character traits and operative links under their own witnesses

The Gated role job walks the admitted character census in roster order. A country-leader or advisor row can carry only when the character pointer, ID, freshly gathered role-map headers and pre-read observer certificate still match the last complete read. The observer covers the role maps, parent links and trait-array writers. Trait-definition tokens and ordinals come from immutable content. A load, gap, recovery, table replacement, poison, an unnamed receiver or an active writer can invalidate a certificate. Duplicate occupant pointers cannot establish one unique held row. An allocation refusal withholds reuse and lets the following walk read afresh.

The quiet fast path requires a complete held walk, a matching census generation and the character domain token recorded before the first registration. It appends ranges of country-leader and advisor rows in roster order, between the occupants with scientist or operative inputs. Scientist rows carry only when their separate token also matches. Lifetime and trait mutations advance that token. A new successful scientist walk refreshes the held rows, so the following quiet hour can carry the new results. The content identity changes whenever either set changes. A frame that already holds exactly that content can restore its outcome and arena length while independently projecting operatives. An incomplete role table retains no held result.

An operative link is tracked by census occurrence and reference. Both the unit leader domain and its trait domain must certify the same resolved object before reading its fields. Each domain observes constructors and destruction. An available read retains the row, its definition values and its text, and a matching certificate can carry them without another object read. An unavailable name or codename makes that observation ineligible for the next carry. Operative holds settle only after their own table completes. The game thread can invalidate both caches by marking them forgotten, while the worker clears them and records retained-byte accounting at finish.

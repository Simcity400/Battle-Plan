# 0403. Identify land events at the point where each operand settles

The common combat removal path handles normal rounds, explicit removal, invalid sides and forced border endings. It finalizes, detaches participants and publishes history before deleting combat state. Border effects run before the base finalizer. Manager destruction frees the registry and history independently. Use an observed finalization as evidence of completion. A registry or save reset establishes a new lifetime. The ordinary hourly combat update follows the date advance and uses the advanced hour, certified by the next hourly entry. A path before the advance would use the previous hour. The observed layout alone cannot establish whether that separate path occurs.

Capture the participant sets before retreat rebuilding can empty them. Actual commander verdict returns are observed in their native order before relevant scripts and participant removal. Calls from effect evaluation are outside the verdict. At finalizer exit, pending losses have flushed and combat sides still exist. The first-country projection for history uses this post-finalizer state. Reuse the authenticated dispatch header and its actual commanders when available. Fallback traversal authenticates only the division class and names an unsupported interval if another class would be required. The participant sets hold raw country references. Their size is bounded by the link table, including reserved link slots, while strings are read from each raw tag's own entry. A null history country selects the reserved tag string.

Destruction dispatch can repeat a victim handle before deletion completes. Preserve every invocation. Snapshot the victim pool and the country choice before leader effects can run and receive the selected killer at its later observation. Combat-side wipes follow a different lifetime path. They occur when retreat is impossible or strength falls below the content-loaded threshold. They log the remaining pool and distribute leader experience while the selected-killer operand remains unavailable. The wipe lifecycle starts after leader experience and authenticates the land combatant and primary division classes before acquisition. The opposing side's first raw country establishes attribution without reading later countries. For an empty side use the first raw link to the reserved zero slot, with zero as the no-match result. The later leader action can choose a different country for its own effects. Keep the triggering combat separately since removal has already taken it out of the victim's other references.

Use the private staging protocol to copy operands at these boundaries without allocation or game calls. Size storage away from the game thread using retained combat population and observed word demand. Later event volume can exceed the first estimate, and a combat-reference roster can grow independently of the country count.

Observe the commander resolver at the two verdict call sites in the native dispatch. Their validated operand identifies the resolver slot. Reuse one authenticated combat header, and group the side identities, unit vector and country-set headers in a guard before reading the separate verdict operands. Participant detachment matches combat pointers. For enemy attribution, equal country identities and aliases are friendly. A different endpoint requires an active war whose retired byte is clear. The regression on dispatch ownership refuses a second header read and still expects success from the owned event header.

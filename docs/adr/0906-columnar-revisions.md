# 0906. Gate format changes at the affected layout

Reader compatibility is proven from format 91. Private format 95 is retired because its divergent table contracts were never published. A format can receive several changes before publication. When a changed layout shares a provisional number, the decoder uses a discriminant where it can distinguish the layouts exactly. Incompatible lengths, table sets and widths are malformed. Exact compatibility rules live beside the table registry.

Format 123 made recordings append in place. The header names the last complete save and each save adds a trailer to its predecessor. Format 124 stores later grouped sections in dense 168-hour chunks. Format 138 made each columnar restart retain the most recent complete `Divisions`, `DivisionEquipmentDeletions` and `SunkShips` with its sample hour. Format 139 writes each table's hours once per block from the collector journal. Format 141 independently decompresses 2 MB raw units. The latter three revisions changed the columnar container and kept row schemas. Each admits its own columnar version. The storage-only alias packings in formats 113 and 114 also leave public rows unchanged.

Format 140 makes tables share facts already recorded at the same hour. Panel rows supply division maxima and base movement speed wherever they carry the same value. Land combat members use their divisions' rows and modifier rows use their matching combat-member row to find the division. The displayed supply ratio derives from its exact value. Removing the corresponding tombstones changes the affected table layouts. Older recordings with those layouts withhold the affected tables by name.

Format 121 records the capture mode in sessions and frames and omits tables outside that mode. Map mode needs the land model operands even though it omits `DivisionStatus`, so format 122 gives them their own table. Format 142 adds optional hover and selection operands. A reader sees those additions as unrecorded when an older layout lacks them.

Event feed format 106 uses separate numeric streams, the row's generation, sequence deltas and dates relative to the read hour. Format 109 adds owner-local refusal operations to that layout, with the reason carried as the token. Format 119 replaces the layout with per-occurrence operand deltas and a pack-local token dictionary. Format 102 first carries the event's native cause, its parent operation and its operands. It adds sources for ended wars, releases, state ownership changes and conferences. Older events lack cause. A format-102 `EventLoss` control record names an unobserved interval when a same-process reattach continues a branch. Older recordings cannot explain that first interval.

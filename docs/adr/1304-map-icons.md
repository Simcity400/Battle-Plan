# Map overlays keep recorded identity and independent presentation state

**Status:** Accepted

Province colour dispatches reuse the immutable province ID image and a device-level stripe pipeline. Record the dirty stripes without consuming them. They become clean only after the encoder containing their dispatch was submitted.

Radar station art, the range overlay, and an individual hovered range are independent. The range roster uses direct faction and subject relationships, while a station hover can use any recorded group. Missing relationship information does not revoke a proved own range. Anchors use the recorded content's host template. Choose the narrower ordinary or seam-shifted bounds, preferring the ordinary one on ties, and halve the integer extents. A recorded simulation orientation overrides presentation rotation. Otherwise retain an angle per pooled draw slot even as its group changes. Advance that angle by elapsed presentation time using a 30 Hz reference and a fractional fixed-point angular step. This keeps the sweep rate independent of display refresh. Alternating air-range slots rotate in opposite directions.

Resource icons use recorded origins and the content's window, row template, text and priorities. The resources mode and strict cutoffs admit icons first, then their rows and flags. All states qualify independently of the viewing country, intel and fog. An ordinary camera applies one height-based cutoff. A free eye tests each icon by distance to its own world anchor, and all of the icon's quads share that anchor. The anchor is the member centroid nearest the rounded, horizontally normalized mean, preserving authored order on ties. Preserve the integer wrapping distance and its negative sentinel, since widening the arithmetic changes anchor selection in the extreme case. Device viewport pixels and interface scale stay separate.

Rows follow resource database order and require a positive nominal amount. The icon uses each resource's authored strip frame. Round delivered and nominal units half away from zero for the localized row text, with colour indicating a deficit or surplus. If every resource right goes to the same foreign country, show its flag on the window and omit per-row copies. Otherwise show only each diverted row's holder, using canonical slots for flags. Refuse individual missing inputs by name and distinguish a refused state from one that has no icon. The prepared-hour product never changes a presented window. Pooled rows are hidden and retained when they fall out of the list so a later row can reuse them. Showing a control clears the hide bit before its show call. Hiding calls hide before setting the bit.

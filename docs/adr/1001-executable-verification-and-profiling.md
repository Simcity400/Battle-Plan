# 1001. Verify relocated executable identities and retain bounded diagnostic evidence

Associate located code with stable source names instead of line numbers that move when the source is edited. A function fingerprint preserves local branch displacements and masks operands that cross function boundaries. Structural filters narrow candidate positions before the complete fingerprint check. Exception continuations may be reachable through unwind metadata even when no ordinary branch reaches them. Never treat a jump table as ordinary instructions. Mask source line operands when they accompany an executable source path. When unwind data splits a function, keep the continuation tied to its original range.

Prefer the smallest unique constructor or destructor witness for each class layout. Use caller or vtable evidence when the location is ambiguous or has no unwind entry. Check a cross-function operand against its independently located target and its expected position within that target. Verify replacement bytes separately when a hook spans the containing function's end. A layout may be withheld without discarding the rest of the build. Keep the reference build first in the generator and record expected per-build refusals, so a new refusal does not silently become allowed.

The citation check catches short and long offset forms, tables of offsets, register operands and bare code-address forms. A visible source note is subject to stricter matching than an ordinary string literal, while assembly macro text needs operand checks. Recognize arithmetic, supported unit suffixes and keyboard notation separately to avoid reporting legitimate prose. Decode register operands once instead of reporting each value both as an offset and as part of its address expression. `git grep` reports a clean search with exit code 1.

The collector enters on a game thread that is already inside native frames. Keep any individual collector frame small and its deepest reachable stack use below a fixed share of the game's reservation. Account for documented Windows x64 unwind operations and chained records. Follow a tail jump only to a different function's entry and replace the caller frame after its epilogue. Leaf calls can lie outside every unwind range. Demangled public and debug names differ in the generic information available.

Profile readers accept the valid fixed-record prefix after an interrupted trailer and never treat trailer JSON as samples. Bound the unresolved symbol aggregation by module. Open installed module debug data using paths from the recording without a network symbol server. When deferred loading opens a PDB, verify its identity before accepting any name. Use fixed-width fields for the Windows debug ABI. Sum global counts in Python integers so the total cannot wrap. The weighted buckets are exact only in the precise range of their floating-point representation. Self-test scratch files are synthetic and live outside the worktree.

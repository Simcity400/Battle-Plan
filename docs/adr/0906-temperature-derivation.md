# 0906. Reproduce the temperature pass from committed neighbours

Playback derives signed fixed5 temperatures from the recording and its content stack. At each unsuspended hour, the manager advances its seed by a synchronized 31-bit value and visits a rotating window starting at the recorded cursor. The window visits at least one slot where possible, wraps at the count and stops once it returns to its start. A past-end cursor stays put, a negative cursor is refused, and the signed decrement case at the lowest integer preserves native wrapping. An active slot has a positive definition with map pixels. Only active neighbours contribute to smoothing, with source order and repetitions preserved.

Stage drift from the slot, native pass and seed using the same integer roll used for raw mud. Clamp the working drift and reset it when it pushes farther outside the period's bounds. Terrain adjusts both bounds. A null region or unmatched period skips the local temperature update. Smoothing can still act on the previously staged word and drift. Read neighbours from the preceding hour's committed words. Commit a slot only when it has an active neighbour, after all jobs have finished staging, so evaluation order and thread count cannot change the result.

Use recorded weather periods and settings, treating omitted settings as native zero. Refuse unavailable terrain only when a period needs the terrain lookup. A planned pass precomputes active slots, terrain shifts, region indexes, active neighbour slices and reciprocals. It reproduces the content path's first refusal in period, terrain and neighbour order. Integer arithmetic preserves wrapping, truncation, the division guard and its sentinel. The precomputed reciprocal gives the exact guarded quotient below a magnitude of 2^31, where the fixed5 scale cancels safely. Larger magnitudes use the guarded rule directly.

The witness is the wrapping sum of slot-specific hashes of each committed temperature. Changing one slot removes its previous term and adds the new one. Each slot's term uses a bijection of the word's bits. The collector and reader share it bitwise. Historical samples before the witness format cannot authenticate a derived temperature. A wrong witness, missing content or a pass that ends before the queried frame refuses the derivation.

Retain the last successful simulation as a possible starting point. Reuse it only at the same branch and anchor when the input seed prefix still agrees, and only up to the target hour. A suspended entry preserves state. An owner can keep per-hour derivations while their frames live and must trim them as those frames are released. A reset invalidates incremental changed-slot output. Tests compare an independent expected rollout, old and new inputs, order-independent threaded access, fast and guarded division and whole-recomputed versus incremental witnesses.

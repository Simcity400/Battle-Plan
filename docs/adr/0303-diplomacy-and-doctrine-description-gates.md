# 0303. Read diplomacy and doctrine inputs at their own gates

Diplomacy descriptions use their native order of carried-country checks, target selection, inventory access and localisation. An earlier native exit can finish without the later tables. A reached wargoal ownership predicate needs both complete tables. Definition ambiguity matters only if the rest of the covering predicate succeeds. An irrelevant duplicate type cannot invalidate an independently decisive inventory. Faction descriptions read a subject roster only when their removal or join branch needs it. A named outside-faction overlord can be available without that roster. Native null templates can give empty names, while a nonnull template requires its recorded token even if the formatted name is empty.

An autonomy ratio or score description needs its recorded feature gate. With a complete autonomy table, an absent record represents null status. Some lookups distinguish null before a target, while the set path resolves its target first. Both authored autonomy-state field spellings write one field, and an explicitly defined state takes precedence over the free-autonomy sentinel. A failed amount parse preserves the previous fixed-point value. The wrapper's native numeric argument remains numeric. Faction-rule descriptions rebuild the manifest from the recorded static catalogue independently of which rules are active, and faction naming resolves the new name before expanding its wrapper.

Locked doctrine descriptions follow the recorded stack's pointer rosters, retaining definition occurrences and repeated sources. Grand sources precede sub sources. Each base, milestone or reward stops at its first tactic match. A milestone uses its track position, so a shorter milestone array is a refusal. Reward thresholds include all prior amounts, with the stack's default used where authored mastery is zero. The available trigger runs in a fresh scope for the described country and does not read that country's doctrine progress. A local failure can withhold one fragment while the other sources remain. Numeric, modifier and effect details use the same formatters as other descriptions.

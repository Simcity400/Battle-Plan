# 0705. Separate division-template identity, counter inputs and optional presentation data

A census authenticates each template against its country roster and retains the full native reference, including dynamic type words. Its composition is contained storage. The original creator, roster owner, native composition country and foreign-template country are separate values. The composition country establishes the local-definition scope and model fallback. A parent reference survives independently of roster membership. Configuration excludes inactive optional payloads and keeps stored flags, signed country operands, role choices and the formation division count in their native representation. Fog uses the selected template's reveal-skip byte. The native icon settings include a separate flag for the NATO style.

The dictionary includes unused templates. It retains the engine's unit category without clamping it to the icon strip. Composition supplies the category override first and the preferred or fallback category subunit otherwise. Model selection takes the stored representative or falls back to the priority subunit. If priority is null, the first regiment grid cell is reached only under the native wrapped real-unit count. A token of zero is reserved for the null object. A real definition with that token is unsupported. The model filter is conditional on its presence flag and the explicit entity string is copied exactly.

The three grids distinguish regiments, support and regimental support. Packed dimensions preserve columns in the low word and rows in the high word. The grid cells appear in native column-major order. An empty pointer has no occupant, while an authenticated null-object definition occupies a cell with token zero. Each grid groups its occupied cells by token and local-clone flag in first-occurrence order. The stored grouped composition counts remain independent of this reconstructed grid view. Local clone membership is scoped by the country whose template named it.

Definition memoization lasts one walk and authenticates each successful pointer once. Database slots sort by pointer, and the local slots reset for each country. An unreadable identity component is tracked separately, so a counter can retain an authenticated token even when the clone flag or model input is unproved. Caller-owned storage sizes from observed demand and half-load bounds. Short scratch falls back to live definition reads, and a full memo may overcount demand without losing rows. A fully carried walk needs neither definition database preparation nor an extension read.

Capture authenticates identities before optional per-occurrence data reads and follows original country and roster order. A carried occurrence never reaches the omitted fields. Mutation of one template need not invalidate other templates. Fixed fields arrive in batches, preserve earlier refusals in source order and grow output from the acquired headers. Range workers own independent arenas whose spans are rebased on merge. A sizing pass uses already acquired icon sources and does not reach extension payloads, forbidden definitions or name text merely to reserve space.

The display name uses the exact authenticated wrapper's literal first and follows its fallback naming operands only where needed. The dictionary retains its fallback key independently of the selected display string. A bad name descriptor or partial copy publishes no name span. Priority subunits shared by several templates share a name-descriptor observation for the walk. Naming operands preserve the selected historical naming-group key and distinguish a null group.

Counter, model and extension operands have distinct refusal scopes. A failed counter field refuses the required table. A failed model field discards that row's model payload without discarding its counter or name. Failed or undemanded extensions leave the existing icon and model fields available. A row that cannot fit waits whole, including its name, with complete arena demand available for a later allocation.

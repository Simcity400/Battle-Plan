# 0403. Bind character carry to both the container and its member writers

The country character pool owns available and appointed advisors and active and retired character records. The manager owns advisor idea tokens and the character roster. A pool certificate covers its membership, while a member certificate covers identity and role fields. Available-advisor rows need both because they read the character's identity and the advisor's idea token. The advisor family forwards construction, destruction, idea and parsing writes to the affected character. The collector reads the country's character pool pointer every hour because a caller publishes it after construction.

Available advisors enter through advisor status updates or the add-advisor command. Status updates are reached from role addition, recruitment, load and civil war registration. Clearing can occur during status updates, retirement and civil war transfer. Role removal erases inline through the scope character's country, with no named pool, and revokes all pool certificates. Appointment and unappointment each use their own helper. The latter also handles retirement, civil war transfer, leader capture, deferred work, status changes and trait-based idea removal, and is forwarded by the stability and research family. Save loading, construction and destruction establish separate lifetimes.

Active and retired character rows use the member id and preserve the native order by name token. Save reading, retirement and civil war copying use the ordinary insertion path, while registration uses the sorted insert. Retirement uniquely erases active records and registration can erase retired ones. Recruitment, country-leader and scientist creation, civil-war transfer, the name index rebuild, and exile leader creation all pass through registration. The save reader fills a pool constructed in the same load. Roster identity repair can change the name token and id after publication. The advisor token set changes through the shared insert and erase helpers reached from status updates, save reading and role removal. The manager's load clear empties it. Other users of the shared intermediate helper include equipment graphics and are outside this certificate.

The historical and dynamic roster arrays append but preserve each existing member's roster and ordinal. The append helper alone changes elements and counts or reallocates. It covers creation and registration, start characters, loading, and historical inserts from civil war, peace, unit transfer and character generation. Clearing frees whole arrays and their roles during manager parsing and destruction. The manager is reconstructed at load or reset and its construction is forwarded by the advisor-pool family. Roster identity repair is the post-append id writer. Scientist trait addition, removal and token assignment cover the trait list. Attachment and removal update the scientist pointer, which the role census reads afresh every hour. Character parsing, merging and destruction remain in the advisor family.

The role census covers country assignment and the leader, advisor, scientist, operative and unit-leader fields. Country assignment also updates the unit leader. The role census owns country assignment, unit role creation and removal, the inline leader-map insertion and range removal, direct scientist pointer addition and the operative reference setter. Other writer families forward their own map insertions, parser, merge and destructor, and scientist attachment and clear. Construction before publication is covered by the roster's own observation. Shared tree helpers serve unrelated maps, so use caller boundaries and compare freshly gathered sampled slices where other aliases are unproved.

Country leader trait mutations append, compact, or swap and then rebuild modifiers on the same role. Both creators and the virtual name setter do the same. Shared or inline leader-map insertion publishes the role, and replacement, removal and destruction notify while the character link is valid. Advisor traits can be changed directly or upgraded. Their cache rebuild is the only refill of modifier entries and tooltip keys. The factory and name setter add the assigned role's own modifier block in the same call. The ideology setting effect selects the ruling party's first leader internally and revokes all character certificates, since it writes the role without a rebuild. Identity repair, name changes, parsing and merging can rewrite carried Characters fields. The scientist and operative rows are read each hour.

# Stage optional carrier suffixes independently of the base census

The existing AirBases worker owns a separate carrier log. It seeds that log with the original pre-vector census, using owned observations and charging no new native bytes. The seed rejects inconsistent repeated observations. Identical successful copies with matching bulk status may share one exact key, and a unique failed observation stays failed. Insufficient arena or index capacity refuses the optional seed, leaving the original census and its rows intact.

The exact-key index has prepared storage and a maximum load of one-half. Worker growth rehashes retained keys before the next request, and fixed callback capacity shortages are explicit refusals. During acquisition, only an absent optional request can reach live memory. Exact failures take priority over containing bulk successes. A bulk result uses the nearest enclosing start and the most recent matching span in a tie. Failed bulk spans provide no bytes. The reader requests the same bytes the owned decoder will have, without inheriting unproved authentication from the live source. Failures and overflow remain sticky for the current read while independent fields retain their own demands.

The worker prepares optional state-summary capacities and byte scratch before calculating the memo fingerprint. Source addresses are acquisition context and never enter recorded rows. The mandatory walk and nested pools preserve native iteration order. Sorting is limited to outer lookup keys. Pool wing ranges are relative to that pool's slice, even when output is appended to a shared arena. The decode worker borrows the result of one lookup for both the optional carrier packet and state-scalar projection and compares values before allocating changed rows.

The carrier job and optional decoded rows have separate retained capacities. Borrowed jobs grow from live demand and the worker refuses invalid observer lengths by name rather than admitting prefixes that have no complete observation. An admitted optional seed is separate from a readable partial packet. Only the worker maintains the memo. A change in fuel words read inside the original container span changes its byte fingerprint, even when the observer's own log and span geometry are unchanged. A subsequent capture with the same inputs can restore the updated optional packet. Allocation hints pre-size storage and leave the observing worker responsible for admission.

An empty registered pool still identifies its definition, owner and base and has known-zero observed passive sums. A missing pool has no observation. Optional carrier failures leave predecessor rows intact. The fixed gather regression checks each original field span and records repeated observations individually, including faults. A counted null in a pointer prefix refuses the typed walk before it gathers fields from that prefix.

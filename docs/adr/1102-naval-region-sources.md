# 1102. Use regional observation and content when binding the naval region view

A sea click opens the authored region panel read-only for the observed country and hour. It withholds controls whose sources are unestablished. Access values represent allowed, avoid and blocked respectively. Highlight the authored button for the current recorded value by copying its position. Access hovers use the localized level heading and following description, and the flag hover can keep an authored title when the native callback declines an immediate title.

The observed country gets exact ship and convoy counts, with separately salted enemy estimates based on civilian intel. Sharing vision or disabling fog supplies full intel. Preserve the enemy roster's stored order and repeats. Count a mission-registered task force's ships for each registration. A convoy client counts for each qualifying route through the region, including imports, its own origins, naval supply transfers, received lend-lease and bought market contracts. A route left without a kind may retain an earlier regional footprint the recording cannot reconstruct, so it yields a named refusal when relevant. Mines use the content's regional maximum and the same guarded fixed-point division. Report fixed-point shares as whole percentages.

Derive the dominance bar from the observed and enemy totals, using the region's minimum supremacy when there are no enemies. Terrain text uses the recorded regional category or the ocean fallback. List terrain, minimum dominance, registered ship classes in database order and the common all-ships block in order. Add the common values to each custom class with wrapping fixed-point sum. The game's format adds a newline for a nonempty accumulator even if it displays none of its entries. Collect inline icons from the localized terrain descriptions.

Use mean province night and any engaged combat to select the region's terrain picture variants. Night switches only above the half threshold. The regional modifier grid follows the matching naval combat display's terrain and weather order, using whole-region inputs. An incomplete combat table can leave the ongoing-combat prefix undecided.

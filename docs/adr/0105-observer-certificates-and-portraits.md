# 0105. Reuse only observations covered by their writer certificates

Mission-registration notifications mark the authenticated country air object for the duration of the original writer call, including calls on strategic-air workers. The whole-domain revision can retain all already observed receivers when no writer ran; per-object sequences retain only the object they name. An active writer, unavailable registration, or changed epoch prevents reuse. Withheld sites leave this family uninstalled and the mission walk reads each country afresh. Radar range reads run in the existing coverage worker on newly demanded or writer-changed groups, using the group and host that the coverage census already authenticated.

The province order observer has a single consumer for the dirty set. It reads only changed provinces and carries the rest of the complete prior walk. An unreadable or zero province identity changes the epoch instead of marking a guessed province, and the consumer then reads every province. Without the family the consumer takes a fresh walk. A load, gap, or recovery invalidates the observation epoch for both registries before the next capture. The first sizing offer can install immediately, while later growth waits for an invalidating hour. A worker releases replaced storage and the loader releases the family only after installed calls have drained. Shared publication defers the entire family if a thread is still executing one of its sites.

Portrait writers can run outside the command batch. The collector registers only authenticated reader addresses, and a watch slot is never reassigned during its attachment. Failure to register selects a fresh read. The general revision protects a walk's fresh reads of unwatched holders, and the watched revision and sequence certify only holders already registered. A writer that raced that registration is still active when the reader validates it, which prevents a false certificate.

Portrait capture defines its own snapshot instant. Before reading, it closes admission and waits within a bound for existing holder writers. A writer active on the capture thread or beyond the wait, or a reader still holding a pre-image from an earlier capture, withholds that capture's pre-images: every portrait read that needs one is refused by name, rows whose certificates still hold are reused, and a withheld capture logs nothing and keeps the earlier capture's records. Once reading starts, the first writer to change each holder publishes the original array into reserved storage, and every reader uses that image. An unreadable image remains a refusal. A writer whose image cannot fit waits for capture to end, and nested writers avoid waiting on a begin that is itself waiting on their outer writer. Writers arriving during the closing state wait to learn which side of the boundary they belong to. Writer callbacks only read the holder they observe and leave ordinary mutation to the original call.

Pre-image slots have one writer before publication and remain immutable until all readers return: every pre-image a reader borrows is counted until it is released, and only a capture that begins with no count rewrites slots. Record, array entry, and text reservations are independent, and an unsuccessful log still contributes demand. The store replaces its storage only with no counted reader and no logging writer, skipping growth rather than waiting, so capture end never blocks on a reader. Capture end reopens the state, wakes waiters, and can grow the store between captures. The Windows wait and wake calls operate on the store's aligned atomic state, with a bounded wait to guard a missed wake. The capture guard ends the snapshot even on unwind, so callbacks may take the pre-image path independently of quiet revision reuse.

# 0304. Resolve names from recorded identities and the matching content stack

Faction naming uses one implementation in dashboard products and scripted text. A nonempty stored name wins, and a known null template returns empty without a content or lexer lookup. A bound scalar can be text or a localization key, with undefined keys copied by the localizer. The native lexer token is looked up by id, independently of the literal's shape. Bound arguments are expanded in authored order using an explicit work stack. The reverse lexer index is needed only by bound token arguments, so consumers share it while they hold the same decoded dictionary. Versioned holders retain changed literal or deletion records rather than copying each dictionary. A repeated complete read still establishes a version. A folded name's highest token determines its result when several rows share the name. The cache estimates the allocation of the map, string and lookup capacities it retains, including the reverse lookup it may build lazily.

Flag candidate construction takes appearance and ruling group from the resolved country object. An alias uses that object's atlas cell, including when the complete alias roster is absent. The candidate chain can use a known cosmetic flag before a later tag refusal. Recorded positive original references contribute their own spelling, while zero and negative references select the object's own tag. When that original operand is missing, a name tag cannot stand in for it. A recorded active ideology group can have an empty token and still contributes the qualified candidate's underscore. A missing ruling-party join is reported if the candidate chain reaches it.

Character names and template identity use the lexical spelling of the recorded script token id. The saved display name is a distinct input. A dynamic country's idea name may use its named override, selected content key, cosmetic or original tag, and independent civil-war predicate. An empty override continues the ladder. The generated advisor path checks cosmetic names first, then the original-or-own set, then the default. It seeds the male name and surname draw with the idea position, canonical country slot and level. If there is no idea definition, a recognized advisor can supply its character name and an unrecognized token becomes its own text.

Civil-war naming recognizes either a live target named by the country's own list or an existing enemy that lists it. The existence check uses positive owned state count. The recorded enemy vector supplies its stored order. An ongoing relation can supply the same order where that vector is unavailable. Indexing the hour once for all countries preserves which unresolved input the native scan would reach before a match. A failure after the first accepted candidate does not invalidate it.

Party names use their recorded override when present. Otherwise they probe the party's own tag, its original tag, and the ideology token in that order. The original tag is an independent lookup after the own tag misses. A defined but empty original spelling remains a real prefix. Unread identity operands produce a named refusal when reached. Display preserves literal bytes and does not run script expansion on the party's presentation name.

Naval battle naming uses recorded victory points and the mod-stack map's candidate order. States are reached by their first province occurrence in the strategic region. Each state contributes its whole province list, including provinces outside that region. Repeated and invalid map province ids are removed from the list. The last state to list a province owns the backlink, but both states can retain the candidate in their own lists. The first equal scoring candidate wins, and the province replaces the region name only once its score reaches the content's cutoff. Distance uses signed wrapping horizontal deltas and the game's fixed-point root, with the maximally ranked sentinel for a zero distance or unrepresentable product.

Occupation law chooses the state's override, an occupier law for the occupied country, an eligible occupier default, or the database fallback. An absent group inventory returns the unvalidated database fallback. Eligibility evaluates visible and available triggers with the occupier and occupied country in their prescribed ROOT and FROM scopes. If they are the same country, the availability step is skipped.

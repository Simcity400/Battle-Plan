# Share two canvases for following log row entries

The browser restyles elements with active animations each drawn frame even when only a few new rows arrive. Fast playback can leave dozens of entries in their 700 ms fade simultaneously. A following row log shares two canvases. The underlay flashes behind row content and the overlay covers each row with its resolved flat background at the inverse easing alpha. Over a uniform opaque backdrop this reproduces the CSS fade's composition without animating or writing each row's style. Resolve translucent ancestor colours on a pixel to use their composite when the backdrop is a flat colour. [Log entry layer](../../ui/src/charts/log/entryLayer.ts)

Use the same easing curve as the normal entry. Share canvas transforms and grow their height in steps to avoid reallocating for every revealed row. Bound the drawn stretch to 4,096 layout pixels; rows beyond it appear without that fade. Keep only mounted entries still within the animation interval. The paint regression isolates entry animation from placement motion so a transform applied to every row cannot hide behind entry timing.

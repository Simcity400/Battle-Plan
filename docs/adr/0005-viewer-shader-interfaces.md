# 0005. Match shader inputs and output measurements to the renderer

WebGPU requires block-aligned compressed texture extents at the top level. The texture unpack pass stages padded BC data and crops the hardware-decoded image to each authored mip's logical extent. The political fill pass uses integer coordinates and row-major buckets so the ordered distance search can stop early. Its control and contested channels accumulate as bytes. The map-mode fill factor adjusts the color band below the outline range while preserving the outlines. With viewer post effects off, the scene is copied and the output format clamps its HDR values.

The snow and mud hatch marks unobserved cells in a separate overlay and leaves the recorded snow and mud textures available to the game's shaders. It uses the terrain pass's blocks, edge snapping and capped coastal heights to match the drawn surface. Only its clip-space depth is biased toward the camera. Ground and water are tested against the underlying heightmap so capped terrain remains correctly classified. The pattern is anchored to map coordinates and doubles its spacing in world units as the view zooms out, keeping it legible.

The hatch uniform packs the camera direction and depth bias into `look`, map-pixel dimensions followed by cell-grid dimensions into `map`, and the ground/water selector, water height, height-byte scale and cell size into `surface`. The heightmap counts rows from the top and the cell mask counts from the bottom. The terrain stream packs a signed 16-bit own height and snapped height into each word. The hatch moves edge vertices onto the same coarser-grid vertex as terrain, then reads the destination's own height. The map wraps horizontally and ends vertically, where excess terrain quads collapse to the edge.

Screen comparison records the size and bounds of pixel changes and the tiles that contain a change of at least two steps in 8-bit color. This distinguishes one-step flicker and scene-wide effects from localized movement. The tile counts follow the eleven aggregate values in the storage buffer, which the Rust readback decodes in the same order.

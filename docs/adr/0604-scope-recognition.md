# Resolve scope operands in the native recognition order

Recognize a nonzero decimal state prefix before `var:`, a three-byte country tag or alias, another character name, a scope keyword or zero-valued number, an exact `event_target:`, a keyword prefix, and a dotted scope chain. Stop on the first match. Quoted keys participate in text-based recognition and bypass the token-kind keyword step. After an event-target or a scope head, number-token classification is suppressed on the remainder. `scope:` accepts the faction form. Prefix recognition uses the shared keyword registry when available, or the caller's known prefixes. Unmatched text stays unknown and an unresolved reference kind remains distinct from a missing reference. A zero accepted-scope mask accepts every scope. Otherwise any tested carried scope bit can satisfy the mask. The state and country facts require positive IDs, and combat and strategic region require a set reference. Callers must refuse scope facts they cannot determine before applying that test.

Scoped variable parsing retains operands for a later evaluation on recorded data. Content readers begin with no character scope. Exact initial prefixes precede numeric syntax and the cuts at the first default, index and target markers. Dotted scope links are interpreted left to right. `this` and `id` can preserve a position without moving scope. `global_event_target:` searches the game-state store only. `event_target:` and the implicit dotted prefix search the current scope and then the game state. The implicit event-target portion takes the current part's length from the start of the original text. A misplaced part records invalid syntax while retaining the fields already read. Operand target normalization keeps native country and scope targets as `.id`, retains numeric or explicit variable/token targets, and assigns `token:` to an ordinary word. The two admitted positive integer forms resolve identically at evaluation, so parsing needs no map-specific bound. Recursion has a backstop because parsing, evaluation and destruction all traverse the nested chain.

Country tag aliases reserve names in a separate pass and keep the first case-folded token. Duplicate bodies skip without adding definitions to the file table. Their score fields append modifiers into one mean-time object and participate only with at least one modifier. Without an original tag, target member or variable, every country slot is a candidate. Unsettled or unrepresentable alias bodies stay named gaps. An original-tag specifier may carry state through repeated assignments and unsupported target members are retained for named refusal.

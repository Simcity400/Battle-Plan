# 0906. Keep owned wars, unused goals and their operands independent

The owned war roster keeps diplomacy vector order and includes retired occurrences. Goal handles retain native order and preserve unresolved entries. Perspective-dependent inputs use the recorded playing or observer country, including the cached subject predicate. Only an acquisition flag equal to one makes the representative's division, factory and subject inputs available. The game-provided default name prefix is recorded as a value. Directional participation ledgers use the owning relation's endpoint order, while each ledger retains its own endpoints. Captured-province first credit is separate from scalar scores, so adding a province does not rewrite the roster. Delivery history includes nonzero values for countries connected to the recorded war rosters, even outside the currently displayed side. The display gate runs at playback. Complete certified absence proves zero within the captured owners' domain.

The serialized country war-goal roster includes goals already attached to wars and keeps expired entries. Only the separate unused-goal roster establishes unused availability. Preserve native occurrence order for goal states, liberation countries, puppet countries, unused goal handles and selected justification states. The containing goal's ordinal identifies every kind other than the unused handles, which use zero. Country and state targets use their low 32 bits and unused goal keys retain full 64-bit handles. Use the recorded content for target terms and duration rules. Declaring a war requires its own action eligibility evidence.

A recorded justification end date takes precedence. Otherwise the displayed completion divides fixed-point remaining cost by the daily rate with half-away-from-zero rounding. This is a display projection with no inference about the next payment. Preserve the raw goal expiry even when the save serializer suppresses the value in the initial year.

# 0805. Require whole coverage and current evidence for land and map checks

Division identity may be serialized more than once at the same nesting depth. Keep the first full reference and authenticate every repeat. Side-loss comparison uses the same hour’s counters for live combats, because the ended-history serializer omits those side pools. Match equipment loss entries using the saved pool’s zero-entry rule. The manpower writer emits only positive amounts and uses raw-indexed strings, which a canonical country link cannot reconstruct for aliases. Division grace belongs to the status oracle.

History drains use intervals open at the start and closed at the end. A command after the read at an interval’s starting hour can still carry that hour’s timestamp. Both adjacent drains must cover an hour for the reverse check to treat it as complete. The pruning pass uses the already advanced clock and keeps entries at the inclusive lower retention boundary. A gap may explain a saved occurrence the recording did not witness. It cannot explain a recorded occurrence missing from the save.

The map input oracle joins a positive original-tag reference to the exact raw string, including an actual empty string. Nonpositive references certify the writer’s omission. For rulers, use the first saved leader of the ruling party. A missing unconditional politics block is a refusal and a null leader character is recorded as missing. Variant selection keeps the first largest signed amount in each ordinary ordered pool. A hidden zero can outrank every visible negative amount or make a saved empty list nonempty at runtime, so the oracle declines an exact selection in that case. Current variant tuples use the save’s fresh registry instead of a carried daily row. Upgrade bytes are summed with the writer’s signed wrapping semantics. Raw launch-base bits can be tested without a country-link join. Compare the reserved launch census and its ordered alias occurrences independently of ordinary country-link failures. A known null list is comparable to an omitted or empty saved list.

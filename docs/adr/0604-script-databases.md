# Preserve script load order and definition ownership

Archive paths use their original bytes for lookup, with lossy display text separate. Direct folder scans merge effective filenames in byte order and honour layer replacements. A scan of database files treats folder and extension case as native lookup does without letting folder casing change effective file order. Where the native reader opens a file itself, retain the native reader semantics rather than reconstructing them from a balanced tree. Debug output for a textual path remains stable for existing digests, while nontextual paths escape the original bytes.

Static modifiers use nonrecursive direct files and a fresh lexer and variable table for each file. Definitions are pushed to the front of their hash buckets and lookup is the last exact-name definition. Absence binds the empty null accumulator. Bare and quoted keys dispatch by modifier token, repeated keys overwrite a zeroed destination, and an unconvertible value stores zero. Description reads include hidden values and omit the accumulator of an added child. A rename can change the effective hash lookup, so reads refuse both names while that case is unsupported. A refused file suffix shadows every earlier candidate until a later complete matching definition. Scalar and accumulator views share the same precedence and refusal.

Static modifier loading precedes sub-unit modifier registration. The relation trigger takes a conjunction with the content rosters visible at that load point. A reader report retains its path, source line and diagnostic alongside values that still have a defined interpretation.

Resources append every declaration in load order, including duplicate tokens. Icon frames are one-based and unavailable without a positive whole number. The recording's resource token and ordinal select the frame, so mod resources need no shipped list. A file stop keeps prior complete declarations and leaves the order of all later declarations unknown. The resource reader hands `modifier` fields to the shared dispatch in the original context. Balance ranges similarly retain authored order with template ranges before side ranges. A repeated balance reinitializes its template; duplicate authored range IDs are ambiguous without the recorded active pointer. Scientist traits keep the first folded token and retain a name independently of failures in the modifier projection. Strategic locations retain the buildings whose maximum levels they can change so consumers can refuse those exact buildings when the effective placement is unavailable.

Script constants load before content consumers. Categories require `schema` first and merge by folded token, while duplicate keys replace whole values. Names corresponding to the rejected token share one key. Leaves retain their schema type and arrays retain their scalar domain: project complexity requests an integer, and scoped variable operands accept integer and fixed5 only. Scope arrays retain their own domain for collection consumers. A failed scalar scan stores integer zero where the reader does, with null and zero IDs allowed by the corresponding schema. A reader stop could replace any prior entry but a later complete declaration settles its own entry. When a block both defines a variable and contains keyless entries, refuse where the correct consumption cannot be established.

Scripted triggers and effects separate name admission from body loading. The name pass scans direct files, registers by folded token and skips values without defining any variables. The recursive body pass binds existing names only. A mismatch continues at the value and can expose that block's children as following fields. The last trigger body replaces, while effect bodies append. After a trigger gap, a later complete body can settle its own template. An unread effect suffix could append to any existing template. Scripted trigger selection tests the body against the consumed boolean and does not substitute parameters. Tooltip bindings are retained separately from predicate children for descriptions. Scripted keys preserve raw C-string text and choose the first null or true trigger. A refused trigger cannot fall through to a fallback key.

Scripted map modes preserve definition positions through replacement. Layer targets and colour effects retain their authored form and an absent target applies to all scopes. A delegated native layer ignores other authored layer fields. Descriptions report unsupported entries by file, field and count in first-seen order. Special-project profiles use lexer-token identities. A repeated project reuses its template, updating scalar fields while keeping omitted ones. Repeated specializations are skipped. Use the first registered token spelling for presentation and preserve the registration array's order, including rehash order based on occupied physical slots. The native load threshold divides by the bucket mask. Output effects and lists append. A block's limit applies to all listed unlocks regardless of its position. Complexity consumes signed integer tokens or integer-only constants, with the caller-supplied default and normalized ranges.

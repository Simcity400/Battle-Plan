# 0805. Join governance state by the identities its writers save

The oracle uses the owner’s saved tag index for party keys and the owner’s canonical slot for a decision’s positive target. The two can differ. Parties with default names omit their stored name keys. The recorded lexical dictionary supplies the earliest registered spelling for serialized idea and technology names, since an authored definition does not establish interning order. Timed ideas preserve roster order and their stored days. Random-item comparison includes inactive items. Election operands covered by newer recordings are compared when their recorded witness is available.

Focus pause serialization depends on the pause byte alone. Countries with focus progress and no selected focus are therefore still compared. Doctrine statuses are indexed by canonical slot and tactic unlocks retain vector order. Every recorded census country has a row, including countries with an empty unlock vector. A status outside the recorded census can be absent from the recording only if it contains no unlock. Packed mastery references preserve both the ID and type words.

Technology rows are owner-sliced. The command requires a proven full refresh because a rowless owner also needs current coverage. Older unscoped callers retain the earlier row-based check. Research slots have independent freshness and active-slot coverage also requires a current slot table. The oracle reports an unreadable table as a comparison failure and a readable older slice as carried. The save omits native slot indices, so the comparison uses complete saved entries with multiplicity, including any omitted operands. When active instances cannot be identified, known positive progress, level, and bonus occurrences must still form an ordered subsequence. Where sharing groups lack a cross-side identity, compare the complete member and bonus pairs across groups.

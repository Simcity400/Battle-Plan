# Keep map presentation relative to the recorded viewer inputs

Country appearance keys use raw country-link identity. Preserve map and UI color floats as raw component bits. Map colors already include the political HSV modifiers, so convert by truncating each scaled component. UI color remains the input to the subject-color chain. Keep ordered subject links, the runtime 2D and 3D culture names, the generator's dynamic name tag and the separately read original-tag reference. A positive original reference can name a known empty string and differs from a nonpositive reference selecting the country's own tag. Stored previous name, adjective and definite name belong to one recorded-language read. When they are known empty, display uses the corresponding current text. A size refusal or unreadable operand preserves the row's other facts.

Keep portrait census independent of the currently selected country, camera and render client. Full character portraits and orders-group HQ portraits have different coverage. A non-HQ leader's absent row does not prove an empty portrait. At each portrait size, the lower-bound selection prefers the requested category and falls back to the first entry of that size. The caller tries only the selected entry. Preserve its exact stored strings, the original-country reference when positive and the leader's character link.

Army and naval counters use full handles and fields acquired under their own certificates. Do not conflate formation flags, raw CanAdd gates, alternate template references or null holders. The ship composition comparator uses same-hour selected-variant operands, resolved against the recorded definition inventory even when a generated definition has a non-unique token. Do not substitute a daily variant record. The naval model's power operands include the class-dependent carrier size. Preserve independent refit, critical-damage and selection results. Old format absence remains `NotRecorded`.

Carry embedded task-force mission and repair state including the stored supply ratio and detached activity. A task force sent to repair can retain a running-away state that the save omits. Raw searcher and target references preserve failed resolution independently of known dangling references and generic roster owner. In an ordered ship-type test, a failed read before the first decisive match withholds that arm; a later failure cannot invalidate a decision already made. Task-force name, supply footer and port mission fields can each fail without invalidating the others. Preserve exact retained name bytes with their recording-language guard, and represent supply-origin refusal separately from the scalar amounts.

Railway guns use full unit handles, raw owners and authenticated locations, with native zero for an unlocated unit. The first combat's role and province, the stored combat counts, and the any-combat attacking test are independent. The current ordinary route's first leg can supply exact sampled progress and speed. Fresh-route operands require the same acquisition hour, and a transfer skips the land domains. The gun's genuine orders group identity differs from its assigned railway group. Authenticate its own theatre reference with the roster owner. Fleet mission-region membership is a sorted multiset with repeated regions preserved under a shared immutable payload. Province occupant order comes from the complete census, including empty lists.

Store local-player and observer references separately from the human player roster. A local tag switch rebuilds flags before the next sample. An observer-view change without a rebuild waits for the subsequent combat-manager update. A complete `LocalPlayer` row is required to distinguish these view choices without guessing. Land model picker order retains the full division and gun handles and excludes task forces. Unrecognized entries withhold that vector. Simulation feature masks, debug bytes and both weather suspension inputs can change hourly and preserve independent availability. The live movement defines are stored using their native scalar widths and independent read outcomes. Country visibility scales foreign units relative to the viewing country; the state-visibility term is read for the owner of an occupied state.

Keep hourly template counters and models independent of the daily template dictionary. The selected composition representative can differ from the priority subunit, and a null representative draws no model. The composition country supplies the clone scope and fallback; the model filter, explicit entity and excluded variants retain their own stored meanings. Failed model acquisition clears only the model leaves and leaves count, counter inputs and country operands available. Display names can refer to the same frame's dictionary. Preserve independently witnessed composition layouts and settings, and keep movement's priority subunit keys in native order with repeats. Sparse province-name overrides preserve source bytes so a localization key remains a key. On a complete table, no row means no override.

Naval port prohibitions test the viewer against the base's ordered raw country list. A nonpositive count is empty; a positive count with null storage is unknown. When present, the actual tag strings are independent. Battle-sound rows have no persistent ordinal identity. Visit the spatial tree in preorder and its local arrays in order. An object can retain its sound through regrouping, and a merge can keep the recording client's instance alive. Keep the acquired coordinate and radius bit patterns and native member order with repeats. Floating-harbor lookup uses the first matching deployment in native order and tests the observed status byte. Record the facility flag from the client state. Radar groups use the current vector position, which can change after swap-removal. Preserve covered provinces in native order and separate range certification from host-state presence.

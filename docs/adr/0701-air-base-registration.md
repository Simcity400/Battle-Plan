# 0701. Preserve indexed registration and independent carrier observations

The three state-indexed base roots admit empty slots. The stateless host vector does not. Resolve full native references without manufacturing generations or locations. Preserve native base kind and signed capacity. Incoming wing vectors can reorder through swap removal. A pool's assigned base can precede successful registration, so displayed membership comes from the country's indexed container rather than the wing roster's base reference. Occupancy and building-level consumers use the other recorded tables.

The indexed vector has the full country-slot extent, and a readable null slot proves no access. The dense list is a different view. Creation publishes both views, removal clears the slot and every dense occurrence, and loading rebuilds both. Treat the dense list as the completeness witness, including when it is empty, and consult only its named slots. A short plan is usable only after authenticating every listed container and confirming its unique in-range canonical slot and matching indexed pointer. Refused or oversized plans fall back to the whole scan without limiting output. An unlinked reference can occupy the reserved slot when a readable link lookup proves it unlinked. A failed lookup stays a fault.

Group slot words, pool headers and wing identities in bounded chunks, then consume each slot, pool and wing in native order. A later unread span must not obscure an earlier failure or its accumulated demand. Decode only fully copied fields in the current prefix and never use old scratch tails. Require the container's positive capacity word, a valid pool and wing identity, and a full wing reference. Keep full demand and omit whole rows when fixed output fills. The original row flattens wings in pool order. A per-walk country cache may reuse successful resolutions only within that observation. Short or absent cache storage takes the same resolution path without caching.

A state base can reuse complete prior output if the caller certifies its subtree unchanged and the current plan, country links and destination arenas all agree. Rebase wing ranges into the current arena. An unsuccessful reuse attempt changes only transient resolver or plan scratch and runs the ordinary walk. The carrier observer never visits state-indexed bases. A separate state summary retains dense order, repeated entries and zero-capacity containers after authenticating full references against indexed membership.

Carrier inputs are collected at the original registration reader's authentication points. Preserve the accepted current AirBases order for the host-name join. A name must come from a validated matching row in this pass, never a carried or sorted copy. A null or known-stale host reference is known empty, while resolution and text-cache failures keep separate refusal reasons. Off-hour sizing uses a fresh resolver, retains no payload, and never substitutes for current acquisition. Optional reads use the observer's independent memory, which contains only owned data on the decoder path.

Acquire the signed fuel demand and allocation words from the same container span as the country link and capacity, even when no pool or active wing exists. Keep those scalars if membership fails. Each accepted pool reuses the original authenticated copied header and collects only its missing inputs. Capture its signed grouping key and the positive content database index of the exact authenticated subtype. Tokens can collide, and a country-local clone copies its index. Authenticate a null definition against the registered null singleton. Addresses used to query fuel remain transient. Retain empty pools, repeated occurrences and registration-relative wing ranges.

Feed each authenticated original wing occurrence to the fuel accumulator once. Admitted transport can reuse its plane-count attempt, independently of fuel, with the native signed wrapping sum. Refused transport admission keeps the original fuel path and adds no plane-count reads. Use the full validated member header for checked sizing, including enough storage for the ace and forecast keys. Only completion of the original wing loop admits a pool, and early returns finalize all optional membership as incomplete. A complete base's indexed certificates also authenticate dense country order. If certificate scratch is short, measure the dense header demand without visiting uncertified entries. Accept a validated name independently of dense census completeness.

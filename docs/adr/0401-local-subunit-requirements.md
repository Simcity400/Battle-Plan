# 0401. Record country-local requirement differences and the sources of bonuses

Country-local subunits clone global definitions when a country unlocks them. A complete requirements table records only clones whose ordered archetype and amount pairs differ from the global definition. An absent clone in a complete table therefore uses the global requirements, while missing or truncated data cannot establish equality. The capture reads clone pointers and fixed fields in batches, then compares the two vectors in spans. It preserves signed fixed-point amounts, counts required capacity even on overflow and refuses repeated country and token keys. A certified unchanged country can carry previous rows. A confirmed carry checks the authenticated deployment status and clone header first, then reads the country normally if they disagree.

The persistent bonus list preserves append order. Unit effects, doctrine rewards and milestones, and special-project rewards append entries and removing a source erases its entries. The game rebuilds its clones from this list. The recording keeps each source's kind, id token, signed number and label and the payload's exact and category targets, preserving this target order. A doctrine number can identify a reward ordinal or a milestone track. Each target owns a bonus definition. Its dense stats and width are added and its battalion grants are merged. An exact target uses the definition's token and a category target uses the category's token. Dense stats preserve selector order and sparse grants preserve repeated selectors, zero amounts and add/display flags. The definition's other fields are outside the rebuild. Effective requirements come from the local requirements table separately.

Bonus reads authenticate the deployment status, each entry, payload, and owned definition. A failed authentication withholds the list because a partial list is indistinguishable from a shorter one. Capacity omits whole entries while tracking their demand, so future captures can grow outside the game thread. Between successful list reads there is no carry certificate.

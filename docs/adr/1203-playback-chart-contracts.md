## Nuclear stockpiles and player activity

The eAPM table follows a columnar head derived from the command index. The client column indexes for its rows and campaign clock match the dashboard product. Floats arrive as bits and the country tag is packed with the first byte lowest. The table structure depends on the ordered row ids and their tags. Numeric changes paint the existing cells. The sort operand doubles thousandths of the eAPM rate and adds one for a gap, preserving the gap marker through table paint. Bind the graph to the clock while playing and show a trailing window clipped to the branch at pauses and seeks. A country label uses the earlier of the series' last hour and the displayed head hour. This prevents a label from showing its campaign-end tag while the graph plays an earlier period. Number duplicate player names only to distinguish separate players. A canonical country can have several tags over time because the activity log names tags. Head queries omit explicit hours and let the service take the trailing window. Use the request path for pinned views and groups with unrecorded membership so the service can refuse unobserved windows.

## Spending and production

The political-power spending and production-spending charts keep their structural state in React and paint amounts on the clock. A change from missing data to an empty view or a drawable chart needs a render. While a drawable chart stays visible, changing amounts and status words can be read from live data without remounting slices.

Production line keys belong to a branch and producing country. A native handle can be reused, so a history lookup uses the appearance covering the displayed hour. Settings name the country at the branch end. A line label can fall back from game name to equipment type or line id, and an organization can fall back to its script key. Line-factor breakdowns keep exact negative corrections as rows while stacking only positive values. A drill fetches factor breakdown over the covering window, replacing it only when moving to another window. A selected breakdown hour is pinned. The production table paints current data before a newly mounted or moved row appears. Its shared factory scale must cover both the number assigned and the number requested. History lanes take their thickness from assigned factories and distinguish active lines from ended lines at the selected hour.

The viewer mirrors the game's efficiency and weekly production arithmetic. Efficiency rounds Q15 raw values by adding `0x4000` and shifting 15. Weekly output is truncated fixed5 speed times `700000`, divided by positive cost. Preserve finer recorded decimals for an output that would otherwise round to zero. A missed tick means units made are unknown, and an incomplete factor total remains unknown. Count production inputs by purposes that consume output and include refits only where the purpose is counted. A rocket design records output. Military and naval factory charts both retain an unresolved design domain because excluding one would imply knowledge the read did not provide. No amount carries past its run or across a holder or observation break. Sum only where each amount is confirmed and carry the reason for unknown values.

Dockyards build only on production lines, so their whole comes from the line totals. An older recording can have valid derived totals without stamped read hours. The total for a chosen factory kind does, because an unclassified cost could belong to that kind. For an unknown endpoint, retain an earlier maximum as the stable ordering and color key without showing it as the total. Use exact decimal arithmetic for applied IC, including values beyond JavaScript's safe integer range. Join equal adjacent runs only within one observation. Fetch covering date windows and the window ahead, rather than a single campaign-wide reply, and keep the head's moving hour out of the React render state.

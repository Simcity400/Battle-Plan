# 0402. Keep intelligence membership and independent payloads distinct

The intelligence readers use authenticated country roots and keep raw references even when aliases are resolved for validation. Collaboration requires reciprocal incoming and outgoing membership. A complete collaboration walk also rejects dangling incoming links and duplicate resolved targets. Network membership comes from native vectors and can change by swap removal. The reader rejects duplicate targets by canonical country slot and preserves a null operative slot as absence. A missing or unreadable slot is a failed read. The operative manager may be absent when its DLC is disabled.

Each graph vertex is checked against the state ID in the row it indexes. The graph's signed selector can leave a state without a selected subnetwork while the row retains its own strength and daily gain. A local quiet byte and a subnetwork's own quiet byte are separate operands. A selector outside the local list reads as unquiet. Selected subnetwork terms retain strength, gain factor and target independently, together with the operative and counterintelligence contributions. The state row retains its signed gains from both operatives and adjacencies. Auxiliary occurrences reuse known state operands and record only independent values, keyed by kind, subnetwork and ordinal. Wider reference words retain their original bit pattern.

Signed national coverage counts, worth, strength sums and cached maximum are separate saved operands. Capture collects those summaries once per actual network, including a network with no vertices. The worker holds authenticated summary payloads between writes, and a failed refresh revokes stale values without withholding good state rows. A membership failure publishes no new values and leaves independently proved payload certificates alone. Worker pointers and ordinals used to establish acquisition identity stay out of the recording.

Independent source pools start from native headers with their caller supplying the authenticated country and dirty source. A bounded copy window limits one read without setting a cap on the pool. Preserve ordered duplicate keys, signed keys and retained zero entries. Positional omissions inside a known extent are exact zeros. A keyed setter updates an existing entry to zero but only inserts a new entry if it has a nonzero lane. Pending additions admit positive lanes and use native wrapping arithmetic. The daily pass clears pending data, decays retained values with truncation toward zero, and removes sources in reverse ordinal order by swapping the last entry into the removed slot. Those observed operations allow the worker to advance a carried result without rereading the entire pool.

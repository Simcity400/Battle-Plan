# 0901. Publish cursor windows without blocking the frame

Cursor slots keep their addresses while resident. A full refresh invalidates every slot, and a scope switch can reuse a departed slot for another address. Consumers of the change list must check the current owner again on a scope switch. Vacant slots have no value. The worker reserves the committed point's single coverage run and prepares the next window's slot scope before births can enter the current one. Scope switches clamp to the available pages in the requested window and place their cut inside both those pages and the current scope.

The source resolves corrections within one published log and branch before exposing rows. A restore sizes its selection to live addresses at the cut and addresses named by the scope. When a requested page splits an hour, restoring before that page includes earlier splits of the same hour. The decoder applies the dictionary-to-cursor slot map once. Local slots are bounded separately from the arbitrary-width varints used for identities, and a typed, validated key handle travels with the restored source.

Only workers traverse the page directory, perform I/O, and decompress pages. The directory accounts for decoded columns and indexes as an upper bound for admission. Measured window bytes report the actual charge. The frame decodes only the requested span of a resident page into reserved columns. Workspace preparation reserves coverage capacity from the served span's coalesced coverage run count and change capacity for the nominal frame span (including pending restored rates), replacing any smaller unclaimed workspace before publishing a new span or scope handoff. Failed staging leaves the last committed state intact.

Admission drops played pages before adding pages ahead. A fill and reclamation share their lock because the fill's working tree may still hold the page a reclaim would remove. An incomplete final hour split cannot extend the advertised served interval. A trim can publish while a reader still pins the old snapshot. Retry admission using the budget itself because the shared ledger can only approximate which bytes that trim released. Use the observed release for the counter. If the retained snapshot blocks a further publication, stop retrying. Reclaim still needs enough metadata space to publish its smaller tree.

Readers pin before loading. The publisher retires the old snapshot and destroys it only after all readers unpin. The frame makes one attempt to claim an error-mailbox cell. A successful claim owns the cell until release.

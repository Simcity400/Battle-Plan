# 0304. Reproduce effect-description traversal and scope selection

Effect descriptions use the parsed effect children and their own-description hooks. A branch attaches to the last child that contributed an effect, even when intervening fields have lexical positions. The embedded conditional trigger can take another `limit` only while it has no children. The multiple-effect probe evaluates each own description and then its children. Rendered text and newline counts cannot substitute for that probe, since the probe performs its own evaluation. Random selectors can be multiple on their own, and an empty tooltip override still uses the base child projection. Scripted-template boolean operands control execution and leave description traversal intact.

The random-effect percent rounds to a signed 32-bit integer before fixed-point division by 100. Random-list members are created before evaluation, and weight modifiers apply in authored order. Each member starts from the same two random words, the final member leaves its draws even at zero weight, and execution-only explicit seeds do not affect text. A scope loop starts from a default-constructed selector, populates its selected object, then copies the caller's ROOT and FROM with PREV pointing to the caller. A conditional selector that consumes a flag instead of an integer leaves the displayed value zero. Native `%i` scans keep the previous value on an unsuccessful repeat, while scoped fixed-point integer conversions truncate toward zero.

An iterator's parsed effect class selects its roster and header, since distinct classes can share the same script name. Displayed scopes and representatives are separate. The caller supplies the group header unless the effect builds a fresh scope, such as the combined country/state localization environment. The perspective gate starts from ROOT's country or state owner and consults THIS only if ROOT has neither. A raid or unit scope can supply children without a header. Multiplicity probes preserve their leaf refusals once and can advance random state. A probe does not count as a second occurrence. Priority state selection preserves roster order and retries the full roster only if the priority pass has no eligible result. Sub-ideology selection needs a top-level `has_ideology` and exactly one passing value, without drawing randomness.

Users can compare rosters against recorded order. State, ownership, party, and diplomatic walks use their own captured sequences. Army leaders precede navy leaders, and operatives have a separate iterator. Global leaders repeat the caller's roster for each applicable country. An old operative membership row can establish an empty or singleton selection without settling order for a multi-target evaluation, which also depends on limit writes and randomness. Active war matrix membership settles enemy selection without a date filter. Subject selection reads the subject count before alias-aware self exclusion, keeping repeated surviving occurrences. Provincial unit lists require their captured divisions census even when no division is present, since a full handle alone is insufficient to prove a division and other unit classes are skipped. Original-tag buckets filter invalid signed words before resolution and preserve duplicate positive candidates. Scientist selection evaluates each limit before checking membership. Character descriptions use directly recorded assignments for army and navy command sizes. An advisor role outside the current display section can affect the role walk, and a hired role must belong to the described character to count for that section.

State and province descriptions preserve evaluation order. Building selectors retain independent plain and scoped inputs. A plain selector can fall back to the current state, while a scoped selector uses its selected result. An authored type can bypass building selector evaluation. A type selected from blocks uses the last applicable provincial template. Build effects evaluate levels before naming, but an existing state building resolves the location before the level. Instant construction defaults to enabled. Existing inactive or level-zero building rows still establish membership. Receivers precede state lookup for resource rights. Temporary-resource descriptions evaluate the amount before resolving the state and omit duration evaluation for a missing state. Resource icon frames use the database id. On a direct construction path, endpoints can settle the result without reading intermediate provinces. A null resource or building is admitted only when the complete recorded/content lookup proves the element absent.

Occupation and province effects separate own operands from children. An invalid state can yield a localized line with an empty STATE, while an effect that requires a current state can produce empty text. Occupation category lookup rejects the database's null object. Generic occupation selector flags leave its description scope and literal-zero operand unchanged. Resistance target descriptions default the amount to minus one, reject ambiguous repeated flag-bearing fields, and read days and both countries only after a nonzero amount. Fixed-point formatting keeps the zero sign and neutral color. Victory-point text uses the state owner's original-or-own tag, with raw recorded renames as fallback after an empty display result and only once the sparse table's coverage proves it. An add description defers amount evaluation until it has a usable name.

An own-description refusal cannot hide independently readable children. Reaching a core input gap produces the recorded world's reason, while an optional direct frame input names its table. Native parse flags, lookup order, and presence determine whether a candidate contributes empty output or a named refusal. Tests cover the attached branches, parse defaults, replay RNG lanes, roster order and gaps.

Meta-effect interpolation consumes literal parameters in first-exact-match order. A missing parameter stays semantically distinct from an empty value in the meta reader. Country-tag resolution can demand original-tag data before an intelligence effect rejects a non-owning target. Numeric effects keep the selected read path's units and wrapper format. Fixed-point progress appends a percent without multiplying by 100, and an execution-time ratio flag takes precedence over amount when present. Numeric duration uses the start of the current day, while priority and cost remain execution-only inputs. An effect whose native path constructs intermediate text and then clears it still yields empty text.

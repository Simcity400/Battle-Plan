# 0903. Prove fixed modifier identities at the affected reading

Fixed modifier indices and lexer tokens are meaningful only under the verified executable definitions. The collector withholds dependent family tables when their identities cannot be authenticated. Playback checks complete ModifierDefinitions and LexicalTokens in the recording against the expected names in the same order, keeping the first relevant unavailable reason. Dynamic modifier identities are resolved through the recorded registry.

A guard whose failure applies to a suffix must keep the independent prefix. This includes fresh task-force ETA beside recorded motion, railway-gun ETA beside its raw counter row, selected-attack weather, night and fort operands, and the preparation and transport operands of airborne orders. Air map raw rows remain useful on an unproved modifier layout. The former speed graph, attrition breakdown and selected-transport preview tables no longer own active layout families; keys shared with current products remain validated under their active consumer families.

The registry joins a definition to the recorded lexical name and preserves the lexer case fold. An absent modifier entry is already known zero. A present entry uses its definition and the recorded DLC flags. A zero selector is eligible without a feature callback, and a nonzero selector with a null callback is ineligible. A missing mask for a reached gated definition leaves it unknown. An eligible value uses the stored amount, clamped to the fixed5 unit interval where the definition enables the clamp. The same eligibility applies to the emptiness test.

Derived power-balance description trees follow the recorded static-source roster. Rebuild after list changes preserves roster order. Adding a source appends the same child a rebuild would produce. A source with a custom tooltip or nested modifier is nonempty even without a qualifying value. Otherwise it needs an eligible stored entry. Each nonempty occurrence becomes a leaf, including repeats in the recorded roster, using the locally named effective value. The formatter does not display the root's value when it has children. An empty source roster produces a bare zero root. Witness comparison checks the displayed leaf names, order and values.

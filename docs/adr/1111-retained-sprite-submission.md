# Preserve sprite pixels across retained uploads and fades

Free-camera icons scale about their anchors. Fade an icon as a group by drawing its quads in their original order and with their original programs and bindings into a premultiplied page cell. Draw the cell in the icon's slot in the original order. This changes opacity once for the combined image, so overlapping parts fade together. Draws with their own projection use a clip-space affine after the projection, composed into the draw's column-major matrix without changing later constants. Round placed scissor bounds outward and intersect them with the target.

Separate cells by a filtering gap. Pack from left to right and top to bottom. A cell the size of a page occupies it on its own. Page extents track their cells, quantized to limit churn. Keep each side that still fits and is within twice the needed size. The largest clipped cell is bounded by the device's frame limit. Keep the composite program per device, format, and sample count so changing views does not rebuild it.

Retained GUI uploads keep a pass-owned arena because the next scene frame can overwrite its own uploads. A matching window key and stamp certifies its quads. Loose quads compare individually, and equality includes drawn order and exact float bits. That preserves negative zero and distinguishes NaN payloads. Transform-only window moves can rewrite ranges in place after confirming the remaining contents, owners, and order are unchanged. Any other mismatch rebuilds from current inputs. A matching frame writes no bytes and leaves the pass-owned arena alone.

Hold an allocation while using its pointer as a packet key. Re-resolve texture views for every draw so a texture becoming resident, disappearing, or being bound to null takes effect. Report each reached declared failure. An absent technique leaves the prior native state with no additional diagnostic. Submit bake commands before sampling baked data. The GUI composes over the single-sample output after the multisampled map has been presented.

The optional overlay check compares the bytes and runs the GPU will actually read against a whole rebuild, naming each affected window and range. Quad comparison alone cannot detect a wrong transform write. Tests use direct content-program draws and analytic pixel bounds that avoid the production projection and bake helpers. They also exercise null bindings, texture and scale changes, alpha composition, and frames that reuse the previous upload.

# Evaluate authored triggers in recorded scopes

Raids, tactics, scripted localisation and authored map rules use one evaluator against one recorded hour. Dispatch follows the content reader's trigger registry for coded and scripted triggers, named scopes and count triggers. Coded triggers check the accepted scope class before reading operands. Products load the shared recorded tables alongside their own tables so a product's local selection cannot discard a valid operand. Use a narrower core table selection when a trigger's operands prove the map is unnecessary. Report absent or unsupported inputs by name. A proved false decides conjunction and a proved true decides disjunction despite another child being unknown. `NOT` is NOR. A refusal already reached still belongs to the reply's accounting even when another result settles the truth value.

Fresh scopes set `THIS` and `ROOT` to the selected object and carry no previous or source object unless the caller supplies them. A combat scope links its own side through all scope links. A default scope for a pool limit points its links to the same empty scope. A scoped target with a clearing setter drops the caller's carried members, while `THIS` retains them and `ROOT`, `FROM` and `PREV` copy their own links. Only reading an unproven link produces a refusal. A raid uses the raiding country and the target's scope and variables. An active ability may keep a country and a leader together after a retaining setter, with each getter using its own priority. Leaders and units use full references, organisations and raids retain their reference type, and projects require both pool owner and local ID. Named organisation lookup chooses the least native roster ordinal. Named project lookup matches its recorded definition and refuses an ambiguous match. A saved target can omit member kinds the native store does not support. Describe that absence or refusal by its source and kind.

Country aliases recompute from the hour because the caller and temporary effects can change. A candidate uses its own `THIS` with the caller's previous scope and links, and target filters see the initiator with the candidate as `FROM`. Final scoring reverses those scopes. Follow the physical country order for all-country checks. Otherwise visit the original's own country and its recorded bucket first. An unscored alias stops at its first passing candidate and can defer unknown later candidates. A scored alias uses the highest positive score, keeping the first occurrence on a tie. A variable or event-target alias reads in the caller's scope and decides alone. The fallback is reached only when no candidate won. A repeated name, caller and effect state proves unbounded recursion, so the evaluator refuses by name. Return the country the alias selected directly.

State selectors use the recorded array and state specifiers. A state already accepted is skipped before its filter can repeat temporary writes, while a rejected state can be visited again. Country and state selectors preserve the native initiator and target ordering and the distinct selector tails. A dynamic country tail currently refuses by name because the recorded selector cannot supply the country boundary. A known missing organisation-store key supplies the game's zero. Missing storage or an unreproduced built-in remains unknown. Integer operands truncate at whole units, including fractional and negative values, and strict ordering and equality follow the lexer comparison. Reuse only while the recorded organisation and the size field it read still confirm.

Class checks evaluate only the carried kinds named by the mask, and mask zero accepts immediately. A combined country and leader can satisfy a character mask even when the country link is unknown. A compatible character or country getter then follows its own native priority. Character `tag` examines the current direct leader or recorded operative role before the character's own country. Entering a unit leader scope supplies its character, whose current role can change independently of the original handle. A positive resolved word can select canonical slot zero as an existing country. A raw zero setter constructs the empty carrier. Country specifiers read scope selectors, authored tags and scoped variables in native order. They handle null, original-tag replacement, and the distinct string termination for spelled tags and variable fallbacks. Character and country target lookups that prove a null or empty carrier return the native invalid result. A missing input remains a named refusal. State ownership selectors read `THIS`'s state only. Predicates can explicitly select the combat country from the combat scope.

Count triggers dispatch using the recorded lexical key and content classification before comparing a scalar. The building count sums levels including damage. A known building class reads only its own state or province table, while an ambiguous class needs both. Country and state counts use their own recorded pools and key shapes. A state count reads the recorded controller's overrides and requires `CountryLinks` to attribute those rows. Ideology support uses the selected group's popularity divided by the sum of every party. Scripted trigger assignment compares the body with its boolean operand. A block is admitted with the native default false operand and diagnostic, with no parameter substitution. A scope mask that proves the body cannot run rejects it before any unsupported content there is read.

Project only immediate links from the caller-owned event graph and retain its cursor for deeper links. Copies preserve members and their own target storage. Walking a dotted selector restores the original previous scope at its boundary. Non-link selectors use the shared resolver. Description targets look up local tooltip storage, then local saved targets and then global tooltip storage. They save one arm by native priority and retain distinct rules for local, global and description-only target storage. A saved project has no target arm. The context and text readers leave the caller unchanged for the unsupported saved target kinds they encounter. Description cleanup clears only the terminal source storage and global tooltip targets, even when no world data was needed. Nested descriptions share a single temporary-variable context seeded by the outer caller.

Select one saved target arm according to its reader's native priority. Variable storage keeps the character arm. The context, text and country readers each retain the target kinds they can carry. With no setter for the selected kind, preserve the caller's existing object.

The war relation has an end only when the end hour is greater than its start. An ongoing test with a recorded end uses a strict earlier-than comparison. When a row carries an end that is no later than its start, the row has the native null date and stays ongoing instead of comparing against a hard-coded sentinel.

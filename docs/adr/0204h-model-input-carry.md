# 0204h. Carry model inputs only while their native owner is certified

The host owns dispatch, loans and table assembly. The model inputs record country-local sub-unit clones whose requirements differ from their global definition. The captured country clone data is considered hourly. The equipment rosters and the unit-bonus panel's persistent entries are read whole on their daily slot, with separate owner and nested arena demand. Repeated roster entries are retained. A bonus range outside the acquired arena withholds that table. Growth reads the actual changed header, even if the country population and last sizing poll are unchanged.

The hook family watches the registered deployment statuses for changes to clone membership and requirements. A shared definition change revokes the whole domain. An in-flight writer, refused registration, disabled observation or a load, gap or recovery prevents reuse under the old certificate. A repeated ensure operation for a token already cloned holds certification closed while it runs, but moves the status sequence only when the clone count changes. The host offers capacity off the game thread and the next boundary installs it. Replaced watch storage is freed off the game thread.

An unchanged domain token lets a country carry its previous rows with no deployment-status read. Otherwise the country, status, clone header and that status's certificate all need to match. Holding a new walk requires it to complete and keeps only the token taken before it, which must still agree at completion. An incomplete or unheld walk reads afresh. Held countries are stored in census order, so matching uses a cursor instead of a per-country search. A new clone header is visible even if a writer was missed during the quiet phase once the next observed writer forces the selective checks.

`local_subunit_changes::Hooks::new` follows the build gate and leaves the family uninstalled when its site sentinel differs. Its owner must restore the patches and quiesce native calls before releasing code. `Hooks::drop` can release the watch tables only when the hooks were never enabled or have been restored and drained after the last capture.

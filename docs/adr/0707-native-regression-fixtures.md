# 0707. Test native observations with independent failure fixtures

The war-membership comparison keeps its original scalar occurrence reader independent of the indexed helper. Test recording adapters own their observations and preserve field boundaries. An authenticated roster view alone cannot supply a raw alias outside the normal roster. That alias needs its own original mapping observation, and payload reads must keep their original source. The opposing endpoint may use a different raw reference to the same canonical country, so changing a raw reference or a valid capacity word must invalidate reuse. Candidate testing retains retired counterparts and requires the exact old count and capacity distinction. [War fixtures](../../crates/engine-native/src/cwar_relation/tests.rs)

The overview page-crossing fixture adds a qualifying occurrence under an unchanged header, shifting the output enough for its flush to overlap a previous page of the same owner. Separate previous and current row storage keeps the next page intact. The certified-carry fixture corrupts a relation that a certified hour must not reread, then revokes certification and expects that corruption to refuse the live walk. Large synthetic censuses and aliases cover native demand beyond previous chosen budgets. The overlapping census fixture places later pointer fields in unused cells to keep the test compact without changing identity or traversal. [Overview fixtures](../../crates/engine-native/src/cwar_relation/overview_tests.rs) · [War fixtures](../../crates/engine-native/src/cwar_relation/tests.rs)

Weather boundary fixtures record the read order as well as the returned row. They open with real dimensions, a token and queue count. Interior updates can repeat their cells, so a count larger than the plane does not imply a full update. A whole-grid update reaches the boundary. A torn queue header must refuse before reading past the observed storage. The attrition fixtures distinguish one 32-bit route ID from a widened load and show that a failed gathered head cannot be retried. [Weather fixtures](../../crates/engine-native/src/cweather_manager/display_grid.rs) · [Attrition fixtures](../../crates/engine-native-land/src/division_panel_operands.rs)

Score fixtures place independent failures within multiple native batches, comparing each known scalar result, the wrapping navy sum and the cost in guarded rounds. A persistent fault fixture does not establish behavior on a transient guard. The fixture's loaded multipliers are nonzero so reading untouched synthetic bytes cannot pass. The live-copy comparison uses a historical-scale site roster and measures per-hour wall time. [Score fixtures](../../crates/engine-native-air/src/game_score_inputs/tests.rs)

Invasion fixtures distinguish a leader's own and parent primary order, a target selected through the reserved slot, and active volunteers-theatre ownership. The same-hour country observations let the route test omit live diplomacy bytes. Only the relevant raw target's sign and canonical equivalence can enable the relation term. The reserved result can serve even when both positive census headers are unreadable. Reinforcement fixtures compare inactive and active winners at equal weights and require each fixed-point product to truncate before addition or division. A late enemy fault must not overwrite another division's admitted arena prefix. The expected source order includes the skipped enemies and is checked in sparse synthetic storage that only supplies explicitly written fields. [Invasion fixtures](../../crates/engine-native-land/src/invasion_preparations/tests.rs) · [Reinforcement fixtures](../../crates/engine-native-land/src/land_reinforcement_inputs/tests.rs) · [Speed fixtures](../../crates/engine-native-land/src/land_reinforcement_inputs/speed/tests.rs)

The fixture for cached modifier definitions uses a default gap before a dynamic key and checks each row's view of the shared eligibility callback state. Unsupported callbacks, an out-of-dictionary token and a changing table refuse acquisition. Failed lookups do not seed a later cache. Tree fixtures exercise cycling parent and right links even when the child used to reach them is a valid node. [Modifier fixtures](../../crates/engine-native-parts/src/modifier_definition/tests.rs) · [Tree fixtures](../../crates/engine-native-memory/src/msvc_tree_node/tests.rs)

Operative fixtures deliberately omit recruitment reads and identity payloads a selected variant must not consume. The shared target getter witness is synthesized without allocating its whole address span. Its unreadable definition table fails a deferred name lookup when the root-out-resistance branch first needs it. Compare independent active and pending missions, null and invalid state or ideology groups, exact heap-terminator failures and resistance context selection. Nationality cases use aliases, missing canonical country links and the null tag. [Operative fixtures](../../crates/engine-native-intelligence/src/operative_missions/tests.rs)

Order execution accepts a verified plan placement and otherwise reconstructs the same native census results, including refusal order. The fixture permutes, duplicates, shortens and omits placements. These tests also cover retaining the reused vectors at unchanged capacity and retaining independent group demand when the unit census fails. [Order fixtures](../../crates/engine-native-land/src/order_execution/tests.rs)

The large-roster and definition-growth cases preserve the native-demand regression coverage. Modifier carry also checks that a faction-held read keeps its subject contribution and original writer certificate.

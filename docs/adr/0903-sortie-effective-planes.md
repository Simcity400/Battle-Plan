# 0903. Calculate scenario aircraft counts from hourly sortie operands

The flying map scenarios calculate effective aircraft from the current recorded wing and environment. The stored simulation efficiency and count refresh in the previous hourly update under the simulation's period, capacity and host-combat gates, so an earlier stored number cannot supply this display. Multiply using the low 64 bits and truncate each fixed5 division toward zero before applying the next factor. An hourly console override replaces the entire law unclamped. The fuel penalty is authored, and the modifier's active DLC gate and clamp come from the recorded definition. Use the mission country's base capacity and supply and the effective country's fuel container. The country-region term is demanded only for missions with a region.

A state rocket base uses its launcher level, or the content launcher-slot define, with the same lower bound used by the loader. A positive rocket product with a remainder rounds up, including the native wrapping multiply-back before the final division and narrowing. A negative product truncates toward zero. An exact multiple avoids the multiply-back. A gun always supplies one aircraft and can skip the efficiency read. An ordinary base rounds to the nearest count with halves away from zero, then applies the carrier stance ratio with truncation. Narrow the result as a signed low-32-bit value.

A stateless base's host task force in combat admits only the qualifying mission bits in its current region. The transfer or pool record must supply whatever host and region operands that path demands. A complete container table with no row represents a null or all-zero container. A row acquired without the effective country's fuel operand cannot supply it. The regional hover can skip a zero-plane contribution, while an individual wing's efficiency still evaluates its actual operands. Unavailable operands withhold only the reached calculation and name the missing dependency.

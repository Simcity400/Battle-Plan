# 1102. Keep state view bindings tied to the hour and authored controls

A ground click binds the native state panel read-only. A control whose recorded input or native presentation cannot be established is withheld by name. Withhold each affected state or province group together when its required rows are absent. Discover controls by their own name regardless of mod nesting. Seed authored text through recorded localisation, and gate the scorched-earth control on the corresponding recorded feature.

The clicked province supplies victory points and terrain. Zero victory points hide both their text and background. Show its name and controller's flag, with the occupation colour when a different country controls the province. Bind visible state modifiers with their scope's flag. The first authored custom icon container determines custom icon order and naming. Fill the authored weather positions with weather icons, present static modifier icons and the impassable icon. If the game would find no weather record, keep the preceding province picture and hide the weather icons unless a dynamic modifier still owns the display. List the state's strategic locations anchored to the clicked province before the province's own locations.

Build the temperature name from its range's static modifier followed by recorded modifiers in their list order. Separate each entry only once the preceding text is nonempty, and keep empty names reached after that point. Add the peacetime note only for positive eligible attrition. Custom province hovers carry the modifier name, remaining days if timed, and its own values. Region weather sums flagged and custom values in the native order. Snow uses the effective level with permanent snow and the authored cap. Distinguish a genuinely absent record, which builds no hover, from an unavailable recorded source, which withholds a named hover. Mud and snow can be replaced by authored tooltips, while the state title hover stays authored outside game debug display. Factory energy has a no-intel hover without full visibility. With visibility it still needs a recorded breakdown distinct from the displayed total.

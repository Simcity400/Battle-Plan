# Separate faction structure from its live values

Faction details bind a recorded decimal id, with zero reserved for the faction system's own pool. Read faction-owned rows by their faction and ordinal range. A held panel sends changed structure, including goals, pooled resources, manpower occurrences, research sharing and doctrine folders. Projection, goal progress, resource amounts, manpower and the research scientist base are live cells. Goal progress is stored in thousandths of a percent and uses the goal's ordinal as its live row key. A goal appearing in several lists is defined once. Refuse a list whose status or contiguous ordinals are missing. An engine empty resource slot contributes nothing. Keep each manpower occurrence, including repeats of the same country. Raw country zero has its own reserved name, and an unresolved reference stays unnamed and reported.

Cache faction artwork against its catalogue, which makes repeated draws and default-icon lookup cheaper than resolving them per reply. Draw the faction template's sprite or the content default when there is no template. A goal icon comes from its group. Goal names, descriptions, term labels and progress bands come from recorded content, with goal term names keyed by uppercase native token. Scripted names expand in the chosen country's scope, or the recording client's player or observer when the view has no selection. Build that context once for an hour. Read the scripted-name operand tables only when a displayed goal or doctrine requires them. Without content, keep the recorded token and say what could not be resolved.

Goal completion descriptions are a separate tooltip product. The `complete_effect` may query any scope, so the operand tables must be read whole. Resolve the faction leader at the requested hour from the member at ordinal zero, using its canonical country slot for the description. Missing leaders and definitions are named refusals. An absent authored completion effect supplies no prose.

Read history at the cost of changes to recorded rows. Join adjacent equal selections only within continuous coverage, starting a segment after an unread interval, history break or restarted recording run. Name each selection at the first hour of its run. Shared programs use their active project at that hour. Upgrade identity is the account, holder and group, and the account contributes only while explicitly a member. Minimum upgrades have one lane per group. Keep separate manpower lanes for repeated occurrences of a country, resolving its slot at each occurrence's start. The per-run lexical dictionary only grows, so its last hour can supply spellings. Cache a naming frame per hour and whether it needs scripted or program operands.

# 1105. Present counters from one hour's immutable preparation

## Decision

Keep camera-independent data per branch, hour, viewing country and required family. Reuse the immutable worker allocations for the camera's layout. A replacement frame with equal values cannot authorize a borrow of another preparation's row positions. Compare actual allocation identity. A refinement keeps its immutable recorded base and gets a distinct preparation identity. Rebuild only the marker products whose decisions depend on engagement history, using the same captured inputs and family order. Resource acquisition and window state stay in the presented view. Mutable access to a uniquely held base is for fixtures.

Separate native resources and windows from a memo of ordered semantic plans.

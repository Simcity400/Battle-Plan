# 1203. Attribute territory to its native holder and supplying observation

Territory breakdown shows country, faction and strategic-region rows from a followed panel. Its structure renders only when rows change. Read country labels at identity changes. Match a selected slot to the tag its holder used at the displayed date. Missing membership, an incomplete roster or multiple memberships prevents confident faction assignment. Use membership span boundaries as render and paint changes. Amounts are live cells. A state can be an exact fraction of the whole state, and unknown cells remain unknown. Land without a holder is an unassigned category. Fill animates against the end snapshot. An absent end row means a known zero only where absence was established. The occupied-territory race stays separate from a world share, which would treat occupied land as a portion of a world-wide denominator.

Territory transfers use campaign-and-branch conference identities. Keep each occurrence even when the same state changed hands twice. An endpoint's native holder is attributed from the read that named it, never by assuming the currently displayed tag still names the same country. A legacy tag-only endpoint stays separate from a known native holder. An older release item may name multiple possible former owners without a transfer graph. Name the giver only if there is one and use a same-settlement witness to resolve that giver's identity. Read the state's victory points at its separately recorded hour and let Live expose them only after that read. A side with a missing state's points has an unknown total. Keep a confirmed finalizer item ahead of a duplicate ownership comparison. A demand that names a potential puppet is not proof it released one.

Filter transfers at each endpoint's supplied date and show outcomes only once their supplying observations are reached. An ownership comparison dates the outcome by its later read and keeps the earlier unchanged bound. Show the full bound in the tooltip. Keep the branch's unknown hours and missing hourly settlement, ownership and war inputs. Intervals between daily conference roster reads are expected cadence. A completed scope uses the conference's observed interval. An active scope can follow playback. An explicit saved conference stays selected even if it is missing in the current recording, where the missing choice is named. Automatic scope uses the newest reached conference. Scope ids are escaped for lossless stored choices.

A held view opens a drill at the shown moment. Follow can inherit the clock. New pins bind the native holder, campaign and branch. Continue to honor older link-based pins and name absent links. The transfer table keeps its own sort. Earlier saved flow-diagram settings remain stored and unused. Request labels only for mounted rows or the open tooltip.

# Select equipment artwork with recorded context and authored precedence

The graphics readers take resolved content and complete simulation operands. Missing replay rows stay unavailable, distinct from an absent optional country, archetype or filter. The variant owner supplies ideology group and graphical culture, while the separately supplied country selects the country, faction and continent buckets. Preserve faction member order and the first province in the authored capital-state vector with a valid continent. A nonzero original capital takes precedence over the current capital even if it is negative. A nonpositive country reference gets default pools; an unresolved positive reference fails the join. Transport artwork's prefix ladder uses the original country of a dynamic country. Missing appearance rows and invalid text cannot prove there are no higher-priority prefixes or filters.

Identify the authored buckets from validated country tags, faction spellings and registered continents. Equipment pool keys fold ASCII, while model and entity names retain exact spelling. A real empty equipment key can match a declaration; the null equipment object is distinct. Visit equipment and then its family, within each visiting country, faction, continent and default, then type and archetype lists in reverse. Visit again when a key coincides. Weight sorting is stable and descending, with zero selecting the general weight. Authored graphic insertion follows equal scores, while legacy insertion precedes equals. An existing entity keeps its score. Scan model lists last to first and deduplicate before testing whether an asset exists. For an aircraft override, return the first authored candidate directly, with a refused declaration still counting as present. Production icons visit only icon pools without sub-unit filters and use the first existing sprite or texture in the native order. Neither path tries pools that have no artwork of its requested kind.

Pool admission uses a fresh empty event scope. On recorded paths the caller evaluates the actual predicate, while content-only lookup admits decidable scope-free forms including DLC. Built-ins must be bare tokens; unsupported predicates stay named, with file, bucket, ordinal and authored child path. A rejected higher-priority pool could change the result, so unknown predicates refuse the relevant lookup rather than disappearing. Fixed-point scans retain the prior weight on failure. Model and icon lists read raw lexer tokens only after an opening brace, while class filters consume value-list tokens. These differences preserve continuation and variable resolution.

The aircraft catalogue recognizes aircraft from references, which can come from graphics pools in any bucket, the airborne prefix ladder, recorded designs and related registered clones. Plane eligibility uses effective classifier categories. Gather clones of referenced entities and their parents without bringing in siblings merely because they share a parent. Handle clone cycles and retain refused declarations and unregistered references for diagnostics. List every registered entity and bare mesh as well, including ones without aircraft references, because names alone cannot identify aircraft. An entity shadows a mesh of the same name. Meshless entities can draw from registered descendant attachments, but a bare mesh named as an attachment is skipped. A bare mesh is directly selectable. Resolve only the chosen entry's files.

# 0101. Queue columnar journal writes only after the row spool commits

The live columnar path prepares a manifest and uncompressed sections from the same frame accepted by the row spool. Its allocations are advisory. Preparation or commit failure withholds that hour and the next successful hour starts a run. The journal receives a committed hour only after its corresponding row write completes. Refusal of the row write drops pending hours and their context, which a later frame can supply again. Branch changes wait for prior writes. A clock witness belongs to its own hour and is embedded in that hour's record. The recorder finalizes from the journal alone.

One thread per session receives ordered operations from the spool thread. Its per-recording lane owns the journal, and the spool thread holds no journal I/O lock. A slow disk can grow the queue without stopping the spool or its frame producers. Each ended segment is synced before appending the next record. The safe prefix left by a killed collector is usable as written. The queue holds each hour's encoded sections until completion. A reservation failure reports the refused operation by name. An ending refused by the queue still runs once earlier work in its lane settles so it releases the reader for later captures. Terminal allocation failure does not prevent the writer finishing already queued work.

Keep serialized control records in encounter order and release each frame's records only after its row write. The journal already knows its session and each frame carries its own clock witness. Digests prevent repeated branch, gap and event-loss context from duplicating the same fact. Control-only data can reach an open journal without an hour. A control-only finish opens a journal when needed, while a session that committed no evidence leaves no journal. Detach drains the row writer first. A qualifying journal starts at the next capture number in the campaign directory, preserving earlier files.

Journal failure stops the current capture and returns the unwritten hours and control records. The next capture preserves earlier controls before newer ones, and it carries named gaps for the lost hours. Consecutive failures double the reopening delay to at most one block. If a terminal journal record cannot be written, the recorder finishes the journal as left. Allocation failure in the columnar writer remains local. Error text uses existing fixed capacity and falls back to an OS code when formatting would allocate. The writer constructs child paths in a fallibly reserved string because pushing a component onto a verbatim Windows path can allocate out of band. Per-capture metrics persist after detach and are formatted by the status thread.

Columnar conversion helpers run between game ticks. The spool thread remains able to finish the current hour during a tick. Sync statistics use bounded buckets, with the exceptional top bucket reporting its measured maximum as the quantile's upper bound.

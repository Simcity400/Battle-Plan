# 0103. Publish template names and model inputs from one authenticated walk

Use the same hourly walk for the template dictionary, counter operands, native 3D-model inputs and their saved choices. Authenticate every roster occurrence. An occurrence with an intact writer witness can publish its held result without rereading its native input. Keep the sub-unit database copies and per-country definition slots with the capture and grow them off the game thread. On sizing, count each independent arena even for empty output. Offer both watch domains before the first capture, including the country-only requirement when icon sizing refuses. The fixed-size status diagnostic keeps distinct model refusals in first-seen order and counts further reasons together without allocating.

Keep the settled stores in the pool's shared home. The home reports its high-water allocation while a capture holds its stores. Each frame counts only its own allocations. If settlement has not returned the stores, or the previous work failed, read every template. Placeholder storage while a worker owns the capture allocates nothing. The template preacquisition consumer takes ticks from a matching accepted walk. On a mismatch it refuses without initiating another native walk.

Keep range arenas between hours while tracking the current staged prefix. One retained loan supplies the split ranges. A refused split falls back to the serial walk, and a completed range supplies the speed keys for the template occurrences it actually read. A serial walk takes speed keys from each read template after the main walk. A refused speed input or an unavailable span has an explicit absent value and counted refusal. Settlement only uses owned observations and frozen witnesses. Keep the exact layout and settings needed for conversion before returning the stores.

Counts expose a missing roster occurrence and new occurrences force a read. A quiet projection may match only when all output families completed, speed reads succeeded, carries remained unchanged, the roster kept its order and all writer witnesses survived. Include the roster signature to distinguish differently ordered buffers, and renew the generation if settlement did not publish its exact held observations. A failed capture supplies no observed rows to count.

A template display-name certificate compares exact bytes with the complete current dictionary row. A partial update's changed subset cannot serve as that dictionary. On dictionary refusal or truncation, write the name as a self-contained override. Quiet frames can borrow the encoder's identical rows without cloning their names, while a new key or changed display value remains readable at a keyframe and after direct seek.

# 0904. Record production measurements and the facts that qualify them

## Production and industrial organisations

Replay the production line's stored Q15 efficiency at the applicable precision. Its average uses the first `min(active_factories, max_factories)` entries, with the game's signed arithmetic and whole-percent display rounding. A recomputation admits the source only when it matches the line's handle, country, variant, organisation, kind and active factory count and supplies the complete prefix. Row operands include historical progress toward a unit for save comparison. Counts of completed units come from a different observation.

Industrial organisations use full reference identity. They retain the holding country's raw reference and ordinal and the owner tag link that chooses their display prefix. The script key, name override and sprite come from recorded content. The name resolution prefers the tag-prefixed localization when present. The icon tries the explicit sprite, then the tag-specific and generic script-key sprites, then the unknown idea icon. The daily production slice also reads the organisation's cumulative completed variant counts. The game credits an assigned organisation when the units complete, including naval output it cannot deploy. Production without an organisation contributes to none of these counters.

Per-line output instead observes every production tick on the branch. Give each first-seen `(country, variant, organisation, purpose)` tuple its own row. Keeping the tuple in the payload fits the bounded replay key and preserves totals when a line changes purpose. Count delivered units separately from organisation credit. A normally clamped zero conversion is exact when its delivery and credit reconcile. Nonpositive delivery or a blocked naval deployment can change credit without delivery. An unclassified tick leaves the amount out and marks the row inexact. A missed tick makes the table unavailable for the rest of the branch. Preserve the producing country's raw link from the tick because the line can disappear before the census. For a census seed with no tick, use its census country. A complete initial census distinguishes a newly created line from a line known only since observation started. Publish an ended line once and keep it eligible to publish again if the first write could have been lost. Live lines with no production still have a row.

The fixed5 credit operand excludes instant progress and has its own refusal independent of output exactness. Older rows can omit it and can omit purpose. Historical progress and auxiliary fields remain readable for save self-checks. Observed country production values are native daily operands for holders with lines. The powered and unpowered factory and dockyard terms are kept separately so the recorder can derive the output factor. Carry line-local bonuses after native token mapping, including the dirty flag. Authenticate a modifier row using country, variant, organisation and factory count. The conversion control is an ordinary recorded operand with a historical absence distinct from false.

Organisation details retain the completed-trait set, ordered queue and cursor, optional cooldown and source location. Tasks keep slot order and distinguish exact research occurrences from production lines. Variables and flags keep their scoped seed, fixed5 values, dates and expiry. A refused details table leaves the independent roster and production history available. A country's policy roster is independent of each organisation's selected policy. Keep empty rosters, native order and the effective attach cost term from the same read. The cost modifier is unknown when its read fails.

## Factory totals and equipment

Read factory group totals hourly from the native status because the top bar, tooltips and triggers use the last native recalculation. Keep military, naval and civilian counts, controlled and owned levels, damage, assignments, transfers and withheld factories, with licence and trade exports and civilian consumer allocations. Stored `_raw` totals are fixed5 and the game truncates them toward zero. Controlled level counts are before the building output factor and are summed with wrapping i32 arithmetic for the controlled-factories trigger. Controlled state and offsite buildings enter groups through content flags. The construction presentation derives owned and occupied allocations, available and consumed capacity and the held-back lines from these independent terms. A factory total is unknown for an absent country row. The save oracle compares level inputs because the exact runtime group operands are absent from saves.

Daily division equipment observations cover every division. The hourly new-division table uses the same row type for newly created divisions until the daily walk observes them. Record country subunit clones only when their ordered requirements differ from the global definition. In a complete table, an absent clone uses global requirements. Keep ordered primary and foreign equipment rosters and best-variant candidates, including repeated entries. Equipment bonus effects and doctrine or project rewards append ordered records and the clone rebuild applies the list in that order. Retain the source kind and token, reward or milestone number, effect label and ordered exact and category targets. The effective clone requirements come from the clone table. Module and upgrade definitions resolve by recorded lexical token.

Recording a deployment line preserves the military deployment's scalars and its exact queue or flag state. A zero signed order or training progress is a known value. Available and needed equipment containers have fixed positions. Its pool byte, allocation count, priority and raw halting reason preserve the corresponding save conditions and absence. Store custom names and ordered or programmatic flag bytes as held. Keep conveyor order because the engine compacts the queue. Its raw country reference is absent when the stored word is nonpositive. Equipment pool amounts can be zero or negative. Applied design bonus snapshots share exact value and attribution, while process-wide design observation can independently be refused.

The logistics equipment observation keeps the daily stored stock, surplus or deficit, and native available operand when observed. The live screen may recalculate later from demand and may add incoming lend-lease. A complete daily table with no rows for a country witnesses the absent non-AI calculation, not zero equipment. Preserve raw reference and database-position identity, with the archetype token naming it. An older row can lack the available operand, and a current refused read also leaves the value absent with different provenance.

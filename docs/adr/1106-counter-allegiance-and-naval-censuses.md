# 1106. Evaluate counter allegiance and naval placement from recorded censuses

Type icons and plates share allegiance independent of fog. Keep the roster, logical and expeditionary owners distinct. Keep neutral paint separate from allegiance-grouping evidence: when relation rows are unavailable, unrecorded slots do not receive `Allegiance::Other` for grouping, so a known same owner still groups while distinct foreign owners stay apart across allegiance-grouped land, railway, at-sea, and political or strategic port paths; non-allegiance port and regional comparator modes follow the game's priority comparator (selection, own versus foreign, full visibility, and detailed mission) without consulting relations or foreign owner identity. Signed nonpositive roster ownership bypasses the ordinary relation predicates. Otherwise identity wins, then directed war can veto faction and direct subject friendship. Access, attachment and a common enemy are insufficient. Evaluate both owners before consulting the ordered sent-volunteer vector. The first qualifying host decides, with equality at that position preceding its directed war test. An unknown earlier war can block a later host. An unruled-out volunteer friend can override ordinary hostility, while a proven ordinary friend stands without the volunteer census. Land, railway and at-sea counters test friendship before hostility, including hidden type icons. Port items and combat tiles test hostility first, omit the volunteer loop and signed-owner bypass, and keep authored icon colour. Use a selected visual mod's colour defines when they read, else the recorded ones, starting alpha at one for RGB inputs.

Each hour’s relation index is keyed by the input allocations and ordered volunteer host key. Equivalent host lists can reuse the index when the division allocation changes. Changed hosts or relation allocations rebuild it. Partial updates share unaffected country shards and keep the first refusal in native decision order, with unresolved volunteer inputs before country refusals and country zero last. Actual zero is never an alias for a positive reference resolved to zero. A missing current operand withholds the index instead of carrying the last answer.

The naval combat grid indexes one hour’s rosters for every combat. It borrows only forward groups in `(group, member)` order and excludes opponent-only groups from both the grid and headquarters frame. Count live convoys separately and add each live ship’s task force once. Item size uses that force’s whole roster even when only some ships joined combat. Incomplete ship or member censuses must not masquerade as empty rosters. For foreign non-sharing forces, an absent intel record in a truncated census withholds the grid. An unresolvable country in a complete relation map is a corrupt join. Force comparisons use native wrapping differences over signed handle halves and stable ordering, even with a nontransitive comparator. Preserve the contiguous-run asymmetry without a second allegiance sort. A lower-priority first item can absorb a later higher-priority item, while the converse starts a new group.

Placement makes independent passes over the province’s ordered direct vector and global registry. Direct icons retain their combat home and are eligible for rotation. An engaged combat may add non-rotating icons for transferred units’ sea provinces in the global pass. Test engagement before resolving transfer chains. The transfer-unit reader omits stale references, so a recorded live unit with an unresolved location withholds the global placement. An unresolved global pass preserves every proven direct presence. A missing direct census or an unresolved earlier global position can leave an otherwise proven icon’s stack offset unknown. Advance the per-province cursor on admitted calls, including deduplicated calls and authenticated calls with missing combat rows, then use the last admitted ordinal with integer GUI height and positive screen Y.

# 1119. Read map tooltips, clicks, and panels from their own recorded hour

The open map's readers use the side's view store. Ordinary frame requests cannot read past the presented hour, even when the side decoded ahead. Keeps associated with an open reader are retired off the frame when it is no longer asked for. Selection observers read keys only. The click reader opens with the tables for the icon families it can currently reach, reuses tables the overlay needs, and learns a missing table whole when a click discovers it. A learn applies until that view changes. A click from a visible icon keeps its target identity and the branch and hour of the overlay drawn at its input, even if a newer publication arrived before dispatch. Wait for the named rows without side effects and preserve event order behind a waiting click. Refuse by name once its hour has left without those rows. A click registered over a window, or released over one, cannot become a map order; an observer's attached-air confirmation displays the answer and closes without posting an order.

In a prepared map, a hover family gets a reader and a worker only while asked. The frame posts an owned job and does not build the text. Cooked results are keyed by target, view, relevant source identities and the recorded branch and hour. Two equivalent copies of the same vision can share that hour's text. A worker coalesces behind its newest job, keeps frames it superseded for retirement on its thread, and can repeat a job after a leaf resolves asynchronously. Learning a missing table reports what is loading and avoids synthesizing a value from another hour. During fast playback target the earliest prepared future hour without text; the current hour is built when no future one is owed, including a still view. Keep each prepared text until it is due. An exact capture can wait for recorded rows and text up to the named bound. Combat marker or division-panel text can keep its previous answer for the same target while its next one loads, with throttled requests during playback. Workers stop and release their rows away from the frame.

The combat window's side posts a read for each publication. Show it with the branch, hour and seek the frame is actually displaying, or name what is loading. Selectors known at load declare their tables before a stepped request, because no later publication can supply a late learn at a held step. Region and state selections that are already resolved open directly. The marker hovers take the engagement index of the engagement layer when a map is open. Division and raid hovers add their worker's lines to the existing tooltip only for their own target and keep the named coverage requirements. The overlay's current vision, movement and combat products are the sources for hover-related answers. Hidden tooltips continue following the pointer, with geometry updated even when painting is disabled.

The find view keys its index by the presented branch, hour and viewing country. It uses map-labelled victory points only if their label coverage matches the same frame used to build the index. The accented search uses folding from the recording, and names an ASCII-only fallback when that table is unavailable. Search and camera centering can therefore follow what the view actually presents without borrowing future names. The states mode's category line comes from the recorded live field, so it is withheld by name when absent. Scripted mode hovers apply the game's scopes for the viewing country and the hovered state, with a named refusal for unsupported expansion.

The hover proof runs the same jobs as the window and pairs each result with a same-hour full reference read. It exercises the overlay's modes and visible targets, including naval regions identified in the recording. It separates a roster request earlier than the open reader's coverage and can replay learned table declarations. The timed path reports shown text age as well as request handoff cost, and compares with a run that has no readers. Time spent on a worker and time spent on the frame remain separate.

# 0303. Resolve declared series against recorded timeline spans

The dashboard reads declared measures through the timeline and country identity index. Each part belongs to one holder within one stretch. Ordinary country lines use part zero. Sub-keyed series require an explicit part for a line because per-key summaries cannot provide the extrema of a sum. A state request with no part can enumerate a holder's parts in key order or rank the parts with recorded values. Singleton and faction lines use their own keys and cannot enter a country ranking. A country's scoreboard tag is its tag at the requested hour. The board reads the ranking measure and then groups the selected columns by table at that hour. A recorded zero can be marked partial when its history is incomplete.

The recording index supplies ordered, disjoint stretches and the reasons for gaps. Adjacent pages extend a stretch only within one run. When a load meets the preceding stretch at the same hour or the following hour, derived columns may carry by their declared rule. A gap or restart breaks that carry. An identity segment follows the same holder back through recorded stretches joined by a load. It stops when the holder changes. A segment opening counts as a change for navigation. A change search steps strictly past its origin. A reached-hour request falls back to the origin clamped to the request bounds, except for autonomy's change-only navigation.

A read reports the exact missing hours from the timeline, holder index, table status and key lifetime. A declaration that stores only nonzero observations may return zero for a missing row when both its table and the owner's slice were read completely. Pair measures resolve recorded raw IDs through their canonical slots while both links hold. A country with no link is its own alias, and an overlapping pair row with the earlier start wins. State reads within one block share a walk of that block. The run bounds are exact only where that walk observed the value change or reached the holder's edge. The other bounds may continue in another block.

Charts use the absolute grid. Full buckets use summaries. An edge that would include unrequested hours is read at finer levels, down to an hourly walk below six hours. Identity boundaries, timeline gaps and requested membership spans break lines. A part sharing a bin with a different or unresolved holder is read over its own hours. If a series has tracks without summaries, folding those runs keeps the exact hours of extrema. Re-folding a finer edge uses the coarser bucket's hour convention so tiling and a single chart agree.

Ranked charts select the top values at each bin's last recorded hour. They use the summaries for complete buckets and rank a clipped or short stretch at its actual end. Membership controls which bins a line draws and which countries' values need reading. In an exact edge bin a winner gets only its own hours, even when another tag held its key earlier. If a bin crosses two stretches, it can hold hours from both. A view with at least one pixel per hour also supplies its winners' hourly runs. A ranked request at one hour uses tag ties, while bucket ranks use key ties. Navigation through a ranked view starts from the top countries at its cursor or boundary. Drop pages count ordinals from the start of the timeline for the selected tags, while a row's own ordinal is scoped to its country. Marks cluster nearby drop bins and retain their prior drop counts.

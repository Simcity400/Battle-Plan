# Resolve sub-unit definitions by recorded identity

Preparation reads sub-units and equipment from the recorded mod stack in database order and spools the resulting resident content. Read every directory the native sub-unit database visits. Other child directories contain different definitions. Layer replacement is by entire path. A bare key is matched as a lexer token, and a quoted key does not select a native keyword. Case-only redeclarations keep the first spelling and ordinal. The native walk starts at index one because zero denotes the null object.

A later declaration resets the same parts as the native database. Type masks, equipment requirements and reset stats start again. Explicit groups replace retained groups. Transport, own-fuel and retained scalar words survive when the next definition omits them. A scalar assignment replaces both the old value and its refusal. Retained lists and battalion grants append entries and refused values in order. Preserve the authored stat keys and values so the recorded executable's stat registry can interpret them, including unsupported mod-defined words. Grants add to matching category base stats when marked additive and otherwise supply factors. A malformed field is refused by its name. Parachuting requires every grouped definition to permit it, with an omitted setting treated as no and a malformed setting refused.

Canonicalise requirements through the equipment archetype while retaining the native order and fixed5 amount. An archetype's list includes sub-units with a positive need of it. An equipment type that is not an archetype has no such list. Native consumers that read the first requirement must keep the first entry even when its amount is zero or negative. Model resolution uses the authored division priority when present and the effective type's DLC mask only when it has module slots. It retains generated equipment and duplicate archetypes. A generated copy belongs to its authored family, and a parent outside the cloned family becomes the native self-link. Archetype registration order is the first production comparator.

A local clone groups apart from its global definition even when they share a token. Resolve its country through the recorded links and its definition through the recorded spelling. Apply the recorded override when present. A complete local-override table can prove that a missing row inherits global requirements. Incomplete data cannot prove that absence. A caller can reuse the link and override index only when the recorded sources that built it still match. Null definition groups are omitted, and the absence of a representative remains the null object.

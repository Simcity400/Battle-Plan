# 0310. Infer war group continuity from dated observations

The recording has native war relations and what each country owns. Grouped war identity and participant intervals are observations reconstructed for the selected viewpoint. Preserve canonical country slots, recorded ownership order, retired and repeated occurrences in owned vectors, and first-array order when deduplicating groups. Null faction witnesses never agree. Check existing opposition edges without inventing participation from a faction or subject relationship. A null or retired matrix entry cannot form an active group even if relation dates are available.

Group deduplication compares membership with the native array lengths. Equal lengths can still require a subset check when an owned vector repeats a member. Seed reuse requires both equivalent ownership and adjacency and evidence that the non-leading equivalent seeds survive cross-side pruning. The complete opposite-side case can skip later seeds after verifying every owned vector and active-neighbour list against the opposite side with no repeats. These checks preserve native group order without walking every possible country pair. The relation that first names a group uses the earliest signed start, breaking ties in first-side then second-side order. Representative ranking keeps major-country pins and compares major status before strength, preserving the swap-removal order on ties. A nonboolean major value is withheld because the native comparison cannot define the total order the stable sort requires.

Process structural changes in native group order. Match each group one-to-one with the open war sharing the most continuing relation identities, breaking ties by the lowest created ID. A new group may join an already assigned war when that war holds its naming relation and shares the most relations with it. This covers a new declaration exposed beside the larger war. Give new wars IDs in group order. Match by native identities so a renamed country remains in its war. Equal held groups can still change assignments when they overlap, so reuse requires assignment equality. Settle open participant intervals before structural changes, keep departed relation intervals at their last hour, and extend held observations only through unchanged evidence. Later hours lacking an observation are withheld. Capitulation events attach only where recorded identities resolve to participant intervals. Keep an indexed open tail per relation lifetime so extending wide wars grows with their observed edges.

Resolve goal, token, state and country naming values from the run histories at the name's dated hour without replaying tables again. Start with the recorded default prefix and the instigator's first owned goal, using any available goal-type override. Reference zero names the reserved country without a link. The first goal's state uses its recorded custom or owner name before the template. The defender-tag suffix is eligible only when its localisation key exists. Use the viewpoint's self, active-war veto, nonnull faction and cached subject evidence in that order. The cached subject predicate is only recorded for the original viewpoint and a missing required value withholds the name. Use the country-pair key or prefix when the extra key does not apply. The ordinal argument is empty. Report naming errors at the required operand rather than reading an unused alliance test.

Participation combines directional contributions and same-side deliveries at the selected hour, resolving countries through that hour's tags and links. Values use signed fixed5 decimal strings. Tests separate a relation's key order from group-side order, and vary a first goal, its token and an owner name at different hours to tie naming to recorded history.

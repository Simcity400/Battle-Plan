# 1104. Group map counters without moving their members

Grouping consumes icon offers in their activation order under the content's source budget. A level change restarts that cursor and increases the budget for the rebuild. A zero or negative budget retains individual anchors. The game's camera uses its height for the content's province, state and strategic thresholds. A free eye measures each offer from its own anchor, so it can retain nearby icons while grouping distant ones. The viewer draws the resulting groups through the existing `units_box` windows.

- The first member defines the comparison kind and owner. Apply the lowest grouping level of all members and the prospective member. When admission would lower that level, recheck the existing members at the new level. Preserve creation order and admit an offer to every eligible group. For different owners below strategic level, ask the recorded relation from the prospective member's owner toward the group's first owner.
- Check strategic geography for two land icons at strategic level and for two sea icons at any grouping level. A huge strategic region falls back to eligible state geography. A huge state falls back to a province. Extents are the larger of their map-unit width and height. Missing province bounds add no extent, and a place with no known bounds never counts as huge. Read the content's size limits as integer defines to preserve its threshold comparisons. The tests use a fixture for the reference content values.
- A strategic member uses its region centre and carries no motion track. Sum current and tracked anchors in canonical source order and double precision because a different join order can otherwise move a pixel in a stopped frame. Use the lowest source index as the seam reference and the lowest moving index for the bracket hours. On mismatched hours, a member contributes its current anchor throughout. Preserve the unwrapped track so playback wraps the interpolated x once where the view reads it.

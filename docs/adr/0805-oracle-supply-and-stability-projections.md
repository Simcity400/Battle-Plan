# 0805. Compare saved supply and stability only within their read scope

The supply oracle validates every held owner’s node and inventory census, but compares saved allocations only for owners covered at the oracle hour. The authenticated map establishes whether a stored node, parent, or route province exists. Sparse save province blocks do not establish that. An invalid or zero province the native getter resolves as null is a named limitation. The parent walk stays within its country. Each parent must have a vertex and a vertex is only a keyed edge. The saved supply-block gate depends on the recorded owned-state count. Native ordered temporary nodes preserve repeated provinces and first-match selection, while their status byte is serialized by truth. Required truck demand is witness-verified at capture time; the oracle checks published values for non-negativity and reports withheld rows by name without blocking other train inventory scalars.

Stockpile exact totals need a load witness. The save stores variant quantities, while variant amounts and archetype totals saturate independently and can change separately after a clamp. Away from load, compare only values within the native whole-unit and essential-requirement bounds. At load, prove a total only if the saved insertion operations cannot give different results under the bound. Repeated variants replace their previous amounts, so compare changes rather than summing all occurrences. Volunteer aircraft use the same witness rule, independently of the raid essential subset. Raid convoy classification can require installed modules that the save does not name. Refuse an exact classification when content cannot prove it from the saved variant type alone.

Stability bases are saved exact. Penalties serialize fixed-point Q15 at five decimal places truncated toward zero, and the coastal term uses ordinary fixed-point emission. Their proved omission is zero. Cached modifiers and presentation lines remain unsaved. Every owner read at the oracle hour needs a row, and a forced full walk reads every nonreserved country. The session threat comparison uses the ordered saved source vector. Aggregate values are rebuilt and have no save witness. Target tags use signed-positive references.

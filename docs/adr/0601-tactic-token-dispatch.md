# Keep tactics and embedded collections on the owning file reader

Tactics get their identities in authored order, including duplicate names, with zero reserved for null. A key equal to exact text `phases` reads the phase list while a differently cased token names a tactic. File variables take no identity, remain available through nested keys and values, and resolve by read order. Tactics resolve phase fields against phases registered so far, after first-NUL truncation. The exact `no` sentinel and an unknown phase remain distinct in tactic fields. The phase-condition reader stores the resolved operand for later comparison, with `-1` for `no` or an unregistered phase. Campaign-assigned unlock IDs remain campaign state.

Keep the native reader's current-token and retained value-slot behavior. Keyword fields fold bare tokens, and quoted ones stay literal. Blocks read by keys that consume one token can instead donate fields to the enclosing reader, and an error can skip a block at the current token instead of the retained value. A comparison can consume a different payload than an assignment. Use the coded class or embedded object reader selected by the key. Keep both read-past diagnostics and unsettled coverage. Where content identity leads to divergent token consumption, withhold the current tactic and later identities by name instead of assuming their positions.

Tactic, weight and content conditions share names and conditional state. A limit may add a child only while its conditional has none. Weight `factor` and `add` consume one scoped-variable value before reading other conditions. Bound localisation recurses through argument bindings and contributes no trigger, even when an argument matches a trigger name. Scalar logical groups can leave empty conjunction or disjunction groups and a diagnostic. A scalar top-level tactic trigger contributes no condition. Preserve source order for effect occurrences. Movement speed uses the native integer scan and retains the earlier value after failure, while other fields use decimal fixed5 conversion.

Compile named collection operators before local operators while preserving the original header lookup. A null reference produces no flattened operators. Collection filters use the containing reader, including its active names and dispatch. Anonymous blocks, unknown keys and raw block skips retain their own consumption rules. Keep the specialized loops where their arrays, variables, flags or subordinate readers choose different token boundaries, including the provincial versus state building check and recovery after a failed numeric scan.

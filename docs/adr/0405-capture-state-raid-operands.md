## Benchmark memory ownership

`raid_state_inputs_bench` owns one synthetic arena for each fixture size. It keeps that arena allocated and immutable from `LiveMemory::new` through buffer sizing and all timed walks. `raid_state_hour_bench` owns both synthetic arenas for the full benchmark iteration. Both remain allocated and immutable through the initial full walk, each census and sliced walk, and the cold measurements that alternate arenas. The writes in these calls are to separate caller-owned output buffers.

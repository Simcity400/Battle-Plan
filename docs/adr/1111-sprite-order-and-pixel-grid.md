# Keep map sprites on their ordered, pixel-aligned drawing paths

The screen-space pass draws after the world without depth tests. Atlas quads convert interface pixels to snapped device corners. Compiled GUI draws retain their own geometry, constants, inherited sampler state, and scissor. Scale each authored scissor coordinate before truncating and clipping to the device target. Exact draws keep attach order within a layer. Free-camera icons draw farthest first, followed by the screen interface. Sampler metadata carries separate values for the primary, secondary, and mask slots. Preserve both texture offsets, animation clocks, and the second colour passed by bars or text. Negative tint alpha requests the disabled-state greyscale treatment, with its magnitude supplying opacity.

Layer keys encode signed content priority, icon ordinal, and child order. Widen the priority after adding the active-window lift. A 64-bit key gives every `u32` icon its own range, avoiding collisions at large icon counts. Only quads for the same child of the same icon can be regrouped by texture. Combat windows draw in a band above lifted map icon priorities and tooltips draw after ordinary windows. Batches share mover tracks by serial to place each publication's icon anchors at the display frame's hour. A named part may use its own anchor, such as a city label with an independent cutoff.

Round to the interface pixel grid, then scale and round each device corner so adjacent rectangles share the same edge. Atlas frames retain even strip pitch, including fractional widths. Clamp their indices at the end of the strip. At 1:1, sample the top mip with the regular bilinear tap. At increased scale, clamp that tap to the cell's texel-centre bounds. At reduced scale, average the footprint while it stays within that cell. An atlas mip could blend neighbouring glyphs or flags. Short rectangles collapse their clamping window to the centre. Device image pages are shared with the name pass, while each pass supplies its own sampler bindings.

Only source-over colour blends writing every colour channel can flatten into a separately composed image. Such a layer accumulates premultiplied colour and coverage, and handles alpha itself. Compiled submissions keep a pass-owned upload arena. A move-only window can reuse a packet after rewriting its world transform. A rebuild handles changes in dependent resource revisions, order, viewport, scale, or drawing content. A mixed rebuild would lose inherited bindings. A draw into a fade page inherits and updates the current binding stream at its original place. A refusal clears unavailable bindings from that stream and reports the draw identity, with one diagnostic per frame. Constant buffer checks refuse reads outside known written ranges. Matrix layout follows each effect, including the row-vector line charts.

Bake caches account for changes in lazy pages and can reuse a result wherever the bake owns all its bindings. Bake commands submit before sampling, including when the main frame is abandoned. Shared pipelines and the BC texture unpack pipeline are prepared outside display draws. A newly discovered pipeline may defer a draw; mark the next frame to try again. Dynamic pages currently drawn stay resident. An upload refusal is reported once per revision, and a later revision can retry.

# 0807. Stage uploads in frame order and retain their submission lifetime

Most draws reuse scene and light-grid constants. Repeated draws still go through the arena's placement and byte comparison so a hit in the pipeline or binding cache cannot skip an upload the draw needs. Comparisons are per reflected slot and include the full supplied blocks. Packed geometry and constant values are compared as exact bytes, including signed zeros and NaN payloads. Native geometry scratch is copied before it can be reused. Constant blocks are padded with zeroes to the reflected size to preserve D3D's out-of-binding behavior. A compatible empty vertex stream binds a zero-filled word that no attribute reads.

The arena stages constant and vertex data into reusable chunks. It restarts placement each frame so a frame with the same staging writes nothing. It compares against bytes known to be in the destination and only writes changed spans and new suffixes. It keeps the chunks in use and a spare, and retired chunks expire the bind groups that refer to them. The staging belt copies in reusable, fixed-size pieces so rendering does not pay for queue-owned staging allocations for every upload. An allocation refusal keeps the current chunk and deduplication offsets consistent so another draw in the same frame can proceed.

Caller-owned buffers are written before arena suffixes. A checkpoint freezes their write content and order at a flush boundary without executing GPU work or holding a borrow of the arena. The frozen data owns its source bytes and GPU destination handles. The bytes at those destinations are still shared. Submit all dependent commands before resetting or reusing an arena. A reached prefix still executes if a subsequent frame segment fails. Caller writes outside a reached checkpoint can carry into the next frame, but an abandoned chunk suffix is discarded.

A binding session holds successful resolutions within one invocation on one actual arena. It supplies every constant block to ordinary arena placement before using an immutable resource group. Cache keys identify effective programs, while retained groups own their resources. Arena reset starts a fresh session scope. Retirement and last-use reads share a total order with touch and revision updates, so an evicted group cannot be brought back by a stale warm lookup. Invalidating the general wrapper's last-view hint still lets locked resolution find an existing group. The general binding path keeps resource handles inline, and the reusable session storage carries allocation capacity across invocations.

The readback oracle inspects the bytes and offsets without using checkpoint construction as its reference. It normalizes buffer identities by actual handle equality so an alias stays an alias. Staging counters measure preparation work separately from writes that actually reach the GPU. The timing harness attributes compiles and pipeline builds to the threads that paid for them and uses counted render-pass creation for the map.

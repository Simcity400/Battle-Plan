# Record resource-map routes by their holder and client

Preserve the distinct render operands of a resource icon and a route line. The icon uses the origin's stored efficiency product. A line compares the widened, truncated fixed-point product of its client's two factors to the live bad-efficiency threshold. Keep its assigned, required and base convoy counts. Base demand precedes the naval dominance reduction and uses the native round-up at final demand. Each country that sees a bad naval route gets regional hotspot operands for that route's sea regions. A region beyond a country's stored records is full, while a reached unreadable record makes its table unavailable. Route weights come from the load-time strategic-region roster on full hours.

Key each route by its holder's raw identity and endpoint or stored client handle. Own and rights-holder origins and supply transfers embed their routes. Import, lend-lease and market clients use the exporter's route at the canonical importer slot. Preserve native directional-order positions independently for each endpoint. Read each reached endpoint list once, joining authenticated client addresses within the pass. A dynamic type word is independent of its class. Duplicate client IDs at the same wire key are refused even if their dynamic type words differ. Acquired pointers never enter the recording. Naval paths retain ports and ordered regions, and land paths retain states. A route with missing ends or path draws nothing. Authenticate native endpoint states only for demanded market routes. Path acquisition preserves the prefix before the first failed or invalid element, including at a guarded batch boundary.

Keep origin, rights, oil factor, client, route and temporary resources independently reportable. The threshold is required only for line status, and the supply systems only for client transfer lists. Rights use the origin's authenticated identity independently of its route or efficiency. Each rights-holder origin has its own route. Preserve one-based resource indices in rights rows and resource lexer tokens in temporary rows. Record the state resource factor and oil factor as distinct operands. For a present modifier key, share only successful metadata within one walk and read current presence and values per accumulator. An absent key has no metadata demand and a refused read is available for a fresh attempt at its next original demand. Fixed metadata storage adds no allocation verdict.

The temporary-resource walk visits states gated by their retained list or flag and omits known-zero key amounts. It uses the current complete resource census and reads each resource key at the first gated state needing it. Batch state pointers and their gates, preserving every native failure position. A failed source keeps its verdict. Unrepresentable indexing reaches the original serial validation boundary. The trade-opinion reader similarly keeps canonical links and relationship verdicts within one pass, where its source world is fixed.

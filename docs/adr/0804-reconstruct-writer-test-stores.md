# Reconstruct writer test stores from the schema and recorded state

Shared writer fixtures use each table's schema and support state rows and append-only logs. Writer observations list keys that were actually set or deleted. A recorder resume fixture reconstructs the stopped store as the recording would, including active table rows and the string dictionary. Tests can also reconstruct the tables while supplying only their held strings. A log is appended to or forgotten by ordinal. A state table is updated by key, and unprovided fields of a new row remain unrecorded. A fixture can set only selected fields without overwriting the existing row's other cells. Test projections follow the table's key or append order so comparisons are stable. [Writer fixtures](../../crates/recorder-derive-framework/src/testing.rs)

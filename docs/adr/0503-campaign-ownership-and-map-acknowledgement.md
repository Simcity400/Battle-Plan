# Keep campaign and map actions bound to the recording they name

Open campaigns retain session identity across page and layout changes. Layout edits preserve equivalent roles and track bindings so unrelated widgets keep the same runtime. A campaign's selected country is session state that survives seeks and clears on reopen. An explicit campaign assignment stays fixed when the default changes, and normally saves as an option. A newly opened campaign stays a draft while it cannot be represented in the saved layout, and uses the first free slot. Option edits apply only their changed fields to the newest spec, so successive edits from one rendered panel compose. A pinned moment belongs to its recording and resets to the widget's default time when changing campaigns. A page swap shows the previous layout until the next one is ready. Unshown pages hold their layouts and drafts until deletion or reset.

Persist device-local recording choices by folder and campaign where that identity is proven. Use the path otherwise. An open or a rename follows the matching campaign, even if another recording temporarily uses the path or the filename changes case. Chain relocations only for the recording initially selected. A pending open finishes under its original path before a rename is followed, and the dashboard allows one outstanding recording lookup. An unload removes its target from the current roster. When replacing a standalone map owner's lease, retire the previous snapshot first, leaving its old binding available for retry if retirement fails.

Map requests bind to the visible window generation and viewer, so an old acknowledgement cannot modify a replacement. Each new generation receives current options and a fresh clock anchor when ready. A running pop-out follows the clock from any dashboard page, including while the main app is minimized. The viewer advances between anchors, using the page's composition time to avoid shifting the clock by delivery delay. A queued target does not establish a drawn frame. During playback an acknowledged frame can be older than the requested hour because newer work is pending or refused. Keep that cause and the options actually drawn with the acknowledgement. The telemetry pairs the drawing time, camera pose and world-space target with the frame, and identifies what that frame highlighted or showed as a tooltip.

Replay branches and joins use segment IDs because the available order can change. A country pick follows a canonical slot after identifying its tag at the recorded hour. The viewer's pick sequence is echoed only when its option takes effect. Flight uses the aircraft saved for the recording, with no automatic default, and sends that choice to each newly ready viewer. Retry resends the latest time and repeatable requests. It clears a failed toggle because the command may already have saved. Toggles use the same service lock as settings saves and flip the stored value when they run. Report a failure where its map is displayed. A library poll watches revisions without opening any recordings.

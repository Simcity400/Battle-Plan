# Hidden actors keep their presentation clocks

**Status:** Accepted

Advance placement, actor plans, mesh admission, animation epochs, particle simulations and light sources independently of display switches. Hidden actors stay placed and carry their events, clock identity and resource budgets. Skip only their submission or audible output according to each producer's gating rule. A pose tick advances actor playback and emits events, while intervening display frames can place and draw the retained limbs. Trains and aircraft still respect the camera gates. Map mode can remove land figures or movement arrows while retaining ships. City actors are precreated outside the per-frame dynamic mesh creation budget. The aircraft and city steps have separate ownership from the rest of the walk and can run on a helper lane. The frame joins their data and diagnostic timings before using them. Stage timing measures the work already done without forcing another input walk, and a stage never reached emits no measurement.

Events flow to particle simulations in submission order with visibility attached, keeping retention and timing stable. Canonical packets can be reused at the seam. A newly visible entity has the same clocks as if it had stayed visible. Sound events use stable producer keys derived from the event and presentation namespace. A new key or a lower age means the event fired. Event nodes supply positions, and weather anchors retain their own event identity. A hidden actor's sounds are suppressed by the actor consumer; retained weather pairs have their producer's own release gates. Strike effects are combat sounds. The aircraft step hands back completed missile scenarios. Start their impacts on the aircraft presentation clock and move the consumed mark at start so a later frame failure does not trigger them again.

A city sample uses full-map pixel strides, Chebyshev edge rings and the wrapping province and coordinate mixer for selecting models and quarter turns. The bounded distance ring still supplies displacement weights when the last mesh has a smaller threshold. Only eligible neighbouring models contribute to displacement, and water rejects the original and displaced samples. The lattice province seeds the sample, but the displaced province owns the actor and provides its admission bounds. Use half-pixel bilinear height sampling. Preserve placement order within admission groups. The cull grid groups houses to local city scale without requiring that it match the separate tree tile size.

City damage uses the lower average health of infrastructure and civilian factories and resolves each province through its state link. Preserve the difference between a known null state link, a missing recorded value and an absent building in a complete table. Fixed-point health preserves the authored arithmetic. The strict authored thresholds choose damaged before destroyed, and a province with no state bypasses the thresholds. The selector uses disclosed visual definitions when visual mods are active. A refused replacement descriptor can fall back to a readable recorded entity. Entity and mesh scales are baked into library geometry. On first healthy display retain the entity's authored default. Leaving and re-entering view retains the actor's last idle request, and an unavailable authored state does not overwrite a live state with the default. Equal damage allocations preserve change flags. A crossed hour advances requests oldest-first without submitting intermediate placements, while the next changed view publishes any outstanding stream. Admission and animation requests can change clock membership even while placement is unchanged. Rebuild clocks in source order only when their inputs change.

# 1302. Rebuild scripted borders with explicit evidence of refresh state

The lower scripted layer supplies channel 1 and the upper supplies channel 2. A single underlying game layer can appear twice. When both channels select variants of the country layer, the upper variant owns their shared layer. Two distinct custom layers can occupy both channels. A scripted label policy names its declared far or near layer, and an absent policy draws no names.

A colour callback uses the recorded trigger world. Its main scopes are the viewing country and the target. Country and state callbacks target their own region. A state-controller callback may target one controller's portion, with the controller scope nested under its state. Uncertain selection can change membership, so withhold the entire affected layer and discard retained borders even if the selector returns a Boolean result. When a target disappears, remove its border. When its province membership changes, start the new border without the former region's style.

Refresh on a first presentation, a mode's scheduled daily boundary, or a witnessed native refresh. An effect callback can inherit a caller's active temporary store and earlier targets can leave values in it. Only complete evidence of no effect refresh permits fresh default temporary values. Incomplete event coverage cannot certify retained borders, even if a particular callback would otherwise be independent. Each outer evaluation opens a new symbolic context and preserves any inherited refusal. Report the underlying reason and affected targets by name.

Alpha gates the other outputs. A proved zero alpha needs no RGB or highlight evidence and leaves a retained style alone when membership still matches. A failed callback can likewise retain the style of an unchanged border, with its refusal reported again between refreshes. Changed memberships and untrustworthy refresh evidence cannot borrow earlier paint to fill the gap. Untickled inputs and stable float bits can reuse exact fill results. Without a thick outline the callback uses the flat gradient, with a thick outline it uses the scripted width.

# 0401. Keep live decision state separate from observed lifecycle events

Current decision vectors describe separately authenticated state, cooldown, timed, targeted and random-count data. The taken count alone cannot witness a completion. A missing status is unavailable, while an authenticated empty vector is empty. Native vector order and duplicates are retained, and row ordinal is only a position within that vector. Signed lifecycle codes and remaining days survive without interpretation or flooring. The target kind is interpreted from the signed country slot, and a numeric target keeps its authored meaning unresolved. Authored execution can receive the instance selector or a separate selector supplied by a command.

Definitions retain their exact authored tokens. Matching random items uses the first definition-name and target match, checking the derived token hash without recording it as identity. The default definition sentinel is outside the authored content set. Completion and removal hooks witness the original invocations. They use the definition argument rather than guessing the untyped receiver's concrete class. Targeted timeout follows the politics owner's observation so it needs no separate patch here. The decision hourly update follows the joined country stages.

Event namespace slots follow registration order. Numeric suffixes can wrap into another slot, so a combined id cannot establish unique authored identity. Empty event names retain their numeric reference. Dispatch consumes an event and a separate owner whose concrete class is not established. Game pointers remain local to the capture callback.

The border-event demand pass follows only active border war sides. It resolves their win and lose events, unions supported branches conservatively, and considers immediate or single-option effects when there are fewer than two options. It never traverses unrelated combat classes. Unsupported subtrees contribute no demand, and operative events retain their named refusal. A scratch shortage or native fault withholds the demand census so it cannot look like an empty set. Case comparison of copied tokens ends at the first NUL. Non-ASCII case folding needs locale information not captured by this reader.

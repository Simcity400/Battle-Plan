# Preserve native trigger operand rules

Recorded country identity, raw original tags and stored relation slots are different inputs. Resolve static and scripted country specifiers before selecting original references. A known null specifier reaches the authenticated reserved country. Original-tag iteration visits the recorded bucket and then the original itself, retaining the native count and visit order. `is_in_faction_with` requires both countries to have that faction. Faction leadership comes from the first recorded member. Focus-tree identity compares its stored ID and may be absent. State continent tests use the retained continent value because province edits and template reloads do not replace it. Coastal tests read the terrain bit of template provinces through recorded content.

The captured-general predicate tests captured, visible members of the country's army leader roster after admitting the yes/no operand, which the native predicate does not use. Leader visibility runs in the owner country's default scope. It reads the stored role, then the linked character's retained template role, and treats a leader without either role as visible. Effect-created skill and trait entries do not supply visibility. Roster traversal retains the country when entering the character scope and its caller applies the captured-role gate. A country-leader query selects the first supplied character, ID or name predicate. A ruling-only query inspects the ruling party's first leader. A trait predicate requires a real recorded trait definition and checks that leader's roster.

Invasion comparisons examine the order's active flag, path states and recorded preparation inputs. The scalar form has the inclusive threshold zero and does not need preparation data. A bounded comparison uses fixed5 preparation, applies inclusive greater or strict less as the native loader does, and declines unsupported operators. Collection representatives retain source and operator order, writing the first terminal result while still visiting later top-level sources. Possible-country iteration includes the null slot, state iteration omits the reserved zero index where its native iterator omits it, and a country is tried before its roster of subjects. `any_state_in` can visit nulls and checks its count before the body at the first eligible state. The country and neighbour loops check their counts at the native point relative to the body, preserve signed count behavior, and use the content's neighbour order. An empty list does not satisfy an `any` check. A reachable unknown remains in the count range unless known results already settle it.

Read flags from the matching scope's manager. A dynamic modifier accepts a scalar name or a block containing the last name and the scoped variable target, with a missing target defaulted to zero. The scalar and string loaders preserve their distinct NUL and newline rules. The target uses the same retained-field reader as MTTH. A repeated read whose fields cannot be replayed is refused. Only a fresh scope's positive country or state field selects a matching modifier target, so a decoded character cannot supply either. Modifier lookup retains recorded order. Without a target, the first matching definition decides. A known match can settle the result despite a prior unresolved operand. Without a match that operand leaves the result unknown.

The shared flag test accepts a scalar flag name or a block with the name, value, date and days. Names intern without case, whether quoted or bare. Without a value test, the recorded value must be above zero. Compare a setting date as an hour, and days against the starts of the recorded and current days. Date and day equality operators add no test. Expiry is independent of this check. Decimal operands follow the native signed conversion rules where reproduced and refuse out-of-range input. Dynamic flag aliases require a raw country spelling and do not reuse the canonical country's tag.

Scope selectors use the token's bare keyword ID, with `event_target:` recognised through its text up to NUL regardless of token kind. Explicit owner, controller and occupied selectors read `THIS`'s state. The country reader has no capital or random selector and uses the null link for those. Boolean assignment begins false. An ordinary malformed boolean leaves that default, and a recognised scoped selector that cannot be evaluated is refused. Integer comparison scans number tokens as integers and evaluates other tokens, even quoted ones, as scoped values truncated to whole units. Fixed5 comparison reads every token as a scoped value and follows its own strict ordering rules.

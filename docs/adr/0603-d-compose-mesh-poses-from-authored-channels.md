# Compose mesh poses from authored channels

Treat mesh and animation containers as ordered, depth-delimited node trees. Properties retain their declared type and order, and name bytes are decoded as Latin-1. Check declared sizes against the remaining payload before reserving or reading. This prevents a corrupt count from requesting a large allocation. Check each string's own length and strip its terminating NUL. Typed mesh import validates object presence, component alignment and triangle indices. Optional streams can retain presence even when a wrong-size value is omitted, since an absent property changes the vertex declaration.

Transforms carry three basis columns and a translation. The underlying mesh's inverse binds are in mesh space, while animation transforms are local to the parent joint. Join animation joints by name rather than order. Compose parents before children, with a missing channel using its authored rest value and an unnamed joint contributing its parent-relative bind. Reuse the same joint transform to place attachments and to build the skinning palette. A joint without a usable inverse bind takes the identity skinning transform. Four influence slots are stored for each vertex regardless of the authoring cap. Unused slots have no weight, and an entirely unbound vertex stays in bind pose. Zero scale hides an attachment without discarding its transform.

Reuse the immutable mesh and animation name joins across repeated pose queries. Keep the final local for a duplicate animation name and the first record for a duplicate authored skeleton index. Reused sampling buffers preserve the same parent walk and composition as one-off queries.

Keep rest values separate from samples. Animation streams are frame-major, containing only the joints declaring the corresponding channel and in their source order. A short or absent sampled channel can use its rest pose. A still recorded hour has no animation time, so it selects the first sample of the default state. Resolve all shapes together if the mesh declares no explicit LOD ladder, since shape order alone can put an undrawable collision subgroup before visible geometry. The collision projection chooses the last qualifying collision submesh and uses bounds when none qualifies.

# 0805. Report only comparisons the oracle has evidence to make

The command compares an independently parsed text save with the recording at the exact hour and resolves content against authenticated recording inputs. A changed sample boundary affects the reported limitation while both sides retain the same named hour. The recording itself witnesses continuity and output histories. Internal consistency checks do not count as saved-field equality. Failure or unavailable content in one domain should not erase independently comparable siblings. Excluded state history leaves dependent membership unknown, including a province whose omitted controller would need that state’s owner. The exclusion itself makes coverage incomplete.

Coverage uses measured walks, per-table read hours, and owner slice dates. Scan branch blocks newest-first for the last reads and stop after all daily tables have a date. A reconstructed snapshot can contain carried rows and cannot prove freshness. A daily-only group with no read at the oracle hour is carried and is reported with its read hour when known. Hourly and static groups remain comparable and sliced groups select their own current owners. A proven full refresh includes rowless owners, with individual owner read markers for sliced families. Keep actual observed loads distinct from attach, skips, or other full-refresh signals.

Country intel can defer its walk while its shared buffer is loaned and retry off-slot. Its measured read proves only its own freshness, and a same-slot sibling’s read cannot certify intel. Other off-slot daily work can witness a full refresh. Without such evidence an unmarked read stays carried. Historic packet stamps need their own hour check. Older or mode-omitted data retains its named absence, and a pending publication is never accepted as an empty result.

Admitted country emission ledgers preserve physical order and repeats while ordinary country joins use authenticated canonical identities. Without admission, compare the strict ordinary census and preserve any refusal of the physical ledger. Exact content-dependent owner aliases do not establish raw tag spelling. Compare ordinary text and raw strings using the writer’s first-NUL prefix. Reverse spellings use recorded first registration; when different reverse names share a folded key, the spelling is ambiguous. Each content read reports its own refusal. Presentation fields compare at the recording’s fixed or derived display precision and name that precision. Keep all differences and repeated limitation occurrences with their groups, since a fixed output cap hid entire failed groups.

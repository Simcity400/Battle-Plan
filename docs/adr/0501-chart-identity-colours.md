# Preserve recorded faction colours until they visually collide

Resolve a campaign's faction colours in numeric faction ID order, applying valid user overrides first, then recorded leader colours, then palette choices. Preserve a leader's supplied colour exactly, including grey, when it is distinguishable from already placed colours. Pick the first noncolliding palette colour for a faction without a leader colour. Define a clash as a separation below eight scaled OKLab units so the default palette is distinguishable in side-by-side use. When defaults clash, alternate lighter and darker steps and keep the nearest adequate colour, without changing hue or chroma before gamut conversion. Compare the final rounded sRGB bytes and retain the best separation if no step suffices. This also keeps a neutral grey neutral. [Faction colours](../../ui/src/charts/factionColours.ts)

Stable categorical colours use a fixed hue order and a shared palette cached by theme surface. Seek WCAG graphical contrast of 3:1, preserving hue and moving lightness first. Grey is reserved for contested and missing states. A recorded identity colour stays as recorded even when it is grey; when one below the grey chroma threshold sits within 0.12 OKLCH lightness of the reserved grey in the same picture, the reserved grey for contested and "other" takes the darker neutral step instead (the base game's Axis, recorded [81, 78, 74], reads L 0.50 beside the usual reserved grey's 0.46). Grey category inputs have no reliable hue and use their palette position instead. Choose the most distinct readable fallback when no candidate clears all earlier colours. Categories beyond the palette repeat its order, with lines carrying distinct dash patterns across rounds and between primary and secondary measures. Prefer each line's stable content-order colour when it is free. [Palette](../../ui/src/charts/palette.ts)

The indexed distance step preserves the earlier scalar calculation and candidate order. Maintain balanced trees in power-of-two buckets as distinct colours arrive. Deduplicate identical points and keep equals or near-boundary results open when pruning, then evaluate returned distances with the same scalar `Math.hypot`. Invalid coordinates retain the scalar NaN and infinity behaviour. [Palette distance](../../ui/src/charts/paletteDistance.ts) · [Scalar parity test](../../ui/src/charts/palette.test.ts)

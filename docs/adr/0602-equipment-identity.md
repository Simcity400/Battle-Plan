# Preserve equipment registration order and native operand identities

Load direct equipment files from `upgrades`, then `modules`, then the root, sorting each by filename bytes. Top-level keywords choose separate readers. Each reader owns its token-consumption rules, including raw lists, scalar reads, object reads and trigger bodies. Keeping those rules matters even when consumers omit a field. Skipping an opening block, for example, prevents assignments in that block from defining variables for later reads. A consumer requiring a complete database refuses an incomplete load by name.

## Types, modules and slots

Use folded first-NUL identity for lookup and keep the first declared spelling for presentation. Register a type before reading its body and its aliases after. A new registration can shadow another name. Redefinition erases every previous alias of the redefined type and resets its links, categories, slot data, sprite and visual additions. Stats, model text, variant naming keys and visual level survive. A reread also clears generated status. A parsed archetype can contribute its then-current stats and sprite. A parent can fill an unset archetype reference without copying stats. Use stored links for later walks, since an alias might take over a linked object's original name. Refuse cycles by name, including archetype-only cycles in designer lookups.

Module and slot lookups use registered tokens. A slot with the same token replaces the module while keeping the first slot spelling, including where rejected names share token zero. Repeated modules reset, and one block's final limit applies to every module declared in that block. A module's own allowed and limit conditions evaluate in a fresh country scope. Preserve each authored slot category occurrence. Whole-slot inheritance reads a distinct parent first, then an archetype. The null object has no slots. An individual slot can copy the same token from its source or take an existing named slot as an alias. A duplicate slot reports an error and skips its block. The reader initially treats an unresolved slot as new, then repeats the file load after an inherited-slot witness proves the earlier block must have been skipped. This retains variable-consumption parity when the two readings differ.

Resolve primary categories from the type or a single archetype step. Finalization adds categories from its own default modules, normalizes naval categories, counts parents, and sums each parent's visual level addition with a minimum result of one. These steps differ from designer family predicates, which examine each archetype and its own defaults. The mission masks have their own identity domain. Technology construction supplies its DLC state when it admits a type, independently of later country evaluation. Numeric category fallbacks only apply in the readers that specify them.

## Generated types and group membership

Repeated duplicate-definition tokens update one definition. Resolve the source through its token and refuse missing token-zero text. Generate copies during the file load, starting with the source archetype, using the native stable hierarchy order and bytewise name suffix. The suffix cut can split a UTF-8 sequence. Remap links to previously created copies, clear aliases, set the family to the source type, apply the duplicate's category mask, and use its sprite when nonempty. Archetype-only mode copies only that type. The slot-removal flag clears allowed types, slots and defaults together. Each stat retains its last accepted operation and uses native fixed5 arithmetic, including wrap and truncation on multiplication.

Equipment groups retain the first declaration of a token. Expand nested members in place and refuse cycles. Organisation lists can include group names in the expansion as well as members. Membership checks the folded type, archetype and family names before testing category keywords. Decimal category literals do not participate. Group captions use their authored description when present and otherwise the declared name.

## Design costs and validation

Cost thresholds and resource pools retain ordered keys and replace an earlier value even when the replacement is zero. Upgrade costs charge both directions of native byte-level traversal, retaining its signed intermediate conversion. A present linear operand selects its formula with zero allowed. Generic upgrade licensing modifies the factor before multiplication, while module licensing applies to the slot sum before final design cuts. A missing recorded owner operand withholds the result. Nominal and applied stat terms are distinct. Applied snapshot words already include their scale, and an explicit average zero still contributes a divisor. The native reserved fixed5 values participate as stored.

Industrial conversion picks an exact module first, then the last entry whose category matches, including the native unset identity. Structural validation counts inactive explicit assignments for aggregate rules, treats them as absent for individual slots, and can use that slot's default along the stored inheritance walk. An `empty` assignment supplies no module. Native count checks apply only to collected map keys and preserve the stored operator mapping.

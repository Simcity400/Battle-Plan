# Record native order and template choices independently of their display

Order plan keys use the owner-group-scoped native instance. Preserve the native management byte and distinguish an invalid front reference from a valid empty front. The root, predecessor and successor orders are ordered simulation facts. Name prefixes and other localization keys are translated at playback, but a name already localized at creation remains stored text. Front section ends delimit words in the shared ordered province sequence and preserve empty sections and repeated pairs.

Record route validity separately from active and executable flags. Naval invasion and paradrop have execution inputs only when reached. A known nonzero paradrop route is required before preparation inputs are demanded. Preserve accumulated preparation when a later modifier or target read fails. The term group is atomic, with known skipped leader or relation terms distinct from refusal. For child fronts, demand the header only above the native controller-area threshold and read no span for a nonpositive child count. A positive army-group count admits the ordered prefix bounded by the same read's group count. Keep repeats and signed spans relative to the parent segment start. Boundaries reached before a failed header or payload remain valid.

The naval invasion's required hours are derived in playback from recorded country, relation, leader and content terms. Apply the live arithmetic order, truncating the fixed5 product to days before multiplying by 24. The target comes from the controller of the first path province's state, with native zero for absence. The relation term demands a distinct positive target. A reached relation bonus can use slot zero. The leader term requires the selected HQ provider's resolved root order. Route search uses the selected unit's raw owner, preserving its slot-zero relations and co-belligerents from that country's packet. The save keeps preparation progress alone. Retain native signed convoy count and separate assigned-unit weight and paradrop modifiers; a failed reached field does not establish zero.

Use native ordered membership for faction and volunteer theatres. Faction pins anchor to the first listed strategic region and use all their regions for the mean; hidden countries retain their order. Volunteer host repeats retain their position and paired deployment counts. Sent-volunteer references preserve unresolved and null entries but consumers use only handles proved by the complete census. Keep a controller area's representative apart from its full repeated membership. An authenticated orders group uses full handles and represents missing native parent, leader and HQ pointers by zero. Its theatre position follows its native regular or army-group roster, with no position when absent. The engine's native member ordinal, not an independently generated sequence, drives replay and save order.

Capture writes country template configuration even with zero templates. Country garrison defaults precede occupied-country and state overrides, with an unset template inheriting its parent. An explicit state zero is distinct from the group scope. The daily dictionary supplies names and the native unit category; the separate hourly rows determine visual effects of edits. Preserve full HQ deployment operands and keep unresolved references without inventing a live target. Remember each spatial cell, including the null definition and the independent empty pointer. Flatten column first and narrow the native index before bounds checking the cell array. Preserve dimensions, grid contents and original mod-authored extent separately. The three composition grids group their definitions by first occurrence, token and clone flag. Ambience depends on the regiment and support grids but excludes the regimental-support grid and null-object cells. Recruitment restrictions retain raw byte flags, order-sensitive roster settings, shared priority and the native deployment-cost word.

# Preserve native texture precision and fog grid geometry

Resolve file textures in DDS, Targa, and authored-path order through the appropriate content coverage reader. Padding depends on the client's decode setting and applies to files. Generated resources have their own logical extents. Preserve loaded mip levels, decoded block extents, and the DDS face order. Block-compressed mips smaller than a block still consume one full physical block. The BC7 GPU unpack path crops authored logical levels from padded staging, preserving hardware interpolation and the file's declared colour space.

Colour drawing uses sRGB views and data drawing uses linear views, with alpha linear in both. WebGPU cannot upload native packed 16-bit formats directly, so expand channels to exact normalized `f32` values. A half-float conversion can cross authored effect thresholds. Upload the values unchanged and filter in shader when the device cannot filter them. Diagnose native file failures as an unbound input that samples zero, and refuse unknown or device-dependent errors. Validate device-independent dimensions, face count, and format before a visual replacement is accepted so a failed replacement can draw from the recorded layer.

Texture producers publish a process-wide content identity for each creation, replacement, or write. Cloned bindings share the identity of their texture, and a new generation invalidates every pass keyed on it. A writer that already proved its bytes unchanged skips the write. A view without a published content identity draws each frame. Generated texture writers use the bound handle to report their writes.

Snow and mud cover four-pixel blocks, and the independent intel texture covers six. The intel texture floors its size and spans the entire map in shader coordinates. Terrain tiles use declared indices with the native low-byte representation. Undeclared tiles sample tile zero with a named diagnostic. Generated terrain IDs use upper, right, base, and upper-right channels in bottom-up order. Set the all-equal flag by adding a wrapping byte offset to the base channel. Gradient-border textures stack two layer bands with zero guard rows and use one layer's height for the shader's sampling span.

The fog grid caches a content-owned composition of its source pixels. Only defined land uses changing province bytes. Water and unrecognized province IDs use the clear byte, and an unseen recorded province keeps its recorded zero prior to the complement operation. Pixels outside the floor-sized grid are excluded. Complement the truncated mean once per cell. If no visibility input is available, the viewer reports it and supplies an all-clear stand-in. Preparation can happen during content loading or on demand. Keep completed composition and structural refusals, and retry transient resource failures.

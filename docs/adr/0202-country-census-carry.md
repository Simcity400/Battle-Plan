# Carry only country rows the hourly census can authenticate

The Ordinary job visits every canonical country slot every hour. Appearance and counters can carry complete held reads only while the round's writer marks certify the same epoch and the slot still names the held object and native ID. Appearance also compares the naming globals. Counters compare the country and link array headers and read the production, diplomacy and character owner pointers for every country, because their changes can invalidate the held rosters or relation suffix independently of writer marks. A new or marked country is read within the hour. A failed or incomplete walk, a lost certificate or an abandoned job holds nothing. If a carried row cannot be copied into the current arena, it is read again. Storage is advisory, grows on the worker and is measured there for game-thread accounting.

The published bytes have native walk order. A carried appearance row restores its original-tag and subject bytes between its fresh neighbours, and subjects retain the native roster order. Loss of a subject payload can move rows and causes subsequent work to read their tag bytes afresh. Counter rosters and co-belligerents similarly restore their held arena entries at the full walk's positions. The counter pass always resolves country identity, reads civil-war headers and reads pride ship names behind nonzero handles and the reverse visibility cell independently. A native null production status is observed data. A refused sent reference can be carried with its row, while other required-read refusals withhold it.

## Reserved country and frame ownership

Reserved country naming and its directed disclosure matrix have independent availability and stay outside the positive census. A reserved land certificate needs the naming prefix before it can admit the optional theatre suffix. The visibility reader retains the original matrix extent and attempted failures. Its fast scalar sample remains available when later required naming refuses. A refusal blocks committing a dependent vector body. Positive counter prefixes are established before the relation suffix attempts. The reserved slot can be observed without a successful positive prefix, and takes or borrows an original attempt rather than retrying it. Forward-zero visibility can use that original status attempt. The reverse observation reads its own cell. An owner refusal consumes no target span. Header hints bound the co-belligerent capacity from known floors while counting each refused owner independently.

Native controls are callback-local and cleared on exit. The host lends the physical navy pass through the mission jobs so each manager slot is authenticated once. The navy pass feeds slot zero's launch bases to the reserved source and its timing is charged to counters. An original launch control is consumed once even when mandatory naming failed. Named packets are published only for the hour in which they were read. Malformed optional spans withhold their own field and leave a valid prefix intact. Direct-war cells come from WarRelations during playback. The retired naval movement and transport preview fields retain their tombstones, and unobserved attack operands stay empty.

The fixtures use a synthetic census with canonical aliases, held and fresh rows adjacent in the same arenas, multiple target owners, moved owner pointers, and a baseline read trace that detects added visibility retries. A replacement read publishes data equivalent to a full read of the same memory, including the ordered payloads, reverse cells and failures of the shared accumulator.

The timed and counted `LiveMemory` reads in `border_effect_subject_scale_bench` target the synthetic world's byte buffer synchronously. Its allocation and pointer targets remain valid and its bytes remain stable throughout each capture.

# 1102. Preserve occupation and access semantics in state window controls

Show active resistance, with law and garrison information restricted to the controller. The law's hover needs the occupier's state for the occupied country. If the game would build no hover, allow authored text instead. Show the law name, description, trigger evaluated in occupier scope with the occupied country as FROM, and regular and suppressed state modifiers in order. Garrison selection falls back from the state to the occupied country and then the occupier. The assigned custom icon applies unless NATO rendering overrides it, in which case use the priority sub-unit's icon and appropriate frame. Read required garrison amount from the game's last computation.

Occupation takes precedence for the owner heading. Core status resolves raw references and canonical country equivalence. Show the non-core or modifier line that applies to the selected ownership plan. For a partial occupation flag, the first weight pair of the controller's country gives its share and the breakdown preserves pair order. No weights or no total indicates whole control only when those observations are actually present. Missing controller-weight data is withheld. Distinguish a core or claim's thin border, owner's thick border, and contested owner's thin border and mark. The viewer provides no diplomacy window, so the native delayed diplomacy action is omitted.

The state row does not record controller weights. The current getter refuses the flag inputs by name. Resolving the flag's partial occupation would require the ordered pairs and total. Scalar static modifier blocks can be accumulated using native wrapping. A block with custom tooltip keys or an added child refuses that sum because the native merged key order is not known.

Adjacency-rule hover text puts the current relation's reason and permissions in its immediate part, with other relations delayed. Use the localized disabled reason in the observed country's scope, or the generic blocked reason if it has no key. A contested side uses its faction name when it has one. A held verdict describes its own triggers; otherwise list the failed verdicts and their trigger sections at the authored indentation. Evaluate availability descriptions in observed-country scope.

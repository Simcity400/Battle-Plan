# 1202. Page event logs independently of milestone rows

The event feed combines pages from the declared feed log with milestone rows dated by other recording families. Request the kind codes separately so the first page can be prepared before the span walk finishes. A milestone-only selection skips the log. The page size bounds the work needed to word scripted text after a seek. Rows from other families join the page whose date range can contain them, and retain a separate page when no loaded page can place them. A server-side country filter gives sparse selections their own page membership and counts. Names and flags resolve at each row's own date, with a removed member identified by the last recorded membership. Only the prepared block and any additional visible rows ask for their names during playback.

Event choices and decisions group opening and continuing rows into cards. A continuing row without a recorded opener starts a card through the no-opener facet. An event card takes the firing date where available and the first recorded choice otherwise. Immediate effects alone never create a choice card. Each edge appears when its read is reached. If a recording break separates the firing from any recorded choice, the intervening choice is unknown. A cut updates cards when an edge, a break, or the next open-card day is reached. Titles and options from recorded content remain unavailable with their reason if they cannot be resolved. A separately recorded chosen option still appears even when the authored list is missing it.

The feed's scripted-text gap marker identifies an unexpanded field rather than a character from the author. Render the gap with its reason, and spell it out in plain text for sorting and assistive technology. Capture limitations go to diagnostics with their counts and never become feed events. Strikes supply their own recorded target and impact outcomes. Missing artwork gets a placeholder.

Espionage uses distinct sources for operations under way, completions, and operations that left the census without a recorded completion. The last kind must retain whether completions were recorded over its lifetime. Apply completion type facets from the recorded tokens and country facets when a single tag role is expressible. Filter other country selections on held rows. Types and tokens are separate reads, so names need not wait on historical pagination. Status bars paint followed readings between structural updates. Preparation displays truncated whole percentages and its slot count includes unassigned slots. Details use the row's actual read when a tooltip requests them.

# 0906. Add capture fields with explicit historical absence

An appended observation or named table has a format-specific introduction. Before it exists, consumers report the field as unrecorded or withhold the affected portion by name. Cadence is also specific to the format so that an older day's carried table retains its original meaning. Retired layout details and fixtures can explain a historical format. They do not make unpublished layouts playable.

Political runtime and selected route and technology occurrence inputs landed together in format 101. Format 102 records the exact election predicate as a nonzero flag and positive frequency. The old fields remain tombstones, and older recordings cannot answer that predicate. Later political captures preserve separate grant and project/scientist details, independent intel/cache sources and signed estimate categories, per-key occupation hover availability, and the active modifier and admission inputs for occupation markers. Estimate keys include the signed category, while full information is a payload operand. Country market's obsolete access and purchase-automation fields retire at format 126, keeping older framing while discarding their values. Faction state keeps numeric terms independent, retains advisor source ownership and carries subject and population accumulators independently. Doctrine grants and choices are separate changed columns. Experience captures retain stored division and commander values and complete commander training progress.

Format 102 adds map population, claims, categories, strategic locations and war-goal recipients as optional fields. It records hourly operative assignments, cooldowns, missions and pending missions, national activity and country pressure, current agency buffers in their native order, and the selected phases, requirements and equipment pools for operation preparation. The network and subnetwork rows retain daily gain, target and quiet inputs separately. Format 104 adds active air mission counts for zero-weight regional colours and the scripted-map cached choice and array extent. That revision also adds scripted refresh coverage to map events. The resources mode's icon inputs and trade lines have separate tables, allowing those views to withhold their dependent features when absent in earlier recordings.

In format 102, retain naval source trees by identity while an observed writer has not changed them. Collect audit samples separately. Earlier naval modifier breakdowns stay retired. Nuclear impact events keep their applied outcome before authored on-actions. Battle sound rows retain the simulation's hourly battle list. Raid equipment availability records integer essential-item amounts capped at the largest applicable requirement. Later raid memoization keeps land and naval domains separate. Template membership names retain the original referenced template even where a save would bind a different one on load. Composition grids preserve definition and cell counts so ambience can count regiment and support slots without the regimental-support cells. Format 104 extends template data to spatial grids and settings and packs variant scalar, name and icon changes together.

Split production output by each tick's purpose and record conversion control independently. Daily captured display operands include commander and observer progress, three division display columns, the country's unit bonuses, industrial organisation policy cost and the panel suppression witness. Retained combat log history and stable observer occurrence keys are separate from the signed numeric lanes. Versioned append metadata for nested values names the introduced field explicitly, so older values can still decode the unchanged prefix.

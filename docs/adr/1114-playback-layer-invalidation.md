# Invalidate only the playback layers and rows that changed

Radar keeps each group's recorded range and origin. Its placement uses the host state's recorded-content geography and the current viewing country's faction and subject families. Occupation marks derive both Resistance and Compliance from the state row and the controller, with camera layout performed separately. The marks are inactive in other modes. Loss of required data yields a named refusal. An output version changes when the layout may be stale. Recreated layers use a new generation so a cached layout cannot match accidentally. [Radar](../../crates/viewer-layers-infrastructure/src/radar.rs) · [Occupation marks](../../crates/viewer-layers-political/src/occupation_marks.rs)

Railways track the graph, supply bits and harbour anchors separately. The same inputs as the full network determine which strips and bridges change. The triangle rule depends on the neighbour's adjacency, so an edge or anchor change can mark incoming strips as well as the endpoints. A supply write matters only if it changes whether a province is a source. Incomplete naval base data withholds the railway. The layer keeps vertex rooms and grows their storage with spare capacity. Publishing writes changed strips and the affected span of the index buffer in province order. Runs whose index positions and contents did not move need no index walk. Train routes can read which province strips changed.

The viewer's relation index is an input to counters, models and naval effects. Its canonical viewer comes from vision. Country zero's relation to a positive viewer uses the recorded visibility packet. A requested receiver at zero is refused because this layer cannot decode its required packet. Relation facts are shared by part between hours. A war or subject edit normally affects only the side related to the viewer. A change to volunteer hosts can affect every country because every classification checks the host list. Consumers receive the raw references of affected countries. [Railways](../../crates/viewer-layers-infrastructure/src/rails.rs) · [Relations](../../crates/viewer-layers-counters/src/relations.rs)

Resources mode keeps icon inputs per state, compares shared folds and leaves camera layout to the window. A state-keyed change marks that state. A changed definition or building grant can mark all states. Changes to a country's oil factor or building-resource overrides mark only its controlled states. Relinking can invalidate every state's canonical owner. A building that grants no resource and is not infrastructure can be omitted from invalidation. Spelling uses the recorded dictionary and token order. Unchanged values preserve existing text, and a missing required table refuses the icons by name.

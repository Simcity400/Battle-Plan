# Preserve recorded text and presentation-clock behavior

The recording stores modifier source labels as rendered text without localisation keys. In the recording language, draw the stored bytes. To show another language, prepare a reverse index from the recording stack's localisation while loading the document. Several candidate keys may recover the label only when their display texts agree. A leading inline icon permits both whole-text lookup and recovery with the icon retained. The two readings must agree when both recover. Draw-time code performs no content-file lookup, and refusal distinguishes missing, unmatched and ambiguous text.

Tooltip timing follows the presentation clock, starting with the first presentation frame. Keep authored delays as floats. A deadline at or below zero is unset. Comparisons are strict, so the scheduler requests the next representable clock quantum at the deadline. An already visible tooltip can update immediately, while show delay applies to a hidden box. Request frames through no-hit periods so a hide can finish. Binding by province and control rectangle preserves a continuing hover. A negative delay can pass immediately once its deadline is positive, while non-finite intervals do not schedule a future transition. The comparison with a NaN delayed body never passes. Empty checks use byte lengths and keep authored spaces and leading newlines.

An explicit tooltip anchor stays fixed relative to its control and flips by its own dimensions as needed. The naval anchor uses the native combat window and authored maximum width. The preferred `ToolTip` declaration takes precedence over `defaultTextBox`, and an invalid declared type refuses instead of falling back. An authored width of zero is data.

Tooltip producers own their localisation keys and scopes. Missing localisation keys draw their own spelling, while a formatting or layout result the viewer cannot reproduce is refused by name. Missing text icons draw no sprite, while unsupported controls and invalid frames are named refusals. Carrier country text uses the recorded flag path when its host supports this. State names prefer recorded custom and owner names before the template and do not localise already rendered text a second time. Country-specific names use the simulation tag, with short names checking the qualified short form and then the plain short form before ordinary country lookup.

Recorded trigger content is initialized with the document. Coastal checks use static movement terrain, state neighbour checks use the province graph, and subtype visibility uses the recorded character templates and their role disclosures. Resource and naval invasion terms come from the content defines. Unit handles are separated by their native class. A transported land unit retains its own class when rendering standstill slots, and task forces use the land directional range for edges from either surface.

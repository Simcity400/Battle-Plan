# 1121. Measure presented image changes and test input at the viewer boundary

Frame rate counts presentations. Pixel comparison separately counts new pictures and compares the resolved world and the composited output, so activity confined to overlays is distinguishable from changes to the world. Changes are grouped by amplitude in byte steps, bounded and counted across spatial tiles. The tile distribution helps distinguish a local change from scene-wide effects. The existing visible-change threshold counts 64 texels with a difference of at least two byte steps. Each comparison occupies a GPU buffer slot aligned for the device. The paced harness reads its measured slots at the end. The optional window diagnostics read one slot asynchronously without waiting on the frame thread. Counting restarts when targets resize, and the presentation tally advances where the swap chain takes a frame. The feature is opt-in and incurs no comparison work when disabled.

Acceptance tests on an isolated desktop inject the same event types that production maps receive after native translation. This lets the tests exercise viewer input, hover and hit testing even though the isolated desktop does not deliver ordinary pointer movement. Only the environment-controlled suite enables the channel, and its listener is restricted to loopback. Points are client pixels, persistent modifiers mirror held keys, and wheel events use the last pointer position. For repeatable close-camera visual checkpoints without altering interactive frame-timed wheel zoom, the suite channel also accepts deterministic per-view camera placement and reset commands, waking the viewer immediately, replying with the active map's resolved clamped camera pose after seam wrapping, and confirming both the sought timeline hour and displayed pose through the map state report before awaiting `export_map` completion and validating the written PNG. The suite can also pin the export animation clock, so recordings replay through the normal layers with repeatable output. Window message translation itself has separate coverage.

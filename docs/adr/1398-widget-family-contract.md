# Declarative widget families with one projection for drawing and audit

Dashboard widgets do not wire playback loops, canvas surfaces, hit testing, tooltips, keyboard mirrors, or separate exact-read audit row builders. Every family (table, and any subsequent chart, card, or list family) upholds five contract properties:

1. **One projection for drawing and audit.** Each widget registers one pure, deterministic projection `(sources, hour, options) => model` with its family. The family runs that same function inside the worker lane to paint frames and inside the main-thread audit reader against exact replies (keyed end-to-end by `auditId` to the exact snapshot of options, settings, expansion state, viewport width, visible row window, and frozen gate that produced each painted picture, refusing missing ids rather than substituting a later snapshot). The painter draws exclusively from the resolved cell paint model (`resolveCellPaintModel`) and the audit (`deriveTableAudit` over `canonicalAuditData`) canonically serializes that same model by construction for the visible window—table chrome (visible column layouts, summary pill, notes, warnings, total row count, empty state), ordered group headers and data rows (rank, tree level/open, muted), every painted cell field (five-state value, format, bar fraction/alert/raw fraction, tone, status, country, icon/flag identity, iconSlot, missingName), plus each visible row's tooltip model (`deriveRowTooltip`). Transient interaction state (hover, selection, keyboard focus, glide animation, and rank-change markers) is excluded from audit comparison. Every painted picture emitted while an audit callback or exact reader is registered must carry audit rows; any unaudited painted picture fails the audit by name.
2. **Sources and time shape declared once.** Every widget declares its followed and exact sources, country policy, and time shape (`branch-to-hour` or `trailing-window`) in one place; shared family source primitives (`ui/src/families/sources.ts`, `holders.ts`, `cadence.ts`, `audit.ts`) derive followed, static (freezing one displayed static snapshot while a newer range is in flight so projection and exact audit read the same span), and exact-audit requests, dated slot holders (lowest covering country id, breaking ties by earliest `firstHour` then tag as native `Holders` does, retaining unresolved existence spans, pre-indexed and frozen for O(log N) boundary lookups), dated country colours, group coverage refusal (`hour` masks unobserved hours, `end` checks the endpoint, `ever` refuses when any gap makes campaign membership incomplete), faction coverage, and single-throttle trailing-flush mirror/tooltip cadence.
3. **Dated facts resolved at the model's hour.** Country existence, slot holders, faction names, player names, flags, colours, and membership are resolved at the projected hour (or a row's own observation hour when older) and advertise their next boundary via `nextChange`, never by looking up the end of the branch.
4. **Five-state values everywhere.** Every rendered scalar passes through the five-state value contract (ADR 1397), rejecting blank text and non-finite numbers and never substituting `notApplicable` for unread or unrecorded facts. Missing country or player names remain explicit `notRecorded` values with their reason, never internal identifiers or placeholder strings.
5. **Host-owned playback discipline.** The family host owns loading, outside, held, unavailable, error, and empty states, caches viewport geometry, focus anchors, and fitted tooltips outside `install()`, unregisters its exact reader on unmount, and executes zero React commits and zero layout or style reads while playing with unchanged structure.

For the table family, ordinary widgets declare their sources, country policy, settings, and columns as data (`TableWidgetDeclaration` + `declareTableProjection`); the registry renders `DeclaredTableWidget` directly so ordinary table widgets carry no component file, no time gating, no request wiring, no exact-read builder, and no body-state `WidgetState` code. `FamilyTableHost` subscribes declared sources on the playback `Pipeline`, binds a worker-painted canvas surface with fixed per-column numeric widths (avoiding per-frame text measurement growth and audit column-layout drift), and caches viewport dimensions and focus anchors from `ResizeObserver` so `install()` performs zero layout or style reads and zero React commits while structure is unchanged. The worker caches projected models and layouts across unchanged sources, builds mirror rows at 1 Hz while playing (flushed via cadence timer and immediately on pause) and audit rows only when requested, and paints only visible cells whose content or geometry changed since the previous frame.

Interaction is identity-tracked: pointer hover resolves to a stable row key (`inspectedKey`), a click acts on the inspected row even if rows reorder beneath a still pointer (cancelling on >4 px drag or `pointercancel`), and hit testing accounts for animated glide offsets. Hover (`fields.tooltip`) and keyboard focus (`fields.focusTooltip`) stay independent: hovering another row never hijacks keyboard pinning (`P` pins the focused row's tooltip at the cached focus anchor). Keyboard focus lives on visually-hidden mirror `<tr>` elements, moves with the focused row across re-sorts, and draws a 2 px accent ring on the canvas.

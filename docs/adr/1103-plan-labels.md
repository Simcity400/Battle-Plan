# 1103. Format a battle-plan label only when layout reaches it

Use the content's arrow font and compose full, middle and short variants lazily. An unused key or unsupported control in a shorter label cannot refuse a full label that fits. Combine localized prefixes and postfixes with the stored unique name or its localized name parts for move and transport orders. Line orders omit that name. Use the recorded display-group name and the number of assigned divisions excluding its active HQ. Native label keys take typed string and integer arguments. A missing top-level key renders its own text and an undrawable used operand refuses its variant. Only the reached full variant above the authored control threshold demands the convoy or transport count, whose signed result includes zero.

Split the usable controls by x direction, merge brief reversals, and use the longest run oriented left to right. The last control remains outside the text path. A run wider than the path proceeds to the next variant. When a glyph center passes the end, retry the full usable path once in its chosen orientation. Lay out one line with a centered pen and place each glyph along the path using the averaged neighboring segment headings. Preserve original stored-control indices for height sampling. A missing glyph breaks kerning without advancing, including the native currency control. A zero-height glyph advances without painting. Match the name pass's corner order and atlas page. Draw labels after the ribbons.

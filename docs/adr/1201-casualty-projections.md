# Casualty charts separate exact recorded accounting from geometry

A casualty pair identifies its endpoints by native holder and keeps their direction, with source dealing losses to target. Successive holders of the same tag remain separate and a holder cannot occupy overlapping aliases. A saved pair selection belongs to one campaign and branch. Native sums can exceed signed 64 bits, so their exact signed counters use `bigint` with the wire range validated. Absent relations contribute no geometry and stay distinguishable from observed zero amounts in the detail. Only positive amounts produce ribbons, slices and chart proportions. Exact details retain signed corrections, zeros and totals. An unrecorded or unloaded window clears the corresponding graph, and an hour's confirmation can update read dates without replacing identical run geometry.

The followed chord resolves its membership at the read hour, and keeps names for all holders its held windows can display. Ask again when one of those identities changes. If a frame reaches an identity change before its name read, use muted geometry until the correct date's name and colour arrive. In a pinned view use the shown hour. Dated flags follow the viewport and keep the last observed holder for an ended enemy. Sorting and labels share that naming rule. Choose history windows from the time-chart viewport and replace the held range only when it reaches different blocks, then release windows no longer needed. A country's breakdown counts each native lifetime once, with missing or overlapping war membership identified explicitly.

Total and race charts use the game's retained Combat Log. A ranked row remains named across pushes while measures for a new top set arrive, so returning holders can paint without a new name request. Keep the last complete set until the new measure answers have arrived. Pinned and ranged views ask for their own read hour. Rank by dealt and known taken losses, using tag as the tie break and leaving a top list short when the remaining rows have known zero losses. Unknown attacker losses do not affect rank, and can be included in the displayed taken amount. A partial total after a lifetime disappears in a gap is a subtotal. An unknown taken amount cannot enter a race, and a nonpositive reading clears existing positive geometry.

Bombing damage uses the same building-by-dated-state projection for the widget and drill, naming states once at the view end per holder. A followed view paints fractions between structural changes. Final values wait for every required window. Campaign clock totals likewise paint from the followed command-index snapshot while following, and query the displayed hours in pinned or range views. The last answered snapshot supplies its own coverage and warnings until a replacement lands.

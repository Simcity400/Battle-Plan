# 0705. Preserve raid graph identity and independent refusals

The collector observes a country-indexed graph at the acquisition boundary. Country handles resolve against the country-link table. Each instance keeps its native reference as its key and the original vector position for presentation. Sorting completed rows detects duplicate references without allocating a second set. Parent, cooldown and instance rows use separate bounds and share caller-owned arenas for eligible and used type tokens and the raw show-for country handles. A short arena counts full demand for off-thread growth and cannot yield a complete prefix. The type memo is sized from the raid database. A type-demand pass reads only the batch headers it needs.

The raid instance preserves its native phase, outcome, preparation and distance. Taking the preparation phase begins with zero progress and consumes its accumulated whole hours. Distance is signed fixed-point, advances at raid speed while in progress and stays available after the phase changes. An absent outcome and a false detection flag have native zero encodings. The detected flag controls the incoming-raid icon. Unknown phase and outcome enumerations select their absent text key. Assigned army and air-wing references are reciprocal while held and are cleared when the raid ends. Type tokens come from the native definition and use zero only for a null definition.

Source kind is meaningful only when its presence flag is set. The full ship reference remains distinct from the source location. The source preserves raw country and building fields even when a different kind is selected, including the native absence encodings. A building location refers to its province or state according to the building kind.

A target retains independent province, state, building and leader arms. A missing arm uses its native absence value. Province selection prefers the direct province, then the target building's province, the secondary province and finally the state when permitted. Building flags identify a province or state, and a positive building country overrides the location's controller. The reader reaches the leader only when the earlier arms are null. An unresolved reference can fall through to the leader's province, while a resolved object whose captor is unproven refuses its row. Only the authenticated army-leader layout proves the captor field. Other leader classes have no verified equivalent. The shared reader exposes a single refusal state so both cooldown and instance rows account for it in truncation without inflating arena demand.

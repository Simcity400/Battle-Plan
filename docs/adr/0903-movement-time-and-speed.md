# 0903. Apply movement terms only to the route edges that demand them

Progress uses the recorded movement numerator and the ordinary first edge, including when a model draws an alternate route. Division and railway-gun embark edges use the authored sea-to-land cost. A truncated route cannot establish a complete estimate.

The estimate walks each non-self edge at its own speed and subtracts progress at the actual first edge's speed. A self edge can supply progress and require a speed even though it adds no leg. For a prospective route, subtract progress only when its first edge matches the recorded one. An empty route needs no speed. Hostility, organisation and invasion selection still use the actual route. Keep the game's signed fixed5 fraction, including zero-divisor and exceptional numerator sentinels. The ordinary estimate exposes remaining first-leg and destination times.

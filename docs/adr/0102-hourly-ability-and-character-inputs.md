# Acquire ability and character operands hourly on workers

Active abilities change at any hour. The Ordinary worker reads their headers over the authenticated country roster, grows rows and token bytes from the original headers and publishes the ability grid's operands for that hour. The cached roster supplies country authentication, so the walk costs one guarded header read per country and three more per record without an optional caster or region. Performance tests count the walk separately from table accounting. The scale fixture deliberately overlaps synthetic country objects because it only populates the fields that path reads. Vacant capture buffers permit the handoff without making the game thread allocate while the worker owns the prepared buffers.

Character-scope triggers need country-leader, advisor and scientist traits and every nonzero operative reference with its resolved operands. The Gated worker normally borrows the admitted role census to avoid another roster traversal. It carries certified country-leader and advisor rows across quiet hours while the observer can prove that their writers did not run. If the census is unavailable, the worker walks the roster and forgets its carried rows. For a frame whose buffers already contain the fully certified role-trait table, the worker restores its outcome and arena length. A walk or failure clears that hold, while resetting output state or growing the buffers preserves the stored data.

Sizing can observe the live walk without row storage and raises retained demand with headroom. Each trait operand carries its token and optional definition value. The captured role key already contains the character, kind and role, leaving the payload comparison to the trait values. Capture failures and out-of-range spans produce explicit unavailable outcomes.

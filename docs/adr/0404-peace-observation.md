# Observe peace outcomes before their source history is dropped

The roster and the finalized settlement are separate recording observations. The hourly walk records every resident conference, including queued conferences, without depending on window refresh. It authenticates each nonzero pointer before reading subtype fields. A readable empty roster is distinct from a refused one. Captured records retain roster ordinal even when sorted by handle to check duplicates. Missing capacity accounts for all remaining rows.

The settlement is copied after finalization sets the flag and before it destroys the bidding history. An immediate conference can finalize between hourly reads. The full conference reference is registered at startup and no country or player filter narrows this observation. A resident save can compare bids at its own hour, while a completed save has already lost that history. Changes in state ownership and conference messages do not recover missing action history or establish the associated war identity.

The settled history keeps the native country, turn and action ordering and excludes statuses three and four before reserving space for their operands. Bids and reduced outcomes are separate because an accepted demand does not always transfer a state to its taker. Automatic state outcomes have no inferred action token or giver. The recorder authenticates each action's concrete form independently of its token and refuses unsupported forms. Puppet auxiliary data stays opaque. A government action has a shorter span, so the copy ends before that auxiliary field would begin.

Beneficiary outcomes retain the ordered state pointers, and automatic civil-war outcomes retain the ordered signed state IDs. A subject action distinguishes the overlord from the selected country, whose reference can be newly allocated. A state action stores its demilitarization, reparations, resource rights and industry dismantling flags in that order.

The navy naming key is read from the installed image. Acquisition validates that a terminator is present, and the collector publishes the bytes up to that terminator. A navy action with the native null selection retains a zero handle, while other forms have no selected-ship operand. An actual selection requires independent ship identity authentication. The raw action token, cached name, status, cost and original country references preserve their native values. The cached name can contain a saved override and stays separate from the contextual display label.

Preallocated snapshots stop at the first capacity limit and report a lower bound on omitted values plus exact demand for a name that did not fit. Off-thread sizing reads backed source headers, including rejected bids and empty turns for the live bid path. It reserves from an array header only after the last element is readable. History traversal validates country keys through the live roster and refuses invalid links using a bound derived from the native node count. Off-thread sizing also detects cycles. A failed read does not turn partial operands into an exact settlement.

# 0103. Preserve ordered division names across parallel ranges

Each naming range acquires its members into owned arenas after the hour takes its status-store loan. Only the admitted census prefix is named. Stitch the first range's arenas into the destination intact, append later arenas while shifting their offsets, and store successful reads in census order. Missing or failed range work withholds the hour's naming. A single full range runs the same acquisition.

The language-neutral operands and cached display text can share a native member copy. Their output arenas and refusals are independent. If the full span fails, a cached name can take its own reads. Heap display text uses one copy into already available space. Each parallel range starts with twice its prior proportional byte demand and a single range keeps the prior allocation. The resolved generator still supplies a programmatic override when its name group is absent.

The held store is read-only for these ranges. Register fresh member reads with their writer watches. A held span and cached name can be reused only for a member registered under the take's epoch that no member or country-wide writer touched. The template group and heap override still need their own reads when reconstructing operands from a held span. If the touched list cannot be retained, reread every member. Used staging is at most one receipt per admitted division. An optional copy of the held ordinals lets the ranges stage attack reads under the same admitted maxima. Losing that copy leaves attack reads to the ordered pass.

# 0403. Capture stored air-map operands without presentation state

## Mission operands

The flying-aircraft map recomputes admission and counts from the recorded simulation operands. The stored mission efficiency and count can lag because their native writer runs only when its period, capacity and combat conditions hold. Keep modifier metadata and the sortie calculation in playback and copy the raw values during capture. Coverage is signed fixed5. Reached entries contain province ids and distances. The vector and region pointer are acquisition context, and a zero last-target id denotes absence.

Reassignment scales efficiency by the complement of the stored penalty and a changed region resets that penalty from content. The console efficiency override for a matching effective-country slot precedes other terms and clamps. CAS diversion and interception tracing have separate stored operands. Current execution is independent of the enabled mission mask, and effective aircraft are reached only for nonzero execution. The worker supplies its exact execution observations, including individual failures, to downstream readers.

Gather the required mission operands and optional leaves together when possible. Fallback requires all mandatory fields, while independent optional reads can leave their own values unavailable. Reached province ids and pool definitions use separate reads. Definition gathers keep a completed prefix and repeat the failed entry and suffix through the serial reader, including its rule that the authenticated null definition yields zero flags. Record each fallback when it starts. Share the original worker cache across mission batches and read retained aircraft counts only for executing missions within the fixed gather. A failed leaf remains unavailable after its applicable fallback. Off-thread sizing retains demand but leaves operand acquisition to the actual pass.

A failed detection leaf can leave its peer readable. The console's detection-vector writer is the first/change-only acquisition boundary and the header supplies demand. Effective-country and weather-region sortie entries share the modifier definition, whose metadata identifies the clamp, feature gate and whether the feature-flags callback supplies a mask. A successful authenticated weather manager and its regional records are shared in the same worker pass. Country containers are read once per base and selected by canonical slot. A null slot contributes the law's zero operands. Base controller admission requires a match in the raw outgoing volunteer-host vector.

The spotting-factor cache uses the simulation mask's width and holds the first result for each mission kind. Patrol readers reuse an existing selection result including failure. A demanded patrol with a held clock uses the cached last-applied night factor, while an updated clock uses its existing certificate. Clear update gates need no held marker. Take only the demanded region's sampled province and the raw accumulator entries used by the combat fold. The accumulator writers keep keys sorted and unique, enabling these reads without copying the rest.

## Base and carrier identity

Air bases named by a wing pool or transfer resolve through the reference registry. A transfer gate excludes a wing when its full handle resolves, while a registry miss remains a miss even if the manager roster lists the handle. A state base uses its cached province when present, then the first province in the manager's state and kind list. A stateless base instead follows its authenticated host to the task force's roster owner. A resolved ship with no task force is a separate state. A base's full host handle is resolved independently of its state association when the count operands require it.

Use one reference resolver per quiescent pass and cache complete manager and province data only after validation. The batch path reads each first bucket, then base fields and the state and province identities. Reuse the completed prefix in serial check order. At the first refused or incomplete result, read that entry and the suffix through the ordinary per-object path. A persistent fault must produce the serial result and a transient fault may be recovered. The regression fixtures use valid collision paths and exercise cached provinces, fallback lists, misses and failures across batch boundaries. Healthy gathers reduce guarded calls without changing witness results.

An ordinary carrier uses its task-force stance to select an authored sortie ratio and must resolve to its ship's actual carrier base. A hosted rocket base takes no stance ratio and can contribute the eligible fleet leader modifier. A state base has no host operands. The leader cooldown can suppress the modifier. When the host task force is in combat, the mission needs its matching region and bit zero or two in the mission mask. If a host ship is stale or unresolved, a wing already rejected by a prior gate can be omitted without withholding the hour.

State rocket capacity comes from the first building with a positive missile-slot weight in the active-building vector. A hosted base instead uses the corresponding content define. A complete state read with no eligible building or a zero aggregate produces zero capacity, distinct from the hosted-base result. The first contribution array uses separate signed maxima for flagged and unflagged entries. Only unflagged entries from the second array add to the result. Preserve the game's signed low-word arithmetic, including negative and wrapped values.

## Regional supply and modifiers

Regional sortie efficiency uses the region object pointer to look up a country's region-specific modifier. Hash the little-endian pointer bytes with the native FNV-1a key. The bucket stores its last node and first node in that order. Lookup starts at its first node and walks through its last. The mask is one below the bucket count. The sentinel or an absent accumulator key produces an absent operand, and a malformed map, invalid identity or short read remains an error. The matched object's pointer stays in acquisition context to identify the modifier certificate.

Regional air supply is acquired every hour since the game completely propagates it each hour. All consumer kinds have a common span from province through from-state amount. Batch that span and the referenced origins, provinces, regions and owners. Obtain the first registry buckets together and continue each probe from its own result. Resolve an air-base owner through its province-access rule. Sort regional rows by country and region with the country total last, and withhold a country's incomplete result.

## Foreign homebases and radar

Foreign-homebase rows preserve native array order and duplicate provinces. Validate the supply system and country backlink, then check the repeated province id within each node. Supply, start, penalty, duration, elapsed hours and decay are signed fixed5. Elapsed time advances a unit each hour and can reset independently. The additional penalty is available in memory although the text save omits it. Copy literal source strings byte for byte and check the binary base flag. Read each string header for exact demand even when storage is short, and gather numeric ranges around the header already read. Omit a whole row if either arena lacks capacity.

Radar groups lack a vtable. Validate the pool first, then require allocator alignment, authentic vector headers and a backlink to that pool. The group ordinal can change after swap-removal, so its host state is the closest stable name. A null host state is absent, and resolution through a country alias still has to identify the same authenticated owner. Reserve from original group and coverage headers and retain demand for omitted rows. The census supplies authenticated group and host identities to the symbol cache. A group with an authenticated host can read the signed fixed5 cached radius under its radar-writer certificate. A partial gather preserves the established validation and owner-resolution order.

# Compare economy pools at native precision with independent row coverage

`CountryResources` must contain a row for every captured country and definition. An all-zero missing row cannot be discovered from the text save because the serializer omits zero amounts. Compare that census separately and then join amounts by country tag and recorded resource spelling. The second `to_use` measure compares as the second use pool less the first. One missing spelling does not suppress comparisons of other resources. [Economy comparison](../../crates/recorder-oracle-economy/src/economy.rs)

A name can refer to multiple definitions. If all occurrences are serialized, they match definitions in index order. A value omitted under a repeated name cannot establish which definition held the zero. Compare the recorded nonzero sequence in order under a named limitation and reject an extra occurrence. The supply save omits a country without any owned state. A saved receiver or resource field is omitted only under its respective null or nonpositive native condition. An omitted subscriber for a route requiring no convoys leaves both counts zero.

Fuel ring sums cover the 24 serialized slots and exclude the pending entry. Consumer entries compare by country and array position. Retired rates, consumption and ring fields have no recorded comparator. The applied fuel day sums are already aggregated and no longer have a saved per-update witness. Other recorded fields still compare exactly even when their neighbouring fields are retired. The logistics save holds stock and balance for non-AI countries at the saved daily window's current index, with contiguous equipment entries. Coverage in either direction is required.

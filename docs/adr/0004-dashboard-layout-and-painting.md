# 0004. Keep dashboard layout stable while playback paints

Virtual lists agree with their stylesheets on row heights. The country and content pickers share `COUNTRY_ROW_HEIGHT`, and the row logs pair `ROW_HEIGHT` and `MONTH_HEIGHT` with their stylesheet. The viewport clips wide log rows so mounting an item cannot add a horizontal scrollbar and change which items fit. Card logs and wrapping tables reserve a vertical scrollbar gutter so crossing the overflow threshold leaves their width and measured heights stable. Pending or refused log pages hold their counted height, and compressed scroll placement rebases immediately to keep the same row under the pointer.

The chart canvas and its dates stay put when lanes scroll. Legends name both solid and dashed series so the stroke alone never has to identify a series. Tooltips keep designated rows on one line so their maximum row count bounds the height. A row log moves its rows through a shared transform that occupies no scroll space. It paints entry through one flash and cover layer so revealing a row does not restyle the row on every frame. Dashboard tables keep native table semantics and mount the viewport's rows. They use the frame engine for bar scales, row motion and fades. A transition on every row caused extra compositor layers to be restyled every frame. The table, meter, live status pulse, and project and focus progress indicators use transforms or separate opacity overlays to avoid repainting content as the clock advances. The appearance setting controls whether those effects run.

The playhead uses the slider for input and separately paints its progress from the clock. The header's country and tools tracks reserve their widths so playback controls stay centered when the selected country changes. Prepared dashboard pages lay out offscreen at the same size as visible pages. Layout containment keeps widgets in their grid slots while letting the drag shadow extend outside its cell. The widget itself carries changing state since selecting the grid cell by a descendant caused grid-wide invalidation. A docked panel narrows the workspace so the native map can measure its new viewport and stay unobscured.

Theme roles and scale tokens come from the user's appearance settings and drive the shared CSS. Focusable unavailable choices retain a tooltip explaining why they cannot be chosen. Pickers retain accessible labels when a visible heading supplies the caption. When compact layouts omit a name, the row tooltip carries it. Game art uses the same slot as the named fallback so an unavailable picture leaves the geometry stable. Styled flag art already includes its mask and overlay and is fitted whole.

Wide mod-provided operation lists scroll within the chip group. Research lanes share a row height so a slot that opens later starts at the right point in the common history. The research detail uses one time axis, with solid blocks for elapsed time and translucent blocks for time saved. A stable grid for each resource row makes it a single focus target while retaining alignment of its values with the other rows. The recorder panel reserves its footer and gives the content its own scroll surface when the screen clamps the window height. The recorder mode cards use native radios for keyboard and assistive technology. A saved recording's row opens the recording, and its folder button retains a separate action.

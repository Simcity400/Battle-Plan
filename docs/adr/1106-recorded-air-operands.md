# 1106. Keep recorded air admission, execution and range inputs distinct

Regional wing traversal visits the viewing country, then two independent ordered country rosters. Each roster preserves the first raw reference for a canonical country. Identical raw references match directly. Canonical equality only aliases nonzero raw references, so a corrupt zero link cannot equate a real reference with raw zero. The ordering uses outgoing volunteer hosts, including their repeated entries, and reads only reciprocal donors for reached countries outside the viewing country and its hosts. A canonical slot need not be a raw key in the links table.

Detection starts from recorded execution and raw modifier terms in the game’s evaluation order, and clamps the final result. Selected missions, current execution and visible sorties are distinct. The selected bombing bit is tested in its own branch, while some bonuses require an execution target. Night and weather are demanded under their own gates. The index decodes country terms once per hour in the counter accumulator’s purpose order. Console overrides need a certified complete vector to distinguish an absent override from an explicit zero. The ace scale is shared with fuel normalization, and an unassigned ace needs no wing census to prove its scale is one.

Raid gates and battle-plan labels share wing-range arithmetic and retain their own table admission. Conflicting rows for a handle are distinct from a table-wide read failure. The table groups by country before wing handle, so a whole-table lookup cannot assume a single global handle ordering. Ace modifier rates come from current `CountryCommandPower` and diminish with recorded assignment size. The map conversion uses wrapping fixed-point multiplication. Its validity check excludes the maximum, minimum and minimum-plus-one signed values without decoding them as fixed-point sentinels. Invalid input and a zero scale return the map range sentinel.

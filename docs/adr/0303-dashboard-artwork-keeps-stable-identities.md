# 0303. Give prepared artwork stable content identities

An artwork reply carries the URL of the exact PNG bytes it prepared. The in-memory table keeps a content address for each PNG. The desktop can also persist those bytes for another process to serve the same address. A persistent entry is published whole and checked against its name on read. A failure writing the folder keeps the image available in the current process. Saved prepared replies carry their images so they can restore the same URLs before serving. A transient image that will only be drawn once can use a PNG data URL without retaining it in the table.

Artwork resolves from the presentation stack. If a visual mod cannot supply a drawable, the fallback restarts the operation from the recording's sprite definition and files and credits that fallback to the consumer. It does not retry a mod declaration with a different stack's files. Strict and fallback-permitted draws use separate cache keys. When choosing alternative names within a stack, only an absent declaration permits another spelling. Text icons try their `GFX_` form first. Existing but unsupported declarations retain their refusal.

Texture loading goes through the same native resource resolver and decode state as the interface. Bare textures can show one frame of a strip with integer query extents and fractional native geometry. A declared sprite runs its stack-resolved Up-state program at time zero, with its mask and other authored inputs. Positive frame indices keep their native positions even beyond the declared strip, and only in-strip frames remain in the cache. A batch with a refusal can retry the affected draws individually so one bad frame does not hide the rest. Shader and sampler combinations unsupported by the viewer report which asset was withheld.

The shield draws the flag with the shield's mask, then any declared loadable overlay with its authored blend. The overlay's extents and the texture's native placement govern framing, including fractional mask centering. The flag atlas and placement are not available in the recording. A standalone flag texture is equivalent only when compiled stages establish that the atlas rectangle maps its texture coordinates. A program using the rectangle for anything else gets a named refusal.

# 1303. Separate recorded overlay inputs from presentation state

Selected-unit paths and first-edge progress are recording facts. Selection, the expansion clock and the first route that seeds its rate belong to the viewer. Resolve declarations once through the recorded content and refuse only the units that reach unsupported styles. An unusable visual mod texture can fall back to the named recorded resource. The scene prepares selected arrows once before the wrapped views. An admission miss clears expansion and retains the route. Hidden arrows still establish the retained state subsequent native producers expect, with their render passes omitted. A failed reached declaration leaves its inputs unknown so a later producer cannot accidentally inherit an earlier binding.

Selected arrows bind their type before testing each ribbon's frustum. A missing program preserves the existing declaration and draw state until the native submission changes it. Only the first four pixel sampler slots are set and the vertex stage retains its bindings. Submit the ribbon with its partial constant allocation. The written prefix is known, the uninitialized tail is unknown, and reads beyond the allocation are zero. Restore the scene rasterizer even for an empty selected-arrow pass. The ribbon smooths movement controls before expansion, uses the existing movement spline, carries the previous raw normal across later intervals and samples both edges for the shared higher terrain height. No extra lift is added. Chord length, accumulation order and the final chord affect texture distance.

Battle-plan ribbons share one draw field. Plan, raid and trade inputs keep producer order, and air orders replace the air-mode ribbons. Vertex storage places the changing plan last, so its length cannot force uploads of the other families. Partial uploads join neighbouring changed chunks and preserve all strips, order and labels. The map's interface and family visibility gate both draw and shadow. Plan shadows follow mesh and tree casters and precede receivers. A plan label follows the arrow's admission even when its own glyphs would be culled. Clear stencil after the two mask passes.

The particle instance declaration leaves its trailing record bytes outside shader input. The largest ordered world-column length determines scale. Point lights come from authored entity events, attachment transforms and presentation clocks. Combat state alone supplies no light. Reconstructed clocks and missing events report limitations. Terrain and ribbons share the tiled light inputs, with no binding change for unrelated passes. The camera origin moves by cells, and the grid keeps the first admitted lights in each cell. Native coordinate conversion truncates before mapping to cells and preserves the inclusive upper bound. Cache tile data and upload only changed textures.

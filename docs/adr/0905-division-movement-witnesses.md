# Qualify land movement and census facts at their supplying read

Division counts use the same completed read as the roster. Apply the positive expeditionary owner before the roster owner and preserve their raw alias identities. The complete read can prove a canonical country's zero count. Incomplete counts cannot prove a partial total, and a carried value cannot certify an unavailable census hour.

Read daily supply nodes and inventories in the same country slice and keep its supplying hour. Parent links name provinces rather than node indices. Extra vertex rows let a recorded parent chain stay inside the companion; preserve native IDs even when they do not resolve. The absence of an ordinary route uses the native fallback value. Preserve route order and duplicates and reverse land parts only during presentation. Inventory order and duplicate or null equipment references remain exact. Use the shared sparse controller-access bytes by canonical country slot, with denied access outside the stored extent or at a stored zero. Sparse bytes preserve logical length and store maximal nonzero runs in index order. The little-endian header and gap-and-length encoding admit one representation per native array. An omitted byte inside the length is zero; an index outside it is absent.

Keep the historical division speed graph framing so old recordings can discard tables by name. Current end-user ETA is derived from routes and base speed under the recorded content stack. First-edge speed in a historical graph had its own value because its call could pass a null destination. Its stored terrain inputs describe only reached terrain. A current mover reads exact base speed from its same-hour panel word, or from its own capture when no equal panel value exists. Only the ordinary positive path reaches that movement calculation. Keep stationary units' fuel reads for their panel speed. Strategic status keeps the reached native path, target, class and retreat gates and withholds only the glyph on a failed read. It does not imply ETA age. Transport speed follows the logical owner and recorded region. Same-hour full combat references preserve native occurrence order and repeats independently of assigned-unit transport operands.

Keep the active stat block's exact attack and movement inputs under its rebuild certificate. Panel words and suppression retain independent optional leaves. The panel's maximum normally supplies the status values, with a separate status read when needed. Map-only captures read their own model, camouflage and exercise witnesses. Normalize experience using the native manpower ratio and sentinel. Experience and officer experience can be held off-slot under their daily, first and full read policy; the exercise predicate remains hourly. Pending conversion can preserve an older full template reference. The panel source retains a witnessed country even when commander selection fails. Preserve the name member's actual template reference independently of the division template, including a deleted target the save can rebind later. Exact retained name bytes and named generator operands are separately available.

Apply the ordinary or separate HQ commander's modifiers using the same selection as the native entrenchment query. Raw absent keys differ from a refused selected block. A land or border-war combat on the first matching attacker side supplies its movement word only for the reached non-withdrawing branch; a reached naval combat contributes no land term. Exile, noncore supply bypass, air supply and low organization use separate branch witnesses. Preserve an independently failed demanded branch rather than using the display approximation. Retreat bans are evaluated at each hour using the reached side of a combat and are carried under the commander's modifier writers. An unresolved roster owner truncates the read, and older daily rows do not prove this hourly behavior. The model number's suffix uses the stored signed low byte. Camouflage recording applies the live threshold to the first greatest positive weight and a resolved non-null category so only a winner or threshold crossing changes the recorded category. Location-based camouflage conditions remain playback inputs.

Land combat progress is derived from ordered same-hour rosters and organization; direction follows the first attacker with a map entity. Exact loss counters are separately dated and a changed manpower count need not re-encode equipment pools. Tactic unlock vectors retain native order and source definition identities, resolving trigger tokens from content. Railway cooldown rows retain the selected source building for the reached domain. The acquisition hour is outside the selection vectors so a new read of equal vectors does not change their payload; a carried selection cannot witness the current gate. A proved unbound railway building shows the native damaged state.

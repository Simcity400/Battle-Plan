# 0706. Preserve theatre identity, ordinals and independent table outcomes

Land theatres and their named theatre groups have separate identities. Each row retains a full reference and its actual position in the native vector. Membership does not drop repeated occurrences or treat an orders group's low reference type as a subclass discriminator. A group's priority assignment applies the native clamp, while loading can restore a retained value directly. The theatre roster is canonical, but the theatre's stored owner remains raw and can be an alias. The actual slot-zero roster, when present, has its own outcome.

The canonical land walk reads persistent headers and can also acquire the separately requested daily nested land and air data. Native name bytes use caller-owned arenas. Completing a header uses one record of identity, owner and volunteer fields. The ordinary fallback preserves ordered scalar semantics. The special slot-zero path retains the first failed span. Failure in a daily child cannot invalidate an hourly header. Land and air acquisition outcomes are separate. Header-derived sizing retains the full native row and byte demand and omits whole rows on shortages. Worker storage can grow from the already read headers.

Reverse group membership follows an authenticated orders registry or authoritative air-wing visit. The parent needs its own identity when nonnull, and leaving a group retains zero. A unit's land theatre resolves only through its roster country's authenticated theatre vector. Reuse that vector only in the current capture, and refuse an unrecognized nonnull pointer. A null theatre produces zero. Duplicate row identity and reverse wing membership are checked at complete-table boundaries.

Only a positive signed volunteer key admits the theatre's controller areas and stationed units. The theatre header still retains the signed key for every row. Area and unit outcomes are independent. Their counted vectors must be complete, and a hole, bad header, unauthenticated element or zero required identity refuses the dependent table. Province reads advance through every bounded batch, and only divisions and task forces are admitted as stationed units. The controller-area vector and the stationed-unit vector are separate native sources for visibility.

# Replay air-base projections from one owned acquisition

AirBases, AirBaseRegistrations and AirAces share a worker acquisition. The census comes from the callback's authenticated roster when its snapshot can be retained. Otherwise the worker records the native country census reads, including the reserved-country test. The manager, base vectors and base identity reads are shared by the first two walks, while ace rosters and name strings have their own spans. Private failures stop only the affected walk. Shared failures stop every walk that needs that input. Discoverable subtrees can still be counted after a census fault, but that fault makes their sizing hints ineligible to publish a complete registration result. Each worker grows from original header demand before the handoff. Count-only hints and optional carrier demand leave the predecessor's observation and capacities independent.

The raw mirror keeps the typed walk's order and span shapes, including whole pointer chunks and field-level takes. It retains a completely copied prefix for native validation before reporting a later failure, so a later pointer fault cannot hide an earlier container refusal. Identity validation happens before consuming typed fields, with null slots treated according to the native vector's rules. A country's first successfully staged link is authoritative for that pass. The direct-map index helps find it, while collisions fall back to the authoritative list. A failed or invalid resolution does not become a cached success. Repeated native base, pool and wing occurrences remain repeated observations when that vector permits them. For heap names the walk records the terminator and then content. The portrait tail is optional and uses the same descriptor reader again over the owned bytes. Its failure leaves an already available prefix in place.

The registration mirror uses the dense slot plan only when it proves the occupied slots. The plan and replay share its exact slot-word observations and the same acceptance tests. The plan relies on the observed writer family keeping the list and vector in step. If the mode or witness refuses that proof, use the complete-slot path. A state base can request optional summary inputs only on a fresh read eligible to hold the segment. A broken certificate or pool backlink is insufficient to poll those inputs. Each state-base membership and handle certificate is taken before the facts it certifies. See [Air-base carry witnesses](0102-air-base-carry.md).

Decode prepares the current worker's logical capacities before comparing. The single-worker memo owns one complete prior result outside every pooled job and frame. Reuse requires the same attachment, adjacent sequence and hour, matching roster observation and exact logical capacities, and the same ordered span fields and used bytes from a fresh acquisition. Active slot faults, missed staging, a typed fallback and incomplete decode clear validity while keeping allocated storage. Inactive slots and spare bytes are outside the witness. Preserving ordered spans preserves exact-before-bulk lookup and independent repeat cursors. Bases and aces share one recorded reader; fog registrations start another over the same log. A refusal in base or registration preparation leaves the independent ace outcome intact. Optional state registration segment reuse is independent of the memo's whole-family key.

The worker's staging refusal can send a frame through the already-admitted typed fallback. A failure after owned staging is accepted publishes a named refusal and does not reread live memory. Tests compare the typed and owned results at exact fit, short capacity, repeated identities and shared or private faults. The dense-plan differential fixture deliberately breaks the writer premise and confirms that a whole scan finds an unlisted slot which the plan is allowed to omit only under that premise.

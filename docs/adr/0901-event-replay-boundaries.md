# 0901. Resolve family events and scoped replay at their own hourly boundaries

Handlers read the pinned version at the delivered call hour after that hour's events, even when decoding has advanced. Declarations and relations are family-local. A declared foreign observation can be read from its metadata without calling or waking its owner. Subscriptions include only a family's filtered events plus mandatory notifications and due timers. Membership changes take effect during the call, and a newly selected existing row is delivered before later lookups. Membership notifications compare the start of the hour with the settled end, including composed causes and status changes. The declared event ordering key identifies the event within an hour, so an independent emission sequence cannot override it.

Observation spans run after the previous call through the current hour and can include unknown intervals. `Never` emits no `Observed`. Terminal delivery still includes the remaining spans when no real call follows. At any hour in the known interval, false is the complement of the recorded true and unknown intervals. Before the stream begins or past its metadata watermark, truth is unavailable. The metadata watermark follows the recorded truth independently of the family's delivered-call watermark.

Closing a key at a call hour includes that hour, retains its earlier inputs, and freezes its outgoing summary fields. The family cannot reopen it or write an outgoing summary field after the close. Window replay restores only the scoped keys and their timers and verifies each key at its own close. Its output supplies those outgoing dependencies while the rest of the transfer stays with the original pass. The provisional pass returns its reduced transfer, resolved passes return the resolved boundary, and the final pass retains state in the family. Prefix resolution and window replay run separately. Full-pass coverage and new provisional declarations cannot originate in scoped replay. A correction's observation hour is independent of the interval it corrects. An unclosed key remains open from the segment's first hour, and dependent indexes stay withheld until the retained inputs reach a resolved boundary.

Window subscriptions retain initial state, transitions, and call facts from the segment start. An empty field set retains call facts. Integer keys use canonical numeric order. The reader owns mutable selectors and handlers update them through `CallContext`. Allocate union storage for every raw insert before deduplication, including each bound relation and observation. A dependency point lookup remains logarithmic for paged sets. For timers, a reschedule replaces the same identifier. Keep the id index aligned with heap swaps and remove the identifier before repairing a truncated heap.

The event benchmark emits natural table order with relation changes interleaved before the global sort. Its event-buffer reuse clears every borrow before transferring the still-admitted allocation to a vector with a new lifetime.

# Retain native sprite registration and container interpretation

Sprite registration matches exact bytes and uses the last authored declaration in native file order. If the last declaration is refused, it still hides an earlier declaration of that name. A consumer asking only whether a name registers can still find it. Keep the parsed facts separate from the drawable projection; a progress bar can have two textures and no single texture field. Normalise layer-relative asset paths without discarding the authored text. An unrepresentable name cannot key this projection. Preserve full declaration bytes for later lookup and decode each retained declaration only on demand. A stray closing token ends its active reader; end of file closes all open readers. If a coordinate depends on an uninitialised conversion, record the refusal.

Both bitmap readers normalise row order to top-left origin. The shipped map files overreport the pixel bytes, so use the file's true length to bound the pixel array. Four-byte stride padding is separate from each row's pixels. Unspecified palette entries remain zero and declared BMP palette colours are opaque. Validate dimensions with the complete DIB header and verified file length before allocating output. Opaque provenance on immutable bytes leaves the payload intact across an unwind.

DDS surfaces preserve BC blocks and their format and colour space for direct upload. Keep the little-endian 16-bit packed layouts and sample their component fields with UNORM semantics. Cube faces use positive then negative X, Y and Z, indexed before their mip levels. A decoded RGBA image adapts to the same surface shape with one face and one level. Targa's native route accepts raw or run-length true colour without a colour map. Preserve orientation bits, 32-bit alpha and native shifting of 16-bit channels. Detect packets or reads outside the supplied buffers instead of making up bytes. A zero-sized native source may pass this stage but is refused at texture creation unless padding fills that side.

The generic image fallback selects a decoder from the file's bytes, routing JPEG to the IJG 9a reader and BMP, ICO, PNG and fallback Targa to the Rust `image` library ([0606](0606-texture-loading-parity.md)). Unrecognised or undecodable inputs produce a named refusal, the final output is straight RGBA, and the retained format determines how zero padding samples.

Windows pointer assets are decoded only if they contain one uncompressed 32-bit cursor image per frame. The stored height includes the colour bitmap and AND mask, and the hotspot uses top-left coordinates. Animated cursor playback reads the RIFF frame and timing chunks, applies ordered frame indices and times in sixtieths of a second, then repeats.

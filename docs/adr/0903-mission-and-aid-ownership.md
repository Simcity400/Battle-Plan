# 0903. Resolve ownership from the authority each game calculation reads

The division census uses a positive expeditionary source owner while its host remains the roster owner. Volunteer attribution takes the division's logical owner. One alias can own a sender's volunteer list, and a complete empty table establishes an empty list. Missing ordinal positions withhold the whole list instead of yielding a partial count. Null and unresolved division references are skipped as the native roster skips them. Deployed manpower retains repeated references and signed wrapping, and demands exile eligibility and sender contribution independently.

War participation preserves native side occurrence order, including repeated entries. The selected participant is included at its native position and appended when absent. Delivery-history operands are restricted to the demanded same-side participants after removing the selected country's aliases. Fuel is summed for the side before the signed dword conversion.

Air mission counts use registration order and retain repeated occurrences. A negative total resets before the next wrapping addition. A nonpositive signed mask selects no missions, while a selected bit receives the entire wing aircraft count. Counts are independent of effective mission country. One wing index and stable registration order serve all owners. Unique wing totals come from distinct handles. The selected-owner path resolves every registration's owner and demands a mission region only for the selected owner's occurrences. One unresolved required occurrence withholds the projection. The mission icon strip is one-based, so mission bit `b` selects frame `b + 1`.

The air-base management roster and the reference registry represent distinct facts. An AirReferenceWitness names every resolved handle and carries the base's fields when the roster lacks it, so an unresolved handle differs from a resolved off-roster base. A transfer check rejects only a resolved base. An incomplete table is unknown and an incorrect table type is corrupt. The roster owns capacity, which this map projection does not read. A state base uses its province's controller and requires that province. A stateless base uses its host ship's task-force roster owner, raw zero for an unresolved host, and unavailable for a resolved host with a null task force.

Effective country takes a positive override before the wing owner. Mission-country resolution tries the pool base's controller and then the transfer base's controller, stopping at the first matching volunteer host of that effective country. It matches raw references or linked canonical slots. An unlinked host cannot match by slot, and raw zero can still match a null controller. A host supplies the mission country only when its raw reference is signed-positive. Same-hour joins use the canonical slot.

# Keep railway capture ordered and field-local

## Identity, batching and carry

The manager is keyed by province slot. Preserve each info object's authenticated province record and building-status back-reference. The building status and selected building are separate from the template. Cooldowns are signed native ticks, including zero. The cooldown list carries stored signed IDs in list order, including duplicate occurrences the daily pass visits. Its writer decrements and removes expired IDs. The constructor zeroes the province table, the token loader can replace info objects and rebuild pairs, and teardown frees the objects and their pair storage.

The neighbour-indexed level array and sorted directed pair vector are independent. Size indexed levels from the province definition's neighbour count and preserve the full signed array, including nonpositive values. The signed pair count's nonzero test uses the raw count without requiring a vector pointer or reading its values. The native setter may update or insert sorted pairs. A directed edge carries its exact signed level, without inferring reciprocity or applying a default content maximum. Authenticate the far province's identity within the same census. Reject an invalid or self-neighbour pair in its original order. Spare capacity is outside the domain.

Gather the manager header first, then province slots and identity/back-references. Keep the fatal identity, cooldown and pair-header gathers independent. Otherwise a table-local fault could stop readable fields or a later record's identity. A null info is absent. A present info with zero cooldown has a row. Preserve each table's demand and refusal as though it had been read in order. Fixed scratch is reused after each guarded batch and consumes only its freshly filled prefix, even on long-to-short or empty transitions.

The worker can publish every slot in a batch from a held complete read when its header still matches and no observed writer touched the batch. When the destination cannot fit that batch, read it afresh without publishing a partial carry. Otherwise authenticate each slot and its info as usual. For a proven individual carry, keep its complete edges, indexed levels and building from the held read, while taking its cooldown from this hour. Register each identity before reading fields that registration certifies. Rebase selected level spans when appending and retain the same demand, row order and failure as the fresh reader. Report a fresh observation to the carry only as a whole output. Separate building outcomes preserve optional-field failures without affecting existing rows.

## Movement and optional health

The army takes the signed maximum of road and directed rail speed before its outer multiplier. Use signed fixed-point speed defines. For rail, use departure cooldown and damage and proceed on a matching directed edge with a nonpositive cooldown. The rail denominator is a signed integer scaled to fixed point. Zero yields a known zero. Use signed short building levels and the native distinct partial-health scale, reading partial health only when a nonzero level differs from the healthy level. A selected null building yields known zero. An unreadable reached field stays refused, and an unreached branch makes no building demand.

Infrastructure uses the authenticated state's healthy level divided by the effective maximum. Prefer the first positive local maximum, then the second, then the signed global value. Keep both operands unclamped. The additive state movement term is independent. Check the shared definition even on a carried state so its refusal matches a fresh read, and retain only states completed in the original census. Reuse authenticated pointers only within the current read. Cache both successful and failed controls for this invocation. A missing maximum cannot withhold the known zero of an absent building.

The selected building operand can be reached by a positive indexed level or a nonzero signed pair count, each independently of the other's failure. Keep the selected building's absent or null state distinct from an unreadable value. Do not let unreadable ETA-only suffixes stop the independent selected level of another source. Supplemental windows retain completed row prefixes, allowing later independent rows to finish after a field fault. The attach-time demand hint establishes capacity only, using native headers each hour to authenticate actual operands.

## Supply state

The disrupted-supply table combines province and node-type keys, with full signed fixed-point values. Its bucket position can change on rehash. Accept all live keys and markers only after validating probe geometry and the first reachable match, including when an output omission prevents storing a preceding row. An empty table has no live buckets despite retained allocation. Keep the end sentinel distinct from live entries. The province-supply vector projects the stored controller and capital-country indices, level bytes and independent flag bits from the authenticated slots. Its last record's tail padding need not be read.

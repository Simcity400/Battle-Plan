# Apply map input against the frame it belongs to

The picker takes its fixed buttons and configurable slots in the stock order, ranges its reassignable slots by the loaded defines and adds the content's scripted modes. The runtime DLC attached to the recording gates the fourth button, operatives and pings. The view may take a mode the layers can draw. It retains a locally chosen mode and slot configuration until the host echoes them. Older host settings therefore cannot undo a newer click. A map-only pop-out hides the picker but retains its hotkeys, and a country pinned by the host cannot be switched with Ctrl+click.

The host owns fog, day and night, and allied plans where present. Each click requests a flip of the host's own current value and the picker shows each applied host value. A standalone viewer owns its fog. Global settings and campaign-map settings retain their distinct scopes. The UI receives the mode inventory once per content identity. Picker label caches use a weak reference because the cache must recognise a previous content instance without keeping it loaded.

The minimap and find view share the picker pointer and handle it before the camera. Dragging the world picture follows its target. The wheel over it changes zoom and retargets to the pointer, while the wheel over results scrolls them. An active edit box takes the keys. Pings in the replay consume the map click, swallow its release and disarm as needed without posting a game command. Layout uses interface pixels and keeps the last reportable DLC mask while its replacement rows load. The find view and minimap controls are hit-tested above the picker's controls.

The viewer uses each pointer event's modifiers. In a single frame the user can release Ctrl after a click, so the last modifier state cannot determine the click's action. Ctrl+click resolves the clicked province's state owner, through its canonical country alias. Strategic-region clicks and stateless provinces remain ordinary clicks. An unresolved owner waits for the clicked hour's rows or reports why it was withheld. Locally accepted country switches are visible immediately and sequence their host acknowledgements, so a delayed echo cannot undo a later switch back to the original country.

Land selection uses the recording client's unit order only when viewing that country. A model click begins after the selected unit to support cycling. It selects stack mates with the same location, first ordinary hop and logical owner, subject to theatre eligibility. One of the game list's former owners clears selection when it is no longer ours. A hover can also try any country's units at the pointed province, including those on naval transfers. If unavailable ordering would change the result, the viewer names the refusal. Infrastructure and Raids modes use the ground's province-selection path. Box selection keeps the candidates from the picture at release until that hour's theatre rows become available. Shift extends the selection. Operatives boxes are withheld when the viewer has no operative icons to pick.

The order cursor reads the first selected unit and the pointed province at the playback head. An undecided order leaves the arrow and names the limitation. Strategic modes pick regions. Outside those modes, sea with a region also picks the region, while land, lakes and unassigned sea keep the province. The cursor prioritises pings, selected wings and a drag over a unit's relationship to the selection. Selection sounds use the content's known effects with recent and per-frame deduplication, and the voice-over cooldown comes from the loaded defines. Player-only counters show the viewing country's roster inside the widget's existing filter. One raid details window is open at a time. The overlay can detect a details redraw from the open and hovered bubble identities without laying the bubbles out again.

The `campaign_saved_settings_reach_the_frame_without_changing_the_hour` test requires a test process of its own. It changes the app-data environment before opening either service or starting its workers.

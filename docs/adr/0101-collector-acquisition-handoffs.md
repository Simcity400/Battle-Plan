# 0101. Return owned acquisition results before the callback lease ends

An acquisition request takes its preallocated payload from the callback and returns it at collection. Each accepted native walk runs at most once, even when it fails or unwinds. Independent template ranges can run beside country census and naming because they borrow the same authenticated country cache and do not take a result of naming. Failure to join the template job with a valid outcome withholds the templates for the hour. The test fixtures own the synthetic census, memory and output through collection. Country naming is the journal's last native borrower in its path. A later fallback using the original family operation does not repair a failed shared authentication seed or authorize a second Map source attempt. A failed CountryAppearance walk may have changed its held rows, so the callback discards the store on failure. The country walk uses the cached convoy operand and omits the local transport preview's pools and reservations.

Faction names and ordered membership share the country lease. Ordered membership supplies the companion inputs before the owner visit. The worker holds the two companion stores exclusively under the quiescent world lease while it installs pending observer growth. Country aliases resolve against the canonical identity. An absent faction template selects the default color. The acquisition tests check that the supplied census storage is retained across the walk.

Presentation workers can publish ready ranges without waiting for the callback to install independent results. Before publishing a ticket, they transfer ownership only. They avoid native reading, allocation and successor admission at that point, and a cancelled request keeps its original data. The callback's batch keeps every child alive until it adopts or drains the ticket, including on unwind or a failed parent. Each phase reserves a separate ledger while a preceding ticket may still await collection. The prior preparation ranges release their immutable lease before their successor launches. The successor ticket and ledger are published before the worker is woken.

The last input publisher installs failures before notifying readiness, assembles the complete source packs and takes all carry registries once for the hour. That take can proceed while earlier decode still holds its loan. If the older store returns after the current hour took its store, it cannot replace the newer result. A mode that omits status still joins the census but submits no successors. Published tickets may precede notifications and do not prove settlement. A rejected or failed input leaves the callback's ordered fallback in place, and all publishing tickets must be collected before that fallback reads or replaces the original ranges. The batch drains the ship-detail ledger after its census and all publishers settle. Final presentation receives the complete source packs and both late and history admission outcomes. Outstanding character jobs contribute raw-owner verdicts only.

Speculative variant jobs decode copied spans without reading native memory. They can work beside the parent when a worker is available, behind already queued native critical-path parts. The project family's other walks can run beside its project acquisition, and governance can read buildings beside its technology lanes. The plan keeps a worker free of waiting parent jobs. When no lane can run a part, the ordered path decodes it inline. The parent runs unclaimed parts locally and joins all of its children before releasing the live lease, even if the worker returns no result. The reported wait is the parent's post-local-work waiting time.

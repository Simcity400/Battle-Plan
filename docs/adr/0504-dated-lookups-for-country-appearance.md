# Scope country appearance to the recorded holder and sample

Read a known holder exactly at its own recorded hour when a widget distinguishes holders. A periodic sample can belong to a different holder of the same tag. A tag-selected line can use an earlier sample only within that tag's known holder segment and recorded stretch. Anchor the monthly grid at the branch start, restart it at the start of a stretch after a gap, and read hover labels at their exact hour. A slot-selected line keeps its own identity through renames and samples with the tag appropriate to its holder run. Sort and deduplicate tags within each requested hour so reordering a selection can reuse the reply.

Throttle appearance reads around a moving hour. Reuse the last recorded identity change at or before a followed head across its pushed hours. Drop retained parts when the identity or recorded stretch changes, even if the Canvas frame has advanced before React's next render. A read still pending can keep its own part's last appearance. Completion without a value or a failed read replaces that part's old display. A style reply can replace the name and colour before a flag reply arrives. A native empty string is a known name, distinct from absence. Name sorting can ask for more countries without expanding flag requests. Refresh failures can be reported beside already shown colours.

Sprite requests use the author-provided zero-based frame and can carry the recording's sprite choice as a fallback for an unavailable visual override. Deduplicate by the whole frame identity and refuse replies naming frames the request did not ask for. An undrawable image does not invent an appearance.

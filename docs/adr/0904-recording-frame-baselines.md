# 0904. Commit recording frame baselines after the write

Each table has its own baseline. The encoder stages baseline changes while it prepares a frame and publishes them only after the spool write succeeds. A refused or truncated acquisition invalidates that table's complete baseline. A truncated walk can supply observed rows while its absent keys remain unknown. A gap in the spool stream leaves the next delta tied to the last successfully written baseline on the branch. The advance for the clock always validates against the enclosing hour.

The encoder accepts producer-certified inputs when the encoder, branch, previous hour and destination agree with its held baseline. An identical shared allocation can reuse the row validation, with the enclosing-hour checks still in force. A compared input requires a complete acquisition and exact equality for its omitted rows, with stable keys and positions. Use a complete input when that comparison sees a change in membership. An owner slice replaces every row of the supplied owners and applies only to a complete shared baseline. A keyframe requires complete state and retains continuity only where the branch and predecessor justify it.

Round owned row values to their display steps before committing the encoder baseline. This makes the committed value equal to what the reader rebuilds. Segments emitted by helper threads must produce the same bytes as serial encoding. The commit retires old baselines and unused input to the caller for deferred destruction. A slice that changes row counts reserves storage before each affected baseline moves, and slice updates run before the other tables. A non-clock row validation error can become an unavailable table with its reason. Frame, baseline, allocation and I/O failures remain errors.

Readers distinguish omission by capture mode, tables delegated to native capture, partial evidence, and recorded layouts they must withhold. Keep the bytes consumed under the source format even when a table is discarded. Append-only historical fields use the source mask width and ordered prefix. Unretained updates still have their fields and keys validated, with the decoded row storage discarded as soon as possible.

Immutable recorded update cells can be shared between readers while reconstruction baselines remain private to each decoder. Keep the cells of retained tables only. An owning frame moves uniquely held cells and copies shared ones. A decoder revalidates the portion a delta can change. A keyframe starts an independent reconstruction and a fresh change span even when it shares allocations with another view.

Record acquisition separately from timing. A nonzero sentinel denotes a read whose individual duration is unknown. The published recording retains this read evidence, the callback total, pool bytes and dropped frames. Spools keep individual durations in nanoseconds. A carried snapshot is only evidence of a read when a source hour marks one.

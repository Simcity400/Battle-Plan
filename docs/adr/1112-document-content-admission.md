# Admit one verified content snapshot for the playback document

The desktop map and native analytics can share the immutable recording handle. Resolve the content identity from the recording's layer IDs and hashes and run its work with the recording's executable tables in scope. Open and seek on a loading thread. The initial seek overlaps content IO and produces the first frame in memory. A coordinator that already has that frame can create presentation state directly, and a second map of the campaign can reuse its content. Shared prefork hours use the main timeline.

The admitted content owns everything invariant over a recorded hour, including the movement map, GPU buffers and texture inputs. GPU resources that belong to a device are weakly cached on that device. A rebuild creates new immutable combat and raid identities, so old asynchronous results do not enter a new snapshot. Shared helper consumers use the same settled buildings, ideology, resource, terrain and trigger registries. Missing movement content leaves units at their province and withholds movement placement, animation and ETA. The document still opens with a named limitation.

Visual mods mount above the recording for artwork only. Derive static geometry and simulation inputs from recorded layers, including city-sprawl placement. An artwork reader can resolve that placement's mesh from the visual stack with a named fallback to the recorded art. Merge graphics defines with the recorded defines. An ill-typed override or a script that fails leaves the recorded graphics value in use and produces a warning. The fallback decision is tied to the recording, the selection and its mounted revision. Load again whenever the selection's files change during admission. A previously refused revision cannot stand for a later revision or another recording.

Local settings govern interface scale, rendering, map options and audio. They are presentation preferences. When client display operands are unreadable, warn and use the neutral scale of 1.0. The local half-resolution preference affects the HDR scene while output and interface stay full-size. The power-of-two texture setting affects the texture decode and its global defines. The initial asset discovery uses the client's settings viewport, then each map reads windows at its own viewport from the same asset set. The window, dump and picker start from the same map options. Missing optional assets and unloaded sections remain named limitations in the window and dump.

Static borders start in the province bucket and are rebucketed by the hour's regions. The strategic region filing feeds borders, counters and aircraft, and its membership is validated before rebuilding battle-name candidates. Region icons can provide anchors for faction-theatre pins. The static railway geometry is shared across hours, while each hour supplies its own graph. Land unit models and buildings use the viewer's visibility, with the native model threshold distinct from the counter threshold.

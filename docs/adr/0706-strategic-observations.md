# 0706. Preserve the strategic managers' indexing rules

The air manager's per-country strategic objects, country air-base containers and other base pools are independent sources. Strategic-air slots follow canonical country indices, while the object contains its raw country reference, including aliases. Empty slots have no object. Unexpected nonempty sentinel or alias slots are still authenticated and can fail the walk. A batch first gathers pointers and then their identities. It visits in slot order and preserves the first failure and the same visited prefix as the scalar reader. The native observer exposes null slots from the same root pass for callers that need them.

The strategic air object keeps two independent air-site vectors for fuel aggregation. Region IDs select mission and air combat lists. Statistics use their own keys. Ordinary mission registration and removal maintain the aggregate and per-region lists. Carrier combat can add a special-only region to the active region IDs without first clearing them. State-indexed airport, rocket and gun arrays are distinct from the dense stateless base vector. The base kind selects its own first-province list, and carrier registration stores a ship handle.

A strategic navy's country comes from the manager slot. The navy's retained raw owner may differ and does not invalidate that slot. Regional mission ledgers can contain registrations beyond a mission's narrower accessible list. The distinct registered-mission set is maintained by registration, removal and reset alongside the ledgers, so an empty set is sufficient evidence that they are all empty. Convoy efficiency reads per region and defaults to full outside the native array. That native default differs from an unreadable array, which refuses the observation. A caller can reuse authenticated array geometry only inside one frozen acquisition and must still read each requested value.

Regional access modes preserve the original mode value and index, emitting nonzero entries in country and regional order. The live array determines storage demand, and a short guarded copy withholds the table. UI, daily AI, reuse and load can mutate access modes, and the reader does not rely on an incomplete writer witness. The strategic-region object has independent primary and secondary identities. Its regional slot can differ from its stored ID. Province membership contributes to the precomputed route reduction and to hourly weather. The retained air-update phase originates in region admission and is compared against the current hour. Sea-template modifiers and dominance need authentication before use.

Supply walks authenticate the game-state-rooted supply and country censuses once. They preserve native province-array count and country-vector count versus capacity. Country supply follows the canonical country slot, and callers can screen a country before reading its supply object. The layout and authentication establish source identity. Consistency across observations depends on the acquisition boundary.

Faction research sharing acquires the companion selected by the owning faction's upgrade status and retains the ordered country references and stored bonus inputs. Its refreshed base is independent of current scientist roster and per-country bonus entries. The saved upgrade is derived from programme state. Graphics and simulation terrain also have independent arrays and null objects. Simulation terrain starts after its null slot, with the one-based database index selecting the previous index of the active unit's stat-adjuster array. Terrain-own attack terms come from authenticated terrain type and adjuster records. The attack-list witness observes them independently of published stat operands.

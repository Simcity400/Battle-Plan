# Preserve native map operands and their availability

Movement geometry comes from the map in the recorded content stack. It is fixed for the session. The ordered adjacency lists are shared with the saved railway reader because those levels refer to neighbour positions, not province IDs. Raster adjacency scans bottom-first file rows and the right, next-row, left and previous-row neighbours, wrapping horizontally and repairing four-province diagonals. A new raster pair appends its reciprocal first. Authored pairs are applied in file order with the source first. Repeated pairs retain their positions and both directions take the new kind and signed Through value. A withheld content listing cannot prove that an authored file is absent.

The province loader admits definition IDs that equal their row positions and fit the native 16-bit pixel records. The first record is the null record. Unknown raster colours, including colour entries that would resolve to zero, create land records in raster order without authored terrain operands. Unsupported province kinds are refused. Coordinates and lengths of raster runs also fit 16 bits. The bitmap decoder reproduces the native data input, including bottom-first file rows, unpadded pitch, the fixed start of 24-bit pixel data and byte rather than bit indexing at one bit per pixel. An out-of-range byte access is a named failure even if the BMP itself loaded. Each padded file row retains its first pitch bytes as later copies overwrite the padding.

Movement anchors use signed coordinate sums and unpainted provinces retain the origin. The crossing search chooses the first largest 8-connected border component, without wrapping component connectivity across the horizontal seam. Coordinate buckets preserve the original discovery order and the per-pixel divide rounds before accumulation. Terrain-cost and river reads share the integer route through the crossing, including it once, with capacity keeping the prefix. Sea border targeting redirects once through the raw Through ID, and movement arrows suppress a midpoint for the native flag or an X coordinate of -1. Battle plans can still read the underlying crossing. Procedural terrain colours resolved from the terrain bitmap have zero cost for a missing name or palette entry. Category ordinals are one-based and may exceed the byte width of a palette index.

Movement reads preserve domain independence. A selected attack reads the directional neighbour kind without requiring distance, and a river crossing reads the route without requiring terrain cost. River sampling runs only for otherwise unclassified land pairs and the first qualifying byte along the ordered route wins. An authored kind bypasses it. Known non-neighbours use the native default fixed5 distance and clear kind. Unknown provinces, unreadable operands and missing authored terrain have separate representations. The ordinary ETA kind uses the distance refusal boundary. Distance scaling uses wrapping signed fixed5 arithmetic and preserves the exceptional positive sentinel.

Terrain flags come from the authored kind, the row's coastal state and the repaired raster adjacency, with a distinct isolated-land bit and distinct coastal bits for land and sea. An authored crossing does not alter raster-derived isolation. Native movement defines use fixed5. The two non-core supply terms, combat movement, rail and naval policy are independently available. A refused organisation pair leaves other movement terms available. Rail speed uses road and rail base and scale terms, and the signed maximum level preserves zero and negative inputs. Naval range scales before taking its guarded half, and the separate policy selects home bases and hubs in place of stored nearest bases at sea.

The embark-specific define replaces edge distance on moves from non-land to land. A mod's terrain choice resolves against the first matching category registered so far. Categories retain distinct ordinals even when their names repeat, and invalid numeric costs retain zero before the native minimum clamp. Absent terrain columns use the parser's unknown terrain name, and only the exact authored coastal word accepted by the parser sets the flag. The synthetic map fixtures use a zero Through value, while strait tests read the authored map to exercise a nonzero redirect. To exercise an isolated river read failure, a test invalidates its decoded bitmap after the loader's global validity checks.

Province geometry publishes raster rows top-down while positions remain bottom-up in map coordinates. Pixel runs narrow position and length to 16 bits, and a painted province with only zero-length runs is distinct from an unpainted province. The state's bounding box chooses the narrower of wrapped and unwrapped bounds. Nearest-province ties keep the earlier authored entry. Land-area counting streams file rows with memory bounded by raster width and the record domain, and applies the same record and BMP validity rules as the full geometry reader. Map distances use the native wrapping and fixed5 square-root arithmetic.

State adjacency walks member provinces and each province's effective neighbours in their retained order. Every other nonzero state enters the result once. Membership overwrites in state-ID order, so the higher ID wins if two states list the same province. Missing provinces or unrepresentable IDs are failures. Separately, the raid distance uses the recorded content's land/sea classifications, admits the destination independently for naval paths, and uses an intentionally non-admissible heuristic with the native heap's insertion and tie rules. It can return the same route the game found even when another route is shorter. The path-producing form bypasses the session memo and retains each successful predecessor. Authored crossings can reference adjacency rules by their stored bytes, using the first loaded rule. A missing rule is absent and a rule whose text cannot single it out is refused.

Map positions use semicolon-separated world coordinates. Building rows require seven fields and preserve the native decimal scan across field and line boundaries for state and adjacent-sea values. Coordinates take the longest native floating prefix or zero if no prefix converts. The scan first applies the CRT grammar and backs off on the small set of truncated suffixes the field conversion allows, so an unbounded field still takes at most two scans. Refuse names the Rust representation cannot hold and positions it cannot place. Weather anchor rows take five fields, cut at the first carriage return, and classify small anchors by the trimmed, case-folded size prefix. Other field counts report the original line number. The authored railway file is one lexer stream, so a segment's count can consume the next line and a short final segment repeats the last token. The viewer uses recorded `RailEdges` for the campaign's hourly network.

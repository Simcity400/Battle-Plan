# 0904. Reconstruct research from the exact observed slot and definition

Research inputs and applied bonuses use the owner's slice hour and the slot's exact technology. Repeated handles make the template occurrence essential. Historical rows with no occurrence cannot select among repeats. For the indexed technology table, nonzero applied-bonus count admits the instance to the save. An empty read leaves the keyed definition inventory unchanged. A complete nonempty read replaces it, and a partial read replaces its own keys. Definition keys have no owner or separate read hour.

Keep arithmetic operands in their stored representation so analytics applies eligibility, clamping and aggregation. Shared country inputs use the maximum slot index. Other ordinals resolve within their owner and slot. Topic and source records keep native cached values, exact category strings, feature metadata and loaded defines. For the multiplexed records, interpret their operands by kind.

| Research modifier kind | Operand meaning |
| --- | --- |
| Sharing group | Base and country bonus, member count, native group id and group token |
| Sharing member | Current level and template maximum, group ordinal and raw member reference. Keep each roster occurrence |
| Missing sharing member | Member identity and template maximum of an absent technology instance |
| Sharing predecessor | Native classifier and member ordinal. An empty set stays empty |
| Sharing filter and category | Category hash and exact string. Filters also carry group ordinal |
| Sharing doctrine | Native doctrine byte. A nonzero value bypasses member and category dependencies |
| Sharing roster | A header with raw −1 and count equal to roster length witnesses the country-wide read. Following rows retain native group ids, including duplicates |
| Scientist and scientist category | Selected category count, and the cached category value and category identity. An absent cached category is zero |
| Modifier metadata | Definition flags, native feature-eligibility flags, feature selector and modified-value ordinal |
| Grant counter | A signed next id in the inventory scope at maximum slot index minus one. Its presence witnesses the complete, possibly empty inventory |
| Speed and cost grants | Grant id bits, native roster ordinal and stored name. Speed and ahead reduction are fixed5. The cost grant holds fixed5 cost reduction and zero auxiliary value |
| Grant uses | Signed uses and active claims, with the cost-grant flag and grant id. Cost grants have zero claims |
| Grant technology and category | The grant's id and kind and the linked token. Technology entries also hold exact template index. Retain ordered occurrences, including duplicates |

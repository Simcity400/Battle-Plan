# 1103. Rebuild combat hovers from the recorded side inputs

The dynamic combat builder owns both hover slots of the widgets it updates. A refusal clears the authored seed regardless of binding order, while the authored shortcut remains a separate tail. Unowned widgets keep their authored text. The GUI reader stores a hash, so authored keys are resolved through the window definition before localization. Widget paths compare ASCII case while retaining the producer's path and ownership. Missing top-level localization shows the key itself. A malformed or refused delayed hover leaves its immediate text standing. Trim the four native ASCII whitespace bytes and preserve the shortcut component indices when translating keycaps.

Land organization effects are rebuilt after tactic changes and load. Content supplies the tactic terms, and the recorded damage sums witness the current side membership. Scope each side to its first linked country and refuse a torn-down side with no country. Look up a recorded tactic by both its database ID and its token so repeated names remain distinct. An unsettled trigger leaves its tactic and the following registry entries unproven. In the tactic counter test a present null tactic counts as a pointer. It uses the standard header and delayed description with zero effects. Only an absent pointer uses the standalone no-tactic line. Defender organization damage takes the attacker color and defender strength damage takes the defender color.

The viewed country's commander gets learning progress. Resolve country aliases before that comparison and refuse progress when the link is unknown. The offence and defence modifiers use the recorded selected leader block and modifier definitions, and can refuse independently of the skill line. Older recordings may lack the side inputs entirely. CAS text describes the selected side's planes against the opposing side's anti-air and committed divisions. The older side details can supply the CAS operands where present. Keep prevented damage at the recorded display step, cap the truncated anti-air reduction with the recorded combat defines, and use the opposing committed width for the number of planes that fit.

Naval progress and stat hovers are bound independently of whether their controls are visible. The two progress icons share one immediate and delayed pair, and the corresponding text and backgrounds share their callbacks. Anti-air has no delayed breakdown. The carrier penalty formatter uses the native fixed-point sortie multiplier, weighted opposing count and minimum. Both flags take the first attacker country's live display name, while the delayed side summaries swap according to the hovered flag. A visible naval pride icon has precedence over the ordinary member hover. Naval commander progress uses the same country-dependent learning formatter as land combat.

Division entries use the exile country's flag only for the exact exiled template origin with a positive reference. Otherwise ownership prefers a positive expeditionary reference over the roster owner. Compare raw country references first, then canonical slots for distinct nonzero references. The frame 14 badge is gated by the side's positive occupier bonus and appears when any opposing committed division qualifies. Its breakdown needs the complete count. Frame 15 requires the unit's state to be an exile-country core. A proven match decides the badge even if another candidate is unknown. With no such match, refuse using the first unknown table and reference. A complete missing key, an unreached key in a truncated table, a failed table and an omitted capture mode remain distinguishable.

The terrain hover replaces the location text and also supplies the state view's terrain description. Land and lake use the definition's terrain category, followed by the localized terrain and local effects. Local effects read the recorded weather modifier accumulator, including the contributions from terrain weather, scripts and building damage. An empty description adds no section and a refused local accumulator leaves the terrain description standing. A sea province uses the strategic region's naval terrain, with the native ocean default when that binding is absent.

# Preserve definition ownership and parser gaps

Modifier values use the CRT conversion into a zero-initialized fixed5 destination, retaining the authored text separately. Bare and quoted names merge by ASCII case at their original position. The last value wins, and a hidden modifier sets the same entry's visibility. Tooltip text has its own identity and an added modifier is a child. The tooltip table retains native iteration order, including growth after displacements overflow its probe window. Equipment stat assignments add when repeated. A block-shaped unknown modifier is reported and skipped, while a registered name consumes the opening brace as its value and keeps reading the block's fields in that modifier context. An equipment stat belongs to the separate equipment domain.

Country name lists retain raw bytes through the seeded draw. Non-UTF-8 entries count toward pool sizes and are only converted once selected. Defaults append across blocks and files while a named country declaration replaces the whole prior exact-name entry. Use cosmetic, original-or-own and default entries in that order. A country with no names or surnames across its pools falls back to the default, but an unusable selected male pool yields no text. Ace and general pools are consumed to keep the reader in step and do not enter the advisor-name draw.

Occupation law icons consume a scalar. An all-digit token changes only the frame, a `sprite:frame` token changes both, and a sprite token retains the frame. The suppressed state modifier is optional and absent suppression contributes nothing. Occupation modifier thresholds use fixed5 percentage points. Definitions replace whole objects by exact name, so an unread suffix can replace an earlier result and requires refusal. Opinion definitions use direct files with the mode that retains the leading byte-order mark and take entries from the opinion wrapper. They keep first token match and omit the null object, with target overrides separate. A later false target assignment leaves the previously chosen name in place. The first-match policy makes later definitions uncertain after an unread file suffix. Trust bounds narrow to signed shorts before clamping, and the clamp preserves the native precedence even for inverted bounds.

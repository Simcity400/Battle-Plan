# 1301. Use the recorded acclimatization choice with province conditions

The current recording selects the camouflage category at capture with the live threshold. An older recording supplies its raw weights and maximum to the same selection law on playback. The first strictly greatest positive weight wins if it reaches the threshold. Missing operands withhold the answer. The category token resolves using the content's lexical fold, and a folded duplicate refuses with its names.

The current province can forbid the chosen category. Apply the authored conditions in order, testing the province before its state's share. Snow uses the recorded current and permanent values, capped by the recorded gain maximum. Outside the weather census the getter returns no snow. Inside a truncated census a missing row remains unknown. Retain the base model when no eligible seasonal entity exists.

Cache state membership while province-to-state reads remain valid. Narrow weather and lexical reads to the selected candidate's dependencies so a kept model can be reused if those facts stay equal.

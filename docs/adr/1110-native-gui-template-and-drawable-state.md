# 1110. Lay out native templates against their retained objects

The renderer distinguishes the container and fixed-window construction paths. The fixed path begins hidden and attaches objects in the native lookup priority. Array lookups retain the first match and the child name tree retains the last. Attaching an object again moves it to the end. A drop-down and a multi-sprite button can be constructed without joining the normal fixed attachment list. A conflicting native type or a missing required parent is refused by name. A missing declared sprite can use the fallback, while an absent session-registered text sprite cannot be inferred from a recording.

The authored position and the constructed extent are separate inputs. Integer alignment, percent sizes, bounds and anchors are evaluated before drawing and use the originating viewport or parent extent. The assigned layout can preserve a truncated extent while emitting a fractional quad. A sprite's own anchor takes precedence over centering. Explicit frames are one-based, and a frame beyond a strip passes the UV to the effect's sampler. Rotation preserves the resulting float corners. The fixtures use an authored angle when the exact parsed value is the behavior under test. Clipping supplies a whole-pixel scissor scaled to the device and does not crop the quad's vertices.

The background belongs to the window's outer object and draws before content. Margins inset content, and nested content scales compose around their origins. Clipping retains its own unscaled coordinates. A grid keeps construction offsets and fill order through its holder. A relayout grows its extent and adjusts top and left padding, while items retain their own order and clips. Overlapping elements can compress spacing to fit the authored box. A wide single entry follows the native floating calculation. The window's own clipping request intersects its descendants' draws even for a normally unclipped window.

The pointer updates the topmost eligible control. Pressing keeps the button's down state when the pointer leaves, and an explicit map hit names the hovered control without a regular hit list. Unbound map icons have no hover. Transparent hit testing uses the loaded sprite's alpha mask. A code change must clear a hide guard before show can reach the object. Bound opacity can propagate to child windows, and a holder preserves its item attachment order along with its origin, scale and clip.

Button, icon and simple-button sprite setters have different native rules for frame, orientation, centering and rotation. An unresolved or unchanged setter name keeps the existing drawable and its state. A successful replacement keeps later frame writes, placement and extent queries on the replacement. A frameless sprite refuses its division. Fixed templates and bound calls use the same drawable paths, including a text-only button's measured extent and a nine-slice background whose cornered texture is laid out at the window's assigned size.

Progress rendering keeps the authored geometry, orientation and state. A sprite progress bar turns about its local bottom-left, with orientation determining the UV axis. Its assigned value can be negative, and a value above the configured steps clamps before division. A zero step count retains the floating result. Circular progress writes the remaining and completed portions as a fan with one triangle per normalized unit. A masked shield draws the flag before the overlay and keeps the two paths' bindings distinct.

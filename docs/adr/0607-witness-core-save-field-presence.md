# Witness omissions in core text-save fields

## Decision

The shared Clausewitz reader owns syntax. The save oracle projects literal serializer values, with exact decimal text and its original optionality. It refuses binary saves before parsing and uses the whole-item identity witness for the physical emission ledger. Ordinary strict parsing has no such ledger. A sparse table is evidence only about the entries it holds. Keep typed identifiers across rosters, explicit templates including unused ones, and equipment variant handles independently of their definition names. Both reference words must be zero to prove null. The save can repeat country tags in the players header and retain players no longer in the live roster. Its `player` tag identifies the saving client's view, using the writer's fallback only when that view is nonpositive.

Native date formatting uses a 365-day year and zero-indexed internal month, day and hour. Text hours run from 1 to 24. Keep the special `-1.1.1.1` date as the unset sentinel rather than accepting it as a BCE calendar date. The save's allocation keys are unconditional and the debug reference ID uses unsigned serialization, so omission or a signed spelling cannot stand for a default.

| Save domain | Evidence retained |
|---|---|
| Countries | The major byte is written when nonzero. Cosmetic tag is unconditional and an empty value denotes no override. Original tag is emitted only for a positive reference. Zero signed manpower residual is omitted. Stockpile values are literal pool entries. Air volunteer hosts retain vector order with their paired counts. |
| State and province membership | Reciprocal core and claim lists are ordered and omitted when empty. Civil-war targets preserve array order. The state controller field is literal and independent of sparse province controls. Impassability and border conflict use unconditional native flag emissions. An omitted manpower pool proves only nonpositive population. Retain separate absence of the pool, absence of its total, and a present total. State and province rename fields are emitted for nonempty overrides and province victory points for nonzero signed values. Preserve ordered state strategic-location pairs and province strategic-location tokens, with empty lists when omitted. |
| Country calculation inputs | Nonzero signed stability and war-support words serialize as five-decimal values. The Q15 penalties truncate toward zero and coastal protection uses the fixed5 formatter. Refresh is unconditional. Bit 1 rebuilds modifiers and recomputes factory totals, while bit 9 recomputes totals alone. |
| Strategic navies | Positive mine values alone are emitted. A missing region in a present mine block proves zero. Access consists of signed-positive byte modes in flat region/mode pairs in stored order. Convoy efficiency is omitted at 1.0. A region record absent from a present registry means full efficiency under the native record omission rule. The navy wrapper's absence is distinct from empty access and convoy registries. |
| Relations | Keep first and second as explicit ordered endpoints independently of the enclosing tags. The `first` and `second` fields identify a serialized relation and each relation contributes an ordinal, including war and subject families whose rows are compared separately. Other types join on their literal key. Unwritten `cached_sum` is exact zero. `cancel` and start date exclude one another and an absent end date constrains the end to at most the start without proving a particular sentinel. Directional war ledgers retain explicit presence and their four unscaled signed values. |
| Intel | Country-link slots index the positional four-lane records. An omitted fixed5 lane equals zero, while the missing list is distinct from all-zero records. |
| Factions | Keep the full reference, pointer-array order with leader first, unconditional icon and optional template. A name emitted empty after its first NUL differs from an omitted stored-empty name. Colour is multiplied by 255 and truncated, with alpha omitted at one. Retain the colour override and ordered upgrade slots including missing advisors. An omitted slot list is empty. Theatre arrays keep their separate order, optional commander, region bits, countries and hidden pins. Checksum mode can omit the theatre name. |

## Source for membership checks

Verify province membership using verified content layers and the same native state reader as the viewer. Apply only the `provinces` lists for membership, deduplicate repeats within each state and keep id zero as the null map record. State history supplies authored resources, but a resource refusal does not invalidate verified membership. A province belonging to a clean kept template may still have unknown assignment if an excluded template named it. Validate overlaps between clean assignments first, then mark candidates of excluded states as unknown with their identities. This preserves a known unassigned province as a separate fact. Never use script history to replace the post-setup owner, controller, core, building or point values the save supplies.

# 0805. Use save witnesses only for military values they can establish

Saved participant classes come from the unit roster that resolves each full reference. An unresolved handle can still be compared without assigning it a class. Battle sounds and movement accumulator operands are runtime-only. The oracle checks their recorded order, map joins, and supported control relations. Only routed divisions demand movement speed and fuel. Movement targets and alternate routes follow their own null and empty omissions. A combat movement word applies to a division in combat and outside withdrawal, with absence also valid for a naval or unresolved first match. Undefined flag bits are rejected.

Save supply values compare at the recording version’s precision. Displayed grace is rounded using recorded content’s supply-grace define. Current captures always populate the exact supply ratio and exact supply grace pair (omitting redundant rounded `supply_ratio`); historical recordings populate that pair only with nonzero out-of-supply days and keep rounded `supply_ratio` at zero days. The save does not witness the received-supply ratio, so the exact grace is checked against `army_current_supply_ratio` while verifying that `supply_ratio` stays derived from exact values when exact values are present, that historical zero-day absence still retains `supply_ratio`, and that the two exact columns are never partially recorded. Nonpositive disruption is omitted by the writer and omission cannot establish a zero value. New scalar reads are compared independently where their explicit presence witnesses permit. A missing ship crew or wing stop flag means the writer certificate did not support that read. These are reported as limitations even if the rest of the row compares.

The saved acclimatization block is gated on a positive maximum candidate. It retains nonzero category weights in original order and omits a default maximum. Compare a current recording’s camouflage selection using the recorded threshold, and older recordings’ exact lists by their original byte names. A stale selected-template reference can remain captured although the save omits it. Name serialization uses stored length for conditional fields and first-NUL prefixes for text. Where the text writer emits the place unconditionally, omission cannot certify an empty string. An unresolved negative expeditionary tag cannot be verified as a known null.

Template icon and movement words carry separate acquisition witnesses. Keep independent the display-name operands, movement keys, and optional model data. For composition, reduce each saved grid by sub-unit name; the recording retains global and local definitions separately and the grouped view combines counts from all grids. Naval transfers are compared in saved vector order and their unit references only when live and resolving. Runtime province combat vectors compare against the recording’s own combat census. Ship experience compares at the existing display step or exact precision for older rows.

A wing pool subtype joins through the recorded reverse spelling, which may predate the authored spelling. Build this lookup once. Check raid identity in a separate group so a content failure cannot erase its comparison. State whether the captured raid flags certify a resolving reference or an unresolved handle; the save omits both stale and null references. A missing certificate remains a named refusal. A captured ace omitted by the save is discrepant if its registered object would have resolved.

The division history oracle checks saved list orders and preserves nested updates to an existing career entry. Name caches used only for display are unsaved. The daily unit bonuses compare only when fresh, retain occurrence and target order, and omit zero sparse values as the writer does. Dense stat selectors compare by name, independent of serialization order. A missing inventory key proves an empty saved list only for the writer’s keyed empty-omitted census.

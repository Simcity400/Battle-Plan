# Convoy heat strips use each day's last recorded hour

Each day reads its final recorded hour and a wholly unrecorded day stays a gap. The regional, deal and lend-lease tables have independent coverage. An observed lend-lease route can have no recorded numeric efficiency, so it can still show its route and report the missing reading. A blank plot period with no read is distinguished from a hatched missing value in an observed period. Heat rows are ordered by activity across the shown span, independent of where the playhead is. Exact fixed-point efficiencies follow the game's percent display by truncating to two decimal places.

Country names are read at the end of each recorded participant run, leaving the tag for the hover explanation if no name is available. The followed playhead paints between structural renders. A drill shows the row's own efficiency and factors or shipment counts, with read facts following the head or the selected day. Chart end labels are drawn outside the plot's clip.

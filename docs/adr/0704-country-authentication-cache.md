# 0704. Reuse only exact country authentication observations within a capture

A direct roster census seeds exact native headers, slots, links, vtables and identity words before the dependent reads. The seed does not observe arbitrary country scalars. A preparation clears the previous observations and performs one direct census without retry or allocation. An inconsistent census leaves no usable snapshot. Capacity pressure returns a transparent source view, and off-thread sizing reflects observed demand, including probe collisions. The derived roster capability can refuse storage independently of the byte cache.

The snapshot is immutable and shared only under the current capture's acquisition barrier. Release every lease before preparing another capture. If an earlier lease still holds the shared owner, preparation refuses without overwriting it. Avoid retaining a snapshot or native pointer in a queued row.

An exact byte hit requires both address and size. Cheap rejection filters cannot supply bytes or authenticate an object, and saturation can increase lookups only. Wider or overlapping requests remain source reads. The roster-only and byte-only views preserve the unselected source path. The actual reserved root is observed independently before positive-slot links. Only its exact address receives the reserved ID-zero treatment, and the first failure for that address stays authoritative. A positive alias is excluded by roster filtering where appropriate. A null or unseeded link is not inferred absent from a complete seed.

Keep fixed-layout record gathers on the source for their original guarded batch. An all-source scatter still uses its original single guarded call. A mixed scatter commits only the successfully read prefix. A failed miss stops later hits, and bytes from that partial miss are not treated as a complete field.

Country intel rows preserve all four native signed fixed-point lanes. The target is the canonical link slot resolved from a country reference. The individual consumers select the relevant lane and apply display normalization elsewhere. Serialization omits exact zero lanes but retains the existence of an all-zero entry.

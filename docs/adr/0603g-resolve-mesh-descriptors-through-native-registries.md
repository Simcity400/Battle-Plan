# Resolve mesh descriptors through native registries

Populate object, animation and entity registries in separate native-order passes through the mod stack. Exact object names share a registry across their kinds. The latest object of a name wins, and a later non-mesh can make its mesh binding unavailable. Animations keep the last successfully loaded clip, lights the latest declaration. Animation and light names have a 63-byte retained limit. Entity names, clone references and mesh references have a 255-byte limit. Reject names above those limits before registration because the effect of truncation on lookup and collisions is unverified. When the tree parser rejects a file, retry after dropping unmatched closing braces and completing open blocks while preserving strings and comments. This accounts for the native reader's observed permissive file boundaries. If a file still cannot be read, an uncertain word can conceal a declaration. A visual overlay that fails can fall back to the recorded file at the same path with a named diagnostic while overlay-only identities stay uncertain.

Entities resolve before same-named meshes because they retain state, scale and inherited fields. A clone copies the parent as registered when the block is read. Missing parents refuse the clone. A lower authored version cannot displace an existing name, and cloning retains the parent's stored version. Missing or wrong-kind mesh references preserve the held binding and report a failed lookup. The child replaces authored fields and state lists by name, but keeps the parent's registered locator order and radius. Attachments match by handle or by joint when both handles are empty. A replacement keeps the old slot; a new attachment appends. A cyclic inheritance or attachment chain terminates and is refused where playback cannot resolve it.

Material overrides select the first matching shape and raw child ordinal, with an empty shape or unspecified index following the native wildcard rules. Only nonempty fields override the material. Paths retain descriptor or mesh directory context where native lookup uses it. Index textures by exact basename and keep the first in load order. Apply the native extension substitution before lookup, then try the authored mesh-relative path on a miss. Preserve the declaration's content origins across clone copies and retain a named diagnostic for undecodable paths.

Stored state text and structural stream alignment are separate. A later valid assignment can replace an earlier unrepresentable text value. A read with unsettled token consumption can shift the enclosing file, so preflight it before admitting declarations. State events remain in authored order and retain callback, sound and timing data for consumers. Keep the parsed fixed-point state chance distinct from the legacy weight on definitions constructed in code. Hit and miss timings refuse an unsettled member so a partially read list cannot masquerade as complete. Literal scalar no-ops and failed scans with known recovery preserve later rows. Locator joints resolve against the registration mesh and an unresolved joint leaves the locator in entity space with a diagnostic.

Test embedded NUL handling at the shared token replay layer. The descriptor tree lexer rejects an embedded NUL before that projection, so the same case cannot be exercised as an integration fixture.

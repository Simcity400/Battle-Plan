# Reproduce panel and flag results from recorded operands

Flag selection uses a country's tag, cosmetic tag, original-or-own tag and ruling ideology group. Selection resolves a playing or observed country's reference through the recorded country links, then uses the last country row at the canonical slot. The appearance and ruling party belong to that object and are shared across aliases. A non-positive reference names no object. An empty cosmetic tag means no cosmetic override, and an empty ideology group token is still a group. A missing exact original tag withholds just that part of the lookup, preserving the other operands. A recorded name tag cannot stand in for that exact suffix. The recorder and app resolve these keys through the content stack while the collector supplies committed rows.

Stability and war support reproduce the game's fixed-point operations. The popularity term uses wrapping multiplication and retains the game's overflow sentinel for parity. The interception term sums, converts to Q15, scales, converts to fixed5 and then clamps to the impact. Maximum command power uses the same frame's command-power row for the maximum, multiplier and allocation. Without that row these operands are unavailable. The displayed value subtracts allocated power, and its reported terms are operands of the calculation.

Intelligence ranges operate on recorded truth in Q15, recorded intelligence and the applicable content. They are independent of panel state, local selection and a captured caption. Fixed5 square root converges using integer arithmetic because floating-point rounding can move a displayed endpoint across an integer. An exact path needs neither the monthly jitter seed nor its unused spread define. Counts round Q15 bounds and keep the signed low 32 bits. Fuel keeps the Q15 bounds. A zero quantity can be available.

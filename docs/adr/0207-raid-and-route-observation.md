# 0207. Observe volatile raid and route operands at their write boundaries

RaidAirSites has no daily slice. Read new countries, unpublished owners and canonical countries named by an observed list writer. An unresolved mark or one that cannot certify the preceding hour requires a complete read. RaidCountryInputs, AceRangeInputs, StockpileArchetypes and CountryCommandPower are read together for every country each hour. Their values can change between boundaries without a relevant observed writer. The supported launch keys must pass the fixed-layout check before their tables are admitted. Reservation buffers cover the live total instead of dropping countries that would not fit.

Raid targets retain scope, validity and each country's persistent detection bits. Offers and detection-dependent buildings can select any viewing country. Target capacity follows observed country slots. A leader target whose captor cannot be proved is counted as refused. The raid intel inputs read each country's accumulator header. Carry entries only when the header, object identity and naval modifier-tree certificate match those of the held read. A certificate is sampled before and after copying entries, so an unobserved or concurrent write cannot certify them. An interrupted walk clears the whole store. The agency defence breakdown keeps an equal printed modifier tree shared and ignores irrelevant zero sources.

State raid operands and country building overrides have separate owner sets. Read new and unpublished owners and the owners marked by a writer. Include the controller of each state selected for resource and modifier rows with the override reads, then use the walk's reported owners to identify coverage. The cores pass reuses the state census. An incomplete census withholds its cores rather than establishing a partial baseline. The hourly supply rebuild can change a route flag without a writer mark. Read the complete `StateResourceInputs` row every hour for known resource origins. Attach and detach marks select affected states immediately. `StateResources`, `StateDynamicModifiers` and `StateCores` keep the scheduled state selection. Each table publishes its own owner read hours.

Resources and convoy terms can update on the hourly trade task, so their input tables read every hour. A route's owner can change because a writer touched the route or because its referenced membership or storage changed. Select owners for either reason. Unresolved or uncertified marks require a complete read. The route census includes both own and rights-holder resource origins and every convoy client. Repeated references share a key only when they name the same route. Duplicate keys naming different routes refuse the census. Keep origin and client acquisition order while deriving route and region demand, then sort each complete table once for conversion. Strategic-region weights are static within a loaded map and read on full hours.

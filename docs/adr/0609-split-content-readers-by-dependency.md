# Split content readers by dependency

The balanced parser owns lexical tokens and values so save readers can depend on it alone. Layers resolve and memoize content while the script crate owns the native grammar and the symbol table it consumes. The defines crate owns Lua evaluation and the key-names crate builds the recorded name product in the original registration order. KeyNames carries names and the metadata that governs their recognition at each read stage, leaving the building and equipment databases in the product that built them. The product retains the existing memo keys and reads from the same effective layers. GUI, mesh, map, military, and politics readers consume those lower-level contracts, and the facts writer receives the equipment section from its caller.

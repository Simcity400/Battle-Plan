# 0304. Derive modifier and political descriptions from recorded inputs

Idea references preserve the template parser's distinction between literal tokens and scoped variables. A `token:` prefix forces the template token, while scoped numeric resolution truncates the signed fixed-point value before its lexer lookup. Naming uses a fresh country-only scope, with the caller's country carrier or recorded country zero for other objects. Targeted modifier fragments resolve operands in default empty scopes. A positive resolved country gates the section, and caller context is retained only by the path that explicitly copies it. Idea tooltips use the short wrapper only when every detail fragment is empty. Advisor tokens take precedence where the add and remove effects have both identities. The recording-language check gates cached strings separately from the numeric fragment, so missing keys retain a named refusal while numbers remain readable.

Timed ideas distinguish an absent membership row from a member with stored duration minus one. Add-days takes precedence over an authored days field and a negative total describes removal. The duration wrapper depends on resolved display names. Both cleanup paths remove a directly adjacent colon and comma. Only add-timed also removes their spaced form. Header and child fragments preserve the game's expansion order and line breaks.

# 1302. Resolve authored building slots and retain camera-local entity state

Resolve slot buckets and entities once from the recorded content stack. Keep candidate types in declaration order and visit each province's slots in authored file order. State and province rows join on their respective location keys. Each ordinary slot retains the bitmap province under its position for fog. Floating harbours use a reserved entity and a separate deployment province from the authored row. They follow ordinary slots in product IDs and can use a known authored state without the ordinary land and bitmap membership gates. A positive deployment province, its supply flag and controller, and the first matching deployment status establish a harbour. Its own fog byte determines visibility. An unknown gate gets a named limitation.

Select ordinary slots using a strict level fraction. Multiple healthy meshes can admit every slot and choose a mesh from the level, while ruins keep the ordered admission and their selector. Probe a destroyed descriptor even when the content does not require one. Damage states with animation may use privately posed geometry while preserving registered definition identity. Apply fixed-point health with the native signed width and truncation so wrapped values and sentinels choose the same state. A missing mesh withholds only its own state. The damage thresholds have hysteresis, so a slot carries its last admitted destroyed selection until recovery, even across hiding.

An ordinary fog or detection gate keeps an undecided building and reports why. A foreign building requiring detection needs the building target's viewer bit, independently of fog. A supply hub stays with the port or city layer where the naval-base membership or terrain proves it belongs there, and incomplete membership cannot prove that. Token spellings come from the hour's recorded dictionary. Retain no mapping once the dictionary changes, refuse missing, ambiguous and unreadable values by reason, and distinguish the no-type token from an unnamed one. The same refusal set reaches the viewer, captures and dashboard map details. State definition conflicts are reported once by the playback document.

Slot history belongs to each rendered view. A branch change, backward move or paused seek starts cold. A forward skip can apply observed hours without creating slots ahead of an admitted frame. At near zoom use the camera's province boxes and visit buildings before the corresponding groups of units and hulls. A replacement clears the old entity and commits its selectors before the creation allowance is checked, so the slot can remain empty until its next admitted creation. Above the update cutoff, a previously near group takes one hiding step, retaining distance landmarks and freezing survivors. Offline cameras render the settled scale. A held camera's slack bounds candidate gathering during pans and turns. Test those candidates against the current camera to get each frame's admission. Cull tiles avoid rebuilding an unchanged stream.

Share groups and unaffected slot chunks across hours and hand producer pages directly to the scene. Reusing a previous slot only applies when the same chunk, positional grouping and motion settings still govern it. Compare the relevant float bits so signed zeros and NaN payloads do not collapse. Recompute only gate dependencies a slot actually observed, and invalidate token membership on dictionary edits even when no building row changed. Cold products share the same immutable groups from content.

# 1106. Measure viewer work outside the frame path by default

The load-cost harness opts into recording stage start time relative to the load, inclusive wall time and the executing thread’s CPU time when available. A stage includes its nested stages. Aggregate counts and bytes distinguish reused and newly built products. Beginning a new epoch discards the previous measurements. Normal viewer stages and counters return immediately while the harness is off.

The optional install check compares a product’s incremental install with a whole preparation of the same hour, including the content of the resulting GPU resources. Each enabled install site samples independently at a bounded rate. The check records the responsible product, range and hour. Disabled sites avoid assembly of comparison data. The diagnostics UI imposes a bounded scroll height, and its component tests inspect text and shapes without a GPU texture upload.

Canonical debug formatting shared by the corpus omits runtime handles and caches. Tests use the viewer’s allocator to exercise the same allocation behavior. Division-template icon preparation expands only the supported compressed base-level color formats on the CPU and names unsupported ones in refusals.

# 0302. Share one recording summary declaration between writer and readers

The recorder and dashboard use the same declarations to agree on which series columns, log facets and row lifetimes to summarize. One table shared by several series gets the union of required aggregates and the greatest requested rank. A computed measure declares every cell it reads and is missing if an input is unavailable. Log facets name either a plain value or a country resolved through the same ownership key rules as series.

Raw country IDs, canonical slots and compound holder IDs represent different identities. A compound key combines a slot and its holder ID so a new country occupying that slot starts its own series. A part sits below the owner in the composite key, allowing an owner's parts to be read as one range. Faction ID and singleton-world lines have fixed selectors and are outside country rankings. Derived columns can carry a sum, a rebased difference or a maximum across a branch fork. Recorded columns follow the child branch's actual states. A running-total window subtracts the endpoints and uses the recorded since/as-of clock and per-column reasons so an earlier unknown endpoint cannot become a zero. Its optional rest key defines which unseen parts belong to a shared value.

Relation opinion and intel-network owner/target pairs are read from keyed runs. Their key count grows quadratically, so storing their summaries could exceed the recorder's memory budget. Reads that require summary pieces such as ranks fail by name on those tables. Only a complete relation-opinion owner slice proves a missing pair has a game value of zero. Other missing readings remain missing. The supply-share denominator must be recorded and nonzero. A zero division count can be known even when the share is inapplicable. A fuel consumer without a recorded nonzero request has no received-share percentage. A held-land result is known as soon as one count proves ownership or control. A negative result requires both counts. Factory damaged totals are shown within built factories and excluded from available-factory races. Resource balances distinguish subject and overlord contributions and keep a documented remainder for native rounding.

Each summary declaration has a cost model based on estimated key cardinality and changes per 720-hour level-0 block. The design world is 1,500 live countries. For the reference run, 439 countries held block 123, with 445 used for the estimate. Use measured row counts rounded up where a recording covers a table and label assumptions for newly summarized tables. The reference level-0 pieces measured 0.6 MB per block with the initial tables and 1.8 MB after more tables were added. Outside daily country power updates, about one changed bucket per cell motivated an estimate of two. Dense log uses one change per base bucket. The verifier requires coverage both ways between declared and costed tables. The aggregate total follows recorder fold order and includes the completed span's maximum memory.

Reference measurements motivating the conservative assumptions include 3,618 stability parts, 1,062 production type totals, 1,132 air force parts, 672 air wing kinds, 256 navy classes and 28 aid rows. Lifetimes measured 514 group spans, 2,029 army mix rows, 1,580 research coverage rows and 1,420 casualty lifetimes. Around 27,000 equipment loss leaves over 439 countries were largely stationary, with fighting countries' losses changing hourly. The reference combat sample across blocks 72 to 110 contained 28,220 finalized land combats, 11,510 battle records and 2,120 naval combats. At most six naval combats were live concurrently. A retained naval-results estimate covers about five years, since that table was absent in the reference recording. Unit leaders measured 1,567 by the campaign's end, and the sampled operations history had 86 starts with at most 11 operations live. Newly summarized log estimates count their distinct facet combinations. Production spending lifetime keys let a producer read skip blocks without activity.

Faction cardinality estimates a few dozen factions with members. Air statistics rows stay while they hold a year-window value. Regional raid air scores estimate six regions per owner with an air object and update at regional daily phase slots. Party popularity budgets four observed vanilla ideology groups per country as an estimate. Production value rows include the type total and the remainder in addition to the archetypes and move with production's daily reads.

The exact units and key composition matter because several products share these pieces. Game experience and fuel tank totals hold 32,768 raw units per point. The gain strip uses fixed5, the burn strip uses the experience scale, and its parts combine that scale with fixed5. World tension uses 1,000 raw units per percentage point, while country contributions and the uncapped world sum use 100,000. The chart's remainder is the uncapped sum less the shown contributors. Resource demand is negative in balance bars. Occupation means follow fixed5 truncation and are unavailable without states. Autonomy divides progress between the lower and upper thresholds in fixed5. The result may exceed either endpoint and is missing when the thresholds leave no range. Factory channels combine military, naval and civilian selections as mask bits 1, 2 and 4. Air superiority groups by raw owner and region and reads the day's final regional scores. Country and faction losses use their holder identity, leaving unknown values outside ranks. Faction sums are recalculated with each hour's membership, so their extrema belong to the faction's own run.

Running equipment production totals preserve the world sum and each producer's archetypes and remaining output. Equipment loss leaves keep their source and design. Political party indexes only identify parts within their recorded country. Their ideology labels come from party history. A drop mark connects the hour's value with the previous recorded value. The combat log exposes modifier hours by battle and finalizations at the hour when the game finalized the combat.

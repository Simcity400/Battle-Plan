# 0402. Record observed event operands before presentation filters

Event readers copy owned operands into the recording. The runtime establishes world and thread lifetime before the read. Native addresses can correlate an acquisition or identify a call path within that acquisition. Persisted identity uses the observed reference and full native ID, with the reserved country slot distinguished from unresolved references.

A war candidate is captured before the replacement operation and verified only on a proved normal return, with fresh reads of both reciprocal slots and the complete endpoint identities. Replacing an existing relation is allowed because disposal can reenter. A candidate already in the selected slot does not prove a new link. The ticket belongs to one invocation, and an uncertain return yields no substitute event. Annex operands are copied before authored dispatch can change either role. Each event retains the hour at its observation, even if the ledger drains later.

Equipment loss comes from signed differences of native pools. A negative loss can be a gain. Live deletion classification preserves expeditionary ownership through cleanup, excludes runtime reset and rejected construction, and lets preceding damage finish before measuring the residual pool. Deception armies selected by the native reveal-skip flag are outside inventory loss. Return, transfer, and merge observations distinguish removal from destruction and avoid counting credited equipment twice. Transfers retain a full handle while the roster entry is absent. An operation that scales and rounds a pool is observed once after both steps. Scripted scaling can increase equipment and keeps signed results.

Combat uses a positive expeditionary owner when available and otherwise the roster owner. Aircraft use a positive pool country and otherwise the host owner. Resistance follows the occupied state's controller. Merge credits the survivor's roster country because the merge and combat owners can differ. The pool reader sums repeated design occurrences in its owned copies and measures actual change from the signed native quantities. An interrupted or short snapshot fails the event while retaining the observed demand for future storage.

Experience is acquired at accepted adjustments after gain modifiers and daily rejection, before addition and any cap. A positive adjustment is income, a negative adjustment is expenditure or correction, and a lower balance is insufficient evidence of either. The status's owner backlink and the live published country link protect against reuse of an address for another country.

An incoming diplomatic queue belongs to the canonical country whose root points to it and must agree with its own owner field. A null queue contributes no entries. A null slot leaves a gap in the native indices retained for other entries, just as the game's serializer does. A malformed wrapper, count, or owner mismatch fails the affected read. The action dates and saved reference retain their native representation.

Map-text observations come from simulation edges before local-viewpoint filtering, so the same recording can render for another viewpoint. Read-only operands capture the applicable province, visibility, and authored text selection for that purpose. Use the route province for a fake division's visibility only when it is embarking onto enemy-controlled sea. The game chooses the first province for a state building and the fallback victory-point selection. Building health reflects the full levels and one following partial level. These facts do not require running the game's presentation code.

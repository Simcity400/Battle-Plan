# Read replay operands from their native sources

The resource trigger evaluator and the viewer use the same resource arithmetic and recorded inputs so a display and a comparison cannot disagree on the order of operations. Amounts and modifiers use fixed5. The template amount, retained pool and gated additive form the base. Add one to the local and global modifiers and clamp each factor at zero before applying it, truncating the products in order. A resource origin holds that base amount. Its infrastructure bonus adds the level-scaled base bonus and the controller's bonus, with positive controller modifiers scaled by level. Without the origin, both origin factors are one. Apply the infrastructure and supply-route factors, clamp the scaled amount at zero, subtract the cost and add building grants. Preserve wrapping signed products and truncating division. Comparisons truncate to whole units and narrow to signed 32 bits before applying the lexer operator.

Building grants use healthy levels and the controller's overrides. Override presence depends on the first entry for the building and the amount comes from the first matching resource entry in native order. An override counts only when the combined amount is positive. Only active resources enter the authored grant lists, and a malformed grant is refused when its building is reached. The recorded resource and building indexes build on first use. Country IDs resolve through the recorded links, and the caller retains typed input failures so an unproven join cannot decide a trigger. Command power likewise reads the country row through the recorded link in the same hour with the caller's declared columns.

Partial table walks preserve the real rows they reached. Consumers may draw those rows and must not infer deletion from missing keys. An unavailable table carries the recorder's reason, and an omitted capture-mode table carries its mode. A table decoded as the wrong schema is corruption. Playback head readers may request only columns they declared. Country reference zero proves no link, while a positive reference that fails to resolve proves neither an equality nor an inequality and is refused by input and reason.

Recorded lexer tokens name authored keys without consulting the installation. Token zero is shared by rejected keys and has no unique spelling. A literal needs NUL-free UTF-8. Matching folds ASCII A–Z at the same length and refuses ambiguous matches, including multiple recorded tokens that fold to the same name. The retained token order gives callers a single allocation-free search for a set of keys and a distinction between a proved absence and a truncated lookup.

Template facts keep their operands separate until rendering. A display name is either a captured literal or a localisation key with the recorded composition country's tag. An alternate country reference joins through `CountryLinks`. Template, country and HQ sections validate text-bearing facts independently so one unresolved name cannot hide available sibling facts or an available numeric pool.

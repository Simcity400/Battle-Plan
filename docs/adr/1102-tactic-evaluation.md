# 1102. Evaluate tactic candidates against the native registry and the recorded battle scope

The possible-tactics popup belongs only to a land battle. Select the observed side through canonical primary country membership, with the naval progress skin testing the defender set instead. An unresolved reference cannot prove absence. Registry order, definitions and preference factors come from matching content, while recorded lexical tokens resolve unlock identities. Keep native IDs even for a definition whose content cannot be read. If the reader loses alignment, later identities cannot be established. A selected tactic requires exact ID and name agreement. Duplicate names retain independent registry pictures, while exact lookup of a name uses the last bucket registration. The null object can be the result of a proved miss, with an incomplete registry unable to prove one. The per-entry picture diagnostic and the inventory of successfully resolved sprites are separate views of that registry.

The tactic content shares the unit-leader traits, country-leader traits and sub-unit inventories with other readers. Trait lookup uses the native registration identity and identifies conflicting ordinals. Scripted bodies are loaded after tactics so phase references can use every registered phase. Known trigger keywords and scope forms take priority over scripted names; content count names and scripted names follow their own readers. Read mod layers as the content stack does, with the higher-priority file replacing the same path and a later template body replacing its earlier declaration. Recursion that never terminates is refused by name. Localised tooltip bindings are not child conditions, even when the content defines a scripted trigger with their name.

Bare keywords compare without ASCII case. A quoted token is not a keyword, though a quoted scope name or value may still resolve through its own reader. Retain each operand's rules for exact text, case folding, first-NUL handling, and decimal or radix-aware numeric parsing. Later occurrences of scalar fields replace earlier ones. Boolean fields accept exact yes or no, retain the previous value on invalid text, and name refusals if the reader loses alignment. Defaults allow active tactics and use defending polarity. Repeated trigger and base bodies append to the same objects. A scalar trigger is dropped and a scalar modifier is empty, while an unaligned base value refuses. A single-value reader can consume an opening brace as its value and then treat the remaining tokens as the surrounding block, which is not equivalent to skipping the whole nested block. The test guard checks that production uses the keyword helper and permits separate comparisons only for values that use their own case rules.

The popup reads the battle side as its combat scope. ROOT, FROM and PREV initially carry that scope; a nested country drops its combat context, and the bare combat scope does not supply a country carrier. OWNER selects the side's first primary country. Follow dotted chains from the preceding resolved scope. Decode variable-held scope references through recorded stores. A country without states uses its recorded original-tag buckets; a complete empty bucket can establish the keep-own fallback. Tag evaluation respects the operand's selector, country or scoped variable form. A character has no direct THIS country tag; for ROOT, prefer the unit leader's recorded country over the character's. Reference zero remains separate from positive country slots. An incomplete country or lexical table cannot establish absence where the trigger needs the missing entry.

The case-folded token table supplies the first interned spelling of a `has_tactic` operand, and the tactic registry then compares that spelling exactly. An active tactic holds and an inactive tactic needs the scoped country's recorded unlock. Unlock IDs resolve to their registry tokens; ID zero identifies the active null tactic. The trigger's country-only applicability is distinct from the tactical combat triggers. Phase checks use the resolved phase ID even with other comparison operators. Terrain comparison uses the first registered case-folded identity, with a missed or quoted terrain operand selecting the null object. Unit composition treats a division without a template as empty. A present template with no verified aggregate is unknown. Its hourly width terms cover all active sub-unit slots, but aggregation does not preserve the original grid partition, so only use them for signed small-integer grid counting when the total itself proves no grid can overflow. Compare all participants with the native min or max rule and name the equality case that the game asserts on. Measure category shares from the full ordered side roster, with the native empty and exceptional fixed-point outcomes. Verify each participant and relevant movement source before establishing full frontage.

Combat `has_trait` uses the commander's recorded character and its assigned role traits. A null commander character is false, and the tactic scope's absence of a scope character means no retirement check applies there. The character scope uses its own recorded roster and role sources. Unit-leader and country-leader trait names resolve to the first definition, and a later same-named assignment does not match it. An unlinked character may fall through to other roles. Ordinary retired characters have the applicable trait restriction; skill does not use the same restriction. Operatives and scientists follow their own recorded references and roles. Count triggers check their accepted scope before reading a table and use their own integer or fixed-point comparisons. Building counts distinguish the country or state's ownership of state and province buildings. Resource and ideology counts use the hour's recorded values, including carried definitions and applicable adjustments. An unresolved owner cannot be silently excluded. A coded keyword can take priority over a same-named equipment category.

Apply base and modifier fields through the common mean-time reader. A weight starts at one, and valid numeric text uses the field's own integer or decimal scanning. Scoping a constant can yield a signed fixed-point value whose integer comparison truncates. Other nonempty weight modifier values read a variable or scope, only if the condition holds. Country preference uses both its define and accumulator; leader preference uses its define. Normalize over the positive weights of all candidates, including choices filtered from display by country. Missing relevant values withhold their dependent parts. Positive `only_show_for` restricts to an equivalent country; a proved unregistered tag is unrestricted. Show unlocked entries first and then descending signed chance, without a fallback ID tie-break. Retain the original sort's partition, insertion, and heap repair behavior to preserve the visible order of equivalent entries.

The popup localises a recorded or authored name before inserting it into the heading and keeps a missing key's own bytes. The name limit is counted in native bytes after text processing, with invalid cropped text refused. A chance is scaled, rounded half away from zero, and passed as its low 32 bits. Effect values use normal text truncation. Display phase falls back to start phase only when display phase is unresolved, with both unknown hiding the widget. The battle variant keeps the authored preference text without adding country- or leader-selector arguments. A missing picture or other unavailable field clears its authored value and hides the affected widget with a specific reason. A partial registry or unsupported text refuses just the affected result.

# 0706. Keep deployed stat operands separate from designer inputs

The active army block and its deployed panel words are read as retained native operands. Template-designer recomputation is a separate source. The caller owns the stopped acquisition and active-stat writer witness. Definition defence, breakthrough, hardness, attacks, organisation, strength, movement speed and weight use native signed fixed-point representations. Width and attack are the reached definition terms without the later contextual contributions. Projection owns clamping. Transport demand rounds each selected occurrence and applies signed narrowing after the per-occurrence calculation. Coastal exfiltration follows the native byte retained by the active block, including the native grouped-subunit combination.

The status pass verifies each selected raw block and can gather distinct uncached blocks ahead in bounded batches. The normal admission order remains in charge, and the incomplete records fall back to their one-record path. A successful raw maximum from the exact same block can supply the later attack pass. That pass reads the attack scalars and terrain header together, then authenticates entries in order. The terrain entry at index zero belongs to the first real database terrain, after its null slot. Movement selectors share relevant observations without moving a later read ahead of an earlier authentication gate. The fort, river and snow movement terms are independent of the attack scalars. A refused adjuster leaves its optional movement terms absent. Fuel and anti-air words outside the original span are acquired separately, and the panel pass reuses an anti-air operand already acquired for that same block. Suppression is a separate designer witness read with the panel, since the deployed panel does not show it.

The native integer movement calculation depends on all three signed inputs exactly as stored. Exceptional signed values, wrapping, low-bit exponent handling and its zero result for the wrapped signed minimum are part of the calculation. Memoization must key the original operands without normalizing them.

A country-local clone can retain a global definition index. It is global only if the indexed global slot holds that exact object. The null subunit has its own identity, token and database slot. Requirement vectors contain an ordered archetype pointer and amount for each entry. The first reached entry supplies equipment selection, and transient native pointers never become published archetype identity. Category masks, sprite selectors and category modifier keys are separate. Land speed can add the priority subunit's own modifier and the modifiers of its listed categories, retaining native order and repeated occurrences.

# 0402. Close observed dispatches at their native completion points

Launching a nuclear strike schedules it. The strike outcome begins with the delayed impact and closes before the authored notification so subsequent effects do not change attribution. The impact identifies the launcher and target independently, and war support belongs to the resolved state owner. A target without a state has no recipient or state-building damage. The impact's type determines its province coverage. Unit reads preserve native order, keep signed strength and manpower operands, and distinguish a supported division or railway gun from an unreadable or unsupported occupant. Divisions may name an expeditionary victim. Railway guns use the roster owner and have no organization operand.

An operation outcome enters the recording after successful native completion, before the manager can destroy the instance. Terminal calls that return failure supply no second outcome. Only copied description bytes and owned row data may leave the callback. Copying the stored string into the byte ring also works when its logical span crosses the physical boundary.

Power observation distinguishes current balance from applied changes. Writer observations are checked against same-hour conservation over every authenticated live country, while startup and loading establish baselines. Command-power acquisition authenticates the original country independently of its political status. A missing status on a different path cannot withhold that identity. Presizing from live roster and lexical data gives capacity hints. Scripted bursts and keys beyond the hint still count their demand. The daily view preserves each timed charge and active-ability upkeep occurrence, traverses all outgoing relations and assignment vectors in order, and reproduces the observed fixed-point intermediate conversion even on overflow.

Script event observations follow native admission and never reevaluate fire-once or option gates. An admitted pending instance differs from an optionless event, and a negative option ordinal selects the immediate option. The delayed pass observes cursor boundaries and admitted timer changes. A fired-set witness exists only when a node is removed or a completed insertion changes membership. Load-time references awaiting resolution are separate from the serialized fired set.

Decision taps can stage a witness before a store, with publication after the original writer completes. This preserves ordinary, timed, and targeted lifecycle changes without reimplementing their selection logic. Timer extensions enclose the scalar add and candidate finalization encloses its clears. Their older descriptors remain as definitions for readers and tests, while the installed observations use the completing boundaries. A return that bypasses a store has no change to publish.

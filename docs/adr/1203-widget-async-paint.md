# 1203. Fetch widget structure separately from live paint

Raid lists draw the phase recorded at the shown hour and date rows by that phase. Filter raiders at the date of the row. An unidentified raider can appear in the all-country log but cannot be matched to a selected country. Request the participants' dated labels with structural rows so scrolling does not generate reads. Prefer the target's state label to its province label. When the target name is unavailable, show its id and the reason for the missing name. Update preparation text from the clock between phase changes. A repeated tally count can cross a holder change, so split compressed counts at recorded identity spans before applying a group or range filter.

Refit and repair panels keep queue and labels in their structure. Hull and line progress change in live cells, and the painter updates them each frame, on seek and on push before reporting the displayed hour. Where the live reply lacks an override, fall back to the value in the same panel read. Report unknown repair or refit rows with the missing source table. Selected ship names can be witnessed names, reconstructed names from recorded naming operands and content or, if neither is possible, design or class names. Name the source in the tooltip. Hull and refit ratios require recorded positive denominators.

Preload the renderers used by a page before mounting its widgets. After mounting, prefetch other widgets one file at a time only while paused and genuinely idle (never starting or stepping while playback is running, with no forced idle timeout and requiring remaining idle budget), preferring `<link rel="modulepreload">` from the build's widget chunk map so fetching does not execute module graphs on the main thread during playback. Settings may use an already-loaded renderer without suspending. Failed idle prefetches leave retry and error display to the widget that needs the renderer.

The scoreboard uses the service's recorded column registry and retains unrecognized saved choices as unavailable. Its Top selection follows one panel that sends the ranked countries with their column values. Keyed selections follow column queries through the table family host. The worker lane projects membership, sorting and values without React commits on head or membership changes (see [1398](1398-widget-family-contract.md)). Pinned reads use the same projection over exact replies.

Ship sinkings appear when first recorded. The sinking hour determines their order and country attribution, even when the recording first lists them later. Ship class choices appear with their first recorded sinking and remain scoped to the branch.

Special-project history asks once per country and branch and clips each tag's reply to the selected native holder's dates. Date a project first seen complete by that observation bound, never as an exact historical completion. Use the latest bound when grouping already completed cards. The Current view retains all completed projects and ignores the former retention-days setting. It renders changes to card order, category and other structural fields, while progress and iteration values paint on every frame. The history groups equal adjacent observations, leaves missing intervals as gaps and dates a captured completion from its recorded event rather than by the later read proving it. Tooltips preserve absence, bounds and the hovered reading. Stable panels keep scroll position during playback. Switching views uses a new scroll surface. Detail rosters unavailable at an hour stay unknown. Paint daily scientist, facility and variable values from their dated pushes. Fetch scripted reward and effects text only while its details are open because it can require multiple tables.

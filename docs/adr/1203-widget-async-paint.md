# 1203. Fetch widget structure separately from live paint

Raid lists draw the phase recorded at the shown hour and date rows by that phase. Filter raiders at the date of the row. An unidentified raider can appear in the all-country log but cannot be matched to a selected country. Request the participants' dated labels with structural rows so scrolling does not generate reads. Prefer the target's state label to its province label. When the target name is unavailable, show its id and the reason for the missing name. Update preparation text from the clock between phase changes. A repeated tally count can cross a holder change, so split compressed counts at recorded identity spans before applying a group or range filter.

Refit and repair panels keep queue and labels in their structure. Hull and line progress change in live cells, and the painter updates them each frame, on seek and on push before reporting the displayed hour. Where the live reply lacks an override, fall back to the value in the same panel read. Report unknown repair or refit rows with the missing source table. Selected ship names can be witnessed names, reconstructed names from recorded naming operands and content or, if neither is possible, design or class names. Name the source in the tooltip. Hull and refit ratios require recorded positive denominators.

Preload the renderers used by a page before mounting its widgets. After mounting, prefetch other widgets one file at a time while idle, so an added widget can appear without competing with page rendering. Settings may use an already-loaded renderer without suspending. Failed idle prefetches leave retry and error display to the widget that needs the renderer.

The scoreboard uses the service's recorded column registry and retains unrecognized saved choices as unavailable. It subscribes its rank and column queries through the table family host, projecting membership, sorting, and values inside the worker lane without React commits on head or membership changes (see [1398](1398-widget-family-contract.md)). Only a service refusal blocks the followed stream; pinned reads use the same projection over exact replies.

Ship sinkings use immutable order supplied by each window, indexed with that window's dictionary. Distinguish event date, which sorts and filters, from the supplying read date that makes the row visible and dates country attribution. Lexical keys unresolved in content stay branch-specific. Plan a block of rows and their label reads once, then reveal them on the clock. Keep a drawn window through a playhead crossing, so entering it cannot release that read and request it again.

Special-project history asks once per country and branch and clips each tag's reply to the selected native holder's dates. Date a project first seen complete by that observation bound, never as an exact historical completion. Use the latest bound when grouping already completed cards. The Current view retains all completed projects and its migration drops the former retention-days setting. It renders changes to card order, category and other structural fields, while progress and iteration values paint on every frame. The history groups equal adjacent observations, leaves missing intervals as gaps and dates a captured completion from its recorded event rather than by the later read proving it. Tooltips preserve absence, bounds and the hovered reading. Stable panels keep scroll position during playback. Switching views uses a new scroll surface. Detail rosters unavailable at an hour stay unknown. Paint daily scientist, facility and variable values from their dated pushes. Fetch scripted reward and effects text only while its details are open because it can require multiple tables.

# 1102. Preserve retained naval result ordering and text

Readiness gates the displayed outcome. An observed member of the selected winning side establishes victory. Defeat requires a complete winning-country list. Authentication of all country references precedes sorting. Keep the game's insertion, buffered run and adaptive merge comparison order. The ship comparator can answer true in both directions for some viewer-country pairs, so substituting a total-order sort would change the visible output. Keep native insertion's first-element shortcut, the separate pride and convoy status, and stable admission order for tied convoy costs.

Group survivor and lost aircraft independently, ignoring a lane only when its own count is nonpositive. Rank countries with the viewer first and then by canonical slot, and preserve the respective grouping order. The ordinary ships, aircraft and convoys enter in that order, with the highest-priority aircraft kept in the visible first row. For ship priority, truncate each ship's recorded build cost before summing. For aircraft, multiply the recorded variant summary inputs and truncate before applying the count, then negate the total and divide by five. Retained hit summaries append all three hit lanes in stored order and sort by viewer, canonical slot, member kind and descending hit score with stable ties.

Resolve an aircraft icon's archetype name before its authored sprite identity. A convoy or null sub-unit keeps its copied type, while other ship types use the viewing country's localisation. Variant display prefers a nonempty stored name. Otherwise use the recorded lexicon and effective equipment definition, localised for a positive origin country's own tag or for the creator's original tag if that country is dynamic. Resolve aliases to canonical countries. The null country uses the fallback tag. Append saved suffixes only when their flag permits it. The stored name and suffix are exact in the recording language.

Accept three authored pride colour values as HSV or four as RGBA, and apply power 2.2 to RGB only in sRGB mode. Keep one-based authored image frames aligned with zero-based bindings. Damaged ships list individually and full-strength runs coalesce by native country, cost and strength comparison. Send only the selected localisation branch's arguments. Use the viewing country's short-name localiser and include a small flag and capitalized definite country name for aircraft origin text. Long detail lists show the heading and first twenty lines, then the rest. Retained sinking text has a separate key from active sinking.

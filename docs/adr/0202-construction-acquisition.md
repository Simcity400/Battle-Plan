# Carry authenticated building rows and stage construction reads

Building status observation is shared by construction, territory, rail and raid capture, including the infrastructure and province fort inputs. The building observer owns those notifications and forwards them while the original write is in flight. Nuclear strike capture also receives building damage from this observer. Enabling the observer family uses the runtime's shared suspension round and waits if a thread is still in the family. An unreadable receiver revokes the affected certificates conservatively. Entering the developer map editor removes the basis for certifying reuse for this attachment, including the forwarded air base, territory, rail and raid domains. The hourly callback invalidates the epoch after a load, gap or recovery. Sizing and collection of replaced watch tables happen away from that callback.

`building_changes::Hooks::new` relies on runtime build admission and an authenticated executable in the current process. A withheld site leaves the family uninstalled, so the building tables read every status afresh. The caller owns the installed family exclusively. `building_changes::Hooks::drop` can release the watch table when the hooks were never enabled or when the caller has already restored them and drained native calls after the last capture. The caller proves this before releasing code or unloading.

## Carry rules

The Governance job walks and authenticates state and province locations in native order. Before reading a status it registers it for the epoch. A held entry matches only when its identity, location, vector headers and observation certificate still match. Duplicate status entries cannot authorize carry. Empty statuses still register and have their active vectors checked. They count as neither read nor reused until a writer touches them. A failed advisory allocation withholds the certificate for the next hour and the current walk still reads the rows it needs.

A complete walk can authorize the next hour to skip the location walk when it held every status, both table headers match, and the hour's take confirms the same epoch. The take happens before any registration or read it certifies. The next take sees writes made after it. A settled hour refreshes touched statuses in their original positions, reusing the index if the same statuses stay in the same order. It reads no status when the hour is quiet. A refused read of a held status, a changed table header or an incomplete walk leads to a fresh location walk. The store owns only the latest complete read and places state rows before province rows. Invalidating it from the game thread is allocation-free. The worker measures retained memory and publishes counts for reused, read, empty and touched statuses, row counts, and quiet and settled hours. Offline tests compare those different read paths with both tables from a full walk, including changed counts, withheld vectors and registered statuses outside either table.

## Owned copy and decode

The World job owns scheduled construction-rest rows, with state resistance supplied by the hourly state worker. The raw staging pass shares a state census between resources and building targets and a country census between queue, occupation and collaboration. The first unreadable country ends the admitted prefix. Staging records the exact byte spans expected by the typed walks, including the constituent reads of game strings and the headers and entries of occupied-country tables. A repeated string occurrence contributes to demand even if its read fails. Live construction targets are authenticated before following links, including the map slot round trip. The copy pass uses the current occupation database for fallback law and records aliases that a direct census may skip. An overflowed staging pass keeps the typed route available without submitting a raw payload.

A single FIFO worker replays those walks from copied bytes. It grows the reusable job and its route, law and other arenas away from the game thread. The per-hour raw gate survives the reset required by that handoff and clears after decode. The staging plan reports independent root failures and uses a shared failure mask where the direct read shares a root. Building and railway share queue roots, and the occupation outputs share their occupation walk. Optional suffix failures remain scoped to their own values. Original read failures take precedence over grant and arena failures. The worker does not retry accepted acquisition failures by rereading live memory. The spool thread applies the shared row ordering, duplicate-key checks and field masks. The enclosing callback converts QPC ticks and measures its own full elapsed time. The verified native cancel flag determines the row's cancelled value.

Capacity follows observed demand. Occupation settings reserve one row per canonical country, which is the same census used to grow the staged settings grant. Other row grants keep their direct walk's truncation behaviour. The fixture exercises alias resolution, default and override strings, payload failures independently of pointer reads, retained grants after a real failure and the exact read ranges between location and building storage.

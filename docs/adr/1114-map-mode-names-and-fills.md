# Keep map mode names and fills tied to the current view

The incremental political and naval layers draw the default mode. The mode fills worker rebuilds other stock modes from the head's recorded rows, using the recording's executable tables for triggers and the selected country only for diplomacy. The scripted fill is refused by name because its borders persist across refreshes. A worker that rebuilds on a cadence cannot reproduce those state transitions. Mode changes clear the old fill immediately. A missing input leaves the new mode loading or refused by name.

Country names are kept by canonical slot and connected area. A changed province marks the former and new controlling areas. Naming inputs and follow-up links mark dependent countries, including ones whose previous resolution failed. The mapping uses the highest native id when more than one country row names a canonical slot. An unnamed dictionary entry is a named refusal and keeps the country's known tag. A component already placed with the same tag and text keeps its placement.

The names worker applies its own column copies in step order and returns each product only after all its affected areas finish. Work can run ahead, but the frame takes a product only at or after that step's hour. A reset sends its camera state with the rows so the initial picture is ready at the requested zoom. A pace change that invalidates steps restarts from the applied mirrors. Placement stays off while zoomed closer than `DRAW_COUNTRY_NAMES_CUTOFF`. Dirty areas accumulate, with placement scheduled when the target camera height admits them, during the zoom transition.

The content's far and near name rules select the country worker, whole placements for other area types, or no names. Switching between modes that both use country names can keep the worker. Leaving that kind of mode clears the shown names and queues. A return composes from the applicable mirrors because the worker missed steps. An unrecognised scripted naming mode is refused by name. The scene receives changed country areas independently and receives the whole set again if another install replaced its generation. Whole mode placements reach the window only once the scene has their glyph buffers.

Proofs compare the stepped and freshly composed views. Tests hold one placement while other areas change, exercise zoom cutoffs and mode handovers, and require glyph buffers for every placement handed to the window.

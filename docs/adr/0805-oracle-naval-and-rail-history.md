# 0805. Reconstruct naval history joins from saved occurrences

Saved records preserve native occurrence order. Province buckets require dense ordinals. When raw country aliases resolve to the same tag, compare full saved tuples with multiplicity. Ship names follow the serializer’s first-NUL prefix. Names authored in definitions cannot substitute for the class tokens the writer emits. A stream argument typed as a C string does not independently prove where an unverified sink stops writing.

Reconstruct order-of-battle joins once from the nested save structure. The enclosing theatre supplies the group roster and its order, the theatre-group listing supplies membership, and the enclosing field-marshal group supplies ordered child membership. A formation’s captured raw country reference is a separate value from its owner in the saved roster. Require positive references to resolve and only compare an independently saved reference when one exists. The recorded group roster and the division’s own parent pointer are independent witnesses. Report disagreements between them even for a division absent from the save. The reserved roster and physical census jointly prove which formation omissions are expected, and a positive physical alias remains within the ordinary serializer’s scope. Captured regular-group units absent from a saved grouping payload need that scope proof as well.

Retain canonical and reserved naval objects according to the authenticated enclosing country census. Without admission the comparison remains strict. Exclude global repair bases only if exclusively owned outside scope, keeping shared and unknown provinces comparable. A carried refit source can remain present after its work order retires, so only a currently resolving full reference certifies a saved refit. The same applies after repair fleets transfer or disband. Use hourly production operands when the daily line table has not reached a new job.

The railway’s selected building is runtime-only. Compare independently saved building-health scalars using the recorded template token. Positive saved edge levels require sorted-pair presence. Nonpositive saved levels do not prove whether the game has a pair. Check exact signed values for recorded pairs and report the remaining presence limitation. Retained accident damage has no serialized counterpart.

# 0805. Check occurrence history separately from saved event state

Text saves omit transient map events. The oracle checks the recording itself for adjacency, sequence, and lifetime. A gap starts a new epoch with coverage unknown. The interval must end at its frame hour. Events at the save hour must join that frame’s provinces, building types, and positive country references. Raw country reference zero is reserved and has no country link.

Script event checking compares save-certified retained state, including timers and decision registries, separately from unsaved occurrence and combat history. The comparison follows the save tree iteratively. Its finite size bounds the traversal even when the recorded graph shares nodes across branches. A missing target storage witness refuses that part of the scope while leaving other known operands comparable. Each named owner and retained domain can fail independently, so an uncertified owner cannot hide a certified sibling’s difference. A missing owner name or unreadable frame context prevents the entire comparison because neither side can then establish the owner joins.

A faction theatre’s saved list position is its captured ordinal because the writer walks the native theatre array in order. Raw country aliases are resolved to saved tags before comparing theatre members.

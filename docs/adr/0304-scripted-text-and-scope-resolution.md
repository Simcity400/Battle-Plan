# 0304. Evaluate scripted text in its recorded event scope

Scope resolution shares the script parser with the game-data readers and builds each join only when its hour needs it. A known null target is an ordinary result. A missing link or incomplete table is a named refusal, while a valid earlier match can avoid later incomplete rows. Saved targets choose the first matching name before checking its validity. A positive raw country reference requires a recorded link. Raw zero uses the authenticated reserved object only in native getters that admit it, while clearing a scope can still leave it with no carried country. Text and event scope deliberately differ on this point. Faction leader selection uses the first member's recorded raw id, and ordinary scalar consumers retain their distinct zero-link convention.

The original-tag iterator uses the stored buckets and the physical country array. Canonical country slots cannot reconstruct their order, because a mutation can move a member without changing final country operands. An owning own country wins. Otherwise the walk can choose the first owning bucket member, and the caller accepts only a positive owning result. A nonpositive selected word avoids demand for the lists, and repeated positive occurrences remain. Alias parsing tries recorded country tags first and then the recorded content's alias database. The standalone recorded resolver can name an alias refusal even where a text consumer has enough context to evaluate the alias from the viewing country. Unsupported target families such as occupied state promotion have a named refusal.

Each bracket starts from the saved localization context, with dot-separated segments promoting the active object before resolving the final property. Name-only expansion admits only its separately supplied recorded names. Promoted ROOT, FROM, and PREV become the active scope for later segments.

# 0704. Record authoritative inputs for espionage and replicated commands

An espionage operation is identified by its dynamic full handle. For both owner and target, resolve the recorded country reference. The optional province target must authenticate before its state link is read. The operation definition contributes its authored lexer token. Its embedded timing object is separate from the name dictionary. The start hour comes from the game date, and save serialization writes it when duration is nonzero.

Keep the exact description bytes retained after the selected effect applies, along with the operation's terminal, bonus and risk-trial flags. Completion trims trailing whitespace in the retained text, and save serialization only writes that description for terminal operations outside checksum mode. It writes the true bonus and detection flags independently. Effect selection uses the bonus trial, and detection dispatches its own action. The leader has no persistent detection flag. An operative description length is string metadata and must never be interpreted as exposure. Capture the operative's authored name or key separately from its localized display and capture codename operands separately from the generated cache. Respect the native string bounds without a smaller reader limit.

Store operation parts from the native vectors in order, with repeats. The shared arena receives selected phases, requirements, pool variants, and archetype totals in that order. The requirements compare the stored per-archetype totals, and a civilian-factory requirement has no equipment type. Keep preparation amounts as signed fixed-point values and times in native units. Both the equipment type and its archetype must authenticate when present.

Recruitment uses the agency's inline recruitment object. Walk its three persistent holding vectors in native order after the active roster. A repeated operative in a different holding vector is a distinct membership. Retain the full handle, roster country and roster kind together. Keep the native ordinal, the separate action discriminator and the active target. A missing active operation locally refuses that membership, names the reason and increments the refusal count, even on a sizing pass. It must never be treated as additional capacity demand. A failed authenticated membership read withholds the table. Use the same signed fixed-point scale for experience and required experience. The operative trait count is read as a 32-bit unsigned word, and the game's signed interpretation of that field is unresolved. The mission and cooldown paths are selected separately by assignment. Pending missions start on arrival, and starting and stopping an operation changes the assignment and stored operation handle independently of its other state.

The command reader authenticates the in-game idler before reading its pause state. At the menu or under another idler it returns no in-game idler. Execute slots skip vanished list references. Human and automated host retreat commands can have the same replicated payload, so unavailable authorship stays unknown. In scripted windows a global scope has no explicit country and uses the authenticated actor as appropriate. Missing command tables hold back the family before owner resolution.

The relation variants share the base relation field reader. A relation's type word and class identity distinguish it from the others, so an offer never stands in for an access grant. The air-base and docking-rights offer constructors allocate the same object size. The null tactic's explicit singleton denotes absence of a preferred tactic.

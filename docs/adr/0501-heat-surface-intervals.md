# Window heat displays independently of their recorded reads

Heat strips reuse TimeChart for date axes, zoom, pointer and keyboard navigation, and tooltip ownership. Rows scroll beneath the fixed date axis. A prepared head column and playhead can paint between renders; the columns wake painting by identity. Keep preparation bands distinct from cells with unknown values. A period may summarize several reads and leave the pointer at its original hour, while exact cells can snap to the read and contribute keyboard stops. Clip geometry to inclusive period bounds and never paint a future read. Merge identical adjacent paint runs to avoid thousands of equal stripes without merging their tooltip reads. Recheck font metrics even if the clamped label column's width is unchanged. [Heat chart](../../ui/src/charts/heat/HeatChart.tsx) · [Heat layout](../../ui/src/charts/heat/layout.ts)

Window heat matrix rows and columns according to scroll position, with a fixed gutter and header. Report only shown rows and columns for artwork requests. Missing live keys use the unknown hatch, while an explicit null is an empty cell. Keep a selected cell attached to row and column identities across structural changes and clamp to the nearest in-range coordinate if an ID disappears. A fresh keyboard action may take the shared tooltip, while a retained keyboard cell cannot take it again during a paint. A narrow layout can reduce labels to flags, which retain full names on hover. Use a neutral centre for signed quantities and leave a side with no valid extent neutral.

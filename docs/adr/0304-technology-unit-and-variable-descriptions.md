# 0304. Preserve reached operands and ordering in technology, unit, and variable descriptions

Technology and project descriptions share sub-unit bonuses across scripted effects and bound localization. A bound technology effect includes its ordinary effect body and omits timing, prerequisites, prose, and debug details. Completion effects get a fresh technology-country scope, after evaluating their conditions, so caller links cannot affect the result. The enabled roster preserves registration order, checks recorded DLC, and de-duplicates definition pointers before applying the leading limit. Filtered display entries do not change which original roster pointer gets the final conjunction. Registered sub-unit spelling is resolved directly so rejected names cannot become the zero token. Equipment names consult qualified current or original tags and fall back to the selected template. The bound helper can explicitly choose recorded country zero.

Special-project completion uses template output. Execution-only `iteration_output` does not pick tooltip effects and `show_modifiers` defaults to enabled. A null template can leave the authored operand as text, and null scientist and province scopes contribute no corresponding body. Output uses a fresh country scope, scientist scope, or facility state in native order. The project's FROM, local facility-province variable, and viewer-country equipment names are separate inputs. When no scientist is explicit, the first roster scientist with the needed specialization level can qualify. Raid target selection stops at the first qualifying province and program in recorded order, even if it has no active project. Raid progress derives its duration with the fixed-point undefined-value path and evaluates the progress operand again for its separate display argument. Research bonus text preserves original roster positions for separators, uses native argument types, and keeps reader-specific headings and wrappers. Effects that require a concrete technology or doctrine cannot silently substitute unrelated content.

The recorded divisions census establishes Army existence. Unit names follow logical rather than roster ownership, and only raw zero maps directly to reserved country zero. Some effects must establish that unit or template before evaluating a numeric operand or looking up its name. The roster of equipment candidates uses the captured country, roster kind, and ordinal. Repeated equipment blocks update the same reference, and a later pending token can replace the cached entry. The first exact version/creator match can make later missing columns irrelevant, while reverse-order fallbacks use their own first matching candidate. Distinct definition handles merge only if their version, type, creator, and origin agree. A resolved variant gates amount evaluation. The variant name retains spelling after an authored variable prefix, and the archetype path ignores the variant name operand. Amounts preserve fixed-point narrowing, then suppress nonpositive entries as the game does.

Creation chooses default modules and ordered explicit changes separately. An unknown module leaves the preceding slot value, and explicit module selections are a separate vector from default categories. Spawn scoring reads installed war and subject links without date filtering, considers recorded mixed occupants, and can still describe an unresolved location. A successful earlier candidate does not hide a later unknown score. Copied scoring scopes retain the caller's original random counter and reevaluate the owner after advancing the copied seed. Region scoring reads every reached score even when only the selected state appears in the final text. Sub-unit and category bonuses keep independently ordered lists and repeated selectors. Terrain data is reached only for a possible terrain adjuster. Unrecognized authored keys can produce a named refusal while recognized fields preserve the game's failed-scan semantics.

Descriptions execute supported temporary scalar setters in their own session. An empty tooltip can short-circuit operand reads where the operation has no description-side write. Empty leaf formats do not execute unrelated setters or array effects. Scoped random operations use recorded words and the description session's own variables. A scorer reuses one fresh target scope with a copied caller as FROM. Invalid scorers write no destination. Each target evaluates before sorted scores and lengths are published, and repeated entries replace scores. Stable descending sort preserves equal scores in native Robin Hood bucket order. The map extends probing past the mask and rehashes physical slots in order on growth so ties remain reproducible.

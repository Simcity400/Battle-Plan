# Keep equipment losses with their coverage evidence

The historical product reads running totals by cause, equipment type and design, using the declared series for chart bins and exact reads for the requested hours. The followed head uses the same leaf keys with live cells. Resolve the country incarnation at the window's end unless the request names an incarnation that held the tag within the window. Use the recording's localization and authored interface for cause names, with app labels where the writer classification has no suitable name. Equipment amounts use fixed5. Mixed causes require a recorded equipment classification before splitting land and air. Supply named refusals for unknown coverage, including a Combat Log retention below one month that can prune even current-month losses.

Destruction and Combat Log land coverage describe different evidence. Read recorded coverage from each run's start so an unknown span or incomplete drain can flow into the requested window, while exporting each run's exact counting and withholding boundaries (`destruction_runs`) so contiguous branch loads and recording breaks stay separate without inferring boundaries from restarts or clean coverage spans. Gate destruction totals, bins and exact reads on the selected run's counting boundary so uncounted startup hours never inherit earlier-run totals or synthetic zeros. A missing drain after counting begins cannot be recovered by later complete drains. Keep the distinct reasons and the hour each began, and publish recorded withholding refusals even when no hour was counted yet, falling back to a neutral withholding message rather than assuming truncation. The run row tracks overall drain, its structured `drain_state` bitmask, unread records and unresolved references, while the identity row names land coverage, fallen convoy counts and lend-lease exchanges that ended after their last read. Those exchanges make the running total a lower bound. Classify current recordings from `drain_state` so display wording never confuses startup or branch partial intervals with withheld reads; recognize the frozen legacy partial-interval string only when reading historical recordings that predate `drain_state`. On current recordings an empty drain reason is complete only when `drain_state` is explicitly complete, and an unrecorded `drain_state` reports a destruction gap (preserving any recorded detail text) rather than guessing a classification from text.

Search the declared sunk-ship log only in occupied six-hour buckets. Date each ship by its sinking hour and retain the greatest observed count for each signature. A later listing does not erase an earlier count. Add chart bin endpoints only when they change, with exact reads available separately. An unrecorded value does not establish that a prior amount ended. Unavailable totals tables supply no exact values.

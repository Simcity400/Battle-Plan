# Resolve GUI sprites, fonts and artwork through one content view

Load GUI resources from the content stack's ordered files. Resolve the latest exact sprite name and try the configured fallback sprite only for an undefined name. A successfully named sprite with a failed texture does not take that fallback. Convert extension candidates to virtual filesystem byte paths and use the first existing file, retaining a path's raw bytes for reads. Keep the authored extension as the last candidate. The decoder distinguishes an absent or malformed texture the native renderer would omit from an undefined or graphics-device-dependent result. The latter needs a named refusal. A caller can also refuse textures above its decoded-memory budget before allocation. A cube texture does not satisfy a GUI surface's two-dimensional binding. A visual override that cannot be drawn can fall back through recorded content with its existing diagnostics.

A sprite's size query and its drawable geometry use distinct conversions. The query truncates the reciprocal frame count times the texture extent, with the native invalid-integer value when the arithmetic cannot represent a result. Geometry uses the floating result and vertical scale. Preserve the authored effect and use the dedicated effect for masked-shield overlays. The last global colour table, cursor offset and selection offset in load order determine those shared defaults.

The font file list follows assignment order. `path` appends and `fontfiles` replaces. Closing the declaration installs family zero. A font override attaches to the font selected by name or fallback at the time it is read, and repeated lists within the override append. Names compare exact bytes within the fixed bucket registry. An absent name uses the latest font in the lowest nonempty bucket. The first family matching the language bytes wins, otherwise family zero supplies the files. The selected family preserves file positions even when metadata is missing, so glyph texture pages remain aligned.

Font glyph and kerning files use the native token walk. Line boundaries do not delimit records. The first file holding a codepoint or kerning pair wins. Line height and baseline come from the first file, and texture paths use bytewise extension resolution. Font-specific text colours retain the first stored colour for each code except code zero. Font draw geometry uses the viewport stored when the font is built. Its auxiliary colour can affect an early sprite bake before text objects restore the default. Integer component writes from offsets may reach later font state. Model the named effects of those writes and refuse any subsequent operation whose required resource state cannot be determined.

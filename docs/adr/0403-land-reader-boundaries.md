# 0403. Bind front geometry and doctrine reads to their owning census

The Orders work binds a complete owned plan census to a sorted list of front handles without reading game memory. Front acquisition can run separately with just that binding and copies every distinct live front's sections and province pairs. It keeps the same order, required capacity and first refusal as the combined walk, and grows worker storage from the inputs it actually admits. If the plan census is refused, there is no partial front census.

An order finds its section through the front's pointer array and the section id. The front keeps the complete reference handle. Each section authenticates its back-link to that front, then reads pairs of province pointers. A guarded gather reads each province's identity and id together. When its result is incomplete, the ordered per-pair path reaches the same refused field even when the province identity itself is readable.

A destroyed front may remain bound by an order until the order is removed. A format-23 recording showed isolated refused hours under that condition, and the orders were gone by the following hour. A registry miss on a bound handle therefore produces no front row. Registry read failure, a bad type or a mismatch with the registered object still refuses the read. Geometry lives on the section. Batch guarded reads of province pairs and their identities while the game thread holds a stable view. On incomplete batch reads, use the same checks as the original per-pair path. The accepted prefix and first refusal must match that path. Failed native suffixes cannot request allocation during recycling.

Doctrine acquisition receives exact country-status, folder or track objects through the country census and writer notifications. Construction, loading and array relocation invalidate the doctrine baseline separately. A changed grant or baseline grows a reusable caller-owned arena. A changed track requires only the selected track's native fields. Record authored doctrine identities through the lexer's dictionary so native selection strings can share a single recorded name.

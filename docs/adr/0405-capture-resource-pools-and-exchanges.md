# Authenticate resource identity before reading pools and exchanges

## Resource descriptors and amounts

The descriptor database includes a null object at index zero. Its parallel token array omits that object, so validate each one-based descriptor against its corresponding key. Keep the native ordinal, lexer token and spelling distinct. Include inactive descriptors and share the complete authenticated census with dependent pool and exchange readers within the same callback. Descriptor addresses are callback-local. Embedded country resource pools have independent headers and data pointers. Preserve stored widths, order and zero values, including the null slot where the serializer visits it. The authored state-template vector keeps full signed fixed-point amounts, native ordinal and empty-key occurrences. Runtime state effects are separate. Reject duplicate resource IDs and copy only the stored amount and lexer ID, excluding trailing padding and spare capacity.

Country resource reads size from complete descriptors and original live pool headers and allow any dependent holder to share the same country census. Read only the descriptor prefix that fits, counting every omission. Look ahead at the next usable slot and resource link. Observe each link or prefetched pool field at its original position. Read consecutive resource values as one block per pool. When an optional block or link lookahead faults, the original per-record or at-turn reads determine the verdict. Persistent faults keep their reason and order. A one-shot speculative fault can succeed at its original read. Keep historical serial and pre-prefetch readers as test references, covering null and alias slots, a partial copy and each block boundary.

## Classic trade and lend-lease

Classic resource exchanges are smaller than resource origins. Delivery-route fields are held by the origin or the exporter's country resource table. Authenticate a trade with its current vtable, registered full reference, importer and convoy owner in the walked country, and distinct exporter whose backlink names its actual resource state. Authenticate the importer state once in its turn and authenticate the exporter for each trade, including if the same address appears after replacement. The owner word alone is insufficient. Read the full exchange object to preserve its native field widths. Unassigned factory demand uses required less assigned factories, and both counts survive serialization.

The primary order is the importing countries' stored exchange vectors. Resolve the reciprocal exporting bucket for each reached resource. Sort only the caller's scratch index when checking duplicates. Read every pointer in a reached reciprocal vector, including beyond the stored prefix. A readable unrelated pointer can remain unrelated. An unreadable slot or duplicate fails with its original reason. The retained primary order and exact omitted-row demand are independent of the scratch sort. Callback-local scratch addresses are discarded after matching.

A lend-lease agreement joins the giver and receiver's lists. The giver's stored delivered and sunk pools are cumulative for that exchange's lifetime and disappear when the agreement ends. Delivery moves convoys and accumulates both the pool and logistics counters. Loss moves equipment from transit to the sunk pool. Preserve the raw country links, full reference identity, native dates, equipment variant and ordered delivered then sunk entries. The reference type comes from the live dynamic-type counter. Fuel quantities and percentages use different fixed-point scales. Authenticate the exchange, pools and variants, rejecting duplicate variant entries; after the first shortage account for each omitted source row. The changed-holder term reader covers just the reached agreement amendment and its recurring absolute, production-share and one-time schedule pools. A refused append stops that occurrence and interval coverage withholds its partial replacement.

The `acquisition_cost` fixture owns its synthetic resource arena for every serial and batched sample. The arena stays allocated and unchanged from `LiveMemory::new` through the last sample. Both walkers copy into a separate row buffer.

# 0103. Publish independent division companions from owned packets

Division status, movement and speed terms share the authenticated census and the game's stopped state, while retaining their own read costs and outcomes. The movement pass owns paths, land inputs and dig-in operands. It reads every admitted seed, then slices dig-in values to the status pass's published rows. When the recording mode omits status, do not dispatch its status, naming, attack, panel, speed, land or dig-in work. The remaining DivisionMovement uses the same observations with or without those passes. A geometry root refusal belongs to movement. A refused census count cannot admit rows beyond the supplied seed prefix.

Prepare each final status range from the live census and available workers. Run independent preparation leaves before settling shared maxima and writer certificates in order. Then lend name and attack staging to the final ranges. Their shared held store returns before stitching and their staging does not change original admission or error precedence. Optional arena failure keeps ownership of the already prepared packet, but the checked allocator's terminal signal still governs publication. An accepted failure is terminal without retrying live memory. The independent speed loan must return even if status refused. Return all loans before merged failure, with speed failure ahead of movement and movement ahead of status. A merged refusal withholds all presentation tables even when its independent passes acquired every division. Completed passes report only their own timings.

Projection accepts only packets acquired for the frame's hour, including any retained growth demand from a failed pass. Sparse execution output installs after both Presentation and Late join, with no native reads during publication. Reset the returned spare before reusing it so a cancelled hour cannot inherit the previous output. Names and paths must stay within their own arenas or their table refuses. Capture timing retains nested phase costs for diagnostics. The benchmark queries the clock frequency by passing a pointer to its initialized local writable storage.

Join combat-member status, panel and movement operands to the division tables only after proving their values match exactly. Duplicate division keys, refused tables and failed allocations leave the combat member with its own copy. Compare status rows after clearing arena placement, rounding displayed fields and excluding unpublished fields. Panel maxima and base speed can supply the corresponding status or movement columns only when those panel rows are admitted and equal. Otherwise keep the observations and their refusals. Full or partial supply changes are compared in displayed steps. Grace uses the live define's fraction rounded to the whole percent and retains hundredth-hour precision if the define cannot be read. Commander progression keeps an empty result distinct from a refusal.

Name selection follows the member's own template reference and its name-group pointer. An unresolved reference is native known absence. A malformed template registry refuses that operand without discarding the independent name member or cached text. Reuse the template icon walk's current census for the group memo when it exists. A full memo can force fresh reads and cannot drop a name. Off-hour sizing seeds capacity only. A changed member template or refusal invalidates reuse. Camouflage retains the selector's category outcome without keeping its weights.

Observe commander retreat bans for the full census, carrying only an admitted complete read under the appropriate forwarded writer witness. An unlinked group has no owner. A failed link refuses dependent rows. The movement entries use the block selected by the dig-in read and the same commander's acquired entries. Attack staging shares the status maxima and store certificate. During a witnessed hour, only its own stat and terrain inputs require extra native reads.

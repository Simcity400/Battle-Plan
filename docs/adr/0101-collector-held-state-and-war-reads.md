# 0101. Reuse complete state and war reads under their own witnesses

The States worker uses one authenticated census to supply StateFlags, active border trees and occupation identity. It consumes each completed visitor's owned rows and time when assembling the frame. The census, continent, movement, name and flag stages retain independent outcomes. A fault in one state's category withholds that category only. A failed optional continent or infrastructure read leaves known independent results. Growth resumes the original observations and never starts a second census.

The States store renews its held view only after a complete census, names, source and fraction capture. It clears marks when taking them and forgets the store after an incomplete or failed capture. On reuse, the epoch, header, slot pointers and shared infrastructure and continent operands must still match, and the state must be unmarked. The state identity, manpower, population and flags remain fresh. Territory and forwarded building writers invalidate affected owners, controllers, names, movement infrastructure and rail fractions. Name effects that encode no individual state invalidate every state. Failure to reserve scratch preserves no witness, and a full read remains available.

Infrastructure carries writer-covered building identity, level, country and controller. The worker verifies the other operands through a batched queue and level-bonus read, the category pointer already needed for the state record, and the hourly and per-controller reads. The category definition is checked and named once per shared pointer using scratch reserved before reuse. Queued construction and plans over other buildings still read each hour. The fixture keeps high-range module operands separate from dense object storage so tracing observes both. Its disabled template lookup distinguishes a nonzero maximum-based term from a refused read. Quiet-hour tests compare the entire name arena, rows, fractions and flag output with a fresh walk.

Occupation reuses certified receiver and shared country or relation source entries without a native dependency sweep. Initial demand, a mutation or a boundary can require native acquisition. A changed core, roster or diplomacy source invalidates the affected derived rows even when the level writer never runs. The cache keeps owned sources, receiver witnesses, raw country evidence and row allocations together. A retained group key follows the retained country even when its native lookup changes. Unchanged rows can be reused by projection generation and hold their exact immutable allocations for in-flight frames. Failed acquisitions retire buffers on the worker, before callback join. The failure verdict alone prevents partial publication. Spool conversion clones output after the persistent store has returned.

An empty authenticated state-country bucket selects the base accumulator and cannot preserve a destroyed group's names from stale pointers. Shared keys permit a second state or a later frame to reuse an already certified empty source in the same way as a populated source. Inactive occupied states still supply retained definitions. Both resistance rate trees remain under source certificates because the hover recalculates the target and selects the printed branch.

The war store requires the same quiet writer token, scope and callback-authenticated country census in its recorded order. Country identity combines pointer, canonical slot and id. The collector verifies the token around a complete walk and holds the ordered war pointers only when every row is accounted for. In a quiet hour it reads all current casualty counters in batches while retaining the fixed rows. An unreadable casualty counter forces a fresh walk. A failed walk, incomplete read or failed advisory allocation leaves no retained witness. A mass war termination still fits the same order and falls back to the fresh walk after its writer moves the witness.

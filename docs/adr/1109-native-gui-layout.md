# 1109-F. Lay out native GUI trees in their retained coordinate spaces

The native GUI renderer consumes the content reader's typed templates and runtime bindings. It draws in attachment order and returns named refusals for an unsupported or unavailable result, including a refusal while measuring. Cases that legitimately draw nothing contribute separate diagnostic counts. A measured or drawn template from the global registry carries its own reader refusals, just like the root. A copied template or a child built through an inherited template has a distinct construction identity, so runtime state follows its construction site instead of a name alone.

Percentage position and size use the parent's extent. Size may depend on authored show position and can measure from the far edge. Explicit bounds apply before aspect-ratio correction. Anchoring combines parent orientation and the window's own origin using integer half extents. Margins use percentages of the window and inset the content extent. A root's supplied top-left can bypass orientation. Backgrounds and scrollbars belong to the outer object, whose translation precedes the content object. Backgrounds use their unrotated authored position, with cornered tiles accepting a replacement extent. A content scale and scroll move the contents while logical whole-pixel clips stay in place. A container scrollbar uses only the parent's clip. Where the clip setting is unset, a background selects clipping to the inset content.

Grid items retain the offsets of construction against the GUI viewport when they are reparented. Fill order and positive append limits govern automatic slots. Explicit positions bypass those limits. Finalization measures bounds and retains adjustments based on fixed padding and overflow. Those adjustments affect later relayout, while backgrounds retain their authored extent. Overlapping lists use their own orientation and first-on-top order. Their items do not take the holder's opacity. Grid items do. Holder composition keeps its item draws between the holder's neighboring parts, scaling shapes without scaling logical clip translations. The smooth list scrollbar can escape the holder clip. Drawing submits a complete window, including any holder items, or rolls back its queued work.

The pointer walk keeps position and hit geometry apart from cropped or stretched draws. Regions include text boxes with no drawn glyphs. The walk resolves hits using the frames already drawn, then draws again with the resulting button states. The last admitted hit is the topmost control. All hovered check boxes qualify for their unchecked Over state even when another control wins dispatch. A held button keeps the pointer until release. The view passes logical construction dimensions, and supplies physical dimensions separately when pointer inversion needs them.

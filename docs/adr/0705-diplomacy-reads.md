# 0705. Keep native diplomacy direction, reserved slots and refusal scopes

The matrix allocates a relation status per target, including its reserved slot. A status is owned by the diplomacy of the receiver. Its stored target can be a raw alias of the canonical slot. Occupation, movement and visibility consume the native bytes and signed slot words. Positive slot validation requires resolving the raw word, and cannot substitute an alias for an actual reserved-zero receiver. Serialization starts after that slot. It preserves raw endpoints, cancellation, retirement and vector order. Only the first endpoint serializes a relation. War and subject relations are authenticated there before being skipped because their own tables record them. Contradictory identity or an unknown class can still refuse the tuple table.

Attache links live in the host's status toward the sending country. Direct military and docking access link the first endpoint to the second and offers use the reverse direction. The link walker reads political slots only for targets named by admitted owned relations and combines several bits for a pair. The transport extension adds current-subject candidates. Refusal of an independently read subject suffix invalidates owner-wide coverage without discarding the original link fields. Current subject follows native endpoint predicates, which can short-circuit before reading the second endpoint and do not depend on relation dates or retirement. With no civil-war link or retired owned war relation, the owned active wars determine the same enemy membership without reading the enemy vector. The ordered transport consumer acquires the original enemy vector independently. Enemy-vector failure withholds that observation and leaves relation links available.

The gather ahead of the serial links pass collects distinct candidates' matrix cells and statuses in a bounded owner batch. The owner accepted this relaxed read order so independent guarded reads can overlap. After a partial gather, unresolved candidates take the original narrow path. A transient gather refusal can therefore yield the original serial result. A persistent failure must still produce the scalar refusal and preserve the original field order. A refused independent suffix is never retried merely because a sibling needs its observation. Hints do not acquire values or change the reached failures. Output capacity cannot suppress required candidate checks. The caller-owned resolver retains successful link and diplomacy identity only for the current walk. New generations invalidate old values, and rollover clears stamps before they can be reused.

Opinion and relation-tuple outputs use one matrix pass with independent outcomes. A tuple-only walk reads statuses named by its owned relations and an opinion walk reads the full visited matrix. Tuple-only input failures cannot erase an opinion observation. Native opinion is its signed stored sum, with zero producing no row. A required prefix or content refusal remains refused even if private scalar reads completed.

The co-belligerence cache reads the directed matrix byte without inferring it from war membership or the reverse status. Rebuilding clears the old bytes and marks the wartime allies. Enemy candidates can change which targets carry a nonzero marker. Candidate deduplication precedes payload reads even beyond output capacity. An exact complete walk reports its full demand. A refused walk reports only previously established demand and exposes no usable prefix. Header-only sizing uses a conservative upper bound and independently accounts for slot zero. Its war pointer and retirement input remain available separately from the subject or directed-cache fields.

Reserved and forward-zero visibility preserve separately reached target, war, subject and military-access outcomes. There is no retry of an original failed attempt. The independent packet may fill only an unreached input. A guard refused for one branch leaves other branch evidence intact. A known second party can prove the raw disjunction even if the first failed. A distinct reverse status reads its own pointer. Sharing pointed data requires an exactly equal known nonnull pointer. The war veto precedes military access, and the presence of military access does not erase the faction or subject result used by another flag. Admission requires the actual reserved root and its own identity and backlink. Missing data remains distinct from a null pointer, an unreached field and a complete empty vector.

The opinion baseline serves only complete observations with authenticated owner identity and write coverage. Owner rows are stored by canonical slot in matrix order. A slice retains unselected owners' marks until their turn. A new observation token, changed slot identity or a replaced matrix requires a fresh read. A mark must still name the owner's current status at its resolved slot. Refused observations invalidate every owner, while a per-owner storage shortage invalidates that owner and records its demand. Separate mark and update buffers can have different capacities. Either shortage forces an original full read of the affected owner. The baseline token is restored only by the completion path, so a panic or aborted walk cannot certify partially updated rows. Replay inserts newly nonzero sums and removes newly zero sums in slot order.

## Benchmark memory safety

`crelation_status::bench::Counting::new` constructs a `LiveMemory` reader for the synthetic benchmark arena. Callers populate the arena before sampling, keep its allocation alive for every read and leave its contents immutable while sampling. This satisfies the immutable synthetic storage precondition of `LiveMemory::new`. The guarded reads handle invalid addresses and provide no protection against concurrent mutation.

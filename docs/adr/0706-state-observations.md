# 0706. Keep state observations independent of their optional operands

The state census walks the live ID-indexed roster, starting after reserved slot zero. A nonempty state's native identity must match its slot. Claims and country rosters use the same state ID, retaining null memberships. Owners and controllers remain raw country references including zero and aliases. A state's controller is independent of its owner and of individual province controllers. The owner and controller reads follow identity authentication and keep separate spans in native order to preserve the first failure and copied prefix. The census visitor receives only complete, authenticated entries, and borrowed native source identities expire with the capture.

Naming keeps the primary text, the cached owner-dependent secondary text and the template fallback separate. The primary can be saved as custom text. The secondary cache is cleared when its owner-dependent lookup is unavailable. The reader copies the two stored strings into a caller-owned arena without a native call. Inline strings and heap strings retain their exact bytes, and the heap read validates its terminator. One oversized row ends the returned prefix, while later rows still contribute to sizing. A proven current row is copied to the same place in the arena as a fresh row. The contested owner vector lies between the name headers and copies as ordered little-endian country links. Its refusal remains local to that state and vector.

The available and locked manpower amounts are distinct from the state's population. The reader takes the available amount and population in the same span or carried identity record. State-category tokens come from a definition authenticated independently of the state, and one pointer can be shared by several states in a batch. An unavailable definition withholds that category. Continent tokens come from the retained state template and require authentication in the live continent table. The actual null continent is known zero. Failure remains absent and name or census refusal does not manufacture a content value.

The flags pass uses the callback's authenticated census and preserves its faults and omitted rows. Demilitarization and the active border-conflict byte have separate meanings even though the reader copies them together. Border-conflict predicates inspect the native conflict set and visit the attacker before the defender. Controller-group count equals one for the scripted predicate. The strategic location list retains insertion order from native additions and loads. It consists of token and anchor pairs and does not substitute a duplicate location. The reader treats the flag and variable addresses as the sources of their respective walks without claiming ownership of the underlying containers.

The state has a base resource accumulator and independently gated resource additions. Added resources and dynamic modifiers have their own saved state. A negative cached best victory-point index selects the first province. State ownership notifications observe the newly assigned owner. These choices preserve the native operands and their ordering.

The state template supplies the province membership, ID and fallback display name. Its resource count and allocated capacity are distinct. Its continent starts at the database's null definition, and a later province traversal does not necessarily clear the retained value. Static modifier definitions are selected by the script name and supply an inherited accumulator visited during composition.

The movement infrastructure term is hourly fixed-point data. The collector reads it separately because it follows the building database. A failure refuses the dependent States table and leaves the independent StateFlags census available. The effective modifier uses the country-specific override when present and the state's base otherwise. A formatting selector has no effect on that numeric choice. The infrastructure calculation retains native signed widths and wrapping arithmetic and uses healthy levels and the loaded scaling terms. Its shared lookup starts without an ordinal and acquires one only if a state needs it. Refusal cannot replace a complete shared lookup with partial data. A carried row compares the loader-owned database, definition, limits, scales and continent operands each hour. The optional continent part of that comparison can remain zero when it cannot be read.

For shared building slots, read state modifiers using the owner and combine those with the owner's country modifiers and the state's extra slots. For factory energy, select state modifiers using the controller and combine them with that country's modifiers and retained energy factor. Resolve keys against the current definitions, and reuse country operands within a walk. An absent accumulator key supplies its defined zero. An unresolved key or unauthenticated accumulator withholds only the operand groups that use it. Invalid roster identity refuses the table. The game derives both displayed results on demand, so capture retains these inputs.

An infrastructure map pass can hold a plan across hours while its database and definition identities remain stable. Resolve shared globals once per hour and country and category operands once per member. A held state is eligible only when covering writers leave its building instance and controller unchanged and the current unobserved operands match. The reader compares both construction queue headers, the level bonus and category. A queued construction entry is a separate object and must be read again. Plans that walk additional buildings, province instances or slot modifiers also read the state afresh. Ungrouped infrastructure counts its own instance. The province cap follows a province from its status, which a state status does not have.

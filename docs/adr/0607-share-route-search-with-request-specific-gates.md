# Share route search with request-specific gates

## Decision

Counter and invasion route callers share A* costs, heuristic, heap ties and predecessor order. Each caller owns its prechecks, admission and fallback. Keep duplicate heap entries and native tie behavior because they can change the selected path. The cost arithmetic uses signed fixed5 operations with wrapping where the engine wraps. Invasion distance handles an invalid square root as signed integer minimum and scales the truncated root with wrapping products and signed division.

A counter route is fresh and does not read a viewer-local path cache. Use the request flag for the viewer's route option and the unit's recorded simulation rail mode. Check that the source matches its actual location for mode-2 region predicates. Leave rail-speed cost division disabled. Test definition sea bits and naval-base-map presence where the interface route option calls for them. Counter admission is class-specific. Railway connectivity needs both nodes, zero cooldowns, positive selected buildings and a directed neighbour. Task-force access uses the recorded theatre, naval service, home or hub and range operands. A task force whose every ship has the submarine flag qualifies even if the ship list is empty. Its hostile strength gate uses the occupants' directed war to the query's owner, with signed wrapping and truncation as recorded.

Evaluate class access before mode-2 node admission. Transport classification uses the authored port-sea pairing independent of base level. Class 6 accepts sea-to-sea and exact port-sea transfers. Class 7 admits land-to-land and eligible sea-to-land without requiring a port on the latter. Exile bypasses fleet and access predicates but still refuses embarkation. A mode-2 non-strategic request retries in mode 0 after search failure. Success with equal endpoints is an empty path, a different result from failure. Normal successful counter paths exclude source and include target.

Invasion routes use mode 0, forced transfer and region checks. Keep native prechecks and their refusal order, including the content-endpoint refusal before task-force access. Use the stored port sea if it resolves, otherwise the first sea neighbour in definition order, even across an impassable edge. Forced transfer accepts sea-to-sea or exact port-sea pairs and refuses land-to-land. Stop expansion on the requesting country's state ownership only if its raw reference is signed-positive. Return the single sea for equal endpoints. Otherwise exclude source and include target, and preserve the route when the final navy-permission gate changes the return flag.

# 0401. Retain native air-history windows and signed channels

Each history has a daily, monthly and yearly ring. Adds write the current daily record. The advance closes the old daily record, zeros the new slot and derives the higher rings from the closed records below. A held copy can therefore apply a witnessed advance locally. An ordinary hour with adds takes only the current daily record, which is usable with the held copy only when all window cursors agree. Construction and load rebuild the storage, so the observers invalidate held state on either operation. Shared history receivers outside the air subsystem are never registered.

The yearly statistics row uses twelve thirty-day buckets, preserving the simulation's calendar and signed channel values. The air schema has 89 fields. The statistics reader gathers the 24 named channels in nine exact spans, so unreadable fields outside that selection do not refuse a row. Building damage has its own display divisor. All recording paths retain the original amounts. The menu reads all channels and stores only nonzero records keyed by level and slot. Its sum visits records in native order and clamps each addition. The alternate roll-up chooses the newest record with a positive channel. Before wrap, the cursor divides already closed records from unused slots. After wrap, aggregation starts at the current slot and visits the ring once. The readers follow the signed capacity they validate from the game memory. The usual constructor capacity is not a reader limit.

Window authentication checks the owning history, the expected field count, record-array geometry, capacity and cursor before following value pointers. Fields, their count and the history backlink belong to the native record storage. Roots retain their roster slots and history-table slots retain the region order. A null table or slot is absent, while a malformed allocated object is withheld. Contiguous slot copies and staged gathers preserve source order and the original position and reason of a failed read. Gathering ahead does not authorize a later object. Storage bounds can withhold rows and count the remaining allocated objects without reading their fields.

Naval-patrol inputs follow each country's fleet and task-force order. Only the first combat of a task force is eligible, and only a naval combat requires reading the province. The region comes from that province. The region's first air-history window supplies enemy ships sunk and own fighters lost, followed by the additional scenario channels. Capturing every record lets a held copy apply a later advance. A fault on a scenario-only channel withholds the rest of that record's scenario suffix and leaves the original pair and other records independent. The reader neither recopies completed fields nor retries the failed span. Repeated record pointers keep their distinct occurrences.

# Carry complete output entries and preserve missing strike parts

Production and construction share an atomic output log. Its ring is sized off-thread and can change only at an empty drain boundary without an active writer. A writer gets a ring slot only when its prior entry has been consumed. When the slot is unavailable, the entry goes to the lock-free spill. Allocation failure records the first missing index and invalidates the affected interval. The log tracks attempted demand across the ring and spill so sizing accounts for complete bursts.

The drain samples the cursor before checking for active writers. A zero active count then settles all entries below that cursor. The returned slice starts after entries already handed over and reports demand for all waiting entries. A missing ring entry or a failed spill remains a named storage loss at its first missing index. Ring writes remain under their active guard through the last store. If a drain relinquishes an interval while a writer is storing and a newer entry can reuse the slot, that writer ends observation. Only the drain locks the held spill entries, and it does so after writers have pushed entries below the cursor. Demand usually settles quickly, so a cheap load avoids a locked maximum update for unchanged values.

The event ledger keeps native callback storage separate from an empty spare the spool offers. Native overlap invalidates the interval before a second claim can certify it. Spool-only loss uses an atomic marker, leaving the draining or writing game thread in control of the store. This includes a loss after the drain transfers its events and while it still holds the store. The first clean boundary ends that loss. A still-unresolved native call also compromises the interval that follows. Consumer state acquires a fresh census after an incomplete interval, independently of writer cadence. Event identities seed from retained recordings before hook publication and continue monotonically across private clock recovery in the same attachment, even where the recorder keeps publishing hours. Demand reflects observed census and callback overflow growth, and held capacity is kept when an older pooled frame carries less.

A nuclear impact opens a strike on the calling thread. The notification closes it before scripted effects run, preventing unrelated changes on that thread from entering its outcome. Unit damage is paired before and after each native call by its zero-based call number. A matching failed after-read cannot double-count a missing unit. Other observers forward war-support changes, destroyed healthy building levels, and signed equipment pool differences by variant. The war-support guard keeps the value from before the native call and pairs it with its result when dropped. The aircraft equipment observer also records crew loss under the owner attributed by the writer. Hook observations use storage prepared off-thread. Synthetic tests serialize the ledger's driver and read their heap-owned fixtures with the usual guard.

An unavailable forwarder, missing read or unobserved call leaves its strike part explicitly refused. Missing strike operands, storage failure or conflicting calls invalidate the interval. A native exception propagates through the original call; its retained flight prevents early detach, and the strike scope closes so later writers cannot attach to it.

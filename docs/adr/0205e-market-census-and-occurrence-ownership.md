# Reuse the economy census and retain exact market occurrences

The market observer owns dedicated writers and receives forwards from existing delivery and rebuild owners. Draft-action resets change local action terms and need no observer. The economy census supplies country, holder and agreement discovery and the sizing demand. Fixed identity and clock operands suffice for ordinary transfers and births, even when an operand pool is large or unreadable. Amendments and removals retain complete final cumulative pools before native code replaces or destroys them. Active removal clears registration before deferred destruction. The retired ID marker can also identify a live contract, so registration determines whether a final witness is still due. Births defer definitions to the worker, where intervening removals cancel private pointers. The worker reads definitions only for newly admitted live holders. Lifetimes are consumed even if state acquisition is refused.

Each first successful census-epoch publication supplies a complete table, including after spool recovery. A manager identity change revokes the held backlinks. A renewed observation must read held owners before carrying its rows. Country reset revokes its holdings while independently owned live exchanges and contracts keep the baselines their own lifetime witnesses protect. A variable write whose end cannot be attributed causes a fresh read of every contract's variables. The variable write and its mark occur on the same side of capture because seed-changing contexts run on the game thread. New holders begin their delivery baseline at zero after bootstrap so a census discovery in the same interval cannot erase a first delivery.

The worker differences cumulative whole-unit manifests. It uses the native Q15 scaling and whole-unit truncation, preserving the original manifest for full delivery. A valid cost cache requires no quote or factor acquisition. If a definition has an invalid lazy cache, the worker derives its cost read-only from the same equipment, quotes and content factors. An erasure without the expected final witness explicitly refuses the affected stream. Scalar acquisition shares the carried pool, preserving the in-transit manifest. For fuel, reset only previously nonzero caches, then apply the observed signed native additions for this hour. A zero operation requires no event or native read. When a giver has several agreements, a fuel change publishes only its agreement and retains the shared manifests.

Agreement events key the giver by the giver resources' owner link. Observer watch keys stay nonzero and aligned, including the encoded null country. State recovery runs before the census and leaves the occurrence interval's separate loss verdict for the drain. A watch clear can succeed while offered growth waits behind a predecessor. Native event revisions reserve zero for the census baseline, and serialized event identity is assigned after worker-derived rows join. Synthetic census support shares the owned paths so native pointers cannot enter a recording. A publication failure names the whole patch batch because its outcome covers the batch.

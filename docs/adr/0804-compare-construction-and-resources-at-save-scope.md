# Compare construction and resources at their saved scope

Naval bases come from the independent saved navy rosters, with building levels read from eligible port provinces. A saved building does not establish roster membership, and a retained zero-level base does not require a building. The active building list rebuilds from positive levels in native order. The manpower save projects positive amounts in native order while the recording retains the full source. Raw country aliases can be distinct native tag-table slots, so resolving an alias to the canonical slot can select the wrong country. [Construction and base checks](../../crates/recorder-oracle-construction/src/construction.rs)

Occupation law strings follow the serializer's pointer and first-NUL rules. Compare still-readable laws even if another group cannot resolve its name. A missing wrapper is not an empty group. Use the actual retained map identity before the display sort. Saved variants retain ordered resources and the zero policy, while allocation scaling and flooring operate separately on variants and allocations. The save proves only the variant projection. Runtime caches and source trees lack a saved counterpart. [Occupation checks](../../crates/recorder-oracle-construction/src/construction/occupation.rs)

Origin and delivery routes compare their stay or path, efficiency and membership at the sampled hour. A missing or historical operand yields a named limitation, while a wrong present value differs. Shared routes require a current client and can serve several clients. Join each client through its independent saved contract and both endpoint tags. The recorded route key cannot choose which saved contract to compare. Regional delivery efficiency defaults to full only where the saved representation establishes the omission. Compare rights by resource and holder membership because the save sorts its resource names. Native positions must still be unique within the live list. [Resource route checks](../../crates/recorder-oracle-construction/src/construction/resource_map.rs)

Only states dated to the compared hour can be compared against that save. Dated empty reads still establish coverage. A readable state without an expected row differs, while an earlier or unobserved state is named. Resource pools with unavailable names can still compare coverage by count. The controller's saved origin membership and the state's building prove the resource origin and infrastructure. Core and claim comparisons invert saved reciprocal memberships and ignore order and resolved alias spelling. Strategic-location, override and dynamic-modifier arrays retain native order, with lexical refusals reported where necessary. [State comparisons](../../crates/recorder-oracle-construction/src/construction/states.rs)

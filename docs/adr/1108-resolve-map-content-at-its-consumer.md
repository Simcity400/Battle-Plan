# Resolve map content at its consumer

A recorded province rename takes precedence over static localization. Read it through its first NUL, treat it as a localization key when present, and otherwise preserve its literal text and brackets. Static lookup tries the owner-qualified victory point key before the ordinary key. Empty values stay undrawn. Report unreadable non-UTF-8 names separately from empty names that the original draw also omits.

Map modes publish shared plain visibility values source consumers can read without owning map-mode selection. Load icon-table priorities as signed bytes from the content. A political mode can share an icon priority table while keeping its own visibility. Unit counters still respect the camera cutoff and peace conference. The air mode limits counters to fleets containing carriers. Naval mode has its own army opacity. Province icons, land figures and label text can turn off independently of ships, marker dots and stars, facilities or naval headquarters. Use content-defined distances for raid icons and use the strategic grouping cutoff only when the mode selects it. Match land model and unit-arrow gates with the raw camera height and mode choice so a mode transition uses the same popup and cleanup path as a camera transition.

Omission flags exist for paired screenshot attribution. Omitted world objects are not uploaded and therefore cast no shadows. Rail omission covers trains and bridges. Weather omission removes particles while keeping snow, mud and terrain grade. The split between counters, labels, political gradient, border strips, unit figures, sprawl and buildings lets the comparison remove them separately.

Load GUI effects from the resolved content stack and compile the technique only when used. An absent technique inherits the prior program and sampler settings while choosing the default blend state. A failed declared technique refuses draws that would inherit it. Compute activity from the compiled program's clock reads and let synthetic layout tests provide explicit technique and clock metadata without a compiler. For sampler conversion, preserve transparent-black borders, wrapping on the unused axis and nearest-mip behavior when a mip filter is absent.

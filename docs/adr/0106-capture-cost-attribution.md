# Attribute concurrent capture metrics to their actual work

Measure entry through dispatch separately from initial setup, the parallel region, and residual completion through enqueue. The free-frame count is observed before a capture tries to take or construct a frame. Count frame growth wall only if it had to construct one. A clockless frame assigns all body work to residual. Parallel markers, the longest join, the longest wait for a dependency to become ready, and the longest dependency handler diagnose different causes of a slow hour. When no frame was free, record each stage’s holder count and maximum age, and the spool pipeline step last started. Break out page operations and private-heap lock visits made by the hold path’s capture and acquisition workers. These metrics exclude other collector threads. Native-tick counters come from the original function’s brackets, include ticks without a capture frame, and exclude work outside that function.

Measure a frame as a whole with exclusive ownership. Replacing its previous total avoids drift as buffers move, reset, or grow. Core storage excludes map and extended allocations when those are measured separately. Include actual executor reservations and its optional help histories, count shared homes once at their readable high-water mark, and add its separate held histories once. Publish the capture’s cost and cause for a forced full read with the frame.

Copy-only work is already measured on workers. Add worker times to their supplying-table slots, not the capture’s elapsed wall, because they overlap. When one pass supplies several tables, charge only the anchor table. For example, the divisions upgrade phase charges groups, strategic-air census charges statistics, the session manager header charges world, construction queue charges building, occupation preview charges settings, supply traversal charges hubs, the resource dictionary charges definitions, the bases census charges bases, and the weather manager header charges regions. Production uses conveyors and licences for their shared paths. Keep each player table’s timing separate. Add map and order costs after their shared map-tick copy and retain the completed StateResistance supplying-read witness even when its duration rounds below clock resolution.

A skipped table exports no walk time. CountryIntel is exceptional because its loan can delay a scheduled walk. That later walk is a real read, and the oracle uses its measured cost to identify the hour of observation. A delayed table that still did not run has no cost.

# 1119. Dispatch input and hits from the map frame the user saw

One dashboard map owns keyboard and camera input, using the most recent press independently of egui focus. A lone map takes the map keys. Before an owner exists, the hovered dashboard map takes mode keys and Escape; the wheel follows the pointer. System focus applies to keyboard and mouse, while the host can route the controller to its active map without keyboard focus. F3 remains the air mode shortcut. Ctrl+F3 asks the host to toggle diagnostics. The controller's view button and the full map's camera shortcut can change camera mode without host controls. Escape first releases a captured pointer, then resolves a pending camera start or the topmost relevant window. It closes the tactics popup before the battle window.

Clicks retain the press owner from the picture on screen, including a window that moved or closed while its replacement was prepared. Presses count on the map under the pointer, releases also matter when made elsewhere, and the modifiers come from each event. Process effects in event order so dismissing a picker list or handing a counter its release is observed by subsequent clicks in the same frame. The picker list grows to fit without a scrollbar. A primary bare-map press can become the game's selection box, decided by the release extent. Another country's unit models leave primary clicks to the ground, while a viewing-country model is tried before the ground and the country-switch action. An explicit fleet choice can reach an empty fleet without a plate. Shift beside a selection leaves ground selection alone. The ground never authors a repair or air order in playback.

The hit index is over the drawn shapes, shared for every consumer of a point. It orders them by actual GUI pass, layer and draw order, with the later offer winning ties. A free eye can instead give the nearer presented icon precedence, and a hidden or sufficiently faint icon cannot take the pointer. Adjacency has a second pass below the main shapes. Broad shapes are tested outside the cell lists. Native child controls can extend beyond an unclipped root and retain their plate's order. Unbound or inert children can take the pointer and show their own tooltip without selecting what lies below. The Operatives entry takes hover even with empty text, and only the actual topmost base can show its radar range.

Camera drags arrive in framebuffer pixels, while GUI layout and hits use interface pixels. Every hit consumer converts from screen to the layout of its own icon by undoing that icon's pan or track offset once and undoing the free eye scale around its pivot. Rectangles take the inverse path. A map click and a tooltip on a moved plate therefore use the same bounds the frame drew. The hit index is invalidated when the shapes change and caches one answer per point for that version. A named raid's secondary lookup uses the same coordinates. Diagnostic overlays use the same screen-space scale as native tooltips, converting the interface scale by egui's pixels per point.

In strategic modes a ground click picks the region. Otherwise a sea province opens its region and land or lake picks the province. A region with any sea member can open the naval region window. A lake or stateless land province can remain selected without a state outline. Draw selected-province and state outlines with palette entries one and two respectively. A ground click in Infrastructure or Raids can be reached through a unit model click.

# 0105. Publish complete land-event intervals from owned words

Land-event callbacks copy transient inputs into owned words. Each record reserves a contiguous logical index range. The ring uses only words that prior consumers have released, and a record that cannot fit there spills whole to a lock-free list. Producers do not wait. The hourly consumer folds the committed ring and the spills in logical order. Read failures, allocation losses, concurrent incomplete publication, and an epoch change refuse a complete interval. Loss during a boundary that cannot be assigned to a record keeps the interval unproven. A load, gap, or first boundary resets the unknown prefix. An independent casualty scan failure is its own observation and does not invalidate a published interval.

The sizing worker takes peak attempted-word demand from the event producer and existing active-side census. This requires no extra game read. The hourly consumer installs offered storage only after draining and only when the resize gate excludes every producer. Producers mark themselves active before checking that gate, and refuse coverage when it is closed. The spool frees retired allocations. Detach preserves all current, offered, and retired storage until the final drain and native call quiescence are proved.

Combat dispatch and finalization share a same-invocation witness keyed by native identity. It prevents a fallback walk only for the dispatch proved for that instance. A division may enter a destruction callback more than once before deferred deletion, so that callback pairs observations by the reserved event record. A failed outer read is already charged to that observation. Commander selection accepts its actual dispatch witness and does not let a script query supply a replacement. The separately retained land census shares the verified division status record for remaining grace and sizes roster storage independently of the division rows.

The land-event native bridge preserves the original caller's return identity, register state, flags, and Windows unwind contract. The deletion reader needs the unchanged caller identity to classify the cause of a terminal event. A relay's suspended instruction-pointer checks also cover intervals in which its body counter has not started or has finished. Rust cleanup cannot prove that an escaping native unwind has finished traversing the collector. An escaped flight therefore refuses observation and retains the loaded collector through teardown, even if subsequent ordinary native calls return. Admission checks that sticky state again after publishing so a racing escape cannot open observation. Unsuccessful cache publication retains the original site until a restore retry verifies it, and a partially admitted family cannot move on to later sites.

Tests reserve the process-wide event log under an exclusive ownership gate, adopt their own workers into that ownership, and divert unrelated test threads. Per-thread loss and resolver counters keep synthetic timings separate from the global counters. Tests sharing native patch pages serialize patch publication. A direct synthetic Rust callback verifies its owner guard but does not count as evidence about a native unwind. The independent foreign-unwind fixture checks the actual production bridge, normal return, and surviving sticky flight before it resets only its test-owned state. The paired benchmark excludes warmup and patch preparation, holds the two paths' context constant, and alternates the measured order.

# Construction playback distinguishes queued work from witnessed output

The log joins consecutive windows into one native project per handle, with earlier counts carried into later windows only once. Read the current window, its predecessor initially and the next window during playback. The visible rows control how far back to prefetch. Keep at least the visible count below the viewport where possible, extending the reach when necessary and resetting after a jump beyond the held span. While a new window is loading the last held hour remains shown. An incomplete or noncontiguous span cannot supply later rows. Within held data, draw project states one block ahead, reveal their changes at the clock and paint only changing factories and levels for drawn rows. A prepared block's end comes from its previous render.

Apply the country group at the project's first read, and name the country at that same read. Carry tag options as arrays because mod names can contain spaces. Building types and art come from the recording's manifest. A project only appears after its first observation, and recorded events are revealed once their supplying read arrives. If a read establishes only an upper bound, keep that distinction in its change date. A row ordered by change gets a new identity when its observed stage changes. Filter stages using witnessed work: a project can repair and then build new levels, and a repair that occurs between reads can still count when output witnesses it. Both filters can keep a project with both kinds of work.

Earlier unobserved work produces bounds. Levels may have been built or dropped during a gap, or both added and built without a change in the remaining total. Keep these possibilities as ranges. An ending accounts for work still in the previous read's totals without double counting, and counts newly reported additions. A gap leaves no current factory count. The row shows factories only while in the queue, including an unread interval after a queued read. After an ending, a tooltip can retain the last read's factories. The tooltip can separately report confirmed repair dates and build dates. Factory output amounts stay exact and signed. Only displayed factory IC rounds to whole units. A pending country name appears as loading, and a missing name or state keeps the recording's missing state.

The spending widget reads the branch totals once, grouped by new work or repair, content building type and state. A railway inside one state belongs to that state. Exact totals add native counters in a wide signed integer. A leaf has known zero before its first output and an unknown total when its supporting reads are missing. Preserve counted output when part is unknown and report why it is partial. Unattributable branch output can make the whole partial without creating a slice for a country. A missing name does not erase measured IC. The end of the view fixes fill ordering and colours from the start. Frame painting tracks values and the render key changes with the presence of a leaf.

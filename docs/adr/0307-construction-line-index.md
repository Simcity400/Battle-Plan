# Index construction lines by their recorded lifetimes

The log and construction spending share a line index. A line begins at its first queue row or an earlier output row that names it and lasts through the read that settles its ending. For each run, take ended lines from their logged `ConstructionLineEnds` row at their last hour and read still-open or unlogged lines from state at their final observed hour. Moving readers forward through the run avoids replaying the projects' entire history to build this index. The logged end must give the same line data the final queue row would supply.

Windows are branch block spans clipped to their timeline stretches. Queue availability comes from each block's page entries, since the journal can land a queue without marking it read in an individual sample. An absent page does not establish that a queue was empty. A window carries each count already reached as one entry, then adds rises based on later queue reads. The rise list, when present, can date the underlying build or repair before the read that established it. Steps and counts do not bridge gaps. Railway rises count segments. The window omits a line if it is never shown there or no tag names its owner at its first read. Raw owner zero means no recorded output owner.

Spending groups fixed5 output by new construction or repair, building type and state, or a railway's endpoint states. In the packed spending key the low 32 bits are the building type or railway destination, as selected by the railway flag. Use the full identifier width so a state past 24 bits remains distinct. Output accrued before a tag took a country belongs to the prior holder. Use the value at the preceding hour as the baseline if the run holds it. A new key counts from zero when it first appears within the holding. Combine deltas for all identities held by the tag, coalescing equal hours. A transition to unrecorded output makes the total unknown there. A line that has not appeared in the output table contributes no shown output. When the final row has missing output, report from the settling read if it is a final-only refusal, or over the known line lifetime otherwise. Prior output before observation remains unavailable.

Names and art are resolved with the recording's content and lexical dictionary. Use the queue's line declaration for the building sprite and repair marker. Authored GUI icon frames are one-based. Building names use their content localization keys. Cache state keys and per-type results by source and catalogue. Leave unavailable fields null and report each kind of refusal as a counted warning.

# Keep shared faction presentation separate from recorded history

Display a per-campaign faction style before its shared style. An explicit shared change removes that campaign's colour override so it is visible there too. Shared identity uses the recorded name verbatim, which avoids translating names when matching settings across languages. Unnamed factions fall back to the first recorded leader, including when the literal was refused. This deliberately makes same-name factions share a colour and does not distinguish anonymous factions with the same founder. Without either identity, the setting stays campaign-only. Named preset sets match recorded names case-insensitively and retain the user's display names.

The default is the first recorded leader's map colour across all branches. Adjust a default just far enough to distinguish collisions, preserving greys as greys and staying clear of user choices. Unknown colours use the palette, with a warning after the bounded fact reads have had time to resolve. An empty result with a history warning can mean missing recorded history. The default list labels continue to identify the recorded factions while the user edits their display names. Saved settings validate accepted fields and share the read and write budget so a successful save cannot be dropped on the next load. In-memory preferences continue for the session if storage refuses them.

Keep the campaign sidebar flag selection in recorder settings on the desktop so the recorder and desktop app agree. The browser uses local campaign settings. A local flag migrates only where the shared setting is absent. A choice or clear during the initial read takes precedence, and writes remain in the order made. Failed migration keeps the choice usable on the device for a future attempt. If there is no flag override, follow the displayed country.

Faction membership follows recorded rosters and historical slot aliases. A saved faction can be absent before founding or after ending; an unread roster and incomplete membership are distinct from a country in no faction. Historical labels use the recorded name at the shown hour, while picker entries can use the latest read to identify a faction absent at that date. Editors keep that latest display and the first known spelling for colour identity. A followed widget renders a change in selected faction or its absence reason, and requests faction text expansion from the chosen country's viewpoint. A tied first leadership read uses the earlier branch. A saturated fixed-point goal cache represents unmeasured progress; a missing cache keeps its own reason.

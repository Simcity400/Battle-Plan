# 1302. Preserve land model choice and pick order

Land selection shares the authored sub-unit resolver and recorded local clones with other consumers. The viewer owns ranking, equipment exclusions and model-country choice. Recover recorded ordinals before stable quantity sorting, keep the first strictly greatest positive need, and calculate default scores in the native signed width. A missing authored or recorded operand is a refusal rather than a new ranking. A signed-positive origin can override the variant creator, while an ordinary roster country keeps its own tag.

The fallback with no selected pair reads production operands only when there is a positive qualifying need. Match recorded grouped requirements to the two viewing-country production rosters and the candidate countries' stored best variants. The native default row remains first. Drain the six candidate queues in their original order and give each entity its first admission. The grouped second option chooses the figure. A single surviving entity needs no labels to decide it, and a sole default row takes the ordinary numbered fallback. Empty entity sentinels do not enter the final list. A positive country operand must resolve before using its recorded culture or ideology.

An option's display-language label follows the original naming rules. The default row localises its default-model key and a graphics-database candidate localises its archetype. A custom variant name can appear literally with its configured appended variant name. Otherwise use the type key with the origin or creator prefix as required, retaining the original-or-own tag for a dynamic creator. Conventional alternatives can use the authored derived variant name. A conventional candidate without a variant uses the viewing country's sub-unit prefix. Missing localisation can fall through to the bare key and ultimately the original bytes. Number repeated labels before queueing, then group by the byte rank of first occurrence. Rank wraps after 256 distinct labels. An unknown earlier label can change a later label's suffix and final rank even when the unknown row's entity is dropped. Withhold the choice if that uncertainty matters.

Cache only successful static facts attached to immutable authored content. Clones share its catalogue order, and replacement content starts a new cache. A demand can reuse a census snapshot or its local successful facts without a per-variant lock. No shared lock spans classification or error handling, and concurrent successes compute the same value. Preserve the existing type and archetype lookup order. Keep timing at coarse job-local stages, count only finished invocations, and propagate an unavailable CPU measurement as unknown.

Pick collision triangles in the actor's own space. Other shapes use the world bounds of posed root joints or the drawable submeshes. Preserve separate rules for the two-sided triangle intersection and forward world-box intersection. The frame's land identity controls an index of conservative cell candidates, including horizontal wrapping. A figure without a finite bound or a query crossing more than the index threshold falls back to direct testing. Both paths retain figure order and therefore the same hit preference.

# Preserve character occurrences and bound reuse by the current capture

Walk the two serialized character rosters in their native historical then dynamic order. The name index is a lossy cache and rejects negative lexer tokens. Each occurrence retains its roster position and complete native identity. Aliases remain separate occurrences and the duplicate identity check still applies. The manager installs and restores its empty index sentinel on construction and clear. A character record can hold a zero country before recruitment. Preserve the raw country link even when an alias names the same country.

Keep the name token, unsaved name and separately saved name string distinct. The template pointer is ephemeral, zero when absent, and can certify reuse only for an identity previously read at that pointer. Its saved tag, runtime source file and line, and generated flag have different provenances. Parsing supplies the source file and line, generation sets the flag, and an unparsed template retains an empty file and a negative line. An absent template contributes default identity values. File bytes follow both strings in the caller's arena. A fixed destination that does not fit reports required capacity and omits the complete row. When acquisition stops before all rows, the reported capacity is a lower bound. The sizing walk uses headers only, without copying text into a recording.

Character roles are separate from roster identity. Country leader roles are keyed by ideology, advisor roles by string, and a scientist or direct unit leader can be absent. The direct unit leader wins over the operative reference. A full operative reference is absent only when both words are zero. Construction clears it and operative creation or loading supplies the full identity. The serializer writes a nonzero reference, a nonempty variable table, and positive-count flags. Pronouns use the feminine variant only for the observed feminine enum value.

A character view exposes only the fields it successfully copied in this callback. Its extent bounds address lookup and is independent of the native allocation size. A partially copied field stays unavailable without retry. Later independent fields can still be read once, and guarded reads remain available for foreign targets. Character identity checks preserve the full ID and type. Inline string payload can be reused from the validated header. The caller validates heap terminators before sizing or publishing. Portrait reads preserve the scalar country-before-header failure order even when guarded together.

Census pages stage exact field spans in bounded pointer chunks. A failed pointer chunk publishes no partial pointer, and an identity error is delivered after admitted predecessors have reported their own domain failures. Refilling must clear the old visible prefix and deferred error, even when the next pointer read fails. Borrow a complete portrait census only within the same callback and at matching scope. Check country readability before lending an authenticated occurrence. The census grows from the full observed roster off the acquisition path. A new census has its own stamp and compares exact occurrences with the preceding complete capture.

The portrait walk takes a contiguous share of the roster, including characters with empty portrait arrays, and the caller merges results by character. Validate roster occurrence, identity, country and array before descriptor use. Prefetch hints overlap admitted independent reads without returning values or following an unvalidated descriptor. Cache only descriptors proven current by a complete writer observation. If a writer overlaps capture, read the captured pre-change image when one is available and refuse a proposed cache hit whose observation changed. Losing the observation restores ordinary guarded acquisition. A short or failed walk can overwrite held arena spans, so invalidate cached ranges before reuse.

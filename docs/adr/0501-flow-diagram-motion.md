# Keep flow diagram geometry separate from exact ribbon facts

Widgets supply stable node and ribbon identities and own all exact numbers. Use fixed ribbon ordering inside each node and break equal-size node ties by stable key. Fold nodes according to actual label capacity and keep the folded total last on its side while retaining every member for exact tooltips. If one country would fall into Other, retain its name. Use the same complete country set to resolve colours, flags and missing looks independently of which side or current display budget shows them. Size labels from the longest yet shown so they do not jump during playback, with a cap that leaves the ribbons room. A present country identity retains its sampled flag state, while a missing optional generic image leaves the outlined slot. Keep exact slot targets even while easing the ribbons and positions. A departing ribbon retains its previous nodes until it shrinks away. Reserve the larger of the current and target sizes so adjacent nodes cannot overlap mid-motion. Small nodes retain a minimum height for visibility and hit testing. Gaps give way before node minima, and shared slot count and optional scale keep the geometry stable as nodes enter or leave. Jump immediately on a backwards supplying hour, a new continuity key, or reduced motion. Only presentation changes during easing. Use the same cubic ribbon curve for paint and hit testing, expanding the target of thin ribbons. The topmost hit wins. Treat drawn flag and label positions as interactive only for widgets with an action there. The keyboard visits each source and its ribbons before target nodes. A repeated frame can refresh a stationary pointer tooltip when its hit or callback changes. An Escape stays dismissed until the pointer moves again, and an old keyboard stop cannot seize a tooltip owned by another chart without a fresh key action. Disable the stop when playback removes it. Activation uses the supplying hour of the frame actually drawn and falls back to the existing context menu when no breakdown action exists.

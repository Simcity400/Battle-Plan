# 0206. Publish event feed values from completed writer boundaries

The feed observes event execution, selection and retained-state writes at their actual boundaries. It avoids hourly queue and roster walks. When an enclosing writer's arguments omit the selected instance, a tap stages the selected object and any old value needed for comparison. The enclosing writer calls its original once. After normal return it publishes completed values in the order staged, suppressing stores that leave a flag unchanged. Effect execution supplies an execution fact. Its occurrence gives no evidence for a separate duration or lifecycle result.

The writer epoch excludes a baseline from spanning an active write. A thread keeps its current frame token and kind, while each nested invocation saves the parent frame on its own stack. This allows nesting without a separate frame cap. A tap with no matching frame refuses the interval. A frame closes before publication because publishing may itself enter another writer. An unwind restores the parent and leaves unresolved witnesses for the next boundary to refuse. The arena grows on demand. A declined entry, failed allocation or arena reset during an active frame has a named refusal so missing observations do not look like an empty result.

For a delayed-event pass, the pass boundary and sparse cursor changes account for quiet timers without a callback per member. The enclosing pass covers writes throughout the original call. A cancellation can shrink the queue behind the cursor and end the remaining visits. A swapped-in entry is revisited. A firing follows its decrement, while invalid definitions skip that step. Mutations inside a fired event follow the fire cursor already emitted for that pass.

Decision selection records the days and active state after their stores. An optionless dispatch can execute without minting an instance. Removal and ignore witnesses carry the pre-store flag so an unchanged request can be suppressed. Replaced-event retirement publishes only if the fired-match branch was staged and the original completed its removal. The withdrawn object is not read afterward. The scalar duration writers publish their actual stored duration after return. Container changes and execution effects remain separate facts. If removal effects reactivate an object and the native path skips the duration store, the observer uses the state and duration it left. Clearing a removal timer and its corresponding taken entry describes the same decision, and counts are combined without another roster scan. A status reset withdraws only that owner's prior baseline. Subsequent witnessed writers can still establish attribution for newly stored members, including a decision that reuses a retired address. An unattributable result is withheld until a new baseline can certify the owner.

War provenance follows an operation scope until normal return or unwind. A nested event uses the active operation and nearest conference. An event that performs an operation records both its own route and the enclosing route. A caller outside the authenticated return-route list or an unreadable cause operand leaves that part of the provenance unrecorded and increments diagnostics. Each listed return names one route. Flags use the native byte, so unrelated upper bits never change the result. An unreadable event operand refuses the fact. The politics and territory families forward their scopes and owner transitions to the event feed. State ownership is sampled before and after the normal setter return, and a same-owner operation emits no transfer.

The detour tests invoke the real wrappers over a fake original that stages the witness, then changes fixture memory as a native writer would. The fixture holds the global store lock for its lifetime. Cases exercise an untouched flag, retirement without a match, an arena reset on another thread and a mismatched latch. This tests committed-state publication without executing the game.

## Native writer boundary contracts

The script observer authenticates the owned command scope at the selection execution entry before reading the instance and actor. That entry has only the selection command's body as its native caller. `verify_hook` retains the sentinel buffer after verifying the prefix the patch actually owns. In `decisions`, enclosing detours start at the first pre-store writer, and the call sites cover the duration additions and replaced-event retirement. `verify_call` and `REACTIVATE_DAYS_LEN` keep adjoining calls' patch spans separate. The duration-add thunks carry the caller's nonvolatile scope into the unused third argument register for the wrapper and jump without changing either native argument or the return address. In the retirement arm of `delayed::tap`, the selected ordinal remains in `R8` and `RSI` reflects native swap-removal. An invalid definition that bypassed the fire boundary consumes no countdown step.

`war_provenance::entry!` preserves the actual native return address and builds a separately aligned argument area for `body`. It forwards four register and four stack arguments and supplies the site and caller separately. A site that passes fewer arguments ignores the unused words. The shim returns the original `RAX`. Its unwind test checks that the prologue contains the saved stack pointer followed by the stack allocation.

| Provenance arm | Native arguments and observation timing |
| --- | --- |
| Join | Diplomacy receiver, ally, enemy, `u32` join reason and `u8` expand flag. |
| End war | War receiver and `u8` truce flag. Read the endpoints while its link is still live. |
| Conference create | Manager, loser, winner, `i64` factor, two `u32` controls, `u8` flag and message pointer. |
| Conference start and apply | Conference receiver, plus a `u8` flag for apply. Start reads the new conference before the original can end constituent wars. |
| Annex | Taker, `u32` target reference, `i64` output pointer, `u8` transfer-troops flag and second `u8` flag. |
| Release | Releaser and target with one `u8` flag for the command or two for the direct path. |

The live operands in `war_provenance::operand`, `state_owner_before` and the apply arm of `body` are guarded reads made on the calling thread. The target selection forwarder belongs to politics and only stages a witness. The script-variable owner installs the delayed cursor taps with their enclosing pass and retains those executable ranges through quiescence. The event feed owner installs the remaining script and war hooks as one family.

# Keep commander selection read-only and scoped to the acquisition pass

Authenticate the group and its leader before using their modifier operands. Army skill words are signed, and captured leaders retain a captor and location. The army formation reference is meaningful for the first two caster categories. The deployed headquarters value is used on the feature-enabled path. Group roots have their own identity and a vector of child orders groups with 32-bit capacity and count. An army group's common fields come from the orders-group layout. Its constructor establishes the child vector and the group discriminator.

Movement selection considers a separate headquarters block only for a division in class zero when the feature is active, the group has a leader and a headquarters provider, and the division and headquarters have different primary roots. An unreadable predicate remains unavailable. Compute dirty root results read-only and refuse a stale supposedly clean result. Search own primary roots first, then the immediate parent's, and stop at the first assigned root. Fallback roots belong to another predicate. Fetch member chunks only as the lookup reaches them, validating the current member and the array headers before reusing any prefix. A capacity miss reads the uncached suffix with the same bounds and ordering.

An acquisition pass is quiescent, so group and leader identity, the headquarters root, and feature flags can be shared. Division membership is local, with reusable underlying root and member reads. A new pass discards the previous generation. A full memo only recomputes further entries. Cache entries follow the observation's rules for reuse. In particular, a retriable fault must not become a persistent negative result. During range preparation, a fault already observed in that range is not retried. Admit observed group and feature values in census order. An earlier admitted value or refusal wins over a later range's contradictory result. Missing provisional branches use the ordinary read.

Resolve one commander selection per division for all presentation consumers, with the authenticated leader handle, group match, training byte and selected modifier block. A missing group differs from an authenticated group with a null leader or an unreadable handle. A current writer certificate can supply a previously read group or leader. Authenticate a fresh, complete record before giving it to the carry implementation. An allocation refusal leaves no partial set of selections.

Read the raw movement modifiers and retreat-ban keys from both possible blocks. A positive effective modifier bans retreat on the applicable side. A missing group or leader contributes no ban. A missing individual modifier key has no value. Read sorted, authenticated accumulator spans and retain the scalar failure for each group. After a short batch, continue with the next group without retrying the failed read. Very long accumulators use the chunked path. A held ban is reusable only while no observed writer has touched either block. An already read group leader can seed the batch.

Trait recalculation rebuilds the terrain and night adjusters and the army leader's fort, river, and snow terms. Capture the direct leader's full handle and raw fixed-point terms. Movement adds the speed term of the destination terrain on each edge. An invalid terrain index selects the first stored entry just as the game does, including when a zero live count has retained storage. A vector with no storage has no first entry.

Division, deployment, and garrison manpower use the same embedded signed layout, with eight-byte entries. Keep positive amounts and their raw tags in occurrence order even when the tags have aliases. A negative header is invalid. A deployment can sum positive amounts into a wider value and omit the sum for an empty array.

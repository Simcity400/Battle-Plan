# 0904. Keep the operands that political and diplomatic playback actually reads

## Slices and presence

`SliceReads` keeps each owner's last known acquisition for a sliced table. A complete read can witness an empty owner, even when it gives the table no rows. An owner with neither rows nor a read marker has unknown coverage. Keep the table's native owner identity, which may be a country reference, canonical slot or state id. A new hour updates only owners it read. A row's sampling hour and the frame hour can differ.

Record the state border-conflict gate hourly for every state, including false. An active state's conflict pairs preserve in-order traversal and signed raw country references. An observed empty tree stays distinct from an inactive state. The province list is sparse, with one row for each nonempty conflict set. Its admitted groups come from the combat defenders then attackers as encountered, keeping resolved groups with the required border-war operand and removing duplicates. An army enters from another conflict province or through a listed group. The neutral-occupation rule tests the stored byte and a shared enemy when no live war relation connects the countries. Enemy sets ordinarily derive from `WarRelations`. Read the native vector for civil-war revolters whose list is still provisional and owners of a retired war that can remain in the list. A sparse absent row means the rule byte is zero and the set is derived.

## Country and state ownership

Retain directed relationship slots by raw status owner and canonical target slot. The attache, air-base access, military access and docking bits feed fog, icons and traversal. The co-belligerent operand affects raid path cost and contributes no access bit. A complete-owner witness makes absent subject-access pairs known, while historical recordings can omit those inputs. Store a directed pair's native cached opinion only when nonzero, keeping its signed unscaled value. Relation tuples keep native vector order, separately recorded endpoints that can be aliases, and raw bytes. Keep the ordinal because the same type can repeat even though each compiled setter owns only one slot.

Keep current war-goal recipient references in native goal-vector order, with a refusal local to the list. Owned goal rows retain their historical framing, recipient, definition token and state ids, including null entries. Keep incoming action handles at their original queue ordinal so null slots leave gaps. Its wrapper byte and date word retain their exact native representation. A civil-war target list records raw references in stored order. A country is in civil war if it has a target or is the target of an enemy. Subject references and state cores and claims use `CountryLinks` where their consumers compare canonical slots. A state read with no cores still has a row.

Preserve the order of a state's cores, claims and strategic locations. Location pairs pack the definition token and anchor province, and province pairs pack their province and location token in the order stored. Unknown location lists remain absent. State resource slices refresh early when a writer marks a state, including core, claim and strategic-location updates. Dynamic modifiers retain definition and scope in container order under the same schedule. Unscoped queries check whether the first matching definition is itself unscoped. Occupation rows retain the group-law inventory, ordered raw references and actual fallback token rather than choosing one by authored position. Group inventories can be historically absent or refused on a new read. State workers observe garrison, resistance and suppression separately from construction, preserving their hourly cache operands.

## Script and political state

Preserve all relevant script scopes as global, country, state and character. A complete variables table includes empty stores and orders recorded keys by exact bytes. Persistent fixed5 values and seeds stay as stored, including the seed written when a scoped context exits. Flag state, variables and active ideas can change between hourly ticks, so refresh them for triggers in that hour. Built-in variable values are computed on demand. Global saved event targets keep their first-match order, duplicate names, and the validity mask and presence bits of their native references. Registry ordinal is the key. Clearing a name removes its row. The unit leader may resolve through the character's stored reference when its direct slot is absent. An observed zero with a leader present represents refusal. Preserve the intern-id-zero name omission and combatant presence separately from the save projection.

Keep the party's raw link tag distinct from its canonical slot. For default names try the tag and ideology-group keys, then the original tag, then the group's own name. Explicit short and long keys apply after an override clears that mode. Resolve them through recorded content. Party leaders retain native party and roster order. The ruling party's first leader supplies its display. Its script id is unset at −1, and the stored signed role key finds the exact leader pointer even when the current ideology has changed. Trait checks compare definition ordinals. The save gives the party list without leader ids, so the oracle can read each id from its recorded role. Political action duration counts remaining days. A complete decision count table makes an absent entry a known missing count. Preserve raw numeric target bits and distinguish unavailable, absent and recorded status seeds. The definition's random seed comes from its token.

The elections flag depends on a nonzero stored byte and a positive interval, with interval data retained in signed months. An exceptional initializer uses its own election date cache. Research placement uses the stored province first and the capital when it is zero. Hourly accepted positive experience awards preserve gross awards independent of spending or a cap. The surrender target retains the earlier instance field. For a complete award interval authenticate the same owner at both ends. Include every current country, even if no award was seen or its first interval is incomplete.

## Presentation operands

The stability, support and command power rows retain native fixed5 and Q15 operands, loaded defines and effective accumulator totals. This allows the dashboard to replay the calculation for the recorded content. A modifier key absent from the running engine has no value and uses the reserved maximum index in key order. Keep the coastal term, popularity, offensive and defensive war witnesses, interception sum and threat total as recorded. Command power is joined by canonical slot to the hourly command-power row, taking its effective maximum and multiplier and subtracting its allocation at that frame's hour. Raid and ace consumers use the same hourly operands. Definitions keep raw lexer tokens, precision, category, feature selector, exact localization keys and argument text. Their process-wide feature eligibility witness is carried on each row.

Stability lines preserve each tracked nonzero modifier entry in native child-tree order for the slice hour. This order determines tooltips and accumulated values. Identity comes from an exactly proved source, such as the idea or ideology token, a leader or advisor character, a static definition or a dynamic definition and scope. Distinguish constant and evaluated dynamic entries and scaled static additions. When source pairing is unproved, keep the rendered label under the recorded language. The resident world-tension total uses the clamped contribution sum and stores it separately from sources. Source ordinal supplies identity because the vector has no persistent ids. Keep both raw country references, the stored engine hour, literal reason bytes and the pre-clamp signed per-country aggregate. The native source count stays independent of rows that fit the capture.

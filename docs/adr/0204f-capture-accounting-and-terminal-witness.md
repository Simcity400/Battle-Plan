# 0204-F. Attribute capture work and freeze the first terminal witness

Each native read is charged to a thread-local table scope. The first withheld site leaves that table unavailable for the session under its name. Clock is the fallback scope, and its readers report their own refusals. Shared country authentication belongs to Countries, and the shared unit census belongs to Divisions. An acquired payload's consumers do not charge the reads again. A job's capture guard encloses its panic boundary so table guards unwind first and the caller's attribution is restored. Merging a job's counts is explicit and occurs once. The outer snapshot follows all source reads and worker merges. Caller-provided output storage avoids using the capture stack for large count arrays.

The collector host installs the allocation callback, which claims the terminal witness once and completes it without allocation. It wakes the frame waiter after publication. Bootstrap prepares the output file, contexts and diagnostic storage before worker admission. Queue changes prepare their capacity before publishing under the queue lock. The terminal callback cannot acquire that lock because allocation can fail reentrantly during a queue update. It freezes outstanding ranges before reading the committed watermark, and can recover a newer watermark even if the range snapshot predates it.

The spool writer advertises the old committed prefix before writing and keeps its attempted hour until its commit hook returns. Bytes written before that hook do not prove a new committed hour. Only a known committed frame hour for the same campaign, branch and load trims the outstanding range. A subsequent non-frame record preserves that context's last frame hour, while a different context does not inherit it. Fault injection counts only allocations in the selected phases. A thread that never entered a phase reports Unphased and does not consume a selected phase's injection ordinal.

`read_accounting::Capture::new` writes every field of `previous` before setting `open`. `Capture::restore` checks and clears `open` before taking the initialized reference. In `terminal`, `borrow_context` keeps an initialized, immutable caller-owned context available for the guard's lifetime. `failure` reads `TERMINAL.record` only after the acquire check sees completed publication, after which the record is immutable. The test fault injector calls the stored observer in `injection::should_fail`. The `observe_counted` registration path provides the typed `fn()` pointer, and a null observer is never called.

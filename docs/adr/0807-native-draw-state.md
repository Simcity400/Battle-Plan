# 0807. Preserve native draw state through refusals and batching

The draw stream receives commands after layer sorting, in submission order. Each renderer binding changes independently. A null technique leaves the previous program and input declaration in place and selects the default blend. A failed program or unavailable texture invalidates that binding because the game would have bound a new value. Draws that need it are refused by name. Explicit null textures have the appropriate zero views. An absent binding is unknown. Pixel null samplers retain their previous state and vertex null samplers use the D3D defaults. The sampler cache uses the bitwise key of the physically retained sampler, since native equality can leave an equal signed-zero command unapplied. A null constant buffer retains its physical extent and known-byte ranges. A new frame or foreign pass invalidates native binding state and can retain compiled pipelines.

The retained program owns the input declaration. Geometry commands provide the actual buffer offsets, strides and counts. A change in geometry must leave the previous declaration usable even with a null technique. Repacking preserves native fetches, including overlapping strides, zero strides, missing component defaults and raw format conversion. A fetch outside the allocation reads zero in the format's present components. An in-allocation byte the recording does not know is a named refusal. Do not reserve as though a short buffer supplied later fetches. Keep strips and their original vertex ID sequence.

A program may still bind when blend-state admission fails. Conversely, a visual mod's replacement may compile but fail to build a native pass from the bound state. Its draw reports the replacement by effect and technique, then tries the same technique of the recorded effect. Layout and packing follow the effective program. The same fallback and diagnostic must happen on every attempted draw. An installed effect outside a visual replacement has no such fallback. Stable refusal identities let the map compare presentations without depending on message text or installation paths.

The native-pass cache owns immutable resources from complete successful draws. A hit still checks the ordered pass key and every initialized constant byte, and never reuses earlier arena offsets. Geometry staging can fail after pipeline resolution, so publish cache bindings only once the entire draw succeeds. Texture maps are snapshotted at that boundary. A deferred pipeline build that cannot start or panics records a refusal so it cannot hold draws waiting indefinitely. A legitimate deferred draw still applies its native binds. Scoped render-to-texture inherits caller state without letting later scoped writes mutate it.

The caller owns attachments, topology, sample count, geometry and viewport. The stream uses native blend, depth and rasterizer handles, including rasterizer bias independent of the depth state. Alpha accumulation for a premultiplied intermediate retains the native color operations, accumulates alpha, and writes all channels. The next effect bind selects its own state again.

Batching is allowed when draws keep their invocation-local inputs. Batch metadata selects constant-buffer storage rows and texture-array layers. The fragment stage applies the per-draw clipping. Instanced rewriting selects only the masked constant bindings plus any per-instance vertex stream. It keeps other bindings and pixel work intact and relays the instance index to the fragment stage only when needed. A program already reading the native instance index is incompatible with rewriting that would change its meaning. Packed and normalized vertex formats in the rewritten stream are refused when the rewrite cannot reproduce the native fetch bits. Ordinary drawing keeps its own input path.

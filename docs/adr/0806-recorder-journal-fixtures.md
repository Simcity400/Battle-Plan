# Build synthetic journals through the recorder's real codecs

Offline recorder tools and tests share synthetic completed, interrupted and resumed captures through dev dependencies. The fixtures do not carry installed game data. They identify each load and publish an hourly clock witness before its frame, including when replacing a closing detach with an additional load. Each campaign segment uses its normal journal name and can omit the ending record to represent a failed collector. A map event interval begins at the prior hour so adjoining test frames remain continuous.

Recorded singleton tables get a row or a named retirement from the current registry. The synthetic collector refuses derived tables so their writer remains the recorder, which prevents an added singleton or derived table from invalidating existing fixtures. The synthetic envelope uses the same identity as comparison tools. The CLI's offline derived test still resolves movement content when no mover was recorded, matching the content requirement of the production command.

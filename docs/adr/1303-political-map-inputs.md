# 1303. Keep political map layers tied to certified recording inputs

Political fill uses two independent layers. Static sea geometry comes from the recorded strategic regions and the content's navy colour and thickness. Its ordinary opacity is zero, and separate control and gaining-side bytes drive the water effect. Land, including assigned lakes, uses canonical controller slots plus one and a recorded appearance colour. This leaves slot zero available without confusing it with the empty region key. Border owner keys resolve through the same country links. Unassigned provinces stay outside the layer. Map modes decide which country channel to draw. A missing core province or country fact is a frame error. If a colour or inherited source alone is undecidable, the affected country retains its region with the viewer's unavailable marker and a named reason.

Inheritance follows the current autonomy definition through overlords. A missing autonomy row is a null status only when the table is complete. An incomplete table, undefined status or missing endpoint leaves the source undecidable until the held inputs certify it. A changed colour, country link or active relation can invalidate a frame even when territorial control stands still. Per-hour work uses already resolved province definitions, with no scan of the map bitmap. A missing region member in an authored strategic list is ignored by the same topology rule as borders.

Naval control uses raw directed relations before resolving their exact certified operands. A viewer's family takes precedence over a directed war. Installed blockades retain direction and membership with no added retired or date filter. Faction, subject and visibility endpoints for the reserved country slot use the appropriate hourly visibility records when positive-owner tables cannot certify them. Read supremacy only for sea regions and use the ocean category when the region's category cannot resolve. Regions with less than one percent sea use constant control. Carry certified daily samples only within the native cache epoch. Do not interpolate across midnight. Match fixed-point wrapping and truncation. Select the gaining side from the top or second-ranked candidate according to control, and withhold an equal-rank choice when equally ranked candidates would write different bytes.

The naval selection overlay counts authored valid occurrences rather than unique region pixels. Repeated registrations contribute, empty sources leave the denominator and ratios clamp before blending. A selected task force does not implicitly select its fleet. The occupation overlay draws badges from captured active-source order, stably sorted by authored threshold, so it does not infer badges from aggregate level or effects. Preserve the native percentage sign and use gradient RGB independently of fill alpha. The existing map icon manager owns grouped admission, slot reuse and rounding. Occupation stripes use inherited country colour for the exact controlled occupied roster, regardless of the resistance percentage. The caller clears them in modes that do not show them.

# 1302. Bake model libraries in source order with isolated recorded alternatives

The model library resolves content-selected meshes, materials, textures and actor rigs. Admit names through their owner-specific declaration checks on both initial and recorded loads. A single failed name is reported without refusing the document. Current installation art outside content coverage is loaded through the uncovered art path and has no recorded hash verification. Diffuse maps use sRGB while normal and material data use linear colour. Texture sharing keys on both path and colour space. The library reads each animation once, retaining its refusal when neither content stack supplies it.

Distribute name loading over contiguous ranges and merge in first-seen name order. Only the first occurrence of each requested name is baked. Merge textures before materials and rebase every palette reference, including rigid indices, so the result matches serial loading. The recorded alternative for a visual-mod entity resolves without overlays and has its own file-cache namespace even for identical path names. A failed bake can use the recorded asset immediately. A later draw refusal can redirect an entity to its resident recorded counterpart, report the reason, and use the recorded shader selection.

Compose attachments in the root's object space. Keep their palette and actor records only after composition succeeds. A refused child leaves the parent and other successful actors intact. A failed root rolls back its model records but can keep decoded reusable textures. A missing joint can leave a locator in entity space. A zero-scaled joint hides its attachment. A dummy binding still plays its authored animation state and events. A subordinate node can retain skin weights for a clip even when it lacks a frozen default animation.

The palette stores three aligned rows per joint and transposes the imported column form once. Compose attachment transforms into root-space bind mappings. Use the placed corners of rotated static boxes and posed vertices for skinned cull extents, which can differ from the bind box. Enclose every drawable LOD. A creation-time convoy collision sphere is a separate native construction from per-bone transformed boxes, with restrictions on LOD and skin support. Map instances retain authored basis, scale and pose fields where supplied. An entity locator's world transform excludes the mesh import scale already baked into geometry.

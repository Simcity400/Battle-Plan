# 0707. Keep Rust ownership separate from guarded foreign reads

The scalar conversion helpers accept only sealed, padding-free types for which every bit pattern is valid. Initialized input bytes can be borrowed at the exact type width. Decoding copies into a disjoint, writable destination of that width. Initializing scratch produces a byte slice only after writing every slot. The immutable slice backend borrows its own complete source range and uses the caller's distinct mutable destination. It returns initialized bytes only after the complete copy. [Memory reader](../../crates/engine-native-memory/src/memory.rs)

The caller supplies the memory-consistency protocol. A native read can contain a foreign source fault without establishing that the source is immutable, or that it could be borrowed as a Rust reference. The source address must pass the null, overflow and host canonical-range checks. This Windows target uses the sign extension of bit 47. A range crossing the gap between the two canonical halves is refused. Windows can report a noncanonical fault with an unknown address, which the source-range exception filter cannot attribute to the requested span. The scalar FFI receives the caller's exact uniquely writable destination. A partial failure exposes no scalar or initialized destination. For the four-byte value return, the success marker is separate from every possible value. [Scalar acquisition](../../crates/engine-native-memory/src/memory.rs)

Batch descriptors and source selectors are immutable and outlive the call. Scattered copies send only the initialized metadata prefix. Prepared copies carry checked descriptor, comparison and destination bounds. Record gathers additionally require the Rust and C field layouts to match, with the validated row geometry covering every destination. The source preflight admits only the field prefix that passed address arithmetic and canonicality, including the fields of a partial final row. The native reader still decides source readability within that prefix and stops at the first fault. Thus an earlier inaccessible field takes precedence over the later address failure without evaluating invalid or later metadata. [Native batches](../../crates/engine-native-memory/src/memory.rs)

Optional lookahead hints use already selected addresses. They make no memory observation and cannot consume a Windows guard. The processor hint treats an arbitrary integer address as advisory, including a noncanonical or unmapped one. [Cache hints](../../crates/engine-native-memory/src/prefetch.rs)

# 0707. Exercise foreign read faults with owned fixture pages

Guarded-copy fixtures allocate writable, non-executable pages without requesting a fixed address. Fixtures own and release the entire allocation and only change protections on their own pages. Immutable fixture source and mutable output are disjoint. When the fixture makes a destination inaccessible, it passes a raw address to the native call and does not borrow the protected bytes. It restores access before checking the bytes and ends the borrow before resetting or protecting the page again. These constraints apply to the war-status hint tests as well as the memory reader fixtures. [War relation fixture](../../crates/engine-native/src/cwar_relation/tests.rs) · [Memory fixtures](../../crates/engine-native-memory/src/memory/tests.rs)

Readable copy inputs are immutable owner-controlled bytes. Fixtures may also supply null, overflowing or noncanonical source addresses to prove the original address gates. The tests for native containment intentionally bypass the Rust source preflight while supplying valid output and metadata. Only the guarded native code can evaluate these malformed or deliberately protected raw sources. Tests also cover a readable prefix followed by inaccessible bytes and guard pages. Ordinary hints must leave the guard armed. The first actual guarded read consumes it and returns a failed observation. [Scalar and gathered faults](../../crates/engine-native-memory/src/memory/tests.rs) · [Lookahead fixtures](../../crates/engine-native-memory/src/memory/tests/native_record_lookahead.rs)

Metadata-boundary fixtures place initialized aligned fields and pointer words immediately before inaccessible pages. Borrow only as many metadata words as the admitted prefix needs, including the final pointer for a partial row, and preserve repeated values as separate rows. Two-field and five-field layouts each restrict their field slice to the initialized descriptors. An empty Rust slice still uses an aligned nonnull pointer. Empty native prefixes must touch no metadata or output, even when supplied wholly inaccessible addresses. Destination canaries and untouched fields are checked after restoring readability. [Native boundary fixtures](../../crates/engine-native-memory/src/memory/tests/native_record_lookahead.rs)

Keep distinct tests for leading and rolling hints. Test aligned, unaligned and page-crossing copies and exact lengths ending before an inaccessible byte to catch widened loads. Overlapping seven-byte rows vary source alignment and a later field may overwrite a previous field in the same record. A failed field alone can be partial, so compare the complete prefix, padding, later fields and exterior canaries rather than treating the failed field as specified. Querying initial protection does not consume a guard; a later actual copy proves it was armed. A synthetic source keeps its own address domain, since host canonicality applies only to the native source backend.

# 1305. Share authored tree geometry across the lit and shadow passes

Generate one canopy instance for each nonzero tree bitmap pixel. Walk north to south and west to east so only placed trees consume the rotation stream. Tile assignment happens before the alternate north-first row's half-cell offset. Position uses bottom-up world rows, independent bitmap pitch on both axes, and bilinear terrain samples whose fractional coordinates follow the clamped base. Scale is baked into canopy positions, while the instance record keeps position, rotation and terrain slope. Preserve the native linear partition behavior at an x remainder.

Resolve used palette meshes from the complete descriptor roster. Keep the first usable material and geometry record for each authored LOD, with geometry uploaded together and indices absolute. The mesh's declared shade inputs include tangent handedness and a second UV pair. The declaration still fetches that pair from the next packed vertex when an LOD omits it, and gives zero at the allocation edge. Resolve the global texture index before mesh-relative lookup. Use the recorded content geometry and installed artwork. The coverage policy verifies covered bitmaps and names limitations for uncovered entities, meshes and textures. Refuse a broken visual overlay by name and fall back to the recorded layers. One tree kind unavailable in both does not prevent the replay opening.

Choose the closest visible wrap copy per bucket, changing the choice only for a strictly smaller squared distance. Compare to squared authored LOD thresholds and clamp to the available shape count. The distance is to the tile's nearest point at water height, evaluated in native axis order. Admit against the four expanded side planes. Preserve generator order before the native palette-and-distance sort, including its equal-key partition and heap permutations. Lit, caster and receiver passes share the admitted walk for the camera, so there is no distinct light-frustum walk. The caster uses the light matrix and has its own scene gates. The receiver runs before terrain and can still write depth at exactly the far fade height even with zero alpha.

The three techniques share the fixed tree vertex declaration. The caster replaces only the first scene matrix and does not copy a lit inverse matrix. Receiver constants contain their wrap matrix and fade. Lit constants clear the matrix and both modes write the known season fields, leaving unknown padding outside written ranges. The scene supplies shared physical texture slots. The tree pass owns its diffuse, normal, tint, season and river textures, with the river mask at slot 14. The renderer preserves alpha-only sampling with a zero RGB mask texture because wgpu has no alpha-only equivalent.

Build the canopy mask at half river-bitmap resolution. Classify indices below the bulk land/sea classes as river, flip input rows for the filter, and use the last 2 × 2 write for each output texel. That write begins on the odd row and column of the input pair. Clamp the last row and column to avoid indexing past the recorded bitmap. Average the four bytes with integer truncation so the authored mask threshold divides canopy pixels as expected.

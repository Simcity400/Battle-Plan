# 1301. Resolve aircraft rigs and models on their first reached use

The authored aircraft comes from the largest amount of primary wing equipment, first on a tie. Designer and stored variant selections precede the standard name ladder. Each available prefix tries equipment name, archetype name and sprite. Cosmetic and country tags precede the bare candidate. Graphical culture supplies no extra fallback. The first registered candidate ends lookup whether usable or refused. An unreadable file may declare the candidate or a dependency, and refuses it by name. Duplicate or unordered declarations with an unverified native choice remain refused.

Resolve an effect or entity from the shown content stack and try its recorded fallback when a visual overlay cannot build it. Keep the shown refusal if neither builds. A bad mesh, animation, parent or attachment affects the rig that reaches it, so the rest of the document opens. A selected name may lack an equipment suffix. Use the same admitted roster for its first bake. Fly mode requires drawable geometry even if another use can retain a meshless entity for its events. Resolve outside the UI thread, share a cold bake only for the same entity, and recheck the committed result after obtaining a claim. Keep successful and failed outcomes and any attachment omissions.

Per-hour model selection can retain a result while its recorded census and addressed reads agree. Fresh pool outcomes and joined country geography are conservative whole-set dependencies. Re-evaluate refusals each hour because their explanations can name the hour. Separate raw country references in the selection key. Read the primary-equipment table lazily when the hour can emit an actor. Reuse exact placement results by the prior build's model, wing, geometry and random inputs while the owning map and assets remain the same. Retain states-in-region from the province identity and membership columns rather than invalidating for unrelated field changes.

Sample scenario tracks from locators and the source-order pose. An animation joint name does not rebind a skeleton. A slot with no corresponding locator rides the entity root with its authored scale. Only an unbound rocket needs the separate rocket speed. Only rigs with a nonlanding actor require near-ground defines. The default outcome reads the selected entity's default state when no explicit default exists, and named outcome states keep their own selection. Authored flight and effect graphics can override the recorded layer's defines, while simulation-based sorties read the recorded operands.

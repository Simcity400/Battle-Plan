# Size capture buffers from live demand without waiting on the game thread

The sizing thread observes live header and roster demand off the capture path. Those observations only reserve storage. They never become recorded data. The game thread does not wait for a scratch frame, a held store, or an off-thread allocation. Demand snapshots grow exclusively owned idle frames outside the shared capacity lock, and the capture can construct a frame from the latest snapshot if no idle frame is ready.

The country and strategic-region watches read cheap headers. CountryIntel totals walk each country and poll less often. Saved-target, character, politics and raid data fill after the country registry on load, so observe their demand separately before a full capture. Logistics, recruiting lines, combat families, moving owners and navy/map inputs can grow independently of the country census. Callbacks perform immediate load and refusal checks even when a sizing observation is throttled. Strategic-region capacity follows loaded content and uses zero only as an internal sizing hint if the count cannot be read.

Track independently readable floor values and retry failed offers, including when the underlying population count has not changed. Combat hints only apply to the corresponding frame generation. Hint allocations preserve existing storage on failure and do not certify the actual capture capacity. A spool return hands back the frame it owns; sizing is the only path that leases an already idle frame. When recording identity verification refuses a capture, preserve its local diagnostic for status.

The periodic census can back off only after a recycled frame publishes the current admitted world’s captured capacities. Loading, world invalidation, or a refused hint restores the fast cadence. Routine capacity raises and skipped observations do not. Advance the census deadline only on a periodic pass, so repeated hour-driven work cannot postpone it. Trigger an early pass after receiving an hour or while a world loads. Retiring encoder-owned data may wake sizing to free it without requesting a live read. On the spool fallback path, gate every live read to wait out an active game tick and grow only the returning frame. Sample that frame’s world generation before recycling clears its clock. Measure complete frames after preparation and charge shared stores separately at their maximum observed sizes.

An arena that must accommodate pending hours grows with the number of frames awaiting spool drain. This includes political staging, which cannot wait for the next census. Prepare script-variable scope watches before native writers can use them, and include event arena demand in the relevant live observation. The fuel-unit arena has independent preparation and timing. Fixed map and geometry buffers keep the mixed map demand group on the prompt schedule. Naval management sizes only after a world is admitted because an early incomplete count cannot grow its table again before load.

Reserve a 16 MiB stack for workers that handle whole frames and tables. Optimized whole-frame functions can already use several hundred KiB, so the standard Windows worker stack has little margin. Windows commits only touched pages. Hand the current spool allocation context to sizing for terminal failure reporting. A refused frame from the ahead builder terminates the spool.

A merely slow spool retains queued frames and reports their time and bytes. A stalled spool that cannot take an hour stops growing a new frame for each later hour and records those losses. Normal growth resumes when the spool can take frames again. Frame returns release the surplus once free frames exceed the reserve, and the kept frame can be an unused spare. The regression holds sizing growth or the free of a surplus frame while the independent builder or capture proceeds, with cleanup guards to release both sides on assertion failures. Separate accounting checks count actual frame storage and each shared home independently.

Sizing tests pin an active throttle instead of relying on when Poll runs. A throttled observation supplies neither a zero nor another failure. A country header above the valid slot range is refused as torn, and a later valid hint may still grow the buffers. A failed or unreadable hint leaves earlier readable capacities intact. Raid sizing consults memo headers even when buckets are unreadable, and a rehash can increase memo storage without new tokens or reservations. A returned frame still receives hints that were published while it was held, including a dropped frame that returns straight to the free queue.

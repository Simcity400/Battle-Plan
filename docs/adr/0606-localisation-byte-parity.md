# Keep localisation loading and layout faithful to stored bytes

Use the recording's content stack for language selection. Prefer the requested entry in the authored language list, otherwise the first declared entry. If the recording carries only another language, its text is shown with the substitution reported. File parsing consumes exactly one BOM and splits on physical LF. Bare key and version lines select a language table. The last quote on a line closes its value before escape decoding, and a missing closing quote yields empty text. Keep keys as authored. Values get one escape pass. Illegal escapes log and retain the character, and failed UTF-8 conversion logs while retaining prior decoded input. Syntax errors stop the file. A value before its first language table has no established source context and is refused.

Files outside `replace/` are merged first in layer and bytewise path order. Keep the first definition and report duplicates. Files inside `replace/` overwrite in the same order, including when a replacement came from a lower layer. A header's version does not affect priority. Parse all file names and tables, since a file name can neither establish the language nor prove which diagnostics the game emits. Concurrent reads are applied in file order, which preserves failure precedence.

Five single authored controls become stored bytes and doubled controls remain literal. Count substitutions in stored bytes. One bounded output cursor is shared across recursive references, and reaching its limit stops deeper writes. Missing top-level keys copy their bytes, while missing nested keys write nothing. A repeated expansion that neither writes bytes nor puts a new runtime demand on the caller can be skipped at the same depth. The same walk handles deferred arguments, missing-argument recovery and formatting. Output can be bytes that are invalid UTF-8. Text consumers distinguish a character cut by the cursor from other invalid text.

Formatting follows the argument type and native rounding. Signed integers ignore decimal precision. Fixed-five values are truncated, and compact forms work from the narrowed whole part. A single `%` scales ordinary numeric paths and appends a percent sign, while consecutive `%%` and compact forms append without scaling. Sign directives use the original value. Float percentage multiplication rounds in single precision, and the textual spelling of NaN follows its original bits. Colour controls and suffixes are bounded by the same cursor. Scripted numeric variables use a smaller scratch space and fall back to all fixed-five digits with trailing zeroes trimmed when the requested format writes nothing. The text layout splits the stored stream into glyphs, colours, flags, icons and spacing. Plain text drops colour markers and inline images and refuses spacing controls with no plain-text equivalent.

A parse memo reuses only the parse of identical bytes for the same language and executable stamp. It cannot replace looking up, reading or verifying files. A damaged memo or one written by a different build falls back to parsing. Separate program names keep the viewer and dashboard from sharing an incompatible memo. Publish complete files using distinct temporary paths and a trailing digest, and write a new memo only when the set of cached parses changes.

# Resolve content and duplicate declarations using each reader's load order

Recording and playback use the same resolved content stack. A file supplied at the same path replaces the earlier file, including when the replacement is empty. A folder replacement hides the base folder. Native database readers that take direct files ignore nested ones. Once the stack decides which files are visible, database readers may sort the surviving paths by filename independent of the layer that supplied them. This is why a base file that sorts later can win over a mod's earlier file. Readers that use the native GUI traversal load files before descending into subfolders and give the load screen file its initial position.

Native database insertion rules differ by definition type. Categories and resources append, groups replace, and ideology, trait and modifier lookup can keep the first matching declaration. Character projections use the same resolved definition so different views cannot resurrect an earlier portrait. Resource and modifier scalar readers keep their native token consumption even on malformed values. A malformed resource declaration can consume a later-looking declaration, but another readable file still loads. Refuse unknown variables and unsupported colour forms by name.

The sprite and GUI readers keep the prefix accepted before a stray closing brace stops the file. A GUI object that reaches EOF without all its closing braces can still be registered. A replacement that the viewer cannot read withdraws the earlier artwork for that name. Later readable declarations can restore it, while unrelated declarations leave its refusal in place. This keeps a missing override from silently becoming base art. For GUI windows, trace the registry's insertion order within each block and across blocks and files, including unnamed templates. Within a window, button names match without case. Lookup uses direct buttons after the shared element-name tree decides the accepted entries. Nested controls, non-window elements, and same-name children of a different window cannot satisfy that request.

# 1306. Stage particle draws only after proving the authored layout

The renderer uses authored techniques, declarations and constants. The viewer supplies reconstructed particles in a stable order by bucket, actor and packet. Historical enqueue order across producers is unavailable. Each actor's ordinary packets precede its trails. A packet's wrap admission and canonical particle positions, world transform and retained atlas tile are independent of the view. A world transform normalizes basis columns independently, preserving zero columns. Camera fade changes the submitted alpha separately from shader conversion.

Retain the native stream's bindings even in a view with no actors. Each enabled actor binds scale and the quad before inspecting particle counts. Trails replace the first vertex slot, and even an empty subsequent actor must restore the quad. Compare the values actually applied in this view, including known constant ranges and bound geometry, so the no-op checks cannot skip a state change that originated in an empty actor or inherited state. Keep depth, frame and light-grid inputs in the order the later world passes inherit. Cache immutable technique decisions by the resolved original technique name and trail state, including absent and refused selections. A bind is insufficient to publish a cached draw if staging later fails. The retained state key includes unread slots, distinct views of the same texture, explicit nulls, and missing entries.

An ordinary actor's instances use one ring append before its first packet. The ring resets per view, appends without overwriting earlier records, and renames the allocation once a discard reaches capacity. Earlier bound records then remain readable in their original allocation. Keep the writer's initialized prefix per instance and refuse to infer the tail from physical zeros. Likewise, trail capacity is bounded by the format's signed byte count and allocated separately from the known upload prefix. Preserve partial constant and vertex ranges in the path capture.

Fast packing requires a proved ordinary declaration and initialized writer ranges before GPU staging. The proof compares formats, strides, offsets and overlaps. Fill alignment padding as the generic packer does. If a stronger prefix proof misses a valid narrower read, allow the ordinary stream path to determine the result. Keep the original quad-upload, actor-upload, stream-bind order. A staging refusal goes directly to stream fallback, preserving allocation and refusal order. Each proof covers the current actor's records. Keep immutable plans and reusable storage across views. Clear GPU slices before another Arena can use the scratch.

The reference tests feed the generic stream declarative bytes and states. Their fixtures specify technique selection, ring layout, binding order and cache keys independently of production. They cover empty actor binds, null technique selection, trail replacement, inherited known ranges, capacity rollover, and late geometry refusal followed by same-frame staging. A separate actor comparison exercises the complete authored prefix and a valid partial layout that the optimization cannot prove.

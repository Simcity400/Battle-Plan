# 0203. Share one authenticated HQ census across portrait reads

The portrait capture reads exact native portrait strings and retains the authenticated leader source pairs for the adjacent picture-directory input capture. At most one leader per orders root can contribute a row, so the orders-root count sizes both buffers off-thread. An incomplete source census withholds the picture-directory table by name. Its tag memo keeps one cell per observed country slot and grows with the census. Vacant buffer placeholders stay allocation-free while a worker owns those buffers.

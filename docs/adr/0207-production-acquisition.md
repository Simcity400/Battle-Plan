# 0207. Replay one owned acquisition through the production readers

The acquisition worker copies the country census and raw production and deployment spans. The FIFO decode worker uses the same typed readers as synchronous acquisition, preserving row ordering, truncation, arenas and failure reasons. One authenticated census feeds the eight scheduled tables. A country is visited only at its canonical slot, excluding aliases of the reserved object. Production lines, stockpiles, licences and licence records share a manager. Conveyors, deployment lines, manpower and equipment share another. The shared census marks all eight tables on failure, each manager marks its own family, and a table-specific leaf marks only its table. Empty licence records still take the same staged walk as nonempty records.

The mirror copies the structurally reachable read spans. It can stage a superset, leaving outcome and failure precedence to the unchanged typed reader. `Recorded` serves exact span keys. Stage the string header, separate header fields and required heap payload and terminator so both whole and scalar reads work. Array headers read separately also need their own keys even when already present in a wider span. Record the production efficiency spans the selected factory maximum actually requires. The factory defines are acquired once at the first line that uses them. Validation of a deployment leaf or allocation entry takes place in the typed walk against these owned spans.

Make storage preparation advisory and grow buffers from original headers and census demand on the worker. Presize to observed country slots so a larger save's first acquisition is covered. Reset lengths and keep capacity between refreshes. The optional discovery trace can fail independently of ordinary capture. A replayed discovery program must acquire fresh payload bytes, validating each controlling read before following its dependent address. A changed control resumes ordinary acquisition at the recorded prefix and leaves its read values and failures intact. Once an acquisition has received source observations, transcript or storage failure cannot justify a second live acquisition. The discovery key includes census capacity, which controls admission, while row capacity belongs to the later typed result.

The fixture covers reserved country aliases, type and kind overrides for factory limits, and exact efficiency truncation. It compares the split's table rows and outcomes against the direct reader with equal capacity. Fixture declarations carry the role of each fake native object. Keep the guarded copy boundaries when partitioning variant children and let the results merge in reader order.

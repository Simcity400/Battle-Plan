# 0901. Share column pages and copy only what a walk changes

A reader holds current rows as typed columns indexed by the writer's slots. It trusts certified changes and applies each column in place. After a decoding error the table may be partly changed, so start again from the next restart. A slot removed from the live set has no row. Its underlying column cell releases list resources and keeps the column default. Table equality compares live rows and their slots. Leave untouched pages shared during release, and preserve the page bases expected by hot walks even when a restart omitted freed slots. An optional value carries presence independently of the numeric storage. A recording's unrecorded cell is unknown even when storage holds a number. Columns absent from an older schema are widened as unrecorded, including when additional rows are inserted. Deltas use wrapping arithmetic at the encoded width so the exact value is recovered.

Columns, keys, and key-index pages are copy-on-write. Share all pages at a restart and copy only updated pages. If a weak restart cache refers to a page, the first subsequent write also copies it. The cache only recovers a table while every referenced page is alive. A first-page check provides a cheap retention check. A positive result still requires a full upgrade. Held bytes count allocations even when shared. Owned bytes count unique pages, shared bytes count pages only the pair owns, and common bytes count pages at the same position even with other owners. The accounting includes each page's shared header.

Page items are allocated fallibly. Only their fixed-size share header uses an ordinary allocation. A partially occupied last page grows by powers of two to limit repeated copies. Keep slot lists ascending so each mutation can hold a page once, including bit mutations grouped by word. Each list page stores one item stream and cumulative slot ends. A rewrite appends the replacement items to its output buffer. A unique page can move the untouched ranges in place. Move leftward ranges first in increasing order and rightward ranges second in decreasing order to avoid overwriting unread items. Append at the end when all affected cells are empty. Rebuild a shared page. Clearing empty cells leaves the page intact. After a large rewrite, release the 64 KiB-plus item buffer to bound retained scratch size.

The open-addressed key index keeps each bucket's slot and the key's hash. The full key lives in the table's key column. The reserved tag bit distinguishes empty and removed buckets. It probes with room to reach an empty bucket, rebuilding above three-quarters occupancy and targeting at most five-eighths occupancy. It can rebuild using the held hashes. Old pages leave before new bucket pages are made. On removal, trailing tombstones immediately before an empty bucket can also become empty because no lookup passes the empty boundary.

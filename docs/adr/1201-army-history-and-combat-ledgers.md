# Army charts preserve the recording's time and accounting boundaries

The monthly losses chart reads only the displayed measure and ledger. Opening a drill reads every part for its one month. The chart lists each ordinary army once, including independent armies. The group is a classification attached to an army, since group headquarters do not hold additional ledgers. An unresolved group gets its own bucket. The three attrition channels partition attrition and add together. Recovered equipment and enemy losses are displayed separately from the army's losses. Manpower uses the game's signed 32-bit wrapping sum. Equipment is kept at the recorded five-decimal precision. Geometry converts exact amounts to numbers, while labels and tooltips retain exact values.

A monthly aggregate is unknown if no army retained the month or if any contributing army's amount in the selected ledger is unwitnessed. A current month includes observations only through the cells' read hour. An authored equipment name that looks like a synthetic bucket stays its own group. A complete recording window can supply zero for groups absent inside that window. A missing window remains a gap.

Army size uses the shared race and sparse history chart. The race follows pushed rows where supported, paints values and order from each answer, and renders only when its structure changes. The ranked countries remain known to the render after they fall out of the current top set, so a returning label or flag needs no new render. A paused seek includes the sought hour in render identity even if the same rows continue to rank. Group membership that has any unrecorded period cannot establish the campaign-wide membership. A known-empty group can omit its history reads.

The chart only requests recording-authored windows required by its viewport and the current row or mix moment. Margins and the next playback block are prefetch. A required window missing from memory surfaces loading. Frame hooks reevaluate request keys on a relevant render and combine arrivals in the next frame. Unwanted windows can be released. Chosen-country series use reusable tiles, and a ranked view reads summaries one view at a time because the ranked members can vary by bin. Only the current navigation request can answer the pending seek. Stable chart roots prevent an extra empty commit from callback-ref churn.

A drill preserves exact native group operands and their unidentified residual and joins boundaries without expanding hours or bridging gaps. Alias tags share an identity's history at their native dates. Pinning retains the origin tag, date and chosen measure, and opening a ranked drill offers the rank at that hour without automatically selecting its first country. The available measure and the dynamic default come from the recording. A capability request with an empty selection can ask only what the recording offers. Chart formats use their fast numeric path only for safe integers. The exact path covers larger values.

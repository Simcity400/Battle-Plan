# 0204j. Select naval combat inputs from an owned census

The host owns the naval part's dispatch, loans and table assembly. The hourly province walk preserves vector order and the native entry classes. It reads every province on an unobserved or changed epoch or header. Otherwise it reads the previously populated provinces and the ones whose combat vectors were marked. Only the hourly path consumes marks or takes the pool's shared held walk. The sizing path walks without touching those observations. The held walk is returned only after a complete read. Transfer scratch sizes from every nonzero occurrence before deduplication because the compacted row count would understate the demand.

The acquisition worker grows naval details and retained result arenas from readable observations. It replenishes the other pooled frames from counts and used lengths without trusting failed headers or allocator slack. Naval sides, linked carrier bases and live planes are selected by the full census. The dense carrier-base inputs retain first-reference order and appear once per base. The capture uses per-task-force doctrine, commander and location memos and a per-capture weapon metadata memo. Serving a memo emits the same rows in the same order as a fresh walk. Bench fixtures mutate values in place between calls to prevent mistaking equal pointers and counts for a certificate. The synthetic scale fixtures separately exercise quiet, typical and broad changes through the real capture callback.

Retained results keep their primary rows even if optional commander context is absent or mandatory fields refuse a dependent detail row. A missing portrait preserves the original side handle. A transient batched fault can recover the same hit list from per-entry reads. A lasting fault keeps the result and error order of those per-entry reads.

Hover inputs walk each distinct reached accumulator once. Country and commander trees may instead be copied when the receiver's certificate held from before the read and still holds. An incomplete census or capture refuses the dependent trees and clears old holds. The diagnostic oracle reads fresh trees for comparison. Its table is empty when the feature is off. Projection prunes display trees per key, preserves names only on rendered leaves and retains a zero child if necessary to keep a root interior. A live side's weather entry keeps its display boundary even if its components print nothing.

`naval_details::member_phase_data` gives `QueryPerformanceFrequency` a writable output pointer to a live local for the duration of the call.

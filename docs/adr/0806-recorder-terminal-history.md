# Recover only history supported by a terminal witness

Passive finalization reads the same codecs as the collector. A modern session must have a prepared terminal witness matching its process session identity. Prepared identity alone is evidence of no published failure. A declared failed capture requires a valid terminal witness. It then projects the committed prefix and uncommitted ranges for the relevant campaign from the terminal bundle. A failure-only segment may have no spool file. Finalization validates the already published prefix and does not re-add loss already present after an earlier save. It names a lost hour only if no committed frame or recorded gap already accounts for it.

Resolve an admitted loss range before the attempt that failed. Adjacent losses on one branch become one gap. Checkpoints may move earlier committed records from the spool into the recording. Recovery derives the branch tracker and the last committed hour from both places. A context record may commit before a branch's first clock. If a witnessed branch follows the previous one with a continuous clock, native invalidation proves the transition. Otherwise recovery uses only the branch evidence it has. A campaign with lost hours and no recording can return loss records without inventing a saved file. The terminal loss revision stays unsaved.

Finishing first reconciles interrupted discards. Sessions report damage, refusals and partial outcomes even when some campaigns were written successfully. Inspection keeps a capture mode's excluded table absent and distinguishes unrecorded timing data from zero. Character inspection resolves a template token only when the recorded lexical table is complete and holds that token.

For live history requests, classic file replacement can be refused while a delete-sharing reader holds the prior request. Publish a replacement rather than updating the request in place, and track whether an error happened before or after rename. A temporarily unwitnessed flush after rename can still leave a loan visible to its reader, so its requested return remains pending. An unresolved return prevents another loan of the same campaign.

# 0701. Keep optional air transport inputs in one observation

Capture optional battle-plan transport fields from an admitted, quiescent wing census. Preserve the source field's own refusal and leave the base wing outcome independent. Scratch grows off-thread, with one distinct reached key per admitted map row in each arena, and accounts for its actual owned capacities. A reserved memo slot admits a read exactly once. Probes are bounded and retain successfully copied values and failures. Growth rehashes the observed keys without rereading them. Only a new pass clears those observations, while idle owners can reset diagnostics without discarding storage.

The fixed pass owns its base and database header observations. It copies the complete stored raid reference and retains the resolved pointer only until this observation ends. This lets another worker consumer use the authentication result without another native lookup. A readable unresolved or null reference remains a known absence rather than a source fault.

# 1104. Decide land combat markers independently of camera placement

A marker exists only when both sides have a nonempty recorded country list. A missing side row withholds that decision. When present, the marker reads the cached engagement state for the viewing country and records its provenance. The unseen state hides the direction, bombardment and air children, keeps the question mark and leaves the last seen frame, using the authored initial frame if history is unavailable. The seen state uses the indicator frame and the bombardment bits on either side. Air map mode uses the Air superiority child in place of progress and frame. The raids map mode clears province icons. Child names, sprite selection, and terrain-qualified sprite fallback follow the content bindings.

Progress uses the observed side fraction based on every ordered participant's current organization. A missing division refuses the percentage, and the `COMBAT_ICON_PROGRESS` localization receives `VAL` as a fixed-point percentage while retaining the content's formatting, color and inline icons. The survival estimate independently needs combat details and reaches only committed units' maximum panel hit points when applying early damage. It does not need the DivisionStatus row to read current organization. A seen combat's plate and wedge take the viewer's winning, losing or balanced tint with the game's ten-percent band. Report each omitted or limited part by cause and combat without treating other proved parts as missing.

Geometry starts both anchors at the defender, then points toward the first attacker with a map entity and current stack kind rebuilt from content. Refuse still-relevant missing geometry by name. Unwrap the attacker's x against the defender before taking the midpoint and direction, so an icon near the seam does not cross the map to the wrong copy. Prepare markers and their gaps once for the hour. The retained windows apply the camera and draw them.

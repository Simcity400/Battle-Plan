# Log widget family

Log widgets (chronological feeds, histories, and ledgers) share one stateless tail contract on the native side and one canvas-painted worker family on the UI side, upholding the five family properties in [ADR 1398](1398-widget-family-contract.md) and the five-state value contract in [ADR 1397](1397-family-value-contract.md).

## Native tail contract

Every log widget subscribes to a stateless, exact `tail(hour, params, limit)` dated panel returning one shared `LogTailReply` envelope (`columns`, `baseOrdinal`, `firstOrdinal`, `total`, newest-first `rows`, exact `facetTotals`, `missing`, and `warnings`) without touching `dashboard-follow::host`.

- **Exactness and statelessness.** `Reader::tail` and `Reader::total` share one `slice` core with `Reader::page` in `crates/dashboard-query/src/log.rs`. `LogTailReply` omits the moving query `hour` (the `PNL2` frame carries it), so `dashboard-follow`'s `panel::product::Delivery` automatically emits zero-byte `STANDS` updates on quiet hours. Multi-facet country filters (`country|receiver`) count and emit each event once under its canonical first matching group across rows, totals, ordinals, and counts. Dated membership runs and unobserved spans are applied per row hour natively rather than flattened to a static tag set.
- **Exact facet totals.** `countFacets` computes exact counts up to `hour` (including the current partial bin), eliminating stale bin-rounded counters such as `division-log`'s vanished diagnostic. Facet summary pills derive complete, partial (with reason), or not-recorded state from coverage over their own counting interval.
- **Inline enrichment and bounded caches.** Domain tail products (`division-log-tail`, `market-ledger-tail`) share one `enrich_rows` path with their paged counterparts (`division-log`, `market-ledger`). Equipment variant names resolve per `(run, row hour, variant)` rather than once per batch. `PlaceCache` and `VariantNameCache` are `Source`-scoped, bounded with FIFO eviction, cleared in `forget`, and verified equal to uncached resolution.
- **Bounded work.** `limit` (`K`) is sized from the viewport height (`tailLimitForViewport`, floor 64 rows). `log::Reader` scans only facet columns into a bounded immutable-bucket index cache and decodes full columns only for the `K` cut rows (`log_rows_at`), and branch table-status coverage is indexed once per `(source, revision, branch, table)`, so per-step work depends on `K` rather than bucket density or elapsed campaign length.

## UI log family (`ui/src/families/log/`)

- **One projection for drawing and audit.** Each log widget registers one pure projection `(sources, hour, options) => LogModel` with `registerLogProjection`. The worker lane (`familyLogLaneView`) and the main-thread exact-read audit (`FamilyLogHost` via `AuditSnapshotStore`) run the same projection and layout on the same visible slice, comparing canonical five-state values and row order (`ordered: true`).
- **Host-owned playback discipline.** `FamilyLogHost` paints onto a worker-owned `OffscreenCanvas` (row layout implemented; card layout declared as an extension point). Facet summary pills and the accessibility mirror update in the DOM without triggering React commits (`0` commits during playback), and `install()` performs zero DOM layout or style reads. `useShownHour()` reports `null` before first paint and the painted `model.hour` thereafter.
- **No entry animation.** Rows appear in place without a new-row entry animation, and the `New-row animation` setting (`rowAnimation`) is removed from log-family widgets (`LOG_FAMILY_OPTIONS`). At high playback speeds the entry animation added visual noise and required a second canvas.
- **Cadence and pause.** Mirror (~1 Hz) and tooltip (≤4 Hz) updates share `CadenceGate` and `TrailingFlushScheduler` from `ui/src/families/cadence.ts`, with an immediate flush on pause.
- **Scroll-back and jump to latest.** Scrolling away from the top freezes the displayed hour and snapshot without shifting the user's rows, displaying `Jump to latest` (or `{N} new · Jump to latest` as live events arrive). Scrolling past the `K`-row tail loads older slices on demand via the existing paged product (`division-log`, `market-ledger`) while preserving the frozen hour's facet totals and diagnostics. Pausing at the top fetches nothing.
- **Widget standard visuals.** Row heights follow R6 (`28/22 px` single-line, `44/36 px` two-line); missing/unrecorded values render hatched placeholders (`drawFormattedValue`) and never silently default to zero or another category; recording gaps render inline as hatched `Not recorded · {span}` rows (R13); filter chips occupy one horizontally scrollable row (R14); tooltips carry a date line (T1) and pin with `P` (T10).

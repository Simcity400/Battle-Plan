# Log widget family

Log widgets (chronological feeds, histories, and ledgers) share one newest-first paged tail contract on the native side and one canvas-painted worker family on the UI side, upholding the five family properties in [ADR 1398](1398-widget-family-contract.md) and the five-state value contract in [ADR 1397](1397-family-value-contract.md).

## Native newest-first row space

Every log widget reads one unified newest-first row space `(hour DESC, group ASC, key ASC)` through a dated `tail(hour, params, offset, limit)` panel returning one shared `LogTailReply` envelope (`columns`, `baseOrdinal`, `firstOrdinal`, `offset`, `total`, newest-first `rows`, exact `facetTotals`, `missing`, and `warnings`) without touching `dashboard-follow::host`.

- **One total display order.** `Reader::newest_page_with` applies `(Reverse(hour), group ASC, key ASC)` before slicing `[offset .. offset + limit)`. The live tail (`offset = 0, limit = K`) and deeper scroll-back pages (`offset > 0, limit = pageSize`) slice the exact same ordered sequence, so same-hour ties never reorder or jump across page boundaries. Chart and notice callers (`bins`, `counts`, `page`) retain per-pattern counting (`Overlap::EachPattern`), while multi-facet (`country|receiver`) and dated-membership log queries deduplicate each event to its first matching group (`Overlap::FirstMatch`).
- **Exact facet totals and coverage.** `countFacets` computes exact counts up to `hour` (including the current partial bin). Branch table-status coverage is indexed once per `(source, revision, branch, table)`. Full-interval coverage belongs to the query identity and is never replaced by an interior page's clipped coverage; inline gap rows use a separate clipped copy.
- **Bounded native work.** `limit` (`K`) is sized from viewport height (`tailLimitForViewport`, floor 64 rows). `log::Reader` scans only facet columns into a bounded immutable-bucket cache, uses zero-copy `partition_point` slices with early-exit single-group dense-hour cuts, sweeps overlapping membership intervals in `O(N log N)`, and decodes full columns only for the cut rows (`log_rows_at`), emitting `Cell::Unrecorded` for any projected-out column. Seeded `dated_tail_panel` reuses the precomputed selection and returns the previous `Arc<PanelData>` directly across quiet hours with zero bucket entries examined. `VariantNameCache` resolves equipment names per `(run, row hour, variant)` and is `Source`-scoped, bounded with FIFO eviction, and cleared in `forget`.

## UI log family (`ui/src/families/log/`)

- **Shared host core.** `FamilyLogHost` builds on `ui/src/families/host/`: independent per-mount placement identity (so inline drills and popouts never share a canvas, binding, or audit reader), scroll geometry, `WidgetState` body states with stream vs local retries rendered inside the viewport (keeping filter toolbars mounted when the last chip is turned off), separate hover and focus tooltip channels (`P` pins the focused tooltip), live appearance/theme invalidation while paused, `FamilyArtLoader` bounded icon loading, and `AuditSnapshotStore` pinning and audit-ready acknowledgement.
- **Unified query identity & scroll-back.** Scrolling away from the top freezes the **acknowledged** picture (`liveSeq`, `hour`, `total`, full-interval `missing`, `facetTotals`) under the full query identity (`source`, `revision`, `branch`, `facets`, `from`, `pin`, `follow`, `bounds`) without shifting rows and mounts `Jump to latest` (updating `{N} new · Jump to latest` via an installed DOM field with zero React commits). Scroll-back pages are cached per page index under the query identity so late replies or failures for scrolled-away pages never overwrite or error over the currently viewed page; any query-identity change aborts in-flight page fetches and clears frozen state.
- **One painted-model audit.** Each log widget registers one pure projection `(sources, hour, options) => LogModel` with `registerLogProjection`. Both the worker lane (only while audit capture is active) and the exact-read verifier serialise the painted model via `canonicalAuditData` (`deriveLogAuditRows`). Audit snapshots include the full query identity and exact fetched page offsets/limits (including expanded offset `0` pages). Paint invalidation uses a lightweight paint-only signature and copies `backCanvas` lazily only when an incremental shift blit applies.
- **Host-owned playback discipline and density parity.** `FamilyLogHost` paints onto a worker-owned `OffscreenCanvas` (row layout implemented; card layout declared as an extension point). Row heights match existing widgets (`38 px` comfortable stacked title over detail; `28 px` compact with title and detail side by side on one line); factual columns (figure/status) and sublines are never dropped at narrow widths (`300–340 px`), and overflowing rich lines truncate as a whole with an ellipsis (`…`). Filter chips wrap in `.family-log-toolbar` matching existing spacing. `Enter` on a focused row opens the row action menu; the `role="listbox"` mirror is built from `visibleItemRange` with distinct non-colliding indices for gaps vs rows.
- **Row entry fade-in (owner decision).** Newly entered rows fade in during the worker's single canvas pass when playback speed is `<= 48` game h/s and `prefers-reduced-motion: reduce` is not active (no user setting). Above `48` h/s rows appear instantly with zero fade tracking. Once visible row fades finish (`180 ms`), `motion` returns `false` so quiet or paused logs schedule zero extra frames.
- **Cadence and pause.** Mirror (~1 Hz) and separate hover/focus tooltip (≤4 Hz) updates share `CadenceGate` and `TrailingFlushScheduler`, resetting inactive gates, cancelling timers on unmount, and flushing immediately on pause.

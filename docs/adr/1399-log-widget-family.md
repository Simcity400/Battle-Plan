# Log widget family

Log widgets (chronological feeds, histories, and ledgers) share one stateless tail contract on the native side and one canvas-painted worker family on the UI side, upholding the five family properties in [ADR 1398](1398-widget-family-contract.md) and the five-state value contract in [ADR 1397](1397-family-value-contract.md).

## Native tail contract

Every log widget subscribes to a stateless, exact `tail(hour, params, limit)` dated panel returning one shared `LogTailReply` envelope (`columns`, `baseOrdinal`, `firstOrdinal`, `total`, newest-first `rows`, exact `facetTotals`, `missing`, and `warnings`) without touching `dashboard-follow::host`.

- **Exactness and statelessness.** `Reader::tail` and `Reader::total` share one `slice` core with `Reader::page` in `crates/dashboard-query/src/log.rs`. `LogTailReply` omits the moving query `hour` (the `PNL2` frame carries it), so `dashboard-follow`'s `panel::product::Delivery` automatically emits zero-byte `STANDS` updates on quiet hours. Multi-facet country filters (`country|receiver`) count and emit each event once under its canonical first matching group across rows, totals, ordinals, and counts. Dated membership runs and unobserved spans are applied per row hour natively rather than flattened to a static tag set.
- **Exact facet totals.** `countFacets` computes exact counts up to `hour` (including the current partial bin), eliminating stale bin-rounded counters such as `division-log`'s vanished diagnostic. Facet summary pills derive complete, partial (with reason), or not-recorded state from coverage over their own counting interval.
- **Inline enrichment and bounded caches.** Domain tail products (`division-log-tail`, `market-ledger-tail`) share one `enrich_rows` path with their paged counterparts (`division-log`, `market-ledger`). Equipment variant names resolve per `(run, row hour, variant)` rather than once per batch. `PlaceCache` and `VariantNameCache` are `Source`-scoped, bounded with FIFO eviction, cleared in `forget`, and verified equal to uncached resolution.
- **Bounded work.** `limit` (`K`) is sized from the viewport height (`tailLimitForViewport`, floor 64 rows). `log::Reader` scans only facet columns into a bounded immutable-bucket index cache and decodes full columns only for the `K` cut rows (`log_rows_at`), and branch table-status coverage is indexed once per `(source, revision, branch, table)`, so per-step work depends on `K` rather than bucket density or elapsed campaign length.

## UI log family (`ui/src/families/log/`)

- **Shared host core.** `FamilyLogHost` builds on `ui/src/families/host/` (the same host core used by the table family): independent per-mount placement identity (so inline drills and popouts never share a canvas, binding, or audit reader), scroll geometry, `WidgetState` body states with stream vs local retries rendered inside the viewport, separate hover and focus tooltip channels (`P` pins the focused tooltip), live appearance/theme invalidation while paused, `FamilyArtLoader` bounded icon loading, and `AuditSnapshotStore` pinning and audit-ready acknowledgement.
- **One painted-model audit.** Each log widget registers one pure projection `(sources, hour, options) => LogModel` with `registerLogProjection`. Both the worker lane (`familyLogLaneView`, only while audit capture is active) and the exact-read verifier (`FamilyLogHost`) serialise the painted model directly via `canonicalAuditData` (`deriveLogAuditRows`): summary totals, facet pill counts/states/reasons, frozen new-row count, empty states, month headings, gap rows, and every visible row's bands, values, states, reasons, raw magnitudes, art, and flag identities (excluding tooltip date lines). Frozen and scrolled pages are audited against the exact frozen hour and page offset captured under the picture's `auditId`.
- **Host-owned playback discipline.** `FamilyLogHost` paints onto a worker-owned `OffscreenCanvas` (row layout implemented; card layout declared as an extension point). Facet summary pills, the frozen new-row badge, and the `role="listbox"` accessibility mirror (`aria-activedescendant`, full spoken cells and gap reasons, identity-reconciled focus so `Enter` never activates row 0 after eviction) update in the DOM without triggering React commits (`0` commits during playback), and `install()` performs zero DOM layout or style reads. `useShownHour()` reports `null` before first paint and the installed model's `hour` thereafter.
- **Row entry fade-in (owner decision).** Newly entered rows fade in during the worker's single canvas pass when playback speed is `<= 48` game h/s and `prefers-reduced-motion: reduce` is not active (no user setting). Above `48` h/s rows appear instantly with zero fade tracking or allocation cost. Once visible row fades finish (180 ms), `motion` returns `false` so quiet or paused logs schedule zero extra frames.
- **Scroll-back and jump to latest (owner decision).** Scrolling away from the top—whether playing or paused—freezes the installed picture's hour and snapshot without shifting the user's rows and mounts `Jump to latest` (updating `{N} new · Jump to latest` via an installed DOM field with zero React commits). Scroll-page fetches track the loaded ordinal interval `[offset, offset + loadedCount)` and load any uncovered viewport or keyboard target (including offset `0`), bound to a frozen-view generation that invalidates on filter, branch, or time-mode change and surfaces page load failures with a `Retry` action. Re-locking at top or clicking `Jump to latest` returns to live tail. Pausing at the top fetches nothing.
- **Cadence and pause.** Mirror (~1 Hz) and separate hover/focus tooltip (≤4 Hz) updates share `CadenceGate` and `TrailingFlushScheduler` from `ui/src/families/cadence.ts`, resetting inactive gates so quiet widgets are never woken, cancelling timers on unmount, and flushing immediately on pause.
- **Widget standard visuals.** Row heights follow R6 (`28/22 px` single-line, `44/36 px` two-line); missing/unrecorded values render hatched placeholders (`drawFormattedValue`) and never silently default to zero or another category; recording gaps render inline as hatched `Not recorded · {span}` rows (R13); filter chips occupy one horizontally scrollable row (R14); tooltips carry a display-time date subtitle (T1) and pin the focused row with `P` (T10).

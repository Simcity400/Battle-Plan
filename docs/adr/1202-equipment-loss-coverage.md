# 1202. Keep equipment loss coverage independent of measured amounts

The equipment-losses history is loaded per selection, chart view and requested exact hour. A followed view loads the branch once and paints from followed cells. A failed followed cell keeps the leaf's history and identifies the unread cause at the head. Attaching a head value never generates intermediate observations.

Totals start again after a gap. Cumulative views use the retained stretch that contains the selected hour, regardless of the follow frame's trailing window. A dated range subtracts the total immediately before its start so the first retained read is counted. Missing land logging cannot be repaired by rejoining an army later. The destruction legend describes which drain intervals were observed, independently of whether a later cumulative value is incomplete. Coverage counts include both endpoints and treat omitted hours as unknown. Different limitations can overlap.

An independently measured subtotal retains its exact fixed-point digits even when a missing cause prevents a complete total. Plotting and ordering may use approximate numeric values. Amount labels use the exact integer where the reply supplied one, including beyond JavaScript's safe integer range.

Sunk ships are not part of the followed totals series. A repeated listing is counted only up to the maximum occurrence of that signature in one read and is placed at the ship's sinking hour. Keyboard navigation merges these hours with declared-series steps and keeps the first hour in the visible window as a stop.

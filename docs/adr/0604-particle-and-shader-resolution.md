# Resolve particle and shader inputs by content identity

Particle resolution follows entity event, `pdxparticle` object and particle type. Startup interface files register first. Ordinary interface and graphics traversal retains files-before-subdirectories and bytewise order, and particle blocks are looked up by their internal names rather than by an inferred filename. Sprite-only declarations contribute no particle objects. Last exact object-name registration wins even if a duplicate consumes an ordinal. Unsettled block duplicates are refused under the affected particle name. Carrier data retains subsystem identity through the shader so sharing a texture cannot merge passes or constant packets. Hidden subsystems contribute zero capacity. Visible subsystems require an authored capacity, and recursively multiply child capacity by the parent count. An invalid descriptor or scale refuses the affected object without consuming unrelated catalogue results. The reverse flag changes only the sort key order. Unknown order assignments keep the previous value. Tile counts are signed and paths retain the native byte limits. Trail and no-billboard options append in that order to the same particle effect source.

Shader effects replace the first exact `.lua` suffix occurrence with `.shader` and keep path-byte identity when opening the file and includes. Include paths are relative to `gfx/FX/` and each exact include contributes stage declarations once in postorder, with authored nesting held in an explicit stack. Techniques and states come from the root. Missing declarations remain distinguishable from malformed or unreadable files, and a present root requires its backend header. Identity covers the root, ordered include identities and missing entries, and backend header. Files outside recorded coverage carry diagnostics. Lossy text is only a display or line-directive label.

The native shader reader consumes raw `[[...]]` code, declaration names up to their first NUL, and token sequences even where the source omits `=`. Declaration names retain line feeds, while references use the stored-string replacement. Lookup finds the first ASCII case-insensitive match and the common stage's entry precedes its stage-specific entry. Code assembly uses the caller and technique defines, the content header, the samplers, buffers, structures and code in that order, then the selected entry. The second constant-buffer register operand belongs to DX9. The sampler array takes common-stage declarations followed by pixel-stage declarations by physical index. Empty slots keep the previous draw's binding. DX11 uses wrap for W regardless of its null sampler, point filtering for authored `None`, and a cube texture only for the cube kind. Invalid array growth is refused. Render states preserve native defaults and ordered overwrites, and the GUI sprite path omits depth and raster states. Alpha test and alpha-to-coverage share a stored flag which that lowering does not consult.

Static float extraction accepts only one declaration of a plain literal outside preprocessor conditionals, with no macro or caller/technique define that can change it. A statement crossed by a conditional is conditional. Refuse uncertain values rather than guessing what the compiled shader sees.

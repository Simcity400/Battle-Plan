# 1105. Resolve map counter resources and geometry before drawing

## Decision

Use the content's resolved windows, their hierarchy and declaration order, and the province's authored anchor inputs. Draw in interface pixels. Sort by signed content priority, then icon ordinal and child slot. A grouped stack uses the priority of its own grouping level. An ungrouped hovered stack increases its own priority by five. Rank declaration indexes into distinct child slots so changing texture pages cannot reorder the children. Refuse an icon if the layer key cannot hold all its slots. Base and port icons share one ordinal sequence. Land combat, naval combat and retained result icons share another, since content may give those icon types equal priorities. A naval combat window and its grid items occupy the same ordinal.

## Authored layout

- Keep the stored one-based strip frames distinct from zero-based draw indexes. A missing authored frame selects the caller's default. Text uses its authored alignment and maximum width. A child absent from the window draws nothing. Unsupported declared child forms and missing templates are reported where reached. A refusal of a railway-gun layout does not withhold the land layout. Unit action children require the independently resolved sprite and supported positive frame. A refused action leaves the rest of the plate intact.
- A rail gun shares land sources and columns but has its own plate, omits the organisation bar, and uses its own location and action inputs. A land counter's authored ability grid places a separate item for each ability whose sprite resolves. An absent or unsupported grid, item or sprite draws no item. The content's grid step sets item spacing. An item-relative orientation can measure from the item's centre. Sprite centring moves the drawable around the resulting point separately.
- The no-intel type sprite has distinct pictorial and NATO frames. A hidden count shows a question mark. A coarse counter shows the allegiance-tinted background in frame three, its count or question mark, and the roster owner's medium flag. The coarse pass hides the other detailed children it owns while leaving low-supply and ideology controls alone. Detailed flags use a positive expeditionary owner when present, otherwise the roster owner. The controller does not select either flag. Resolve the recorded flag candidate order using the original or cosmetic identity and ruling group. Only a drawn counter whose candidates fail gets its recorded flag limitation.
- Compute visible ratios on the recorded fixed-point scale before converting to draw coordinates. A quarter-turn swaps a bar's drawable dimensions while retaining its authored position and centre adjustment. Orders-group markers use recorded own or inherited colour. A land combat's authored terrain selects its background. It compares side survival estimates using a ten-percent band and distinguishes a missing estimate (unknown white) from no intel (wedge hidden). A facility replaces its button sprite using the building's first specialization token.

## Assets

- The native registry reads the content stack's GUI files independently of the legacy layout reader. Acquire all authored sprites, fonts, effects and their inline localized resources, including the programmatically selected sprites. Share the localized tooltip inventory and the viewport-specific templates with other native windows. Compile effects with the map bitmap dimensions and decode using the viewer's force-power-of-two texture setting. Loading a base or ability sprite never depends on one hour's membership. Attribute omitted art to the reached child or kind.
- Keep texture IDs stable by appending sheets in the serial load order after parallel decoding. Append sprites only reached by recorded operands after the ordinary counter resources, including the fallback portrait and rocket-site glyph. The flag registry does not name each cell's texture. Resolve small, medium and separately masked flag sets through the content stack. Apply the cloth overlay to medium flags only, truncating the signed per-channel blend delta toward zero and keeping the flag's alpha. An unreadable visual overlay can fall back to the recording's content overlay with a warning. Without a readable overlay the medium atlas still builds. Warm the flag candidates for every counter size before drawing and acquire any reached candidate that was not warmed. Portraits decode on first draw. A queued portrait draws nothing for that frame, while an unresolved fallback descriptor can use the unknown leader artwork. Operative portraits take their first frame with the icon's mask.
- Use the submitted batch for a diagnostic census so it reflects the exact draw order, frames and rectangles. Frames in the census are zero-based. Its interface rectangles convert to device coordinates with the draw scale. Reuse candidate comparisons across frames only when their exact tags, flag tags and ruling groups agree.

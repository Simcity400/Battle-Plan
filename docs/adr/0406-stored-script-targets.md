# Preserve saved global target identities and order

Capture the saved global target registry independently of transient event-chain or description targets. Loading appends records, erasure shifts them, and reset clears the array. A change of player or ownership leaves the retained selectors intact. A retired character can still resolve while it exists. Destruction can leave a reference present in a target after the referenced object stops resolving.

Capture retains the array order, the selector stored in each record, all nine reference-liveness flags, the region and combatant presence flags, and whether the saved name was omitted. Observe every reference even if a context, variable, or earlier reference wins selection. The unit reference resolves its whole object. A secondary base without an object is null. The leader uses the direct leader when set and otherwise a fallback reference that the ordinary leader table does not capture. A null leader identity withholds the leader consumer for that row. Off-thread sizing uses observed headers and string lengths without a country multiplier.

Names are interned case-sensitively. ID zero can still refer to a string in the live registry, while a save omits its name. Once a nonempty registry contains aliases caused by wrapping 16-bit IDs, the reverse name vector cannot identify which alias a stored record meant. Withhold that registry by name. An empty registry remains available. Variable storage is a separate Robin Hood table with one-based probe distances for occupied nodes and zero for empty nodes. It preserves signed 64-bit values.

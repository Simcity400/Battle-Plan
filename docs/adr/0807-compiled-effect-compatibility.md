# 0807. Compile content-selected effects through the pinned renderer pipeline

Gamefile loading assembles effect source from the recorded mod stack and the viewer's presentation layers. The shader library parses a source once in its content scope and compiles selected techniques lazily. A visual replacement must supply every technique the recorded effect compiles with the same define set. A caller variant preserves library globals before caller defines and applies the same acceptance check. Stable variant handles reuse pipelines across frames. A missing technique retains native state, while a declared technique that fails compilation is refused. Offline verification can supply precompiled programs.

The DXC version shipped beside the executable is part of the persistent cache ABI. Other builds may differ in SPIR-V support or output. The effect name chooses no substitute program. HLSL 2016 semantics are used for compatibility with legacy D3D compilation. DXC and naga keep the renderer's clip-space orientation so translation does not invert the vertical axis a second time. Vertex output and pixel input registers must have matching declaration order, with an input prefix allowed. Stage interfaces and native register namespaces remain separate. Any consumable register the content did not declare is refused because a previous draw could otherwise leave it bound.

Map-derived global defines match the renderer's texture decode setting. Their order differs with power-of-two texture decoding enabled, and dimension scaling uses the renderer's texture limit and native truncation before calculating the next power of two. Decimal formatting uses three digits with round-to-even. Treat that as content compilation input for GUI effects as well as map effects.

Constant-block change detection follows the values actually used after dead-code elimination. It excludes padding, tracks projected components when those are the only uses, and conservatively includes all uniform bytes when pointer parameters can alias them. Bytes outside a bound physical buffer read zero. In-range consumed bytes that were not initialized cause a refusal. Settlement analysis runs before numeric lowering so it can recognize authored time intrinsics, distinguish clamped elapsed time from continuing clock dependence, and combine both stages conservatively. Numeric lowering tests NaN with integer predicates because finite-math optimization can invalidate floating-point self-inequality tests.

Raw shader text is never allowed to introduce filesystem reads or probes. The content resolver controls includes. A defensive scan can reject or neutralize raw include directives and path-probing builtins without flattening conditional branches. It uses a compiler-compatible logical view of line splices but preserves the original source bytes submitted to DXC and restores original source line numbering after its prologue. If lexer state could diverge across a raw diagnostic directive or uncertain input, refuse the source rather than guessing. Tests cover bare carriage returns, splices, whitespace, comment and literal boundaries, and directives in conditional branches. Keep the persistent-cache regression cold on its first run and warm on its second, where it must not discover a compiler. The GUI sweep selects effect families that use the GUI renderer's constant and geometry interface.

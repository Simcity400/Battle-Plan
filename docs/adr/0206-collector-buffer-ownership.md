# 0206. Keep collector capacity with its owner until publication or retirement

Capture workers use monotonic census sizing within an attachment. A freshly sized country buffer includes headroom so the normal pressure threshold does not immediately double it. Frame capacity merges use an exhaustive field pattern so a newly added dimension cannot silently miss growth. A failed table publishes no partial exact rows. Its observed complete-row pressure and truncated demand remain available to grow all recycled buffers off-thread. Advisory growth reserves every vector before changing any logical length and does not invoke the terminal allocation callback.

Raw accounting follows allocation ownership. Moving one payload from the pool through observation, the queue and decoding to retirement keeps its charge intact. Replacing or releasing it adjusts only that owner's charge. Even a logically empty retained index counts when it still owns capacity. Vector accounting measures reserved element bytes rather than estimating allocator rounding.

Observer logs give registered threads dedicated producer lanes. The shared lane covers further producers, which can reserve a slot and publish its complete payload without waiting for the consumer. If the ring is full or a byte span exceeds the fixed stride, a producer requests its own spill node. Failed allocation is counted along with the original demand. Ring space is recovered only over a released prefix. A reservation dropped before publication becomes a void slot or frees its unlinked spill node, so an abandoned reservation cannot permanently block the ring. Spilled records are taken by a single consumer. If its staging arena cannot grow, the taken records come back to the caller so the failure retains its exact lost demand.

Native allocations commonly place same-sized objects at regular address intervals. A simpler multiplicative hash left some of those strides concentrated in a few watch slots. The SplitMix64 finalizer spreads every address bit into the result before selecting the table's top bits. It is pure arithmetic on an observer path, and the one-slot case returns zero without shifting by a whole machine word. Synthetic tests check the distribution over regular strides.

`FirstReason::record` publishes the winning static string's address before releasing its length. `FirstReason::get` acquires the length before reconstructing the string, so a losing caller cannot supply its own length and a partial publication yields no read. In `shared_lane`, only the consumer uses `Taken` and it accesses the list under its lock. A `SpillStack` node is producer-owned until its release push, then belongs to the consumer that takes it. This ownership split is what permits sharing the raw-node stack without concurrent producer access to taken nodes.

# 0701. Keep one authenticated wing census with independent projections

Read the strategic-air manager's primary identity and walk the canonical owner roster, with pool order followed by wing order. Bound nonempty rosters, retain the reserved slot-zero owner when authenticated, and preserve a wing occurrence's ordinal even if a consumer cannot fit it. Split parts use the owner's canonical slots. A missing manager refuses the wing census but still supplies score's independent zero witness through the first part. Retain full type and ID pairs. A single zero word is not a null handle. The primary wing contains the mission, pool backlink, stat fields and name plus a separately authenticated secondary subobject. Resolve the positive country override before the raw pool owner and the wing's base override before the assigned pool base.

Keep native signed plane, acquired manpower, accident, experience and relocation values. The source can clamp acquired manpower after losses without the recorder imposing another bound. Current progress and total relocation distance are distinct fixed-point values. Admission uses the veto and the signed counter and limit. Preserve the independent raid range and fuel base operands. Tactical orders-group lookup runs only for the tactical mission. A readable null group has an explicit null reference, while an unauthenticated group withholds only that field. Only a readable null region represents an absent mission region. Read the selected cached mission record without recomputing it. A valid selector names one mission bit or no mission, and the designated default index is distinct from an invalid index.

Keep the map, full-source, naval and score outcomes independent. The same visitor can feed independently admitted consumers, sharing copied fields and the same-pass owner and wing identities. A map or source storage shortage must not change the other consumers' ordinals or admissions. Preserve pool definition index and null status, full raid reference and authenticated liveness, optional mission stat, and certified replacement and map flags with their field-local failures. Pointers are callback context and never enter the recording. Fuel and map-flag extensions owned by the worker do not cause extra reads on the synchronous fallback. A tactical consumer can join the transient group discovery pointer to the current authenticated group census.

Queue bounded roster steps and replay them in serial order. Gather wing row fields and stored-name headers together when requested. Read only reachable spans, including a minimal projection when only identity and score are requested. Adjacent eligibility words use one span. A completed gather prefix is valid, while its failed wing and remaining queued wings read serially. A refused pointer run also falls back once. The first serial failure, the owning slot's witness and independent capacity outcomes retain their order. A later prefetched owner refusal cannot escape an earlier ending wing. A persistent fault therefore gives the per-object reference result. A first-touch fault can recover on the serial retry. Prefetch hints never change observation order or outcomes.

Authenticate strategic regions once per pass, including their paired identities and ID, and start the memo fresh next time. Read copied string headers at their original admission points. Size names using headers without reading their payload and then copy the retained bytes and terminator once. A header refusal can withhold the name without discarding the authenticated wing row. A later heap terminator failure is a string fault rather than a gathered row retry. Equipment extensions keep raw occurrences and variant IDs in vector order, using the authenticated embedded equipment pool. Variant discovery pointers belong only to that observation. The saved replacement setting has two independent writers and is admitted under its own witness.

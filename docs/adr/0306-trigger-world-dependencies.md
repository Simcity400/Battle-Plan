# Keep trigger query reuse exact with recorded inputs and lazy lookups

The world represents one recorded hour. Build indexes only when an operand asks for them and join raw references through that hour's `CountryLinks`. Use the last country row for a canonical slot and the recorded physical order for iterators. Recorded content facts, including the movement map and DLC roster, are acquired separately. A static content input that a query never reaches must not prevent the query from answering.

## Completeness and indexing

- The strict world constructor requires complete links, countries, provinces and states for its callers. The lenient constructor retains each table's failure independently. A known row in a partial table can answer a selective lookup. Its absent row remains unknown when the partial table could contain it. An invalid walked row is refused where reached, while unsupported layout is reported separately from acquisition gaps.
- An existential query can answer true from one known matching contributor. A negative result needs proof that no unresolved contributor could match. Track unresolved raw countries separately from known linked rows. Preserve the first relevant refusal in native table order, even when a faster keyed path reads only one country's range. Only use contiguous country ranges when sorted keys justify them, with a scan for other rows. The tests compare indexed verdicts and specific refusals against independent scans.
- Maintain native ordering when it affects results. State memberships can differ from authored content. Only a matching membership may use content province order. A current recording's missing ordered country roster remains unavailable, while older recordings can derive order-independent membership where the consumer admits it. A feature using native owned-state count or order must read the appropriate recorded field.
- Country-tag identity checks raw references first, then compare nonzero canonical aliases. Country presence requires an owned state, independently of whether content defines the tag. Dynamic modifier targets select the positive country first, then a positive state, then the first unscoped entry. An unresolved country can affect first-entry selection. Idea checks distinguish advisor tokens and faction hires from ordinary active idea entries. The research query selects the first matching definition name and then the recorded completion classifier. An unseen completed definition can prevent proving absence.
- Naval invasion checks use positive and reserved country theatre rosters independently. In a theatre, only regular groups on its orders roster qualify. Visit the primary invasion roots and their successors. A certified empty group reads no order payload. A possibly matching positive theatre can withhold a negative result even when the known group has no matching order.
- The lexer folds ASCII uppercase only. The compact index stores each folded literal once and keeps its hash table at most half full. An ambiguous folded spelling is refused. Keep a thread's two most recently read folds by decoded lexical view identity. A separate literal lookup preserves last-row wins for unordered or duplicate decoded tokens, including zero.

## Reuse validity

An evaluation records the tables and query operands it reaches on every call, including calls through a previously built index. Reuse requires the same result from those inputs. Declare every reached table, field, owner range and nested lookup in the query's dependence. Keep acquisition freshness and clock metadata separate from row-value comparisons. A query reading a raw-country range also depends on link changes that could make another row relevant. Check mode reruns every admitted query and compares its answer, and the tests change only rows outside declared dependencies to validate that those changes can be ignored.

Supported geography predicates use the static movement map's coastal flag and the current recorded controller's resource overrides where required. Core and claim checks use the recorded vectors and accept raw or canonical aliases, with an unavailable claims field withheld by name. The service reads invasion preparation operands and their content define as inputs, so a previously built preparation index still participates in validation when the value advances.

An owned and controlled state must have provinces and its recorded owner must be its controller. Country character queries retain the collected country and ordinal order, with a null character record preserved as an empty slot. Invasion preparation uses the wrapped product of its speed and days factors, then converts the whole day count to hours. Keep the whole-hour truncation of its recorded progress before dividing by the required hours to produce fixed5. Absent bonuses add zero, and zero required hours yield zero preparation.

# Preserve acquired stability operands and ambiguous source labels

Capture stability, war support and maximum command power operands for replay, including tracked modifier entries and their source labels. Stability uses the base, war and ruling-party terms, propaganda penalty, effective modifier and stored coastal adjustment before loaded bounds. War support includes offensive and defensive war terms, world tension, the recorded bombing, interception, hero, convoy and propaganda terms and the effective modifier. The mode-one war predicate also checks the counterpart's hosting word. The interception contribution sums the relevant column of the stored ring with its saturation rule. Propaganda penalties are Q15 and their saved fixed-point conversion truncates toward zero. The define vector follows the recording field order and uses fixed5 except for the Q15 interception scale. Command-power getter values belong to the command-power row so there is one reader for each value. Consumers join that row at the same frame and subtract allocated command power where the game does. Pair modifier children in rebuild order. Filter out empty signatures that cannot contribute tracked values before comparing the leftmost and rightmost order-preserving assignments. Attribute a source only when both assignments agree. An unsupported or ambiguous child retains its display text and contribution. Digest comparisons can reject early, but accepted unscaled pairs require exact ordered nonzero entries and, if copied by the child, exact display bytes. A scaled static instead compares its display and nonzero key set because its values change with scale. Conditional static modifiers are admitted only when a native activation witness proves they are active for that country and their values are unscaled (sent attaché relation, mode-zero peace or war status, or the sunk-pride active flag); scaled conditional statics (including war-support-during-war, whose rebuild-time scaled values are unverified and vanish at full war support) and any static whose witness site is withheld or whose witness read fails or is inactive are omitted without tainting table withholding or failing the country read, while a verified sent attaché relation still prevails over malformed attaché siblings in any order, so unverified observed lines stay unpaired with their observed display and contribution. An idea reached through a secondary base needs its own primary identity before reading its modifier. Idea labels are generated with the child, while leaders can copy their character name. Enabled dynamic modifiers contribute their constant and evaluated parts separately. The evaluated part sums entries by key and requires the stored name, so a language change can leave that part unpaired. Resolve tracked keys by installed name and keep them only while the same modifier-definition header can be observed. An unreadable header is a failure. The shared context digest includes tracked definitions, loaded constants, language and bound statics, while each country read takes up the current world-tension drift. The language reader treats a null root or string as empty. Prepare both country and shared text outside the callback and take each original acquisition before using it. Child reads reobserve the tree header to keep the changed-tree check live. A country whose lines do not fit emits none of those lines and returns the size needed for retry. Diagnostic timing uses the job's existing endpoint reads where possible and stays separate from the ordinary walker. Batch only the exact operands used by the serial readers and retain only complete batches. The same address and length reuse the first observation. A speculative failure discards its partial bytes and lets the authoritative readers proceed once in their own order, so a persistent failure and a recovered one-shot fault both keep the serial walk's meaning. A failed country-local batch disables further speculation for that country. Earlier successes stand. A failed authoritative observation can be shared across country walks for the same admitted static and hour. Clear shared static observations at every new hour, including skipped or failed hours and loads. A country-local observation takes precedence. Without room for optional memo retention, proceed through the ordinary read and keep no partial bytes.

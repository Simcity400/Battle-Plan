# 0906. Preserve modifier sources without repeating shared trees

Tree sources use table identities from tables the caller already has. A naval side normally visits country, weather, terrain and commander in native order. Screening correction uses country alone and the early defender term uses the opposing commander. Ship escape and carrier sortie visit the recorded weapon context, excluding the scopes that have no printable tree. The capture decides region and commander admission. An admitted source in a complete table without a row has no printable contribution and a zero root. A missing table cannot certify that. Capture can carry a country or commander tree across a quiet hour while writer observation proves it unchanged. Other reached kinds are refreshed with their combat.

Preserve the complete printable preorder at the game's requested depth. Keep nonzero leaves and their ancestors, with display bytes only for leaves. If all its children prune, keep one zero child so an internal root stays internal. Retain a genuine childless root's value and name. Root values still affect convoy escape and side totals. A key with zero root and no printable contribution can be omitted. Validate strictly ascending keys and complete trees. Source ordinals can recreate native traversal after identity sorting. A ship joins by combat, side and battle slot. The dedicated side slot sentinel retains the side's source order instead.

Keep reserve chance breakdowns only for the sources the hourly reserve set reaches. Country sources retain the raw link and commander sources retain the full handle and selected block kind. Read the commander's display name only for a nonzero root, which is the condition for showing its line. The attrition source packet keeps its independent order, depth and scaling. A local tree read failure keeps its key and reason without discarding other roots or scalar inputs. Native display bytes are usable in the recorded language. Legacy reserve and naval breakdowns retain framing for older files.

Power balance stores source occurrences in order, including repeats and empty sources. Its description derives from those static named modifiers and recorded content. Its older cached trees and diagnostic samples are witnesses only, and both must exist together. Naval diagnostic oracle rows similarly record the reached occurrence afresh and are empty in production. Their identity allows comparison with the shared captured tree. Production modifiers keep one printable tree per reached root and retain refusal separately for each root.

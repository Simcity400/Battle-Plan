# 0401. Record scope graphs as occurrence-local identities

An event's scope country, actor and enclosing recipient are distinct. Zero scope country is valid. Signed state identifiers select state scope only when positive. The ability operand uses the known scope layout. Saved and tooltip targets remain optional. Packed object references keep native order and both words without resolving unrelated objects. Unsupported pointer-owned operands carry explicit demands, while absent links remain absent.

Copy only the graph reachable from the named occurrence. The acquisition follows native ROOT, FROM and PREV order and assigns ids at first encounter. Shared and self-linked nodes therefore retain identity without retaining any address. A read failure or insufficient scratch capacity withholds the graph rather than publishing its prefix. Preparing a large graph does not make smaller occurrences clear its retained capacity because the acquisition releases only the index slots it used.

An incoming diplomatic action wrapper and its action body have different identities. The wrapper receives a packed reference after construction starts at its default invalid reference. The body has no established concrete class witness. Preserve the full raw action word because the serialized initiator-relevance byte is only its low part and the save's action type is separate. Positive recipient references can be resolved as recorded country references. Keep both dates' bits without assuming signedness. Aircraft participant vectors refresh on the named diplomacy boundaries, with loads handled as discontinuities. Observation selects changed countries without executing a game function.

# 1102. Reconstruct naval environment and weapon displays from applicable operands

The current gun, torpedo and depth-charge totals use current combat member operands. Historical damage belongs to the hover and does not supply current attack. Use recorded formation flags and separate ship and convoy references. The modifier sum follows the captured definition's feature eligibility and per-source clamp. Doctrine weighting, weather adjustment, critical severity and maximum headquarters influence contribute through their own branches. Some raw weapon adjusters and relation operands are not additive. The selected leader's scopes depend on the call site. For descriptions, doctrine weight and critical count scale the lines, while the country factor and critical severity change the numeric result alone. Equal headquarters contributions retain the first influence and nonpositive ones print no support line.

Live convoy weapon values come from equipment fields. The recorded convoy operands do not identify the selected equipment and weapon value. The display can still give a whole-number result if the full possible convoy interval, including zero, yields the same truncated total after adding ship attack. Keep fixed-point values until the last truncation, including possible negative convoy attack. Refuse the logic by name when differing endpoints can change the visible value or when content leaves the bounds unknown.

Derive the convoy interval through the same content database used elsewhere and widen it over the hour's recorded convoy variants (`VariantDefinitions`, `LexicalTokens`, and lazily `VariantUpgrades`, `VariantModules`, and `VariantBonusSnapshots` when reconstruction is needed) so applied design-team, direct, named and unresolved bonuses as well as global variant upgrades (including level-zero upgrades whose average count affects the denominator) are reflected whenever convoys participate; named-bonus convoy variants read their recorded final `unresolved_stats` cache first without demanding reconstruction tables. Keep layer, file and generated registration order, archetype duplicates and default module categories. A convoy's effective type comes from its own type or its archetype's, plus module additions. Each field's reader consumes its own value or skips an unread block, so a nested unknown weapon name cannot affect the enclosing equipment. An archetype copies the current stat block, module stat multipliers and reliability-scaled stat terms in load order while leaving the type's own recognized `upgrades` list intact (reporting unknown and duplicate upgrade entries as misreads), and later fields combine or overwrite them; redefining an equipment clears all three multiplier and reliability-scaling blocks before reading the new definition. A parent forwards the archetype identity when unset without copying stats or stat multiplier blocks. Any present forbidden stat in `scaled_by_reliability` (`reliability`, `reliability_factor`, `carrier_size`, `build_cost_ic`), including explicit zero or terms folding to zero, is reported and zeroed at load time. Convoy weapon bounds evaluate optional default modules jointly by multiplicity when modules carry correlated additive/average and multiplicative terms (evaluating unit-count coupled additive+average and pure average-only default modules by fixed count with sign-split Lagrangian branch-and-bound truncation bounds in the fallback alongside empty selections, and folding purely additive, purely multiplicative, and ratio-grouped pure average-only default modules independently via exact prefix/suffix average extrema, projected through module stat multipliers) together with the clamped reliability interval `[0, 1]` for reliability-scaled weapon stats using overflow-checked interval arithmetic, withholding by name any convoy that can overflow fixed-point arithmetic, admits weapon-modifying upgrades across its archetype chain, lacks complete recorded variant tables or design state when convoys participate, or defines module slots that combine with dynamic stat terms or directly or transitively admit weapon-modifying modules. Ship-only battles with zero convoys return the truncated ship total directly without consulting the convoy bound. Case-insensitive module slots skip a repeated or inherited slot's block. Self-links terminate while true cycles, unsupported values and traces that lose reader alignment are reported as unknown.

Night is suppressed above the recorded speed threshold while playback is running. Viewer pause overrides that suppression. A province's whole naval combat vector determines the engaged picture prefix, and ambiguity can be ignored only when both possible prefixes resolve to the same picture. Keep the battle prefix on the generic water fallback and preserve the environment picture's own weather priority. Read weather, province and night modifiers from the selected naval fight's joined ship context rather than taking the strategic region name as terrain. Match authored sprite candidates and name unavailable ones.

The region grid visits nonzero custom sea modifiers in template order before weather flags. Use a live regional combat's values where available, or the weather row's values otherwise. Both custom entries and weather entries require a category-one effect and a localized icon. Parse that localization as a sprite name followed by an optional colon and signed one-based frame prefix, defaulting to frame one. An absent key stays visible by its own bytes and an empty localization sets nothing. Keep the weather heading and joined weather names, the no-weather value, the newline boundaries between terrain and weather and night, and the localized entry name before its static modifier body.

The opposing silhouette groups forward ships and convoys in native category priority, rounds each group's result, and sums with wrapping integer arithmetic. The screen term scales with capital silhouette and the authored reduction factor, using the guarded fixed-point division and upward rounding. A submarine outcome that does not depend on the equipment predicate can skip that read. The carrier penalty's laurel remains visible at half opacity without a penalty and uses the same result for its hover. Pride resolves through the task force's roster owner and the pride ship's logical combat side. The bonus is available to the qualifying country's task forces on that side.

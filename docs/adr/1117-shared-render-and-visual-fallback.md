# Share the scene and distinguish visual-mod failure from recording limits

Window frames and headless dumps draw the same scene and negotiate the same adapter features. A dump checks adapter support before loading the document, uses complete placed models and the hour’s own rows, and writes an RGBA PNG from the rendered texture. The unverified-content banner follows the resulting picture. Demilitarized zones are a named dump option because their flag is absent from the recording. The headless path warms pipeline caches before measuring steady-state work. It separately measures command encoding and the drain through GPU completion because a headless dump has no swap chain. Allocation retries leave the requested clocks unchanged. Settling can advance effects before the capture, while profiling and model-history diagnostics run after the PNG because some effects cannot be rewound. Parity diagnostics can inspect ungraded output before PNG quantization.

The viewer and dashboard maps share an affinity-sized worker pool that reserves threads for the game, driver and display. A full queue yields an admission refusal; the caller can try the next frame. Retired allocations are freed off the display’s path. Display warnings come from the drawn layers and the recording tables, with named refusals for missing layers. A nested ship warning is shown only while the units layer draws it.

Visual-mod fallback belongs to the exact recording source, recording revision and visual-mod revision. Content may be shown or reused only while its build stamp agrees with that key’s current decision. A new refusal with mods starts a probe without them. The probe measures as many settled frames as the modded view reached, counting only frames that drew the requested hour without errors or queued decoding. If the recording alone shows every failure, the mods return and those named failures are treated as intrinsic to the recording. Otherwise the unmodded view remains after the exposure and keeps watching. A later observation of every failure still restores the mods. All reports from a frame reduce together, so observing the same failure on one map wins over another map finishing the probe that frame. Reports from an older content build or a different recording or revision have no effect.

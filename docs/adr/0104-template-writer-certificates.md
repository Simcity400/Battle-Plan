# Carry division template data under writer certificates

The template census reads a certified template only as far as its identity. Its core certificate covers the template object, its owner and the owner's local-definition writer stamp. A template references global definitions and its own country's clones. Another country's clone writer leaves that certificate standing. An object, handle or owner change requires a fresh read even at a reused address. A write during a read or a failed field, name, variant or speed-key read cannot certify those values. A fresh-only observer reads again even under otherwise valid stamps. A command that changes custom icons without naming a template invalidates the complete domain.

Core and extension payloads are held independently. The census can retain their allocations on quiet hours and acquire just the dirty templates. Beginning a country and each template batch takes the stamps before their reads. Certification rejects a payload if its writer moved during acquisition. Settlement consumes owned rows after that check. A roster move renumbers the held settings, including the first-name-match operand, without rereading unchanged payloads. Only a complete census may prune absent templates. Per-visit hints verify the key before use, so a stale or dropped hint costs a lookup. The held rows return in census order. If a duplicate is already published from a held occurrence, its later occurrence cannot overwrite the stored payload during that walk.

The census also supplies country identities and configuration, including readable empty rosters. Observing a split range copies a country's entry so every range starts from the same store. Commit preserves roster order. A reservation failure keeps nothing for that entry. Rereading unchanged values keeps the publication witness stable, while a membership change moves it even for a previously cached country. A refused configuration cannot revive old values and a quiet hour does not retry it. Mandatory configuration and occupation selection retain independent availability. A refusal of optional template model fields keeps the independent counter fields and contributes its named failure.

The icon census supplies the dictionary every hour from the same roster and traversal order. It carries each template's full handle, owner, literal name, fallback name key and override or derived unit type. The dictionary retries only names the icon walk could not supply. Unknown type, a second name refusal or an unavailable parent walk prevents complete publication. A readable empty roster is distinct from an unreadable one. A matching same-frame dictionary lets the icon row certify the display name, including a same-hour rename. A failed or nonmatching dictionary needs a self-contained display override. Quiet publications can share the last witness only when the previous complete unprojected rows match and the required projection is available.

# Paint and navigate the clipped timeline in full-lane coordinates

A full-height spacer represents all lanes. The canvas covers the clipped viewport and overscan while retaining full-timeline layout-pixel coordinates. The parent keeps ownership of scrolling. A large scroll jump paints from the scroll event, before the next frame. Layout measurements run on scrolling, resize and lane changes, so playback frames do not force layout. Read the placed viewport before updating backing dimensions, since resizing clears canvas state. Capture the elements used by observers and cleanup because React can clear their refs before an unmount cleanup. Cache label metrics by font, text and width.

Keep a stable campaign label catalogue so expanding lanes and changing playback rows do not continually refit the left column. Requests for sorted lane names can cover the full catalogue. Flags and visible-lane reads cover what the viewport shows and its margin. The reported view excludes sticky axes and rendering overscan. Rate-limit whole-hour summary requests as the view changes, report its newest range when it settles, and detect a new lane selection even when its count matches.

Pointer and keyboard tooltips resolve the same drawn bar or band. In the left column, describe the holder at the playhead. A keyboard lane is retained by identity through insertion and removal, and a stop retained by identity through zoom. If no stop remains in view, describe that lane's held state at a reached hour in view. Report nothing before playback reaches the view. Scrolling to a selected lane accounts for widget zoom and a sticky axis. Read the full tooltip to assistive technology while requesting rich art only for visible rows. Hold a keyboard tooltip until the pointer moves; do not steal the shared tooltip after another chart takes it. Leave it dismissed on Escape until the pointer moves again.

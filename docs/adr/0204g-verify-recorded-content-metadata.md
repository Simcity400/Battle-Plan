# 0204g. Verify content and layout before publishing metadata

The first clocked hour checks the fixed layout. A settled check is kept for the attachment, and an interrupted check is retried at the next hour. Layout refusals are applied after carry and slice merging so an earlier baseline cannot make the affected table available. The task-force ETA field uses the same check and can be withheld without discarding the verified motion prefix. The fixed-key validation covers unused built-ins because their indices belong to the same contract. The fixed15 token is checked by the save oracle and does not withdraw capture tables.

The loader sizes the roster from live counts and text before installing the callback. Preparation is only capacity evidence. The callback reauthenticates and acquires the current bytes without allocation, normalization or I/O. The worker verifies the successful mount order and descriptor membership against the recorded mod stack and resolves DLC activity under the game's exclusion rules. It keeps capture evidence even if proof of the full stack fails. Diagnostics can name a differing mount by its position. Machine paths belong only in the local diagnostic sidecar and never in the recording identity or spool controls.

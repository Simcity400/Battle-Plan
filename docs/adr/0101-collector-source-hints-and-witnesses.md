# 0101. Keep collector sizing independent of recorded evidence

Capture preparation reads advisory native size hints before attaching and at the relevant demand cadence. It never takes recorded values from a hint. A skipped or failed hint preserves the previous floor. Prompt inputs that fail still request the original retry cadence. Country, province and state indexed registries exclude slot zero, while CountryLinks preserves its zero row. The faction census also provisions observer owners, and the indexed registry and conflict-group floors serve fixed consumers. They use the prompt cadence. Independent state name, faction member, war, air and physical navy capacity walks can wait for the slower census because their worker-owned rows grow before publication. Supply sizes from every non-sentinel slot. The dictionary's floor is independent of a failed or racing campaign root. A failed native root leaves independently valid map population floors available.

The largest consistent country, link or tag header determines the idle sizing floor. The game's 16-bit country slot consumers bound what a consistent hint can report. An oversized count is treated as a torn hint, while row storage can still grow on actual demand. Allocation stays off the game thread, with attaches and idle spool polls establishing floors before the first loaded hour. DLC and mod counts are fixed at launch and need one observation. Independent readers keep their own counts, including dense intel vectors, selected ace and portrait strings, saved global names, raid content and convoy reservations, and the separate Rocket roster. Map floors use independent headers and the province count includes the reserved slot needed by sizing. Daily political staging scales for every frame still in use, above the steady count when a backlog holds more frames. Failures keep their names and previous floors. The registry-sizing tests serialize their attachment-local hints and reset the shared counters before measuring.

Naval sizing reads the physical slot count from its manager header and uses the existing authenticated task-force visitor for names, supply and port operands, including stationary task forces. The visitor reads headers and string boundaries without copying payloads, adding a census or following the searcher. Optional supply or port failures leave established name floors. Positive header counts with missing data are refused. The physical slot count includes reserved zero. Tests keep complete object ranges disjoint as the fixture adds distant port fields.

The scale regressions generate fixture bytes on demand to cover dense intel, two warring blocs, and rotating occupied air-history windows without storing large fixture memory. Parallel and serial sampling must agree. Quiet relation hours carry watched rows, reread refused or replaced owners, and emit daily slices together with explicit changes. Recovery after a withheld frame requires a full output even if fingerprints already saw its changes. Air history copies a refused owner every hour. A failed or unadmitted part withdraws every part's certificates and withholds the hour as a whole. The next staged hour may already be in flight, so it must read fresh even before the previous failure finishes decoding. Recycled frames prepare future growth and watch tables before the next use.

Ship and wing crew operands require matching quiet writer tokens around the read. A stable global token permits the attach-hour read even before its per-receiver registry exists. A missing token or a failed read means a withheld crew column. The ship supplies acquired and required crew in that order. The wing supplies acquired manpower and its government-in-exile country. Air detection overrides come only from the simulation writer, with no local interface state included. A sequence boundary invalidates reuse on a detach or reattach because writes could run during the gap. Active originals still count after their entry was restored.

Callback profiling is opt-in. The game thread reserves fixed slots and samples using atomics. The status thread creates JSON. A reserved slot is never overwritten, and status readers can omit an in-progress reservation without seeing partially published data. The slowest join keeps the earliest tie. Missing hook-entry time or unavailable or decreasing cycle counts produce missing values. The body counter reports an elapsed counter difference. The frequency is already validated, and the two cycle queries are inside the wall-time interval, so their cost is included. Start and finish samples on the game thread before the native trampoline. The platform's current-thread pseudo-handle is borrowed, and the thread identifier carries no handle lifetime.

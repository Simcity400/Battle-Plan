# Scene resources, hour data and submission have separate lifetimes

**Status:** Accepted

The loader warms static textures, model passes, pass pipelines and GUI effects while hour builders run; a model's textures are uploaded just before the first frame that draws it. Each content set uploads its icon pages once, on its host's single device, and keeps that upload. Its terrain and water textures are uploaded once for every scene on that device and their CPU sources dropped; when the device's last scene goes they are read again from the installation for the next scene. Opening a recording loads shared CPU content without building a GPU scene; each map builds its scene from that content only when shown, and a host releases its scenes when it shows no map view (the campaign map is not shown and no map widget is on the open page), keeping the content loaded so the campaign map builds its scene again when shown. Each scene owns its hour data and render targets. Static river, border, tree and sprawl geometry stays installed for the document. Use the recorded content's map dimensions for shader globals. Decode heightmaps as top-down raw byte samples, keeping the original bytes separate from any power-of-two-padded sampled texture. The terrain ID payload counts rows from the bottom. The tree bitmap can be coarser than the map when the two axes have equal pitch. Authored city and weather flags choose which cells contribute to those passes. Terrain sight derives lazily from the heightmap for a free eye. The colormap alpha carries emissive city lights and the city light texture's alpha carries snow noise. The water and fog use the same packed fog/specular source. Underwater tint retains its authored coordinate scale. Startup checks whether a view's device can allocate its formats, sample count and required bindings.

An hour installs only the layers it holds. Their destinations are disjoint, so every install can run even after one refuses. Return the first refusal in layer declaration order. A worker can prepare immutable uploads and placement banks, and installation can adopt or replace them without touching the presentation clocks. Return retired banks, paths, plans and weather runtimes for disposal off the frame path. Install order ribbons and country names by parts where possible, updating only affected vertices, labels, draw order or generation. Faction highlighting outlines the union's outgoing edges. Custom highlights outrank the ground selection, which outranks the demilitarised zone. Ordinary and secondary border banks partition the same edges, so their classification plans install together. A view can update its local navy selection and dirty political stripes without copying the recorded region tables. Pending fills stay pending until their encoder is submitted.

The intel texture has fixed province-image dimensions. A single channel uses alpha-compatible RGBA samples, with changed consecutive pages uploaded together. The texture and its fog coverage flag travel together so the renderer knows whether a payload is backed by recorded visibility. Snow factors can be prepared with the hour and attached without advancing the presentation clock. The snow and mud textures can accept changed rectangles without a rebuild, while a separate unknown mask supplies hatching. The hatch reuses terrain blocks and vertex heights and draws on the just-rendered ground or water before other layers cover them. Its geometry is built lazily for the active sample count. Political and occupation textures keep transparent stand-ins before their inputs arrive. Rebuild texture bindings only when their referenced texture objects change.

The held camera and its slack keep model candidates available during bounded camera motion. The frame's current camera decides its actual draws and motion report. Terrain block lists retain their per-view identity when a new cut preserves their blocks and rim ownership. [Model candidates](1390-viewer-camera-gather-and-draw.md) · [Terrain cut retention](1391-terrain-draw-reuse-across-cuts.md). Present enough world-wrap copies for the reachable view and keep per-copy uniforms consistent across the seam. Each copy uses the canonical vertex positions. A free camera's player figure uses its own bounds and reachable map copies at any height. It retains placement storage, updates an upload only when the entity changes, and casts within the ordinary light footprint. An unchanged placement draws with the existing field. Country name glyphs and projected interface overlays borrow the camera they were built for. Near names fade against far names; plan labels instead follow their own ribbon colours. World names shade and grade with the map, screen icons retain their interface scale and composite over the output. Display switches can hide world interface draws while preserving their clocks. Free-eye floating text can use terrain sight to decide visibility.

Pose requests use the active presentation tick and the actor draws that can need them, including their wrap copies. Playing frames swap in the latest ready set without waiting and reject results from older animation histories. A batch omitted a pass when it held no eligible player or the pass has changed histories. An actor without a retained pose is evaluated where needed. Still pictures and exports settle poses and build all needed effects before drawing. Draws for installed hours can refuse unprepared name glyphs instead of silently warming them. The window drawing thread does not wait for an unrelated pipeline build. A failed frame that never walked its province schedule returns the cut and force counts, while a consumed cut stays consumed. Every path restores borrowed state and joins work already started. Text atlas bakes can be submitted independently of an abandoned frame. Marks and commands of the failed frame are otherwise dropped together.

The world uses shared scene and depth targets. The unlit shadow receivers have independent depth. Draw each admitted wrap completely, including its retained constants. Keep world layers in separate render passes because the merged-pass experiment increased frame time and required recreating state established by pass starts. The underwater target reads the previous shadow-screen buffer before clears and receivers update it. A retained underwater target needs a new draw only when an input its compiled program reads changes. Prepare shadow depth and receivers, then lit terrain, water and border batches in their authored order. Submit regular materials before alternate materials across queues and preserve enqueue order prior to mesh and tile grouping. Scene text and particles follow meshes in each wrap. Alternate seam envelopes reuse canonical particle packets and keep their own footprint and ordering. Sky runs once with the original camera. Resolve the multisample scene once before grading or copying it to the 8-bit output. Screen icons, egui and readback all consume that output. Frame finishing can proceed on helper lanes while encoding continues. Submit staging writes before the ordered world and trailing buffers. Only after submission do retained targets and dirty uploads become current.

Preflight-only passes can isolate a refusal when the last fallible step precedes the first command. Track dependencies from authored inputs, such as retained border constants and water's exclusive refraction target. Withhold affected readers and preserve independent colour and depth contributions. Any error after recording begins, or a shared library, pipeline, arena, pool or device failure, abandons the shared frame. Validate retained initialization ranges as well as buffer bytes. Keep one diagnostic per pass and retry the producer on a new frame. Tests observe actual encoder and output state, including partial fatal attempts, independently of earlier app warnings and audio reset. Refusal keys use stable pass names so views with and without visual mods can compare them. GPU timestamps settle asynchronously and do not block frame closure. Separate caller CPU timing from GPU queries and attribute final finish and submission to scene submission. Hiding a view releases view-sized render targets while retaining shared content, installed hour data and used exposure history.

# Interpret jurisdiction and rosters under the save's omission rules

Province names and state names are gated by the stored length, and their written prefix can be empty after first-NUL serialization. Province owners are inferred from states because the province record has no owner field. An explicitly saved controller can compare directly. The province serializer omits signed nonpositive controllers and the loader supplies an omitted controller from its owner. A state's serializer omits a controller when its raw or canonical identity equals the positive owner's, and it can explicitly write zero. These rules compare the projection and preserve the stored identities. [Core oracle](../../crates/recorder-oracle-core/src/core.rs) · [Country rosters](../../crates/recorder-oracle-country-rosters/src/country_rosters.rs)

The state category resolves through the recorded dictionary using the lexer's case fold. Contested owners compare in stored order. A positive population requires the saved manpower pool and its total. An omitted pool can establish only that the population is nonpositive. Railway fraction compares healthy infrastructure to the base maximum selected by a positive province cap, then a positive state cap, then the signed recorded define. State stockpiles apply native per-row clamps in saved order. [Core comparison regressions](../../crates/recorder-oracle-core/src/core/nonpositive_state_tests.rs)

Boundary counters are witnesses of possible intervening work. Equality does not establish that the frame was synchronized with the save and a counter difference does not excuse a field difference. The command reports the assumed refresh boundary, since the frame does not record it. An increase is consistent with a frame following the save. Reload, counter wrap and a frame preceding the save can cause regression. [Boundary counter check](../../crates/recorder-oracle-core/src/core.rs)

Country roster comparisons retain the serialized order and duplicates. Leader, advisor and operative roles use their applicable raw rosters, with an operative fallback independent of military roles. Runtime limitations are reported even when a positive saved-country join is missing. Portrait scopes must match the independent saved selection as well as each other, so shared omissions cannot certify an absent leader.

# 0204-B. Decode a lexical refresh from one owned capture

The host dispatches and loans the capture. The acquisition worker reads the opening writer witness, bulk-copies the header table in fixed chunks, takes the heap bytes and terminators in token order and obtains a closing witness. Reverse-table growth recomputes its maximum, so the original writer-free witness must remain unchanged throughout. A failed bulk chunk switches to exact header reads in that chunk so it stops at the same token as the scalar walk. A readable but invalid terminator still counts as an observation. The semantic error belongs to decoding.

Staging a raw payload causes typed capture to leave the reset outcomes in place. The flag survives a reset until the decode worker installs rows, arenas and outcomes from the staged payload. A complete validated packet lets the worker grow from owned byte counts before the first publication. A foreign length word is insufficient evidence for allocation. A partially readable string grows only through successfully copied chunks. Native guard failures may write a prefix but that prefix is discarded. The fixed-width append cases preserve the measured behavior of the former observation log. Only the observation's outcome and an owned-pool offset are needed, and a separate tag leaves the last valid offset available.

Complete packets decode directly if their witness and header ranges are unaliased and the caller uses the captured base. Successful heap observations may alias one another because the complete path consumes them in acquisition order. Witness or header aliases, failed reads and incomplete packets reconstruct the typed read stream from owned bytes. This preserves exact-key repeats and bulk containment, source error order and truncation without retrying live memory. Reconstruction accounts for its own buffers while the packet still owns its allocation. The decoder requires independent evidence of closure before publishing a complete or truncated table. Repeated observations in the generic reader could otherwise make a missed closing read appear to match the opening witness.

Spool conversion can reuse the actual offered shared table allocation after comparing the current outcome, token ordinals and text bytes. It retains no earlier native rows, dictionary bytes or capture loan for that comparison. Unused pool tails do not affect equivalence. A synthetic scalar acquisition serves as the differential reference, while live capture uses the same owned representation for direct and exceptional decoding. The tests cover missing boundary reads, header aliases, shared heap keys, failed partial reads, and destination capacities independent of the acquired payload.

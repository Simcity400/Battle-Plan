# 0403. Invalidate derived native stats on their owning rebuilds

The active-stat rebuild owns runtime division attack operands. It applies the template's equipment stat calculation to the division's block and then processes equipment modifiers. The hourly pass uses one of 24 slices selected by the division's id plus one. Its worker and the explicit refresh paths reach the same rebuild. Other uses of the equipment-stat calculation produce separate definitions. Build and load create fresh division blocks, so a division must have a held read in the current epoch before it can carry.

Division name-member identity is set at construction. Cached-name refresh follows changes to an existing member through template changes, rename commands, binding and deserialization. Its callers can also name ships, operatives and production lines, so authenticate whether the member is watched. A country-wide name refresh can rewrite members inline without this helper. The country identity is sufficient to mark those divisions after the refresh. New members are read afresh.

Local sub-unit clones are rebuilt from global definitions and country deployment bonuses. Ensuring a new clone appends and advances the vector count. An already present token only changes a flag outside the recorded rows. Ordinary default initialization creates clones during reset or dynamic reuse. Save loading rebuilds this state from its dependencies. Runtime clone rebuild replaces the archetype requirement pool and applies current bonuses, including rebuild by token after research or bonus changes and full rebuild after content reload. Clearing destroys all clones on teardown or appearance reset. Rows exist only for a difference from current global requirements. Global definition or equipment archetype replacement can change that comparison without naming one country, so it revokes every certificate.

Naval hover modifiers have separate country and commander trees. Country modifier recalculation rebuilds the country tree, including helpers reached only with its block. Appearance reset clears it during dynamic reuse, runtime reset and country-file loading. The stability and research family forwards recalculation and the politics family forwards reset. A pooled child may reuse its address even when its value changes. The commander tree is written by the modifier recalculation tail and HQ communication scaling. Leader construction, copy and destruction revoke that witness. Loading reconstructs the trees in a new epoch.

# Keep capture, history and recorder ownership independent

A recorder claims a process by ID and creation time before checking or attaching the collector, and holds that claim through session end. A stopped recorder can leave a collector sampling into its existing session. Takeover requires a matching recorder build and session identity. It keeps the folder, admission decisions, writer resume point and branch, then logs the previous recorder and last reported hour. A live owner, foreign collector or ended session is refused by name. An incompatible orphan must detach through its own controls before a new session can begin. Its journal still gets finalized independently.

Fresh capture waits for the game to finish initializing content and load a campaign. The loaded content roster is sized at attachment and will be wrong if initialized before that point. Content verification is joined before a capture leaves. Stopping before a fresh attachment starts leaves nothing to detach. A takeover stopped during verification requests a drain and then applies the normal Save or Discard choice. Other early exits request cancellation and detachment through the capture guard. The collector owns the feature-gated sampler request grammar. The recorder passes it through and an ordinary collector refuses a nonempty request by name.

Campaign writers consume journals independently of the hourly callback. Background packing respects the collector's sampling boundary so the game need not compete with its memory traffic. The active campaign is never set aside, even before its first spool hour. Leaving a campaign closes its segment regardless of admission for the next load. A set-aside campaign can be saved or discarded while capture continues. A history loan lets the collector release that campaign's files while the recorder acts. If a file publication was visible before its flush failed, return the loan before accepting another one.

The controller preserves Save or Discard requests until they have acted and answers late requests when capture has ended. Toggling autosave can save previously waiting hours while leaving an earlier refusal for explicit action. Earlier sessions' waiting hours are saved with the current ones. An admitted campaign left before its first spool hour still participates. Preview names are calculated only while requested, using the session's content and all admitted waiting hours in scope. A Stop decision uses the loaded campaign at the time of the request, with the collector's last campaign only where the observation is unambiguous. An unknown campaign cannot be discarded by guess.

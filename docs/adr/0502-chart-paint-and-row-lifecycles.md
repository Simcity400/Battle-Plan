# Schedule chart painting and commit row motion separately

Chart tasks run in the shared engine's paint phase. The scheduler apportions the frame across ready tasks, starting each frame where the previous budget ended. Individual draws are synchronous, so a long one can overrun the budget. A return from a background tab clamps task time steps. A wake during a draw remains pending for the next frame. Hidden tasks keep their registration and draw again when shown. Pending paint is stored as a canvas property so the acceptance suite can time rendering without changing DOM attributes and invalidating styles.

Where the browser supports it, transfer the chart canvas to an offscreen surface. Font and text operations on a document canvas can trigger a style pass after another widget writes to the page. Preserve the layout-pixel drawing coordinate system and size the backing store to the on-screen device pixels, including widget zoom. Observe the surface and its parent so only a resize invalidates cached geometry. Bound the backing allocation for a single widget. Treat font loading as a change to cached text widths. Read chart colours through the browser's computed styles so composed theme expressions resolve correctly. Invalidate shared chart tokens when appearance changes, including when every chart is unmounted.

Rows derive motion from the last committed history. Strict Mode renders and abandoned renders leave that history intact. A commit uses the fade cutoff it rendered so it cannot drop an unseen leaving row based on a later wall-clock time. The first update has no entry flash. A row that reappears cancels its departure, and another row taking its slot draws over the departure by suppressing the old slot's fade. Keep unchanged histories by identity so re-observation does not schedule another render.

Following lists prepare short windows of rows ahead of the playhead and reveal them on frame ticks. Window length is bounded by playback time and prepared row count so one batch can render within a frame. A paused list ends its window at the next row. An incomplete page stops at the last known arrival hour because other rows from that hour can still land. Keyboard focus and pointer interactions share row-menu and tooltip semantics. Description IDs include the owner and the typed key so numeric and string identities remain distinct.

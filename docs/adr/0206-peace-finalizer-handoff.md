# 0206. Hand off owned peace-finalizer events each hour

Finalization is observed as an occurrence. A try-only exclusive lease owns the prearranged arena, grows it for a larger conference and counts competing or reentrant calls as missed events. A successful observation copies its payload while the native data is live. The hourly boundary moves only owned observations. If a destination cannot take the complete event, the recorder counts the loss and retains the missing-event reason instead of publishing a partial conference as exact.

The loader and spool size storage from complete native roster and resident-history demands. Their capacity hints use the prepared shape, since only the lease can inspect vectors that the callback can grow. The hourly boundary installs a replacement after it is writer-free. The spool releases retired storage and converts payloads into replay rows. A conference whose details cannot be read still has a manifest row. Resident bids are sampled before finalization for comparison with a fresh save. The acquisition worker continues each original walk using its copied headers to size shared arenas.

`Log` can share its `UnsafeCell` storage because all live access holds the exclusive lease and retirement waits for the writer-free boundary. `peace_finalizer_entry` supplies a synthetic return to the continuation after the patched instruction so Windows unwinds through that site's native record. Using the patch itself as the return would expose its jump to epilogue decoding. The bridge's saved flags, registers and scratch allocation keep the observer call aligned. `peace_test_call` reproduces the interior site's alignment and returns through the original target stub. The unwind fixture builds the scratch, saved registers, flags and synthetic return in that order and never enters the observer. The ignored measurement uses isolated, single-threaded storage and installs no hook, so its direct counter reset needs no live lease.

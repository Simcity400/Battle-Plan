# 1301. Replace ordinary edges at recorded demilitarized boundaries

Join complete state flags to current state IDs. Any nonzero raw flag qualifies. The outline requires both provinces on land and exactly one side flagged. Withhold the entire result if either table is partial. Treating missing entries as zero could cut a false outline through the zone. The dump-only override can add explicit state IDs for verification.

Prepare highlighted runs from the ordinary traced meshes on the hour worker. Preserve each edge's base material and its fine and coarse geometry. A secondary selection reason moves the edge out of the ordinary draw. Custom highlights can claim dormant strips at coasts and isolated islands, and take precedence when they overlap demilitarized edges.

Resolve the palette from content. Ground selection uses its province or state entry, and demilitarization uses its selection reason with full alpha and presentation-clock pulses. When the zone display is hidden and ordinary borders show, draw its edges with the ordinary alpha and palette choices. Faction hover is interaction feedback and remains available despite border switches. Keep the material binding sequence even for empty runs so later drawing inherits the same state.

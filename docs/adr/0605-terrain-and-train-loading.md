# Replay authored order for terrain categories and trains

Terrain categories append in file and entry order, even when names repeat. The null category occupies zero and the first ASCII-folded category match is resolved when a terrain entry is read. A later category cannot resolve an earlier reference. A malformed field normally keeps the preceding value and records a diagnostic. If the entry cannot be held, skip it. Emit no palette writes when there are no colour indices. Repeated colour fields append, failed colour-element scans leave zero, and each kept palette slot uses the last writer. Indices that cannot be sampled from a byte are omitted; negative indices refuse the entry as an out-of-range write. A water province falls back to the named ocean category if its region has no usable terrain category.

Keep the numeric and recovery semantics of the terrain field readers. Omitted movement cost is zero. Clamp to the native minimum on every movement-cost read, including a failed one. Widths and adjustment amounts retain fixed5 values without this clamp. Common modifiers add to each class after loading, where repeated class names share their first bucket. Category colour starts at white and subsequent colour reads update the previous value. Widths, flags, integer scans and keyed statement bodies each retain their own value-consumption rules. A scalar or malformed category entry can consume tokens that appear to belong to later entries, so the file reader preserves that continuation and reports where it departed from the authored shape. Each file starts with a fresh variable scope. Quoted keys do not dispatch as keywords.

The default map keeps its last path for a repeated key and accumulates tree palette indices. Its CPU bitmap reads retain their authored dimensions. The world-normal texture uses ordinary texture path resolution and can apply the client power-of-two option. BMP images with entirely opaque alpha upload without an alpha channel, and unusable textures are refused by name. The movement map shares the terrain reader's file order so it sees the same category identities and costs as the viewer.

Train graphics reads every direct definition file in content order and shares the wagon-name table across the scan. Wagon entries need a registered entity, with later declarations replacing the name for subsequent references. Repeated consist definitions replace individual fixed slots and append their random wagons. Unknown wagon names leave a slot unchanged and produce a diagnostic. Keep authorship units distinct: rotations are converted from degrees to radians and numeric fields use prefix scans.

Choose country, graphical culture, and then default, with the first two available only for a valid creator tag. Within a table try the equipment type before its archetype and require its first wagon. A country archetype can therefore win against a culture's exact type. Resolve country tags and culture names through content, trying the culture suffix for unqualified names. The registered null culture is a real index-zero object and distinct from a missing culture. Train definitions sharing an ASCII-folded equipment name share one table entry.

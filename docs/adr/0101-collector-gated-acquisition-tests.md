# 0101. Use explicit gates for acquisition lifecycle tests

Acquisition tests order work with gates and isolate terminal allocation state in child processes. A callback's batch drains every accepted job before returning or unwinding. Started work must return, and queued work can cancel before it starts. The test guard releases held jobs after callback unwind begins, including when a job records a terminal allocation failure during that drain. A contained stitch panic charges the executor and its own role once, stops the pool, and still drains accepted sibling jobs.

The executor can publish a completed request before its detached notification retires the active claim. Reusing its cell must preserve the old request's isolation and context lease. A child that depends on a ready producer can launch once the producer is collected, while fixed slot order and first refusal still apply to results. Tests force stale readiness notifications and reverse part publication to witness those conditions.

A borrowed naval order reader must drop before the ordinary decode can rebuild or reset its job. Normal collection transfers the loan to its owner. Panic, early rejection and cancelled queued work still settle it. Parked successor stages reuse the exact loan with no copy, including when they wait for the Naval stage. ChildFronts that needs an army-group operand uses worker-only reserved slots. A pass that requests no operand allocates nothing and can run from a join while queued. The loan fixture starts with the naval job's default because its capture state is private.

Allocation refusal tests precede injectable ordinals with the same initialization and serialized work, including journal writes, so each ordinal names the same allocation of the test binary. Fix ordinals to module-relative return sites across process layout changes. Use child-local fixtures and paths unique to the case because Windows can reuse process IDs. Attach failure keeps the observer unbound and releases partially prepared storage. An hour that fails to allocate a frame reports that hour and stops without creating an extra loss or gap. Local raw and decode refusal withholds the affected tables by name, retains other results, and allows the next hour to decode normally. A refusal outside contained work stops capture. Later terminal reasons cannot replace the latched one.

# 0103. Keep character data owned through settlement

The character copy path records successful span offsets into the owned arena. A failed field can have written partial bytes before another field reuses that space. The failed field, like a zero-length inactive scatter slot, must publish no offset even when its position coincides with a successful field. Arena growth changes addresses without changing these offsets. The compact view copy stores eight span offsets, including gender, plus the optional unit ID and carried flag. Its parity fixture compares the new sequencing with the pre-hint caller using the same literal parser and copy primitive. Aliased sentinel values still represent separate target requests.

Capacity observations size the next capture and supply no values to the current capture. Both roster vectors keep every occurrence and its own leader. Repeated pointers count toward demand. Trait-training capacity covers the full native vector independently of assigned traits. Before copying assigned occurrences, reserve from the authenticated count. Copy each successful definition's token and terminator once and index it only within the current owned acquisition. Occurrences retain native order. The decoder uses only the owned log, and neither arena offsets nor the address index survive to the next pass.

The spool's conversion shadow owns the used typed fields and bytes, without a live pointer or capture lease. An exact hit requires matching input order, field values, used bytes, branch, and the current complete table's weak identity. The leader-layout identifier can witness the full training table. Replacement or invalidation of the spool cache prevents reuse, even if a different table has the same rows. Equality ignores struct padding. An exact hit preserves the ranges previously validated, so only changed input needs another row-validation pass. The advisor parity fixture compares flags, failures and nonempty spans and accepts different offsets for empty spans because they address no bytes.

Advisor tail measurements are bounded and opt-in. Acquisition records them without allocating or taking locks. The character quiet-hour benchmark uses a synthetic world rendered into host buffers at 13,200 characters. It separates copying and native reads from decode and rebuild work, compares warm and cache-evicted copy, and measures disabling each of table republication, census reuse, and held leader rows. The advisor bench compares fresh and retained frames. The portrait bench compares repeated and newly acquired census stamps. Run the `quiet_bench` group in a release test build with `--ignored --nocapture`.

The benchmark uses `_rdtsc` on x86-64, where the test's direct instruction use requires no operand or memory precondition.

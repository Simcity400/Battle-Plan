# Bind picker choices to their recorded identity and render context

The country picker requests country names for searching even when a row is offscreen, and reads flags only for visible rows. Names remembered for a held hour stay searchable while filters and scrolling change the visible rows. Dated names cannot reorder a mounted row and cause more queries without scrolling. Rows keep the CSS option height, and the initial viewport uses the CSS maximum until measured. Initial list focus marks the first visible item without scrolling under an in-progress click. The top bar asks for names and flags at its playback day and holds their prior same-context values until the dated results arrive. A dated name already in flight finishes before the newest wanted day is requested. Switching the client, supplying country, branch or flag size releases the prior picture. A drill-supplied dated read controls the row's looks and must match the requested branch. A click still returns the offered tag or canonical slot rather than a supplying alias. A later recorded alias can be offered without inventing a canonical slot. Top-bar shields keep the game's shading and panel shields even it out.

Flag canvases clear as soon as their input changes. A refused decode or a replacement that has yet to arrive cannot expose the prior country's image. One observer schedules painting at the presented size and display density. All outcomes occupy the same slot, and dated refusals retain their name and detail. Artwork fallback occupies its picture slot and is decorative when the adjacent name already gives its identity.

The aircraft list docks beside the workspace while Fly mode is active. A popover cuts a hole in the map it overlaps, so a popover could cover the selected aircraft during the preview. Fly mode opens the list once for a campaign with no chosen aircraft and honors dismissal. Missing pages and refused entries retain their list positions, and only available rows participate in keyed selection. Saved content-set choices are resolved only against a complete catalogue, including saved choices absent from the campaign.

Map settings retain stored choices for unavailable mods and advertise possible anti-aliasing sample counts until a particular renderer reports its support. Returning settings to inheritance preserves the separately managed visual-mod selection and the stored shape. When relevant mod content changes, open maps reload at their current positions. The acceptance suite uses the setting identifiers and values emitted by the settings rows to compare saved settings with renderer state.

Map export closes the settings popover, whose hole can clip the whole map, and waits for the map to be shown before requesting the image. Refusal reopens the menu to show why. Pop-out actions use the displayed window generation so commands cannot apply to a replacement window. The branch join control records the user's choice or delegates to the recording's own decision. A successfully read group that contains no countries uses the empty-selection state. Unavailable readings show the missing value and keep the detail in the reason.

# Date experience changes by the daily read

Report each branch's banked experience at the last daily read, its change from the read a day before and the gross gain over the day as distinct facts. The game's unit is 32768 per experience point. A daily table sample hour dates the complete read for every country. Each country row is keyed by its recorded raw id. If the read or any needed value is unavailable, the view reports why without inventing a number.

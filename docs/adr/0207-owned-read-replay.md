# 0207. Decode only the exact owned observations of a raw acquisition

An acquisition copies guarded data into an owned span log. Each span holds an exact address, width, success flag, affected-table mask and byte offset. Structural producer logic can read acquired headers to choose the next span. Typed conversion, ordering and comparison use the same readers against the FIFO worker's owned log. The replay fails unrecorded reads. Its masks attribute failures to tables and do not select which acquisition phase can serve a read. A failed or malformed span stops just the subpath that needed it, preserving earlier observations and the ordinary reader's error precedence. Local arithmetic failure or an empty span requires no memory read. Reject noncanonical ranges before passing them to the guarded copy path, using the ordinary unavailable outcome for that read.

The log exposes only its initialized successful prefix. Failed or partial copies cannot expose overwritten or previously used storage. Record each successful field and the first failure of ordered gathers, preserving the failed field's address even when it was rejected without a read. Acquire no later fields from that gather. Batched guards bound the work in one call. Their exact-entry mode yields the same observations as separate scalar calls, while bulk mode stores the copied prefix as one enclosing span. If batching cannot be admitted without changing capacity semantics, record one field at a time. Null, overflow and torn headers fail before touching memory. An impossibly large length is named unreadable, rather than increasing capacity until it happens to fit.

Acquiring may grow initialized storage from the original request before its first guarded read. Fixed-buffer overflow retains demand for the next independent acquisition. The worker grows span and byte arenas independently and reuses their allocations. A source read refusal itself is not growth demand. Additional already-owned observations can be spliced only when the caller proved their sources unchanged. Staging charges new native span bytes once, retaining exact table attribution even for data used by more than one table.

Optional read-plan tracing has its own bound. A failed trace cannot change the ordinary acquisition. A prepared plan validates control observations before their dependent reads and carries the exact successful prefix into an ordered fallback. A complete plan loans immutable span geometry to the decoder and retrieves it on clear or recycle. Planned geometry never certifies held bytes. Unsupported plan execution can use the ordinary producer only before source observations exist. A changed operation kind cannot consume an existing scalar prefix. Once any source observation happened, prepared failure or capacity refusal cannot start an independent live retry, including from a compound caller. Retirement and recompile run on the recycle worker. Compact repeated controls only over this producer's append-only destinations, keeping the earliest check of each byte.

Replay looks up exact address and width first. Match both fields to resolve hash collisions. An exact failure wins over an enclosing bulk span. A repeated exact key consumes its stored observations in order, then keeps serving the last one. A key never staged remains unavailable. A negative lookup cannot advance an observation cursor. When no exact key matches, a flagged bulk span can serve a request wholly inside it, choosing the nearest enclosing start. A later-starting nested range forces a new search even when the cached range still encloses the request. A contained immutable view is safe only when exactly one admitted observation overlaps it, with no conflicting exact read, duplicate or competing bulk span. A whole-bulk exact key still takes the ordinary read path.

Recycle address index storage by acquisition phase. Reuse requires equality of the ordered structural span shape, including success and bulk flags. Payload bytes and offsets come from the new capture. Each simultaneous reader has its own cursors, and every reused reader resets duplicate keys to their first observation. Unique keys need no resets. Reserve index storage before altering its shape and size buckets by distinct keys rather than occurrence count. Exact widths below the conservative large-width bucket can bypass exact search only when their recorded-length bit is absent. Allocation failure withholds the reader by name without a partially admitted index. Index preparation owns timing and allocation diagnostics. Query and native copy loops add neither atomics nor timings for those measurements.

Country-slot staging uses the same canonical identities as the typed reader. A positive slot can point at an alias of another country or the already authenticated reserved zero object. Publish the country once, at its canonical slot. A null slot is distinct from a refused slot, which ends the census at its prefix. Resolution can need a raw link and slot outside an earlier census prefix. Replaying that resolution cannot use a successful span from an unrelated phase to cover an earlier failure.

Tests use a simple linear replay and earlier direct scatter paths as independent references. They change values between requests to detect reordered duplicate reads, move the same span shape to new byte-pool offsets, and exercise exact failures against cached bulk ranges. A separately acquired suffix must not publish previously untouched bytes after a short copy. Cache tests track the retained capacity, including reuse after an empty shape, rather than transient allocation overlap.

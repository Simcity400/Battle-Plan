# 0301. Resolve each map choice at the narrowest applicable scope

Resolve each choice independently from the game through global, campaign and widget scope. Persist only overrides. Leaving a field unset takes its parent’s current value, and selecting an optional value is distinct from inheriting an unset parent. A widget’s filter, settings and mod selection can therefore change without rewriting other scopes. Keep inheritance markers and the user's selection order on disk. A flip uses the value resolved inside the save transaction so a queued edit or reset cannot supply an older value. Coordinate saves across windows with a file lock and advance a generation whenever a map may need to re-resolve its settings. Default to an empty visual selection at the root and canonicalize resolved mods by ID since mount order comes from the game. Resolve mod IDs against the installed catalogue, retaining the name of unavailable choices.

Display switches control drawing and shadows. The hidden content’s simulation, clocks, picking, selection and hover remain active. Weather is the exception: disabling it releases its particles and enabling it seeds a new stream. Advanced parts need both their own switch and their main switch. Battle-plan and trade-route ribbons share drawing machinery, and trade routes still follow their map mode. Record antialiasing choices once the renderer reports its device capabilities. Until then, represent availability as unknown.

The map reads the game’s own defaults overlaid with settings the game can load. Read the last valid value of each key regardless of case, leaving unchanged fields on missing or unparseable values. Map shadows and quality use their map options. The game’s day/night hide setting is inverted and changes lights without replacing the recorded clock. Some app settings have no game preference, including fog, player-only counters and radar. A missing game preference for NATO frames can remain unknown until the recording supplies a choice or a scope sets one. Preserve decimal sound values within the game's scale. Music is the exception to reading the game: it starts silent whatever the game's own music volume is, and plays only once a scope turns it up. The second master factor comes from game settings alone, and the focused map plays audio.

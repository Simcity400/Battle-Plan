# 1103. Resolve map counter operands at the viewed hour

Each hover and diagnostics batch shares one lazy index over the immutable hour. Start from the representative's full reference, then keep original member and timing ordinals while skipping later references proven dangling by a complete census. An incomplete census leaves those references unknown. The active ability has its own handler and does not depend on the generic counter's representative gate. Detailed arrival marks its generic handler even if the text is empty, while coarse counters own their body. A location-model hover uses the same army list over the divisions at that province, without the counter's arrival lines. Diagnostics enumerate presented controls without a pointer, and add template, garrison, HQ and naval management sections only when requested. The tests install the viewer's allocator.

Composition icons and generated names follow the recorded composition country even if the composition is unreadable. Literal template text wins, and an older recording that lacks the name key refuses only the reached fallback. Use the roster country for the roster label. A failed name cache does not authorize a regeneration from available operands. Evaluate disclosure before hostility, with a separate branch for the viewer's own country. An undisclosed singleton or a fully unknown group never reaches supply. Supply averages the known per-member ratios with native wrapping fixed-point arithmetic. Preserve the paired absolute current and maximum getters for the counter's stat display.

The generic counter's arrival branches require a positive route count, an ordinary route with no special target, and a resolved destination before choosing the ownership branch. Foreign hovers use only the next-province duration and omit the line when hidden. Format reached durations with the native signed hour ceiling, treating whole days below one as total signed hours. The selected counter wording uses the content's own/foreign time keys with integer hours and days, preserving native wording for railway guns and task forces while appending `(estimated)` to division counter arrival and next-province estimates whose native speed terms are not all captured. A legacy client hover duration cannot fill a missing movement operand. Title fragments terminate their lines and the painter supplies the divider newline.

Division progress integrates its recorded route and keeps the reached refusal. Its ETA uses the recorded base speed with combat, country, commander, state, sub-unit, weather, supply, enemy-air, terrain, organisation and fuel inputs when those terms are reached. Infrastructure and terrain terms are edge-dependent. Land speed observes the native floor, redeployment uses its road or rail speed, and transfers use regional naval transport speed. Edge topology and movement defines come from matching content. The same settled route point supplies counter and model positions. The viewer's selection alone admits movement arrows. Admission uses roster ownership and the canonical country censuses. Style uses logical ownership and the ordinary destination, while geometry can prefer the alternate route. The route controller relation is directional and reverses the action-tail relation. Style selector names are content selectors.

A prospective query runs the shared route search for divisions and railway guns, and preserves the searched route when its independent duration refuses. A rejected search yields a proven empty route, while missing facts leave a reason. An empty route demands neither speed nor progress. Validate table reachability lazily so a failed rail domain cannot deny a route that only uses transport edges. Resolve both land endpoints' rail-info before demanding their buildings; a complete rail census can prove no-info. A fresh railway gun uses equipment speed with its directed track bonus, land scale and supply factor. Sea legs use the logical owner's speed in the source region and the naval scale. Capture records only regions reached by stored paths or current locations, so a fresh route through another region refuses its reached speed explicitly. A zero-speed leg returns immediately, while a division overflow reached on an earlier leg cannot be masked by a later zero. The actual first-edge progress is demanded only on a matching departure.

A task force's fresh route admission depends on uncaptured range, theatre, access and nearest-base inputs. Refuse its prospective route by name and use the stored ordinary route for counter arrival. Integrate whole routes for own forces and first legs for others, using the current speed packet and each departure region. Preserve census order and raw class tokens when averaging ship adjustments, including native wrapping before division and the empty-roster arm. A complete reverse dictionary can establish that a class has no bucket. No embark distance is used for this class. Preserve the reached zero-speed and overflow rules before considering actual departure progress.

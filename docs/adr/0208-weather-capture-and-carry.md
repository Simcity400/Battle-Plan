# Weather carry follows the observed native update

## Acquire once and preserve independent refusals

The hourly weather acquisition worker copies the manager topology, exact region and province fields, clocks and the two display arrays. Header-based advisory sizing carries no recorded values. The FIFO decode worker uses the ordinary native row parsers and display join on the owned bytes. It keeps the original row order and the first failed field. A failed native read is terminal even if the prepared payload also runs out of storage. An overflow with a valid observed prefix can continue from the already acquired headers. An accepted failed acquisition never retries live memory. The decode worker clears the raw-mode handoff before the next capture.

Region and province outcomes are independent. The snow ceiling is required only by regions. Region weather modifiers keep native key order as specified by `COMBAT_KEYS`. Attack, breakthrough, and weather speed remain raw operands. Preserve absent keys, unavailable operands, and region refusals separately. A region's sea array preserves its native value count and order and can fail independently of its region record. An air-efficiency read can independently consult the same region header, and an equal tree reuses its allocation for a pointer comparison. Province accumulator entries are ordered by key and use fixed5 values. Static list entries contain the script name and days remaining in native list order. The packed buffers retain one optional span per slot and distinguish a complete empty list from a refused list. Reuse storage on recycle and keep growth off the callback.

## Reuse records outside the two windows

With the suspension and initial-mode gates clear, the ordinary update performs one province window pass and one region window pass. Each starts at its live cursor and wraps at the native count. The game content, including mods, sets the budgets. A nonnegative cursor in bounds visits at least one slot, with the visit count limited by the budget and one revolution. A cursor at or above the count visits no slots. Negative cursors and invalid array counts refuse the window.

Reuse requires the next consecutive hour, an unchanged acquired manager and array topology, matching budgets and observed writer count, and both cursors advancing by exactly one pass. Then gather the two visited windows and carry the other records. Ordinary record updates also rebuild each visited province's weather accumulator and refresh the visited regions' modifier and sea values. Those operands follow their certified record windows independently. A failed field gather keeps only the current prefix, refuses that part without retry, and makes the next hour read all records. A failed region modifier observation is unavailable for that region. Custom sea values can refuse without forfeiting carried records and force a full read of those values the next hour. A new manager, forced or incomplete hour, gap, disallowed gate, moved count, changed budget, unexpected cursor or unavailable writer count triggers a full read.

Off-window writes include weather reset, reload, reseed and load, console commands and the native modifier add, remove and expiry paths. The country-input observer counts their entry and return. A daily expiry can decrement positive days without a hooked write. Static province lists therefore carry only from the previous hour, under the same manager and province array, with neither an observed writer nor the daily update. Otherwise gather all static list headers, then their entries. A failed header refuses its suffix and a failed entry list refuses that province. A complete held list is shared with frames, and old capacity can be reused when it has no frame readers.

## Observe clocks and a coherent display boundary

Read clocks and display arrays whole each hour. A clock array has no row identities, so its captured count must match the province records before joining by slot. A completed day/night update supplies clocks for slots after zero. A suspended or unread gate leaves clocks held. Slot zero publishes the pass and display data. A province row's fault does not erase a separately acquired display or clock payload, and later successful joins cannot supersede that row fault.

The display grid uses a quarter of the map size and captures the last row and column of each plane with their shared corner once. Interior weather marks can stay queued while the live border remains readable. A queued whole-grid update can change either plane before clearing its queue, even under the same generation token. Capture checks completion around the pair so it can refuse an impossible snow and mud combination. A later capture can observe the same token after work completes, including after a mid-game attach. No display history is supplied before attach.

## Anchor temperature derivations

The decode worker observes hours in order. A complete observation supplies every province's temperature words and the manager's cursor, window, seed and suspension gates. Extend the current anchor when the preceding read proves either an ordinary step with no outside-window changes or a suspended hour without a change to cursor, seed or words. A proven ordinary step records its seed. A suspended step records no seed. A failed or incomplete read publishes no pass and breaks the run, while preserving separately read province fields. A load, reseed or gap starts a new anchor from its current words.

Use a new periodic anchor every two replay keyframe intervals. A keyframe halfway through keeps the same anchor and can refer to its prior encoding. This bounds reconstruction and seed-list length while avoiding repeated storage for the province words. A periodic anchor still records its own seed if the preceding observation proves the pass. Frames share the anchor and return the displaced observation buffer for the next read. Slot zero publishes the daylight, display and temperature pass even when no other province changes.

## Verification cases

The synthetic tests compare certified windows to complete reads of the same memory. They vary native cursors, wrap, live budgets, manager topology, writer counts, load and suspension, and distinguish incomplete acquisition from recovered observations. Read probes verify there is no retry of a failed weather record, while an independent operand reader can still probe its own input. The collector builds a local modifier fixture for the numeric reader's passive metadata path because the engine registry fixture belongs to the engine's own tests. Display tests schedule whole-grid work before or between plane reads, and temperature tests reconstruct states across suspension, reinitialization and periodic anchors.

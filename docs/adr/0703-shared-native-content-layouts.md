# Keep shared native layouts and content readers tied to their object identity

The diplomacy relation subtypes share a base layout. Their type identities and constructor declarations do not establish field offsets of arbitrary receivers. That same distinction matters for ideas and GUI objects. Idea token fields use the complete primary base after any secondary adjustment. The game-specific GUI manager inherits the ordinary creation and registration operations without proving arbitrary root ancestry. GUI registration state is outside the hourly game-state capture. Map dimensions come from a separate owner, and weather divides the signed dimensions by four with truncation toward zero.

The character advisor and leader node readers use the node base. The advisor key is stored text with a separate unsigned hash, and the leader key is a signed ideology value. The portrait reader holds its raw role, size and kind words and exact identity bytes. A valid empty heap string remains a heap string, and text need not be UTF-8. Capture an owned descriptor without a native pointer or texture-cache data. Copy the independent header spans together when possible, then preserve the dependent string validator's ordering and named failures. When a later address would overflow, check the earlier descriptor first. A writer observation keeps the descriptor held before the holder changes.

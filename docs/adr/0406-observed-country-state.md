# Record country collections at their witnessed boundaries

Timed country modifiers are sampled after the joined hourly update. The daily decrement and scripted add and remove rebuilds have finished at this boundary, which makes inferred lifecycle events unnecessary. The reader visits retained token and value headers, including disabled entries, to size storage. It copies owner-authenticated entries and preserves ordered fixed-point values, a signed daily remaining duration separate from expiry, and the native indefinite-duration sentinel. Values are sized from the definition's value count. Disabled entries still carry their stored data. Read an entry once under the caller's boundary. Capacity shortfalls omit whole entries and count the rows missed. [Container](../../crates/engine-stability/src/cdynamic_modifier_container.rs) · [Entry](../../crates/engine-stability/src/dynamic_modifier_entry.rs)

`dynamic_modifier_entry::copy_values` borrows the caller's initialized `i64` output as bytes for the checked copy, then decodes the little-endian values in place. The checked length covers exactly that slice. `i64` has no padding and every bit pattern is valid, so even a partial byte write from a failed copy keeps it initialized. The byte borrow stays inside the call. [Value copy](../../crates/engine-stability/src/dynamic_modifier_entry.rs)

Faction upgrade status is read when an owning writer marks it. Reuse the authenticated faction and its current lease for the upgrade header, companion slots, and collection reads. Sharing groups and advisor slots fail independently. The slot serializer's unset change hour is a loaded value, and a failed slot does not withhold siblings. The modifier wrapper yields stored operands and literal display text for the witnessed owner, preserving the input of a later calculation even when current content differs. [Upgrade status](../../crates/engine-stability/src/cfaction_upgrade_status.rs) · [Modifier acquisition](../../crates/engine-stability/src/cmodifier.rs)

Keep two country collections separate. Country aliases that ask to check all country occurrences use physical array order, including repeated pointers. The first passing result or first tied score wins. A reserved-country pointer match requires the proved reserved identity. A zero mapping or missing census entry alone cannot prove it. Original-tag buckets instead follow their stored order and canonical bucket selection, including stored slot-zero members, followed by any positive original raw reference. That cache has no text-save field. Keep every raw member without filtering or deduplication. [Country roster](../../crates/engine-stability/src/country_roster.rs) · [Original-tag buckets](../../crates/engine-stability/src/original_tag_lists.rs)

Sizing hints contain headers and lengths, without requiring complete payloads. They cannot establish availability. A changed bucket selection or invalid country pointer withholds the respective collection, even when some caller-owned arena bytes were written. Publish spans only after the whole collection succeeds. Count both bucket arenas before copying members and retain unrelated naming fields on refusal. The political-hover input reader applies the same distinction at a finer grain. Its six simulation operands are independent of viewpoint caches and each is attempted once. A failed operand leaves siblings available.

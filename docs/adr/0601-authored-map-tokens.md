# Preserve the map loaders' token and row boundaries

An authored map selects its adjacency rows, rules and ambient placements through `map/default.map`. Refuse a missing adjacency path by name, because loading an empty table could change whether a crossing exists or can be used. Keep raw rows shared between map passes and the province graph, with validation at the point of use.

The adjacency reader skips the header, reads nine semicolon-separated columns and then skips a line. A zero `From` restarts at the next field, while a negative one ends reading. Refuse a negative `To` instead of using it as a province index. Numeric fields cut by EOF retain the previous value for `To` and `Through`. Position fields start at zero. The reader treats `0xff` as end of input and preserves `\r` or a terminal NUL on rule names when the token reader would keep it. A row missing its final comment column can consume the following line. These boundaries matter because normalizing the text first would change the set of crossings.

Rules read through the native token stream so file-local script variables replay across proven rule, permission, trigger, province, icon and offset fields. Rules match the first exact stored name. Rule and permission keywords use ASCII case folding for bare tokens. Names retain their bytes through the first NUL, with escaped diagnostics for invalid UTF-8. Verdicts start with all four permissions enabled. Keep the icon outcome independent of permission parsing, so a rule with an unreadable permission can still contribute a valid province and three-dimensional placement offset. The disabled reason uses the last `not_tooltip`, then the last `tooltip` with `_NOT` appended if present. These tooltip assignments contribute no trigger. A permission field the reader cannot represent refuses the rule by name. A token-consumption mismatch that can shift later rules refuses the file. A non-rule top-level key consumes only its value, so a nested block can supply file-loop keys and terminate that loop at its closing brace.

Ambient placement uses a persistent type reader and its current flags when each `object` token arrives. Placement names identify instances separately from their entities. The type default scale is one and combines with the entity scale. Rotation is in authored degrees and the viewer uses only the Y component. Coordinates are world X, Y and Z, with fixed5 input and bounded component reads. The height is Y and the map depth increases along Z. Nonpositive duration and admission limits mean unlimited. A replacement `dlc_allowed` field supplies the new conjunction, and a failed scalar scan leaves the earlier field value. Variable resolution can change an excess vector token into a block opener, so it happens before handling excess tokens. The viewer owns entity admission and lifetime.

City sprawl uses the terrain palette to locate urban blobs and the separately authored style bitmap to select their architecture. Select a ring by distance from the blob's edge in map pixels, scanning the rings in reverse declaration order and taking the first reached ring even when it has no meshes. Its entities supply the random choices. The signed density displaces placements toward the ring-weighted neighbouring houses. The parser uses native prefix scans, so a decimal spelling can supply an integer prefix without error. A recorded error prevents sprawl construction entirely. Preserve that refusal by name rather than fabricating an integer result from a failed scan.

# Read authored start states before campaign history

## Decision

Read the direct state files in resolved content order after map definitions. Read each file on its own and merge definitions in their source order. A state registers only when its final signed ID is positive. On a repeated ID the first definition keeps its original province list and the conflict names both files. Unsettled reading refuses the whole inventory because an unread state could register an ID before a later read candidate. A prefix also cannot establish all candidate provinces for consumers such as naval battle naming.

Keep campaign-start facts and record the keys of dated and conditional history without applying them. History values with nonzero integer keys open a dated body. Dated conditions still consume their limits with the trigger reader so subsequent start-state fields remain reachable. Startup effects dispatch in state scope. Bare keywords are case-insensitive and quoted keywords do not dispatch. State names resolve through the file's variable table, use the last assignment, and require UTF-8 only before the first NUL. A line feed produces `Unreadable String`. Category lookup uses its C-string prefix without that name-specific line-feed check and does not run for discarded templates. Invalid impassability text leaves the previous value.

Preserve all number tokens in each `provinces` block with repeats and validate them against the loaded map count. That count includes the null row, and membership starts at 1 and ends before the count. The map reader refuses unregistered bitmap colours which could change that count. Take two `%i` operands for a victory point assignment. A wrong count reports a recovery and changes no points. An unconverted integer operand retains zero. Building fields hold either a signed level or a block with level and unevaluated `allowed` triggers. A level starts at zero and caps at the content define. Positive integer keys dispatch province buildings and other keys dispatch state-wide buildings. Repeated building names are case-insensitive with the last value retained.

Let the native reader own token consumption. Ordinary scalar fields take one token even if it is an opening brace. A group skipped by an unexpected key consumes only a current bracketed block. Province lists count nested braces, ignored links consume a list and startup effects consume a body. A non-block buildings value reports that loss and reads no building entries. Keep recovery diagnostics attached to the state loop's current occurrence because states can share a source line and reuse named effects. File-level variable and recovery errors with no narrower ownership affect all definitions of that file, including earlier states. Only nonpositive and duplicate IDs are registration skips. Live consumers get typed causes while the corpus keeps the original wording and file/line information.

## Registry-dependent reads

Register each resource block name by its C-string prefix and keep entries in order. The first resource with the resolved lexer token wins. Resource amounts use signed integer scans. A token-zero resource can match a name the lexer does not hold, and whether that name has a token depends on all registrations before the read. Name that uncertainty and refuse a block whose token-dependent consumption is unknown. Parse resource scalar fields as one value. Pass `modifier` through its own registered key to modifier dispatch. An unsettled modifier makes later names unknown for unresolved lookups.

State categories compare names with an ASCII-folded identity and retain first-declaration spelling and order. A repeat reuses the object. Localise category descriptions from the effect operand. The colour reader starts from white and applies subsequent authored reads to the existing components, even across files. An unread colour stays absent and the map mode names the states that cannot be coloured. A fully specified later value replaces a prior packed-colour refusal, while a partial value does not.

# 0301. Keep the native naming and formatting choices visible in product replies

Modifier definitions come from a branch hour holding both the recorded definitions and lexer names. Prefer those definitions over content-defined modifiers, and use the lexer to resolve definitions. An unknown built-in type is left marked unformatted. Use the executable definition’s order, units, precision and flags when available. A recorded postfix key with unreadable text is still a known unit. Native feature gates cannot be assumed active from a format entry alone. The viewer applies the disclosed formatting instead of guessing a modifier’s meaning. Render scoped modifier labels through the shared localiser with the stored argument, which remains available in nested expansions. A scripted modifier follows its content defaults.

The Politics content cache owns the shared idea, character, ideology, and trait reads per catalogue. Its two presentation slots remain independent, and it releases the slot lock before loading. It remembers success and refusals per binding, while a cancelled read can retry. Defines run before parallel helpers because executing their scripts can affect later values. The reads preserve the first sequential failure. Read the define-selected officer groups as character advisor templates. Load power-ledger definitions as a separate group of content. Preparation can populate it without giving unrelated replies its diagnostics. Only an item using the ledger presentation makes those diagnostics reachable.

A saved character name wins, including a rename, and can be shown even when the authored role cannot be read. Localise it in the plain view and preserve its bytes when the key is undefined. An unresolved saved name keeps its refusal and blocks authored fallback. Use authored alternatives only when the name was absent. A higher unknown portrait role blocks a lower fallback. Portrait size and artwork mode belong to the cache key so small and strict draws cannot displace normal full-size artwork. Keep each portrait finding’s original identity to deduplicate offline and interactive replies.

For ideas, choose a nonempty authored name override first even if localisation lacks the key. Otherwise try the country-prefixed token and then the token where the native civil-war rule allows those choices. An eligible group can generate names using the recorded country context, with its cosmetic tag when applicable and the native seed built from the database index, slot and level. Unavailable country inputs yield a named refusal on paths needing them. Localise only the selected key. Description selection prefers the token’s own description, then an authored override’s description. Authored absence of either is a valid empty description. A recorded holder’s known name survives a refusal loading authored role metadata. A diagnosed gap in advisor files cannot hide a known idea definition. Images follow the selected catalogue for the entire candidate search, and reach the shared fallback only after all known authored candidates miss.

Industrial organisation policy quotes use the organisation owner’s resolved link and policies. The holding country’s roster and raw alias cannot supply them. Cost inputs use the attached policy, the initial traits and resolved completed traits. Apply each source clamp only when its definition requires one, and match the native arithmetic, including wrapping intermediates and half-away-from-zero rounding. `FROM` names the owner while `ROOT` and `PREV` name the organisation. A failed availability gate decides visibility even when visible checks need missing data. When the answer remains undecided, refuse the quote by name instead of introducing zero.

Resource balance and trade share the same resource identities and presentation cache. The native index distinguishes every declaration, and a repeated token matches its occurrence in content load order. If recorded lexer text has yet to appear, leave that index for a later frame. A refused definition file can make offsets after it undecidable. Plain localisation uses the authored resource key, leaving the key itself visible when missing. The trade view’s selected icon sprite uses the declaration’s recorded one-based frame. Read names independently of GUI assets, and when a prepared reply shows visual mods, redo the icon transaction from the same recorded frame. Report the selected draw’s diagnostics without contaminating name-only replies. Missing game folders leave resource tokens and a named reason.

# 1101. Keep retained combat input on the visible native layout

Retain authored combat GUI templates, controls and sounds, and bind runtime-owned entries with explicit member order and measured geometry. Dynamic absence clears bound fields and an unhandled static field returns to its authored presentation. When artwork arrives, rebind the whole window and every nested row at the same generation. A tactic drawable replacement only changes a created path the content provided, preserving its clocks if no change is reached. Fixed-clock capture must still publish newly loaded sheets. A missing template refuses the prepared picture by name. Normal flags sample raw atlas cells through the authored mask and then its overlay.

Dispatch input on previously painted geometry, intersecting each entry clip. Paint the popup above its parent, absorb clicks on window backgrounds, and respect the control that owns a press until release even after other items move. Route ordered button steps to the topmost covered holder or the window and give nested text providers to their actual entry. A child that owns its own provider or rejects immediate text prevents parent substitution. Scroll repositions entries before using their hit regions. Hit collision follows graphical attachment order, and pointer input precedes the smoothing tick. Finalized content uses the dimensions supplied by its bound art, including escape bars, and hidden children still synchronize. Saved pictures settle fade and movement independently of elapsed time, but can still acquire newly published art.

The replay confirmation popup consumes clicks and localises authored buttons without posting a game order. In the find view the focused editor owns the keys, moves its caret by code point and filters control characters. The retained search index is built for one hour and uses recorded executable folding before ASCII lowercasing. It admits state-owning countries, all states and named victory points in native order. A query needs two bytes unless it is one digit. Rank by first name match or, only when absent, secondary match. Equal offsets retain index order. An unavailable fold reports why. Return or a result centres the camera and closes the view without selecting an object. The home control uses the viewing country's capital. Dragging, blinking and scrolling are retained on native control geometry.

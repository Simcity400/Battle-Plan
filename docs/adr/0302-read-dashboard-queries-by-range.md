# 0302. Answer dashboard queries from indexed recording ranges

Queries compose a few reads of the recording's own tables within the requested timeline. The index keeps the timeline runs and recorded country-holder runs while the recording is open. It holds no collection of previous query replies. Summary declarations supply shared series without product-specific readers. Request work scales with the named rows, blocks, pieces and pages. A nearest-change query uses summary pieces to identify candidate blocks, then reads the exact change in the candidate block. A table without a summary is walked. A transition into or out of a row also counts as a change, and a comparison requires the preceding hour of the run.

The `TagHolders` history is append-only while a run is read, so reading its last page gets the holder history for that run without scanning each hour. A tag request follows the country's recorded holder at each hour. A canonical-slot request follows that country through changes to its tag. If aliases overlap at the same hour, the lowest linked raw ID represents the slot. A missing link, absent tag, record of all holders unknown, and a missing identity table are distinct evidence. An unresolved hour starts a new holder segment. Adjacent runs of the same resolved holder can coalesce across recorded loads. A slot's synthetic lookup key has a NUL prefix that a real tag cannot have. A label can use the nearest recorded tag when the hour has none, but a slot with no witnessed name in the history stays unnamed.

Chart bins preserve boundaries for first, last, minimum and maximum observations. Ordered merge cannot turn missing children into recorded zero, and coverage breaks remain visible. Hourly bins carry their original runs, including source bounds, so a view clipped in the middle of a run does not invent a new segment. The wire format uses dense columns for populated buckets and records the skipped empty slots. It delta-encodes hours and preserves absolute totals and exact integers without relying on JavaScript number precision. The per-bin activity total sums each absolute raw value over its covered hours at the series decimal scale. Timing separates storage from work such as a visitor callback, and nested storage reads are counted once. A read that requires lifetimes refuses a table that has no such summary.

Every paged log uses declared facet counts on the absolute time grid. Six-hour base buckets with no matching rows need no scan. A partial bucket reads exact rows, and a bin cut by a run boundary is complete within that run. Rows are ordered by hour, group and key. Global and per-group ordinals count from the timeline's first hour, including buckets skipped before the page. Multiple country facets can keep a row for each matching group's holder. A state table used as a log contributes each row when it was inserted. A held reader reuses its bucket walks and can advance an existing table reader or seek from a restore if that reads less. The streaming index path emits each row once without retaining it.

The tile benchmark compares current chart replies against tiles over aligned and shifted views. It checks coverage separately for views whose bins are widened to tile boundaries. Hourly comparisons reconstruct runs across tile seams and clip them to the view without manufacturing a holder segment. Mark comparisons use the chart's eighteen-pixel grouping. The timing mode requests batches of tiles on the reply threads, reports response sizes and timings, and measures opening separately from the requested view. Its timing mode probes the recording path to surface open failures and labels its measurements as fresh recording and index per batch with process-wide caches retained and an unverified system file cache, since reopening buffered handles does not clear process-wide caches or evict or verify the Windows file cache.

The synthetic query fixture starts away from bin boundaries and spans enough blocks to create a level-1 piece. It leaves some recorded hours outside the selected timeline. It deliberately gives one state an unresolved controller in chosen hours so a missing country's totals also invalidate its faction's total. These checks exercise gaps, alias and part changes, and faithful pagination from the recorder's own indexed tables. Core fixtures can supply missing cells directly, which the spool row encoding cannot represent. A branch's later segment retains its original context before a new keyframe. Product fixtures use alias IDs, omitted data and cadence anchors on neighboring tables to exercise the same identity and shared-read rules as recorded observations.

Research fixtures populate the hourly companion from the same logical observation. Three-byte synthetic tags match the engine's accepted shape, with a separate fixture for a modded tag that contains a space. The tile benchmark's separate hourly mode covers runs skipped by its equal-bin comparison. Its timing mode defaults to half the machine's threads, with at least two, and accepts an explicit thread count for constrained runs.

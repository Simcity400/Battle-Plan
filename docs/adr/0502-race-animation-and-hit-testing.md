# Draw exact race labels over eased shapes

Carry race state across frames and rerank when the input entries change. Animation identity is stable across draw frames, and the dated tag remains the identity for country lookups and interactions. An entering bar starts at its value. It eases subsequent changes only within one known recording stretch, snapping at gaps, holder changes, and new segments. Reduced motion snaps even inside a stretch. A departing row keeps its last value and a fixed goal just past the last slot as of its departure, so the fade is independent of frame rate and the row can return smoothly. The axis eases except when it must immediately accommodate a scale jump to show an entry or segment's full drawn extent. Labels retain their exact recorded value while bar geometry moves.

The rank count sets row height. Actual entries bound scroll range, and a chart with too little room scrolls the rows under a fixed axis. A visible arrival or departure can animate while rows outside both ends of that move settle at once. Draw lower rows first, so a row moving up passes over the others. Pointer hits select the topmost visible bar at the pointer and fall back to the nearest current slot where no bar covers it. A leaving or scrolled-away row cannot be hit. Keyboard interactions keep the hovered row reachable, clear a keyboard tooltip when its row scrolls away, and suppress the extra browser context-menu event after the menu key already opened the row's menu.

Scroll events supply the paint loop with offsets so it avoids a layout read each frame. Widths for tabular digits can share a cache entry based on label shape. Measure fixed names once per typography and content context, and grow columns as new amounts arrive. Separate passes for flags, names, bars and exact values keep font changes per frame small and keep value labels over passing bars. Skip a live redraw when its visible picture matches the previous one. A data-source wake still services its store when the chart is hidden, so a loading or failed chart can retry before it has a canvas size.

# Country and state capture follow their own publication schedules

## Slow tables

The collector host dispatches and assembles the Slow job. Factories read each canonical country's stored military, naval and civilian factory groups and civilian consumers hourly. Tactic unlocks are read whole every hour so the viewer can join a fresh list to its chosen perspective without duplicating the list in combat rows. Tactic registry and country pointer scratch stay private to capture. Published unlock spans belong to complete rows, and capacity demand includes rows that could not fit, even if a later read or conversion fails.

Faction theatres provide political-map pins, and the same hourly faction census supplies occupied faction advisor slots and token bytes. An absent commander is a valid observation. A job failure withholds both tables for the hour. The logistics snapshot reads the stored archetype surplus or deficit and counted stock on the first daily slot following the update. State building capacity and factory energy operands follow their daily slot, with group-specific refusals preserved. Modifier definitions are static between loader registrations. Full hours and a changed definition table pointer or count require a fresh read, with a failure surfaced for that scheduled read. The game thread supplies the current header-change flag before each dispatch. Advisory capacities grow with observed native demand and carry no row values.

## Doctrine changes

The current doctrine census seeds its baseline. Prepared receiver marks select terminal reads on the Slow worker, and parent membership is reconciled before child marks are consumed, so a retired child is no longer dereferenced. Grant occurrence snapshots retain expiry anchors. Expiry before a new grant is settled first, and later expiry counts then apply to the new row. Cost add and consumption notifications coalesce to terminal inventory after removal and compaction. The effective daily gain callback records the pre-store operand independently of the store mutex. The worker applies the last operand before later terminal refreshes, which can supersede it. Lost observation or conversion failure schedules a new baseline. The root uses the header authenticated by the tactic census. The shared projection is made on the first capture after a baseline. The spool recycles pending events and converts owned rows, and quiet hours share allocations.

The host registers `observe` with a pointer to a live `Mutex<Store>`. The callback can dereference that pointer, so the host retains the mutex from registration until all native callbacks have quiesced. `observe_cost_consumption` and `observe_gain` use the same registration lifetime and quiescence contract.

## Country stability and visibility

The Stability job is dispatched beside Slow. Stability inputs and modifier lines read the current slice, changed, new and unpublished countries, with a full read when the store cannot certify the result. The no-store inline path uses the slice. Tracked modifier keys are resolved once per definitions header, and a failed check keeps its original refusal. Writer marks use the native link-table bound for dynamic ids. The census can find new and unpublished countries without reading their stability. Capture accounts for unsuccessful speculative reads before propagating the serial failure. A country's failure before observation leaves that country's diagnostics without a contribution from previously used scratch.

Visibility provides the simulation DLC mask, active country and occupied-state modifiers, relation links, enemy lists and naval region access. The shared diplomacy walk creates both relation links and country wars, so its refusal applies to both. Other input failures stay independent. Naval region access and simulation feature switches are hourly. Quiet access can reuse a complete result while neither setter nor navy reset ran. A failed read leaves nothing to carry. Raw country visibility accumulators can carry under a matching epoch and census identity. Effective modifier definitions and eligibility still run in native country order for each hour. A lost certificate or changed census object takes a fresh observation, and an absent movement define or unit-order vector is reported as refused. Known empty links remain distinct from a failed arena.

## Supply trains

Supply train nodes, path vertices and inventory are read together for the same countries. The owner decision dated 2026-10-11 puts these decorative trains and panel operands on a daily slice, with immediate reads for new and unpublished countries and a complete read on full hours. A country census is the owner census. Part zero owns selection and the loaned fingerprint store. The one production part lets countries share route and endpoint observations. The typed fallback reads every country when it has no store. Returning an accepted failed request retains observed capacity demand for recycle and publishes no partial data.

Authenticated parent provinces can belong to another country, and a valid null province is recorded as stored. Other failed province checks refuse the node walk, with the last observation and hour copied together for diagnostics. Conversion checks that each access run exactly covers its value span, sorts by key, and refuses repeated engine ids. The spool merges complete rows for sampled owners into its held table by owner. Sliced rows never stand for the whole encoder baseline.

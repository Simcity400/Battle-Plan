# Keep recording compatibility explicit at the wire boundary

Writers publish the current format. Readers accept the proven compatibility horizon and check container signatures independently of row and spool versions. A changed or retired table is refused by name under the formats for which its contract cannot be read. Byte-boundary information can skip an incompatible row while preserving neighboring fields. A format that predates a required record layout refuses the file by name, including in recovery paths where damaged records can normally be withheld.

Prepared row and value codecs are independent of frame envelopes. Prepared endpoint patches are absolute typed patches. Recording wire deltas apply to their own operands and require the original numeric baseline and range checks. Legacy weather data can retain a temperature pass without a witness when its old checksum occupied those bytes. Current writers require the witness. Checkpoints preserve the missing witness so an unsupported temperature still refuses by name. Weather source words distinguish updated and held, with held clock words allowed only on held rows. Province accumulator keys must be positive, unique and ascending so a search cannot silently miss or select the wrong value. An empty modifier list and a refused read remain distinct.

The recorded identity is checked on write and read. Pre-mode sessions are decoded as full capture because their format recorded all tables and had no mode byte. An unrecognized coverage policy is preserved so the viewer can name it in its refusal. For unit combat references a host packet is bound to the hourly row, while a historical stamp brings its own hour. The codec refuses trailing bytes from retired packet fields.

Map presentation deltas separate the singleton key from the current field mask. The opaque packet length precedes the option tag and fields. Tests keep native null separate from absence in nested launch sources and keep independent literal-zero predecessor fields. An inserted numeric delta starts from zero, and applying it again to an existing extreme value must still honor the decoder's range checks. Direct field serialization and row-level validation have different boundaries, so movement snapshots and deltas still validate the complete row.

Fixtures use field-specific valid key extrema where enum tags leave bit patterns unused. They use current packet and display-step semantics and keep old-only words for historical paths. Truncation tests reuse the result for identical fixture encodings. Character input snapshots and deltas refuse contradictions between a reference and its operands. Current missing data, independently recorded refusals, empty lists, absent legacy fields, false settings and recorded zeros stay separate. Country appearance tests also keep exact floating-point bit patterns, including NaNs, signs of zero and infinities, and preserve the independent cosmetic color and appended 2D culture fields.

Present combat hover inputs follow the retired side parts and store detail at display precision while preserving the no-progress sentinel and exact operands needed by CAS. Current rows prefer those inputs and older ones may still supply CAS operands through historical side parts. A field-local refused input does not become an empty breakdown. Division status and panel statistics keep independent layouts so panel values do not consume room reserved for movement operands. An unjoined member can supply its own copied combat values, and it otherwise needs a division row to resolve them. Native order and repeats in movement speed keys are preserved. Naval base lists use their full native length and order. Sparse arrays preserve that length while omitting zero runs. A gap in the array is a recorded zero, and an index beyond its count has no entry.

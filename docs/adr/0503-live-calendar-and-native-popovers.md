# Place and update live controls within the native window

An open date picker follows an advancing playback value until the user navigates or picks an hour. The frame painter updates text and the row selection; changing months commits a render. Opening starts from the actual painted date. User navigation holds the hour shown, and boundary days preserve the intended time when that hour exists in the recording. The fixed calendar uses 365 days each year and displays hours 01:00 through 24:00. It shares the native reader's and viewer's epoch, and computes edge month grids in a wider range before validating selected hours. Omit Gregorian weekday headings and announce user changes rather than each automated update.

The dashboard strip renders on clock anchors and paints live text, the range input and boundary controls from clock frames. A compositor animation carries the visual playhead between anchors without per-frame DOM work. Pointing seeks to the hour under the pointer, while the keyboard uses the range input's value. Map audio follows the focused map.

Native popovers are hidden during their first layout. The next opening reuses the measured size and shows the menu within the opening task, so an immediate click hits a preset instead of dismissing the menu through the underlying page. Closed contents keep their last appearance for the exit fade. Dynamic anchors are measured at reposition, and nested menus stay in their parent element to participate correctly in native light dismissal. Ancestor toggle handlers distinguish their own element from nested controls, and manual popovers leave dismissal to their owner.

Select keeps equal replacement option arrays stable so measurements survive incidental renders. It measures all authored labels with canvas and checks drawn rows with the DOM. Windowing keeps all enabled options in native Tab order and leaves either edge to the browser. Shared interface tooltips remain on the sidebar side of a visible native child surface. They track anchor removals, visibility and size through observers, so querying a tooltip does not force layout while playback paints. Focus-driven hints wait for the keyboard focus scroll to settle.

Loadable components show their fallback until their code arrives and update ordinarily, so Suspense's fallback hold cannot delay the revealed component and its requests. Already-loaded components mount directly, and a failed load reaches the boundary for the next attempted mount. Appearance can validate authored outline icon names without importing their drawings.

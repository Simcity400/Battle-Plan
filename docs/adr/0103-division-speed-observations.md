# 0103. Read movement-speed operands only for reached route branches

The movement capture uses the status census for divisions with ordinary nonempty routes. Determine which itinerary branches can use ordinary land speed before reading state, category, supply or combat operands. A readable ordinary land edge establishes demand even if a later edge fails. A route can start with embarkation and later reach that land branch. Unblocked strategic redeployment keeps its early return. Stationary and other early-return cases publish known combat absence without reading their lists. On an ordinary edge a missing or withdrawing combat can also produce known absence. An absent outer value means a refusal. A defender needs side membership but no attacking movement word, and the first qualifying combat ends the search.

Use the expeditionary owner if positive and otherwise the roster owner while building the land keys. Transport uses logical owner independently of roster availability. Reuse the location ID from the census when supplied. Group province facts by province ID and state facts by state pointer. Determine each shared state block under its roster owner and the controller branch under the owner/controller pair. Demand the attack term separately from common state keys. Neither selected block nor branch reads unselected relation entries, so those entries cannot refuse the row. Query core supply once per owner/controller area, only where exile and noncore bypass are both clear, and keep province-keyed rows for playback.

Read each demanded combat once. Store combat movement results in census order for the common matching ordinal and keep a separate lookup sorted by division for arrivals in another order. For movement hostility, share each destination and controller/logical-owner pair within the pass, including a readable empty province slot. Only successful reads enter the memo. A transient read failure affects its mover and cannot be cached for a later mover. A failed advisory reserve leaves a subsequent duplicate to reread. River relations share one owner/controller query over reached route provinces. River crossing kinds keep a per-world memo, since map load and adjacency reload begin a new world. Tests isolate this memo per thread. Count a failed common gate during demand preparation and an edge refusal during river acquisition, so one failure is not counted by both.

Select each logical owner's transport speed under its reached sea edges or naval transfer's source region. Transfer requests do not use destination flags. Every established readable source demand survives later position refusals. Read each distinct region identity once per hour and release its pointers when the acquisition ends. A healthy route uses one bulk copy. If that read fails, retry individual positions and preserve other readable positions, routes and movers. Rows with a formed key have an independent resulting value, known absence, or counted refusal. An unreadable key can refuse before producing a row. Duplicate-key refusal takes precedence over a malformed truncation in table publication.

Use the country and speed key for each demanded unit-speed entry. Drain the writer marks every hour, including hours with no reads. Carry only entries from the current loan epoch with complete marks, an untouched country, and a held entry for the requested key. Marked and newly needed entries read afresh. A refusal of one key does not change independent entries for the same country. Acquisition times each table family and owns the observations before releasing live memory. FIFO settlement constructs rows, observer counts and the next baseline from those earlier observations only. Reuse scratch for both generations. A failed, dropped or unwound frame invalidates its partial baseline. The common frame return releases this loan even if no status-store loan was ever taken, including after a panic consumed the pending flag.

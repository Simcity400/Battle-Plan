# Track uncertain trigger effects

The evaluator retains temporary values, failed writes and the first unreproduced writer in its variable session. When that writer may have overwritten a value, an output read must refuse even if the old name now appears absent. A child after an undecided short-circuit may never execute. Preserve the distinction between a proved value and an effect that might have occurred. Count executed writes and random advances even when the new value equals the old one, because repeated control flow and scope recursion can depend on this history. Closing the context retires its active state without erasing known values. A new outer trigger starts a fresh context. A larger-stack localisation worker carries the immutable evaluator context and receives the mutable variable session separately.

A recursive trigger, role, organisation or trait can make the game fail to return. Report proven divergence through the enclosing evaluations. Keep it confined to the outer composition that reached it. A colour callback uses stricter admission than ordinary Boolean output. Capture every unavailable input it reached or that its preparation reached, including inputs whose effect later writes or Boolean results conceal. The caller withholds its target layer if that set is nonempty.

Mean time starts from the recorded or authored base. Each applicable modifier multiplies the current fixed5 value before adding its term, in order, and processing stops at the first applied zero. The conditions exclude the modifier's arithmetic fields. The modifier sequence shares one seeded temporary-variable context.

Read the base's fields in authored order starting at one fixed5 unit. The duration words use the signed native day counts and month and year multipliers. A failed factor scan leaves the prior value. An empty factor or add operand leaves the current parsed state alone, and later occurrences can retain fields from a previous parse. A final literal is exact because it returns without consulting those fields. Other repeated forms refuse by name when their retained state cannot be reproduced.

Load child keys in authored order, keeping an unknown child when its dispatch cannot be proved. Attach alternatives to the last loaded `if` when possible. The first attached `else` closes the sibling chain, while alternatives inside a conditional use their own native key handling. Repeated limits after a loaded one are logged and skipped. Evaluate only the first passing alternative, treat an empty limit as passing, and keep a chain with no entered branch true. The branch implication retains both possible outcomes when its limit is unknown. A compound operation keeps one variable-random context for its nested checks and scoped operands. On proven divergence, discard reads taken beyond it and report the enclosing refusal.

# Reuse successful attrition operand reads during one capture

The collector reads only requested accumulator and key pairs. Traversal retains the order and repeat occurrences of children and preserves stored display labels. Country attrition uses its two-level format with nonzero interior and leaf labels. Source depth and scale remain on the army operand and are independent of tree identity.

The caller supplies the request prefix and output arenas. The capture sorts and deduplicates requests in place. Insufficient request or root capacity withholds the table because it cannot publish every root identity. Other faults belong to their root. A refused root retains its identity and failure while its partial storage is returned for reuse. Known demand includes omitted output. The count-only fallback uses bounded worker stack reservation to continue past short scratch without allocating or imposing a native-depth limit.

Different keys on one accumulator revisit the same native headers, strings and entry arrays. The optional cache reuses only successful reads in the current acquisition and for the same accumulator. First reads reach the original source in the same order. A failed array lookup is reached again as a complete original lookup rather than resuming at the fault. Cache growth failure falls back to a fresh read. This preserves independent outcomes under both one-shot and persistent failures. Shared storage can survive a capture, but its contents cannot.

# 1302. Keep model queues and actor histories stable across frames

Build model groups by asset identity and cull tile, retaining producer placement order for equal assets. Binding slots may change as libraries merge and cannot supply stable ordering. Keep native submission order separately for draws whose outputs depend on it. Cull conservatively from the ground rectangle, widening for elevated models and retaining wrapped copies. The held camera gathers candidates. The current frame's native ground, distance and side-plane tests decide which model figures draw. [Camera gathering and draw admission](1390-viewer-camera-gather-and-draw.md). City sprawl and building cutoffs use height relative to water. The separate transient pass owns the ordinary map-object cutoff.

Mesh and material buffers stay immutable as placements and poses advance. Upload the library before warm draws where possible, or make newly placed meshes resident as the library grows. Treat content failures as named actor refusals and propagate unrelated upload failures. Maintain actors on append-only library growth. A seek, branch change or replaced animation history invalidates the corresponding pose generation. Reject work from an older generation. A paused or captured image makes its poses from the samples it draws. Live frames can take a completed worker set without waiting, use it across all views and passes, and evaluate actors it lacks when reached. A pose worker can deduplicate jobs by actor even when the actor has several placements.

Animation keys identify a shared player independently of wrapping and placement. The producer's last request for a duplicate key wins before redirecting by original key order. Replace old clocks completely when another field owner may have changed them. Hidden actors retain clocks and events without drawing or casting. A producer can keep a deactivated naval wrapper's explicit phase and requests alive without creating a placement. Duplicate animation calls retain occurrence order inside one player, and callbacks that intern content state names retain placement order. The native-only dispatch retains source occurrences and layout capacities across frames. Refuse the optimisation for the whole pass if any child requires a real palette and keep current sample, timing, placement and visibility inputs live. Native draws that need no name-joined palette preserve its logical offsets without allocating its ranges.

A display frame can change part placements without rebuilding the underlying group, actor or pose. Keep the animation-owned palette offset on a moved root. Default-state clocks start at appearance and restart with the presentation clock. Refuse a reachable default variant that needs unrecorded randomness. Reuse stable queues and poses where field order, group and actor identity, camera bounds and relevant draw state permit it. For repeated actors match occurrences in each field. Re-run a caster walk that reached a refusal or changed routes. New player births can invalidate individual figures, while full field changes need a fresh walk. Field comparisons ignore the previous palette offset because native draws do not read it, and all retained lists share a frame's change result.

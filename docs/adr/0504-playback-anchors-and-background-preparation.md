# Run dashboard playback from frame time and defer preparation to spare capacity

One page-local wall clock publishes positions for painting and anchors for external work. While playing, the engine advances the clock before the data and paint phases. Fall back to anchor-based reads, and let native maps advance independently between anchors. An explicit seek, including one at the same hour, must still be identifiable after coalescing. Reaching an end publishes an anchor, stepping forward retains presentation history, and stepping back discards it. Bank the elapsed fraction before pausing or changing speed. Move the clock's anchor before invoking callbacks so a subscriber that pauses cannot bank those milliseconds again.

Give moving values that require React a transition path so input remains responsive. Each update carries the value observed by its own subscription generation, and a previous subscription's update cannot become the new subscription's initial value. A view driven by recorded changes can render at the latest change hour. Restrict held pending data to its client and request owner through anchor and identity changes.

Warm offscreen rows and other pages through one prepare lane per base client. Send at most one background request while the visible page has no work. A visible request sharing a queued preparation request promotes it immediately. Caches key on the base client so a prepared read can supply the first visible render. Cancel or disown preparation work when a page leaves. When playback starts, remove the prepared copy during the play commit so it cannot commit a render as an active playing page. A prepared copy does not acquire the visible page's native follows.

The playback fixtures cover regressions where dropping a frame skipped unrequested windows, an advancing block remounted flags, a cold seek read a whole campaign, and a paged log repeatedly requested failed or short-lead pages. They also cover offscreen logs whose counts were already loaded, cleanup that could restart log requests, and country membership changes that need new selection even when a followed panel's body is unchanged. Fast playback should draw updated values into existing rows, with work bounded by the reached windows and lookahead. A failed log page reports its error until retried, even if its count was readable.

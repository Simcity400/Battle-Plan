# Separate interface rasterisation from desktop scaling

Layout uses logical interface pixels. Projected anchors are divided by the effective GUI scale, while `.gui` sizes remain as authored. Matching the game uses the effective settings and display in SDL order and preserves its native window-size raster. Windows display scaling then stretches the already blended image with linear filtering, which preserves one-texel features. For hit tests, reverse the display stretch before applying camera or interface transforms. Egui sizes convert from interface pixels through the frame's GUI scale and the platform's device pixels per point. Dumps keep the native frame size and independent GUI scale.

Display enumeration runs on a worker because enumerating adapters on a display frame costs time. Each installed monitor list increments a generation the viewer can use to refresh its resolved scale. A refresh arriving during a pending read is serviced again before the worker goes idle, including the race just before it clears its running flag.

Viewer GPU tests serialize through a single device guard. Overlapping WARP devices in one process were observed faulting, while the viewer already uses one shared device. Hold the guard from device request through readback. The test hang guard bounds deadlock detection without measuring completion time on a busy machine. Shared test fixtures exercise the production content-stack loader for localisation and use differing raw country references and canonical slots to catch identity confusion. The GUI fixture can defer pointer geometry until a hover test supplies the physical viewport. Explicitly refused sheets and runtime-only sprites let a fixture distinguish content and session lookup gates.

# 0206. Keep production acquisition equivalent across split and raw paths

The daily production slot reads industrial organisation rosters and output histories in array order from one walk. Each policy's cost modifier is read on every visit because it can change independently of its roster. A failed scalar stays unknown without compromising the roster. An out-of-bounds arena span withholds the affected table, and a truncated walk retains its truncation and sizing demand. The worker accounts for nested capacities and leaves hourly pool accounting constant-time. Default placeholders own no allocation while the worker owns the capture buffers.

Production-hover data is acquired independently of the ordinary census. The formatter uses the shared caller-owned tree reader. Root refusals retain their original reasons, and pressure is kept for off-slot growth. Attrition modifier demand sizes army hovers only. With enough producing countries, the daily reader divides the work into consecutive census ranges. It reads shared defines once, lends each extra range to a prepared worker, and reassembles by census slot. The first failure in slot order is the failure the unsplit walk would have reached first. A capture with no producing country uses the default context and publishes no rows. The next split uses country and line counts from the last complete capture. An incomplete capture leaves the preceding split available. Synthetic parts exercise this handoff independently of the native walk.

Production and division detail paths skip their corresponding typed walk only after obtaining a valid raw payload. The worker interprets owned copied spans with the same checked readers and installs the same rows, arenas and outcomes before handoff. It clears the per-hour mode after decoding. Exact, complete fresh rows may compare directly with their encoder baseline before allocating equivalent replay rows. A partial source, invalid arena span or uncertain certificate cannot prove equality. In that case acquisition and conversion use the ordinary full path or withhold the affected table by name. Native-order traversal preserves the associations between variants and their modules and context. Normalization sorts owned definitions only after that work is complete.

A failed recovery consumes its immediate request but leaves missing proof to be rebuilt on a later daily visit. Any unobserved interval withdraws the earlier object evidence. Hash-consed bonus values are immutable, so a design retains the exact snapshot it held, including repeated sources. A longer complete prefix of the append-only cache is a later snapshot; equal values share stored payloads.

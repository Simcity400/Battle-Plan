# Measure content-reader coverage in reproducible mod stacks

The corpus runs the viewer and dashboard's actual content readers and preparation against vanilla and then one stack per installed mod. Each stack uses the enabled DLC and its installed dependency chain in mount order. The real installation stays read-only. A scratch user folder reproduces the launcher inputs, including game language, enabled mods and rewritten descriptors. Workshop identity deduplicates a separate descriptor pointing to the same item. Missing or ambiguous display names leave their dependencies out and recorded by name. The rewritten descriptor must parse to the same fields, preserving field ordering and quoted or bare values. Each stack keeps its own gather hash cache because the gather step rewrites it.

The corpus uses the configured client texture decode settings and language. It exercises the same GUI, equipment, movement, combat, trigger, map and sound preparation as the consumers. Independently unreadable subdomains keep separate diagnostics. Readers whose prerequisite refused the stack are marked as skipped by name. A native GUI read can leave the rest of a file unknown, while a reading-client setting unavailable to an offline corpus is annotated separately. DLC and mod audio is decoded; vanilla audio is located. The state history listing uses the reader's affected states and diagnostics, so a consumer's notes cannot invent an affected state.

The output manifest lists the stack reports produced by that run. Diagnostic kinds preserve the producer's distinction between a refused stack, an unsupported form, unsettled content, an ambiguous answer, a documented game misread, a logged error and a presentation fallback. A documented parity finding and an offline dependency remain distinguishable from findings to investigate. Locations and normalised causes help group diagnostics without losing the underlying message. Normalisation masks paths, quoted text and standalone numbers. A path can contain spaces, and list separators end a path. Comparing runs uses multiset differences. Changes to counted examples and aggregate inventory growth update totals without changing a diagnostic's identity. Typed value formatting orders unordered containers and retains the order of sequences.

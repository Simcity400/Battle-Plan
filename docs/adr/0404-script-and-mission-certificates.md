# Certify persisted script stores and mission registrations separately

Script flags preserve the native row fields and order for global, country, state and character managers. Certificate coverage includes scoped set and duration operations, playthrough flags, load, expiry and both targeted and full clearing. Row-array assignment reaches the embedded array and is mapped back to its manager. Allocation, release and destruction can replace storage, and a lifetime change must invalidate the old certificate. Expiry decrements positive remaining durations before removing expired rows. The writer observes the manager after a complete operation rather than trying to read a partially written row.

Script variable retention covers the same persisted scopes, their key and value rows, and the store's seed. Scope-aware mutable access can insert a row or change an existing value before returning. Array and scalar removals reach the erase path. A release names the embedded hash table and must be mapped back to the owning store. Country, state and runtime resets invalidate the relevant persisted stores. Save loading and world epoch changes cover lifetime replacement. The thread-local temporary store has independent writers and does not enter the recording. A context end can change a persisted seed only when active, enabled for a seed change, and backed by a store. One cannot infer a persisted write from the temporary path.

Air registration invalidates the owning country air object at registration and unregistration. Registration appends the mission to the selected regional list and the all-active list and inserts its active-region key in sorted order. Unregistration removes matching occurrences, shifts their ordinals, and drops an emptied regional key. Mission region changes reach these writers through the wing and its pool owner. A same-region change reaches neither. Capture retains the resulting native order and resolves a mission's wing using the hourly wing census. A load invalidates the relevant epoch rather than certifying retained mission pointers.

# Resolve time chart interaction against the frame shown

The time chart keeps a series canvas and a separate overlay for the crosshair and selection. A stable series data identity and frame produce no series paint. Live playhead and tile updates can paint between React renders, while frame callbacks batch React updates. Changing branch or extent resets zoom. Ease the distance to the target and snap within half a rendered pixel so large absolute hour numbers do not jump hours or keep the frame loop alive after motion stops. The last scheduled frame paints the exact fitted scale. [Time chart](../../ui/src/charts/TimeChart.tsx)

The branch start anchors persisted axis offsets. A viewport fit fills only axis bounds left open by settings. Log axes fit below the smallest positive value. Tick precision can see the whole set so adjacent labels stay distinct, and tick layout's independence from left padding lets the widest label size that padding. Draw dates from the recording calendar, with the hour as a fallback when a calendar date is unavailable. Held runs preserve exact steps and leave recording gaps open. Chart lines clip to the plot. [Time chart](../../ui/src/charts/TimeChart.tsx) · [Shared drawing](../../ui/src/charts/draw.ts)

Use the same resolved hit for hover, pick, and context menu. The crosshair sits at the hovered or keyed hour while the tooltip describes that hour. Pass the full sorted stop set so a held value crossing the view's left edge is still reachable. Following cuts hits and requests at the playhead, unless whole-campaign playback explicitly exposes later hours. A view fully beyond that cutoff has no candidate. A click picks immediately and its second press never picks a second time. Use the axes or reset control for zoom reset when click already acts as pick. Restore focus when default pointer behavior is suppressed so Escape still resets, and open only one context menu for the menu key. [Time chart](../../ui/src/charts/TimeChart.tsx)

Resolve a stationary pointer on each frame so its hover stays current, but request exact hover facts only after it rests. Deduplicate callback notifications across React renders. The callback that was notified owns its outstanding facts and releases them, even if the current callback has changed. Enter or Space picks the shown hover hour or playhead. A pending pick is scoped to a source, selection and numeric model identity that is independent of playback and label updates. The keyboard can take over after a fresh key action. A delayed result may claim the shared tooltip only if no later pointer action has moved its revision. Speak tooltip text only when it changes, and remove an inactive chart's tooltip. [Time chart](../../ui/src/charts/TimeChart.tsx)

Request summaries on whole hours using the measured plot width and playback cutoff. Coalesce requests and viewport callbacks during continuous movement, then send the settled range. Keep a compatible prior summary at its own hours until the next arrives. A view callback hears the current range on replacement and sees only changed ranges thereafter. [Time chart](../../ui/src/charts/TimeChart.tsx) · [Chart summaries](../../ui/src/charts/chartSummary.ts)

Scale vertical wheel zoom by delta so trackpads can move fractionally and mouse notches still make steps. Match a fractional viewport start to the hour a pointer at that edge would show. Memoize the sorted stop list by data, viewport and cutoff, and retain the logical keyboard anchor when it scrolls out of view. A physical pointer press resets menu ownership after a keyboard-generated menu. A track jump is available only within the branch, and ordinary row activation stays native. A deferred click retains its original drawn callback and geometry. Later playback or label changes under the same owner do not change an accepted actor, and replacing the numeric model invalidates the waiting click.

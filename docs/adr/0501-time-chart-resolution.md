# Resolve time chart interaction against the frame shown

The time chart keeps a series canvas and a separate overlay for the crosshair and selection. A stable series data identity and frame produce no series paint. Live playhead and tile updates can paint between React renders, while frame callbacks batch React updates. Changing branch or extent resets zoom. Ease the distance to the target and snap within half a rendered pixel so large absolute hour numbers do not jump hours or keep the frame loop alive after motion stops. The last scheduled frame paints the exact fitted scale. [Time chart](../../ui/src/charts/TimeChart.tsx)

The branch start anchors persisted axis offsets. A viewport fit fills only axis bounds left open by settings. Log axes fit below the smallest positive value. Tick precision can see the whole set so adjacent labels stay distinct, and tick layout's independence from left padding lets the widest label size that padding. Draw dates from the recording calendar, with the hour as a fallback when a calendar date is unavailable. Held runs preserve exact steps and leave recording gaps open. Layers can nominate their own unavailable spans when several products share the plot. Unknown spans hatch and report their status. Preparation extent and recording gaps have separate meanings. Chart lines clip to the plot, and end labels can move with leaders while keeping exact value suffixes. Use the same resolved hit for hover, pick, and context menu. The crosshair can sit at a clipped bar or snapped position while the tooltip describes the bar's recorded hour. The strip uses its own hit rule, remains time-only during box zoom, and contributes keyboard stops alongside plot stops. Pass the full sorted stop set so a held value crossing the view's left edge is still reachable. The categorical row plane uses Up and Down for rows while horizontal keys retain the time stops. Following cuts hits and requests at the playhead, unless whole-campaign playback explicitly exposes later hours. A view fully beyond that cutoff has no candidate. A click picks immediately and its second press never picks a second time. Use the axes or reset control for zoom reset when click already acts as pick. Restore focus when default pointer behavior is suppressed so Escape still resets, and open only one context menu for the menu key. [Time chart](../../ui/src/charts/TimeChart.tsx)

Resolve a stationary pointer on each frame so its hover stays current, but request exact hover facts only after it rests. Deduplicate callback notifications across React renders. The callback that was notified owns its outstanding facts and releases them, even if the current callback has changed. Enter or Space picks the shown hover hour or playhead. A pending pick is scoped to a source, selection and numeric model identity that is independent of playback and label updates. The keyboard can take over after a fresh key action. A delayed result may claim the shared tooltip only if no later pointer action has moved its revision. Speak tooltip text only when it changes, allow separate stops at the same hour, and remove an inactive chart's tooltip. [Time chart](../../ui/src/charts/TimeChart.tsx)

Draw and announce event badges from the same visible set. Compare drawn badges by identity and content so a pan with unchanged badge count still updates text. Dense summaries place clusters by screen width without holding a campaign-long event list. Reached exact event rows and keyboard stop queries stay separate from display geometry. Event hit testing groups only the nearest event hour even if several dates overlap onscreen. Occasional inventories can be revised by later preparation and are signalled as approximate. A reached capitulation names its actor at the event's own hour. [Time chart](../../ui/src/charts/TimeChart.tsx) · [Event badges](../../ui/src/charts/badges.ts)

Request summaries on whole hours using the measured plot width and playback cutoff. Coalesce requests and viewport callbacks during continuous movement, then send the settled range. Keep a compatible prior summary at its own hours until the next arrives. A view callback hears the current range on replacement and sees only changed ranges thereafter. Scale vertical wheel zoom by delta so trackpads can move fractionally and mouse notches still make steps. Match a fractional viewport start to the hour a pointer at that edge would show. If two distinct stops share an hour, the chart's own stop precedes the strip stop. Memoize the sorted stop list by data, viewport and cutoff, and retain the logical keyboard anchor when it scrolls out of view. A physical pointer press resets menu ownership after a keyboard-generated menu. Chart gaps cover their inclusive lost hours, through the boundary following each lost span. A track jump is available only within the branch, and ordinary row activation stays native. A line pick uses the rendered path, including held vertical edges. When lines coincide within a stroke width, offer the matching actors instead of guessing one. Keyboard picks lack a screen ordinate and offer all actors at the chosen hour.

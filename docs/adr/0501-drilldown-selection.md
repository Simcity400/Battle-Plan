# Separate drill state from playback and preserve access to exact parts

Picking a date updates the drill's state while the campaign clock continues independently. A new drill follows playback until it has a date selection. A whole-campaign view with no playhead retains the chosen date. Keep the drill view and beside-widget panel on the same controls and data rules. Start the slide immediately, then mount the expensive breakdown a frame later. Measure a side panel as it places so it follows its parent during scroll, and allow clicks a widget uses to pick without dismissing its own panel. A drill opening in-widget moves focus to Back when the main view becomes inert. Escape closes either surface; restore chart focus only while the drill owns it. Hold the latest popover methods in a ref so new method objects do not replay the open/close effects. [Drill host](../../ui/src/charts/drill/DrillHost.tsx) · [Drill state](../../ui/src/charts/drill/drillState.ts)

Keep exact signed part amounts and recorded game or replay labels. Render a separate unexplained row for missing attribution and omit a percentage for an incomplete total. Corrections remain selectable even when they have no positive bar geometry. A part can opt in to native row activation, while residual and refused IDs remain unselectable. Paint live amounts between renders and change React row structure only when membership or ordering needs it. Share the cell formatting between render and paint. Release mounted-row reports with their retained identities so a replayed effect reports the rows again. Full inventories stay navigable through viewport rows and fitting must preserve the full spoken metadata. [Fuel detail](../../ui/src/widgets/fuel/fuelDetailProjection.ts) · [Drill parts](../../ui/src/charts/drill/DrillParts.tsx)

An open follows a known playing head or a date within 45 days of it. Otherwise the chosen date stays pinned. Pinning as a widget copies the campaign, tracks, countries, time, and content scale, selecting the same breakdown through the widget's ordinary Show option. The catalogue and pin action use the same naming rule. Placement considers only the existing layout breakpoints and preserves the intended slot against compaction by moving an adjacent widget out of the way.

# Separate drill state from playback and preserve access to exact parts

Picking a date updates the drill's state while the campaign clock continues independently. A new drill follows playback until it has a date selection. A whole-campaign view with no playhead retains the chosen date. Keep the beside-widget detail window on the same controls and data rules, anchored to its parent widget. Escape closes the surface and restores focus while the drill owns it. [Detail window host](../../ui/src/families/host/DetailWindowHost.tsx) · [Drill state](../../ui/src/charts/drill/drillState.ts)

Keep exact signed part amounts and recorded game or replay labels. Render a separate unexplained row for missing attribution and omit a percentage for an incomplete total. Detail part lists and histories render through the table and time-chart families inside the detail window. [Stability detail](../../ui/src/widgets/stability/stabilityDetailProjection.ts) · [Fuel detail](../../ui/src/widgets/fuel/fuelDetailProjection.ts)

An open follows a known playing head or a date within 45 days of it. Otherwise the chosen date stays pinned. Pinning as a widget copies the campaign, tracks, countries, time, and content scale, selecting the same breakdown through the widget's ordinary Show option. The catalogue and pin action use the same naming rule. Placement considers only the existing layout breakpoints and preserves the intended slot against compaction by moving an adjacent widget out of the way.

# 0203. Refresh retained intelligence from writer observations

Saved network membership comes from the existing authenticated census. A census grants one preparation attempt. Duplicate or partial membership data cannot carry over a successful grant to a later ordinary hour. Callbacks mark receivers in prepared lanes, and the worker alone reserves replacement storage in response to observed demand. Published lanes stay pinned until hooks are restored and callbacks quiesce. A lost event or incomplete membership revokes the current certificate. An ordinary hour does not respond by polling every owner.

Propaganda histories use daily append observations. The worker retains their logical order, keeps history keys stable when adding the same value to a full ring leaves the history unchanged, and reads the ring once when several writes precede one cut. The daily writer certifies the weekly sum. Loading can restore an independent weekly cache, so a newly read header preserves that value until the next daily writer produces the sum. The header uses a key beyond all real history sequence numbers. A load or refresh reads this state alongside the strategic census, including saved slots without current countries. Manager membership changes also trigger enumeration. A fully observed quiet hour skips both enumeration and retained owner history reads. Publication failure revokes retention and identifies the first writer refusal in diagnostics.

The source-state worker retains independently observed setters, decay and arithmetic. It reads only the affected native payloads when independent replacement or merge events need them. A daily writer that clears a vector supersedes an earlier replacement for that vector. An empty pending merge leaves retained accumulation unchanged and needs no native result read. Token-manager and reference lifetimes can change even when the embedded address is reused. The worker reads final reference state for a forced cut and does not let an older event overwrite it. Load and prune rebuild ID selection in ordinal order, with the final occurrence winning. When a reference index is swapped, the writer increments its flight count before reading it, which permits the worker to retire the old index once no callbacks remain.

The acquisition layer transfers certified changed rows by moving their existing native vectors. Quiet cuts share a handle without projection or copying the table. Spool projection sorts replay keys, checks duplicates and can prepare an unadmitted snapshot while reclaiming the original native allocation. Failed advisory allocation preserves that acquisition for a later retry. The worker neither enters projection's lock nor substitutes an empty named result when projection is incomplete. An actually observed empty membership can establish an empty baseline.

Operative trade opinions are read live per owner and target each hour. The printed breakdown retains just the source tree values visible in its output. The worker can leave unrelated zero sources out of that comparison and sweep held entries when some were untouched. The accounting snapshot is updated when that held storage changes.

# 0203. Carry governance rows under read certificates

A successful governance walk can retain Politics, PoliticalParties, ActiveIdeas and PartyLeaders as one set. Reuse avoids repeating the same country reads in quiet hours. The walk records the observation keys and scope before its first read or registration. The next hour must request all four tables, match the held census in order, match the structure, party and party-leader keys, and still hold the character certificate for each listed leader. The character domain changes frequently, so the walk checks certificates per character. Idea definition tokens are fixed within the session.

The political-status structure key covers capitals, election data, ruling party and the party and idea arrays. The separate popularity key covers the daily politics update and explicit popularity writes. A popularity change by itself triggers one guarded gather of the held parties' popularity. The gather updates the retained rows only when it succeeds. A failed gather, an incomplete walk, invalidated observations or a forced full read falls back to walking the affected tables. Capture accepts an authenticated census from the hourly boundary. Unrelated tables in the country loop still run.

The held copy is advisory and belongs to the party store. A failed governance job or candidate retention allocation discards its ability to serve a later quiet hour. Publishing a quiet hour leaves the party and party-leader stores' previous walk intact for later per-country reuse. The stored visit ranges identify each country's output rows and string arenas. A stored party row and the original party pointer must agree one for one so a later popularity gather updates the right row.

Party and party-leader observers record the duration of native writes in an allocation-free guard. A disabled or poisoned registry, refused registration, running writer or lost epoch forces a read. The hourly boundary invalidates observations on a load, gap or recovery. A full walk supplies the off-thread sizing demand for its registry. The first table can be installed as soon as it is offered. A replacement waits for an invalidating hour, and the worker frees the replaced allocation off the game thread. Party changes address watched parties and register political status for ActiveIdeas. The latter has no writer notification in this domain and is tied to the epoch. Party-leader changes also track the relevant character and forward the ruling-party leader observation to the stability inputs. A transfer invalidates both parties.

The `Hooks::drop` implementations in `party_changes` and `party_leader_changes` release their watch registries only for families that were never enabled or after removal and draining following the last capture. The same ownership boundary governs the hook relays, so no live callback still holds a watch table when it is freed.

Research and technology acquisition can reuse a certified roster on a scheduled slice while reading live progress and banked days. Research slots and technologies change their selection under separate writer marks. A technology slice must have the paired ResearchSlots data to certify its held roster. Without a complete hold or observer epoch, the next read covers every country. Changed roster data triggers a full read. Focus progress drifts on the daily tick only for countries that own a state. The daily boundary also reads owners that gained or lost their last state, and a writer mark causes a read within the next observation hour. Timed ideas remain on their own hourly cadence.

A carried research roster reads drift in the full walk's acquisition order, including one progress read for a technology assigned to multiple slots. Publication sorts slot rows by native slot index. A gather can consume a one-shot read fault. The fallback tries the original serial read once and may publish fresh rows if it succeeds. A persistent fault must give the full walk's unavailable outcome and reason. Tests compare emitted rows with an independent per-country walk into fresh buffers, using distinct values for each country to expose overwritten or misattributed output. A failure in the family or a separately loaned research part does not erase the other part's rows. The tests derive expected failure versus cadence skip from the actual cadence.

Power-balance capture reads the source roster. Playback derives the description trees from the recording, so an unreadable cached tree does not withhold a readable source roster. A `breakdown_witness` build additionally captures a native tree sample only when the record is in its selected slice.

The politics fixture reserves a distinct region for each country and starts with only two of three positive slots occupied, so tests can authenticate a new country without relying on a politics notification. The research fixture gives each country different technologies, progress, modifiers and bonuses, and enumerates slots in a different order from output. Its sparse module window shadows overlapping heap addresses, and scaled fixture objects skip that span. The `research_quiet_hours_bench` test belongs to `collector-governance`. It compares synthetic 446, 1,500 and 5,000 country worlds with all owners drifting, a one-sixth drift case, and the authenticated roster view. Each run measures one full hour and 24 unmarked hours.

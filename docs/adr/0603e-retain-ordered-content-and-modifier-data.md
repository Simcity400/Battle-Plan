# Retain ordered content and modifier data

Keep frequently queried content in an ordered buffer instead of materializing its full table on startup. The buffer begins with a count and stores each distinct key before its value. A lane of cumulative end offsets identifies alternating keys and values relative to the payload. Sort by key bytes so loading can read the count and bounds alone and lookup can decode only the keys visited by binary search. Refuse impossible counts and out-of-range or reversed offsets as damaged data.

Content reader tests use the viewer's allocator so their allocations follow the shipped runtime's behavior.

Scripted modifier display definitions come from the mod stack. The recording retains the executable's built-in modifier metadata. Scripted definitions use a fresh reader per key, retain the first registered identity under ASCII folding, and keep registered byte names even when they cannot be rendered as UTF-8. Digit or minus prefixes are refused for this registry. An unread suffix can conceal another registered name. Color and value options accumulate flags, whereas a stored postfix replaces the previous value and `none` leaves it alone. Precision starts at two, preserves a negative authored value to trim trailing zeroes, and survives an unsuccessful scan unchanged.

Modifier values and their tooltip order are separate concerns. A repeated numeric modifier replaces the value in its original position. Hidden modifiers remain in the object and a stored zero still counts as present. Custom tooltip text is deduplicated by exact bytes with a case-sensitive hash and listed in native slot order. Copying and growing the table preserve the expected reinsertion order so tooltip display remains stable. Conditional modifier inheritance queries eligibility only on the branch it actually uses. An unread or unavailable roster can make the modifier reader's choice unresolved and must not become a known miss.

Organisation trait lookup walks ordinary traits in creation order. Initial traits remain separate. Relative anchors use the first ordinary trait of the given name. An absent anchor supplies the zero offset, while a cycle is refused. An appended override cannot replace a same-ID local trait in first-match lookup, and inherited copies do not carry their source's deletion list. A local equipment or production bonus category replaces that entire inherited category. Otherwise eligible bonuses combine in first-insertion order with native fixed-point arithmetic. Research category lists append and an unset list can copy the included organisation's current list unless it was deleted.

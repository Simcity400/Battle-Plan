# 0805. Preserve writer order and separate saved rows from event witnesses

The peace oracle compares saved bids independently of retained settlement outcomes. Use the writer’s group order and count only groups with actions. Across outcomes in one tick, native event sequence and transfer order determine the final state owner and subject recipient.

Conference queue cleanup runs before advancing the first remaining conference. A finalization can already be recorded while its conference remains resident, so a later disappearance can match that witnessed publication. The match must remain inside the relevant drain, or a busy interval specifically witnessed by the collector. A gap at branch start or explicit event loss can leave a finalizer unknown. Other losses and delayed publication do not extend coverage.

Modifier definitions have no save counterpart. Validate the captured table’s structure, including the shared eligibility callback, and report the lack of a save witness. Appointed advisors do have an hourly save projection. Compare ordered character and slot occurrences and resolve each idea through the saved advisor role for that character and slot. The role supplies the idea because the appointment payload omits it. Idea text is empty-omitted and invalid ordinals cannot establish an ordered comparison.

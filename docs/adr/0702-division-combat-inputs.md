# Division combat acquisition preserves source selection and failure order

Acquire native operands while the combat membership is authenticated. Leave composition of displayed combat values to playback, and reuse strength and organisation already recorded for the division. A successful read retains the division, handle, and stat-block identity only for the current pass. The name and commander reads depend on the captured name member and group pointers. Guards authenticate a group before consulting its leader, even when both reads share a scatter.

The division owns the stored equipment-category mask in its stat block. Record the mask directly so a trigger can intersect it with its own categories. Armour, piercing, and anti-air supply the modifier icons. Positive direction words group attacking divisions. Retain fixed-point defence, breakthrough, hardness, soft attack, and hard attack in that order. Record the strength factor for the committed row, fuel and capacity for its fuel icon, and reconnaissance and initiative separately. Keep the four scales in attack accumulator, defence accumulator, attack base, and defence base order. Record the direct formation leader's complete handle, with zero for no group or leader.

Name spans refer to the caller's arena. If the name or group key does not fit, count the needed bytes and withhold that row for the hour. Historical names can share a group key. An explicit override uses its stored text, and a programmatic member selects its stored text when it has no group. A full naming cache still reads fresh inputs. Test comparisons use old scalar readers to check the order and contents of the gathered reads and use immutable synthetic graphs for the scale measurement.

For reinforcement and width, copy modifier keys together with their raw definition metadata and the feature flags. Capture the cached base movement speed before terrain adjustments. The owner is the positive expeditionary country when present and the roster owner otherwise. A selected leader source distinguishes no block, the ordinary movement block, and the separate headquarters block. Runtime accumulator pointers identify acquisition sources and stay out of the recording. Eligibility distinguishes a null callback from the authenticated flags getter. Read complete modifier vectors so an unreadable or malformed suffix can still refuse the value. Batches keep stack use bounded without limiting the number of entries. Preserve a checked-address error at its original ordinal, after the readable prefix. Failed or partially copied spans are never retried.

An exile row is possible only for a committed division whose template has origin value two. Values zero and one are master host and subject. Other origins follow the ordinary-owner path. A positive template country takes priority over the fallback. Resolve the exile country before reading its diplomacy status, and report a named failure if either read fails. Spans hold the location state's cores and the exile country's full occupier list. Validate both list counts and their combined destination before copying either list. Signed nonpositive counts hold no entries. A count larger than the live country table is invalid. If validated lists exceed the arena, report required capacity for growth off the game thread and withhold the division meanwhile.

An acquisition pass shares the country census, definition metadata, and template width terms. It reads the division's identity, ownership, base speed, and template pointer separately. Capture width terms in template order, retaining the first read that failed. Each division checks its own name arena between the template's width count and payload reads.

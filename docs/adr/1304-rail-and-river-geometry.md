# Rail and river geometry preserves authored order and recorded topology

**Status:** Accepted

Railways read the hour's directed edges, supply sources and naval-base members. A missing network or incomplete naval hash can change the selected graphics anchor, so the viewer does not reconstruct it from scenario rails or province centroids. An admitted harbour payload selects the port anchor even at zero base level. Hubs and ports use content-declared spawn slots. An ambiguous slot provides no anchor. Fixed geometry is cached outside the hour and an hour's build examines its affected graph. A changed edge or port can also change a neighbour's run, since each run considers triangles and neighbour anchors. A build runs outside the lock and the last publisher wins.

A rail province joins neighbour pairs that do not complete a triangle, using the lower edge level. Endpoints and supply sources have short spurs to their anchors. Crossings derive from adjacent boundary pixels and smoothed river geometry. Scanning bottom-up assigns a boundary pixel to the lower province ID once. The boundary calculation uses its largest eight-connected component and rounds the sum of fixed-point per-point quotients. The authored endpoint ordering and nearest-end tie order stay intact. Cubics use three-unit handles with straight sections and gaps at bridges. Strips are one world unit wide. Height reads are bilinear with the half-pixel convention and a water floor. Railway texture and bridge artwork resolve from the presentation layers.

Trains follow the rail's centre-line geometry and the same water-floored heights before the strip's lift. A terminal spur can run in reverse. An absent segment stops a planned route before that province, and an absent first spur suppresses the route. A camera cutoff fades the rail over time without changing its width. The first frame, a still capture or a backwards replay clock takes the settled opacity. Trains and rail draw only at or above the same minimum visible opacity.

Province runs and bridges preserve their respective province and pair ordering. The packed rail vertices duplicate route ends for strip joins. Strips share one index list with restart indices. Prepared immutable rail buffers can be built with the hour or installed later from the same CPU product when a device becomes available. An install adopts buffers without copying and the host retires displaced banks off the window thread. The upload oracle reads the actual payload. Pipeline warming keeps compilation out of draw frames.

River tracing starts with source pixels in bitmap order and visits cardinal neighbours in the native order with a clamped seam. It carries a palette-derived width. Junction passes repeat until no remaining junction touches traced water, so a tributary of a tributary can connect. A junction starts on the stream it joins and initially carries that stream's width so the ribbon meets the water at full width. While still on the marker, the walk skips traced neighbours. Once it reaches a body pixel it diagnoses and stops a circular walk. Greedy tracing does not fork, short walks are dropped, and unreachable body pixels are reported separately. The equal-key junction order stays stable because ribbons can overlap. Bitmap input uses top-down rows and world coordinates use bottom-up centres.

River ribbons apply one forward in-place five-point mean with two endpoints retained on each side. Preserve the float rounding in the height sampler's texel-centre arithmetic and the widening's double multiply before narrowing. Heights use the terrain's bilinear sample without a water floor. Paired vertices carry position and end fade separately from texture coordinates and flow direction. The along-flow coordinate retains the original point index after smoothing or simplification. End fade distances resolve `NDefines.NGraphics.RIVER_FADE_FROM` and `RIVER_FADE_TO` from the applicable content stack (withholding river ribbons with a named diagnostic when missing, non-numeric, or non-decreasing instead of aborting map load), accumulate centred tangent lengths in double precision and taper at the source's first or junction's last end. The last vertex pair reuses the previous tangent and offset. The coarse ribbon retains deviations in position, width, height and fade. It retests both rails with the tangents they actually draw, measuring fade at each rail. A split changes the span against which its removed points are measured. Where simplification saves too little, both levels draw the fine strip.

River and rail use recorded effect definitions, with an applicable visual replacement preferred when it can be drawn. Shader constants retain the source programme's initialized ranges, including inherited pixel slot state. The high and low river techniques select corresponding diffuse and normal maps. Masks share one texture, with bank blend and opacity in their authored channels. Rivers upload the static geometry once per document and change only the selected range and pipeline on draws.

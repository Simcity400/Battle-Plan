Project and history rows are hourly. Programs and breakthroughs compare at their own daily refresh. A scientist’s serialized character country is independent of its roster container and requires a positive reference. Specialization experience follows its positive gate. Resolve the runtime program hash index to an actual saved definition. Every required row needs a corresponding saved full reference, and every recorded row needs an admitted saved raid. Speed operands, player interface state, and some tooltip families lack saved witnesses. Validate their structure and name the missing evidence. Saved name bytes include the final chunk’s zero padding, while the ship’s retained display text requires a matched native hover.

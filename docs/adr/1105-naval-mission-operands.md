# 1105. Prepare naval mission operands before placing mission windows

## Decision

Resolve naval mission membership, conditions and hover text from the recording at hour preparation. A camera update reuses those decisions. The regional map view can request the dominance sources for a single region and gets the same result for that region as the whole-hour query. Keep hover text semantic until the view supplies its language. Escort task-force descriptions precede country sources.

## Consequences

- The distance lookup uses the recorded map's load-time geometry and port sea provinces. Geometry and ports have precedence when reporting missing range inputs. The shared distance matrix initializes once for that content. Another preparation can use its own matrix if the shared one is in use. The range calculation consults the navy's hubs after establishing a home base and accepts a lake as a source when its land bit is clear. Missing region terrain follows the lookup's `ocean` default.
- The escort calculation keeps original ledger positions, including other mission kinds and repeated registrations, because its callbacks use indexes into that ledger. If a task force has no fleet, it returns a full value before examining the other inputs. Join ship and sub-unit classes through lexer tokens. A class absent from the class table uses common values. Combine the raw accumulator terms before clamping and exclude the added-modifier children from the merge.
- Convoy spotting applies fixed-point truncation at each original step. Its kind indexes are ordered trade, ordinary transfer, invasion transfer. Its first convoy-design values are visibility, surface detection, submarine detection and speed. The task-force detection already accounts for carrier aircraft and its detection modifier. The night description is gated by the preceding spotting factor.
- Patrol derives each carrier's contribution from its aircraft-to-capacity fraction and preserves country and wing occurrences, including repeats. Spotting and radar use the viewing country's registered pool, including its own occurrence counts. Wing effective country, controller shares and allied pools belong to the separate air-strength query. Known no-home and unresolved base references use the native no-home result. An unapplied night marker is a known empty accumulator, independent of the longitude offset and local hour. The night accumulator accepts all categories and excludes category-less static entries.
- Regional grids admit one resolving live raider target even when another target is unknown. The alternate searcher test follows the searcher's roster owner independently of ordinary visibility. Prepare only reached regional controls and require a complete ship census for their counts. Local selection can reorder or restyle those items without changing membership. Relayout moves the status row and all three grids before centering the window on its region anchor.
- Regional handlers are inherited by the controls actually presented. Container membership selects the regional handler branch. Port spotting descendants inherit the host handler and only the exact bound controls select special branches. In either view, the authored object's hit predicate controls admission, so an opaque control can win the hit without an applicable mission handler.
- Repair text uses the shared capacity calculation and keeps the authored text colour when there is no native override. A missing recorded row remains a named unknown even with a complete slice witness. A recorded source that contributes zero participates in the aggregate with that value.

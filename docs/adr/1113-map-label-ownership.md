# Stamp map labels with settled hours and perspective

Build label candidates from recorded positive victory points and capital state evidence. The highest linked raw country ID with a qualifying row supplies the capital and the original-or-own tag under the full-hour path's ordering. Only the state's controller's current capital can carry a star, and only a unique province with the highest positive victory points can receive it. Explain ties, missing rows and names that the text port cannot lay out. Withhold labels when Provinces, CountryLinks or Countries are incomplete.

Keep reverse indexes of raw country links, canonical country data, stars by state and candidates by controller. Update only the candidates that read a changed value. Changing the viewed country updates its tag and war sides. A gap-message change also invalidates refused candidates. Hidden labels release their table inputs and are rebuilt when those inputs return. The side stages the label data, and camera-bound layout consumes it without a layer GPU upload.

Attach the branch, viewing country and settled hour range before publishing the layout product. A refused or unfinished calculation cannot claim even an empty label product for an authoritative hour. Tests keep the previous allocation alive when checking publication identity so allocator address reuse cannot stand in for the wrong product.

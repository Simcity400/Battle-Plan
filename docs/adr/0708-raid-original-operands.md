# 0708. Record raid inputs at the original demand boundary

Every canonical country contributes command power, country modifiers, convoy reservations, ace data and essential stock. Only selected countries contribute strategic-air sites. Site selection happens before those objects are read, so missing sites for an unselected country do not prevent its other raid rows. Stockpile failure is independent. Site accesses use the original list order, including duplicates where the game preserves them. A batched read keeps the error the per-site walk would meet first. Autonomous flags use local fallback so a fault in one batch cannot make other readable flags disappear.

Offer inputs use effective stored modifier values under the modifier definition's registered clamp. Fixed built-in keys are gated by the installed game's metadata. An absent key remains missing. Aces require the registered air-range key and use the same acquired accumulator for their range and raw normalization operands. Wing and ace-owner terms are joined by canonical slots. In each hour, fresh native reads are needed for reservations and the ace's wing and alive state because no writer certificate covers their changes. Type range terms may be shared within that acquisition. Volunteer stockpile reuse requires an equipment-reload and world certificate.

Country raid selection uses a definition database separate from the raid system. The equipment requirement map orders entries by definition pointer. Content order cannot recreate it. Record the map's stored order and count, so an empty map differs from missing order. Its tree traversal acquires the count first, then visits each node in order and refuses malformed structure by name. Essential stock is recorded only for demanded archetypes, in whole units capped by the largest authored requirement for that archetype. A larger stock value cannot affect the affordability or shortfall outcome. The native archetype ID identifies one object, so its authenticated pointer can identify the allocation entry. The raid's own pool preserves variant entries and stored archetype totals separately. Native running sums can clamp independently, preventing a reconstruction of the totals from item rows. Arena shortage records the original demand and withholds the incomplete pool row.

Speed acquisition is hourly while the raid flies, including the first completed hour while the unit can still be visible. Daily variant data cannot certify the speed for that hour. A transport raid uses the maximum qualifying variant speed in its own pool, then in the owner's pool if the raid has none, then the native default. The convoy and nontransport paths follow their distinct original operands. The viewer combines content factors with those operands, and does not call a game calculation.

Tooltip acquisition keeps raw operands and native order. Direct modifier scans retain every occurrence, and binary-search fields retain the occurrence the native lookup selects. Wing mission statistics, army experience, manpower and target resistance come from their specific original sources. Experience uses all signed manpower entries, and maximum strength clamps at the native ceiling. Target selection and building requirement selection have different precedence. Map distance uses nonwrapping horizontal coordinates and the native signed wrapping squared comparison. Equal distances retain the first occurrence. Interceptors come only from the target country's pools in the matched mission region. Type, region and cached display strings are independent dependencies when the game can show them independently.

Army naming precedes wing naming. A cached or programmatic string can outlive its authored localization source. Retain its stored text and the naming group and raw user text where present. A ship's cached display name is decoded and published independently of derived naming operands. For stored strings, a complete header supports inline and heap forms. The heap copy includes the terminator. If it faults, the original terminator check retains its precedence. An unreadable string drops its own partial rows without hiding other naming data.

The signed definition count and ordered tree traversal are part of the definition database's layout. The transport branch reads the variant's retained candidate speed lane. Use the synthetic raid benchmark to measure direct and rebased guarded acquisition. `Rebased::new` gives the source ownership of its immutable image throughout the native copy.

The tooltip `names::string` reader borrows unpublished integer rows as byte scratch only when their capacity covers the text and its terminator. It reads the initialized prefix of a successful copy and writes the rows backwards so each new row leaves the unread data intact. Every integer field accepts any bit pattern used by the byte copy.

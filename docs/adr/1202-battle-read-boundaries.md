# 1202. Keep battle state bounded by the recording's dated reads

Merge battle windows in recording order regardless of network arrival. Prefetched windows never supply facts to earlier hours. A result and verdict appear only after the read that settles them, even if the result is dated earlier. When a result omits participants already known from a census, keep the participants from their supplying read. Absence from an unended census is not a defeat. A battle already in progress at the start of its recorded stretch only has a lower bound on length. For a known naval ending, use the native linked length without extending it to the result's timestamp.

The log prepares structure at roster, identity, result, coverage or known-field boundaries. Its painter updates visible loss and size cells between those boundaries. A row held ahead is bound or painted when its state first becomes visible. Opening a battle preserves the actual read. If it later leaves the list, retain its last listed state and date, but never show that state before its source hour. The ranked list uses the product's own rank and country filter, with peak size when the product cannot rank an older recording by casualties. The separate retained Combat Log disclosure takes the last paused hour while following, so holding it open never fetches each playing hour.

Load names and terrain for held windows before rows reach the clock and retain already-read places when scrolling. Terrain belongs to the client, recording revision and content revision. Naval fleet details read at the start of each held run, and report pending or refused status until a detail is supplied. Merge each compact loss delta against its previous read. Raw equipment stays exact even where the display number would exceed safe integer precision. The course chart breaks on unread spans and scans for bounds without passing an unbounded read list as call arguments. Use exact equipment in the tooltip even when the visible label shows whole amounts.

The dense-land-battle browser fixture distinguishes preallocated row bindings from elements remounted on a commit. It drives the native frame callback and measures the main thread until its posted message, when the frame has drawn. Deterministic state makes the frame counts comparable.

# engine-research

Native research readers and their operands, layouts and synthetic tests.

Demanded scripted sharing predicates use a country-wide ResearchModifiers roster
witness under the existing research certificate. Active countries reuse the group
identities already acquired for their research; idle countries read only the status
roster and group identities. Flat output storage preserves empty rosters and repeated
IDs without a new per-country vector.

The public capture API is available through [engine](../engine/README.md). Shared rules live in [AGENTS.md](../../AGENTS.md); field contracts, arithmetic, native gates and failure order stay beside each reader.

The module list is in [lib.rs](src/lib.rs). Production dependencies are [engine-characters](../engine-characters/README.md), [engine-executable](../engine-executable/README.md), [engine-native](../engine-native/README.md), [engine-projects](../engine-projects/README.md). Tests keep their synthetic fixtures and existing ignored scale gates.

Grant inventory acquisition shares the research input pass's authenticated status, including countries with no slots. It preserves both native grant rosters, signed counters and use/claim values, repeated technology/category restrictions and native occurrence order. Applied grant identities and values are reused in the same acquisition.

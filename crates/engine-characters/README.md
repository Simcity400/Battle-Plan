# engine-characters

Native characters readers and their operands, layouts and synthetic tests.

The public capture API is available through [engine](../engine/README.md). Shared rules live in [AGENTS.md](../../AGENTS.md); field contracts, arithmetic, native gates and failure order stay beside each reader.

The module list is in [lib.rs](src/lib.rs). Production dependencies are [engine-native](../engine-native/README.md). Tests keep their synthetic fixtures and existing ignored scale gates.

Scientist roster acquisition can demand injury recovery operands independently. The collector requests those operands only at its daily supplying read; the ordinary hourly roster and specialization walk does not read the injury timer.

The same daily demand authenticates the retained scientist role template and visible conjunction, including effect-installed replacement roles. Null and empty conjunctions require no content. Nonempty conjunctions retain their own source filename and line in a reusable arena; only the requested filename-pool chunks are visited. Ordinary hourly acquisition reads neither visibility state nor origin.

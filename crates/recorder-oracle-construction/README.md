# recorder-oracle-construction

Construction quantities, progress, output, target levels and occupation inputs. Owns [construction.rs](src/construction.rs) and its child tests. The [oracle command](../recorder-oracle/README.md) composes comparisons; this crate calls its specific dependent comparisons directly.

Table completeness, exact joins, differences and named limitations use [shared oracle support](../recorder-oracle-support/README.md). Content-dependent facts resolve through the recorded content stack. Synthetic fixtures are dev-only through the support crate's `test-support` feature.

Shared rules live in [AGENTS.md](../../AGENTS.md); the [recorder guide](../recorder/README.md) defines fresh-save/load and matched-native-observation checks.

Resource-map comparisons include native own/rights-holder origin order and outgoing lend-lease order from the save. The writer sorts resource rights by resource name, so their native order is runtime-only, along with received lend-lease, directional market contract and supply transfer client lists. Required positions and uniqueness are checked without claiming saved order equality; saved resource-right membership still compares exactly.

Market-referenced delivery routes' source/destination states compare exactly with the seller's saved `resources.delivery_routes` entry for the buyer. Contracts join by their saved seller/buyer and convoy-client handle; captured membership, route country/class and freshness are checked separately. Missing or different endpoint values fail. Only a seller/buyer pair with no serialized route entry has a named runtime-only limitation; present saved differences are never waived.

Delivery-route keys reconcile in both directions with every current client's reference, including imports and lend-lease. Shared references need only one route row; missing routes and unreferenced recorded routes are differences.

The active resistance hover compares every scripted target addition (amount, country selectors and tooltip) and the occupied country's exile host and legitimacy with the matched save. Spread caches, the compliance-gain ratio, local effect accumulators and source trees are runtime-only: their framing and root totals are checked without claiming that the save certifies their display. A matched native hover supplies that observation. Both resistance growth/decay trees follow the same framing, root-total and failure checks as target and compliance trees; no rate-tree exception is accepted. An absent root total fails validation even without error text; scalar capture and playback of independent keys remain available.

The occupation map comparison checks state-then-core active definition occurrences exactly, preserving order, duplicates, empty names and native first-NUL serialization even for inactive states. Core lists join by the actual retained-country witness, including empty groups and the reserved country, against the saved controller's occupation groups. The narrow zero-resistance/nonpositive-compliance target witness compares with the saved stored target, including omitted zero. Missing acquisition, saved wrappers, group keys and controller inputs fail the comparison. An omitted controller with a positive saved owner follows the serializer's canonical-equality gate; when the owner is omitted, the complete recorded state supplies the controller with a named unsaved dependency. The embedded group lookup link is unsaved, so the saved key certifies the retained country and list values without independently certifying that lookup or native group absence. Other saved targets are outside the map's narrow acquisition.

Occupation settings preserve the retained-country roster's order and join group laws by the captured retained country, including reserved ID zero. State override laws, garrison occupied countries and assigned-manpower occupied countries use the matching controller and embedded lookup record's retained-country witness from the same supplying hour. Missing, failed, ambiguous or differently supplied witnesses leave the dependent join incomplete; independent law and numeric comparisons still run. The saved key certifies the retained country and saved values, while the embedded lookup link remains unsaved.

Saved occupation country tags use their captured raw tag spellings and first-NUL serialization. Own-ID country rows and the reserved naming singleton supply those spellings; a CountryLinks alias alone cannot certify its spelling. Resistance country fields retain the serializer's signed-positive gate. The map's owner-omitted controller lookup resolves the captured state controller to its country holder independently of raw saved tag spelling.

# collector-construction

Construction capture: the construction rest's owned raw copy and decode, state and province buildings with the held building store that carries a quiet scope's rows, and the building writer observer that forwards to the territory, raid, rail and nuclear strike observers in collector-observers. The host owns dispatch, the World job's construction part, loans and table assembly.

Read the [shared rules](../../AGENTS.md) and the [collector guide](../collector/README.md).

Run `cargo test -p collector-construction` and `cargo clippy -p collector-construction --all-targets -- -D warnings` for its synthetic checks.

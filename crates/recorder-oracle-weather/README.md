# recorder-oracle-weather

Recorded weather and temperature save comparisons. Owns [weather.rs](src/weather.rs) and its child tests. The [oracle command](../recorder-oracle/README.md) composes comparisons; this crate calls its specific dependent comparisons directly.

Each saved weather province matched to a recorded row compares its modifier accumulator (`WeatherProvinces.modifiers`). The game sums into it, per modifier definition, `weather_mud` when the province has mud, the first thermal modifier whose interval holds its temperature, every static modifier in its `custom_modifiers` list in list order, and the ground snow modifier its snow plus permanent snow selects (capped at `snow_gain_max`; high wins where both intervals hold). The save writes no accumulator: a load rebuilds it from the saved mud, temperature, snow and list. The live one, which the game keeps applying, keeps the mud, thermal and ground snow modifiers of its last rebuild, because the hourly window rebuilds a province only when its mud, temperature class or ground snow modifier changed against the record's previous hour while temperatures and mud also change outside that test. So the accumulator's parts are compared as follows. Save-backed, compared exactly: the saved list's static modifiers and the arithmetic that sums them with the rest. Runtime-only, with no text-save equality claim (as `WeatherProvinces.display` is): which mud state, thermal and ground snow modifier the live accumulator holds, among those the content's intervals can select (a thermal interval an earlier one shadows, or a ground snow interval above `snow_gain_max`, selects nothing). An accumulator that is not the saved list's sum with one such state is a difference, listed per key against the load's own rebuild; one that two distinct states both fit leaves the list's part uncertified: that province is a failed comparison, so the comparison is incomplete. A static modifier adds its own entries whose definition has a category, zero values included, each scaled as the game adds it at multiplier one (a wrapping multiply by fixed5 one, then a signed division), never an `added_modifier` child's; a name without a recorded definition was dropped at load; one whose every entry is feature-gated off, with no tooltip or child, adds nothing. The intervals come from `common/weather.txt` ([`province_modifier_rules`](../installed-content-weather/src/weather.rs)) and the values from `common/modifiers`, both through the content stack, joined to the recorded ModifierDefinitions by script name. A live accumulator keeps an expired list entry's values until the province's next rebuild while the save no longer lists it; that difference is reported like any other. A refused row, or a province whose rebuild needs a refused or unread static modifier, is a failed comparison for that province; unread content or recorded definitions fail every recorded accumulator as one. Each leaves the comparison incomplete, never a pass.

A save-backed value left uncompared is a failed comparison, so the comparison is incomplete: a refused temperature derivation fails every saved temperature as one. Named limitations remain only for what the save does not hold (census-only and runtime-only fields) and for notes on how content values were read. Table completeness, exact joins, differences and named limitations use [shared oracle support](../recorder-oracle-support/README.md). Content-dependent facts resolve through the recorded content stack. Synthetic fixtures are dev-only through the support crate's `test-support` feature.

Shared rules live in [AGENTS.md](../../AGENTS.md); the [recorder guide](../recorder/README.md) defines fresh-save/load and matched-native-observation checks.

WeatherProvinces.daylight is runtime-only: the text save does not retain the manager's held seasonal direction or feather operands. Completed-update direction derives from date/content; suspended and initialization state requires the matched native observation specified in the lane's live checks. This adds no exemption to the save-backed weather comparisons.

WeatherRegions raw naval detection and Air attack/defence map terms, with their known-read gate, are runtime-only: text saves omit the live regional accumulator. The oracle names this limitation independently of saved weather comparisons. Integration must compare these words against matched native regional observations, including a missing key and a read refusal.

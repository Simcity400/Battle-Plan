# recorder-oracle-fog

Fog operands and visibility consistency checks. Owns [fog.rs](src/fog.rs) and its child tests. The [oracle command](../recorder-oracle/README.md) composes comparisons; this crate calls its specific dependent comparisons directly.

Table completeness, exact joins, differences and named limitations use [shared oracle support](../recorder-oracle-support/README.md). Content-dependent facts resolve through the recorded content stack. Synthetic fixtures are dev-only through the support crate's `test-support` feature.

Shared rules live in [AGENTS.md](../../AGENTS.md); the [recorder guide](../recorder/README.md) defines fresh-save/load and matched-native-observation checks.

State Air-base dense country order compares with the saved countries occurrences through recorded country identities. The independent demand/allocation columns compare exactly with fuel_consumption and received, including signed fixed5 remainders, repeated containers and zero omission. Pool partitions, empty-pool metadata and signed subtype grouping remain recording self-checks with a separate matched native check.

# installed-content-unit-path

Army, task-force and railway-gun movement admission, routes and selected transport text. The implementation and its tests live in [`unit_path`](src/unit_path.rs); the same public paths are exported through `installed_content::unit_path`. Shared parsing, identity and authored foundations come from [installed-content-core](../installed-content-core/README.md).

Authored map operands use the recorded content stack. Runtime movement facts come from the existing world interfaces and recorded state; missing operands remain named refusals. Preserve native admission, neighbour/heap order, per-occurrence arithmetic and early returns.

## Tests

Synthetic tests live beside the reader. Integration tests of independent readers live in `installed-content`; layer fixtures come from the core through dev-dependencies. `test-support` forwards the existing core test constructors and retains reader test gating. Runtime metadata tests initialize `BATTLE_PLAN_GAME_DIR`; ignored installation tests remain read-only. See the [installed-content contracts](../installed-content/README.md) and [project rules](../../AGENTS.md).

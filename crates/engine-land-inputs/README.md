# engine-land-inputs

Native land inputs readers and their operands, layouts and synthetic tests.

The public capture API is available through [engine](../engine/README.md). Shared rules live in [AGENTS.md](../../AGENTS.md); field contracts, arithmetic, native gates and failure order stay beside each reader.

The module list is in [lib.rs](src/lib.rs). Production dependencies are [engine-air-history](../engine-air-history/README.md), [engine-deployment](../engine-deployment/README.md), [engine-executable](../engine-executable/README.md), [engine-native](../engine-native/README.md). Tests keep their synthetic fixtures and existing ignored scale gates.

`doctrine_state` authenticates demanded doctrine statuses, folders, tracks,
commander contributions, cost reductions, mastery grants and equipment handles.
It follows only a same-pass census object or an exact writer receiver. Lexical
identities stay tokens; optional filters, signed fixed5 values and complete
commander references retain their native forms. CountryTacticUnlocks exposes its
already authenticated status-table header for the companion baseline. The
status reader authenticates only folder membership; the independently demanded
grant, reduction and equipment readers acquire their own headers.

The grant filter reads the authored track reference and numeric track index as
separate operands. A null track and an unfiltered index are independent absences.

[combat_log_history](src/combat_log_history.rs) reads retained group operands from an authenticated group header and settled battle records by requested pool index. It preserves empty equipment months, independent manpower counters, template occurrences, ordered battle references, serializer pool-presence gates and reusable battle-pool identities. These readers are worker-only; neither installs a census or periodic capture.

[combat_log_events](src/combat_log_events.rs) streams the specific operands
reached by native writers without allocation. Initial seeding accepts the
existing walk's group header; recurring acquisition reads the changed last
month, the template already located by the native writer, or one reached battle
slot. Native event sites are authenticated by purpose-named sentinels.

# collector-session

Session and map name capture: the session's world tension tables and DynamicModifiers, ProvinceNames and NavalRegionAccess, each published from its held read over an hour none of its native writers touched (the world input observer in collector-observers). The host owns dispatch, loans and table assembly.

Read the [shared rules](../../AGENTS.md) and the [collector guide](../collector/README.md).

Run `cargo test -p collector-session` and `cargo clippy -p collector-session --all-targets -- -D warnings` for its synthetic checks.

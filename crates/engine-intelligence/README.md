# engine-intelligence

Native intelligence readers and their operands, layouts and synthetic tests.

The public capture API is available through [engine](../engine/README.md). Shared rules live in [AGENTS.md](../../AGENTS.md); field contracts, arithmetic, native gates and failure order stay beside each reader.

The module list is in [lib.rs](src/lib.rs). Production dependencies are [engine-native](../engine-native/README.md). Tests keep their synthetic fixtures and existing ignored scale gates.

[Agency operation buffers](src/agency_operation_buffers.rs) passively capture the shared client UI buckets in native visit order, retaining stale/empty membership and unresolved references. Their resolved target states are authenticated separately from saved operation-roster admission.

The [network census](src/ccountry_intel_network.rs) acquires each actual network's retained coverage and strength aggregates once alongside its state rows, including networks without vertices. Its worker cache carries those independent values between daily rebuilds under the caller's writer certificate while the existing census checks current membership. A summary fault withholds summaries without refusing readable state rows; resets, loads, gaps and forced refreshes revoke reuse.

The [propaganda history reader](src/propaganda_history.rs) follows the native logical ring and copies only its two saved Q15 channels. It exposes the newest append separately from the independent weekly cache; unused capacity and unsaved effort channels are never recording inputs. The strategic census also exposes its already-acquired manager membership for auxiliary bootstrap reads.


[Source pools](src/intel_sources.rs) read independent dense allied/cryptology extents, ordered static/current/prior contributions, static source IDs and removals, dynamic pending values and accumulators, and source references. Source arithmetic helpers preserve keyed-zero membership, signed targets, native wrapping and prune order. [Writer sites](src/intel_source_sites.rs) identify the mutation contexts and low-level value boundaries, including the independent daily allied clear; readers enumerate no countries or potential viewer-target pairs.

The network auxiliary reader shares authenticated census membership and copied vertex identities. Its own rebuild/prepare/load/construction/destruction certificate selects actual networks; it retains ordered records, operatives, topology and independent subnetwork coverage, sums and detection operands. Selected strength/target terms come from the existing state rows.

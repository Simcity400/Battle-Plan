# recorder-oracle-governance

Country governance, focus, research and power-balance comparisons. Owns [governance.rs](src/governance.rs) and its child tests. The [oracle command](../recorder-oracle/README.md) composes comparisons; this crate calls its specific dependent comparisons directly.

Table completeness, exact joins, differences and named limitations use [shared oracle support](../recorder-oracle-support/README.md). Content-dependent facts resolve through the recorded content stack. Synthetic fixtures are dev-only through the support crate's `test-support` feature.

Shared rules live in [AGENTS.md](../../AGENTS.md); the [recorder guide](../recorder/README.md) defines fresh-save/load and matched-native-observation checks.

Politics compares its election interval with the saved election frequency. The cached next election date has no independent text-save field.
Doctrine comparisons cover every saved status slot, ordered selection and
completion, track scalar, commander reference/contribution, reduction, filtered
grant and equipment handle. Native invalid cost/grant entries project to the
serializer's anonymous empty blocks; no membership is excluded. Effective daily
mastery is an unsaved runtime cache and requires matched native observation.

Grant days are compared after the replay row API applies the recorded country
expiry counter to each grant's anchor. This compares the native saved day word
without assuming a daily clock schedule.

Mastery-grant track selectors compare saved token bytes with the recorded
track token spelling, independently of the optional signed track_index.
Research grant comparison joins the recorded inventory to each saved country, comparing the next ID, both ordered grant rosters, uses/claims, names, raw reductions and repeated restrictions, including zero-slot countries.

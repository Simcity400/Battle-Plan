# collector-raids

Raid input capture: RaidLaunchInputs and the raid state input tables, read beside their daily slices for the owners a raid writer marked (the raid observer in collector-observers). The host owns dispatch, loans and table assembly.

Read the [shared rules](../../AGENTS.md) and the [collector guide](../collector/README.md).

Run `cargo test -p collector-raids` and `cargo clippy -p collector-raids --all-targets -- -D warnings` for its synthetic checks.

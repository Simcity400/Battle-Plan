# collector-raids

Raid input capture: RaidLaunchInputs and the raid state input tables, read beside their daily slices for the owners a raid writer marked (the raid observer in collector-observers). The host owns dispatch, loans and table assembly.

Read the [shared rules](../../AGENTS.md) and the [collector guide](../collector/README.md).

FIFO decode sorts and validates the independent resource-rights, oil, temporary-resource and regional-efficiency rows from owned observations. Origins, clients, route selection and carry certificates remain in parked acquisition because they select native read demand.

Run `cargo test -p collector-raids` and `cargo clippy -p collector-raids --all-targets -- -D warnings` for its synthetic checks.

Resource-map row sorting preserves captured native ordinals as ordinary columns: both origin lists, origin rights and both directional convoy-client lists. These hourly operands change when native membership or order changes; route structure keeps its existing sliced cadence.

The route census marks market endpoint demand. Adding or removing that demand selects the owner, and endpoint states participate in route verification hashes. Only market-referenced routes acquire these optional state columns; they retain the route family's sliced cadence.

StateResourceInputs projects local manpower, noncore manpower, recruitment addition and recruitment factor as independent optional numeric columns. Existing state writer certificates and owner slices carry them; the state verification digest includes them.
Route carry consumes marks from state-to-state updates, supply port-to-port
updates and origin refresh's inline clear, alongside the route lifecycle writers.
A supply repath selects its owner even when its client and route addresses stay
the same. Convoy clients and route membership are read every hour. Membership,
storage and market endpoint-demand changes mark the census owner before sampled
comparison, so a known client removal replaces its rows without poisoning carry.

The hourly ace range read projects raw night/weather modifier entries from its existing complete accumulator copy for living aces. The range metadata and failure order stay unchanged; no second accumulator read or added hook is used.

The same owned accumulator copy projects living aces' raw fuel modifier entry, including known absence; no additional read or cadence is introduced.

Volunteer senders' uncapped whole-plane stockpile totals fold the existing allocation bytes before essential-equipment filtering. A retained plane-classification cache carries under the existing local-subunit observer's equipment reload certificate and world lifetime, with no second stockpile walk or new hooks. Failed certification withholds this independent RaidCountryInputs scalar.

Living ace speed/attack/defence raw terms project the complete own-range accumulator read. The existing per-type range memo also retains raw speed and direct-positive attack/defence predicates from its original complete copy. Independent numeric columns and known bits delta separately, with no added native reads or acquisition schedule; playback applies recorded metadata to raw speed.

# engine-events

Native events readers and their operands, layouts and synthetic tests.

The public capture API is available through [engine](../engine/README.md). Shared rules live in [AGENTS.md](../../AGENTS.md); field contracts, arithmetic, native gates and failure order stay beside each reader.

The module list is in [lib.rs](src/lib.rs). Production dependencies are [engine-deployment](../engine-deployment/README.md), [engine-native](../engine-native/README.md), [engine-peace](../engine-peace/README.md), [engine-production](../engine-production/README.md). Tests keep their synthetic fixtures and existing ignored scale gates.

Script-event sites observe accepted dispatch, admitted choices, retained pending/fired writers, delayed scheduling and sparse pass/cursor boundaries. Scope graphs follow ROOT/FROM/PREV iteratively into caller-prepared storage, retaining shared links, native random words and object references without serializing pointers. Saved-target, tooltip-target and combat operands have independent refusal flags. Retained registries have one baseline per observed world; native append readers demand only the selected entry.

Sparse duration sites reuse the effect-selected mission/removal timer and native add operand. Explicit cooldown clearing observes all three affected membership headers; the ordinary mission display-duration helper exposes its final selected result after authored/default evaluation. No timer-visit observation is added.

Decision sites cover actual append/erase/cleanup, selected reactivation/results, admitted hourly/refresh pass anchors, pre-effect cuts, reset/restore, target candidate/filter and ignore writers, and description-count increments. Quiet timer visits have no site. The owning politics and script-variable families publish their forwarded sites.

Decision roster presentation uses only the final native candidate-clear boundary; intermediate allowed/target rebuild entries have no observer publication.

Adjacent selected decision CALLs expose their owned verification length separately from their stored fingerprint; the duration-reactivation and timed request prefixes end at the following selected CALL. Written patches remain five bytes.

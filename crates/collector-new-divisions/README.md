# collector-new-divisions

New division capture: the hourly equipment of the divisions minted since the daily DivisionEquipment walk, found from the unit id and reference registry counters. The host owns dispatch, loans and table assembly.

Read the [shared rules](../../AGENTS.md) and the [collector guide](../collector/README.md).

Run `cargo test -p collector-new-divisions` and `cargo clippy -p collector-new-divisions --all-targets -- -D warnings` for its synthetic checks.

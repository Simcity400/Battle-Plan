# collector-observers

World-input admission counts its complete base hook group before companion hooks
are appended. Companion storage does not withdraw the shared design or fog
forwarders; a missing base group still refuses them.

The country-input observer has an independent design-modifier consumer for the
country accumulator's existing recalculation/reset writers. Its marks select
demanded equipment-design country operands without consuming visibility marks.
Faction research sharing has an independent retaining registry beside the country-input dirty sets. Existing membership/bonus hooks forward their group receiver, and the existing scientist-base before/after check forwards changed or unreadable bases. A faction consumer takes per-group certificates without consuming another consumer's marks or patching the same native site twice.

Between-tick native writer observers that several capture families share, with the forwarders that let one patch owner per native site notify the others: country inputs (and the weather carry diagnostics they report), rosters, characters, census, advisor pools, opinions, the output and event ledgers, nuclear strikes, wars, naval trees, unit leaders and their traits, retreat bans, raids, air base carry with the air registration counts, rail, territory, the event feed with its history, entry stub and native guard, and war provenance, political status, world inputs, wings, air losses and building bombing. The host installs the hooks, drains the stores at the hourly boundary and composes the capture families that read them.

The war domain forwards status, relation-slot and diplomacy lifetime receivers to the participation owner before and after native mutation. These fixed-size marks keep invalidation local to the affected owner or war while the domain token excludes acquisition.

Read the [shared rules](../../AGENTS.md) and the [collector guide](../collector/README.md).

Market boundary recovery is independent of event availability. A first, lost or
partial interval revokes held state before the existing economy census, and a
fresh census epoch publishes a complete baseline even without a caller full flag.
Off the daily owning-contract slot, the resource census completes the missing
contract seed once for that epoch; quiet epochs read no native contract list.
The ledger keeps the true interval loss named; it cannot poison the new state
baseline. Even an empty country census advances the held epoch.
Country discovery binds early native-read failures to the new epoch before
census completion, so a failed header cannot become a complete empty baseline.
A failed shared bootstrap does not trigger a contract-read retry.

Spool-only loss refuses its lost interval but leaves the next intact interval
complete, preserving its events without another state census. Unresolved native
execution retains a separate recovery verdict, even if spool loss also occurs.
The owning-contract census records attempted and successful states independently;
off-slot recovery visits only a skipped census, never a failed attempt.

Country receiver keys encode ID zero as a nonzero registry key; reset and the
three country domains use the same encoding. Their live-sized tables still
come from the existing sizing census. An active purchase-contract removal emits
its fixed final-progress witness and lifetime before native reference retirement;
the later retired destructor emits no duplicate. Retirement places the former ID
in the type word and the retirement marker in the ID word, with registration
cleared. The observer checks registration before treating that marker as retired,
so an active contract whose ID equals the marker still emits its final witness.

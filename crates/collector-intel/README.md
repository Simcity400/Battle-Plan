# collector-intel

Faction variable ownership uses the existing variable watch registry through non-consuming embedded-store certificates. Epoch/sequence and release/exception structure tokens certify each demanded embedded store; this does not consume the ScriptVariables dirty stream or install another hook.

The existing live variable-scope sizing prepares watches before the first boundary; ordinary scopes, MIO stores and faction stores contribute additive demand to that table.

Intel capture: country intel, agencies, operations and operatives, script flags and script variables, the shared daily CountryIntel buffer, and the flag and variable writer observers that let quiet scopes carry their rows. The host owns dispatch, loans, the spool conversion caches it lends and table assembly.

Read the [shared rules](../../AGENTS.md) and the [collector guide](../collector/README.md).

Run `cargo test -p collector-intel` and `cargo clippy -p collector-intel --all-targets -- -D warnings` for its synthetic checks.

`AgencyOperationBuffers` reads the four shared agency UI lists every hour, including stale and empty snapshots. Header-sized worker storage grows through the guarded allocation path; unchanged snapshots use the ordinary row delta carry. This client cache is not a reconstructed per-country saved roster.

Variable writer hooks also notify registered project stores. Context-ending callbacks share the existing context read; exception or unreadable-context paths revoke project variable carry. The project forwarder is disabled before any hook/exception-handler transition can fail.

`IntelNetworkSummaries` shares the existing `IntelNetworks` census, daily scheduling and reset/growth observation. It reads the aggregate payload once per actual network on a daily/forced refresh, reuses authenticated unchanged payloads on an intervening census, and delta-encodes only changed fields. Existing forwarded country-reset counts and load/gap epochs revoke payload reuse even when a recreated network reuses its address and pair; console growth preserves the independent national cache. No additional country/network walk or hourly aggregate polling runs. Without the writer certificate an unscheduled summary acquisition is unavailable by name. Summary failures remain independent of readable state rows.

`PropagandaEfforts` observes the strategic operative's daily append and reset. Callbacks mark only the native receiver, without native reads or allocation. The worker reads the marked owner's newest saved stability/war-support pair, retains logical history and derives the daily weekly sum. Reset clears are derived without payload reads. Bootstrap reuses the strategic census's roots and manager header, including the saved reserved/unused-country objects, and preserves an independently loaded weekly cache. Quiet hours carry without scanning retained owners or reading native history. Surviving effort keys stay stable, and a repeated unchanged full history emits no daily rows. Lost observations require a daily/forced bootstrap and stay unavailable in between.


`IntelContributions` and `IntelSources` share authenticated roots with the existing daily CountryIntel census, including empty and reserved roots. Native writer hooks publish source setters, IDs, retirement, pruning, pending additions, aggregation, decay, replacements and held-reference mutations. The worker derives exact arithmetic and clears from retained state, including the independent daily allied clear outside sharing-group replacements, reads only replaced vectors or affected independent merge results, and carries quiet cuts without owner scans or allocation. Lost observations refuse coverage until the existing daily/forced census. Explicit extent headers preserve ordered duplicates, keyed zeros and empty pools; dense zero entries are implicit inside the native extent. Held cheat/radar/token/network references keep their independent identities. Status includes writer-specific failures, the first diagnostic and retained memory.

`IntelNetworkAuxiliaries` has its own receiver-only writer certificate. The existing network census supplies membership and copied state identities; only marked held networks are read on the residual worker. A newer topology rebuild waits for that census instead of reusing stale identity operands. Independent occurrence keys preserve duplicates/order, including unselected subnetworks. Quiet cuts carry before owner visits or native reads. Each existing census grants one attempt; membership preparation and acquisition failures revoke it until the next census.


Hook installation errors retain the source/propaganda/network family, exact named site and underlying sentinel, construction or publication cause. Diagnostics run outside native flights and suspended publication.
The script-variable hook family owns delayed-event pass entry and sparse cursor publication, forwarding pass observation to the existing event feed. Its context-ending observation remains in the same publication owner; event-feed coverage requires that forwarder enabled.

The four hourly certified tables (`PropagandaEfforts`, `IntelContributions`, `IntelSources`, and `IntelNetworkAuxiliaries`) retain a shared lazy handle to the already-certified acquisition vectors. Changed worker cuts transfer vector ownership in constant time; they do not allocate/copy replay tables, sort keys or enter the projection lock. The spool alone materializes the replay snapshot through the ordinary `table()` conversion, including key sorting and duplicate refusal. It returns the original native vectors before off-thread frame growth/reuse, including cuts that were never admitted to a recording. Quiet hours lend the same handle and reuse its immutable replay allocation. A fresh encoder, periodic keyframe or post-gap keyframe can materialize a baseline independently of previous admission. Advisory projection allocation failure retains the acquisition for a spool retry; coverage loss clears the handle and remains a named refusal until the existing recovery census. Observed empty membership is a complete baseline. Family status accounts retained native and replay storage. `IntelNetworkSummaries` keeps its existing daily/forced census and spool cache. No native certificate, hook, read scheduling, schema or ID changes.

ScriptFlags' existing pre-install sizing walk also counts every scope, including empty managers, for the shared flag-watch demand. Embedded MIO stores add to that complete demand instead of installing an undersized first table. Watch growth otherwise waits for an invalidating boundary; even one refused registration prevents whole-walk carry. With complete certificates, quiet hours publish the held walk without scope/container reads, apart from the unchanged sampled verification slice; writer marks refresh only their managers. Flag dates are stored set hours, not hourly ages, and positive remaining days change only through the observed daily expiry writer. Missing certificates and failed reads keep the existing fresh-read/refusal path.

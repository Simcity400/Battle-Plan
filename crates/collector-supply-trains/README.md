# collector-supply-trains

Supply train capture: SupplyNodes and TrainInventory, read in parts beside the daily slice. The host owns dispatch, loans and table assembly.

Read the [shared rules](../../AGENTS.md) and the [collector guide](../collector/README.md).

Run `cargo test -p collector-supply-trains` and `cargo clippy -p collector-supply-trains --all-targets -- -D warnings` for its synthetic checks.

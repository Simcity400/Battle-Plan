# collector-naval-details

Naval combat capture for the ordinary naval part: live naval combat details, NavalModifierTrees under the naval tree observer's certificates, naval result details and naval combat sources, with the synthetic fixtures the host's runtime and spool tests reuse. The host owns the part's dispatch, loans and table assembly.

Read the [shared rules](../../AGENTS.md) and the [collector guide](../collector/README.md).

Run `cargo test -p collector-naval-details` and `cargo clippy -p collector-naval-details --all-targets -- -D warnings` for its synthetic checks.

The shared source-tree projection also accepts a narrow demanded key set; escort hovers reuse its pruning without adding escort to every combat tree.

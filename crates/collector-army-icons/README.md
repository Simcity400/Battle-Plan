# collector-army-icons

Army icon inputs capture: ArmyIconInputs, read from the division sources and the seeded unit inputs whose census gathers both icon fields. The host owns the ArmyIcons job's dispatch, the division source loan and table assembly.

Read the [shared rules](../../AGENTS.md) and the [collector guide](../collector/README.md).

Run `cargo test -p collector-army-icons` and `cargo clippy -p collector-army-icons --all-targets -- -D warnings` for its synthetic checks.

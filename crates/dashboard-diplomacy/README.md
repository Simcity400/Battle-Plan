# dashboard-diplomacy

Sparse opinions, relation-tuple occurrences and observed incoming proposal episodes share one `diplomacy_state` block pre-pass, resumable continuation and series store. The streams retain independent coverage and supplying reads. Queries read selected prepared pages; a cold opinion snapshot reads at most one cadence window and is marked `snapshot`.

Missing opinions are zero only with complete owner and target proof. Aliases, raw signed totals and self-pairs survive; gaps and identity changes end continuity. Pair history follows the first native holder, excluding tag reuse.

Pacts retain ordered roles, native dates, raw flags and observed presence bounds, not an invented active predicate. Proposal handles remain decimal strings; neither queue order, action_type nor status supplies a kind or outcome. `identities` and `rawCountries` follow the wire roles in order. Read evidence includes every returned storage or queue owner, regardless of tag selection.

`prepared/{opinions,tuples,proposals}` separate read proof, projection and episode updates. `query` separates selection, inventory, naming and read coverage. Shared diplomacy selectors resolve labels through the recorded content stack; missing operands, empty selectors and missing localisation remain counted refusals without losing raw state.

Tests are synthetic and need no game installation.

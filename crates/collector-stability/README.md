# collector-stability

Country stability capture: CountryStabilityInputs and CountryStabilityLines, read beside the daily slice for the countries a country input writer marked. The host owns dispatch, the fingerprint store loan and table assembly.

Read the [shared rules](../../AGENTS.md) and the [collector guide](../collector/README.md).

Run `cargo test -p collector-stability` and `cargo clippy -p collector-stability --all-targets -- -D warnings` for its synthetic checks.

# collector-projects

Projects and raids capture: special projects and project history, raids with their paths, facilities and counter-operatives, raid target statuses, and the raid intel carry that answers a country's raid intel values from its held read. The host owns dispatch, loans and table assembly.

Read the [shared rules](../../AGENTS.md) and the [collector guide](../collector/README.md).

Run `cargo test -p collector-projects` and `cargo clippy -p collector-projects --all-targets -- -D warnings` for its synthetic checks.

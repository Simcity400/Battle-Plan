# engine-raid-inputs

Native raid inputs readers and their operands, layouts and synthetic tests.

The public capture API is available through [engine](../engine/README.md). Shared rules live in [AGENTS.md](../../AGENTS.md); field contracts, arithmetic, native gates and failure order stay beside each reader.

The module list is in [lib.rs](src/lib.rs). Production dependencies are [engine-executable](../engine-executable/README.md), [engine-intelligence](../engine-intelligence/README.md), [engine-native](../engine-native/README.md), [engine-projects](../engine-projects/README.md), [engine-resources](../engine-resources/README.md), [engine-stability](../engine-stability/README.md). Tests keep their synthetic fixtures and existing ignored scale gates.

StateResourceInputs includes four effective recruitment entries for selected controlled states. Acquisition reuses the resource pass's copied base accumulator and state hash header, and its authenticated country mapping. A selected country accumulator is read only when needed. Recruitment failures remain independent of the resource operands.

The regional superiority reader copies the Air map mode's two active-mission counters with its weights and movement impact. It separately copies the independently optional regional aircraft spotting scale from the same selected records. It reads only the regions in the native air-update phase, carrying the others and failed scale observations under the existing reset certificate. Entries are sparse only when both weights, both counters and the observed scale are zero; unknown scales remain explicit, and the final-region witness remains.

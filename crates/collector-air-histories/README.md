# collector-air-histories

Air history capture: the air history tables, re-read beside the daily slice only where a native writer touched them, with the history writer observer. The host owns dispatch, the fingerprint loan and table assembly.

Read the [shared rules](../../AGENTS.md) and the [collector guide](../collector/README.md).

Run `cargo test -p collector-air-histories` and `cargo clippy -p collector-air-histories --all-targets -- -D warnings` for its synthetic checks.

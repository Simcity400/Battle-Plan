# collector-naval-movement

Country naval movement inputs: the physical navy census and reserved launch sources that the country appearance, country counter and naval mission families read. The host owns the navy pass, loans and installation into the appearance pack.

Read the [shared rules](../../AGENTS.md) and the [collector guide](../collector/README.md).

Run `cargo test -p collector-naval-movement` and `cargo clippy -p collector-naval-movement --all-targets -- -D warnings` for its synthetic checks.

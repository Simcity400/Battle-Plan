# collector-governance

Governance capture: politics, political parties and party leaders, ideas, research and technologies, focus, decisions and timed effects, buildings, and the held fingerprint, building, party-leader and party stores that let quiet countries carry their rows, with the party and party-leader writer observers. The host owns dispatch, loans and table assembly.

Read the [shared rules](../../AGENTS.md) and the [collector guide](../collector/README.md).

Run `cargo test -p collector-governance` and `cargo clippy -p collector-governance --all-targets -- -D warnings` for its synthetic checks.

# collector-visibility

Country visibility capture: CountryVisibility, carrying an unmarked country's raw accumulator entry under the country input family's marks beside its daily slice, with the live definition and eligibility metadata applied every hour. The host owns dispatch, loans and table assembly.

Read the [shared rules](../../AGENTS.md) and the [collector guide](../collector/README.md).

Run `cargo test -p collector-visibility` and `cargo clippy -p collector-visibility --all-targets -- -D warnings` for its synthetic checks.

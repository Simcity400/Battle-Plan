# collector-extended-support

Outcome, sizing and hourly-boundary contracts the extended capture families share: the missing-source and failed-capture outcomes, truncated sources and elapsed ticks, raid read counts, failed sizing observations with census storage demand and the live world they read, the frame pool size and the native-tick marker, the exact wall-time distribution the spool, the runtime and the country counter phases record, and (under `test-support`) the synthetic many-country world the capture-cost benches share. The host composes every family; neither this library nor a family reaches the host.

Read the [shared rules](../../AGENTS.md) and the [collector guide](../collector/README.md).

Run `cargo test -p collector-extended-support` and `cargo clippy -p collector-extended-support --all-targets -- -D warnings` for its synthetic checks.

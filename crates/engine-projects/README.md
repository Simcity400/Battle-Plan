# engine-projects

Native projects readers and their operands, layouts and synthetic tests.

The public capture API is available through [engine](../engine/README.md). Shared rules live in [AGENTS.md](../../AGENTS.md); field contracts, arithmetic, native gates and failure order stay beside each reader.

The module list is in [lib.rs](src/lib.rs). Production dependencies are [engine-native](../engine-native/README.md) and [engine-characters](../engine-characters/README.md). Tests keep their synthetic fixtures and existing ignored scale gates.

The program acquisition appends primary and supporting scientist assignments to its existing owned byte arena. Full references, signed delayed-action target/current values and the timed byte retain native order. A zero reference omits timer reads. The project pool walk retains acquisition-only object identity for the runtime consumer.

Daily facility details reuse acquired lead/support references and the selected program. They visit only its configured building, active-project index, assigned scientists, specialization entries and requested modifier keys. Independent scalar-source observations preserve native ordering, signed arithmetic and partial-health rounding; no source tree or extra census is read. Pending reward identity includes its occurrence in the retained template roster.

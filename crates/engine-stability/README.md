# engine-stability

Native stability readers and their operands, layouts and synthetic tests. The
faction upgrade reader owns independent research, doctrine and advisor-slot
companions and shares this crate's stored modifier reader.

The public capture API is available through [engine](../engine/README.md). Shared rules live in [AGENTS.md](../../AGENTS.md); field contracts, arithmetic, native gates and failure order stay beside each reader.

The module list is in [lib.rs](src/lib.rs). Production dependencies are [engine-native](../engine-native/README.md). Tests keep their synthetic fixtures and existing ignored scale gates.

Demanded embedded modifiers can copy their ordered stored entries and literal
display names into retained worker storage. The reader leaves writer-certificate
selection and publication to its caller and never recalculates the modifier.
Selected stability input reads reuse their authenticated diplomacy identity for the country recruitment ratio, exile host and exile-only legitimacy, recruited-leader count, manpower and cap. Each scalar keeps its own availability.
